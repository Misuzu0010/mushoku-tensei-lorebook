# 任务：批量将小说 EPUB 转为按卷切分的纯净 Markdown 章节（EPUB Preprocessing Engine）

本规约旨在指导编写与执行本地脚本（`tools/convert_all.py`），将原始日轻/网文 EPUB 电子书，精准、无损、按卷切分为标准化、易于大语言模型批量处理的 Markdown 正文章节，为后续设定提取与角色语料挖掘奠定基石。

---

## 一、输入与输出规范

- **输入目录**：`inputs/`（包含 1~N 卷电子书，如 `inputs/*.epub`）
- **输出目录**：`outputs/chapters/{volume_id}/`
  - 示例：第 1 卷输出到 `outputs/chapters/01/`，第 15 卷输出到 `outputs/chapters/15/`
- **章节文件命名**：`{chapter_id:02d}_{chapter_title}.md`（如 `01_第一话_「家庭教师到来」.md`）
- **日志输出**：
  - 各卷独立日志：`outputs/chapters/{volume_id}/convert_log.md`
  - 全局总览日志：`outputs/chapters/_summary.md`

---

## 二、核心处理原则（四大硬性铁律）

### 1. 章节真实物理顺序：以 OPF 的 spine 顺序为绝对准绳
- EPUB 内文件名（如 `Section0001.xhtml`、`text_12.html`）中的数字编号经常混乱或带有后置补丁（`-1`、`_2`）。
- **绝对严禁按文件名字母序排序**。必须解析 `content.opf` 中的 `<spine>` 节点，严格按照 `<itemref>` 声明的阅读顺序进行遍历。

### 2. 章节标题提取三级降级策略
- **优先级 1（首选）**：读取 `toc.ncx` 或 `nav.xhtml` 中与当前页面匹配的导航标签 `<navLabel><text>`。
- **优先级 2（备选）**：若 NCX 缺失或为空，抓取正文中的第一个标题标签（`<h1>` 或 `<h2>`，并剔除样式与注音）。
- **优先级 3（保底）**：若正文亦无标题，采用 `chapter_{index:03d}` 兜底，绝不中断流程。

### 3. 内容智能语义判别（基于文本实质而非文件名）
轻小说 EPUB 包含大量插图页、版权宣告、彩页与扉页。遍历 spine 中的每个文件时，按实质内容判定其流向：

| 页面分类 | 判定特征 | 处理策略 | 日志记录要求 |
|:---|:---|:---:|:---|
| **正文章节** | 包含实质文本段落（中文/日文长文本、对话引号） | **保留**，清洗后转换为 `.md` | 记录章节标题、字数与来源文件 |
| **纯插图/彩页** | `<body>` 内主要是单张或多张 `<img>`，纯文本不足 30 字 | **跳过**（不输出文件） | 记录跳过原因：`[纯插图页]` |
| **扉页/卷首** | 仅含书名、卷号或章节单标题，无正文叙述段落 | **跳过**（将其标题合并至后续正文） | 记录跳过原因：`[扉页/标题占位]` |
| **目录/跳转页** | 核心内容为 `<a>` 链接列表或 nav 导航 | **跳过** | 记录跳过原因：`[目录导航页]` |
| **版权/出版元数据** | 包含 Publisher、ISBN、Colophon、版权声明等文本 | **跳过** | 记录跳过原因：`[版权页]` |
| **后记/作者感言** | 包含“后记”、“あとがき”等实质性文字 | **保留**（作为独立章节输出） | 记录：`[后记]` |
| **特稿/短篇/特典** | 包含“特典小册子”、“特稿短篇”等正文文本 | **保留**（作为独立章节输出） | 记录：`[特典正文]` |

> [!TIP]
> **疑难处置原则**：看内容实质，不迷信文件名。若某页介于插图与正文之间（如插图配有重要旁白或手写信件），**倾向保留**，绝不漏掉有效剧情。

### 4. 绝对零静默丢失原则
- 整个转换过程中，**严禁静默跳过任何一个 spine 声明的文件**。每一个被跳过的文件都必须在 `convert_log.md` 中标明理由。

## 三、HTML 语义清洗与排版规范

### 1. 结构与标签转换
- **容器标签**：`<div>`、`<span>` 仅作为容器，不额外引入换行符。
- **段落标签**：`<p>` 转换为 Markdown 独立自然段，段落之间保留**一个空行**。
- **内联换行**：
  - 段落内的 `<br />` 替换为**单个半角空格**，防止把同一句话切断成多行。
  - 标题内的 `<br />` 替换为**单个半角空格**，保证标题在一行内完整显示。
- **注音标签**：彻底清理 `<ruby>`、`<rt>`、`<rp>`，**仅保留正文汉字**，移除注音符号（假名/拼音）。
- **脚本与样式**：彻底删除 `<script>`、`<style>` 标签及其包裹的所有内容。
- **插图标签**：移除所有内联 `<img>` 标签，避免生成破碎的图片占位符。

### 2. 标点符号与版式保留
- **100% 原样保留标点**：严格保留直角引号 `「」`、双引号 `『』`、全角破折号 `——`、全角省略号 `……`、问叹号 `？！`。
- **严禁机械替换**：
  - 严禁将中文标点强制转为英文半角标点（如把 `……` 替换成 `...`，或把 `「」` 替换成 `""`）。
  - 保留日文排版中的全角空格 `　`（若用于对话前缩进或语速停顿）。

### 3. 空白与垃圾字符过滤
- 剔除无意义空段落（如 `<p><br/></p>`、`<p>&nbsp;</p>`、`<p>   </p>`）。
- 连续多空行一律合并为单个空行。
- 段首段尾的多余空白字符执行 strip 处理。

## 四、特殊边界场景与长篇特异性应对

1. **同一章节跨文件分卷（如 `Section012` + `Section012-1`）**：
   - 若在 spine 顺序中相邻、标题完全一致且文意承接，应自动合并为一个完整章节。
   - 若标题不同或无法确认连贯性，分别输出并于日志中提示 `[疑似同一章切分]`。
2. **特殊图文混排（如《无职转生》第15卷未来日记插图）**：
   - 部分书籍的关键剧情（如老鲁迪日记）以图片形式印刷，导致 OCR 缺失。脚本应预留补充注入接口（如 `tools/vol15_diary_data.py`），对特定章节自动追加文本还原。
3. **编码安全性**：
   - 全流程必须以 `utf-8` 编码读写，严格处理 Windows 平台下的 `\r\n` 换行符与控制字符。
