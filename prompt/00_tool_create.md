# 任务：批量将 EPUB 转为按章切分的 Markdown

## 输入
- `epubs/` 目录下的所有 `.epub` 文件（共 15 本）
- 每本结构可能不同，**不要假设任何一本的具体文件名**

## 输出
- 每本书提取的各个章节输出到：`outputs/chapters/<卷数>/` 
- （示例）`无职转生 ～到了异世界就拿出真本事～ 01` 的输出文件夹为`outputs/content/<01>/`
- 每章一个 `.md` 文件
- 章节文件命名：`<章节数>_<章节标题>.md`


## 核心要求

### 1. 章节顺序：以 OPF 的 spine 为准
- 每本 epub 都有 `content.opf`（若无则报错跳过该本）
- **必须按 spine 顺序**，不要按文件名排序
- 文件名里的 `-1`、`_2` 等后缀不代表顺序

### 2. 章节标题：优先 NCX，其次正文 h1/h2
- 优先从 `toc.ncx` 取标题
- NCX 缺失或为空时，取正文第一个 `h1`/`h2`
- 都为空时用 `chapter_XXX` 兜底

### 3. 文件分类：由你根据内容判别（关键）
遍历 spine 中的每个文件，**根据文件内容判断它属于哪一类**：

| 类别 | 判别特征 | 处理 |
|---|---|---|
| **正文** | 纯文本段落多，有实质内容 | 保留，转 md |
| **插图页** | body 内主要是一个或多个 `<img>`，几乎没有文本 | 跳过 |
| **扉页** | 只有章节标题，无正文段落 | 跳过（标题归入下一章） |
| **目录页** | 内容为 `<a>` 链接列表 | 跳过 |
| **版权/元数据** | 文件名或内容含 title/copyright/colophon 等 | 跳过 |
| **后记** | 有实质文本，含"后记""あとがき"等 | 保留（作为一章） |

**判别原则：**
- **看内容，不看文件名**。文件名仅供参考，不同书命名规律完全不同。
- 判别不确定时，**倾向保留**（宁可多转，不可误删）。
- 判别标准要在 15 本书之间保持一致。

### 4. 每个判断都要写进日志
**绝对不允许静默跳过任何文件。** 每个被跳过的文件都要记录原因。

## 技术实现

- Python 3.14
- 依赖：`ebooklib`、`beautifulsoup4`、`lxml`
- 使用 `ebooklib` 读 spine 和 NCX，用 `BeautifulSoup` 解析 xhtml
- 运行方式：
  ```
  python convert_all.py inputs/epubs outputs/chapters
  ```

## 文本清洗

### 一、XHTML 结构特征（转换时要处理）

1. 正文通常被 `<div>` 包裹，div 内才是真正内容
2. 标题标签可能是 `<h1>` ~ `<h6>` 任意级别，且常带 class（如 `class="illus1 tco6"`）
3. 空段落用 `<p><br /></p>` 或 `<p>&nbsp;</p>` 表示
4. 段落内可能有 `<br />` 换行
5. 标题内也可能有 `<br />`
6. 可能含 `<ruby>` 注音标签
7. 可能含图片：`<img src="..." />` 在 `<div class="illus...">` 内

### 二、清洗规则

#### 1. 标签处理
- **标题**：`<h1>` ~ `<h6>` 一律视为标题。级别不影响处理方式。
  - 保留文字，去掉标签
  - 标题内的 `<br />` 替换为**空格**（让标题成为一行）
- **段落**：`<p>` 保留为独立段落
  - 段落内的 `<br />` 替换为**空格**（不要换行，避免破坏段落）
- **div**：作为容器，不产生换行标记
- **ruby**：删除 `<rt>` 和 `<rp>` 标签及其内容，只保留汉字
- **script / style**：整体删除
- **img**：如果所在 div 有 class 含 "illus"，整个 div 删掉（插图页）；否则只删 img 标签

#### 2. 空内容处理
- `<p><br /></p>`、`<p>&nbsp;</p>`、`<p> </p>` → **整段删除**
- 纯空白段落 → **整段删除**
- 连续空行 → 合并为一个空行
- 段首段尾空白 → 去掉

#### 3. 标点与符号
- **原样保留**：`「」『』`、`……`、`——`、`！`、`？` 等
- **不要**把中文标点转成英文标点
- **不要**把 `……` 转成 `...`
- **不要**把 `「」` 转成 `""`

#### 4. 段落合并与切分
- 同一 `<p>` 内的内容**不切分**
- 不同 `<p>` 之间用**一个空行**分隔
- 标题与其后第一个段落之间用**一个空行**分隔
- 不要合并相邻段落（原文一个 p = md 一个段落）

#### 5. 不做的事
- 不改写任何文字
- 不调整标点
- 不删除对话引号
- 不合并段落
- 不补全省略号
- 不加任何 AI 生成的说明性文字

### 三、输入输出示例

#### 输入（xhtml 片段）

```html
<div>
  <h4 class="illus1 tco6">特典小册子<br />
  『腹肌的力量』</h4>

  <p>「今天要来锻炼腹肌。」</p>

  <p><br /></p>

  <p>基列奴在我和艾莉丝面前如此宣言。</p>

  <p>地点是室内，平常被用来当作舞厅的场所。</p>
</div>
```

#### 输出（md）

```markdown
## 特典小册子 『腹肌的力量』

「今天要来锻炼腹肌。」

基列奴在我和艾莉丝面前如此宣言。

地点是室内，平常被用来当作舞厅的场所。
```

**注意**：
- 标题里的 `<br />` 变成了空格（一行标题）
- `<p><br /></p>` 空段落被删掉
- 其他段落各占一行，之间空一行
- 对话引号原样保留
- 标题级别：源文件是 h4，输出统一用 `##`（或按脚本设定，但要统一）

### 四、边界情况

| 情况 | 处理 |
|---|---|
| 标题为空（如 `<h4></h4>`） | 删除该标题行 |
| 标题只有 `<br />` | 删除该标题行 |
| 段落内多个 `<br />` | 全部替换为空格 |
| 段落内容只有图片 | 删除该段落 |
| 段落前后有大量空格 | strip 掉 |
| 全角空格 `　` | 保留（日文排版用） |
| `&nbsp;` | 视情况：单独成段则删，句中出现则保留为空格 |


## 输出格式

每章 md：

```markdown
# 章节标题

（正文部分）
```

## 转换日志

每本书输出一份 `chapters/<卷数>/convert_log.md`（卷数定义同上），包含：

1. **书籍信息**：书名、总 spine 文件数
2. **章节列表**：编号、输出文件名、来源 xhtml、标题、字数
3. **跳过列表**：文件名、判别类别、判别依据、跳过原因
4. **异常记录**：NCX 缺失、标题为空、判别存疑等

另外输出一份**总日志** `chapters/_summary.md`：
- 15 本书各自：章节数、跳过的文件数、是否异常
- 便于横向对比，发现哪本书可能判别有误

## 特殊情况

- **同一章拆成多个文件**（如 `Section012` + `Section012-1`）：
  - 若 spine 顺序相邻、标题相同、内容连贯 → 合并为一章
  - 若标题不同 → 视为独立章节
  - 判别不确定时，**分别输出**，在日志里标注"可能需合并"
- **NCX 缺失**：降级用 h1/h2 标题，并在日志里标注
- **spine 缺失**：报错跳过该本，不要瞎猜顺序
