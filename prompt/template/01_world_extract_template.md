# 任务：逐章提取《{{PROJECT_NAME}}》的世界设定与认知反转

## 一、配置参数

```yaml
项目设定:
  作品名称: "{{PROJECT_NAME}}"
  输入目录: "outputs/chapters/{volume_id}/{chapter_id}.md"
  输出目录: "outputs/world_raw/{volume_id}/{chapter_id}.md"
  执行策略: "按卷循环推进，单卷内多章节推荐子代理并发执行"
```

## 二、提取核心准则

1. **绝对字面接地（Zero Hallucination）**：
   - 提取的每一条设定，必须且只能基于当前章节的原文，必须附带**逐字引用的原文段落**。
   - 严禁脑补推测，严禁使用后续剧情的“上帝视角”提前补充。
2. **客观真相 vs 角色主观认知的严格剥离**：
   - 必须区分：客观世界物理/魔法法则 vs 角色根据谣言、教义或伪装产生的认知偏见。
   - 若本章包含重大谎言或未解伏笔，在反转栏明确标注。
3. **时间线阶段打标（Stage Tagging）**：
   - 在文件头部标定本章所属的时间线阶段（如 `stage1` ~ `stageN`）。
4. **空章节兜底**：
   - 若本章纯为日常或无新增设定，生成文件并写明 `本章未包含新增世界设定`，严禁遗漏章节文件。

---

## 三、九大设定检视维度

- **一、地理与场所**：版图、城镇、建筑物、地下迷宫、特殊自然地貌。
- **二、组织与势力**：国家政权、公会门派、教会宗派、隐秘结社、军团。
- **三、力量与技能体系**：修炼阶梯、魔法法则、武道段位、特殊瞳术、限制与代价。
- **四、种族与生物**：非人族群特征、亚种、魔物魔兽习性与天敌弱点。
- **五、物品与神兵道具**：圣遗物、专属武器、魔药符咒、科技机械。
- **六、历史传说与大事件**：上古战役、神话纪元、国家兴亡、灾厄大事件。
- **七、社会规则与文化习俗**：货币与度量衡、法律与禁忌、婚姻制度、阶层风俗。
- **八、关键角色当期状态**：当期年龄、外在形象、所持战力与阵营状态。
- **九、认知偏差与反转甄别**：角色误信的“假象”与客观暗示之间的矛盾。
