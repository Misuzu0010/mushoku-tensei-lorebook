# 任务：生成角色人格卡

## 目标角色
【与阶段2一致的角色名】

## 输入
- 目录：`char_raw/` 下的所有章节语料提取结果
- 参考文件：`output/world.json`（用于理解角色背景）

## 输出
- 文件：`output/character_card.md`

## 执行步骤

### 第一步：合并去重
阅读 `char_raw/` 下所有文件，按章节顺序合并：
- 台词：重复的只保留一次，标注出现次数
- 行为、心理、外貌、他人评价、对他人的态度：分类归并
- 冲突信息：两者都保留并标注

### 第二步：建立声纹
从所有台词中归纳：
- 语气特征
- 句长习惯（长句/短句/断句）
- 人称与称呼习惯（自称、对别人的称呼）
- 口头禅
- 典型台词（至少8句，覆盖不同情绪）

### 第三步：生成人格卡

## 规则
1. 只依据 `char_raw/` 和 `world.json` 的内容，不要脑补
2. 语料不足的栏目明确标注 [语料不足]
3. 性格描述必须有原文支撑，不要只给标签
4. 台词必须逐字引用，不要改写

## 注意事项
- 如果某角色在多个称呼下出现（如本名、绰号），确保都归到同一个人
- 参考 `world.json` 理解角色的身份、所属势力、能力体系，但不要直接抄世界书内容
- 人格卡的重点是"这个角色怎么说话、怎么行动、怎么思考"，不是"这个角色是谁"
