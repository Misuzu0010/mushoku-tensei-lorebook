# 任务：按时间线聚合各章设定，生成专业分阶段防剧透世界书（Stage-Sliced Worldbook Merging）

本规约旨在指导大模型与数据流水线，将 `outputs/world_raw/` 下逐章提炼的设定草稿，按照严密的**时间线阶段（Stage Slicing）**与**防剧透认知边界**，聚合提炼为面向大语言模型角色扮演（RP）与推演的专业级结构化 JSON 世界书，最终发布至 `world_stages/` 目录。

---

## 一、输入与输出资产架构

- **输入数据**：`outputs/world_raw/{volume_id}/*.md`（全 15 卷全部章节提取草稿）
- **输出成果目录**：`world_stages/`
  - **通用底层基座**：`world_stages/shared_world.json`（全时期跨阶段通用法则）
  - **分阶段专属世界书**：
    - `world_stages/stage1_childhood.json`（阶段一：幼年篇 · 卷 01~02）
    - `world_stages/stage2_demon_continent.json`（阶段二：魔大陆长征篇 · 卷 03~06）
    - `world_stages/stage3_academy.json`（阶段三：魔法大学与早婚篇 · 卷 07~11）
    - `world_stages/stage4_labyrinth_family.json`（阶段四：迷宫救援与两妻篇 · 卷 12~13）
    - `world_stages/stage5_dragon_god.json`（阶段五：空中要塞与决战龙神篇 · 卷 14~15）
  - **总览与快速索引**：`world_stages/world_summary.md`（人类可读全条目索引表）

---

## 二、核心架构准则（四大支柱）

### 1. 彻底打破静态单一实体，推行分阶段切片（Stage Slicing）
- 在《无职转生》中，角色身份、人际依附、地理版图、阵营敌友与身体状态随剧情剧烈演变。
- **硬性要求**：同一实体在不同阶段必须独立拆解为不同条目，并赋予唯一的 `timeline` 属性。
- **RP 挂载规范**：在实际角色扮演推演时，严格采用 **“1 个通用底座 + 1 个当前阶段”** 模式，彻底杜绝时间线串味与超前剧透。

### 2. 标准 15 卷阶段划分与基准对齐表

| 阶段文件 | 阶段名称 | 对应卷数 | 角色年龄基准 | 核心剧情特征与防剧透边界 |
|:---|:---|:---:|:---:|:---|
| `shared_world.json` | 跨阶段通用底座 | 全 15 卷 | 全时期常驻 | 魔术级别、三大剑术流派、斗气原理、七大列强石碑、神子咒子、六面世界宇宙观、吸魔石等跨越时代不变的客观法则。 |
| `stage1_childhood.json` | 幼年启蒙篇 | 卷 01~02 | 3~10 岁 | 布耶纳村启蒙、师尊洛琪希家教、幼年希露菲、狂犬艾莉丝调教，止步于菲托亚领地大转移爆发前夕。**（此时无转移灾难，全员平安）** |
| `stage2_demon_continent.json` | 魔大陆与长征篇 | 卷 03~06 | 10~13 岁 | 大转移后苏醒、Dead End 建立、穿越魔大陆、横跨大森林与米里斯、赤龙下颚初战龙神胸口被贯穿、艾莉丝不辞而别。 |
| `stage3_academy.json` | 青少年·魔法大学篇 | 卷 07~11 | 13~16 岁 | 独行冒险者“泥沼”、莎拉心结、入读拉诺亚魔法大学、七星与札诺巴、菲兹身份揭露治愈 ED、购置新宅迎娶希露菲、转折点三。**（保罗在世，洛琪希在迷宫）** |
| `stage4_labyrinth_family.json` | 迷宫救援与两妻篇 | 卷 12~13 | 16~17 岁 | 驰援贝卡利特大陆转移迷宫、魔石九头龙决死战、保罗战死与塞妮丝救出（废人失智）、鲁迪失去左臂（装配札里夫义手）、迎娶洛琪希、长女露西诞生。**（人神伪装未破）** |
| `stage5_dragon_god.json` | 空中要塞与决战龙神篇 | 卷 14~15 | 17~18 岁 | 登上空中要塞晋见佩尔基乌斯、七星干涸病、**转折点四老鲁迪时空日记彻底撕碎人神假面**、研制魔导铠一式血战龙神、狂剑王艾莉丝归位成婚、**鲁迪宣誓归顺龙神**。 |

### 3. 字数与元数据严苛约束（50~150 汉字硬指标）
- **`content` 长度硬约束**：每个条目的正文描述必须严格控制在 **50~150 汉字**之间。
  - 低于 50 字：视为信息稀疏，缺乏有效事实细节，退回重写。
  - 高于 150 字：视为拖沓冗余，占用过多大模型上下文窗口，必须精炼压缩。
- **删除原文文学修饰**：删掉主观抒情、景物描写与心理旁白，只保留客观、高信息密度的百科级事实陈述。

### 4. 认知反转的“双条目隔离机制”（Dual-Entry Anti-Spoiler）
针对具有严重剧透与反转的设定（如人神的伪装、拉普拉斯的身世、艾莉丝出走的原因）：
- **第一条（表层认知条目）**：
  - `spoiler`: `false`，放置于事件发生前的阶段中，记录当时的普遍认知或谎言。
- **第二条（真实内幕条目）**：
  - `spoiler`: `true`，`reveal_arc` 明确标注真相大白的卷数或节点（如 `"第14卷老鲁迪日记后"`），并在 `note` 中写明触发前禁止加载。

## 三、世界书条目 JSON 规范 Schema

```json
[
  {
    "keywords": ["鲁迪乌斯·格雷拉特", "鲁迪", "泥沼", "无咏唱魔术师"],
    "content": "拉诺亚魔法大学特别生，水王级魔术师。在大转移流落魔大陆长征归来后化名泥沼独行，患有重度心因性ED。在大学重逢女扮男装的希露菲（菲兹）并治愈心结，与其在新居完婚。为人谨慎自谦，极度重视家庭与同伴，但尚未察觉自身正处于各方神魔博弈的核心漩涡。",
    "timeline": "stage3_academy",
    "priority": "核心",
    "category": "角色",
    "reveal_arc": "",
    "spoiler": false,
    "source_chapters": ["007_01", "008_03", "010_05", "011_07"],
    "note": "保罗仍健在，洛琪希仍在迷宫，严禁剧透后续断臂与日记"
  }
]
```

### 字段定义与填报说明

| 字段名称 | 类型 | 说明与规范要求 |
|:---|:---:|:---|
| `keywords` | Array[String] | **触发词穷举库**。必须囊括：官方本名、中文译名、简称、旧称、别号、绰号、重要同伴专属称谓。 |
| `content` | String | **设定本体**。字数严格在 **50~150 汉字**以内。客观、精炼、无废话、只记录该阶段的状态。 |
| `timeline` | String | 该条目归属的文件标识：`shared_world`、`stage1_childhood`、`stage2_demon_continent`、`stage3_academy`、`stage4_labyrinth_family`、`stage5_dragon_god`。 |
| `priority` | String | 重要性评级：`核心`（主线人物、关键法则、直接影响剧情）或 `次要`（背景地理、辅助道具、一次性客串）。 |
| `category` | String | 分类标签：`地理`、`组织`、`力量体系`、`种族`、`物品`、`历史`、`社会规则`、`角色`。 |
| `reveal_arc` | String | 反转揭露节点。普通条目留空；剧透/反转条目注明如 `"第14卷老鲁迪日记"`。 |
| `spoiler` | Boolean | 是否为真实反转/剧透条目。常规设定填 `false`，内幕条目填 `true`。 |
| `source_chapters` | Array[String] | 论据来源的章节编号列表，格式形如 `["012_04", "013_01"]`。 |
| `note` | String | 供 RP 提示器阅读的防剧透边界说明与挂载警告。 |

## 四、自动化构建与字数约束校验引擎

世界书整合可借助自动化辅助工具完成结构合规校验与构建，对应工具：`tools/build_final_stages.py`。

运行校验指令：
```bash
python tools/build_final_stages.py
```

该工具会自动化遍历并执行以下硬核质检：
1. **JSON 语法规范**：是否符合合法 JSON 数组规范。
2. **字数绝对检查**：逐条检查 `len(item["content"])` 是否落在 `50 <= count <= 150`。任何超出或不足立即触发告警。
3. **必填字段完整性**：9 个标准字段缺一不可。
4. **触发词非空检查**：`keywords` 至少包含 2 个以上关键词。
5. **阶段归属检查**：`timeline` 必须与所在阶段文件名严格一致。

---

## 五、交付验收指标

1. **零原文抄袭**：全设定由原著客观事实提炼改写而成，不直接堆砌整段小说正文。
2. **条目数量合理**：
   - 通用底座 `shared_world.json` 保持在 20~30 条之间。
   - 各阶段特有设定文件保持在 15~40 条之间。
3. **索引文档同步**：生成与条目 100% 对应的 [`world_stages/world_summary.md`](world_stages/world_summary.md)，清晰列出各个阶段的条目目录、关键词与阶段概览。
