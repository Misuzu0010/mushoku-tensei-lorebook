# 任务：按时间线汇总各章设定，生成分阶段世界书

## 输入
- 目录：`world_raw/` 下的所有章节提取结果

## 输出
- 文件：`world_stages/shared_world.json`（跨阶段通用设定）
- 文件：`world_stages/stage{N}_{name}.json`（各阶段专属设定）
- 附加文件：`world_stages/world_summary.md`（人类可读的条目总览）

## 核心原则

无职转生的角色、地点、势力状态随剧情剧烈变化，不能按类别归并成单一静态条目。

同一实体在不同阶段必须拆成不同条目，用 timeline 字段区分。世界书按阶段分文件，RP 时只加载当前阶段对应的文件，避免时间线串味。

## 执行步骤

### 第一步：确定阶段划分

根据 1-15 卷剧情，将世界书划分为以下阶段（卷数对应可按实际版本微调）：

| 阶段 ID | 阶段名 | 大致卷数 | 鲁迪年龄 | 核心地点 |
|---|---|---|---|---|
| stage1 | 幼年篇 | 1-3 | 3-7 岁 | 布耶纳村 |
| stage2 | 魔大陆篇 | 3-5 | 7-10 岁 | 魔大陆、海上 |
| stage3 | 青年前期 | 5-8 | 10-13 岁 | 拉诺亚、魔法大学 |
| stage4 | 成年篇 | 8-12 | 13-16 岁 | 米里斯、贝卡利特 |
| stage5 | 后期 | 12-15 | 成年后 | 拉诺亚、各大国 |

阶段划分可由使用者调整。若需简化，可合并为三个阶段：
- 前期（stage1+stage2）
- 中期（stage3+stage4）
- 后期（stage5）

### 第二步：通读归并（按阶段）

阅读 `world_raw/` 下所有文件，对每条设定判断：

1. 该设定属于哪个阶段？跨阶段通用设定归入 shared_world，阶段特有设定归入对应 stage 文件。
2. 该设定是否随阶段变化？若是（如角色状态、地点归属），在每个相关阶段各写一条，内容只描述该阶段的状态。
3. 该设定是否只在一个阶段出现？只归入该阶段。

归并类别（仅作组织参考，不强制按类别分文件）：
- 地理与场所
- 组织与势力
- 力量体系
- 种族/生物
- 物品/道具
- 历史/事件
- 社会规则
- 角色

### 第三步：处理冲突

同一设定在不同章节有矛盾时：
- 优先判断是否为时间线变化（前期说法 vs 后期说法），若是，拆入不同阶段条目
- 判断是否为反转：是/否/不明
- 两种说法都保留，用 reveal_arc 字段标注可启用时机

### 第四步：统一专有名词

- 同一事物的不同叫法要合并
- 列出所有别名、简称、旧称、他人称呼
- 跨阶段通用的专有名词归入 shared_world

### 第五步：条目化

转成世界书条目格式，按阶段输出 JSON。

## 条目格式

[
  {
    "keywords": ["关键词1", "关键词2", "别名1", "简称1"],
    "content": "简洁客观的设定描述，50-150字。只描述该阶段的状态。",
    "timeline": "幼年篇",
    "priority": "核心",
    "category": "角色",
    "reveal_arc": "",
    "spoiler": false,
    "source_chapters": ["001", "005"],
    "note": ""
  }
]

### 字段说明

| 字段 | 说明 |
|---|---|
| keywords | 本名、简称、别名、旧称、他人称呼、相关词，穷举 |
| content | 50-150 字，只写设定本身，删掉原文修饰 |
| timeline | 该条目所属阶段，与文件名一致。shared_world 中填 "通用" |
| priority | 核心（影响剧情走向、反复出现）或 次要（背景细节、一次性提及） |
| category | 地理/组织/力量体系/种族/物品/历史/社会规则/角色 |
| reveal_arc | 涉及反转的条目填写可启用时机，如 "第8卷后"。无则留空 |
| spoiler | 是否为剧透条目。表面认知为 false，真实设定为 true |
| source_chapters | 来源章节编号 |
| note | 补充说明，如 "仅第8卷后使用" |

## 规则

1. 关键词要穷举：本名、简称、别名、旧称、他人称呼、相关词
2. 内容要精炼：删掉原文修饰，只留设定本身
3. 阶段优先：同一实体跨阶段必须拆分，不得合并成一条
4. 优先级判断：
   - 核心：影响剧情走向、反复出现的设定
   - 次要：背景细节、一次性提及
5. 防剧透处理：涉及反转的设定拆成两条
   - 第一条：表面认知（spoiler: false）
   - 第二条：真实设定（spoiler: true，reveal_arc 写明启用时机，note 写明"仅第X卷后使用"）
6. 不添加原文没有的内容
7. 控制条目数：每个阶段文件的核心条目建议 10-25 条，次要条目不限。若某阶段条目超过 50 条，检查是否过度拆分

## 输出要求

1. 生成 `world_stages/shared_world.json`：跨阶段通用的世界规则、种族基本特征、地理框架、历史背景。以蓝灯条目为主。
2. 生成 `world_stages/stage{N}_{name}.json`：每个阶段一个文件，只含该阶段特有的角色状态、地点、事件、势力。
3. 生成 `world_stages/world_summary.md`：人类可读的条目总览，按文件分组，列出每条的名称、优先级、timeline，方便快速检查。

### world_summary.md 格式示例

# 世界书条目总览

## shared_world.json（通用）

### 核心
- [力量体系] 魔术等级体系
- [种族] 长耳族基本特征
- [地理] 大陆分布框架

### 次要
- [历史] 拉普拉斯战役背景

## stage1_childhood.json（幼年篇）

### 核心
- [角色] 鲁迪乌斯（3-7岁）
- [角色] 洛琪希（家庭教师时期）
- [角色] 希露菲（幼年期）
- [地理] 布耶纳村

### 次要
- [组织] 村庄治安维持会

## 注意事项

- 如果某类设定条目超过 30 条，检查是否过度拆分，可以合并
- 核心条目建议控制在 10-25 条（每个阶段文件），次要条目数量不限
- 跨阶段通用的设定不要重复写入各阶段文件，统一放 shared_world.json
- 阶段文件的 timeline 字段必须与文件名中的阶段名一致
- 切换 RP 阶段时，禁用旧阶段文件，启用新阶段文件，shared_world.json 始终启用
