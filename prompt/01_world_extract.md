# 任务：逐章提取世界设定

## 输入
- 目录：`outputs/chapters` 下的所有 `.md` 章节文件
- 每个文件是一章原文

## 输出
- 目录：`world_raw/`
- 每个章节对应一个文件，命名与原章节文件相同（如 `001_序章.md` → `world_raw/001_序章.md`）

## 执行方式
遍历 `outputs/chapters` 下的所有 `.md` 章节文件，对每个文件独立执行以下提取任务。
如果章节较多（超过10章），请使用子代理并行处理。
考虑到上下文的原因，建议，子代理和主代理的一次工作应该一次只处理一卷书，处理完毕之后，再循环进行下一卷处理，直到所有书都被处理。

## 提取规则
1. 只依据原文，绝对不要脑补、不要补充常识
2. 信息不确定的标注 [存疑]
3. 每条设定必须附原文依据（逐字引用）
4. 只提取本章出现或补充的设定，不要复述已知信息
5. 区分"客观事实"和"角色认知"——角色说的话可能不是真相
