# 任务：逐章提取世界设定与反转甄别（Chapter-Level Setting Extraction）

本规约旨在指导大模型（或并发子代理）对切分后的正文章节（`outputs/chapters/`）进行细颗粒度、零脑补、强接地的逐章设定挖掘，重点提炼**世界法则、势力地理、力量体系、关键物品、社会习俗，并严格分离“角色主观认知”与“客观世界真相”**，输出至中间草稿库（`outputs/world_raw/`）。

---

## 一、输入与输出规范

- **输入目录**：`outputs/chapters/{volume_id}/{chapter_id}.md`（如 `outputs/chapters/01/01_序章.md`）
- **输出目录**：`outputs/world_raw/{volume_id}/{chapter_id}.md`
  - 示例：`outputs/chapters/01/01_序章.md` $\to$ `outputs/world_raw/01/01_序章.md`
- **文件命名**：必须与输入的章节文件名保持 100% 一致。

---

## 二、执行方式与并发策略

1. **按卷分批推进（Volume-by-Volume Batching）**：
   - 为避免上下文污染与长文本遗忘，**单次会话只处理一整卷（约 10~18 章）**。
   - 一卷全部提取完毕并验证无误后，再推进至下一卷。
2. **子代理并行提取（Subagent Concurrency）**：
   - 当单卷包含章节较多时，推荐派出多个子代理分别认领 3~5 章并发执行提取。
3. **完全无设定章节的处理**：
   - 即使某章属于纯日常对话或无新增设定，也必须生成对应的 Markdown 文件，注明 `本章未包含新增世界设定`，严禁遗漏文件。

---

## 三、提取核心原则（三大铁律）

### 1. 绝对字面接地原则（Grounding & Anti-Hallucination）
- **只依据本章文本**，严禁使用预训练知识补充后续剧情或常识设定。
- 每一条提取出的设定，必须附带**逐字引用的原文段落**（使用 `> "……"` 引用标注）。
- 严禁脑补推理。文本写到什么程度就记录到什么程度，若原著描述语焉不详，标记 `[原文未详述]`。

### 2. 客观世界真相 vs 角色主观认知的严格剥离（Critical Discrepancy）
在《无职转生》等长篇架空作品中，大量信息是角色通过传闻、宗教、偏见或欺骗获取的（例如：人神伪装为慈父救世主、斯佩路德族的恶名源于拉普拉斯的诅咒长枪、鲁迪自以为洛琪希是无所不能的神）。
- **必须严格区分**：
  - 【客观事实】：世界实际发生的客观物理/魔法现象或确凿历史。
  - 【角色认知】：该角色“以为”的真理、“听闻”的传说、“被告知”的假象。
  - 【反转潜伏】：标注是否存在与此前剧情矛盾的蛛丝马迹。

### 3. 时间线阶段归属标定（Stage Tagging）
在每章提取文件的头部，必须显式标注其对应的剧情阶段（`stage1_childhood` ~ `stage5_dragon_god`），为后续 02 世界书按阶段聚合提供切片索引。

---

## 四、九大设定提取维度

针对章节文本，必须穿透以下九大分类进行检视与提取：

1. **地理与场所**（世界各大板块、王国、城镇、迷宫、空中要塞、具体建筑物位置与地貌特征）
2. **组织与势力**（国家皇族、魔导公会、冒险者公会、宗教派系、米里斯教团、七大列强等）
3. **力量体系 / 魔法 / 剑术 / 斗气**（咏唱级数、无咏唱机制、魔力总量与拉普拉斯因子、三大剑术流派与段位、斗气缠绕、魔眼等）
4. **种族 / 生物 / 魔兽**（魔族各部落、长耳族、兽族、斯佩路德族特征与弱点、特定魔兽生态）
5. **物品 / 道具 / 武器 / 名器**（神刀、傲慢水龙王、吸魔石、魔导铠、转移卷轴、通信石板等）
6. **历史 / 传说 / 关键转折事件**（拉普拉斯战役、六面世界神话、菲托亚领地大转移、转折点事件等）
7. **社会规则 / 阶级 / 习俗 / 禁忌**（货币汇率、奴隶制度、冒险者等级考核规则、婚姻风俗、宗教戒律等）
8. **关键角色当期状态切片**（当期年龄、外貌衣着、所属势力、已掌握技能与身体状态）
9. **认知偏差与真相甄别**（本章中角色自以为的常识，与客观暗示之间的落差）

  - 原文依据：> "握着手中这根由傲慢水龙王枯木打造的短杖……"

- **事件名**：菲托亚领地大转移事件

  - 原文依据：> "那道吞噬一切的苍白强光，将罗亚城镇连根拔起……"

## 七、社会习俗 / 规则 / 制度
- **规则**：魔大陆流通货币体系
  - 核心设定：魔大陆不通用人族阿斯拉金币，只认可生铁钱、青铜钱与魔大陆金币，汇率折算极高。
  - 原文依据：> "在魔大陆，阿斯拉金币几乎是一文不值的废铁……"
