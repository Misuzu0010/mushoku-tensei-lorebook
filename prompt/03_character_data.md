# 任务：逐章提取指定角色的语料

## 目标角色
【鲁迪乌斯·格雷拉特】

该角色的其他称呼（如有）：【鲁迪，泥沼，Dead End的饲主，龙头老大，龙神的右腕，魔导王、大魔导师、无咏唱】

## 输入
- 目录：`outputs/chapters` 下的所有 `.md` 章节文件

## 输出
- 目录：`outputs/char_raw`
- 每个章节对应一个文件，命名与原章节文件相同

## 执行方式
遍历 `outputs/chapters` 目录下所有 `.md` 文件，对每个文件独立执行提取。
如果章节较多（超过10章），请使用子代理并行处理。
考虑到上下文的原因，建议，子代理和主代理的一次工作应该一次只处理一卷书，处理完毕之后，再循环进行下一卷处理，直到所有书都被处理。

## 核心难点：轻小说不标注说话人

判断说话人时，按以下优先级：
1. 对话前后的动作描写（"她别过脸""他叹气"）
2. 对话中的称呼（对别人的称呼、别人对该角色的称呼）
3. 说话风格（语气、句长、用词）
4. 段落归属（同一段落内的动作与台词通常同属一人）

**依据不足时标注 [说话人存疑]，不要强行归给该角色。**


## 提取规则
1. 台词逐字引用，不改写、不转述
2. 每个判断都要给出依据
3. 只依据原文，不脑补
4. 如果本章该角色没出现，输出"本章未出现"
