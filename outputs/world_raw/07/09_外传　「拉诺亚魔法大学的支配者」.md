# 外传　「拉诺亚魔法大学的支配者」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚王国
- 内容：魔法三大国同盟的盟主国。魔术教育在三国中最发达，多次培育出优秀魔术师，是阿斯拉王国魔术教育理论的来源。
- 原文依据："拉诺亚王国。即使在魔法三大国中，此国的魔术教育也特别发达，还多次培育出优秀的魔术师。大约一百年前，身为魔法三大国同盟盟主的拉诺亚王国为了让三国之间的关系能够更加强固稳定，建立了一个城镇。"、"对于从拉诺亚王国吸收魔术教育理论的阿斯拉王国来说"

- 名称：魔法都市夏利亚
- 内容：约一百年前由拉诺亚王国倡议并建立的城市，旨在巩固魔法三大国同盟关系。汇聚了三大国引以为傲的三大机构：涅里斯公国的魔道具工房、巴榭兰特公国的魔术公会、拉诺亚王国的魔法大学。
- 原文依据："大约一百年前，身为魔法三大国同盟盟主的拉诺亚王国为了让三国之间的关系能够更加强固稳定，建立了一个城镇。那就是魔法都市夏利亚。这座魔法都市夏利亚里存在着三个国家都引以为豪的三个组织，涅里斯公国的魔道具工房，巴榭兰特公国的魔术公会，以及拉诺亚王国的魔法大学。"

- 名称：拉诺亚魔法大学
- 内容：坐落于魔法都市夏利亚的顶级学府，世界规模数一数二的大型学校，在校生逾一万人。不仅传授魔法，还教授各类知识。魔法三大国宫廷魔术师、阿斯拉王国魔术学校教师、知名冒险者（如洛琪希・米格路迪亚）多毕业于此。校区设施包括学生宿舍、校舍、林荫道、大学附设餐厅、学生会办公室等。
- 原文依据："拉诺亚王国的魔法大学。其中以魔法大学最为有名。据说魔法三大国的宫廷魔术师，阿斯拉王国魔术学校里的教师，还有其他在世界各地闯荡出名号的冒险者全都就读过这所学校。连那位被吟游诗人作成诗歌传唱的冒险者洛琪希・米格路迪亚也是这所学校的毕业生。现今，这里的学生人数已经超过一万名，而且不只能学习魔法，还能学习到所有一切知识，成为世界上数一数二的大规模学校。"

- 名称：大森林
- 内容：与拉诺亚王国在地理上呈对角线分布的遥远森林，是兽族之王「德路迪亚族」的故乡。
- 原文依据："千里迢迢从可说是和拉诺亚王国位于对角线上的大森林来到此处后"

- 名称：剑之圣地
- 内容：在野优秀人才名单中出现的地域，由剑神加尔・法利昂守护。
- 原文依据："甚至连剑之圣地的守护者，剑神加尔・法利昂都名列其中。"

## 二、组织与势力
- 名称：魔法三大国同盟
- 内容：由拉诺亚王国（盟主）、涅里斯公国、巴榭兰特公国组成的北方同盟体系，共同在夏利亚设立代表性机构。
- 原文依据："大约一百年前，身为魔法三大国同盟盟主的拉诺亚王国为了让三国之间的关系能够更加强固稳定，建立了一个城镇。那就是魔法都市夏利亚。这座魔法都市夏利亚里存在着三个国家都引以为豪的三个组织"

- 名称：涅里斯公国魔道具工房
- 内容：位于魔法都市夏利亚，属于涅里斯公国引以为豪的三大组织之一。
- 原文依据："涅里斯公国的魔道具工房，巴榭兰特公国的魔术公会，以及拉诺亚王国的魔法大学。"

- 名称：巴榭兰特公国魔术公会
- 内容：位于魔法都市夏利亚，属于巴榭兰特公国引以为豪的三大组织之一，对阿斯拉王国的魔术教育具有重大影响力。
- 原文依据："巴榭兰特公国的魔术公会……对于从拉诺亚王国吸收魔术教育理论的阿斯拉王国来说，这些都是具备巨大影响力的存在。"

- 名称：拉诺亚魔法大学学生会
- 内容：一万名学生的中心与顶点，享有极高的学生号召力与声望，但未获赋予独立自治权或强大实权。由学生会长任命干部，会长离任时所有干部自动成为候选人并由全校学生普选产生下一任会长；候选人不可中途退选。爱丽儿在二年级即当选会长，创下校史罕见纪录，并以此为跳板与拉诺亚王国高层及魔术公会建立同盟关系，招揽人才输送回阿斯拉王国。
- 原文依据："魔法大学的学生会并没有特别被允许进行自治，也不具备强大的权力。然而毫无疑问，学生会是一万名学生的中心，同时也是顶点。"、"拉诺亚魔法大学的学生会采用任命制。由学生会长选出自己觉得适当的人才，并任命对方成为学生会干部。只有会长一职是在前任学生会长退役那一刻起，其他的学生会干部全都会自动成为候选人，再由全校学生投票决定出会长。这是魔法大学的首任校长制定的规则，也是持续到现在的习惯。"、"按照计画，由于她在二年级就当上学生会长，得以成功和魔术公会与拉诺亚王国建立起关系。那些对自己有信心的人才也纷纷聚集到学生会来，他们正在推行把其中特别优秀且人格可以信赖的人选送回阿斯拉王国的计画。"

- 名称：阿斯拉王国魔术学校
- 内容：阿斯拉王国设立的魔术教学机构，其教员多出自拉诺亚魔法大学。
- 原文依据："阿斯拉王国魔术学校里的教师，还有其他在世界各地闯荡出名号的冒险者全都就读过这所学校。"

- 名称：爱丽儿流亡阵营
- 内容：由阿斯拉王国第二王女爱丽儿率领的流亡集团，随从原有近二十人，逃亡途中遭刺客杀害至仅剩四人（路克・诺托斯・格雷拉特、菲兹、埃尔莫亚・布鲁沃夫、克丽妮・艾尔隆德），在拉诺亚魔法大学潜伏并夺取学生会主导权，积极寻找与招揽优秀人才以图东山再起。
- 原文依据："爱丽儿・阿涅摩伊・阿斯拉在阿斯拉王国的政治斗争中落败，只能逃离母国。……她有四名随从。路克・诺托斯・格雷拉特。埃尔莫亚・布鲁沃夫。克丽妮・艾尔隆德，还有，菲兹。原本将近二十人的随从大多在路上遭到刺客杀害，减少到仅剩四人。"

## 三、力量体系 / 魔法 / 技能
- 名称：兽族固有魔术（声波魔术）
- 规则：利用兽族特有的生理声带在特定音域上附加魔力效果发出的咆哮魔术，能瞬间震撼对手并令其失去行动能力或流鼻血昏厥；此魔术可被破坏听觉（如震破自身鼓膜）所破除。
- 原文依据："这是在利用特殊声带发出的音域上追加魔术效果，瞬间让对手无法行动的兽族固有魔术。菲兹流出鼻血，上半身也突然往旁边倒。"、"他用双手用力打向自己的耳朵。现场响起清脆声响，菲兹的耳朵喷出鲜血。……转向因为自己的声音魔术没有效果而慌张失措的普露塞娜。"

- 名称：无咏唱魔术（菲兹）
- 规则：无需咏唱咒语即可随手释放多种属性魔术（冲击波、烈火、地底突刺冰块、水球等），反应神速，可单人瞬间压制数十人。
- 原文依据："他在兽族们展开行动的那瞬间，冲到爱丽儿前方，使出无咏唱的冲击波，把周围的人全都打飞出去。"、"每当菲兹的手做出一个动作，就会刮起猛烈火焰，或是有冰块从地面冒出。"

- 名称：阿斯拉贵族不动嘴唇说话技术（腹语术）
- 规则：阿斯拉王国贵族的独门修养技术，能够完全不动嘴唇、不露唇形地发出低语，外人无法通过面部察觉发言。
- 原文依据："没有人类能看出爱丽儿嘴唇的动作。基于阿斯拉贵族的修养，爱丽儿拥有不动嘴唇就能说话的技术。"

- 名称：神子
- 规则：天生拥有异能与特殊体制的存在，本章提及西隆王国的札诺巴即为神子。
- 原文依据："今年入学的札诺巴・西隆与克里夫・格利摩尔应该可以期待吧。前者是神子"

- 名称：上级魔术
- 规则：魔法阶级体系之一，新入学的克里夫・格利摩尔已掌握并在入学时即可使用。
- 原文依据："后者则是在入学时就能够使用上级魔术。"

## 四、种族 / 生物
- 名称：兽族（含德路迪亚族）
- 特征：
  - 生理特性：听觉极其灵敏，是普通人类的数倍，能清晰捕捉极小声的低语；长有猫耳或犬耳、毛发与利爪；具有一年一度的“发情期”。
  - 文化与部族：德路迪亚族为兽族之王族；在魔法大学中有相当数量的兽族学生（包含不少人兽混血）；兽族向对手完全认输或表达极度屈从、谢罪的最屈辱动作为躺倒在地上露出肚子。
- 原文依据："然而，兽族的听觉比人类优秀数倍，可以听见远处的声音。"、"这两人是兽族之王「德路迪亚族」的公主。"、"今年的发情期过后，两位就会生下父亲不详的小孩吧？"、"对兽族来说那是屈辱的姿势，也就是露出肚子的谢罪动作。"

## 五、物品 / 道具 / 武器
- 名称：魔法大学制服
- 说明：魔法大学全校上万名学生日常统一穿着的标准制服，但不良学生穿着时往往衣衫不整。
- 原文依据："在所有人都穿着相同制服的情况下，只有爱丽儿散发出光彩"、"两人的制服都显得衣衫不整，姿势也很差。"

- 名称：厚重墨镜
- 说明：菲兹常年佩戴在脸上的厚重眼镜，遮挡住眼睛与面容神态。
- 原文依据："脸上带着厚重墨镜的少年，菲兹。"、"他的双眼被墨镜遮住而无法看清"

- 名称：在野优秀人士推荐名单
- 说明：由埃尔莫亚整理、存放在学生会办公室的资料，汇集了夏利亚本地、魔法三大国乃至其他地域的杰出在野人才（包括知名冒险者、剑神加尔・法利昂、鲁迪乌斯・格雷拉特等），用于爱丽儿阵营选拔并通过副校长招揽其入学。
- 原文依据："埃尔莫亚从学生会办公室的储物柜里拿出一叠纸张，呈交给爱丽儿。……从居住在魔法都市夏利亚的人物开始，到活跃于魔法三大国的冒险者，甚至连剑之圣地的守护者，剑神加尔・法利昂都名列其中。……菲兹手上的名单……写着「鲁迪乌斯・格雷拉特」这个名字。"

## 六、历史 / 传说 / 事件
- 事件名：魔法都市夏利亚建城
- 内容：约一百年前由拉诺亚王国发起建立，作为强化魔法三大国同盟的核心城市。
- 原文依据："大约一百年前，身为魔法三大国同盟盟主的拉诺亚王国为了让三国之间的关系能够更加强固稳定，建立了一个城镇。那就是魔法都市夏利亚。"

- 事件名：爱丽儿逃亡与潜伏魔法大学
- 内容：爱丽儿在阿斯拉王国王位争夺中失势逃亡，随从遭沿途暗杀至仅剩四人，流亡至拉诺亚王国获庇护并入读魔法大学，制定步步为营掌握学生会以拉拢人才与三大国高层的复兴计划。
- 原文依据："爱丽儿・阿涅摩伊・阿斯拉在阿斯拉王国的政治斗争中落败，只能逃离母国。……原本将近二十人的随从大多在路上遭到刺客杀害，减少到仅剩四人。"

- 事件名：食堂制裁兽族不良集团事件
- 内容：长期霸凌学校的德路迪亚族公主莉妮亚与普露塞娜及其二十名兽族跟班在食堂拦截爱丽儿，爱丽儿暗中言语挑衅诱使其率先动手，菲兹以无咏唱魔术单枪匹马击垮二十二人，逼迫莉妮亚露出肚子认罪；爱丽儿阵营趁机将舆论导向兽族企图不轨，促使涉事兽族大多退学，学校恢复秩序，爱丽儿借此巨大功绩在二年级高票当选学生会长。
- 原文依据："菲兹伸出来的手发出看不见的冲击波……莉妮亚不得不摆出恭顺的姿势。对兽族来说那是屈辱的姿势，也就是露出肚子的谢罪动作。"、"后来在埃尔莫亚与克丽妮的运作下，指称莉妮亚与普露塞娜鼓动跟班试图对爱丽儿做出不轨行为的谣言被当成事实传播开来……让参与这次事件的大部分兽族都遭到退学。"、"因为爱丽儿迫使那些不良学生退学，让魔法大学恢复和平，长期遭受欺凌的学生们基于感谢，在下次的会长选举中都投票给爱丽儿。不仅如此，还开始以带有强烈崇拜的眼神看待二年级就当上学生会长的爱丽儿。"

- 事件名：洛琪希传唱于世
- 内容：洛琪希从拉诺亚魔法大学毕业后成为知名冒险者，其事迹甚至被吟游诗人编成诗歌传唱。
- 原文依据："连那位被吟游诗人作成诗歌传唱的冒险者洛琪希・米格路迪亚也是这所学校的毕业生。"

## 七、社会规则 / 习俗 / 文化
- 内容：魔法大学学生会任免与选举制度：
  魔法大学首任校长立下的规矩。学生会干部由会长直接任命；在前任会长退任时，所有在职干部自动成为下任会长候选人且不可退选（若想退选必须在接受任命时辞绝），全校一万多名学生直接投票决定会长人选。候选人之间的相互背书具有重大拉票效应。
- 原文依据："拉诺亚魔法大学的学生会采用任命制。由学生会长选出自己觉得适当的人才，并任命对方成为学生会干部。只有会长一职是在前任学生会长退役那一刻起，其他的学生会干部全都会自动成为候选人，再由全校学生投票决定出会长。这是魔法大学的首任校长制定的规则，也是持续到现在的习惯。"、"候选人不能辞退。如果想辞退，必须在当初被任命为学生会成员时就先行辞退。"

- 内容：兽族的认输与臣服礼仪：
  兽族在彻底败北认输时，最具有服从和屈辱意味的姿态是躺倒在地上露出肚子向胜者谢罪。
- 原文依据："对兽族来说那是屈辱的姿势，也就是露出肚子的谢罪动作。"

- 内容：阿斯拉贵族的仪容与言行修养：
  注重外表整洁体面，同时掌握诸如不动唇发音等隐秘沟通技巧。
- 原文依据："莎莉雅同学，你的领口不整齐喔。……因为你长得很漂亮，要记得注意自身仪容。"、"基于阿斯拉贵族的修养，爱丽儿拥有不动嘴唇就能说话的技术。"
