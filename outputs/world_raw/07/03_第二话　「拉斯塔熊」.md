# 第二话　「拉斯塔熊」 世界设定提取

## 一、地理与场所
- 名称：罗森堡北门
- 内容：罗森堡城镇北向城门，是冒险者组织远征探索、天色昏暗的大清早聚集出发的常规枢纽。
- 原文依据："隔天，我按照约定前往北门。"、"实际上，看起来即将出发的其他队伍也在北门附近聚集。"

- 名称：库库鲁湖及其湿地生态
- 内容：距离罗森堡向北约三天多路程的湖泊。周围分布有稍高的小山丘、茂密草丛及大片湿地。是拉斯塔熊夏季繁衍筑巢的核心聚集区，部分族群会在湖畔露天交配休憩，另有大型族群屯聚在近水的烂泥湿地中潜伏伪装。讨伐战后该湖泊周边一带被超高热火魔术彻底焚毁，化为焦土平野。
- 原文依据："罗森堡往北约三天路程的地点扎营。从这里到事前情报显示有拉斯塔熊族群栖息的库库鲁湖，还需要再花上几个小时。"、"而在湖泊附近，和我们观察的族群隔了一点距离的地方有其他族群。它们屯聚在类似溼地的地方，躲在泥巴里睡觉时"、"一个小时后。湖泊周遭已经化为被烧毁的平野。附近散落着大量拉斯塔熊的尸体。"

- 名称：米尔波兹领地
- 内容：位于阿斯拉王国境内的领地，由诺托斯・格雷拉特担任领主管辖，是莎拉的故乡所在。
- 原文依据："诺托斯・格雷拉特，米尔波兹领地的领主。只有在我小时候，他带着士兵来村里狩猎魔物时曾经见过一次。"

## 二、组织与势力
- 名称：「Counter Arrow」
- 内容：阿斯拉王国出身的B级冒险者队伍，成员分工细致且团队资源运用极度充分：
  - 提摩西：队长，魔术师（后卫），身穿红褐色长袍、手持长权杖，主修火系攻击魔术，负责队伍战略把控与社交公关。
  - 苏珊娜：副队长，战士（前卫），穿戴护胸与护手，掌管队伍编制统合与实战现场调度发令。
  - 帕特里斯：魔法战士（前卫），佩剑持入门魔杖，兼修初级风魔术，本质偏近战战士。
  - 密米尔：治愈魔术师（后卫），身着白长袍，精通中级治疗魔术与初级解毒魔术。
  - 莎拉：弓箭手（中卫），14-15岁，年轻阿斯拉平民少女，擅长极高命中率的超远距离要害连射。
  全队综合实力虽在C级高阶水准，但因配合默契、战力运用彻底而稳居B级，且擅长利用请客公关消除外来者仇恨。
- 原文依据："我叫苏珊娜。是『Counter Arrow』的副队长，职业是战士，负责前卫。"、"我叫提摩西。职业是魔术师，擅长在后卫使用攻击魔术。基本上是这支队伍的队长……"、"我是治愈魔术师，密米尔。治疗是中级，解毒是初级。"、"我是魔法战士，帕特里斯。虽说是魔法战士，也只是能使用初级的风魔术而已，几乎完全算是战士。"、"我是中卫，弓箭手莎拉。"、"实际上，这些人的实力只到C级高阶的水准。然而靠着巧妙彻底运用资源的做法，让他们能在B级从事冒险者工作。"

- 名称：诺托斯・格雷拉特家族
- 内容：阿斯拉王国的贵族家系，统治米尔波兹领地。在阿斯拉王国，拥有格雷拉特姓氏者多为中、下级贵族。
- 原文依据："诺托斯・格雷拉特，米尔波兹领地的领主。"、"在阿斯拉王国，格雷拉特并不是少见的姓氏。然而叫这名字的人大部分都是中、下级的贵族。"

## 三、力量体系 / 魔法 / 技能
- 名称：冒险者队伍战术协同机制（前卫、中卫、后卫）
- 规则：两名前卫（苏珊娜、帕特里斯）近身顶防牵制；中卫（莎拉）游走射击支援要害；后卫（提摩西、密米尔）远距离倾泻火力或提供治愈辅助。队伍加入鲁迪乌斯后，以后卫制造泥沼阻滞敌群为起手，远距离由火魔术消耗，迫近后交由前卫中卫。
- 原文依据："成员是两名前卫，一名中卫，两名后卫。取得了不错的平衡。这样的组合再加上我之后，采用的战法是一旦发现远处的敌人，就由我制造出泥沼来困住对方，再由擅长火魔术的提摩西尽可能在远距离下减少敌人数量。要是敌人逼近，则换成苏珊娜和帕特里斯往前，然后身为中卫的莎拉支援他们两人。万一前卫受伤，密米尔会负责治愈。"

- 名称：魔术体系与具体魔术
  - 「大火球」：中级火魔术，咏唱咒文为“愿伟大的炎之加护降临汝所求之处！猛烈狂暴的火焰啊，将巨大的恩惠燃烧殆尽吧！『大火球』！”，火球直径超一公尺，兼具高速、高破坏力与命中率。
  - 「泥沼」：改变地面性状的土系/控制魔术，鲁迪乌斯以无咏唱方式瞬间形成陷阱限制大批魔物冲锋。
  - 「狱炎火弹」：高阶（上级/圣级）火系攻击魔术，无咏唱瞬发，魔杖喷涌出超大范围的猛烈火柱与烈焰，瞬间焚毁上百只B级魔物并改变地形为焦土。
  - 「岩炮弹」：土系投射魔术，鲁迪乌斯无咏唱释放，用于远距离精确狙击歼灭溃逃的魔物。
  - 「治愈魔术」与「解毒魔术」：水/神圣体系魔术，中级治疗可愈合外伤，初级解毒可化解体内酒精毒素与身体不适。
  - 战斗施法常识：在不可预知的持久战中，后卫魔术师必须严格控制魔力消耗，不可无端挥霍。
- 原文依据："「愿伟大的炎之加护降临汝所求之处！猛烈狂暴的火焰啊，将巨大的恩惠燃烧殆尽吧！『大火球』！」"、"「『泥沼』。」"、"「『狱炎火弹』。」魔杖产生的巨大猛烈火焰非常轻松地把成群的拉斯塔熊全部燃烧殆尽。"、"逃走的拉斯塔熊则被我用岩炮弹解决。"、"万一演变成长期战，魔术师要保留魔力是常识吧！"、"他隐瞒自己是上级，甚至是圣级魔术师的事实。"

- 名称：无咏唱魔术的罕见性
- 规则：不借助语言咏唱即可引导发动魔术的能力。极其稀罕罕见，即使在正规魔术学校中，也通常仅有少数极高阶教师能够掌握，绝大多数魔术师一生难得一见。
- 原文依据："在学校见识过老师使用无咏唱魔术后，这还是我第一次碰上能做到这种事的其他魔术师。"

- 名称：弓箭手与魔术师的职业定位对比
- 规则：此世界中弓箭手数量极其稀少。因弓箭物理攻击力与射程普遍不及同位阶魔术，且箭矢携带量受体力与行囊负重限制（不能无限制携带），而魔力仅靠睡眠即可自然恢复。但如果个体拥有极端突出的射术天分（无论任何环境极速连射且准确洞穿要害），弓箭手亦可超越魔术性能在冒险者界立足甚至匹敌A级。
- 原文依据："这个世界的弓箭手并不多。因为弓箭明明是远距离攻击，攻击力和射程却都劣于魔术；再加上和只要睡觉就能恢复的魔力不同，箭矢数量有物质上的限制。箭矢增加就等于行李增加，不可能像某款RPG游戏那样带着一万支箭矢跑来跑去。如此一来，还是学习魔术比较好。然而，有时候所谓的卓越才能可以推翻性能的差异。若能拥有无论何种状况都可以正确射穿要害的本领，或是能以比魔术压倒性迅速的速度来连续射击，即使是弓箭也十分足以吃得开。"

## 四、种族 / 生物
- 名称：拉斯塔熊
- 特征：
  - 等级与分布：属于B级魔物，在中央大陆西北地区极其普遍常见。
  - 外观特征：全身长有白毛，体正中脊椎沿线分布有一条显著的黑色线条。
  - 活动规律：群体行动，不掘深穴，如海狮般瘫卧在水边休息；午后至黄昏交配，入夜后睡觉；夜间视力极弱，行动迟滞。
  - 季节变化：夏季较为温和，聚集在水边繁殖，是冒险者组织夜袭讨伐的标准时机；入冬前则会大群搜集并囤积过冬食粮，此时频繁主动袭击人类。
  - 拟态伪装：部分潜伏在近水湿地的族群会全身涂满烂泥形成保护迷彩，隐藏于黑夜中极难被肉眼侦测。
  - 产出价值：尾巴为向公会交付委托的讨伐证据；其毛皮可剥取贩卖，具备可观的经济价值。
- 原文依据："拉斯塔熊在魔物层级中属于B级。在这个中央大陆西北地区，它们是以特别普遍的魔物为人所知。外观是长着白毛的熊，在身体的正中央有一条沿着背脊的黑线。讲到和一般的熊有什么不同之处，是它们会群体行动，还有在接近冬天时，会成群搜寻并储存食物。碰上那段时期，袭击人类的次数也会变多。不过因为它们在夏季时比较安分，还会前往靠近水边的地方繁殖，经常在这时遭到冒险者讨伐。驱除方法也已经确立，就是在夏季，尤其是针对繁殖期发动夜袭。"、"是泥巴。拉斯塔熊沾上泥巴藏起自己的身影，就像是穿着迷彩服。"、"必须收集拉斯塔熊的尾巴作为讨伐的证据，还有进行有利可图的剥皮作业。不用说，这种魔物的皮能够卖钱。"

## 五、物品 / 道具 / 武器
- 名称：拉斯塔熊的毛皮与尾巴
- 说明：猎杀魔物后的战利品。尾巴作为讨伐数额的官方审核证据，毛皮需现场手工剥下并搬运回城出售换取金币。
- 原文依据："必须收集拉斯塔熊的尾巴作为讨伐的证据，还有进行有利可图的剥皮作业。不用说，这种魔物的皮能够卖钱。所以按照冒险者的作风，要尽可能剥下来带回去。"

- 名称：圣物（洛琪希的内裤）
- 说明：转移事件后由女仆莉莉雅转交给鲁迪乌斯的一块白色布料。鲁迪乌斯视其为指引人生与赋予生存勇气的圣物，贴身藏于口袋，在绝境或崩溃时用双手合握抵在额头寻求抚慰与神圣启示。
- 原文依据："望着壁炉火焰的我从口袋里拿出某样物品。是一块白色的布。但不是手帕。而是在转移事件里失去一切后，莉莉雅送到我手上的东西……没错，就是圣物。在旅途中，我一直把这东西放在口袋内。我用双手握住圣物后，抵在额头上。"

- 名称：木雕项链
- 说明：莉莉雅亲手为鲁迪乌斯雕刻制作的木质饰品，鲁迪乌斯佩戴于胸前，承载着家人的挂念与重聚的希望。
- 原文依据："我伸手摸了摸胸前的项链。大概是莉莉雅亲手为我制作的木雕项链。她总是为我竭尽心力，应该会很期盼哪天能和我再度相见。"

- 名称：艾莉丝留下的布
- 说明：艾莉丝离去后遗留下的随身物品与情感寄托。鲁迪乌斯在历经心路洗礼决定彻底振作后，将其投入旅社壁炉化为灰烬，象征与过往的依赖决裂。
- 原文依据："最后，我从行李里拿出另一块布。在旅程中我一直很没出息地随身携带，是艾莉丝留下的东西，也是充满回忆的物品。我一言不发地把这块布丢进壁炉里。"

- 名称：长权杖
- 说明：提摩西所持的高级法杖，杖身较长，魔术师用于引导攻击法术。
- 原文依据："他也是魔术师吧，身上穿着红褐色的长袍，手里还拿着长长的权杖。"

- 名称：入门者用魔杖
- 说明：帕特里斯作为魔法战士随身携带的简易魔杖，用于辅助施放低阶风魔术。
- 原文依据："腰上佩着剑，手里拿着入门者用的魔杖，体格很健壮的前卫帕特里斯。"

- 名称：罗森堡烈酒
- 说明：罗森堡当地供应的强劲酒水，烈度与风味近乎威士忌，刺激感强且容易致醉上头。
- 原文依据："因为不习惯喝酒，再加上这城镇的酒跟威士忌一样强烈又有特殊风味，让我很快就觉得不舒服而不得不使用解毒。"

## 六、历史 / 传说 / 事件
- 事件名：库库鲁湖拉斯塔熊讨伐战
- 内容：「Counter Arrow」与鲁迪乌斯联合承接A级委托，于夜间突袭库库鲁湖畔筑巢的20只拉斯塔熊。战斗途中大火球引燃并惊醒了湿地深处隐匿伪装的近百只拉斯塔熊，队伍撤退不及陷入团灭绝境。鲁迪乌斯受到同伴绝不放弃求生的意志触动，挺身施展无咏唱「狱炎火弹」与「岩炮弹」全歼熊群，将湖畔烧为焦土，完成委托并凯旋。
- 原文依据："提摩西连续使出的大火球虽然直径有一公尺以上，却以优秀的速度冲向拉斯塔熊的族群"、"「数量太多了！」「撤退！快撤退！」提摩西慌慌张张地发出号令。"、"「『狱炎火弹』。」魔杖产生的巨大猛烈火焰非常轻松地把成群的拉斯塔熊全部燃烧殆尽。"、"一个小时后。湖泊周遭已经化为被烧毁的平野。附近散落着大量拉斯塔熊的尸体。"

## 七、社会规则 / 习俗 / 文化
- 内容：冒险者远征出征礼仪与集合时间常识
- 原文依据："对方并没有指定时间，然而冒险者要去远征时，大清早集合是一种常识。而且，早到应该比迟到好。"

- 内容：外来冒险者化解排挤与立足公关策略
- 原文依据："在冒险者当中，也有许多人选择一个城镇落脚生根。要是来自其他城镇的家伙突然办成什么大案子，那种人就会像现在这样送上带刺的视线。在治安比较差的地方，甚至会有人直接来找碴，要求交出保护费之类。……「这就是提摩西的做法。只要像这样在各处请其他人喝酒，无论去到哪里都不会被讨厌。毕竟考虑到被奇怪家伙长久纠缠的情况，这种做法反而可以省更多钱。」……他们是趁着赚到大钱时回馈给周遭，并借此降低仇恨值。"

- 内容：委托清算与遗体火化行规
- 原文依据："接下来，所有人都要尽可能多带一点毛皮，然后踏上凯旋之路。讨伐虽然结束，但委托还没完成。直到把委托的证据带回去并换成金钱为止，都是冒险的一部分。"、"等剥皮作业结束，把剥下的毛皮和尾巴聚集起来，再集中尸体予以火化时，天空已经开始泛白。"

- 内容：阿斯拉王国的阶级结构、姓名特权与贵族教育
- 原文依据："在阿斯拉王国，格雷拉特并不是少见的姓氏。然而叫这名字的人大部分都是中、下级的贵族。一般城镇和农村的居民很少有人拥有格雷拉特这姓氏。正确说法是，基本上那种身分的人通常没有姓。我也一样。猎人夫妻生下的我只有莎拉这名字。我的父亲跟母亲也没有姓氏。换句话说，自称鲁迪乌斯・格雷拉特的这个少年是贵族的少爷。"、"离家出走的贵族少年并不是那么罕见的存在。……贵族从小就接受教育。读写和算术自不用说，有的家庭还会让小孩学习剑术。好像部分贵族会舍弃魔术认为没有必要学习，但我也有听说过有些学校把初级魔术列为必修课程。"、"但是他们完全没有以冒险者身分活下去的心理准备，也没有做好失去生命的心理准备。要是遇上魔物而受伤或是同伴陷入危机时，他们会逃走。因为，他们还有地方可以逃回去。"

## 九、角色认知 vs 客观事实
- 角色以为（一）：莎拉认为鲁迪乌斯不过是一个“不知世事的井底之蛙，生活在优渥特权家庭中，因在学校或与父母争吵赌气离家出走的贵族少爷”，并笃定他宣称的“寻找在转移事件中失踪的母亲”纯属借口谎言，遭遇死局必会抛弃队友逃跑。
- 原文是否暗示另有真相：是
- 原文依据："换句话说，自称鲁迪乌斯・格雷拉特的这个少年是贵族的少爷。……简而言之，他是离家出走。……我认为鲁迪乌斯也是那种贵族少爷之一。……一开始听到他要去寻找母亲虽然让我受到冲击，但是过了一阵子之后，可以推论出他是在说谎。"——事实真相是鲁迪乌斯在死战中非但没有逃跑，反而以压倒性魔术救了全队；且其家园消灭、长年漂泊寻母皆为真实，莎拉后续在内心深处亦意识到这并非谎言，仅是出于平民对贵族特权的敌视与偏见而强行抗拒承认。

- 角色以为（二）：提摩西误以为鲁迪乌斯此前队伍的队长是一位“优秀却不幸阵亡的领袖”。
- 原文是否暗示另有真相：是
- 原文依据："「是吗……死去的队长是个优秀的人吧。」「不……」一点都不优秀，那个队长直到最后都是个没有用的家伙。比起那种人，成为队伍名称由来的家伙反而优秀得多。"——事实真相是此前队伍「Dead End」的实质战术指挥者正是鲁迪乌斯自己，且队友（瑞杰路德与艾莉丝）并未死亡，只是各自离去。
