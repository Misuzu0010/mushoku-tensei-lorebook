# 第五话　「快速进展」 世界设定提取

## 一、地理与场所
- 名称：米尔波兹领地（ミルボッツ領）
- 内容：位于阿斯拉王国中央附近的领地，由阿斯拉上级贵族诺托斯・格雷拉特家管辖。其西部边缘为多森林的贫困边陲村落，为莎拉的故乡。约五年前该处曾爆发大规模魔物泛滥惨剧。
- 原文依据："听说莎拉出身于阿斯拉王国中央附近的米尔波兹领地，故乡是领地西部边缘的一个村子。……而且莎拉故乡的米尔波兹领地是由保罗逃离的诺托斯・格雷拉特家负责治理的区域，也很有可能无法说是没有关系。"

- 名称：多纳提领地（ドナティ領）
- 内容：阿斯拉王国靠近北方的边境领地。「Counter Arrow」在阿斯拉王国中央升上B级后，因中央缺乏高阶委托而在此活动，后以此为跳板前往中央大陆北部。
- 原文依据："升上B级之后，在阿斯拉王国中央一带几乎没有工作可接，因此他们不断往偏远地区移动，后来乾脆下定决心，提议前往难度更高一级的地方。原本犹豫着该选南部还是北部，后来因为当时的活动地点多纳提领地比较靠近北方，再加上提摩西出生于北方大地，对那边的地理情势都比较熟悉。似乎是基于这些理由，他们决定往中央大陆北部移动。"

- 名称：利美特商店（リメット商店）
- 内容：位于罗森堡的知名武器店铺，是总部位于阿斯拉王国首都亚尔斯的大型商会所开设的分店。主要招牌商品是来自阿斯拉王国的进口武器，近年来由于进口货品质大幅改善而在罗森堡声誉极高、迅速成长。
- 原文依据："莎拉前往的目的地，是最近在这个罗森堡也特别受到好评的武器店。店名叫作利美特商店，是总部位于阿斯拉王国首都亚尔斯的大型商会经营的店铺，主要的招牌商品是来自阿斯拉王国的进口货。利美特商店以前的评价并非如此良好，听说是因为进口商品的品质在最近几年有了戏剧性的改善，所以急速成长。"

- 名称：首都亚尔斯（王都アルス）
- 内容：阿斯拉王国的首都，跨国商会利美特商店的总部所在地。
- 原文依据："店名叫作利美特商店，是总部位于阿斯拉王国首都亚尔斯的大型商会经营的店铺"

## 二、组织与势力
- 名称：冒险者队伍「Counter Arrow」的组建渊源
- 内容：「Counter Arrow」最初是由在阿斯拉王国米尔波兹领地魔物泛滥讨伐战中失去原队伍、幸存下来的孤身冒险者们（苏珊娜、提摩西、密米尔、帕特里斯）重组而成的队伍。初建时为D级，收留失去双亲的莎拉并协助其快速成长为弓箭手加入队伍，后经历人员增减升上B级，最终转往中央大陆北部发展。
- 原文依据："他们是为了讨伐那些涌出的魔物，被附近城镇派遣到当地的冒险者。魔物的数量相当多，所以投入了相当多的冒险者，受到的损害也很严重。苏珊娜的队伍只剩下她自己和提摩西，其他人都死了。密米尔和帕特里斯的情况也类似，「Counter Arrow」似乎是由那些参加米尔波兹领地的魔物泛滥讨伐，结果成为孤单一人的人们聚集起来后组成的队伍。当时的「Counter Arrow」还是D级队伍，莎拉成为冒险者后，靠着苏珊娜他们的帮忙迅速提升层级，并且加入队伍。……最后升上B级。"

- 名称：诺托斯・格雷拉特家（ノトス・グレイラット家）
- 内容：阿斯拉王国四大格雷拉特上级贵族分家之一，管辖米尔波兹领地，亦是保罗当年叛逆出走的本家。
- 原文依据："而且莎拉故乡的米尔波兹领地是由保罗逃离的诺托斯・格雷拉特家负责治理的区域"

- 名称：利美特商会
- 内容：总部设立于阿斯拉王国首都亚尔斯的大型商业集团，经营武器防具制造与跨国商贸。
- 原文依据："是总部位于阿斯拉王国首都亚尔斯的大型商会经营的店铺"

## 三、力量体系 / 魔法 / 技能
- 名称：心因性ED（勃起功能障碍）
- 规则：鲁迪乌斯因被艾莉丝不告而别抛弃造成的巨大心理创伤，产生强烈的心因性性功能障碍。面对极具魅力的女性肉体接触、亲吻与求欢时，完全无法勃起且失去正常的生理冲动（本章正式证实此前第四话中鲁迪乌斯在接触女性身体时感受到的“缺少该有之物”的真相）。
- 原文依据："莎拉的身材紧实有致，衣服下的皮肤雪白又美丽……她本身没有任何问题……问题在我身上。我的身体在诉说着异常。……如果是平常遇到这种情况，应该会直直挺立彷佛等待已久的那家伙。那个以体感年龄来说已经陪伴我将近六十年的灵魂。现在却连动都不动一下。我举不起来。之后，我们尝试了很多方法。例如自己刺激，麻烦莎拉来摸，或是抵在她身上，来回摩擦等等。然而，我的那玩意儿依旧无力地朝着下方。"

- 名称：剑术等级（鲁迪乌斯）
- 规则：鲁迪乌斯的剑术等级评定为中级。
- 原文依据："「既然你的剑术是中级，那么应该多少懂一点短剑的好坏吧？」"

- 名称：弓箭手的近身剑术防卫
- 规则：弓箭手一旦被敌人贴身近战将极其危险无力，无法直接以箭刺击，因此需兼修基础剑术并配备短剑作为副手自卫武器。
- 原文依据："「其实啊，我也稍微会用剑，不过真的只会一点点。因为如果只会用弓，万一被敌人逼近时会很难应付，所以有请苏珊娜教我剑术。」……「毕竟也不能直接拿着箭去刺敌人嘛。」"

- 名称：无咏唱水魔术造水
- 规则：魔术师可通过魔术直接无咏唱凭空生成可供饮用的清水。
- 原文依据："「你房里有水啊？」「因为我是魔术师，可以制造出来。」"

## 四、种族 / 生物
- 名称：斯佩路德族武器禁忌的影响
- 特征：整个世界对斯佩路德族的恐惧深入人心，将其使用的长枪、长棍等长柄武器视作“恶魔的武器”与不祥禁忌，导致冒险者不愿购买，武器店亦全面忌讳而不予摆设贩卖。
- 原文依据："没看到枪和长棍之类的长柄武器，我记得是因为这个世界把斯佩路德族使用过的东西视为恶魔的武器，所以成了忌讳。毕竟冒险者方面也不会购买不吉利的武器。"

- 名称：北方魔木（制弓材料）
- 特征：北方大地出产的魔木枝干具有极佳韧性与强度，被弓箭手广泛用来手工制作高品质弓箭。
- 原文依据："而且在这附近，如果使用魔木的树枝，就可以做出一把好弓。"

## 五、物品 / 道具 / 武器
- 名称：短剑的层级与分类（以利美特商店为例）
- 说明：
  1. 高级短剑：多具备魔力附加功能，但售价极高，普通冒险者财力难以承担。
  2. 中等短剑：由知名锻造师精工锻造，无特殊魔力附加，但坚固锋利、重心极佳。刀身约20公分微弯者适于精细切削（如削制箭矢）；刀身30公分以上笔直厚刃者适于近战格挡魔物冲击。
  3. 低价格短剑：未精细保养则劣化极快，常态使用寿命最多两年，多被当作消耗品。
- 原文依据："那里有挂满整面墙壁的高级短剑，放在架子上的中等短剑，以及随便堆在箱子里的低价格短剑。在三个种类中，我们首先放弃高级短剑。因为虽然有很多高级短剑都是魔力附加品也很有吸引力，但是钱包里的资金不够。基本上，会选择中等的短剑。这些短剑是有名锻造师制造的武器，尽管没有附加特殊能力，不过有的坚固耐用有的尖锐锋利，或是重心非常稳定，使用起来特别顺手。……至于低价格的那些短剑，全新的时候还算不错，不过除非能保养得非常好，否则状态会立刻变差。要是经常使用，顶多只能撑个两年。很多人都把这种短剑当成消耗品。"；"一把的刀身长约二十公分，而且略为弯曲；另一把则超过三十公分，不过刀身呈现笔直。「要用来削箭的话，应该选这把。」……「不过，要和魔物战斗的话是这把。」"

- 名称：手工弓箭
- 说明：弓箭在冒险者群体中并不普及，武器店一般无现货出售。弓箭手通常就地取材手工制作（利用魔木树枝制作弓身，随身储备羽毛削制箭矢）。
- 原文依据："因为弓是手工制作，就算坏掉也可以立刻重做一把。而且在这附近，如果使用魔木的树枝，就可以做出一把好弓。由于弓并不流行，一般的武器店里并没有贩卖。"

- 名称：民用魔道具（北方巴榭兰特公国产业）
- 说明：巴榭兰特公国魔道具技术发达（高阶魔道具售价相当于冒险者一年收入），但常规武器防具铸造不及阿斯拉王国。其民间研发出类似于家电或具备初级魔术效果的器具（如拳头大小、注入魔力即可点火的取火魔道具），但目前民用器具体积大、做工粗糙。
- 原文依据："这个巴榭兰特公国的魔道具产业很发达，只要支付大笔金钱，就可以买到比阿斯拉王国更好的东西。但是在武器防具方面却是怎么样都比较劣等。"；"这世界里的魔道具好像有很多是类似家电的产品，或是具备初级魔术效果的道具。我看到一个只要注入魔力就能点火的魔道具，原本觉得就像打火机一样，似乎还算方便；不过那东西的体积有拳头般大，要随身携带看来有困难。说是研究有在进展，成果看起来倒是很粗糙。"

## 六、历史 / 传说 / 事件
- 事件名：米尔波兹领地魔物泛滥事件
- 内容：约五年前（莎拉十岁左右），阿斯拉王国中央西侧米尔波兹领地的森林突然涌出大量魔物。管辖领地的贵族托词不肯派骑士团救援，导致大批村民丧生（包括莎拉父母）。周边城镇紧急调遣大批冒险者讨伐，战况惨烈导致多数冒险者队伍覆灭。
- 原文依据："在莎拉大约才十岁时，森林中突然涌出大量魔物，双亲似乎都因此过世。……他们是为了讨伐那些涌出的魔物，被附近城镇派遣到当地的冒险者。魔物的数量相当多，所以投入了相当多的冒险者，受到的损害也很严重。苏珊娜的队伍只剩下她自己和提摩西，其他人都死了。密米尔和帕特里斯的情况也类似……"；"「……贵族……在我故乡的森林里涌出魔物时，讲了一堆理由，不肯派出骑士团。所以才会遭受到那么严重的损害。」"

- 事件名：鲁迪乌斯勃起功能障碍爆发与莎拉决裂事件
- 内容：鲁迪乌斯与莎拉感情升温，莎拉主动前往鲁迪乌斯旅社房间并主动献身求欢，然而鲁迪乌斯因心因性心理创伤完全无法勃起。莎拉在极度羞愧与自尊重挫之下，误以为鲁迪乌斯嫌弃自己、对自己的肉体毫无感觉，为了挽回自尊而口是心非宣称自己也并非喜欢鲁迪乌斯，只是为了还人情的“义务”之举，摔门离去并留下「倒楣透顶」的自嘲；鲁迪乌斯亦产生巨大误会，深受打击借酒浇愁。
- 原文依据："察觉至今为止多次感觉到的不对劲感到底是什么。……我举不起来。之后，我们尝试了很多方法。……莎拉移动到房间门口附近，背对着我站着。「我……其实也不是说……喜欢你还是怎样……是要道谢……对，我只是想偿还之前欠你的人情。所以，你可不要误会。这次再怎么说，都只是类似义务的行动。」……莎拉只丢下这句话，就打开房门，迅速离开。……我听到她在离开房间的那瞬间，喃喃说了句：「倒楣透顶。」"

## 九、角色认知 vs 客观事实
- 角色以为（莎拉对格雷拉特姓氏的初期偏见）：认为拥有格雷拉特姓氏的鲁迪乌斯必然是阿斯拉贵族少爷，是魔法学校毕业后遇到小挫折就任性逃离环境的娇生惯养之徒，迟早也会像腐败贵族一样见死不救干肮脏勾当。
- 客观事实：否。鲁迪乌斯虽有贵族血脉，但并非特权贵族，幼年经历大转移灾难与魔大陆生死跋涉，性格谦逊克制，在战斗中多次挺身殿后掩护队伍撤退。
- 原文依据："「我听到格雷拉特这个姓氏的时候，心想你应该是个阿斯拉贵族少爷。也只认定你是从魔法学校毕业的贵族小孩，只不过碰上一点烦心事就打算逃离原本的环境。」据说莎拉一开始那种浑身带刺的态度，是因为误解了我的出身和行动准则。简而言之，她对我有偏见。"

- 角色以为（房内受挫后莎拉的误会 vs 鲁迪乌斯的误会）：
  1. 莎拉以为：自己主动献身求欢，鲁迪乌斯却毫无生理反应，以为鲁迪乌斯嫌弃鄙夷自己的身体和女性魅力。极度羞愤之下为了维持自尊，口是心非宣称自己“根本不喜欢你，只是为了还人情的义务”，摔门离开。
  2. 鲁迪乌斯以为：听到莎拉临走时称“不是喜欢你”、“只是类似义务的行动”以及喃喃自语的“倒楣透顶”，误以为莎拉真的对自己毫无爱意，这段时间的陪伴全都是出于救命之恩的敷衍与应付。
- 客观事实：否。两人产生了极大的双向认知错位。莎拉早已真心爱慕鲁迪乌斯（约会前悉心梳理打扮、娇羞靠在鲁迪乌斯身上、主动挽手臂回旅社），所谓“还人情的义务”纯为自尊心受创后的逞强谎言；而鲁迪乌斯完全是因为前世自卑叠加艾莉丝离开的心因性创伤爆发导致身体无法勃起，并非不认可莎拉的身体与魅力。
