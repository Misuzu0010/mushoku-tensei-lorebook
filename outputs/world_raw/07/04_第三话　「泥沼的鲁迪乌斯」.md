# 第三话　「泥沼的鲁迪乌斯」 世界设定提取

## 一、地理与场所
- 名称：加尔高遗迹（ガルガウ遺跡）
- 内容：位于罗森堡往南约两天的路程。入口在山沟旁漂浮着碎冰的河川岸边，外观像突兀的洞窟，洞口约一半被冰覆盖，冰柱形成类似屋檐的形状，宛如熊窝。约十年前由某冒险者偶然发现。洞窟内部有发出蓝白色光芒的苔藓或宝石类物质，深处一侧为悬崖，崖下为地底湖（栖息着巨大青蛙）。道路尽头为第一次人魔大战时地底魔王拉冈哈冈建造的巨大地下要塞，高约五层楼、宽如国中校舍，天花板近五公尺高，通路狭窄，构造如迷宫。最深处与伊尔布隆洞窟连通。
- 原文依据："从罗森堡往南移动约两天的地方，似乎有个遗迹是这次的目的地。……山沟里有条漂浮着碎冰的河川，岸边可以看到一个显得突兀的洞窟。洞口约一半被冰覆盖，冰柱形成类似屋檐的形状，所以从山崖上难以看清。这外观与其说是遗迹，反而更像是个熊窝。……然而有情报显示，大约在十年前由某个冒险者偶然发现的加尔高遗迹入口确实是这种感觉。……加尔高遗迹是第一次人魔大战时建造的要塞，建造者是当时被人们畏惧为五大魔王之一的地底魔王『拉冈哈冈』。"

- 名称：伊尔布隆洞窟（イルブロン洞窟）
- 内容：距离罗森堡约一天路程的洞窟，平常出没魔物多为E到D级，深处产有岩盐，附近有村庄。数日前其最深处与加尔高遗迹连通，导致大量加尔高遗迹的魔物涌入。
- 原文依据："伊尔布隆洞窟是距离罗森堡一天路程的洞窟，出现的魔物大多是E到D级，由于深处有岩盐，有时候会有冒险者承接委托去采集。那样的地方，发生突然涌出大量C级魔物的事态。因为附近有村庄，距离罗森堡也很近……"

- 名称：魔法都市夏利亚（魔法都市シャリーア）
- 内容：拉诺亚王国内以魔法大学闻名的都市。
- 原文依据："「是的，我出生于拉诺亚王国的无名村庄，在以魔法大学闻名的魔法都市夏利亚长大……」"

- 名称：巴榭兰特公国（バシェラント公国）
- 内容：北方大地的国家之一，其禁卫骑士团配有使用雪龙兽鳞片制造的铠甲与盾牌。
- 原文依据："据说巴榭兰特公国的禁卫骑士团就拥有使用雪龙兽鳞片的铠甲和盾牌。"

## 二、组织与势力
- 名称：Stepped Leader（ステップドリーダー）
- 内容：S级冒险者队伍，隶属于大规模集团「Thunderbolt」，是罗森堡城镇中最强的冒险者队伍，平常主要以探索迷宫为主。队长为使用剑神流剑术的佐尔达特・黑克勒。
- 原文依据："这些人在『Stepped Leader』，S级的冒险者队伍。隶属大规模集团『Thunderbolt』的强大队伍，也可以说是罗森堡这城镇中的最强冒险者。这男子是『Stepped Leader』的队长，名字应该是叫作佐尔达特・黑克勒。据说是个使用剑神流剑术的厉害剑士。"

- 名称：Thunderbolt（サンダーボルト）
- 内容：大规模冒险者集团，S级队伍「Stepped Leader」为其所属队伍。
- 原文依据："隶属大规模集团『Thunderbolt』的强大队伍"

- 名称：巴榭兰特公国禁卫骑士团
- 内容：巴榭兰特公国的亲卫部队，装备以雪龙兽鳞片制成的铠甲和盾牌。
- 原文依据："据说巴榭兰特公国的禁卫骑士团就拥有使用雪龙兽鳞片的铠甲和盾牌。"

## 三、力量体系 / 魔法 / 技能
- 名称：神击魔术（神撃魔術）
- 规则：对幽魂等幽灵系魔物最具特效的魔术系统。比火魔术消灭幽魂更快速彻底，被神击魔术击杀的幽魂会四分五裂化为光粒消灭且不会复活（火魔术消灭的幽魂一段时间后会复活）。若击中骷髅兵也会使其化为光粒消失（但幽魂不灭仍会继续召唤）。咒语包含『Exorcistrate』。
- 原文依据："对那个幽灵最有效的攻击是神击魔术。神击魔术远比火魔术快速，而且可以完全消灭幽魂。被神击魔术打死后，幽魂就不会再度复活。顺便说一下，听说骷髅兵要是被神击魔术击中也会化为点点光粒消失，然而只要没打倒幽魂，好像就会无限召唤出骷髅兵。「将恩惠赐予慈母般大地的吾之神啊！对违背天理的愚蠢之徒给予神罚吧──『Exorcistrate』！」"

- 名称：神级土魔术
- 规则：神级层级的土系统魔术，地底魔王拉冈哈冈擅长此魔术，能于地底建造雄伟要塞并开凿地底道路实施奇袭。
- 原文依据："「据说地底魔王能使用神级的土魔术，所以擅长像这样在人族无法干涉的位置建造要塞，还会在地底挖出道路后再发动大规模奇袭。」"

- 名称：火系统攻击魔术「火炎放射」
- 规则：火系统广范围攻击魔术。咏唱文为："微小的火星将会把巨大的恩惠燃烧殆尽！『火炎放射』！"
- 原文依据："「──微小的火星将会把巨大的恩惠燃烧殆尽！『火炎放射』！」……他把双手朝向空中，使用能攻击广范围的火魔术来迎击敌人"

- 名称：土系统防御魔术「土堡」
- 规则：无咏唱在前方制造出拦截通道的坚固土制壁垒。
- 原文依据："「『土堡』！」我制造出土墙堵住它们的前进路线，一道像是要截断通路的土制壁垒。高度差不多到达石像的肩膀，隔开我们和雪龙兽。"

- 名称：冰系统魔术「冰枪暴风雪」
- 规则：制造激烈冷风并射出数根如大腿般粗的冰枪。
- 原文依据："「『冰枪暴风雪』！」情急之下我用出了冰魔术。空间里刮起惊人的激烈冷风，散落一地的鳞片在空中飞舞，好几根有大腿那么粗的冰枪朝着钻过缝隙的雪龙兽飞去。"

- 名称：剑神流剑术
- 规则：剑术流派之一，S级冒险者佐尔达特所修习。
- 原文依据："据说是个使用剑神流剑术的厉害剑士。"

- 名称：治愈魔术舒缓肌肉酸痛
- 规则：治愈魔术能有效舒缓消除过度运动后的肌肉酸痛。
- 原文依据："不能使用治愈魔术。那种方式的确可以舒缓肌肉酸痛，却无法培育出爱情。"

## 四、种族 / 生物
- 名称：雪龙兽（スノードレイク）
- 特征：龙的低阶种族，无翅不会飞，外形如三至四公尺长、长有四脚的雪白蜥蜴/壁虎。栖息于加尔高遗迹深处，成群筑巢。战斗力强且成群，强度分类为S级；但讨厌光线、不喜外出、性情温和，不侵犯巢穴少主动攻击，危险度为A级高阶。行动极为敏捷（身躯庞大却有小蜥蜴般的敏捷度，能攀墙走壁）。鳞片极坚硬牢固且高度隔热，对冰魔术与严寒具极高耐性，但讨厌火焰。有外出觅食必经路线上理毛掉落鳞片的习性。
- 原文依据："所谓的雪龙兽，在这附近是只有栖息于该遗迹里的魔物。而且正如其名，拥有如雪般洁白的鳞片，是龙的低阶种族。体型大约有三公尺到四公尺左右，没有翅膀所以不会飞行，会在洞窟和迷宫等地的深处筑巢并成群生活。由于雪龙兽拥有强大战斗力加上会成群活动，因此以强度来说被分类为S级。然而它们讨厌光线也不太会外出，再加上个性较为温和，只要不袭击巢穴就很少会主动攻击，所以危险度被视为较低，顶多是A级高阶吧。"；"像壁虎一样长着四只脚，还拥有雪白鳞片的蜥蜴……"；"雪龙兽的鳞片是隔热材，冰魔术怎么可能会对栖息于这片寒冷地区的那些家伙有用。"

- 名称：骷髅兵（スケルトン）
- 特征：由骸骨构成的魔物，手持生锈武器。弱点为敲击钝击（能将其迅速击碎瘫痪）。具不死性，火烧亦能行动，烧毁后可从灰烬复活；只要召唤操纵它的幽魂未死，碎骨会重新聚合复活。被神击魔术击中会化为光粒消灭。
- 原文依据："路上到处可见的骸骨正发出喀哒喀哒的声音并缓缓站起。……这是骷髅兵。……「只要幽魂还活着，骷髅兵就是不死身！」……骷髅兵是不死身。即使放火烧，燃烧中的骷髅兵也能够继续行动，而且被烧光之后还能从灰烬中再复活。最有效的攻击是以强大力量敲打……"

- 名称：幽魂（レイス）
- 特征：半透明幽灵系魔物，无头无脚，具人类细瘦躯体，披破烂斗篷滑行移动。可驱使并无限复活骷髅兵。火魔术只能使其暂时消失（一段时间后复活），神击魔术为绝对弱点，被命中会彻底消灭不再复活。
- 原文依据："道路前端出现某种半透明的物体。那玩意儿没有头，也没有脚。可是却拥有像是人类的细瘦躯体，身上的破烂斗篷随风摇曳，正滑行般地慢慢靠近这里。是幽灵。……对那个幽灵最有效的攻击是神击魔术。神击魔术远比火魔术快速，而且可以完全消灭幽魂。被神击魔术打死后，幽魂就不会再度复活。"

- 名称：巨蝙蝠（ジャイアントバット）
- 特征：体型约一公尺的黑色飞行魔物，飞行速度快，栖息于洞窟遗迹。
- 原文依据："有某种约一公尺大小的黑色物体正飞往这边，而且速度相当快。「是巨蝙蝠！」"

- 名称：地底湖巨大青蛙（未说明具体学名）
- 特征：栖息于加尔高遗迹地底湖，蓝黑色体表（推测有毒），体长五公尺以上，能将一公尺大的巨蝙蝠一口吞食，在严寒环境下不冬眠。
- 原文依据："从湖里现身并一口吃下蝙蝠的东西是更巨大的青蛙。看起来就有毒的蓝黑色对比让我联想到箭毒蛙，眼前那家伙肯定有毒。……大到能够把一公尺的蝙蝠当成苍蝇般一口吃掉的程度。所以大概有五公尺，说不定更大。"

- 名称：加尔高遗迹其他魔物
- 特征：蚰蜒状魔物（极弱，前锋单人可斩杀）、红眼鼹鼠、蕈人。
- 原文依据："反方向和二楼会出现巨蝙蝠、红眼鼹鼠、蕈人或幽魂等魔物。"

- 名称：魔大陆蛙形种族
- 特征：魔大陆上生活着长得像青蛙的魔族。
- 原文依据："况且魔大陆上有长得像青蛙的种族，讨厌青蛙会很难度日。"

## 五、物品 / 道具 / 武器
- 名称：雪龙兽的鳞片
- 说明：色泽为澄澈透明的白色，反射光线时微微泛蓝，质地极为坚固耐用，具备优秀隔热性。主要用作高级建材（铺设于贵族宅邸卧房地砖等），亦用于制作防具（巴榭兰特公国禁卫骑士团的铠甲盾牌、S级冒险者防具，对当地魔物防御效果极佳）。
- 原文依据："因为雪龙兽的鳞片具备优秀的隔热性，主要是被当成建筑材料。……雪龙兽的鳞片是特别高级的一种。不但坚硬牢固又耐用，而且原本几乎透明澄澈的白色在反射光线后会微微泛出蓝色，呈现出非常漂亮的色彩。所以会被当成磁砖使用，铺设于贵族宅邸的寝室等地方。还有也会被用来制作铠甲和盾牌，据说巴榭兰特公国的禁卫骑士团就拥有使用雪龙兽鳞片的铠甲和盾牌。"

- 名称：火龙骨做的箭镞
- 说明：使用火龙骨制成的弓箭箭镞。
- 原文依据："「我这次有带火龙骨做的箭镞，不过可能会没有用。」"

- 名称：火把（洞窟探险用）
- 说明：洞窟探索必需品，除照明外可充当紧急武器，粗暴对待亦不易熄灭，投掷后仍能发光。
- 原文依据："拿出事先准备好的火把后，我在前端点火。这是探索洞窟时的必须品。虽说也可以使用提灯，不过火把上点燃的火焰本身可以当成武器，而且就算稍微粗暴对待也不会熄灭，所以就算在战斗时紧急丢了出去，依旧能够当成光源。"

- 名称：鞋底加钉
- 说明：在鞋底加装金属钉以防止在洞窟结冰地面滑倒的探险对策。
- 原文依据："基本上我们有在鞋底加钉作为对策，不过会跌倒的时候还是照跌不误。"

## 六、历史 / 传说 / 事件
- 事件名：第一次人魔大战与地底魔王拉冈哈冈的进军
- 内容：第一次人魔大战时期，人称五大魔王之一的地底魔王拉冈哈冈擅长神级土魔术，在人族无法干涉的地底修建加尔高要塞，开凿地道向地面人族发动大规模奇袭，罗森堡一带曾是双方激战地带，流传有许多相关传说。
- 原文依据："「加尔高遗迹是第一次人魔大战时建造的要塞，建造者是当时被人们畏惧为五大魔王之一的地底魔王『拉冈哈冈』。」提摩西喃喃说道。「据说地底魔王能使用神级的土魔术，所以擅长像这样在人族无法干涉的位置建造要塞，还会在地底挖出道路后再发动大规模奇袭。」「这一带过去似乎是地底魔王和人族激战的区域，所以有好些相关事迹被当成很久以前的故事而流传下来。」"

- 事件名：加尔高遗迹与伊尔布隆洞窟贯通导致的魔物灾害
- 内容：加尔高遗迹古代地下要塞的地道与伊尔布隆洞窟深处原本相通，后因坍方或战争封死，近期因某种原因再次贯通，导致原本栖息在遗迹内的雪龙兽等大量魔物涌入伊尔布隆洞窟，使前去讨伐的冒险者队伍近乎全灭，任务提升为S级由「Stepped Leader」解决。
- 原文依据："「其实也没什么，是伊尔布隆洞窟和这个加尔高遗迹的最深处由于某个因素而互相连通，所以加尔高遗迹的魔物大量涌入了伊尔布隆洞窟吧。」……加尔高遗迹是过去魔王的要塞。魔王在地下建造堡垒，到处挖洞并攻击地上的人族。如果伊尔布隆洞窟也是那些攻击用洞穴之一的话……其实也没什么好奇怪。"

- 事件名：莎拉故乡灭亡事件
- 内容：莎拉的故乡因森林中涌出魔物而毁灭，当地领主贵族直到最后都不肯派遣骑士团救援，导致莎拉父母死亡，使莎拉极度痛恨贵族。
- 原文依据："我的故乡是因为贵族的懈怠才会灭亡。在森林里涌出魔物时，那些贵族直到最后都不愿意派出骑士团。父母也都是因此而死。"

## 七、社会规则 / 习俗 / 文化
- 内容：单人冒险者以佣兵身份协同队伍活动及报酬惯例
- 原文依据："我基本上是独立活动，碰到有队伍在犹豫是否要承接以自身实力来说有点困难的委托时，就会毛遂自荐表示自己可以提供支援，然后像佣兵那样跟着对方，持续做出帮助他们的行动。报酬是该委托能获得之金额的一成左右。还有击倒魔物后会取得一些素材等杂物，这部分的收入则是要看我拿得动多少，其中一半算是我的份。没有加入队伍，而是以佣兵身分跟着对方并索取金钱的行为，据说并不是太受到冒险者公会肯定的举动；然而公会方面还是睁一只眼闭一只眼，认定这样基本上并没有违反规则。"

- 内容：冒险者队伍的人数上限
- 原文依据："或者是队伍成员凑齐上限的七人，应该已经轻松升上A级吧。"

- 内容：战斗波及与残余战利品分配默契
- 原文依据："也就是万一在和魔物交战时有其他队伍遭到波及，那么被波及的那一边只能分到一只剩下的战利品。这默契原本是为了抑制队伍故意被波及的行为。"

## 九、角色认知 vs 客观事实
- 角色以为（佐尔达特）：以为「Counter Arrow」是趁着他们在前面辛苦讨伐时，故意从后门溜进来偷捡雪龙兽鳞片捡漏的无耻队伍。
- 客观事实：否。Counter Arrow 是接了正规的公会A级采集委托来到加尔高遗迹，完全不知道深处与伊尔布隆洞窟贯通，也不知道 Stepped Leader 正在另一头清剿雪龙兽。
- 原文依据："「抢了别人的猎物，别摆出一副嘻皮笑脸的样子！」……「趁别人工作时偷偷从后门溜进来，打算只摸走鳞片，哪能说什么突然不突然！」……「其实也没什么，是伊尔布隆洞窟和这个加尔高遗迹的最深处由于某个因素而互相连通……」……佐尔达特就皱起眉头。接着，他愤愤地啐了一口。「啧，突然打人是我不好……」"

- 角色以为（鲁迪乌斯）：以为遗迹深处传来的喧闹兽吼是雪龙兽进入发情期求偶的声音，自己是虚惊一场。
- 客观事实：否。实际上是遗迹深处的雪龙兽巢穴遭到 Stepped Leader 的强力清剿与屠杀，恐慌溃退的雪龙兽群朝出口通道狂奔涌来。
- 原文依据："看样子是我白担心一场。说不定只是雪龙兽进入发情期，正在进行求偶行动而已。……雪龙兽就像是被那些东西追赶，想要逃到遗迹外面。站在最前方的男子接二连三地击倒雪龙兽……"

- 角色以为（鲁迪乌斯）：看到遗迹深处的断头妖艳巨乳女性雕像，怀疑是魔界大帝奇希莉卡・奇希里斯的雕像并认为雕刻者严重夸大美化捏造了她的身材（胸部和身高）。
- 原文是否暗示另有真相：不明 [存疑]（魔界大帝奇希莉卡在第一次人魔大战时期的成熟形态与当前幼女形态是否存在差别，本章未证实，仅为鲁迪乌斯主观推想）。
- 原文依据："那石像该不会是奇希莉卡・奇希里斯吧？我之前遇到的奇希莉卡有着小女孩般的外表，该不会，不，不可能……不过，通常那种作品在制作时都会美化很多，所以被塑造成那种美女也是很正常的事情。只是，再怎么说也捏造过度了吧？尤其是胸部和身高。"

- 角色以为（莎拉）：认为自己极其憎恶贵族以及有贵族血统的鲁迪乌斯，在危急时刻舍弃他也无所谓。
- 客观事实：否。在雪龙兽群围攻鲁迪乌斯时，莎拉是第一个不顾危险冲出去射击支援拯救鲁迪乌斯的人，内心承认自己并不讨厌鲁迪乌斯。
- 原文依据："苏珊娜以前有说过……「讲这种话，但是第一个冲出去的人不就是莎拉你吗？……」……承认吧。我并不讨厌鲁迪乌斯。因为虽然鲁迪乌斯是贵族小孩，但他本身并不是贵族那种东西，所以我不讨厌他。但是，顶多也只是不讨厌而已。绝对不是喜欢。"
