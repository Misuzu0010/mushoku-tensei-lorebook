# 第一话　「失意的魔术师」 世界设定提取

## 一、地理与场所
- 名称：罗森堡
- 内容：巴榭兰特公国的第二都市，规模在公国内数一数二。与阿斯拉王国国境相隔约两个月路程的距离，被称为北方大地的入口。巴榭兰特公国的财政营收大半依靠罗森堡出口至阿斯拉王国的魔道具。城内街道整齐排列着行道树，设为固定间隔以便在紧急状况时砍下充当柴薪。气候严寒，多云阴白的天空为雪国特有景观，冬季会降大雪。冒险者公会位于远离城门入口与旅馆街的偏远位置。城北设有北门。
- 原文依据："巴榭兰特公国，第二都市罗森堡。这个城镇和阿斯拉王国国境相隔约两个月路程的距离，可以说是北方大地的入口。规模在巴榭兰特公国内也是数一数二。据说巴榭兰特公国的营收有大半部分是靠这城镇出口到阿斯拉王国的魔道具。"、"巴榭兰特公国里有许多行道树。据说是为了在发生不测事态时砍下来当作柴薪使用，不过大概是因为保持着固定间隔，看起来绿意盎然。"、"不知为何，这个城市的冒险者公会位于远离城镇入口，也离旅馆街有一段距离的地方。"

- 名称：「圆盾亭」
- 内容：罗森堡旅馆街的一家B级旅社，招牌为圆盾造型。房间墙面为其他国家少见的砖块直接外露结构，房内配有床铺、衣柜、桌椅，并装设有供暖壁炉（配备柴薪与打火石）。
- 原文依据："根据招牌，这里是B级的旅社，名字叫作「圆盾亭」。唸起来实在拗口，再加上招牌也呈现圆盾形，感觉会被误认成防具店。"、"讲到特别之处，就是这种砖块直接外露的墙壁在其他国家很少见，还有墙上设置着一个壁炉。壁炉旁边有柴薪和打火石，大概是要客人觉得冷的话就自己点火。"

- 名称：库库鲁湖
- 内容：罗森堡周边湖泊，公会A级委托单中显示该处附近有筑巢的拉斯塔熊族群。
- 原文依据："【A：讨伐在库库鲁湖附近筑巢的拉斯塔熊族群。】"

- 名称：哈朵拉森林
- 内容：罗森堡周边森林，公会B级委托单中显示该处正在执行大规模树木砍伐计划。
- 原文依据："【B：护卫在哈朵拉森林进行的大规模砍伐计画。】"

- 名称：涅里斯公国
- 内容：公会B级委托单提及的商贸目的地国家，有商队由罗森堡护送物资前往。
- 原文依据："【B：护卫将商品运送到涅里斯公国的商队。】"

- 名称：王龙王国
- 内容：中央大陆南部的大国。阿斯拉王国的冒险者在层级提升后，因本国高阶委托匮乏，往往会选择南下前往王龙王国或北上前往魔法三大国。
- 原文依据："因此，自身层级提升到某一程度的冒险者会离开阿斯拉王国，前往南部的王龙王国或是北部的魔法三大国。"

## 二、组织与势力
- 名称：冒险者公会（罗森堡支部）
- 内容：设立于罗森堡的公会设施，远离城镇入口与旅馆街。内设双开大门、接待柜台与大型委托告示板。提供更新卡片、办理队伍解散、跨级承接委托等功能。
- 原文依据："隔天。我前往冒险者公会。不知为何，这个城市的冒险者公会位于远离城镇入口，也离旅馆街有一段距离的地方。"、"告示板上贴着大量的委托单。虽然数量比不上魔大陆，和阿斯拉王国却是天差地别。这附近对冒险者的需求应该非常高吧。委托的等级大部分是C和B吗？"

- 名称：「Dead End」
- 内容：由瑞杰路德、艾莉丝与鲁迪乌斯在魔大陆创立的A级冒险者队伍。因同伴离散名存实亡，鲁迪乌斯在罗森堡冒险者公会柜台正式办理了队伍解散手续，卡片上的队名刻印被消除。
- 原文依据："队伍……我的冒险者卡片最下方还刻有「Dead End」这几个字。Dead End，这是瑞杰路德、艾莉丝和我一起组成的队伍。已经没有人留下，成了一支名存实亡的队伍……必须解散才行。"、"卡片上的「Dead End」已经消失。当艾莉丝和瑞杰路德更新卡片时，也会发现队伍已被解散吧。"

- 名称：「Counter Arrow」
- 内容：抵达罗森堡的B级冒险者队伍，由女战士苏珊娜、弓手莎拉及多名男性成员组成。因队伍编制缺少后卫，在公会中向孤身一人的鲁迪乌斯提出联手承接A级讨伐委托的邀请。
- 原文依据："B级冒险队伍「Counter Arrow」一行。"、"「这样刚好，我们的队伍也正想再添一个后卫。」"

- 名称：菲托亚领地搜索团
- 内容：针对菲托亚领地转移事件成立的大规模专门搜救组织，动员了众多干练细心的人手建立作战计划并进行调查宣传，但历经数月乃至更久仍未寻获塞妮丝。
- 原文依据："因为菲托亚领地搜索团这种具备一定规模的组织已经动用过许多人手寻找，至今为止还是没有结果。所以毫无疑问，找不到的机率比较高。搜索团里一定有比我聪明，而且也干练细心的人。就是那种连收集或宣传情报都很有一套的家伙。"

## 三、力量体系 / 魔法 / 技能
- 名称：冒险者公会等级承接规则（±1跨级机制）
- 规则：公会规定冒险者可承接与自身阶级相同，以及往上一级和往下一级（±1级）的委托。A级冒险者可承接S级、A级与B级委托。
- 原文依据："我现在是A级。根据冒险者公会的规定，也可以承接往上与往下一级的委托。因为看起来没有S级，能承接的委托剩下A和B级。"

- 名称：团队委托前置要求规则
- 规则：A级且目标为击倒群聚魔物的委托，公会通常以“必须组队承接”为常规前提，拒绝单人接取以防送命。
- 原文依据："「可是这委托一个人去做实在有点……因为这是A级，还是以组队承接为前提的委托。」"、"嗯，毕竟委托内容是要击倒整群魔物嘛，正常来说是该组队。"

- 名称：队伍前后卫定位与支援魔术
- 规则：队伍战术分为在前线抗压的前卫与在后方施法的后卫。魔术师普遍担任后卫，职责多为施展支援前卫作战的辅助或控制魔术。
- 原文依据："「我……在之前的队伍里是担任后卫，擅长使用支援前卫的魔术。」「这样刚好，我们的队伍也正想再添一个后卫。」"

- 名称：无咏唱魔术
- 规则：无需念诵任何咒文即可瞬间引导并施放魔术的罕见高级技巧。
- 原文依据："如果我会无咏唱魔术、出身于菲托亚领地，还有正在寻找因为转移事件而失踪的母亲等详细情报没有一并传开，即使变得有名也没有意义。"

## 四、种族 / 生物
- 名称：拉斯塔熊
- 特征：在库库鲁湖一带筑巢繁衍的熊类魔物，以群体形态活动，公会发布的讨伐任务难度定为A级。
- 原文依据："【A：讨伐在库库鲁湖附近筑巢的拉斯塔熊族群。】"、"讨伐拉斯塔熊。从名字来判断，似乎是熊类的魔物，但我不清楚详情。"

## 五、物品 / 道具 / 武器
- 名称：冒险者卡片
- 说明：公会签发的身份与等级记录凭据，底部雕刻有队伍名称。队伍解散后可在柜台抹消刻字，其余队员更新卡片时亦会同步体现状态。
- 原文依据："我把冒险者卡片递给对方。『那个，可以麻烦你……帮忙办理解散队伍的手续吗？』队伍……我的冒险者卡片最下方还刻有「Dead End」这几个字。"、"卡片上的「Dead End」已经消失。"

- 名称：阿斯拉货币（阿斯拉银币）
- 说明：阿斯拉王国的官方通货。在巴榭兰特公国罗森堡等北方大地区域具备极高的信誉度和交易价值，可直接用于支付昂贵的住宿费。
- 原文依据："这一带可以使用阿斯拉王国的货币，虽说迟早必须去换钱，不过现在用这个应该也没问题。况且根据那个女战士所说，阿斯拉货币的信用度和价值似乎都比较高。看到放在桌上的几枚阿斯拉银币，老板睁大双眼。"

- 名称：口袋里的东西（神物/御神体）
- 说明：鲁迪乌斯贴身放置在口袋深处的布料，在极度消沉、窒息或心神受创时握紧能够带给其心理平静与精神支柱。
- 原文依据："不知不觉之间，自己已经把手放进口袋里。我握紧口袋里的东西，狠狠咬紧牙关。虽然胸口发疼，但只要握住口袋里的东西，不知为何内心就会感到平静。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地搜救长期化僵局
- 内容：菲托亚领地转移事件发生后过去相当长时间，专门的搜救搜索团动用大量侦搜力量仍无法掌握塞妮丝等核心失踪人员的踪迹，搜救陷入大海捞针的停滞状态。
- 原文依据："转移事件至今已经过了相当长一段时间，我不认为塞妮丝待在哪个会被他人注意到的地方。"、"因为菲托亚领地搜索团这种具备一定规模的组织已经动用过许多人手寻找，至今为止还是没有结果。所以毫无疑问，找不到的机率比较高。"

## 九、角色认知 vs 客观事实
- 角色以为：公会大厅内的旁观冒险者以及苏珊娜误以为鲁迪乌斯在柜台痛哭并坚决单独接取A级魔物剿灭委托，是因为遭遇了队伍全员阵亡的“全灭”惨剧，且面临断粮缺钱的绝境。
- 原文是否暗示另有真相：是
- 原文依据："看样子这些人似乎是认为我以外的队伍成员都在战斗中死光了，他们当然不可能猜到我是因为被女人甩了所以才哭。"、"「不，我已经听说状况了。你的队伍全灭，想寻找下落不明的母亲却缺钱。所以才想承接这种乱来的委托吧？真是了不起。」我根本没说过那种事。我没说过队伍全灭，也没说过自己没钱。"——事实是「Dead End」因艾莉丝和瑞杰路德各自离去而解散，鲁迪乌斯是因感情受创而心碎落泪，手头尚有此前积累的资金。
