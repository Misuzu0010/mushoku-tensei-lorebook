# 第七话　「婚宴・结束」 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国王宫（政治险境）
- 内容：阿斯拉王国的政治权力中心。对于流亡在外的第一王女爱丽儿阵营而言，该处为极端凶险的夺权死地，一旦返回夺位，结局唯有登基成王或战死于王宫之中，且战死概率极高。
- 原文依据："「……总有一天，我会回到阿斯拉王国。一旦回去，我不是成王，就是死去，两者择一。以机率来说的话，后者是压倒性地高，阿斯拉王宫对我而言，将会成为葬身之地。」"

## 二、组织与势力
- 名称：阿斯拉王国王位争夺阵营（爱丽儿派）
- 内容：以第一王女爱丽儿为核心的流亡势力，旨在积累力量夺取阿斯拉王位。阵营内部有着严酷的政治使命与流血牺牲（已有多数同伴牺牲），王族将回归争位视作不可逃避的统治阶级义务；但爱丽儿认为平民出身的局外人希露菲不应承担此种送死义务。
- 原文依据："「要是逃避，我就会不明白自己到底是为了什么而存活至今。至少得奋战到最后一刻，不然我有什么脸去面对那些相信我而死去的人们呢？回到阿斯拉王国，是我的义务。」「可是，希露菲并没有那种义务。」"
- 名称：米里斯教派伴侣道义准则
- 内容：米里斯教徒具有虔诚的婚姻与伴侣义务观。教徒认为无论深爱的女性背负何种隐情或过往，亦无论现实与自身理想偏差多大，作为信徒都有必须让自己深爱的一名女性获得幸福的绝对道义与责任。
- 原文依据："「那又如何？我是米里斯教徒。无论对方有怎么样的隐情，和我的理想有多大出入，我依旧有让自己深爱的一名女性幸福的义务。」"

## 三、力量体系 / 魔法 / 技能
- 名称：路克的剑术流派水准
- 规则：修习并掌握剑神流中级以及水神流初级。
- 原文依据："「路克习得了剑神流的中级以及水神流的初级。」"
- 名称：剑神流先发制人技「击臂」
- 规则：剑神流正规传承的型制技法，旨在看穿对手出剑轨迹，以攻代守抢先重击对手前臂，破坏其持剑与进攻能力。
- 原文依据："我瞄准路克的前臂。剑神流，先发制人招「击臂」。这是我很久以前就学过的技巧，重复了好几次、好几万次，遵照剑神流之型的动作。「唔！」我的石剑重重劈下，一击就打断路克的手臂。剑从他手中掉落插入雪中。"
- 名称：土魔术塑形制剑
- 规则：以土魔术凭空快速凝聚生成高密度、高硬度的石质实体武器，具有极强的钝击与斩击杀伤力。
- 原文依据："总之，我用土魔术制作出石剑。虽然做得多少比较坚固，相对的也比较重。但因为我姑且每天都有在练习挥剑，还不至于挥不动。"
- 名称：预知魔眼在近战体术中的应用
- 规则：开启预知眼后可提前观测到对手身体冲刺与武器挥砍的未来动作轨迹，使得对手原本迅速的动作在使用者眼中变得迟钝破绽百出。
- 原文依据："不过，总之还是让我用个魔眼吧。毕竟我可不想因为意外而死掉或是杀人。……﹝雪被踹散，路克的身体朝着我笔直加速。﹞好慢。……﹝路克步步逼近，挥剑斜劈了下来。﹞剑势迟钝。"
- 名称：治愈魔术现场接骨治疗
- 规则：中级以上治愈魔术能迅速使被强力击断的肢体骨折复原愈合。
- 原文依据："「爱尔摩雅，用治愈魔术。」爱丽儿一声令下，一名随从冲到了路克身旁。像是要用那丰满胸部包裹住折断的手臂似的抬着，施展治愈魔术。"
- 名称：不死魔族不伤不病体质
- 规则：不死魔族具有超常体质，巴迪冈迪自称“既不会生病也不会受伤”。
- 原文依据："「呼哈哈哈哈！吾既不会生病也不会受伤！」"

## 四、种族 / 生物
- 名称：长耳族（精灵族）对不贞与混血的迫害排斥
- 特征：长耳族社会内部具有极其严重的传统偏见。因背负诅咒而私生活放荡的艾莉娜丽洁所生下的半长耳族子女，在长耳族内部被视为严重忌讳，会遭到非人对待、残酷迫害甚至逐出村落。
- 原文依据："这种现象似乎在长耳族之间特别严重。艾莉娜丽洁的小孩仅仅因为是她的小孩这点就会理所当然地受到他人忌讳。受到迫害，遭受非人的对待，到最后甚至还会被赶出村落。"
- 名称：艾莉娜丽洁与后代的断绝抚养模式
- 特征：因多次在相遇时被亲生骨肉谩骂唾弃，艾莉娜丽洁为保护后代不被自己污名牵连，在此后生下孩子时绝不透露自身姓名，独自将其抚养至能自立后便彻底断绝关系离开。
- 原文依据："由于这种事不胜枚举，据说艾莉娜丽洁在遇见孩子或者是孙子时，见了面的当下就被劈头谩骂的状况也不在少数。因此，艾莉娜丽洁后来即使生下小孩也不会对他们说出自己的名字，直到将小孩照顾到他们成长到能独当一面时再断绝关系，一直以来似乎都持续着这样的模式。"

## 五、物品 / 道具 / 武器
- 名称：路克的魔力附加品高阶战斗套装
- 说明：阿斯拉高级贵族配备的全套高阶魔力装备：
  1. 武器：魔力附加真剑，能轻易劈开铁质盾牌；
  2. 鞋子：与希露菲同款的加速魔力鞋，强化装备者移动速度；
  3. 斗篷：具备隔绝高热特性的隔热斗篷；
  4. 手套：强化物理力量的力量手套；
  5. 内衬：穿在制服内部的高韧性防刃护甲衣。
- 原文依据："「那把剑是魔力附加品，能轻松劈开铁盾。鞋子和希露菲穿的那套相同，可以提高装备者的速度。这件斗逢可以隔热，手套能提高力量，在制服底下还穿着防刀刃的衣服。」"
- 名称：七星的护身魔力附加品 [存疑]
- 说明：七星虽无战斗力与魔力，但在外出时随身配有护身用魔力附加道具保障安全。
- 原文依据："不过她是一个人过来这里的，那应该有带着护身用的魔力附加品，大概没问题吧。"

## 六、历史 / 传说 / 事件
- 事件名：鲁迪乌斯与路克的新婚决斗
- 内容：婚宴结束时，路克在爱丽儿公主的公证下向鲁迪乌斯提出禁止使用攻击魔术的纯剑术比试。鲁迪乌斯凭借土魔术造石剑与预知魔眼，使用剑神流“击臂”招式一招击断路克手臂获胜。路克借此比试确认了鲁迪乌斯具备守护希露菲的强大实力，正式将希露菲托付给鲁迪乌斯。
- 原文依据："「能请您和路克决斗吗？来一场不使用魔术，剑与剑之间的胜负。」……我瞄准路克的前臂。剑神流，先发制人招「击臂」……一击就打断路克的手臂。剑从他手中掉落插入雪中。……「希露菲……就拜托你了。」"
- 事件名：希露菲与爱丽儿相识与追随背景
- 内容：希露菲因菲托亚领地大转移事件坠落至阿斯拉王宫救下爱丽儿，以挚友身份担任护卫一路逃亡并流亡至夏利亚；爱丽儿为避免希露菲卷入未来阿斯拉夺位死局，期望其通过结婚生子自然退出护卫阵营。
- 原文依据："「希露菲救过我一命，以朋友的身分留在我的身边。就连知道自己失去双亲时也一直如此。至今为止，我一直都在对她撒娇……但是，已经足够了。我也差不多该停止对希露菲撒娇，希露菲应该要走上自己的道路才对。」"

## 七、社会规则 / 习俗 / 文化
- 内容：当地民间婚宴的无仪式性与聚餐本质
- 说明：在魔法都市等地民间举办婚宴没有交换戒指或誓约之吻等繁复死板的仪式程序，其社交实质为好友聚集、开怀饮食畅谈后各自散去。
- 原文依据："我们并没有特别在众目睽睽之下进行誓约之吻或是交换戒指。这里的婚宴就只是把东西吃吃喝喝，彼此交谈，吵闹过后就三三两两地回去。不死板这点确实不坏。"
- 内容：兽族作客不拖延滞留的礼貌
- 说明：兽族做客参加庆祝派对时遵循不在主人家过久逗留的规矩，进食交流尽兴后便迅速道别归去。
- 原文依据："最先回家的人，是莉妮亚和普露塞娜。不在别人家待太久这点，或许是出于兽族的礼貌。"
- 内容：西隆王室的饮酒自律规矩
- 说明：西隆王族视在友人/师长家中醉酒闹事为王族莫大之耻，在身体出现醉意但仍能自控行走时必须即刻离席。
- 原文依据："「不，假如在师傅家耍酒疯是弟子……甚至还是荣耀的西隆王族之耻。尽管不舍，就请容本王子在还能走动时先行离席。」"
- 内容：希露菲解除自卑与留长发女性化转变
- 说明：希露菲过去因绿色头发引起偏见及伪装男性护卫，始终保持短发；如今发色转白且已为人妻，决定克服自卑将头发留长以增添女人味，但在学校依然坚持穿长裤行动。
- 原文依据："「鲁迪……我啊，打算把头发留长。……像我……你看，现在的发色也已经不是绿色了吧？况且爱丽儿殿下也要我像个女人。只是在学校果然还是打算穿长裤，所以我想至少得把头发留长比较好吧。」"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯揣测路克向自己拔剑决斗是出于男女之情暗恋希露菲。
- 原文是否暗示另有真相：否（爱丽儿明确澄清彼此为生死与共的战友之情，并非男女之情；决斗纯粹是路克作为护卫同伴为了确认鲁迪乌斯实力的男儿执着）。
- 原文依据："「男人的执着……难道说，路克也喜欢希露菲吗？」「我们大家都喜欢希露菲。只是，那并非男女之间的关系。正因为是曾经生死与共的同伴，才会对彼此有各自的思虑。」"
- 角色以为：鲁迪乌斯以为克里夫得知艾莉娜丽洁连孙女都有且情史极其复杂后会对艾莉娜丽洁彻底幻灭并分手。
- 原文是否暗示另有真相：是（克里夫并未幻灭，反而更加怜惜其遭遇，并以米里斯教义中让爱人幸福为己任，誓言运用自身天才才能协助解除其诅咒）。
- 原文依据："「老实说，丽洁并不是我想的那种人。」……还是幻灭了啊。……「丽洁是个比我想像中更可怜的人，我绝对要治好她的诅咒。虽然因为我是天才迟早会帮她治好……我是米里斯教徒。无论对方有怎么样的隐情，和我的理想有多大出入，我依旧有让自己深爱的一名女性幸福的义务。」"
- 角色以为：希露菲听闻决斗后对鲁迪乌斯的安全毫不担忧，认定路克太弱认真出手会被鲁迪乌斯打死。
- 原文是否暗示另有真相：否（客观事实中鲁迪乌斯仅用一记中级剑神流击臂就重创路克，希露菲对双方实力的认知与客观事实完全一致）。
- 原文依据："「不过还是谢谢你，鲁迪。」「谢什么？」「对路克手下留情。因为路克很弱，要是鲁迪认真出手的话他会死掉吧？」"
