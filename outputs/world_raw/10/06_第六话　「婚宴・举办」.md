# 第六话　「婚宴・举办」 世界设定提取

## 一、地理与场所
- 名称：鲁迪乌斯宅客房 / 备用休息室
- 内容：位于鲁迪乌斯宅二楼的空房间，摆放有简朴的床铺、衣柜、桌椅和水瓶，用于婚宴等聚会活动中宾客突发身体不适或进行私下交谈时的临时休息避难场所。
- 原文依据："二楼的空房间，也为了这天整理好了。话是这么说，其实也只是把简朴的床铺、衣柜、桌子、椅子、还有水瓶什么的搬进去而已，但在万一有人身体不舒服时也是必要的吧。"
- 名称：阿斯拉王国的私宅浴室普及状况
- 内容：在自家住宅中建有专门浴室的设施，即使在阿斯拉王国也仅有极少数顶级阶层或贵族才能拥有，属于极其奢侈少见的居住配置。
- 原文依据："「哎呀，居然在自宅就备有浴室，这在阿斯拉也只有极少部分人士才能拥有呢，真令人羡慕。」"

## 二、组织与势力
- 名称：阿斯拉王国贵族随从与命名文化
- 内容：阿斯拉王国高级贵族配备有身份等级清晰的家臣随从（如第一王女爱丽儿的随从爱尔摩雅・普尔沃夫与克莉涅・艾尔隆德）。鲁迪乌斯推断阿斯拉贵族姓氏多以“颜色与特定动作/动物”的组合命名（如灰色老鼠格雷拉特、苍之狼普尔沃夫等）。
- 原文依据："「我是爱丽儿殿下的随从，名叫爱尔摩雅・普尔沃夫。」「我叫克莉涅・艾尔隆德。」姑且先不论名字，姓氏倒是很好记。是苍之狼和传说骑士。毕竟我的名字是灰色老鼠，阿斯拉王国的贵族是不是以颜色和动作组合起来的名字为多啊？"
- 名称：米里斯教派祝福仪轨
- 内容：米里斯教徒在向新人进行宗教祝祷时，需将新人并排，单手在胸前划出类似十字的手势，并念诵米里斯教专门的简短祝辞。
- 原文依据："克里夫将我们排在一起后，用单手划出类似十字的手势，诵读了简单的祝辞。「虽然你们不是米里斯教徒，不过我能做的祝福就只有这样。」"

## 三、力量体系 / 魔法 / 技能
- 名称：怪力的神子（神子特性）
- 规则：天生具备超常神力、非普通人力所能抗衡的特殊个体（札诺巴・西隆即为怪力的神子）。
- 原文依据："「唔。这真是失礼。毕竟本王子是怪力的神子，空有一身力量但却欠缺智慧。」"
- 名称：七星的防身戒指 [存疑]
- 规则：七星面对魔王级强敌巴迪冈迪接近时，下意识从口袋取出戒指戒备，推测为某种具备防御或抑制魔力影响的特殊魔道具。
- 原文依据："被那股氛围吸引，巴迪冈迪靠了过去。七星慌张地从口袋取出戒指。真傻啊七星。这都是因为你明明说不想和任何人扯上关系，却又那么贪吃的结果。"

## 四、种族 / 生物
- 名称：兽族的婚宴朝猎习俗与繁衍观念
- 特征：兽族参加婚宴时，按照习俗必须在当天一大早亲自外出打猎，用雪橇将刚猎得的优质野兽（如整只大山猪）作为贡品提早送至新人宅邸；送达时间越早代表对受邀对象的忠诚与敬意越深（若猎不到则折衷去市集采购代替）。在婚育观念上，兽族极其崇尚实力，主张“强者之间配对繁衍”，认为强强结合生下强壮子嗣才能保全全族安泰。
- 原文依据："「就我们的常识来说，在庆祝的派对上得要带着猎物提早过来喵。」「没错的说，所以我们把最好的拿过来了。是对老大忠诚的证明的说。」她们用雪橇把庞大的山猪运了过来。兽族在出席婚宴时，似乎有着在当日一大早去打猎，并带着在外头猎到的食材前来参加的常识。在越早的时间去打猎获取食材并赶回来出席，才能表现出对对方的敬意有多深。"
- 原文依据："「不过，菲兹和老大结婚的话，我能接受喵。强者之间配在一起是好事喵。」「没错的说。只要生下强壮的小孩，一族就能安泰的说。」"
- 名称：不死魔族 / 魔王登场法则
- 特征：不死魔族魔王（如巴迪冈迪）拥有黝黑高大躯体与六只手臂。据巴迪冈迪说明，魔界的王族/魔王在参加宴会聚会时，依照魔界大帝奇希莉卡一时兴起所定的规矩，必须在让人大吃一惊的时机突然登场以引起全场混乱骚动。此外，长寿达数千年的高阶魔族普遍缺乏明确的时间观念。
- 原文依据："黝黑的身躯加上高大的身材。那六只手臂硬是被塞进制服里面。不死身的魔王巴迪冈迪突然蹦了出来。从连接厨房的那扇门。"
- 原文依据："「吾没骗你。这是奇希莉卡一时兴起决定的，所以吾也觉得实在很蠢啊！」吾可是为了你不惜两肋插刀，专程绕到后门再从后方选择登场的时机啊。"
- 原文依据："「巴迪冈迪应该是不会准时出现。以千年为单位活着的人士都没有什么时间观念喔。先当作他大约一个月后才会过来比较好。」"
- 名称：长耳族与希露菲的祖孙血统
- 特征：艾莉娜丽洁・杜拉冈罗德为希露菲父亲罗尔兹的生母，即希露菲的亲生祖母。希露菲体内具有浓厚的长耳族血统。
- 原文依据："「那个，我从很早以前就一直想问了……艾莉娜丽洁小姐，难道你是……我的奶奶吗？」……「我爸爸曾说过。我的奶奶……以前曾是鲁迪爸爸的伙伴。」……「我爸爸曾说过。当初是因为奶奶的缘故才被人赶到大森林。还说和母亲结婚时也遭到反对。」"

## 五、物品 / 道具 / 武器
- 名称：阿斯拉王室结婚赠礼（粉红媚药与木棒假阳具）
- 说明：阿斯拉第一王女爱丽儿送给新婚夫妇的实用礼品，包括装有粉红色液体的媚药小瓶与房中助兴木棒，意在增进夫妻房事和谐。
- 原文依据："里面有一罐似曾相识，装着粉红色液体的小瓶子，还有一根木棒。用直截了当的说法，就是媚药和假阳具。「尽管我不认为格雷拉特家的男人无法满足女性，但如果有需要的话还请不吝使用。」"
- 名称：异世界洋芋片与七星烧
- 说明：利用七星商路开拓带来的便宜食用油，将马铃薯切片油炸洒盐制成仿现代风味的洋芋片；以及仿照日式油炸肉食烹饪的“七星烧”。
- 原文依据："「洋芋片？你做了洋芋片吗？」「这都是托你的福，所以我才能轻易地取得食用油啊。」……只是把马铃薯切片用油炸过，再洒上盐巴而已。"
- 原文依据："莉妮亚正盘据在暖炉前，咬着模仿日式炸肉制成的七星烧。七星拿走了整盘洋芋片后，就缩到房间的角落开始一口接一口地吃了起来。"
- 名称：家族同款木雕项链
- 说明：希露菲亲手制作的木雕项链，款式与艾莉娜丽洁佩剑剑柄上的项链完全一致，为祖孙血缘传承的重要信物。
- 原文依据："话说回来，希露菲制作的木雕项链，和艾莉娜丽洁剑柄上的项链是同样的东西啊。这么说起来，她们两人的五官也很相似。"

## 六、历史 / 传说 / 事件
- 事件名：艾莉娜丽洁与罗尔兹的母子过往
- 内容：早年艾莉娜丽洁因自身背负诅咒及放荡恶名，导致其子罗尔兹受牵连被迫迁居大森林；在罗尔兹与希露菲的母亲结婚时，亦因艾莉娜丽洁的名声遭到长辈强烈反对。艾莉娜丽洁为此长期消沉内疚，罗尔兹曾向希露菲提及奶奶即使相遇也可能不敢相认。
- 原文依据："「我爸爸曾说过。当初是因为奶奶的缘故才被人赶到大森林。还说和母亲结婚时也遭到反对。」「……唔！」「爸爸说奶奶因为这件事而消沉，就算见了面或许也不会表露自己的真实身分。」"

## 七、社会规则 / 习俗 / 文化
- 内容：多族群混合婚宴的着装与形式平衡
- 说明：当宴会聚集了王族、魔王、兽族头目之女、贵族、冒险者、奴隶等多阶层与不同种族时，为避免阶级与贫富差距凸显，以魔法大学制服作为统一出席正装；同时采用立食自取餐点形式，避免因排定主次座次而产生礼节纷争。
- 原文依据："顺便说一下，出席的正装是魔法大学的制服。这是我决定的。毕竟来客之间贫富差距太大，要是在穿着上太过讲究，民族色彩会太明显。"
- 原文依据："会场是采立食形式。烦恼位子顺序到最后，索性把椅子都给撤走。"
- 内容：人族与兽族宴饮礼节的文化冲突
- 说明：兽族专注即时享用肉食猎物，对人族在宴会中途端酒四处寒暄打招呼的礼节感到不解，视其为“在吃饭中途跑来打扰、没有规矩的行为”。
- 原文依据："「人族的礼仪是在吃饭吃到一半时跑来打招呼吗喵？」「真是没有规矩的说。」"
- 内容：阿斯拉贵族对房事道具的新婚贺礼文化
- 说明：阿斯拉高级贵族在赠送新婚贺礼时，对于媚药及房中成人用具态度极为开明坦然，同行的年轻贵族随从亦习以为常。
- 原文依据："爱丽儿显得泰然自若。这种事很普通吗？路克和另外两人也表现得很冷静。文化差异啊……"

- 原文是否暗示另有真相：是（鲁迪乌斯此前是因患有ED性功能障碍而无法施展欲望，痊愈也是多亏了希露菲，并非单纯偏好娇小）。
- 原文依据："「老大喜欢娇小型的说。」「都散发出那么强烈的性欲气味却始终没有袭击我们，原来是喜好的问题喵。」"
- 角色以为：札诺巴一直以为菲兹（希露菲）是男性。
- 原文是否暗示另有真相：是（希露菲客观上一直是女扮男装的女性，鲁迪乌斯此前也同样长期误认）。
- 原文依据："「夫人。老实说，我一直以为您是男人。居然会把师傅的伴侣误认为男性……还请原谅我的无礼。」"
- 角色以为：七星对希露菲宣称自己之前只是因为鲁迪乌斯懂特殊语言而误以为是同乡。
- 原文是否暗示另有真相：是（七星和鲁迪乌斯皆来自现代日本异世界，七星是出于避免多生事端而故意向希露菲掩盖转生/召唤真相）。
