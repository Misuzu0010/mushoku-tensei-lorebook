# 第七话　「转折点三」 世界设定提取

## 一、地理与场所
- 名称：贝卡利特大陆
- 内容：塞妮丝受困之地。从魔法都市夏利亚（北方）前往贝卡利特大陆，单程常规赶路至少耗时一年（走过一次东部港路线可能缩短至半年左右），往返耗时极长。
- 原文依据："前往贝卡利特大陆，然后再回来……这段期间内，你要让自己的妻子一个人面对吗？""无论途中如何赶路，前往贝卡利特大陆至少也要花上一年。从这边到东部港的路程已经走过一次，或许能再缩短一些时间。可是，就算半年能够赶到，来回还是要耗时一年。"

- 名称：迷宫都市拉庞
- 内容：位于贝卡利特大陆的城市，塞妮丝受困并在该处发生棘手事态，保罗与基斯等人展开救援的地点。
- 原文依据："没有其他人能够闯越贝卡利特大陆，前往迷宫都市拉庞，然后解决在那里发生的问题。"

- 名称：东部港
- 内容：连接北方大陆与魔大陆/贝卡利特大陆交通的关键港口枢纽。
- 原文依据："从这边到东部港的路程已经走过一次，或许能再缩短一些时间。"

- 名称：纯白房间
- 内容：人神与鲁迪乌斯在梦境中会面的超自然精神空间。鲁迪乌斯在此处会恢复为前世肥胖且自卑的原本模样，人神全身带有马赛克。
- 原文依据："等我回神时，已经待在一间纯白的房间里。外型恢复成肥胖又自卑的模样，同时精神也烦躁起来。我不爽地看着前方。那家伙就在眼前，藏在马赛克后方笑个不停的人神。"

## 二、组织与势力
- 名称：爱丽儿阵营（王族派系侍从规章）
- 内容：王族护卫怀孕时，主君会下达长期休假命令（希露菲获批至少休假两年并申请休学），期间可由其他人员（如艾莉娜丽洁）自愿顶替担任护卫职责。
- 原文依据："另外爱丽儿大人下达夫人最少要休假两年的命令，还有要记得先向学校申请休学。另外，亲家奶奶艾莉娜丽洁大人自愿在这段期间内负起责任，担任爱丽儿大人的护卫。"

## 三、力量体系 / 魔法 / 技能
- 名称：人神的因果预知与神谕
- 规则：人神能够预见未来的因果倾向。他声称鲁迪乌斯前往贝卡利特大陆会后悔，留在北方同样会错过后悔；并给出让鲁迪等待下一次发情期与莉妮亚或普露塞娜发生关系以获得“幸福”的建议。
- 原文依据："你去了贝卡利特大陆就会后悔，这点到现在还是没变。""我没有骗你。实际上我现在还是要说同样的话，不要去贝卡利特大陆比较好，否则你会后悔。""一旦前往贝卡利特大陆，你会错过巨大的机运。所以，还是不要去比较好。""鲁迪乌斯，你要等待下一次的发情期。到了那时，莉妮亚和普露塞娜应该会来诱惑你，你要和她们其中之一发生关系。那样一来，你就会变得更加幸福吧。"

## 四、种族 / 生物
- 名称：长耳族（精灵族生理特征）
- 特征：长耳族及其混血后裔的体质受孕几率极低，属于不容易怀孕的种族。
- 原文依据："不过之前有听说过长耳族不容易怀孕，所以我只是因为出乎意料地快，现在有点困惑而已。""因为我觉得这样一来，自己好像终于可以真正成为鲁迪的妻子。……因为她的体质不容易怀孕。"

- 名称：兽族（发情期生理机制）
- 特征：兽族具有周期性的发情期，在发情期间女性兽族受生理本能驱使会主动诱惑男性发生关系。
- 原文依据："鲁迪乌斯，你要等待下一次的发情期。到了那时，莉妮亚和普露塞娜应该会来诱惑你，你要和她们其中之一发生关系。"

## 五、物品 / 道具 / 武器
- 名称：紧急快捷信件
- 说明：跨大陆远距离紧急邮政系统。特征是内容字数极其精简扼要，但即便使用快捷，从贝卡利特大陆寄达北方依然需要半年时间。
- 原文依据："然而两个月后，我收到噩耗。使用紧急快捷送来的那封信上的寄件日期是半年前，寄信人是基斯。内容符合快捷的特色，只有极为简短的文字。「塞妮丝难以救出，请求支援」。"

## 六、历史 / 传说 / 事件
- 事件名：转折点三（塞妮丝救援危机与决意）
- 内容：希露菲怀孕两个月后，鲁迪乌斯收到半年前基斯寄来的紧急求援信「塞妮丝难以救出，请求支援」。人神在梦中警告鲁迪千万不要前往贝卡利特大陆，否则必会后悔。面对家庭责任与亲人危机的两难，加上艾莉娜丽洁决意牺牲与克里夫的恋情前往救援、诺伦甚至收拾行囊试图孤身前往，鲁迪乌斯最终下定决心前往贝卡利特大陆迷宫都市拉庞拯救家人。
- 原文依据："第七话　「转折点三」""「塞妮丝难以救出，请求支援」。""「我……要前往贝卡利特大陆。」去那里救出我的家人……我如此下定决心。"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯教教义的婚姻观：米里斯教严格要求信徒对伴侣专一，不可出轨或背弃婚姻，克里夫作为虔诚且有前途的教徒若被伴侣单方面舍弃，可能会导致信仰产生严重动摇。
- 原文依据："米里斯教的教义要求信徒对伴侣专一。要是艾莉娜丽洁离开，克里夫的信仰心或许会动摇。"

- 内容：家庭与孕期礼俗：妻子怀孕初期需严禁夫妻性生活以保护胎儿。
- 原文依据："哥哥大人，顾虑到夫人的身体状况，请暂时严禁性行为。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯最初以为只要自己遵从人神的建议不去贝卡利特大陆、留在家里照顾怀孕的希露菲，就能避免人神所说的“后悔”。
- 原文是否暗示另有真相：是。
- 原文依据：人神直言“就算你不想后悔也躲不开”，无论如何选择都会后悔；随后诺伦因鲁迪的不作为而试图独自冒险启程救援父母，迫使鲁迪意识到若自己置身事外反而会酿成更大的家庭破灭与终身悔恨："「我才没有骗你。你去了贝卡利特大陆就会后悔，这点到现在还是没变。」……「意思是不管我怎么做，到头来都会后悔吗？」「没错，就算你不想后悔也躲不开。」""哥……哥哥你不去的话，我想自己去。……可是哥哥……爸爸和妈妈他们碰上困难了啊！为什么……哥哥你为什么不去救他们！"

- 角色以为：艾莉娜丽洁以为克里夫对自己只是一时年轻人的冲动与昏头，自己为了替孙女夫妇分忧而不告而别前往贝卡利特大陆，是对克里夫最好的解脱方式。
- 原文是否暗示另有真相：不明 / 鲁迪乌斯指出这可能摧毁克里夫的真心与宗教信仰。
- 原文依据："「克里夫是个纯真的孩子。他有才能，也很积极，具备将来或许能成为教皇的器量。对我的爱只不过是年轻人一时昏头……就当作是这么一回事才是最好的办法。」……米里斯教的教义要求信徒对伴侣专一。要是艾莉娜丽洁离开，克里夫的信仰心或许会动摇。"
