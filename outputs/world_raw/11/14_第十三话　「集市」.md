# 第十三话　「集市」 世界设定提取

## 一、地理与场所
- 名称：沙漠集市（Bazaar）
- 内容：位于巨大岩棚下方的补给集市。地表为缺乏养分、散落拳头大石头的红褐色大地（类似魔大陆地面），气温较沙漠大幅下降。整体布局呈甜甜圈状：中心为大湖泊，湖畔环绕一圈白色帐篷，外围有一圈绿色植物。集市无旅社客栈等设施，无帐篷的旅行者通常露宿；夜晚点燃篝火、早早熄灯入睡；白天人声鼎沸，进行货币买卖与以物易物。湖边地带最受帐篷露宿者欢迎。
- 原文依据："从高处往下看，集市就像是甜甜圈。在大湖泊旁边围了一圈的帐篷是糖粉，然后再往外一圈则围着若干绿色植物。"、"地面也不再是沙漠了，而是似乎很欠缺养分的红褐色大地，还散落着许多拳头大小的石头，或许和魔大陆的地面很类似。……气温也大幅下降，那个岩棚的两侧真是天差地别。"、"「旅社？哪来那种地方，自己随便找个喜欢的地方睡吧。」……这个集市没有旅社之类的设施，没带帐篷的旅行者基本上好像都是露宿。"、"听说湖边比较受欢迎。"

- 名称：前往迷宫都市拉庞的路线与周边地理
- 内容：
  1. 距离与位置：从集市往北走约需一个月路程。
  2. 路线一（绕行路线）：从恩寇兹绕过沙漠，但近期多盗贼出没，风险极高。
  3. 路线二（乌丘沙漠商道）：穿过乌丘沙漠。先依据东侧路标北上至绿洲，沿向西延伸的道路前进，看到卡拉山脉后向北走，保持左视卡拉山脉的轨迹到达下一个绿洲，由该绿洲东侧较狭窄的沙漠处向东横穿，再向西北行进即可并回主路。
  4. 金卡拉：位于集市东侧的大型城镇与商贸据点，集市中绝大多数商人均前往金卡拉，该地可雇到向导。
  5. 提诺里欧：位于集市西南方向的城镇，为行商采购魔石与魔力结晶的起点之一。
  6. 迷宫都市拉庞：周围分布无数迷宫，为魔力附加品的产地与魔石消耗地。
- 原文依据："据斯拉庞位于从这个集市往北走一个月左右的地方……「一般会走从恩寇兹那边绕过沙漠的路线，不过最近经常有盗贼出没所以很危险。如果是聪明的商人，会选择直接穿过乌丘沙漠。首先要根据东边的路标往北移动到绿洲，从那里顺着往西延伸的道路前进，看到卡拉山脉之后，必须往北移动并让自己持续走在朝左看就能看到山脉的路线上，这样就可以到达下一个绿洲。那个绿洲的东边是沙漠比较窄的部分，从那里往东穿过沙漠之后，接下来只要再往西北移动，就可以回到最初的路线了。」"、"一般的商人都是要前往位于东边的金卡拉。"、"据说这个商人是往来于拉庞和提诺里欧之间的行商……"、"拉庞不愧是迷宫都市，周围存在着无数的迷宫，也是魔力附加品的产地。"

- 名称：特产地（维嘉、纳尼亚、特寇兹）
- 内容：维嘉以生产高品质四角形厚质花纹玻璃瓶闻名；纳尼亚为特色布料产地；特寇兹为特色水果产地。
- 原文依据："「有没有人在卖纳尼亚的布！我要用特寇兹的水果来交换！」"、"「这是维嘉的玻璃瓶！不会再往东运送了！有没有人要在这边进货啊！」……摊位上摆满了刻有美丽花纹的四角形玻璃瓶，外形有点类似威士忌的酒瓶。其中甚至有一些是有色玻璃，表面也很光滑。"

## 二、组织与势力
- 名称：加尔邦商队
- 内容：由行商加尔邦率领的沙漠商队。加尔邦往来于提诺里欧与迷宫都市拉庞之间，靠从西南方买入魔石与魔力结晶运往拉庞、再将拉庞产出的魔力附加品高价运往其他城镇转售累积财富。商队拥有六只骆驼作为运输主力，配备护卫战士（如独眼资深战士巴里巴德姆、浅黑皮肤女战士卡尔梅丽塔等）。
- 原文依据："据说这个商人是往来于拉庞和提诺里欧之间的行商，还借此累积了一笔财富。他会把魔石运到拉庞，再从拉庞运出魔力附加品。拥有六只骆驼，收入似乎相当不错。"、"外面拴着六只骆驼。……就是那个女战士卡尔梅丽塔。……我叫巴里巴德姆……"

## 三、力量体系 / 魔法 / 技能
- 名称：风魔术冲击波
- 规则：风系魔术应用，以强力无形冲击波进行远程轰击，可破坏空中飞行魔物（如狮鹫兽）的平衡使其失速坠落。
- 原文依据："同时，我瞄准位于高处的狮鹫兽放出冲击波。命中目标……那只狮鹫兽还是掉着羽毛往下坠落。"

- 名称：斗神语（地域口音）
- 规则：贝卡利特大陆通用语言。各地域与个体间口音差异显著（如资深战士巴里巴德姆口音标准普通，而卡尔梅丽塔带有浓厚乡音）。
- 原文依据："由于对方用斗神语道谢，因此我也用斗神语回应。……我实在无法顺利听懂她的发言，是因为口音很重吗？……相比之下，男子的口音就很普通。"

## 四、种族 / 生物
- 名称：骆驼
- 特征：贝卡利特沙漠商队的主要负重与乘骑牲畜。遇魔物袭击时容易受惊四散逃逸，是商人视若性命的最核心资产。
- 原文依据："听说他们是去寻找逃跑的货物──也就是骆驼。把骆驼抓回来之后回到原地……"、"拥有六只骆驼，收入似乎相当不错。"

- 名称：普通蝙蝠
- 特征：栖息于红褐色大地周边的非魔物普通蝙蝠，傍晚成群盘旋，无攻击性，内部不含女性梦魔。
- 原文依据："蝙蝠在红褐色的大地上空飞来飞去。……没有攻击我们，中心也没有藏着女性梦魔，就只是普通的蝙蝠。"

- 名称：狮鹫兽（素材价值与威胁补充）
- 特征：会游荡到集市周边的红褐色大地袭击商队，嘴喙可直接咬穿人类头骨致死；其爪子为当地可售卖的素材（市价约三十新萨）。
- 原文依据："「这里有狮鹫兽的爪子！现在只要三十新萨！」"、"可能是脑袋被狮鹫兽的利嘴咬中，额头上开了一个大洞，肯定是立即死亡。"

## 五、物品 / 道具 / 武器
- 名称：新萨（Shinsa）
- 说明：贝卡利特大陆通用的货币单位。外形为圆形金属板，表面刻有简陋图案。中央大陆货币（如拉诺亚王国铜币）在当地无法流通。购买力参考：一顿含肉粥浓汤与南国水果的现成餐食为 3 新萨；狮鹫兽爪子约 30 新萨；集市至拉庞护卫酬劳约 600 新萨包伙食；全职专属熟练护卫年薪约 8,000 至 10,000 新萨。
- 原文依据："这附近的货币叫作「新萨」。来到这世界以后，这好像是我第一次听到货币的单位……只是在圆形的金属板上刻着拙劣的图案而已。"、"「是拉诺亚王国的铜币。」「那是哪里的国家啊？这种东西不能用啦。」"、"「现在只要三新萨就供餐！」"、"「到拉庞为止，六百新萨还另外包吃，这样如何？」"、"「还可以提高一点价钱，一年一万新萨……不，巴里巴德姆会抗议。八千新萨怎么样？」"

- 名称：沙漠曲剑与重装铠甲
- 说明：贝卡利特大陆本土战士的典型装备。身穿红色厚重铠甲，腰部围有类似裙子的厚实腰布；武器为长逾一公尺的大弧度宽厚曲剑，专门针对大型魔物劈砍设计，但面对高敏捷度的三维飞行魔物（如狮鹫兽）时机动较显笨拙。
- 原文依据："穿着红色的铠甲，下半身垂着一条很像裙子的厚重腰布。和中央大陆的平均装备相比，他们的装备更加厚实。挂在腰上的武器是弯曲幅度很大的曲剑，剑刃又宽又厚，长度远远超过一公尺。我在魔大陆也经常看到这种感觉的剑，大概是对大型魔物很有效吧。武器巨大，铠甲也很厚重……或许正是因为这样，面对狮鹫兽这种敏捷的对手才会处于劣势吧。"

- 名称：维嘉玻璃瓶
- 说明：产自维嘉的工艺玻璃制品。呈四角形刻花厚壁瓶身（类似威士忌酒瓶），包含有色玻璃，表面光滑、质地厚实，工艺与透明度显著高于中央大陆北部。
- 原文依据："摊位上摆满了刻有美丽花纹的四角形玻璃瓶，外形有点类似威士忌的酒瓶。其中甚至有一些是有色玻璃，表面也很光滑。中央大陆也有玻璃，但是没这么厚，而且表面粗糙，透明度也不高。"

- 名称：集市熟食（旱作米粥浓汤、微辣蒸肉与南国水果）
- 说明：集市售卖的平民熟食套餐。主食为类似马铃薯炖肉炖豆子的白色浓汤，实质是以当地旱作稻米煮烂熬成的黏稠米粥；搭配带辣味的蒸肉及淋上甜酱汁的酸味南国水果。
- 原文依据："首先是很像马铃薯炖肉加上豆子熬煮而成的黏稠白色浓汤，接着是看起来会辣的蒸肉，最后是吃起来似乎会酸，还被淋上甜甜酱汁的陌生南国水果。……乍看之下是白色的马铃薯炖肉，但那些黏稠的部分其实是煮烂的米饭。换句话说，这是一种粥。没想到可以在这种地方吃到米饭。这边不太可能有水田，大概是旱作吧……"

## 六、历史 / 传说 / 事件
- 事件名：加尔邦商队遇袭与鲁迪乌斯受聘
- 内容：加尔邦商队在集市外围遭遇五只狮鹫兽袭击，两名护卫阵亡，骆驼惊散逃走。鲁迪乌斯与艾莉娜丽洁出手斩杀狮鹫兽救下商队。商队找回骆驼后回到集市，以六百新萨包食宿聘请鲁迪乌斯二人担任前往拉庞的护卫。
- 原文依据："四个人类vs五只狮鹫兽。……剩下这三人正挥着宽刃剑并发挥出优秀的默契，不过还是能看出明显的疲态。"、"「这也是一种缘分，你们愿意做我的护卫吗？」……「到拉庞为止，六百新萨还另外包吃，这样如何？」……「好，我们愿意接受到拉庞的护卫工作。」"

## 七、社会规则 / 习俗 / 文化
- 内容：沙漠行商的价值优先级与救援潜规则：沙漠商队遭遇魔物袭击时，普遍遵循“见死不救”原则；在魔物被击退后，首要行动是全力找回逃逸的牲畜与货物（如骆驼），阵亡同伴遗体常被暂搁或甚至不收尸，利益与货物优先于人命与礼节。
- 原文依据："「愿风之恩惠与你同在。」男子只说了这句话就迅速转身离开……「一般来说会见死不救。」"、"「快点去找货物啊！」……「在这个大陆上，是不是有丢着尸体不管的文化啊？」……不过，或许他们的行动才是这地方的常识。最优先的东西是货物，其他一律晚点再说。"

- 内容：集市交易与借宿规则：集市不流通外部大陆货币，以新萨为主，并广泛接受金属首饰（如戒指）抵账及以物易物；中央大陆北部物品在当地可溢价数倍卖出；集市不设客栈，旅人大多就地露宿或在大型商队帐篷间择地扎营。
- 原文依据："「那是哪里的国家啊？这种东西不能用啦。」"、"艾莉娜丽洁已经把一个物品塞进拉客男子的手里。是金属戒指。……「这种时候直接拿东西出来抵帐就可以了。」"、"中央大陆北部的东西在这里可以卖到高价，例如便宜的肉乾居然卖了三倍的价钱……"、"「旅社？哪来那种地方，自己随便找个喜欢的地方睡吧。」"

- 内容：地图缺失与向导揽客生态：贝卡利特大陆缺乏测绘和出售纸质地图的文化；向导通常只在起点和大型交易据点（如金卡拉）揽客，中途补给集市无固定向导，旅人通常选择依托商队同行带路。
- 原文依据："「地图？谁会做那种东西？」"、"「是有那种知道路要怎么走的家伙，但是没有人会来这种中途补给的地方找客人啊。」「当然是啊，正常来说会在交易据点揽客吧？」"

- 内容：辨识女性梦魔的沙漠常识：沙漠战士间流传“傍晚见蝙蝠且出现单身女性即为女性梦魔”的防范经验，但女性梦魔绝不会与男性一同行动。
- 原文依据："「可是，大哥，你说过，有蝙蝠在飞，看到女人，就要认为是女性梦魔！」「蠢货！哪有带着男人的女性梦魔！受人帮助还讲这种鬼话！」"

## 九、角色认知 vs 客观事实
- 角色以为：卡尔梅丽塔因傍晚有蝙蝠飞舞而误认艾莉娜丽洁为女性梦魔。
- 原文是否暗示另有真相：否。蝙蝠为普通生物，艾莉娜丽洁为长耳族精灵；巴里巴德姆明确斥责“哪有带着男人的女性梦魔”。
- 原文依据："「大哥，这家伙，该不会，是女性梦魔？」「蠢货！哪有带着男人的女性梦魔！受人帮助还讲这种鬼话！」"、"没有攻击我们，中心也没有藏着女性梦魔，就只是普通的蝙蝠。"

- 角色以为：鲁迪乌斯和艾莉娜丽洁认为商队在被救后连谢礼都不给、把同伴尸体丢着不管，是薄情无义或有弃尸文化。
- 原文是否暗示另有真相：是。商队当时是为了争分夺秒追赶并找回受惊逃散的六只骆驼（核心财产）；找回骆驼返回原地后发现鲁迪等人已离开并将同伴尸体火化安葬，商队曾试图寻找恩人道谢。
- 原文依据："「在这个大陆上，是不是有丢着尸体不管的文化啊？」「实在是一些不配当冒险者的家伙。」"、"听说他们是去寻找逃跑的货物──也就是骆驼。把骆驼抓回来之后回到原地，才发现恩人已经离开，同伴的尸体也已经被火化埋葬，想要道谢却找不到我们……"
