# 外传　「诺伦和米里斯教团」 世界设定提取

## 一、地理与场所
- 名称：夏利亚米里斯教堂
- 内容：坐落于魔法都市夏利亚小巷内的米里斯教教堂。外观与米里斯神圣国普遍街区教堂相比略有差异，天花板较低，但同样以收敛的白色调为主，内部设有整齐排列的长椅、深处的圣堂、圣米里斯象征以及告解室。平时环境神圣、静谧而庄严，设有一位神父，在固定时段常外出；克里夫・格利摩尔从今年起在此担任神职实习生，在弥撒时协助神父，平时常在告解室读书并接引零星教徒。
- 原文依据："「米里斯教堂……原来这城市里也有啊。」……以白色为基调的内敛设计还是能让人一看就知道是教堂。……虽然这里的天花板比记忆中的教堂低，但是整齐排列的椅子和位于深处的圣堂都一样。沉浸在怀念感的诺伦走向米里斯教的象徵，跪下来握起双手。"、"「我是克里夫・格利摩尔，从今年起开始在这间教堂实习。」……在这间教堂举行弥撒时，经常看到他紧跟在神父身边帮忙的模样。……其实克里夫这个时段都会在告解室里念书，顺便等待偶尔会出现的零星教徒……"

- 名称：圣剑大道（历史地理渊源）
- 内容：传说中由圣米里斯挥下圣剑斩击魔王而开辟出的笔直巨型通道。起点自米里斯神圣国首都米里希昂，贯穿青龙山脉与大森林，跨越海洋直抵现今的温恩港，后被世人命名为“圣剑大道”。
- 原文依据："圣剑的威力非常惊人，从米里希昂开始，经过青龙山脉与大森林，接着甚至越过大海，直达现在已成为温恩港的地方，让魔王立刻死亡。而且圣剑沿途劈开的地方形成道路，最后被命名为「圣剑大道」。"

## 二、组织与势力
- 名称：米里斯教团（权力中枢与派系争斗）
- 内容：崇奉圣米里斯的庞大宗教势力，最高统领为教皇。教团内部存在错综复杂的权力斗争。克里夫・格利摩尔的祖父即为现任米里斯教皇；克里夫此前因年幼弱小缺乏抵御暴力的实力与权力，为避免在教廷内部政争中沦为对手绑架要挟教皇的人质，被秘密送往拉诺亚魔法大学留学以作避险。
- 原文依据："「我的祖父是米里斯教团的教皇。因为差点被一场规模不大的权力斗争波及，所以被送来拉诺亚这里留学。不用说，我当然无法回到米里斯。就算想要帮忙祖父，也没办法做到任何事情。……因为年幼、弱小，又没有权力的我，无法抵抗对手的暴力。万一遭到袭击，就会简单落入敌人手里，然后被当成人质利用。人们都说我的祖父大人是个能人，但是前途无量的我要是被抓去当人质，他也不得不听从对手的要求吧。」"

## 三、力量体系 / 魔法 / 技能
- 名称：圣剑劈山断海之威（传说神技）
- 规则：传说中圣米里斯运用圣剑所施展的究极剑击。其威力能够一次性劈开山脉、大森林并横跨海洋直击远方港口，将魔王斩成两半。
- 原文依据："「在邪恶魔王的大军逼近之时，正当之人挥下圣剑。圣剑劈开山脉，劈开森林，劈开大海，把邪恶魔王也斩成两半。」"、"圣剑的威力非常惊人，从米里希昂开始，经过青龙山脉与大森林，接着甚至越过大海，直达现在已成为温恩港的地方，让魔王立刻死亡。"

## 五、物品 / 道具 / 武器
- 名称：米里斯教圣书
- 说明：米里斯教的核心经典经卷。信徒日常诵读，包含《阿特摩斯书》等篇章。其中《阿特摩斯书》第十二章三十一节明确记载了圣米里斯在魔族大军压境时艰辛忍耐蓄积力量、最终挥舞圣剑斩杀魔王的典故教诲。
- 原文依据："克里夫说完，从怀里拿出米里斯教的圣书。他没有打开，直接背诵其中一章。「阿特摩斯书第十二章三十一节。正当之人在艰辛时刻必须忍耐，在痛苦时刻最能储备力量。当内心脆弱之人询问其因，正当之人答以解放力量之日终将到来。在邪恶魔王的大军逼近之时，正当之人挥下圣剑。圣剑劈开山脉，劈开森林，劈开大海，把邪恶魔王也斩成两半。」"

- 名称：圣剑（神话圣兵）
- 说明：圣米里斯在魔族战役中所持有的神圣佩剑，具劈山分海、斩杀魔王的破格破坏力。
- 原文依据："正当之人挥下圣剑。圣剑劈开山脉，劈开森林，劈开大海，把邪恶魔王也斩成两半。"

## 六、历史 / 传说 / 事件
- 事件名：圣米里斯挥剑斩魔与培特将军战死（圣剑大道战役）
- 内容：
  1. 圣典故事：面对逼近的魔族大军，圣米里斯挥下圣剑劈开山脉、森林与大海，斩断魔王身躯并开辟圣剑大道。
  2. 真实史实：圣米里斯并非万能，在挥出决定性圣剑前需在艰苦绝境中竭力蓄积力量；与此同时，圣米里斯的挚友兼米里斯军队总司令官培特・杜利欧尔率军在北方海岸线顽强死守阻挡魔族攻势，最终英勇捐躯。两人互相信任、各自尽人事履行职责，方迎来了最终的胜利与和平。
- 原文依据："「阿特摩斯书第十二章三十一节。……」「虽然这段故事会让人比较容易注意到圣米里斯的伟大，然而真正重要的部分，其实是圣米里斯虽然伟大却并非万能，所以为了挥动圣剑，他必须先储备力量。只要解读史书就能知道，当时，米里斯的军队正在北方海岸线抵御魔族的攻势。总司令官是被视为是圣米里斯挚友的培特・杜利欧尔。后来，培特在那场战役中捐躯。然而圣米里斯即使身处艰苦时刻，也继续把眼光放向未来。」「那种行为不是舍弃了朋友吗？」「不是。圣米里斯相信自己的朋友，而他的朋友也相信圣米里斯，所以没有败退，而是死守战场。所以，最后才能获得两人共同期望的胜利与和平。」"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯教教义核心与祈祷规范：
  1. 祈祷时机：真正的祈祷应当在“一天结束之时”进行，而非开始之时。其内涵在于：人必须先在白天克尽人事、忍耐困苦并储备自身力量（学识、魔术、人脉积累等），唯有在做完所有力所能及的事情后，向神祈祷守护才有意义。
  2. 拒绝贪婪：圣米里斯不回应任性妄为或充满私欲贪念的诉求。
  3. 教堂告解室制度：设有私密的告解室，供信徒在感到不安或遭遇蛮横苦难时向神职人员倾诉秘密与寻求开导。
  4. 圣书背诵习俗：米里斯神圣国的学校普遍将背诵圣书典故作为基础通识教育。
- 原文依据："圣米里斯不会帮助满心欲望的人，不可以耍任性。"、"米里斯学校的老师曾经说过，要大家在一天结束时祈祷。不是在一天开始时，而是在一天结束时。原来，那种行为有着这层意义。"、"「正因为如此，我们必须实做好自己能力所及的事情，然后储备力量。这也是米里斯教的教诲。」"、"「如果是难以启齿的事情，也可以使用那边的告解室。」"、"由于米里斯的学校曾多次要求学生背诵，因此诺伦也记得这部分。"

- 内容：拉诺亚魔法大学生活规制：校方设有每十天一次的“回家露脸日”，寄宿生可在该日离校返家探视亲友。
- 原文依据："今天诺伦这样做时，突然注意到窗外有学生正朝着校外走。「今天是该回家的日子……」今天是十天一次的「回家露脸日」。"

## 九、角色认知 vs 客观事实
- 角色以为：诺伦自责地认为自己每天放学跑去教堂祈祷只是懦弱无能的自我安慰与逃避，实际上对家人没有任何实质帮助。
- 原文是否暗示另有真相：是。克里夫以教廷实习生身份为诺伦阐明教规深意：祈祷并非推卸责任，而是米里斯教徒在艰辛时刻必须先咬牙忍耐、竭尽全力做好自己能做的事情（读书、练魔术、储备实力以备来日成为支柱），在一天结束时再祈求圣米里斯的庇佑，二者是相辅相成的。
- 原文依据："祈祷会让她觉得自己有做了什么，但实际上什么都没有做，也什么都做不到。……「正因为如此，我们必须实做好自己能力所及的事情，然后储备力量。这也是米里斯教的教诲。……你要为了这个愿望去做好自己能做到的事情。也就是要好好用功，学会魔术。……如果把自己能做到的事情都做完了，接下来该怎么办呢？……最后就祈祷吧，圣米里斯随时都在守护着我们。」"

- 角色以为：世人及普通学生在阅读圣书时，多将圣剑斩魔王的故事视作圣米里斯个人无敌神力的英雄颂歌；诺伦甚至下意识困惑是否是圣米里斯舍弃了友人培特。
- 原文是否暗示另有真相：是。克里夫依据正史解读指出，圣米里斯并非全能神，他挥动圣剑同样必须忍耐蓄积力量；而他的挚友培特司令官正是深知这一点，才甘愿在北方前线死守殉国，这代表的是双方在绝境中彼此绝对信任、共同承担战局的牺牲精神。
- 原文依据："「虽然这段故事会让人比较容易注意到圣米里斯的伟大，然而真正重要的部分，其实是圣米里斯虽然伟大却并非万能，所以为了挥动圣剑，他必须先储备力量。只要解读史书就能知道，当时，米里斯的军队正在北方海岸线抵御魔族的攻势。总司令官是被视为是圣米里斯挚友的培特・杜利欧尔。后来，培特在那场战役中捐躯。然而圣米里斯即使身处艰苦时刻，也继续把眼光放向未来。」「那种行为不是舍弃了朋友吗？」「不是。圣米里斯相信自己的朋友，而他的朋友也相信圣米里斯，所以没有败退，而是死守战场。」"

- 角色以为：外人普遍以为克里夫只是个性格乖僻傲慢的天才留学生。
- 原文是否暗示另有真相：是。克里夫实为米里斯教团现任教皇的亲孙子，因自身年纪幼小、缺乏足够实力与权势，为防在教廷政争中遭政敌绑架作为人质逼迫教皇，才被迫以留学名义避难至拉诺亚；其自满与勤勉背后，是迫切希望通过学习魔术、积累知识与结识未来权要人脉来壮大自己，以便将来回归米里斯辅佐祖父。
- 原文依据："「我的祖父是米里斯教团的教皇。因为差点被一场规模不大的权力斗争波及，所以被送来拉诺亚这里留学。不用说，我当然无法回到米里斯。就算想要帮忙祖父，也没办法做到任何事情。……前途无量的我要是被抓去当人质，他也不得不听从对手的要求吧。……换句话说，我为了不被当成人质，必须拥有能抵抗暴力的力量。……要好好学习累积知识，或是学会魔术……还有交朋友也是个好办法……要是哪一天自己突然被叫回米里斯，我可以使用在学校学会的魔术、技术、知识和人脉帮助祖父大人……」"
