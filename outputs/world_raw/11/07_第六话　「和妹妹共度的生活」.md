# 第六话　「和妹妹共度的生活」 世界设定提取

## 一、地理与场所
- 名称：巴比诺斯地区
- 内容：位于魔大陆上的地区，是斯佩路德族战士瑞杰路德的故乡，据说位于比耶寇亚地区附近。
- 原文依据："瑞杰路德先生说过他出身于巴比诺斯地区。哥哥有在魔大陆上旅行过吧？你知道巴比诺斯地区在哪里吗？""听说在比耶寇亚地区附近，不过我没有去过。"

- 名称：比耶寇亚地区
- 内容：魔大陆上的地理区域，与巴比诺斯地区相接或在其附近。
- 原文依据："听说在比耶寇亚地区附近，不过我没有去过。"

- 名称：魔法都市夏利亚周边自然与气候
- 内容：第二年夏季来临，当地气温凉爽轻快，并没有酷暑之感，且该国家境内没有蟑螂等擅自侵入民宅的黑色害虫。此外，夏利亚周边的土壤相当贫瘠，通常不适宜开展一般园艺种植。
- 原文依据："虽然这里并没有热到真的有夏天到来的感觉，人们的服装倒是变得更加轻薄。""而且这个国家也没有那种会擅自住进别人家里的黑色害虫。""这附近的土地相当贫瘠，我想大概不适合园艺。"

## 二、组织与势力
- 名称：魔术公会
- 内容：魔法世界的专业学术/商业机构，不仅收购各种魔法相关成果，也可以向其出售具有高价值的魔法阵版型/卷轴。如果报上七星（塞伦特・赛文斯塔）的名字，便不会遭到公会恶意压价坑骗。
- 原文依据："把那个版型拿去魔术公会的话，应该可以卖出相当高的价钱。""连魔术公会都不知道这个魔法阵""如果要卖给魔术公会，记得报上我的名字，那样就不会莫名遭到坑骗。"

## 三、力量体系 / 魔法 / 技能
- 名称：召唤术体系（魔兽召唤 vs 精灵召唤）
- 规则：
  1. 召唤术总体分为「魔兽召唤」与「精灵召唤」两大类。
  2. 魔兽召唤：通过魔法阵召唤具有高度智慧的魔物或物品，支付某种代价后驱动受召唤对象。能召唤从周边魔物到栖息于其他异世界的传说生物，亦可召唤死物/道具（如异世界宝特瓶）。魔兽较难控制，但能自主思考行动，便于灵活应用。
  3. 精灵召唤：本质是「使用魔力制造出被称为精灵的存在」，是用魔力进行创造的魔术，机制类似程序设计。精灵虽只能重复既定行动，但只要编写足够复杂的程序，就能表现得像人类一样行动。
  4. 召唤条件精度：目前的召唤术能附加一定程度的条件，但范围较为粗略且存在个体差异（如指定“猫”可能召唤出老虎或豹）。现阶段召唤无机物主要局限于由单一材质构成的物品。
- 原文依据："这个世界的召唤术，其实分为魔兽召唤和精灵召唤两种。""所谓的魔兽召唤，似乎是一种能叫出魔物的魔术。透过魔法阵来召唤高度智慧的魔物，支付某种代价后就可以驱使对方。……其实之前的宝特瓶就被分类于魔兽召唤，也就是这个魔术也能够召唤物品。""相较之下，精灵召唤的性质不同。精灵召唤是「使用魔力制造出」被称为精灵的存在，也就是用魔力创造的魔术。类似程式设计。……只要编写复杂的程序，精灵似乎可以像人类那样行动。""虽说无机物，但是现阶段基本上只能召唤出由单一材质构成的东西。"

- 名称：魔法阵的版型印制量产机制
- 规则：魔法阵不一定必须手工纯手绘。可以使用土魔术制作出如地瓜印章般的硬质版型，直接盖印即可批量印制量产出具备效力的魔法阵。
- 原文依据："我想，只要用你的土魔术做出类似地瓜印章那样的版型就可以量产。把那个版型拿去魔术公会的话，应该可以卖出相当高的价钱。""刻个版型来印啊……原来魔法阵可以不必手绘吗？"

- 名称：治愈魔术与解毒魔术等级
- 规则：鲁迪乌斯完全掌握了上级治愈魔术和中级解毒魔术，并预定选修上级解毒魔术。即便记忆力极强，掌握此类神圣魔术也耗费了相当长的时间。
- 原文依据："前几天，我完全学会了上级治愈魔术和中级解毒魔术。虽说我很擅长背诵，却还是花了相当长的时间。接下来该学什么呢？扣掉预定要选修的上级解毒后，没有其他特别想学的科目。"

- 名称：圣级攻击魔术特性
- 规则：火属性与风属性的圣级魔术大多属于大规模操纵天候的魔术，在日常冒险或战斗中极少有施展机会。
- 原文依据："乾脆把火和风都学到圣级好像也是个办法。不，基本上圣级大多是操纵天候的魔术，很少有机会用到。"

## 四、种族 / 生物
- 名称：斯佩路德族
- 特征：魔大陆的战士种族，曾参与拉普拉斯战役。因拉普拉斯的阴谋及战役后的历史恶名而长期遭受全世界的歧视与迫害。其武器三叉枪背后承载着沉重的悲剧经历。
- 原文依据："一本彻底揭露斯佩路德族过去的书籍。""我还记得瑞杰路德在拉普拉斯战役中战斗的情形，也知道他们在战役结束后受到迫害的历史。""瑞杰路德先生那把枪的故事……是个让人潸然泪下的故事呢。"

- 名称：赤龙
- 特征：龙族生物。札诺巴雕刻的模型额头上生有角，但鲁迪乌斯在现实中亲眼见过的真正赤龙额头上并无长角。
- 原文依据："这个模型和我实际见过的赤龙不同，额头上还长了角，不过很帅气所以别计较吧。"

- 名称：魔大陆魔物
- 特征：魔大陆上的魔物普遍极其巨大。
- 原文依据："那里的魔物都很巨大，文化也有相当大的差异"

## 五、物品 / 道具 / 武器
- 名称：抑制诅咒的魔道具（一号试作品）
- 说明：由克里夫在札诺巴与七星的协助下开发出的试作装备。外形粗硬、带有前方垂饰，类似相扑横纲的兜裆布或尿布。通过从外部注入魔力与穿戴者体内的魔力同调相互抵消，能将艾莉娜丽洁体内的诅咒发作期限延长数倍，但无法抑制其发情冲动。目前试作品存在外形不美观（克里夫目标缩小至内裤尺寸）以及耗魔量极大（连克里夫的魔力量都无法维持一小时以上）两大缺陷，需由魔力量庞大的鲁迪乌斯协助测试改良。
- 原文依据："他居然做出了能抑制诅咒症状的魔道具第一号试作品。……「这东西可以从外部送入魔力，和体内的魔力相互抵销。虽然还没达到完美抑制的水准，不过已经能够把期限往后延长数倍的时间。」……结果那东西很像是相扑横纲穿的，有前方垂饰的粗硬兜裆布，要是换个角度来看，甚至挺像尿布。……其实啊，这个魔道具必须消费的魔力实在太多了。……顺便再说一下，关于这个魔道具……似乎没有抑制发情的效果。"

- 名称：「灯之精灵」魔法阵卷轴
- 说明：画在B4大小纸张上的精致魔法阵。注入魔力后可召唤出持续发光并跟随术者的灯之精灵，听从简单照明指令，直至魔力耗尽消灭。该魔法阵是七星认识的召唤术权威所原创，魔术公会此前完全不知晓。
- 原文依据："那是一张B4大小的纸，上面画有精致的魔法阵。……「召唤『灯之精灵』的魔法阵。」所谓的灯之精灵，是一种能发出明亮光芒并跟在术者身后的精灵。能听从「照亮那边」之类的简单命令，经过一段时间后，会因为魔力枯竭而消灭。……连魔术公会都不知道这个魔法阵，是刚才提到的那个人的原创。"

- 名称：异世界宝特瓶
- 说明：七星召唤实验第一阶段从原本世界成功召唤出的无机物（单一聚酯材质，无瓶盖和标签），现插上花当作花瓶摆在研究室窗边。
- 原文依据："她在上次的实验中召唤出「宝特瓶」，那个宝特瓶现在被当成花瓶，放在研究室的窗边。""单一素材……那个宝特瓶确实没有瓶盖和标签。"

## 六、历史 / 传说 / 事件
- 事件名：魔神拉普拉斯的魔大陆声望
- 内容：在中央大陆被视为恶魔邪神的拉普拉斯，在魔大陆本地却被普遍视为英雄。因此公开撰写有关其事迹的书籍时若将其刻画得过分反派，会招致魔大陆读者的强烈反感。
- 原文依据："内容要劝善惩恶，然后把拉普拉斯写成坏人……不，拉普拉斯在魔大陆上好像被视为英雄。要是把他写得太坏，可能会引发读者的反感。"

## 七、社会规则 / 习俗 / 文化
- 内容：佣人/女仆的家训与职业规范：按莉莉雅对爱夏的严厉家教，女仆不允许按照自己的个人兴趣购买家具或装饰房间。
- 原文依据："妈妈说不行，还说女仆不可以按照自己的兴趣买家具……哥哥也认为不行吗？"

- 内容：主仆与骑士效忠誓言：金洁对札诺巴怀有毫无保留、近乎狂热的绝对忠诚，源于札诺巴的亲生母亲临终前亲自将札诺巴托付给她，她以此立誓毕生倾力侍奉，即便札诺巴被流放或境遇悲惨亦毫不动摇。
- 原文依据："「札诺巴大人的母亲曾经亲自把札诺巴大人托付给我，所以我当时发誓，必定要殚心竭力侍奉札诺巴大人。」「哦，真是一段美谈……然后呢？」「没有然后了。」"

- 内容：魔法阵产权与商业交易：原创魔法阵具有极高商业价值，经由权威推荐后可以在魔术公会以高价转让专利或流通。
- 原文依据："把那个版型拿去魔术公会的话，应该可以卖出相当高的价钱。……如果要卖给魔术公会，记得报上我的名字，那样就不会莫名遭到坑骗。"

## 九、角色认知 vs 客观事实
- 角色以为：世人普遍认为精灵是真实存在于“无的世界”，再通过精灵召唤魔术将其从该世界跨界召唤出来。
- 原文是否暗示另有真相：是。
- 原文依据：七星指出世人的常识是错误的，精灵并非来自异次元，而是魔术师「使用魔力制造出的存在」，本质是用魔力编写程序的人工造物："因为这世界一般认为精灵存在于无的世界，然后被魔术召唤出来。也就是说，精灵召唤被视为和魔兽召唤相同。……相较之下，精灵召唤的性质不同。精灵召唤是「使用魔力制造出」被称为精灵的存在，也就是用魔力创造的魔术。类似程式设计。"

- 角色以为：札诺巴认为赤龙额头上长有威武的长角，并将其雕刻在模型上。
- 原文是否暗示另有真相：是。
- 原文依据：鲁迪乌斯在现实中亲眼观察过的赤龙额头上其实并无长角，模型带角只是札诺巴的主观艺术加工："这个模型和我实际见过的赤龙不同，额头上还长了角，不过很帅气所以别计较吧。"
