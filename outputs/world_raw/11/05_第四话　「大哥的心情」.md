# 第四话　「大哥的心情」 世界设定提取

## 一、地理与场所
- 名称：魔法大学女生宿舍
- 内容：宿舍房间格局基本相同，配有双层床铺、桌子椅子以及衣柜。宿舍一楼盘踞着“女生宿舍守望相助队”，严禁男性擅自进入。鲁迪乌斯虽然已获准通行宿舍门前道路，但依然禁止进入宿舍内部。
- 原文依据："基本上宿舍的房间都是相同的格局，有双层床铺、桌子椅子，还有衣柜。""虽说我已经获准使用宿舍前面那条路，恐怕还是不会允许我进去。""让盘据在女生宿舍一楼的守望相助队成员都积极参加。"

- 名称：魔法大学一年级教室
- 内容：一年级班级日常会进行班会。班级内学生年龄跨度大，既有十岁左右的幼童，也有十七八岁的年长学生。
- 原文依据："我们到达诺伦就读的一年级教室。里面看起来已经在进行班会。""教室里也有看起来和诺伦同年的学生。但是大部分比较年长，有几个人看起来已经十七八岁。"

## 二、组织与势力
- 名称：女生宿舍守望相助队
- 内容：盘踞在女生宿舍一楼的自治/警卫组织，主要由女生宿舍成员组成（辛馨亚蒂为主要成员之一），负责看护宿舍进出秩序、严防男生闯入。
- 原文依据："想必辛馨亚蒂和女生宿舍守望相助队的诸位成员不可能体谅我的苦衷，结果还是要偷偷潜入。""爱丽儿似乎事先用了什么办法，让盘据在女生宿舍一楼的守望相助队成员都积极参加。"

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术「土枪」
- 规则：土系统初级或中级魔术。除了用于攻击外，还可以通过在脚下生成土枪抬升自身高度（如用于翻窗潜入），并且可以主动解除土枪使地面恢复平整。
- 原文依据："我使用土魔术「土枪」举高自己的身体，俐落地从窗口入侵。同时解除土枪，让地面恢复平整。"

- 名称：无咏唱日常造水/造器
- 规则：能够凭借魔术凭空塑形做出杯子并注满水饮用。
- 原文依据："我用魔术做出一个杯子，装水喝了下去。虽然没有任何味道，还是让自己缓了一口气。"

- 名称：剑王
- 规则：剑术体系的高阶位阶之一。基列奴原本性格粗暴且什么都做不好，但在接触剑术后最终达到了剑王的境界。
- 原文依据："基列奴姑姑本来是个什么都做不好的粗暴人物，但是她接触剑术之后，最后成了剑王喵。"

## 四、种族 / 生物
- 名称：狸系兽族
- 特征：兽族的分支之一，具有短发、圆圆的体型，外表给人迟钝内向的印象。
- 原文依据："因为那是个显得很内向的女孩，年龄大约十三岁，是狸系的兽族。她留着一头短发，有着圆圆的体型，看起来似乎很迟钝。"

- 名称：猫系兽族（猫眼与生理气味）
- 特征：猫系兽族（如莉妮亚）的眼睛具备夜行性猫科特征，在黑暗中会闪闪发光。兽族少女的居住空间会有较浓的动物骚味。莉妮亚与普露塞娜是因为头脑太笨且不具备统率种族的资质，才被部族送进学校学习以期达到担任族长的水准。
- 原文依据："接应我的人是莉妮亚。她的眼睛在黑暗中闪闪发光，果然是猫眼。""一进到室内，一股很浓的动物骚味扑鼻而来。""这两个家伙正是因为太笨又不是率领种族的料，才会被送进这间学校，要她们好好用功以达到够格担任族长的水准吧。"

## 五、物品 / 道具 / 武器
- 名称：宿舍洗衣推车
- 说明：女生宿舍用来集中运送待洗衣物的推车，推车内部和下方空间足够塞入毯子、衬衫、床单并藏匿一个体型正常的人潜入。
- 原文依据："这是用来运送待洗衣物的推车，我钻进放在推车上的床单里。……大概是为了让我能把身体完全藏住，连推车下方也塞了毯子和衬衫之类……"

## 六、历史 / 传说 / 事件
- 事件名：一年级内裤事件（后续调解）
- 内容：莉妮亚和普露塞娜此前去与一年级新生“交换内裤”，被旁人误认为是敲诈勒索现场并向爱丽儿举报。在爱丽儿的斡旋善后下，该事件被定性为一场闹剧解决，一年级新生并未受到严重精神创伤。
- 原文依据："最后一根稻草，是那个内裤事件。一年级的学生中并没有人因此受到严重的精神创伤，多亏爱丽儿帮忙善后，这件事基本上被当成一场闹剧。虽然我听说是莉妮亚和普露塞娜去强脱一年级学生的内裤，实际上似乎不是那么凄惨的场面，而是一种和莉妮亚交换内裤的逗趣光景。只是看在旁人眼里却以为是敲诈现场，所以跑去向爱丽儿报案。"

- 事件名：基列奴的成长过往
- 内容：基列奴以前在部族中原本是个什么都做不好的粗暴人物，后来通过学习剑术展现才能，最终晋升为剑王。
- 原文依据："基列奴姑姑本来是个什么都做不好的粗暴人物，但是她接触剑术之后，最后成了剑王喵。"

## 七、社会规则 / 习俗 / 文化
- 内容：魔法大学一年级学生的年龄构成并不一致，不局限于十岁左右的儿童，还有很多十七八岁的年长青年同班就读。
- 原文依据："教室里也有看起来和诺伦同年的学生。但是大部分比较年长，有几个人看起来已经十七八岁。"

- 内容：魔法大学学年中存在“一号生笔头”这种代表性/首席优秀学生的制度或称呼。
- 原文依据："是说，那个学生应该是以前被介绍给我的一号生笔头吧？"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯先入为主地认定诺伦闭门不出是因为在一年级教室遭遇了不良学生的欺凌霸凌或教师的体罚虐待。
- 原文是否暗示另有真相：是。
- 原文依据：女学生和教师的说明证实并无霸凌，师生们并未怀有恶意，但诺伦总是被大家拿来和天才且出名的哥哥鲁迪乌斯比较、被要求向哥哥看齐，导致自尊心受挫、压力过大而闭门不出："结果是我的错。听说诺伦只有在被拿来和我比较，或是听到别人举我为例子时才会表现出情绪。……至少他们的比较行为并没有恶意。"

- 角色以为：学校其他人一度以为莉妮亚和普露塞娜在暴力强脱一年级新生的内裤敲诈勒索。
- 原文是否暗示另有真相：是。
- 原文依据：实际情况并非凄惨的敲诈现场，而是莉妮亚和新生“交换内裤”的逗趣闹剧："虽然我听说是莉妮亚和普露塞娜去强脱一年级学生的内裤，实际上似乎不是那么凄惨的场面，而是一种和莉妮亚交换内裤的逗趣光景。只是看在旁人眼里却以为是敲诈现场，所以跑去向爱丽儿报案。"
