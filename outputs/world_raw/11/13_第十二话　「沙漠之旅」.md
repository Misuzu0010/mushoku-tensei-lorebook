# 第十二话　「沙漠之旅」 世界设定提取

## 一、地理与场所
- 名称：固定沙尘暴带（疑似自然结界） [存疑]
- 内容：位于沙漠途中的特定地带，常年在一面墙壁般的固定地点刮起且不会消散。被魔术驱散突破后约一小时又会在同一地点重新刮起。通过该沙尘暴带后，沙漠生态系统明显改变（魔物数量锐减、种类不同）。鲁迪乌斯推测其可能是通往奥尔斯帝德遗迹道路上的魔力型自然结界。
- 原文依据："看起来这片沙尘暴一直在固定地点刮起，似乎不会消散。……继续前进一小时后，我不经意地回头一看，只见同样地点又刮起沙尘暴。说不定那也是一种魔力型结界。这条路会通往奥尔斯帝德经常使用的遗迹，所以沙尘暴是为了把路堵住的自然结界之类。"、"通过沙尘暴后，这里的生态系统和之前完全不同。蝎子只有一条尾巴，也没碰到整群行军的蚂蚁。沙虫的尺寸缩小到和艾莉娜丽洁的躯干差不多粗，晚上也不会有蝙蝠飞来飞去。在傍晚过后的时段还是有看到迅猛龙，但是族群的数量很少，体型也不大。金翅鸟更是连个影子都没见到。夜里也不再遭到女性梦魔袭击。"

- 名称：巨大岩层（岩棚）
- 内容：位于沙漠中的巨大岩层地形，高度约五十公尺，类似于艾尔斯岩，延续到地平线另一端看不到边际。上方虽有沙子，但地表由坚硬岩石构成，到处有巨大石块阻挡视线，性质类似山地，是魔物狮鹫兽的巢穴。北侧尽头为悬崖，下方为分布少量树木的热带稀树草原与湖泊。
- 原文依据："原来是一片让人联想到艾尔斯岩的巨大岩层，高度差不多有五十公尺。我脑中浮出「岩棚」这个名词。……这样的巨大岩层一直延续到地平线的另一头，看不到边际。"、"岩棚上可以看到一些沙子，不过地面确实是由岩石组成。"、"这片岩棚很大。我把这里称为岩石，实际上可能更类似山地。虽然没有高低落差，但是视野并不良好，因为到处都有巨大的石块挡路。……走了一段时间后，岩棚突然结束。……可以看到悬崖下方不是沙漠。尽管数量不多，还是有一些树木存在。是一片类似热带草原，只是草比较少的土地。然后在远处，可以隐隐约约看到某个景象。一片广阔的湖泊，以及湖泊周围用白布搭成的屋顶。集市到了。"

- 名称：贝西摩斯的坟场 [存疑]
- 内容：坊间传闻中存在的场所。因从未有人发现过贝西摩斯的尸体，故传说存在一处贝西摩斯坟场，满地都是大量的贝西摩斯骸骨和大量魔石。
- 原文依据："此外，明明贝西摩斯的身体那么巨大，尸体却不曾被发现。所以传闻中，某处存在着贝西摩斯的坟场，那里满地都是大量的贝西摩斯骨骸以及大量的魔石。"

## 三、力量体系 / 魔法 / 技能
- 名称：风裂
- 规则：中级风魔术，能产生风刃将目标身体切碎、四分五裂。
- 原文依据："那时心里虽然有点焦急，还是立刻使用中级风魔术「风裂」把那家伙的身体四分五裂。"

- 名称：中级解毒魔术
- 规则：解毒类水魔术，可治愈双尾死蝎等强毒魔物的毒素。
- 原文依据："看到艾莉娜丽洁屈膝倒下还满脸发紫，我立即打倒双尾死蝎，使用中级解毒魔术治好艾莉娜丽洁。"

- 名称：土刺猬
- 规则：上级土魔术，以施法者为中心，在周围地面呈放射状布满突起的尖锐土石尖刺，尖刺长度可由施术者自主设定控制（如三公尺）。
- 原文依据："上级土魔术「土刺猬」，尖刺的长度设定为三公尺，以放射状布满我的周围。"

## 四、种族 / 生物
- 名称：贝西摩斯
- 特征：栖息于贝卡利特大陆沙漠的著名巨大魔物。体长在一百公尺到一千公尺不等，外形似蓝鲸长有多条象腿，行走时掀起滚滚沙尘。性格极其温驯平稳，不主动受击则不攻击。没有特殊攻击手段，但庞大身躯暴走极具威胁。外皮极其强韧坚硬，普通攻击无法撼动；劣势时会潜入地底深处遁逃，几乎无人能成功击杀。传言其体内藏有大量魔石。迄今从未发现过其尸体。
- 原文依据："贝西摩斯似乎是栖息于贝卡利特大陆上的着名生物，体长从一百公尺到一千公尺不等。发现地点是沙漠，但不知道它以什么为食。以魔物来说，贝西摩斯的性格算是特别平稳，只要没受到攻击，通常都表现得很温驯。据说过去曾有人打倒过贝西摩斯，根据那段轶闻，贝西摩斯的肚子里藏有大量的魔石。……它的外皮极为强硬坚韧，普通攻击甚至无法撼动那巨大身躯分毫。尽管没有攻击手段，却只要以庞大身躯做出狂暴行动就能造成充分威胁。这下可能会有人认为换成远距离攻击不就行了，然而贝西摩斯一旦处于劣势，就会潜入地底深处逃走。因此，听说几乎没有人成功解决过它。此外，明明贝西摩斯的身体那么巨大，尸体却不曾被发现。"

- 名称：狮鹫兽
- 特征：栖息于岩棚地带的砂色魔物，长有鹫头、狮子四肢和巨大翅膀。为B级魔物，不会使用魔术，但肉体能力极为强悍，敏捷且具备优秀的三维立体飞行机动能力。拥有高度智能，通常单独行动；繁殖育幼时会结成2至5只的族群，群聚狩猎时展现高水平战术配合，族群状态等同于A级。同族间地盘意识极强，彼此间隔约一天路程不会互相侵犯，其领地范围内通常不见其他魔物（如女性梦魔不敢涉足）。幼兽肉质多汁柔软但有特殊异味。
- 原文依据："原来是一只拥有鹫头和狮子四肢的砂色魔物，那家伙拍打着巨大的翅膀……狮鹫兽是B级的魔物，并不会使用魔术。然而拥有极为强大的身体能力，以及还不错的飞行能力。由于行动范围能遍及三维空间又相当迅速，对于魔术师来说应该是强敌吧。经常单独行动，不过也会因为找到伴侣生下后代而形成二到五只的族群。拥有高度智能，族群在狩猎时还会发挥高水准的合作，因此形成族群的狮鹫兽被认为等同于A级。……狮鹫兽就算是对同族也保有很强烈的地盘意识。如果是一天路程左右的距离，其他狮鹫兽似乎也不会从远方跑来袭击。……小狮鹫兽的肉既柔软又多汁。虽然有种特别的味道，不过被调味料的辣味盖掉了。"

- 名称：双尾死蝎（毒性补充）
- 特征：尾部毒针带有烈性毒素，中毒者会迅速脸色发紫倒地陷入濒死，需中级解毒魔术方可化解。
- 原文依据："等我用土魔术回到地面后，艾莉娜丽洁已经中了双尾死蝎的毒。……看到艾莉娜丽洁屈膝倒下还满脸发紫，我立即打倒双尾死蝎，使用中级解毒魔术治好艾莉娜丽洁。"

## 五、物品 / 道具 / 武器
- 名称：冒险者复合辛香调味料
- 说明：流传于冒险者（尤其是盗贼型成员）中的实用配方。以 1：2：2 的比例混合柯库利的果实、阿瓦兹的种子和干燥的艾比叶研磨成粉。具有强烈的刺激性辣味，可用于调理魔物肉掩盖异味，亦可利用其刺鼻气味驱赶蚊虫、抵御讨厌该气味的魔物，紧急时还可作为致盲粉抛掷攻击敌人眼睛。
- 原文依据："以1：2：2的比例混合柯库利的果实、阿瓦兹的种子和乾燥的艾比叶，然后磨成粉状。把沾在手指上的粉末舔掉后，可以感觉到刺激的辣味。……「好怀念啊，基斯身上也总是藏着这种调味料。」「盗贼型的人通常都会带着这种东西呢。」……每支队伍里必定会有一个能做出这种调味料的家伙。尤其以盗贼型居多。他们每次出去，总是会顺便采集路边树木的果实和叶子并储存起来。这些东西并非只能用在料理上，也有一些魔物讨厌这种香气和味道特别强烈的香草和果实。所以可以在紧急时刻丢出去，或是用来驱除蚊虫。还有些家伙会制成粉状再拿来攻击敌人眼睛。"

- 名称：抑制诅咒魔道具（试作品补充）
- 说明：由克里夫制作、需鲁迪乌斯持续注入魔力的护符型试作品。其机能仅能将艾莉娜丽洁诅咒发作的时限向后延缓，无法完全根除；在未与男性交媾约十天后，诅咒对艾莉娜丽洁行为与欲望的影响开始浮现。
- 原文依据："或许是诅咒造成的影响开始浮现。对于那个魔道具，我有持续注入魔力。然而，据说那只能把期限延后。艾莉娜丽洁最后和克里夫做过之后，已经过了大约十天。我本来以为靠魔道具还能再撑一段时间，不过那充其量只是试作品，不能掉以轻心。"

## 六、历史 / 传说 / 事件
- 事件名：黑狼之牙旧日轶事与解散秘闻
- 内容：十六岁左右的塞妮丝初遇保罗并被搭讪带回队伍加入「黑狼之牙」；当时的基列奴对人类羞耻观念不了解，甚至不知胸罩为何物，队伍露营睡觉时常全裸或仅着内衣；后来因塞妮丝怀孕队伍解散；保罗曾对艾莉娜丽洁做出过严重的感情纠纷行为，使艾莉娜丽洁坚决表示绝不原谅他。
- 原文依据："「对了，我第一次见到塞妮丝时，她正好差不多是你这年纪……」「十六岁左右？」「嗯，还是个分不清上下左右的小丫头。保罗去找她搭讪，然后就把人带回来了。」……「不过你要知道，当时大家晚上睡觉时通常都脱光光或是只穿贴身衣物喔。基列奴甚至不知道胸罩这种东西的存在。讲到保罗看她的那种猥亵眼神，真的是……」……「父亲他好像有事情想跟艾莉娜丽洁小姐你道歉，我可以请教是发生过什么吗？」「…………你还是不要知道比较好。」「你应该也不想知道自己父亲的感情纠纷吧？」……「…………不管他说什么，我都不会原谅他。」"
