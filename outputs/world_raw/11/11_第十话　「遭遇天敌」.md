# 第十话　「遭遇天敌」 世界设定提取

## 一、地理与场所
- 名称：贝卡利特大陆转移遗迹（B3站点遗迹）
- 内容：位于贝卡利特大陆荒漠中的古代地下遗迹。内部布局与夏利亚流明森林遗迹基本相同（地上单层四室石造建筑，地下设大型转移魔法阵）。但该处未见藤蔓攀爬，通道与地面堆积厚沙，整体石质偏黄褐色。一楼存有奥尔斯帝德遗留的白色厚斗篷与水筒。
- 原文依据："周围和刚刚一样是石造的遗迹，看不出来有什么差异。不，角落里积了一些沙子，墙壁上也没有攀附着藤蔓。整体看起来似乎比较偏向褐色，是不同的场所。"、"一楼也是和森林遗迹很相似的石造建筑。要说哪里不同，大概只有墙壁和天花板上没有藤蔓攀附，还有通道里堆积着沙土吧。……这里也有四个房间，我想遗迹都采用了相同的设计。其中一间房间里保管着白色厚斗篷和水筒……这些果然是奥尔斯帝德的私人物品吧。"

- 名称：贝卡利特大陆沙漠环境与气候
- 内容：遗迹外是一整片连绵沙丘。日间极端酷热，热风刮面，湿度极低；日落后气温急剧暴跌，夜晚极度严寒（昼夜温差悬殊）。大部分沙漠魔物属于夜行性。
- 原文依据："到达一楼的那瞬间，可以感觉到气温一口气上升。蒸腾的热气迎面而来。不过或许是因为湿度很低，并没有黏腻的感觉。听说遗迹周围是一整片沙漠，难怪会热成这样。"、"眼前是一整片自己生前曾在照片里看过很多次的沙丘风景，真的来到沙漠了。"、"夜晚极度寒冷。听说沙漠的昼夜温差非常夸张，真的是那样没错。"、"我记得沙漠里的魔物有很多都是夜行性。要是在黑暗中移动却遭到魔物奇袭，想必会成为危险的状况。"

## 三、力量体系 / 魔法 / 技能
- 名称：转移魔法阵的运作与时空落差机制
- 规则：使用者踩入魔法阵后身躯如被地面吸入般消失，传送至另一端时则如倒带般自地面浮现；走出魔法阵后魔法阵重新充盈蓝白色光芒自发活化，无需外置魔力结晶。传送过程并非绝对无延时的瞬间跃迁，而是存在单程数分钟的时间滞后（艾莉娜丽洁往返测试中，外部观测耗时约十五分钟，本人体感立刻回头）。
- 原文依据："我们走出范围之后，魔法阵似乎再度活化，开始发出蓝白色的光芒。真是方便。明明看起来并没有设置魔力结晶，到底是怎么做到的？"、"艾莉娜丽洁跳进魔法阵，下一瞬间就消失无踪，而且看起来很像是被魔法阵吸了进去。"、"大约十五分钟后，艾莉娜丽洁回来了。出现时很像是在倒转播放消失的过程，可以看到她的身子从地面往上冒了出来。……「不过时间似乎有点久。」「是吗？我觉得自己有马上回头啊。」会出现时间落差吗？话虽如此，顶多也就是几分钟吧，大约是单程七分钟的程度。"

- 名称：土魔法「土堡」
- 规则：利用土系统魔术构筑的临时庇护所。常规状态下如果施术者停止供给魔力便会自然崩解；但只要施术者施加一定加工塑造结构，便可维持类似稳定雪洞的建筑状态，供野外生火露宿。
- 原文依据："只是土魔法「土堡」虽然方便，一旦停止供给魔力就会崩塌。不过只要稍微加工，还是有办法维持类似雪洞的状态，我们可以待在里面生火取暖。"

- 名称：中级解毒魔术（净化魅惑毒素）
- 规则：女性梦魔所散发的气味诱导效果在魔法体系中判定为毒素侵害。施术者对自己施展中级解毒魔术，可即刻净化该气味导致的剧烈催情与意识蒙蔽，使理智迅速复原。
- 原文依据："「鲁迪乌斯，我会数到十秒，这段时间内你要对自己使用解毒魔术。」……我完全不掩饰自己粗重的呼吸，开始咏唱解毒魔术。从初级开始，接着依次咏唱中级的咒语后，突然感觉身体变轻了。……接着，连脑袋也恢复清醒。虽然下半身有点沉重，但是那种无法克制的欲火已经消失。"

## 四、种族 / 生物
- 名称：女性梦魔（Succubus）
- 特征：栖息于贝卡利特大陆沙漠等地的恶魔类魔物。
  1. 拟态与攻击形态：平时具备拟态能力，能伪装成衣着单薄、身材极具诱惑力的人类女子（舞娘装扮）；露出本性及攻击时，指甲暴长变硬，骨骼突变，背后展开巨大蝙蝠翼飞空；真实外形为皮肤呈蓝色、五官类似蝙蝠、面部奇异狰狞。
  2. 气味与魅惑能力：散发强烈的特异气味，该气味在男性嗅觉中为浓郁甘甜、激发极强性冲动与意识蒙蔽的香气，甚至导致流鼻血与失去判断力；但在女性嗅觉中则是极其刺鼻、令人窒息的恶臭。
  3. 捕食机制：诱惑男性贴近交合，借机将其全身生气/精气吸食殆尽致死。
- 原文依据："死掉的那个女子不管怎么看都是普通的女人啊。只是背上长着跟蝙蝠一样的翅膀，还有指甲的长度也很异常。噢，仔细一看，原来她的皮肤呈现蓝色，而且五官也和人类有一点不同。"、"「你振作一点，那是女性梦魔啊！」……「我也是第一次碰到，但是这种让人窒息的恶臭正如传闻，所以应该没有错……」「恶臭？」我反而觉得是很香的味道，会让人特别兴奋。"、"「我听说过女性梦魔发出的气味有诓骗男人的效果，没想到如此强烈。」"、"近看才发现女性梦魔的长相并不可爱，其实很像蝙蝠。"、"如果我就那样抓住女性梦魔的手……说不定已经被吸光生气死掉了。"

- 名称：贝卡利特沙漠魔物群
- 特征：贝卡利特大陆的魔物总体强度略逊于魔大陆，但大多数具有夜行性习性，善于在夜间发起隐蔽奇袭。
- 原文依据："我记得沙漠里的魔物有很多都是夜行性。要是在黑暗中移动却遭到魔物奇袭，想必会成为危险的状况。"、"听说贝卡利特大陆上的魔物没有魔大陆那么强。话虽如此，想来还是会出现同样程度的魔物。"

## 五、物品 / 道具 / 武器
- 名称：奥尔斯帝德的备用斗篷与水筒
- 说明：奥尔斯帝德存放在贝卡利特大陆B3遗迹房间内的备用装备，包括适应沙漠烈日与低温的白色厚斗篷以及盛水器皿。
- 原文依据："其中一间房间里保管着白色厚斗篷和水筒……这些果然是奥尔斯帝德的私人物品吧。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移事件的时空偏差现象
- 内容：在数年前的菲托亚领地大转移事件中，受灾区域居民消失的时刻与在世界各地被目击出现的时刻存在时间偏差，佐证了空间转移在物理法则上并非绝对零延时的瞬间移动。
- 原文依据："话说起来，自己好像也在哪里听说过菲托亚领地消失的时间和难民出现的时间有一点偏差。是不是希露菲告诉我的？或许转移并不是瞬间移动，而是高速移动。"
