# 第二话　「女仆和住宿生」 世界设定提取

## 一、地理与场所
- 名称：夏利亚（气候）
- 内容：拉诺亚王国夏利亚气候极为寒冷，日常需要注意防寒保暖。
- 原文依据："因为这个地区很冷，真是最棒的抱枕。"

- 名称：拉诺亚魔法大学宿舍
- 内容：魔法大学学生宿舍并非单人独居，基本为双人房。宿舍内有严格明确的规章制度与安全保障，也有年龄十岁甚至更小的学生在其中居住生活。
- 原文依据："然而，学校的宿舍并非独居，基本上都是双人房。"、"以年龄来说还是多少有点问题，不过在那间学校里，也有年纪更小就住进宿舍的学生。宿舍有一定程度的明确规则，是安全的地方。"

## 二、组织与势力
- 名称：拉诺亚魔法大学（制度与课程）
- 内容：
  1. 入学笔试不按考生年龄区分题目，而是综合“一般教养”与“基础六类魔术”的标准测试，适用于所有年龄段。
  2. 展现特殊才能者（如十岁即考获满分）可附带特定条件破格录取为“特别生”。
  3. 学制体系为前两至三年接受一般通识课程，之后根据志愿选择专攻专业课程。
  4. 该地区医疗资源紧缺，非常缺少治愈魔术师，因此专攻治愈魔术的学生毕业后可进入诊所或医院工作。
  5. 校园极具包容性，拥有大量混血种族（如魔族、兽族等）学生。
- 原文依据："这次的测验是笔试。内容并没有针对年龄出题，而是综合了一般教养和基础六类魔术的正统入学测验，适用于所有年龄……"、"吉纳斯副校长也说既然爱夏才十岁就有这种成绩，那么只要附带几个条件，就能安排她成为特别生。"、"不过我记得接受一般课程两三年之后，就可以选择专门的课程。我们这间学校有一些相当有趣的课程，你要不要总之先念个几年，顺便寻找自己想做的事情呢？要是没找到特别有兴趣的科目，我想专攻治愈魔术应该也不错。母亲她也是治愈魔术师，而且这一带缺少治愈魔术师，将来可以进入诊所或医院工作。"、"这间学校里面有很多学生是混血"

## 三、力量体系 / 魔法 / 技能
- 名称：魔力总量成长法则
- 规则：自幼年期起持续使用魔术能够扩充魔力总量上限；到了十岁左右，魔力总量的成长空间虽然大幅受限，但依然存在一定的提升余地。
- 原文依据："原本这样决定的我突然想起从小使用魔术可以增加魔力总量的法则。既然爱夏不去上学，至少要让她锻炼一下魔力比较好。虽说十岁小孩无法成长那么多，也不代表进步空间是零。"

- 名称：攻击魔术分级效用
- 规则：初级攻击魔术足以应付平民的日常生活；若用于实战自卫或战斗，泛用性与便利度最高的则是中级魔术。
- 原文依据："另外，也顺便让她的攻击魔术提升到中级吧。如果只是要过一般日子，初级也完全没有问题。然而一旦提升到实战等级，用起来最方便的其实是中级。"

- 名称：土魔术隔音强化
- 规则：可借助土魔术对室内门窗与墙体进行强化，达到强力的隔音闭音效果。
- 原文依据："当然我有锁门，还用土魔术强化了隔音。"

- 名称：召唤魔术
- 规则：召唤魔术包含用于施展召来或传送机制的专用魔法阵，分为不同阶段与实验步骤。
- 原文依据："所以我指定了大概能派上什么用场的召唤魔术用魔法阵。她似乎会在实验要进行到第二阶段时向我说明，届时再顺便把魔法阵给我。"

## 四、种族 / 生物
- 名称：鸟系兽族 / 鸟系魔族（以梅莉莎为例）
- 特征：外貌特征带有鸟类要素，长相类似鹦鹉，生有类似凤头鹦鹉的头冠；头冠具备生理与情绪表达功能，会随着情绪起伏而抖动。
- 原文依据："诺伦的室友是一个长得像是鹦鹉的少女，还拥有类似凤头鹦鹉那样的头冠。头冠会随着感情起伏而抖动，大概是魔族或鸟系兽族吧。名字叫作梅莉莎，没有负面的传闻。"

## 五、物品 / 道具 / 武器
- 名称：召唤魔术用魔法阵
- 说明：刻画用于执行召唤术式的专用阵图，七星承诺在实验进入第二阶段时提供给鲁迪乌斯。
- 原文依据："所以我指定了大概能派上什么用场的召唤魔术用魔法阵。她似乎会在实验要进行到第二阶段时向我说明，届时再顺便把魔法阵给我。"

- 名称：魔术教本
- 说明：记载魔术法术模型与咏唱咒文的指导教材，供掌握基础原理者快速自学中级等魔术。
- 原文依据："中级魔术也只是还没记住而已，只要看过魔术教本，应该可以立刻熟习。"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯贵族的门第嫡庶观念——米里斯传统贵族门第（如拉托雷亚家族）极其讲究血统纯正与嫡庶尊卑，正室子女受到尊崇与爱护，而小妾/女仆所出的庶出子女则被视为地位低下并遭受歧视与冷落。
- 原文依据："「……哥哥对诺伦姐比较偏心，是因为我妈妈是小妾吗？」「你说的小妾是指莉莉雅小姐吗？爱夏，是谁对你说过这种话？是父亲吗？还是……该不会是诺伦说的吧？」「是妈妈……还有，诺伦的祖母……」"、"至于塞妮丝的娘家是贵族，我记得是颇有渊源的一族。我的阿姨特蕾兹虽然不是坏人，然而不可能所有人都那么不计较身分吧。况且基本上，他们有理由疼爱塞妮丝的女儿，却没有理由必须疼爱莉莉雅的女儿。毕竟彼此没有血缘关系。不管哪一边都没有错，这是一种文化。"、"塞妮丝的娘家瞧不起庶出的爱夏，导致爱夏不愿意输给诺伦，一直努力至今。"

- 内容：米里斯神圣国与北方大地的地域文化差异——两地在一般教养与文化常识考核上存在地域偏重差异。
- 原文依据："爱夏的成绩是满分。米里斯和这里的文化多少有些不同，也就是在一般教养方面会有点差异。结果爱夏却考了满分，实在无可挑剔。"

- 内容：北方多民族共处与反歧视戒律——在魔法大学等多民族与混血汇集的北方社会中，严禁在言行上对魔族产生公开歧视。
- 原文依据："这间学校里面有很多学生是混血，我必须事先提醒诺伦不可以讲出歧视言论。"、"包括在宿舍里要遵守规定，在学校要努力用功，以及见到魔族不可以歧视对方。"

## 九、角色认知 vs 客观事实
- 角色以为：爱夏认为鲁迪乌斯同意诺伦去住宿舍是因为偏心诺伦是正室塞妮丝所生的嫡女，而嫌弃自己是小妾莉莉雅所生的庶女。
- 原文是否暗示另有真相：是。客观事实是鲁迪乌斯完全视两人为同等重要的妹妹，绝无嫡庶歧视；之所以批准诺伦住宿舍，是因为觉察到诺伦同住会因才能落差与心理障碍产生极度自卑，拉开距离更有利于其身心健康成长。
- 原文依据："「……哥哥对诺伦姐比较偏心，是因为我妈妈是小妾吗？」"、"「我没有把莉莉雅小姐当成小妾，也认为你和诺伦都是我的妹妹。」"、"「我自认有根据情况来分别做出判断。例如……如果你现在改变心意想去上学，想住宿舍，我会答应你的要求。可是如果换成诺伦说不想去学校，要待在家里帮忙做家事，我不会答应。这是因为你在测验中考到满分。」"

- 角色以为：希露菲以为鲁迪乌斯批准诺伦住宿舍是想要从家里疏远排斥诺伦。
- 原文是否暗示另有真相：是。鲁迪乌斯解释这并非疏远，而是因为突然靠得太近激化了姐妹矛盾与心理压力，退后一步在远方守护反而更适合目前的诺伦。
- 原文依据："「你要疏远诺伦吗？」希露菲的语气略带责备。"、"「或许把爱夏和诺伦分开会比较好，因为爱夏好像被说过一些难听话，例如说她是小妾的女儿之类。而且我不是要疏远诺伦，只是因为彼此突然靠得太近，所以想拉开一点距离。」"
