# 第十一话　「沙漠的生态」 世界设定提取

## 一、地理与场所
- 名称：贝卡利特大陆荒漠生态与气候
- 内容：
  1. 日夜温差与气候：白昼烈日高照、燥热强风吹拂，沙地松软下陷，消耗体力巨大；黄昏时夕阳将沙丘染为绯红，波纹呈现梦幻的红黑相间条纹；傍晚气温快速下降，入夜极度寒冷。
  2. 水源与魔物连锁反应：沙漠生物与魔物对水源极度渴望，若在沙漠降雨会立刻引来大批魔物汇集。
  3. 魔物密度与生态链：贝卡利特沙漠的魔物密度极其惊人，甚至超越魔大陆。黄昏及夜晚大量夜行性魔物涌现，形成复杂的捕食链（巨大蝙蝠 → 迅猛龙型蜥蜴 → 巨型金翅鸟 → 更大型肉食兽）。大部分贝卡利特大陆魔物具有畏寒怕冷的生理特性。
- 原文依据："强烈的日光和热风还有上升的体温，让我感到头晕目眩。……沙漠的黄昏是一片红艳。夕阳把沙地染成鲜红，让沙上的波纹形成鲜明的对比。地面布满红黑相间的条纹图案……"、"「下雨会引来魔物，最好不要那样做。」不管在哪里的沙漠，生物都会寻求水源。"、"我听说过贝卡利特大陆的魔物怕冷"、"这里的魔物比想像的还多。老实说，这里的魔物密度比魔大陆还夸张。"

## 三、力量体系 / 魔法 / 技能
- 名称：火魔术「Burning Place」与温度调节应用
- 规则：原属于在寒冷环境下给周身空间加热的火魔术应用。鲁迪乌斯将其逆向微调，能够在酷热沙漠中使施术者周围体感温度下降约5℃。
- 原文依据："那个时候，我曾利用魔术让自己周围的空间发热，也就是应用了火魔术「BurningPlace」。只要稍微调整一下，应该也可以改善现在的状况。我立刻试着实行。……体感温度应该是下降了5℃左右"

- 名称：水/冰魔术物理降温
- 规则：将随身水筒注水后施以冰魔术冻结成冰枕贴身放置，融化后重复施术冻结，可大幅降低在高温沙漠行军的虚脱感与中暑风险。
- 原文依据："我一边降低周围温度，同时拿一个水筒做成冰枕放进衣服里。冰枕融化之后就再用魔术冻结。如此一来舒服很多，这下高温已经不成问题。"

- 名称：战士的“斗气”与体能
- 规则：该世界的受训战士（如艾莉娜丽洁等）体内运转着“斗气”，赋予其超常的体力与抗疲劳抗耐力，在严酷沙漠长途行军亦能维持充沛体力。
- 原文依据："果然这个世界的战士都拥有怪物般的体力，这也是托了什么斗气的福吗？实在让人羡慕。"

- 名称：魔物危险层级评定规则
- 规则：公会评估魔物的危险度等级时，会将“群聚数量”综合考量。单独个体即便是D级或C级，数十只聚集便等同于B级或A级；集结超过一千只以上则直接列入最高危险度的S级。
- 原文依据："在这个世界里，评估魔物的层级时，会把族群数量也考虑进去。就算是D和C级，十只凑在一起就会变成B或A级；超过一千只的话，被列为S级当然很合理。"

## 四、种族 / 生物
- 名称：双尾死蝎
- 特征：贝卡利特沙漠的B级魔物。全长约两公尺的巨型蝎子，长有两条可独立发起攻击的尾针。外壳坚硬，行动相对迟缓。尾部附带烈性毒素，必须使用中级解毒魔术方能救治。
- 原文依据："第一个遇到的是巨大的蝎子，长度大概有两公尺吧。尾巴分成两条，还会各自发动攻击。根据艾莉娜丽洁的情报，这个魔物好像叫作双尾死蝎。尾巴带有剧毒，必须使用中级解毒魔术才能治愈。……虽说好像是B级魔物"

- 名称：仙人掌魔木
- 特征：栖息于沙漠的C级植物型魔物，完美拟态成巨型仙人掌。能发射尖刺并施展类似土魔术的技能。体内蕴含极丰富水分，无法晒干充当引火柴薪，但在断水绝境中可作为天然水源。
- 原文依据："这次的会拟态成仙人掌。顺便说一下，名字就叫作「仙人掌魔木」。层级是C级。虽然会发射尖刺和使用类似土魔术的能力，果然还是没什么大不了。……这个仙人掌不能拿来当柴薪呢。「因为水分太丰富了。如果我们不懂魔术，这倒是让人很感谢的存在。」"

- 名称：沙虫（Sand Worm，贝卡利特种）
- 特征：潜伏于沙层之下的巨型蠕虫魔物。直径约一公尺，冲出地面的上半身长达五公尺，全身接近十公尺，能轻易将成年人类整体吞没。平时深潜沙土伺机伏击经过上方的生灵，属于即死型陷阱猎手。体液腥臭，遭遇避开初突袭后，可用土魔术直接在地下将其绞杀。（大森林亦有同类但直径仅20-30公分，魔大陆则存在更大个体）。
- 原文依据："是蚯蚓。直径一公尺，长度恐怕有五公尺的巨大蠕虫一跃而出。……是沙虫，只是大了一点。所谓的沙虫，是一种会待在土里静静等待，在猎物从上方通过时才跳出来捕食的魔物。……贝卡利特大陆的沙虫真是巨大，光是跳出地面的部分就有五公尺。再加上躲在地底的部分，全长是不是将近十公尺呢？是可以把人类一口吞下的尺寸。"

- 名称：方阵蚁（Phalanx Ant，贝卡利特特有变异种）
- 特征：贝卡利特大陆极端危险的群体魔物，由行军蚁变异而来。个体单体为E级至C级，但庞大群体（超过一两千只横跨地平线）被公认为无可挑剔的S级灾难。
  1. 习性：全身鲜红，不筑固定巢穴，沿途迁徙并把行经路线上一切生灵全部啃噬殆尽（甚至包括陆行脱队龙），直到特定时期才筑巢完成世代交替。比普通行军蚁更加聪明狡诈且极度好战，即便旁观不敌对也会列阵围剿。
  2. 构造：群体分工明确，小工蚁约30公分，大个体达1公尺（部分具翅膀或拟人上半身）；女王蚁体长超两公尺，上半身呈现人类女性形态。
- 原文依据："「有一大群方阵蚁！」……可以看见全身鲜红的蚂蚁正排着队列前进。大小差不多是三十公分到一公尺吧……外型也相当多样化，有的长着翅膀，也有上半身很像人类的家伙。……看这些蚂蚁的尺寸和数量，是无可挑剔的S级。……方阵蚁是会把所有东西都啃食殆尽最强魔物之一。大森林也有，不过那种大小……一定是贝卡利特大陆的特有种。方阵蚁似乎是行军蚁变异而成的魔物。虽然是蚂蚁却不筑巢，只是不断旅行，并且把途中一切都啃食殆尽。……就算是脱队龙也能吃掉。……比普通行军蚁更聪明也更加好战。……「啊，那个就是女王。」……大小在两公尺以上，上半身长着人类女性的身体。"

- 名称：巨大蝙蝠
- 特征：翼展约五十公分的蝙蝠型魔物，单体F级，大集群时等同E级。日间潜伏，黄昏外出觅食昆虫蜥蜴。攻击性较弱但拍翅噪音极重；常被女性梦魔收为眷属部下，集群扑咬干扰同行女性，为梦魔诱捕男性制造空档。
- 原文依据："原来是五十公分左右的蝙蝠。……是巨大蝙蝠呢。……层级是F级。这一批数量很多，或许该算是E级。攻击能力并不是特别高，也没什么威胁性，不会袭击人类。……女性梦魔似乎也是把巨大蝙蝠当成属下。如果发现有有男有女的旅行者，就让蝙蝠缠住女性，然后趁机迷倒男性，把对方带走。"

- 名称：女性梦魔（捕食生态补充）
- 特征：战斗力单体等同E级，但因综合催情迷幻与驱使眷属能力被列为C级。散发的费洛蒙气味会把方圆之内的肉食魔物引诱集结，导致人类旅人途经地沦为危险杀戮场。被诱捕男性会被带回巢穴先榨取性欲，最终被吸干并作为食物吃掉。
- 原文依据："女性梦魔的战斗力大约是E级程度，分类上却等同于C级，是一种强大的魔物。"、"如果发现有有男有女的旅行者，就让蝙蝠缠住女性，然后趁机迷倒男性，把对方带走。男性会被带回女性梦魔的巢穴，先被用来满足性欲，最后会被用来满足食欲。"、"根据艾莉娜丽洁的推测，她认为是那个女性梦魔的费洛蒙把魔物引了过来。……既然有这气味的地方就会出现能猎食的对象，当然会吸引魔物靠近。"

- 名称：迅猛龙型蜥蜴（贝卡利特特有爬行动物） [存疑]
- 特征：两足直立行走的小型迅猛龙状蜥蜴魔物，十几只成群行动，长有尖牙，动作极快，性格凶残贪婪，会抢食落地的蝙蝠等猎物，肉质鲜美可作为旅行口粮。
- 原文依据："有一群跟迅猛龙一样以两只后脚步行的蜥蜴从沙丘另一边冒了出来……它们的长相个头不大，不过总共有十几只，其中几只还开始捕食掉在地上的蝙蝠。「我没见过这种东西。」……应该是贝卡利特大陆的特有种吧。……在撤退的途中，艾莉娜丽洁很机灵地回收了迅猛龙的尸体。那玩意儿看起来比蝙蝠好吃。"

- 名称：金翅鸟（巨型鸡冠鸟怪）
- 特征：高达五公尺的巨型鸟类魔物（类似恐龙），长有硕大亮红的鸡冠，以五至六只集群狩猎，是迅猛龙型蜥蜴的天敌。单体C级，成群为B级（体型庞大者可能达A级）。
- 原文依据："若以一句话来形容，就是巨大的鸡。大概有五公尺吧，根本已经是恐龙等级。大红色的鸡冠非常刺眼。这家伙似乎是迅猛龙的天敌。以五六只的小组对那些迅猛龙展开猛攻……「这是一种金翅鸟……」金翅鸟单体的层级是C级，这种成群的状态似乎等于B级。不过看这体型，也有可能算是A级。"

- 名称：灵魂破坏者与刽子手（魔大陆铠甲魔物补充）
- 特征：魔大陆有名的武装铠甲魔物。灵魂破坏者（Soul Breaker）为常态铠甲魔物；刽子手（Executioner）手持巨型大剑，战斗力与凶险度极高，单体遭遇极为致命。
- 原文依据："「铠甲……是灵魂破坏者吗？」「不，记得是叫作刽子手吧，一个拿着大剑的家伙。」「噢，是更强的那一种。那可是单独行动时绝对不想碰到的敌人。」"

- 名称：史莱姆（栖息环境补充）
- 特征：艾莉娜丽洁纠正常识指出，该世界的史莱姆只栖息在洞窟之中，并非随处可见。
- 原文依据："「嗯？史莱姆只会出现在洞窟里啊。」"

## 五、物品 / 道具 / 武器
- 名称：水筒冰枕
- 说明：将水注入普通水筒后施放冰魔法凝固而成的降温道具，融化后可反复使用魔术冻结，是鲁迪乌斯在沙漠行军时抵抗酷暑的自制装备。
- 原文依据："我一边降低周围温度，同时拿一个水筒做成冰枕放进衣服里。冰枕融化之后就再用魔术冻结。"

## 七、社会规则 / 习俗 / 文化
- 内容：冒险者的野外自给自足法则
  长途远征探索的冒险者在旅途中遵循优先猎杀捕获可食魔物（如迅猛龙肉）食用、尽量保持干粮物资充裕的野外生存基本功。
- 原文依据："基本上，本日晚餐是迅猛龙的尸体。并不是因为我们担心带来的食物会不够，而是在旅途中要自给自足是身为冒险者的基本功。"
