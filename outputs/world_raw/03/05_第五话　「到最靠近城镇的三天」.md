# 第五话　「到最靠近城镇的三天」 世界设定提取

## 一、地理与场所
- 名称：魔大陆野外环境
- 内容：魔大陆上没有能当作柴薪的木材，野外生活生火必须通过狩猎魔物（如石魔木）来取得木料。从米格路德族村落前往最靠近的城镇需徒步三天。
- 原文依据："「首先要升起火堆，但是魔大陆上没有能当成柴薪的木材。」……「那么该怎么做？」「要狩猎魔物。」在魔大陆上，似乎不狩猎魔物就无法生活。"及"前往最靠近的城镇，似乎必须徒步三天。"

- 名称：妖精之泉
- 内容：位于大森林中，泉水蕴含超高浓度的魔力。小型魔木若从中吸取养分，会变异为能使用水魔术的长老魔木。
- 原文依据："而小型魔木如果从大森林里的妖精之泉吸取养分后，就会变化成叫作长老魔木的魔物。妖精之泉蕴含超高浓度的魔力，据说靠着这力量，长老魔木会变得能使用水魔术。"

## 二、组织与势力
无

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术・无咏唱岩炮弹（变形加工）
- 规则：通过无咏唱魔术控制魔力，在产生硬度极高的炮弹型岩石后，将前端削平并加上凹槽与刻痕（类似空尖弹），赋予高速旋转与极快速度。破坏力极大，命中可导致魔物直接爆炸碎裂；亦可设定为在命中目标的同时爆炸。
- 原文依据："产生：炮弹型岩石。硬度：尽可能最硬。变形：将炮弹前端削平，并加上凹槽和刻痕。变化：高速旋转。大小：比拳头再大一点。速度：尽可能最快。「『岩炮弹』！」……打中还在拟态的石魔木。发出让人想要塞住耳朵的声响后──魔木爆炸碎裂。"及"「必须以无咏唱方式来使用，否则无法让炮弹的形状产生变化。」"及"「不，刚刚那个还可以在击中敌人的同时爆炸。」"

- 名称：初级治愈魔术（Healing）
- 规则：念诵咏唱咒文后发动，能治愈身体外伤并恢复气力。
- 原文依据："「神圣之力是香醇之粮，赐予失去气力之人再次站起来的力量吧∣『Healing』。」总之，我先帮她把伤口治好。"

- 名称：剑术等级（剑神流上级）
- 规则：艾莉丝在快到鲁迪乌斯生日之前达到了剑神流上级；保罗在剑神流、水神流、北神流三流派皆达到上级。基列奴曾评定艾莉丝的才能在保罗之上。
- 原文依据："结果，她在快到我生日之前达到了剑神流的上级。……讲到上级，已经和保罗同等……话虽如此，保罗连水神流和北神流都是上级，所以再怎么说还是保罗比较厉害吧。……但基列奴说过艾莉丝的才能在保罗之上，总有一天应该会超越保罗。"

- 名称：三人小队阵形划分
- 规则：针对三人队伍特性划分战术定位：艾莉丝担任前卫（自由进攻）；鲁迪乌斯担任后卫（远距离魔术支援与治愈）；瑞杰路德担任游击（自由战斗、掩护死角、指挥并应对危险）。
- 原文依据："「瑞杰路德先生，我想以后就采用以艾莉丝为前卫，我担任后卫的阵形。」「我要做什么？」「游击。自由战斗，也请同时掩护我们的死角。还有，万一碰上什么危险情况，请你做出指示。」「好。」"

## 四、种族 / 生物
- 名称：米格路德族（生命周期与外貌特性补充）
- 特征：在约十岁上下就会成长到和成人后差不多的模样，之后直到一百五十岁左右外貌都不会改变。洛琪希母亲洛嘉莉一百零二岁仍显年轻；洛琪希四十四岁换算成人族年龄相当于二十岁左右。
- 原文依据："「哎呀，居然说我年轻……我今年都已经一百零二岁了。」……顺便说一下，米格路德族似乎在约十岁上下就会成长到和他们成人后差不多的模样，之后直到一百五十岁左右，外貌都不会改变。"及"虽说洛琪希已经四十四岁了，但换算成人族的年龄……大概也才二十岁左右。"

- 名称：斯佩路德族（身体构造与枪的共生）
- 特征：出生时会长着一根有三叉的尾巴。随着成长尾巴变长，到一定年龄后突然硬化并与身体分离，化为伴随一生的枪。枪被视作以斯佩路德族的灵魂构成，即便脱离仍是身体的一部分，越经磨砺使用就越锋利，理论上能成长为不折不断、无坚不摧之利器。族人抱有“到死为止都不能放开自己的枪”的戒律信条。
- 原文依据："「斯佩路德族一出生就会带着一把枪。」……据说斯佩路德族出生时，会长着一根有三叉的尾巴。随着成长，这根尾巴也会变长，到了一定年龄后就会突然硬化，和身体分离。不过即使分开，枪似乎还是身体的一部分，越使用就会越锐利。绝对不会折断，也不会被任何东西打碎，可以贯穿世上万物的最强之枪……根据持有者本人的锻炼程度，据说也有可能成长为那样的利器。「所以，到死为止都不能放开自己的枪。」"

- 名称：魔木（石魔木 / 小型魔木 / 长老魔木 / 大型魔木 / 僵尸魔木）
- 特征：
  - 概括定义：吸收魔力变异、袭击人类的树木总称为魔木。行动模式为拟态为树木或岩石，袭击接近的猎物，留下种子自行繁衍。
  - 小型魔木：年轻树木变异而成，拟态成普通树木袭击人类，力量弱、动作慢，普通成年男性用斧头即可砍断。
  - 长老魔木：小型魔木吸收大森林妖精之泉的浓厚魔力变异而成，能使用水魔术。
  - 大型魔木：大树变异而成。
  - 僵尸魔木：枯树变异而成。
  - 石魔木：特殊魔木，在种子阶段就成为魔物，平常呈巨大马铃薯状凹凸不平的岩石拟态，有人靠近瞬间化为树木攻击。死亡后躯干立刻干燥，是优质的柴薪来源。
- 原文依据："魔木这种东西，简单来说就是树变成的魔物。只要是吸收魔力，产生变异并变得会袭击人类的树木，全都被统称为魔木。……小型魔木……长老魔木……大型魔木，枯树变化成的僵尸魔木……不过，这个石魔木有点特殊。居然是拟态成岩石。……是在种子时期就成为魔物。平常会保持巨大种子的外型，等人靠近时才瞬间变化成树木并发动攻击。……讲到火堆，石魔木只要一死亡就会变乾，所以好像不需特别乾燥就可以直接当成柴薪使用。"

- 名称：大王陆龟
- 特征：魔物，肉质偏硬且腥味重，通常需耗费长时间慢火炖煮；可被风干制作成肉干充饥，亦可直接火烤或生食。
- 原文依据："大王陆龟被瑞杰路德一击解决。是从正面打穿脑袋的一击……晚饭是大王陆龟的肉。由于一次吃不完，所以一半的肉以上是按照瑞杰路德的指示来制成肉乾。大王陆龟的肉……老实说，不太好吃。腥味相当重，肉质又硬。一般来说似乎会花费长时间来慢慢炖煮，但瑞杰路德却只是简单地用火烤。……「生肉也不是不能吃。」"

- 名称：毒酸狼
- 特征：魔物，能从嘴里喷射吐出强酸液的狼形魔物。其血液不具强酸腐蚀危险。
- 原文依据："毒酸狼是一种会从嘴里吐出酸液的狼。……原本担心既然这魔物会吐酸液，血液会不会也有危险，但似乎没问题。"

- 名称：帕克斯郊狼
- 特征：魔物，以数十只为规模成群结队行动。繁衍并非群聚而是由首领每隔数月自我分裂产生，首领可完全统御操控分裂出的所有个体；即便原首领阵亡，其余个体亦能立即继承首领地位继续统领战斗。其毛皮具备变卖经济价值。
- 原文依据："帕克斯郊狼会形成数十只的集团。并不是聚集而成，而是会分裂。话虽如此，也不是在战斗中会一直增加，而是每几个月分裂一次，集团首领可以完全控制增加的个体。就这样，数量越来越多。即使打倒本体，也会由其他个体继承首领的位置，继续战斗。……「帕克斯郊狼的毛皮可以变卖，来剥皮。居然能遇上这么多只，运气不错。」"

## 五、物品 / 道具 / 武器
- 名称：短弯刀（洛因赠予的单刃剑）
- 说明：刀身约六十公分的宽幅微弧单刃剑，深灰色刀身反射微绿光芒。由过去造访米格路德族聚落的铁匠使用特殊金属与特殊锻造法制成，历经长年使用仍刃口无损、不易生锈。由洛因赠与鲁迪乌斯，转交艾莉丝作为武器。
- 原文依据："这是一把宽幅的单刃剑，刀身部分大约是六十公分，尺寸算是比较小。刀身带点弧度，类似开山刀……不，应该比较像短弯刀吧。……虽然整体是深灰色，但会反射出偏绿的光芒。「这是以前来到聚落的铁匠送我的东西，即使长年使用，刀刃也坚固得毫无缺损。可以的话就拿去用吧。」"及"艾莉丝使用的剑也是特殊金属在特殊锻造法下制造出来的武器，所以似乎不会生锈。"

- 名称：斯佩路德族的三叉枪
- 说明：纯白色短枪，无多余装饰，枪柄与枪刃一体成形。非金属制造，而是由斯佩路德族身上的三叉尾巴自然硬化脱落而成，不会生锈。
- 原文依据："瑞杰路德使用的枪不是金属制……斯佩路德族的三叉枪是一把纯白的短枪，没有装饰，枪柄和枪刃一体成形。"

- 名称：魔大陆与阿斯拉王国货币体系
- 说明：
  - 魔大陆货币分为四种：绿矿钱、铁钱、屑铁钱、石钱。货币购买力价值为全世界最低。
  - 石钱：以石头制成的粗劣硬币，约合 1 日元。
  - 屑铁钱：劣质铁质硬币，约合 10 日元。
  - 铁钱：深灰色金属铸造，约合阿斯拉铜币 1 枚（约 100 日元）。
  - 绿矿钱：魔大陆最高等货币，约合 1000 日元（等同或略低于阿斯拉大铜币 1 枚）。
  - 阿斯拉货币比价参考：阿斯拉铜币（100 日元）、阿斯拉大铜币（1000 日元）、阿斯拉银币（10000 日元）、阿斯拉金币（100000 日元）。
- 原文依据："发现里面装着以石头制成的粗劣硬币，以及用深灰色金属铸造的硬币。我记得魔大陆的货币是绿矿钱、铁钱、屑铁钱、石钱这四种。货币价值是全世界最低，即使是最高等的绿矿钱，也和阿斯拉大铜币一枚同价甚至有点不足。铁钱和铜币差不多。顺便一提，把阿斯拉王国和魔大陆的货币换算成日币后，大概是以下的感觉。如果把最便宜的石钱设定为一日币。阿斯拉金币十万日币 / 阿斯拉银币一万日币 / 阿斯拉大铜币　一千日币 / 阿斯拉铜币一百日币 / 绿矿钱一千日币 / 铁钱　一百日币 / 屑铁钱十日币 / 石钱　一日币"

## 六、历史 / 传说 / 事件
- 事件名：斯佩路德族四百年前的重大失败
- 内容：瑞杰路德为四百年前发生的某场失败深感悔恨自责，该历史事件直接促成了他“至死不得丢弃自己之枪”的固执信条。
- 原文依据："眼前这男子的表情，显示出他为了四百年前的失败深感后悔。瑞杰路德的枪大概比其他任何一个斯佩路德族都还要坚硬锐利吧，真可靠。"

## 七、社会规则 / 习俗 / 文化
- 内容：魔大陆生存法则与柴薪获取
  魔大陆野外植被稀缺无普通木材柴薪，要在荒野露宿扎营，必须猎杀魔木（如石魔木）将其脱水残躯当作燃料生火。食物也主要依赖猎杀魔物，过着自给自足的肉食生活。
- 原文依据："「首先要升起火堆，但是魔大陆上没有能当成柴薪的木材。」……「那么该怎么做？」「要狩猎魔物。」在魔大陆上，似乎不狩猎魔物就无法生活。"

- 内容：战士对武器的维护责任
  即便是不易生锈的特制武器或自身尾巴形成的骨枪，在战斗后也必须及时清除血污。残留血渍不仅会引诱附近魔物聚集，还会削弱武器锋芒。战士对自身兵刃的妥善保养被视作立身处世的基本理法。
- 原文依据："要是放着武器上的血汙不管，不但会吸引其他魔物靠近，也会减低锐利度。而且身为战士，管理自身武器是理所当然的行为。这是瑞杰路德的理论。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯起初以为瑞杰路德坚持独自猎杀魔物是出于自负或把他们当累赘。
- 原文是否暗示另有真相：是。瑞杰路德纯粹是出于战士保护小孩的本能和责任感（"狩猎是战士的责任。小孩子乖乖等"），在鲁迪乌斯以战士对等身份郑重沟通后，瑞杰路德立刻认同并同意配合实战训练。
- 原文依据："「你打算一个人战斗吗？」「嗯，狩猎是战士的责任。小孩子乖乖等。」"及"「……我明白了，你是战士。」"

- 角色以为：鲁迪乌斯以为贵族大小姐艾莉丝无法忍受腥硬粗糙的火烤大王陆龟肉。
