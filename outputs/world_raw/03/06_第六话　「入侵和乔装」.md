# 第六话　「入侵和乔装」 世界设定提取

## 一、地理与场所
- 名称：利卡里斯镇（别名：旧奇希里斯城）
- 内容：魔大陆三大都市之一。建立在一座巨大环形山的凹坑底部，高耸的环形山壁成为天然城墙与结界，既能多次抵御敌军入侵，也防止外界魔物侵入。全城仅有三处由环形山裂缝形成的天然出入口，防守森严。城中心矗立着半崩塌的黑铁之城——奇希里斯城，城门附近设有供商人停驻的旅社与马厩。
- 原文依据："利卡里斯镇。魔大陆三大都市之一。据说在人魔大战时期，这里是被魔界大帝奇希莉卡・奇希里斯作为根据地的城镇。别名：旧奇希里斯城。看到这城镇后首先会感到惊讶的事情，是它的所在地点。居然是盖在一个巨大环形山的凹坑里。环形山的山壁成为天然的城墙，好几次挡住敌军入侵。现在也发挥出防止魔物入侵的功用，是自然的结界。……城镇有三个入口，环形山的裂缝被直接当成入口使用。环形山的山壁很高，除非能够飞行，否则很难从入口以外的地方入侵。……在入口附近，有商人用的旅社和马厩等店家接连相邻。"

- 名称：奇希里斯城
- 内容：位于利卡里斯镇中心的黑铁之城，魔界大帝奇希莉卡时代的威势象征。在拉普拉斯战役中遭到破坏，现存建筑有一半崩塌，遗留着当年奇希莉卡派魔王与魔神拉普拉斯交战的痕迹。
- 原文依据："城镇中心是有一半崩塌的奇希里斯城。这城堡在拉普拉斯战役中遭到破坏，是当时奇希莉卡派的魔王和魔神拉普拉斯交手后留下的痕迹。拥有可靠城墙和过去荣华痕迹的黑铁之城。"

## 二、组织与势力
- 名称：冒险者公会
- 内容：类似人才派遣中介组织，只在大型城镇设立。具备能力者登记后可作为正式身份证明，承接委托赚取酬劳并积累公会声誉；登记成为冒险者后在城镇住宿享有折扣优待。最低阶初级冒险者主要承接城镇内日常杂务委托。
- 原文依据："「那么，就去冒险者公会吧。那里的话即使是外来的人，也可以不需花费成本就赚到每天的收入。」……「只要在冒险者公会登录，住宿费也会稍微便宜一点。所以至少要先完成登录手续。」"及"所谓的冒险者就是派遣员工。拥有技能的人们前往名为「冒险者公会」的人才派遣公司进行登录，接受工作仲介，同时提升自身的评价。……只有大型城镇里才有冒险者公会吗？……最低层级的冒险者能接的工作据说是城镇中的杂务。"

- 名称：奇希莉卡派
- 内容：人魔大战及拉普拉斯战役时期效忠追随魔界大帝奇希莉卡・奇希里斯的魔族派系，其麾下魔王曾与魔神拉普拉斯展开过激战。
- 原文依据："这城堡在拉普拉斯战役中遭到破坏，是当时奇希莉卡派的魔王和魔神拉普拉斯交手后留下的痕迹。"

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术・岩石塑形具象化
- 规则：将手掌按在地面灌注魔力，能瞬间以土壤岩石为原料，精细塑形出硬度极高、严丝合缝的全罩式岩石战术头盔。
- 原文依据："「所谓乔装，就是改变外型，伪装身分的行为。」「哦……要怎么做？」「这个嘛……总之，先把脸藏起来吧。」于是我先原地坐下，把手放到地面上并灌注魔力。……瑞杰路德用我制作的岩石制全罩头盔遮住脸。"

## 四、种族 / 生物
- 名称：利卡里斯卫兵魔族亚种（蛇头魔族 / 猪头魔族）
- 特征：守卫利卡里斯镇城门的魔族亚种士兵，分别长有蛇头（性格严肃警觉、配剑）与猪头。
- 原文依据："城镇入口站着两名卫兵。一个是长着蛇头，看起来很严肃的家伙；还有一个是长着猪头，似乎很自大的家伙。"

- 名称：魔大陆骑乘蜥蜴
- 特征：利卡里斯镇马厩售卖的类似蜥蜴的骑乘生物，适应魔大陆多岩石、高低落差大的严苛地形，实用性优于普通的马匹。
- 原文依据："利卡里斯的马厩和罗亚不同，贩卖着类似蜥蜴的生物。在地形布满高低差和岩石的魔大陆上，这种生物应该比马更有用吧。另外，虽然没有公共马车，但商人们会各自派出马车。"

## 五、物品 / 道具 / 武器
- 名称：米格路德族的护身符（项链）
- 说明：洛琪希从鲁迪乌斯家中毕业时赠予的贺礼信物。在魔大陆佩戴此护身符，可被外界视作与米格路德族存在紧密联系之信物。鲁迪乌斯将其借给瑞杰路德佩戴以完善伪装。
- 原文依据："我拿下项链，挂到瑞杰路德的脖子上。「这是米格路德族的护身符吗？」「对，是我的师父庆祝我毕业送的贺礼。之后，我随时随地都贴身戴着。」只要戴着这个，至少会被认为是和米格路德族有关系的人。"

- 名称：类柠檬水果
- 说明：魔大陆市集贩售的水果，果汁富含强效天然酸性成分，可用于清洗去除翠绿色等较淡发色色素，起到漂发脱色效果。
- 原文依据："我拿出在摊位买来的类柠檬水果，挤出果汁让瑞杰路德的头发褪色。原本翠绿色就是色素比较淡的颜色，所以成功漂掉颜色。"

- 名称：兽耳兜帽
- 说明：魔大陆市集出售的兜帽斗篷，头顶部分附带为兽族耳朵预留的立体结构。艾莉丝用来遮盖显眼的红发。
- 原文依据："我摊开之前买的兜帽，才发现上面付着「耳朵用的部分」……是兽族用的兜帽吗？……艾莉丝立刻戴上兜帽，笑容满面地说道。"

- 名称：布莱迪康德《行遍世界》
- 说明：冒险家布莱迪康德撰写的世界游记地理名著，详细记录了魔大陆历史古都利卡里斯的地理沿革与黄昏落日之美。
- 原文依据："利卡里斯是个历史悠久的城镇。旅人们将会在夕阳西下时，明白这城镇的真正之美。──引用自冒险家：布莱迪康德的着作《行遍世界》。"

## 六、历史 / 传说 / 事件
- 事件名：人魔大战时期利卡里斯的统治
- 内容：人魔大战时期，利卡里斯镇作为魔界大帝奇希莉卡・奇希里斯统治的核心根据地，因而被称为“旧奇希里斯城”。
- 原文依据："据说在人魔大战时期，这里是被魔界大帝奇希莉卡・奇希里斯作为根据地的城镇。别名：旧奇希里斯城。"

- 事件名：拉普拉斯战役中奇希里斯城的损毁
- 内容：奇希里斯城在拉普拉斯战役期间遭到半毁，毁坏原因为奇希莉卡派麾下的魔王与魔神拉普拉斯交锋激战所致。
- 原文依据："城镇中心是有一半崩塌的奇希里斯城。这城堡在拉普拉斯战役中遭到破坏，是当时奇希莉卡派的魔王和魔神拉普拉斯交手后留下的痕迹。"

## 七、社会规则 / 习俗 / 文化
- 内容：斯佩路德族在魔大陆遭遇的极端防备与“Dead End”的恶名
  在魔大陆，斯佩路德族同样遭到极端恐惧排斥，只要靠近聚落就会引发警卫警报与冒险者倾巢围剿。瑞杰路德拥有响亮骇人的外号“Dead End”（遇上必死），只要周边出现其目击报告，城镇便会实施最高级别戒严。魔大陆民众普遍认为斯佩路德族狂暴好战缺乏伪装智能。
- 原文依据："「我没进去过，每次都会被赶跑。」……「首先，只要我一靠近城镇，守门警卫就会大叫，不久之后会出现大量的冒险者。」"及"「不，是因为最近似乎有人在这附近目击『Dead End』，所以特别警戒。」……「有一部分人那样称呼我。」结果似乎是指瑞杰路德∣「Dead End」……"及"我想他们一定没把斯佩路德族当人看，而是认为斯佩路德族是只会到处闹事的魔族，不具备懂得乔装打扮的智能。"

- 内容：崇尚强者的社会风向
  该世界具有强烈的崇拜强者倾向，击退知名魔物或化解城镇重大危机能够迅速赢得民众信赖、抬高社会地位与名望。
- 原文依据："在这个世界里，有强者比较容易被众人接纳的倾向。击退具备高知名度的魔物后，也有机会让地位多少往上提升一点。"

- 内容：市集交易与魔物素材变现规则
  城镇市集流动摊位存在虚报要价与讨价还价机制；讨伐魔物所得素材（如帕克斯郊狼毛皮、毒酸狼牙齿）可直接交付市集摊贩回收变卖换取硬币。
- 原文依据："「大叔，这个染料是不是太贵了点？你在抬价吗？」……「啊，对了，你顺便收购这些吧。有帕克斯郊狼的毛皮和毒酸狼的牙齿。」……「真没办法，那出四枚吧。」经过交涉后，我一口气完成购物和变卖。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯在城门听到守卫严阵以待防备“Dead End”，以为“Dead End”是某种凶暴可怕的未见魔物，甚至妄图将其引来由瑞杰路德斩杀立威。
- 原文是否暗示另有真相：是。“Dead End”正是瑞杰路德本人的外号，并非什么凶猛魔物。
- 原文依据："「遇上必死」吗？真是可怕的名字，应该是很恐怖的魔物吧。"及"「瑞杰路德先生，你知道『Dead End』是指什么吗？」……「是我。」……结果似乎是指瑞杰路德∣「Dead End」。"

- 角色以为：鲁迪乌斯以为艾莉丝排斥兽族，送她兽耳兜帽会招致反感厌恶。
- 原文是否暗示另有真相：否。艾莉丝不仅没有抵触，反而十分惊喜欢快地接受并当场佩戴。
- 原文依据："她不太愿意做出类似兽族的打扮和动作。……「我……我想给艾莉丝你用……如何呢……」「真的吗！」我原本很担心，可是她却非常高兴。……「我会好好珍惜！」艾莉丝立刻戴上兜帽，笑容满面地说道。"
