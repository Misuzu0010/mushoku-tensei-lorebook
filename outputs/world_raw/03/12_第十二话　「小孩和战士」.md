# 第十二话　「小孩和战士」 世界设定提取

## 一、地理与场所
- 名称：石化之森（南方森林）
- 内容：距离利卡里斯镇约整整一天路程的危险森林，紧邻道路，穿行此森是通往邻镇的捷径。森林中密集生长着大量形似尖锐骨骼的白骨状树木，远望犹如整片森林皆被石化。林中盘踞着杏仁巨蟒、刽子手、白牙大蛇以及极罕见的赤食大蛇等危险魔物（B级至A级），危险度极高，通常仅有配备多名精锐护卫的商队才敢涉足。
- 原文依据："石化之森。距离利卡里斯镇需要整整一天的路程。是一座位于道路旁边的森林，生长着大量状似尖锐骨头的树木，所以看起来很像是整个森林遭到石化。穿过森林的路线是前往隔壁城镇的捷径，然而这里栖息着杏仁巨蟒和刽子手等被归类为B级的危险魔物，因此大概只有雇用多名强大护卫的赶路行商才会走这条路。虽说这个世界里的每座森林都很危险，无一例外，但是魔大陆的森林更是特别危险。"

## 二、组织与势力
- 名称：冒险者公会评级晋升与惩戒机制
- 内容：公会评级进阶与降级具有明确硬性指标：
  - 升阶指标：F→E需完成10次F级任务或连续达成5次E级任务；E→D需完成50次F级任务、25次E级任务或连续达成10次D级任务；后续阶级要求次数倍增。
  - 降阶与禁接惩戒：若接取低于自身阶级的任务连续失败5次，或同阶级任务连续失败10次，将直接降级；挑战高于自身阶级的任务失败不降级，但连续失败5次后将永久失去跨阶接单资格。
- 原文依据："升级的条件如下所示：F→E：完成十次F级工作，或是连续五次达成E级工作。E→D：完成五十次F级工作，或是完成二十五次E级工作，或是连续达成十次D级工作。后面的层级虽然规定次数增加很多，但也是类似的内容。此外，连续失败会被降级。比自身层级还低的工作连续失败五次，或是相同层级的工作连续失败十次都会遭到降级。至于没能完成比自身层级高的工作虽然不会导致降级，但连续失败五次后会再也无法承接。"

- 名称：冒险者队伍「Super Blaze」
- 内容：B级冒险者队伍，由猪头魔族队长布雷兹率领，全队共6人，成员涵盖多种族老手冒险者。在石化之森执行白牙大蛇讨伐任务时偶遇变异高阶种赤食大蛇，全员战死覆灭。
- 原文依据："B级队伍『Super Blaze』。……一开口就以火大表情讲出这种话的人是『Super Blaze』的队长布雷兹。……他们的队伍由各式各样的种族构成，共有六人。"、"让布雷兹他们全灭的魔物非常巨大。是赤食大蛇。……躯体有一部分整个鼓起，我想那里面有一半大概是那只猪的肉吧。"

- 名称：冒险者队伍「多库拉布村愚连队」
- 内容：D级冒险者队伍，由队长库尔特及鸟人少年加布林等三名年轻魔族组成。承接石化之森采集谜之卵的委托，因错判难度遭刽子手与杏仁巨蟒夹击，加布林阵亡，剩余两人在获救后护送同伴遗体退出森林返回城镇。
- 原文依据："D级队伍『多库拉布村愚连队』。……『多库拉布村愚连队』队长的库尔特一脸不高兴地回答。"、"那个少年等于是被我害死的。……那个被砍成两半死掉的少年。他的脸上有鸟嘴，记得是叫作加布林吧？"

- 名称：冒险者队伍「Dead End」
- 内容：鲁迪乌斯、艾莉丝、瑞杰路德的小队。历时三周成功升上D级（已解锁承接C级委托权限）。在石化之森击溃刽子手、群聚杏仁巨蟒并独立猎杀A级巨兽赤食大蛇。此为该小队在利卡里斯镇承接的最后一个委托。
- 原文依据："过了三个星期，我们升上D级。……现在是D级，换句话说可以承接C级的工作。"、"──而这次的委托，也成为我们在利卡里斯镇承接的最后一个任务。"

## 三、力量体系 / 魔法 / 技能
- 名称：复合爆炸岩炮弹（土火复合魔术）
- 规则：将岩炮弹弹头塑形为破甲高速的楔形尖锐结构，同时在石质弹体内部注入延时引爆的火魔术，能够在命中或贯穿目标躯体的瞬间产生二次爆破。
- 原文依据："形状设定为楔形，内部还藏有火魔术，让岩炮弹在击中魔物后能够爆炸。发射。炮弹以超高速往前飞，直冲赤蛇，直接引发大爆炸──我原本是这样盘算。"

- 名称：泥沼限制与重力落石组合术
- 规则：针对冲锋型重甲强敌，先以软泥沼术软化其脚下土质使其单足深陷失去平衡前扑，随后在敌人正上方凭空凝聚巨大岩石借重力加速度猛砸压制。
- 原文依据："我冷静地在刽子手脚边设置柔软的泥沼，它一只脚深深陷入，往前倒下。接着在正上方制造出巨大岩石，把它狠狠砸烂。"

- 名称：斯佩路德族额头第三之眼的透视感知
- 规则：斯佩路德族额头宝石（第三之眼）具备穿透障碍的生物与个体辨识能力，即使被遮光防具（如内置铁板的护额）覆盖，其侦测与视觉分辨能力依然不受阻碍。
- 原文依据："虽然不知道瑞杰路德的第三只眼看出去是什么情况，不过就算被护额盖住也依然保有视力，甚至还能识别个体。"

- 名称：强力魔物的动态视力与魔术回避能力
- 规则：B级及以上的强力魔兽与人型怪物（如刽子手、赤食大蛇）拥有超越常理的动态视力与神经反应，能准确看清飞行的远程攻击魔术轨迹并在受击前做出规避动作。
- 原文依据："赤食大蛇扭动身体，避开岩炮弹。这回避不是偶然，很明显赤食大蛇是先看清飞向它的岩炮弹，然后才做出闪避动作。"、"仔细想想，碰上刽子手时也一样。原本以为会直接命中的攻击却被敌人避开，结果只打断一根手臂。B级以上的魔物就能够回避魔术吗？"

- 名称：冒险者尸骸不死转化机制（刽子手形成）
- 规则：战死在魔大陆危险地区的冒险者遗骸若未按规定彻底火化深埋，会受魔力影响转化为身披厚重板甲手持巨剑的僵尸怪物“刽子手”，保留生前战斗技巧。
- 原文依据："刽子手是人型的魔物，实体是由死掉的冒险者变成的僵尸。而这个僵尸不知道为什么会装备着巨大的剑和厚重的全身铠甲。"、"至于布雷兹一行人的尸体，先把能卖钱的东西都搜括一空后，再放火烧过埋葬起来。要是把尸体丢着不管，是不是会变成刽子手呢？"

## 四、种族 / 生物
- 名称：猪头魔族
- 特征：头部为野猪外貌的魔族分支，体格健壮，性格暴躁粗野，代表人物为「Super Blaze」队长布雷兹。
- 原文依据："因为他的头就是猪，和那个以猥亵视线看着艾莉丝的门口卫兵应该是同样种族吧？"

- 名称：鸟人魔族
- 特征：面部生有鸟嘴等禽类特征的魔族亚种，代表人物为加布林。
- 原文依据："他的脸上有鸟嘴，记得是叫作加布林吧？"

- 名称：刽子手
- 特征：B级人型僵尸魔物，由战死冒险者转化而来。身披沉重全身铠甲、手持双手巨剑，具备较高剑术水准与不合体重的突进速度，生命力极顽强。其被击杀消亡后，身上的武器与板甲亦会随之烟消云散，无法作为战利品出售。
- 原文依据："刽子手是人型的魔物，实体是由死掉的冒险者变成的僵尸。而这个僵尸不知道为什么会装备着巨大的剑和厚重的全身铠甲。由于铠甲很重，动作并不是那么快，不过很顽强而且拥有剑技。明明基本上是单体活动，外型尺寸也不是很大，却是B级的强敌。死掉之后剑和铠甲会消失，所以无法换钱。"

- 名称：杏仁巨蟒
- 特征：B级蛇形魔物，全长约3米，体表具杏仁状斑纹。通常以3至5只的小群体活动，牙藏剧毒，身法敏捷难以捕捉，为石化之森标志性危险魔物之一。
- 原文依据："杏仁巨蟒是三～五只成群出现的魔物，身上有类似杏仁的花纹。长度大约是三公尺，牙齿有剧毒，动作也很灵敏。因为难以打倒且数量又多所以是B级，也是强敌。"

- 名称：白牙大蛇
- 特征：B级蛇类魔兽，体表呈白色，长有白牙，栖息于石化之森。
- 原文依据："布雷兹的委托：『讨伐石化之森出现的白牙大蛇』。"、"赤食大蛇是白牙大蛇的高阶种。……白牙大蛇是B级"

- 名称：赤食大蛇
- 特征：白牙大蛇极罕见的上位变异高阶种，评级等同于A级。体长约10米，躯干粗大超数人合抱，颈部可向外扩张示威。覆盖着具备耐火属性的坚韧硬鳞，毒牙锋利无比，不仅体格庞大而且极度敏捷，能闪避高速魔术与枪刺，可轻易团灭B级冒险者整队并将其整只吞食。其肉可食用，其卵体积硕大。
- 原文依据："让布雷兹他们全灭的魔物非常巨大。是赤食大蛇。这条红色大蛇的躯干粗壮到即使我和艾莉丝牵起手来也无法抱住，长度大概有十公尺，颈部还向外张开，像是意图威吓。……赤食大蛇是白牙大蛇的高阶种。不但拥有比白食大蛇更巨大的躯体，连敏捷性也大幅领先。全身覆盖着具备火抗性的坚硬鳞片，尖锐的牙齿带有剧毒。……赤食大蛇却是等同于A级的强敌。"

## 五、物品 / 道具 / 武器
- 名称：魔大陆四级货币体系（绿矿钱 / 铁钱 / 屑铁钱 / 石钱）
- 说明：魔大陆通行的成套货币进制。已知换算基准：1绿矿钱 + 7铁钱 + 14屑铁钱 + 35石钱 = 1875石钱。按购买力估算在阿斯拉王国尚不足两枚阿斯拉大铜币。
- 原文依据："现在持有的金钱是绿矿钱一枚、铁钱七枚、屑铁钱十四枚、石钱三十五枚。全部换算成石钱是一八七五枚。一千八百七十五日币……就算付出所有财产，也无法换到两枚阿斯拉大铜币。"

- 名称：赤食大蛇的毛皮与毒牙
- 说明：A级变异巨蛇身上的战利品素材。毒牙锋利含剧毒可换取报酬，蛇皮坚硬厚实可剥离卷曲成毯状带回。
- 原文依据："拔走牙齿，然后把剥下来的蛇皮像毯子一样卷起。"

## 六、历史 / 传说 / 事件
- 事件名：「Super Blaze」石化之森全灭覆亡事件
- 内容：利卡里斯镇老牌B级队伍「Super Blaze」全员6人在石化之森遭遇极罕见出现的A级赤食大蛇，实力悬殊惨遭团灭吞噬。
- 原文依据："让布雷兹他们全灭的魔物非常巨大。是赤食大蛇。……我记得他们是六人队伍吧……剩下的两人呢？『死了。』似乎是全灭。"

## 七、社会规则 / 习俗 / 文化
- 内容：危险区域入口的“队长碰头会”行规：冒险者各小队在进入同一森林或迷宫险地前，各队队长依例必须在入口处面对面开会，确认彼此承接的委托与路线，避免中途发生利益摩擦或意外冲突。
- 原文依据："据说这是冒险者的常识，要是在森林等地方的入口意外碰上其他队伍，基本上要先和对方开个会。"

- 内容：公会撞单（Double Booking）时的处置潜规则：当公会管理出现疏漏贴出重合或关联委托时，业内一律遵循“先到先得、各凭本事、拒绝结伴当保姆”的冷酷竞争原则。
- 原文依据："『就是有不同人在同一时期提出类似委托，但是公会却没有管理好，全都贴出来徵求的状况。』……『那么，这种情况该怎么办？』『没什么怎么办，先抢先赢啊。』"、"『所以你意思是要大家一起去找？要我们当保母吗？』……B级的布雷兹是不愿意让我们和库尔特他们这两支队伍像金鱼大便一样紧粘着他们，还轻轻松松地达成委托吗？因为那种做法只有布雷兹他们的负担会增加。"

- 内容：冒险者身份与死亡觉悟：在魔大陆，凡踏上冒险者道路者（哪怕外表尚是少年）均被视作自立自负的战士，必须随时背负丧命的觉悟与选择风险的全部责任，不应以“未成年小孩”自居寻求大人的无条件庇护。
- 原文依据："『我们不是小孩！是冒险者！鲁迪乌斯身为队长的判断很正确！』……『看也知道！的确我们也想要就这样三个人一直走下去！可是，我们也早就做好有一天会丧命的心理准备！既然身为冒险者，不管是年轻人还是老人，大家都抱着这种觉悟！』"

- 内容：瑞杰路德心中的“战士信条”：在瑞杰路德的道德框架中，“战士”的核心定义是恪守尊严、绝不危害并竭力保护小孩子，以及誓死守护与看重同伴。一旦对方以战士之姿做出觉悟，他便会尊重其身为战士的尊严而非强加保护。
- 原文依据："『对瑞杰路德先生来说，战士是什么？』『战士就是保护小孩，重视同伴的人。』……战士不可以危害小孩。战士有义务保护小孩。战士不可以舍弃同伴。战士必须保护同伴。"

- 内容：野外遇难冒险者的拾荒与埋葬礼仪：遇到在荒野战死的冒险者遗体，同行冒险者会搜刮其身上所有残存财物，随后必须施以火化并埋葬，以防止尸体化为僵尸类魔物。
- 原文依据："至于布雷兹一行人的尸体，先把能卖钱的东西都搜括一空后，再放火烧过埋葬起来。要是把尸体丢着不管，是不是会变成刽子手呢？"

- 内容：魔大陆少年的感谢亲吻礼节：库尔特在道别时执起艾莉丝的手，亲吻拇指掌根部位以示崇敬与感激，属于当地表达心意的一种举止。
- 原文依据："他握起艾莉丝的手，在大拇指连接手掌的地方亲了一下。接着，库尔特带着满脸笑容离开。"
