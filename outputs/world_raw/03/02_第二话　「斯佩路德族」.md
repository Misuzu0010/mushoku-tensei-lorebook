# 第二话　「斯佩路德族」 世界设定提取

## 一、地理与场所
- 名称：比耶寇亚地区
- 内容：位于魔大陆东北方的区域，邻近旧奇希里斯城。地表环境极其荒凉安静，入夜后呈现干涸龟裂的大地，到处都是岩石，几乎看不到草木植物，甚至没有昆虫生存鸣叫的迹象。
- 原文依据："只见乾涸龟裂的大地在夜空下往外延伸，几乎看不到草木等植物。是连昆虫都没有吗？除了篝火发出的声音，没听到其他任何声响。"、"「这里是魔大陆东北方的比耶寇亚地区，靠近旧奇希里斯城。」"

- 名称：旧奇希里斯城
- 内容：位于魔大陆东北区域的城址/地名，邻近比耶寇亚地区。
- 原文依据："「这里是魔大陆东北方的比耶寇亚地区，靠近旧奇希里斯城。」"、"的确，奇希里斯城位于魔大陆的东北区域。"

- 名称：魔大陆与中央大陆的地理距离与交通路线
- 内容：魔大陆东北区域与阿斯拉王国在世界地图上分列于对角线的两端，距离极度遥远。且该世界的航运船只仅能通过限定的几条固定航线，因此两地往返必须走陆路绕极大一圈。
- 原文依据："魔大陆的东北区域和阿斯拉王国在地图上分别位于对角线的两端，彼此之间的距离远得跟从拉斯维加斯到巴黎差不多。而且在这个世界里，船只只能通过限定的几条航线，因此必须走陆路绕好大一圈。"

## 二、组织与势力
无

## 三、力量体系 / 魔法 / 技能
- 名称：斯佩路德族额部感觉器官
- 规则：斯佩路德族额头中央天生具有类似红色宝石的感觉器官，具有感知功能 [存疑]。
- 原文依据："额头上有类似红色宝石的感觉器官。"

## 四、种族 / 生物
- 名称：斯佩路德族
- 特征：魔族中的一个种族。外貌特征为翠绿色的头发、宛如白瓷的雪白皮肤，额头正中央长有宛如红色宝石的感觉器官；战士通常随身配备三叉枪。极度重视战士威信，信条是“战士一旦下了决定就绝不更改”，并且“保护幼童、绝不抛下小孩子不管”。可以使用人族语言顺畅交流，并不吃小孩。全族统一拥有固定的种族姓氏“斯佩路迪亚”。自拉普拉斯战役之后，在全世界范围内遭受所有种族无差别的排挤、畏惧与迫害，被外界视作绝对的邪恶。
- 原文依据："翠绿色的头发，宛如白瓷的雪白皮肤，额头上有类似红色宝石的感觉器官。一道伤痕纵贯整张脸，眼光锐利，表情严肃。给人一种危险的印象。最骇人的，是放在旁边的三叉枪。"、"「不，斯佩路德的战士一旦下了决定绝对不会改变心意。」"、"「要是丢下小孩子不管，会伤害到斯佩路德族的威信。」"、"「我们不吃小孩。」"、"在战争后，斯佩路德族持续受到迫害。对其他魔族的歧视似乎有逐渐改善的倾向，但只有对斯佩路德族的态度显得特别异常。就像是二战中的日本人对美军那样，所有种族都毫无理由地厌恶他们。这种态度彷佛是在宣扬：「如果这世上有绝对的邪恶，肯定就是斯佩路德族没错。」"

- 名称：魔族的固定姓氏特征
- 特征：魔族中部分特定种族拥有全族固定的姓氏（例如斯佩路德族的“斯佩路迪亚”，米格路德族的“米格路迪亚”）。与人族普及家族姓氏不同，魔族基本上不取家族姓氏，仅有特定种族继承固定姓氏，或极少数个体自我取名。
- 原文依据："某些特定的魔族，每个种族各自拥有固定的姓氏。基本上只有人族会取家族用的姓氏，不过听说偶尔也会有其他种族因为吃饱太闲而自我取名。顺道一提，洛琪希的姓氏是米格路迪亚。"

## 五、物品 / 道具 / 武器
- 名称：斯佩路德族三叉枪
- 说明：斯佩路德族战士随身携带的标志性武器，外表令人生畏。
- 原文依据："最骇人的，是放在旁边的三叉枪。"

- 名称：斯佩路德族民族服装与斗篷
- 说明：具有浓厚民族特征的服饰，带有刺绣花纹的背心与长裤（印第安人风格），并配有能供露营保暖使用的斗篷。
- 原文依据："在昏暗的火光下观察，他身上穿着充满民族特徵的服装。如果要形容得具体点，大概算是印地安人风格吧？就是那种有刺绣花纹的背心和裤子。"、"不知道为什么，艾莉丝身上盖着类似斗篷的东西。"、"艾莉丝把她身边那件类似斗篷的东西（我想应该是瑞杰路德的个人物品）盖在我身上。"

- 名称：魔杖「傲慢水龙王」
- 说明：艾莉丝在鲁迪乌斯十岁生日时赠送的高级魔杖，在此次转移灾害中伴随掉落至身边。
- 原文依据："另外，可以看到我的魔杖「傲慢水龙王」也放在她背后的地上。那是几天前过十岁生日时，艾莉丝才刚送我的高级魔杖。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：距今五百年前爆发、人族与魔族交锋长达一百年以上的大战。战后斯佩路德族受到全方位的严重迫害与歧视，至今仍被全大陆所有种族深恶痛绝。
- 原文依据："我学过关于拉普拉斯战役的历史。那是一场从五百年前开始，人族和魔族交战了一百年以上的战争。也知道在战争后，斯佩路德族持续受到迫害。对其他魔族的歧视似乎有逐渐改善的倾向，但只有对斯佩路德族的态度显得特别异常。"

## 七、社会规则 / 习俗 / 文化
- 内容：交通航运受限规则——该世界船运仅开放少数几条特定安全航线，无法任意航行跨海，长途跋涉通常必须沿陆路绕远路通行。
- 原文依据："而且在这个世界里，船只只能通过限定的几条航线，因此必须走陆路绕好大一圈。"

- 内容：幼儿哄睡迷信与种族妖魔化——人族（如阿斯拉王国贵族家庭）常以斯佩路德族作为哄孩子睡觉的恐吓素材（如“不早点睡觉就会被斯佩路德族吃掉”），导致人族孩童自幼建立极端恐惧心理。
- 原文依据："「母亲大人说要是我不早点睡觉，就会被斯佩路德族吃掉。」原来如此，是被当成用来哄小孩睡觉的迷信吗？"

- 内容：斯佩路德族战士守则——言出必行，诺言一旦立下绝不违背；视呵护救助孩童为本族战士威信的基石。
- 原文依据："「不，斯佩路德的战士一旦下了决定绝对不会改变心意。」"、"「要是丢下小孩子不管，会伤害到斯佩路德族的威信。」"

- 内容：种族命名习俗——人族以家族为单位使用家族姓氏；魔族绝大多数无家族姓氏，唯有某些特定种族全族共享固定的种族姓氏。
- 原文依据："某些特定的魔族，每个种族各自拥有固定的姓氏。基本上只有人族会取家族用的姓氏，不过听说偶尔也会有其他种族因为吃饱太闲而自我取名。"

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希告诫“绝对不要靠近斯佩路德族，也不要和对方搭话”；艾莉丝母亲灌输“不听话就会被斯佩路德族吃掉”；世人普遍认为斯佩路德族是毫无理智、凶恶恐怖、吃小孩的绝对邪恶存在。
- 原文是否暗示另有真相：是。瑞杰路德不仅主动升火救助照顾两个小孩，甚至愿意护送他们回中央大陆；其性格耿直、富有同理心且喜爱孩童，并亲口澄清“我们不吃小孩”；洛琪希本人其实从未见过斯佩路德族；斯佩路德族的恶评源于战后全大陆普遍盲从的偏见迫害。
- 原文依据："「不要靠近斯佩路德族，也不要和对方搭话。」"、"「斯佩路德族会！会……会吃……吃小孩啊！」" 对比 "「我们不吃小孩。」"、"「人族的小孩非常脆弱，所以我升起火堆让你们取暖。」"、"洛琪希虽然说过要我别接近斯佩路德族，但也说过实际上她并没有亲自遇过他们。"、"瑞杰路德以战战兢兢的态度把手放到我头上，然后带着迟疑摸了几下。看到我没有拒绝，他露出松了口气的表情。"

- 角色以为：鲁迪乌斯推测瑞杰路德可能是人神派来串通好的使者。
- 原文是否暗示另有真相：否。瑞杰路德完全不知道“人神（Hitogami）”是谁，只是单纯路过救助了从天而降的孩子。
- 原文依据："「你是神的使者吗？」听到这提问，男子歪了歪脑袋。「虽然我不懂你为什么这样问，但你们是从天上掉下来的。」"、"「话说回来，你有听过人神这种存在吗？」……「HITOGAMI？没有，那是人名吗？」"
