# 第一话　「自称神的骗子」 世界设定提取

## 一、地理与场所
- 名称：魔大陆
- 内容：位于世界角落的大陆。大地呈红褐色。自然环境极其严苛，几乎没有食物可吃，魔物的数量多到与中央大陆根本不在同一个层次。此外，魔大陆的常识与中央大陆相差极大。
- 原文依据："费尽千辛万苦终于紧急煞住，掉到红褐色的大地上。"、"毕竟魔大陆是个严苛的地方嘛，几乎没东西可吃，魔物的数量也多到和中央大陆根本是不同层次。你好像会说那边的语言，不过其实连常识也相差很多喔。"、"所谓的魔大陆，就是那个位于世界角落的那块大陆？"

- 名称：中央大陆
- 内容：本章对照魔大陆提及的大陆，魔物数量和常识规范均与魔大陆不同层次。
- 原文依据："魔物的数量也多到和中央大陆根本是不同层次。"

- 名称：全白的空间（精神空间）
- 内容：鲁迪乌斯在梦中/意识中进入的纯白空间，内部空无一物。在这里鲁迪乌斯的外貌显现为前世三十四岁死宅的模样（精神体），人神在此处与鲁迪乌斯的精神体进行直接沟通。
- 原文依据："睁开眼睛的瞬间，我发现自己待在一个全白的空间里，而且这里什么都没有。"、"眼前是三十四年以来已经看惯的那个模样。"、"「是你的精神体，另外还有肉体。」"、"「哎呀，这可不是普通的梦喔，我是直接和你的精神沟通。」"

## 三、力量体系 / 魔法 / 技能
- 名称：魔力灌注双眼（视觉动态强化）
- 规则：将体内魔力高度集中灌注到双眼上，能让高速运动中眼前的景象与流速在一瞬间产生变慢的效果。
- 原文依据："我更加集中意识，把魔力灌注到双眼上。于是，只有一瞬速度变慢了。"

- 名称：精神托梦与跨界感应（人神权能） [存疑]
- 规则：直接与目标的精神沟通，通过梦境跟人对话，人神自称这种能力只有自己能够办到。
- 原文依据："「哎呀，这可不是普通的梦喔，我是直接和你的精神沟通。」"、"「像透过梦境跟人对话这种事，只有我能办到耶。」"

- 名称：转生术（坏龙神权能） [存疑]
- 规则：让人转生的手段，人神声称自己办不到，并指称转生是坏龙神的拿手把戏。
- 原文依据："「基本上，我才没办法让人转生呢，这种事情是坏龙神的拿手把戏。」"

- 名称：大规模魔力灾害转移
- 规则：由于大规模魔力灾害的爆发，产生的光芒会将受灾范围内的人员跨越大陆强制转移到遥远地点。
- 原文依据："「你啊，是被大规模的魔力灾害波及才会转移到那里。」"、"魔力灾害……是指那道光吗？"、"「对，就是那道光。」"、"转移……原来那是转移啊……"

## 四、种族 / 生物
- 名称：人神（Hitogami）
- 特征：自称神明。脸庞平板偏白，面带笑容，但五官毫无特征；旁人只要确认其五官样貌，记忆就会立刻从脑海中消失无法记住，呈现出整个人宛如被打上马赛克的模糊印象。声音中性分辨不出男女。自称无法将人送回六面世界以外的异世界，也无法让人转生；声称一直在观察鲁迪乌斯并给予行动建议。
- 原文依据："对方有张平板偏白的脸，正露出笑容可掬的表情。但是没有什么特徵。一确定对方拥有这种模样的五官后，记忆立刻从脑海中消失，实在无法记住。或许是因为这样，给人一种全身似乎都被打上马赛克的印象。"、"声音很中性，听不出来是男还是女。"、"「算了，我是神，人神。」"、"「就算是我，也无法把你送回六面世界以外的异世界。」"

- 名称：坏龙神（龙神） [存疑]
- 特征：人神口中提及的存在，人神声称让人转生是其拿手绝活。
- 原文依据："「基本上，我才没办法让人转生呢，这种事情是坏龙神的拿手把戏。」"

- 名称：魔大陆的魔物
- 特征：生态极为凶残密集，数量多到与中央大陆完全是不同层次。
- 原文依据："魔物的数量也多到和中央大陆根本是不同层次。"

## 六、历史 / 传说 / 事件
- 事件名：大规模魔力灾害（转移事件）
- 内容：先前在罗亚城上空出现的大规模异变与光芒，被证实为一场大规模魔力灾害，灾害发生后导致鲁迪乌斯等人被强制转移到了遥远的魔大陆。
- 原文依据："「你啊，是被大规模的魔力灾害波及才会转移到那里。」"、"魔力灾害……是指那道光吗？"、"「对，就是那道光。」"、"转移……原来那是转移啊……"

## 七、社会规则 / 习俗 / 文化
- 内容：魔大陆拥有本地专门的语言（鲁迪乌斯先前已学会），且魔大陆的风土人情、生存法则和日常常识与中央大陆相差甚大。
- 原文依据："「毕竟魔大陆是个严苛的地方嘛，几乎没东西可吃，魔物的数量也多到和中央大陆根本是不同层次。你好像会说那边的语言，不过其实连常识也相差很多喔。」"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯在纯白空间中看见自己前世三十四岁的身体，以为转生到异世界的十年生活只是一场美梦，自己已经梦醒并回到了前世的现实。
- 原文是否暗示另有真相：是。人神指出鲁迪乌斯看见的仅是精神体，转生后的异世界肉体平安无事，从梦中醒来后身体就会恢复原样。
- 原文依据："我感觉这十年来宛如一场梦，心中的失望感油然而生。直觉领悟自己回到过去后，我很乾脆地接受了这个现实。果然只是梦啊。" 对比 "「不不，你别误会。我不是指前世，而是在讲今生的事情。」……「是你的精神体，另外还有肉体。」「当然，肉体也平安无事。」「YES！这是梦，醒来之后，你的身体会恢复原样。这下放心了吗？」"

- 角色以为：鲁迪乌斯认为人神极度可疑，跟网络游戏中的诈骗犯一样，散发着欺骗和玩弄他人的危险意图，根本不值得信任。
- 原文是否暗示另有真相：不明。人神自称站在鲁迪乌斯这边，动机是对少见的异世界人感到好奇与有趣；人神给出的最初建议为“醒来后依靠附近的男子，并帮助对方”，但其动机是善是恶、真实意图究竟为何目前无法判明。
- 原文依据："没错，很可疑，散发出满满想要骗我的气势。" 对比 "「我站在你那一边喔。」"、"「是因为你活着好像会很有趣，这理由不就够了吗？」"、"「鲁迪乌斯，你听好了。当你清醒后，要依靠附近的男子，然后帮助对方。」"

- 角色以为（人神自述之事实性）：人神声称“透过梦境跟人对话这种事只有我能办到”、“转生是坏龙神的拿手把戏”。
- 原文是否暗示另有真相：不明 [存疑]。目前仅有人神一面之词，缺乏其他事实交叉印证。
- 原文依据："「像透过梦境跟人对话这种事，只有我能办到耶。」"、"「基本上，我才没办法让人转生呢，这种事情是坏龙神的拿手把戏。」"
