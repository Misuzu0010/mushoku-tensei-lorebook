# 第七话　「冒险者公会」 世界设定提取

## 一、地理与场所
- 名称：利卡里斯镇冒险者公会大厅与设施布局
- 内容：大厅装有巨大双开式木门，环境喧闹粗野。大厅左侧为张贴大量委托羊皮纸的巨大告示板；右侧设有一排四个高台柜台供职员受理事务；建筑物后方设有专门的魔物素材收购处。
- 原文依据："利卡里斯镇冒险者公会的巨大双开式大门突然被用力推开。"及"左边有一个贴满纸张的巨大告示板；右边并排着四个柜台，里面的职员愣愣地望着这边。……至于收购请前往本栋建筑物的后方，届时请不要弄错。"

- 名称：利卡里斯镇内门牌设施
- 内容：
  - 利卡里斯镇十二号：有红门的仓库（奥尔特族杜冈姆的仓库）。
  - 利卡里斯镇四号：足踏亭（卡南德族西尼多拉经营的餐馆）。
  - 利卡里斯镇二号：奇里布排屋三号室（霍加族梅赛儿的居所）。
- 原文依据："・地点：利卡里斯镇十二号，有红门的仓库"及"・地点：利卡里斯镇四号，足踏亭"及"・地点：利卡里斯镇二号，奇里布排屋三号室"

## 二、组织与势力
- 名称：冒险者公会（组织运作与核心规约）
- 内容：
  - 全球通用服务：在全世界范围内统一提供工作仲介、报酬转交、素材收购、货币兑换。公会资格全球通用，跨大陆无需重新登记。
  - 登录与管理：登录资料烧录于冒险者卡片由本人保管。遗失可补发，但层级重置为 F 级并处以地区罚款。自愿退出后再登录同样从 F 级重新开始。
  - 禁止行为与处分：严禁违反各国法律、贬低公会品格、妨碍他人委托、私下倒卖委托。违者剥夺资格并罚款；在魔大陆一旦被剥夺资格起码在此大陆永久禁止再次登录。
  - 违约责任：接下委托未能在半年内完成者，需支付报酬两成作为违约金，逾期未交剥夺资格。
  - 层级体系（Rank）：分为 S、A、B、C、D、E、F 七个层级。原则上只能承接自身层级以及上下各一级之委托（如 F 级仅限 F 与 E 级）。
  - 升降级：完成各层级规定指标委托后升级；冒险者亦可选择自愿留在当前层级；若连续任务失败达到一定次数会被强制降一级。
  - 强制义务：国家遭遇魔物侵袭等提出协助要求时有义务响应；紧急态势下必须遵从公会职员命令。
  - 魔大陆特则：魔大陆因诸多居民出生时无姓名且治安定义有别，公会准许使用假名登录，只要不给公会招致麻烦即可。
- 原文依据："二、服务内容 在全世界的冒险者公会，都提供工作仲介、报酬转交、素材收购、货币兑换等服务。……三、登录情报……四、退出冒险者公会……五、禁止行为……六、违约金相关……七、层级……八、升级与降级……九、义务……"及"「由于魔大陆对罪犯的定义和其他大陆并不相同，所以只要不给冒险者公会带来麻烦就没有问题。不过，请记得一旦冒险者资格遭到剥夺，起码在这个大陆上就再也无法登录。」……「因为魔大陆上有许多人出生时并没有名字。所以如果禁止使用假名，会导致非常多人无法登录。」"及"「在这里完成登录后，去到别的大陆还需要重新登录吗？」「不需要。」"

- 名称：冒险者队伍与集团制度
- 内容：
  - 人数上限：队伍人数上限为七人。
  - 队员资格：仅限与队长处于同等级或高低各一级的冒险者组队。
  - 层级与委托：队伍层级以全体成员层级的平均值计算；队伍可接委托以队伍层级为准。
  - 升级与自由度：完成委托后的升级点数由所有队员共享；成员在编队状态下仍保留以个人名义承接委托的权利。
  - 入队与退队：加入队伍须经队长与公会共同许可；成员退出只需公会核可；队长享有强制开除队员的权限；队长阵亡队伍自动解散。
  - 集团概念：两支以上队伍可进一步联合结成“集团”，公会对出色集团予以优惠。
- 原文依据："・队伍的人数上限是七人。・只有和队长同级或是高低各一级的冒险者能加入队伍。・能承接的委托会根据队伍的层级决定。・队伍的层级是成员的平均值。・所有成员都能获得成功完成委托时的升级值。・即使加入队伍，也能够以个人身分承接委托。・加入队伍时，必须获得队长和公会的核可。・退出队伍时，只需要公会的核可。・队长拥有强制成员退出的权限。・当队长死亡时，队伍将自动解散。・两支以上的队伍可以组成集团。・公会将提供优秀的集团各式优惠。"

- 名称：队伍「Dead End」
- 内容：鲁迪乌斯、瑞杰路德与艾莉丝于利卡里斯镇公会登记建立的冒险者小队，初始队伍层级为 F 级。
- 原文依据："「那么，您要使用的队伍名称是什么呢？」「是『Dead End』。」……「队伍：Dead End（F）」"

## 三、力量体系 / 魔法 / 技能
- 名称：委托层级与魔物实力分布
- 规则：
  - F 级与 E 级：均为城镇内部日常杂务类委托（如仓库重物搬运、饭馆帮厨、算账、寻回失踪宠物、清扫除虫等）。
  - C 级及以上：魔物讨伐类委托限定 C 级以上冒险者承接。魔大陆环境险恶，野外不存在如哥布林般弱小的魔物。
  - S 级委托：包含讨伐盘踞在北方的落单巨龙等极度凶险的任务。
- 原文依据："「但是讨伐类的委托要C级以上才有。」「C级以上才有吗？」「看起来是这样。」「可是我听说过一开始可以讨伐哥布林之类的魔物耶？」「这个大陆上没有那么弱的魔物。」"及"「没有能和龙战斗的委托吗？」「在S级的委托里有，就这张。」……「上面写着北边有一只落单的龙住下来不走了。」「打得赢吗？」「最好不要挑战，因为龙很强。」"

## 四、种族 / 生物
- 名称：魔族亚种（公会魔族多样性）
- 特征：魔大陆居民魔族包含大量体貌特异的亚种群体。大厅中可见猪头男性、蛇躯下身女性、背生飞翼男性、生有马蹄双腿女性、马脸男性、前臂为螳螂巨镰的男性、背生蝴蝶双翅女性、双肩生刺者、全身蓝肤者、四臂魔族以及双头魔族等。
- 原文依据："外型像猪的男子，下半身是蛇的女子；长着翅膀的男性，拥有马脚的女性。各式各样的种族聚集在此……长着马脸的男性，身上有螳螂镰刀的男性；背后有类似蝴蝶翅膀的女性，以及下半身跟蛇差不多的女性。……肩膀上长着像刺的东西，有人全身的皮肤都是蓝色。还看到长着四只手臂的家伙，甚至是生着两颗脑袋的人。"

- 名称：奥尔特族 / 卡南德族 / 霍加族
- 特征：魔大陆的魔族氏族种族名。本章出现的杜冈姆为奥尔特族，西尼多拉为卡南德族，梅赛儿为霍加族。
- 原文依据："・委托人姓名：奥尔特族的杜冈姆"及"・委托人姓名：卡南德族的西尼多拉"及"・委托人姓名：霍加族的梅赛儿"

- 名称：变温蛙形魔族（佩尔多克）
- 特征：长有黑斑纹的蓝色青蛙脸外貌，拥有细长双腿，激动或受辱时皮肤会从蓝色充血转为红色，兼具变温两栖动物特征。
- 原文依据："是只有黑色斑点花纹的蓝色青蛙，脸颊整个鼓起……挡在他前方的那只脚就跟青蛙脚一样显得又细又长……青蛙男的蓝色脸孔很快变成红色。果然他也是变温动物吗？"

- 名称：马面魔族（诺克巴拉）
- 特征：长着马头、身材健硕肌肉发达的魔族男性冒险者。
- 原文依据："有个长着马头，浑身肌肉的男子。我记得他就是刚刚出面阻止争执的那个家伙。……「不过诺克巴拉……」"

- 名称：龙
- 特征：栖息于魔大陆北部等地的极强悍魔物，具备极高危险度与战斗力，属于冒险者公会 S 级讨伐委托的对象。
- 原文依据："「上面写着北边有一只落单的龙住下来不走了。」「打得赢吗？」「最好不要挑战，因为龙很强。」"

## 五、物品 / 道具 / 武器
- 名称：冒险者登记鉴定魔道具
- 说明：约游戏光盘包装盒大小的透明平板，中央刻印魔法阵，底部附带金属底板。申请者将手掌贴合于板面上，职员轻敲角落触发红光，即可自动读取申请者的性别、种族和生理年龄，连同职员录入的名字与职业一并刻录至下方的金属卡片。
- 原文依据："职员准备的东西是一个大小和色情游戏外盒差不多的透明板子，正中央刻着魔法阵，下面还垫着金属制卡片。……我头一个把手整个贴上去之后，职员轻轻敲打板子的角落。……魔法阵发出微弱的红色光芒，然后立刻消失。"及"姓名、职业、层级等部分似乎是由职员手动输入，但性别、种族、年龄是不是从放在板子的手上读取到的呢……"

- 名称：冒险者卡片（魔道具卡片）
- 说明：
  - 外观形态：铁板质感的金属薄片，表面文字浮现发光字迹，记载姓名、性别、种族、年龄、职业、层级及所属队伍。
  - 多语言转换机制：卡片默认根据持有人血统浓淡显示其所属种族的母语文字（如人族语、魔神语）；持卡者若用手指按压卡片正中心并念出指定语言名称（如兽神语、斗神语等），卡片文字会自动切换为对应语种。
  - 能源维持与充能：内置微型魔力结晶维持运作，正常魔力可支撑约一年；每次结算完成委托时公会免费补充；魔力耗尽内部数据不丢失，过度频繁切换语言会加速魔力耗尽。
- 原文依据："在一片没有特别之处的铁板上，以发出朦胧光芒的文字写着以下内容……「因为文字会随着种族变化。」……「虽然也有语言混杂出现的情况，但基本上会以血统较浓的种族语言来显示。」「如果是那种情况，只要用手指按住卡片正中央，然后讲出想要变更的语言即可。」……「要是变换太多次，会让卡片的魔力提早耗尽，请多注意。」……「魔力通常可以维持一年左右，而且每次完成委托时都会顺便补充，因此一般来说并不会耗尽。」「补充魔力需要多少费用？」「不需费用……」"

## 七、社会规则 / 习俗 / 文化
- 内容：魔大陆语言与文化多样性
  魔大陆公会与社交普遍以“魔神语”交流；此外世间还存在斗神语、兽神语、人族语等主要语种。魔大陆许多居民自幼无名，法律与犯罪界定与外大陆大相径庭，公会态度崇尚实用自由。
- 原文依据："顺道一提，公会内的对话全都使用魔神语。"及"「魔神语」、「斗神语」。"及"「因为魔大陆上有许多人出生时并没有名字。所以如果禁止使用假名，会导致非常多人无法登录。」"

- 内容：冒险者公会的江湖风气
  公会环境粗暴狂放，崇尚强力实力，老资格冒险者试探、挑弄、恶整新人（如设伏绊倒）屡见不鲜；但原则上避免在公会内部闹出动刀动枪的恶性冲突。
- 原文依据："冒险者公会……实际环境却更加粗野。……有一只脚挡在我的前进方向上。那只脚的主人是一个看起来真的非常狂妄的家伙。……「这年头根本不流行恶整菜鸟了吧？」"

- 内容：大众对斯佩路德族特征的固化认知
  魔大陆普遍深信斯佩路德族的发色绝对是“鲜亮的翠绿色”，若看到暗蓝发色便笃定是冒名假货；同时外界虽对“Dead End”之凶名极为忌惮，却普遍并不知晓其全名为“瑞杰路德・斯佩路迪亚”。
- 原文依据："因为斯佩路德族的发色是鲜亮的绿色，才不是那种又暗又脏的蓝色。"及"或许她并不知道「Dead End」的本名是瑞杰路德・斯佩路迪亚。毕竟从先前起，即使多次听到「Dead End」这外号，但是却没有人提到瑞杰路德的名字。"

## 九、角色认知 vs 客观事实
- 角色以为：公会里的所有冒险者与职员都认为，眼前这个蓝头发、额头有红宝石眼、脸有伤疤的男子，是个借用“Dead End”凶恶威名招摇撞骗的滑稽冒牌货（因为发色不是亮绿色，且自称救了小孩还登记成最低等 F 级）。
- 原文是否暗示另有真相：是。这名男子正是货真价实的“Dead End”瑞杰路德・斯佩路迪亚，只是被鲁迪乌斯使用果汁与染料将头发染成了暗蓝色以掩人耳目。
- 原文依据："因为斯佩路德族的发色……是绿色喔。下一瞬间，冒险者公会的大厅爆出了哄堂大笑声。"及"这些家伙，要是哪天知道瑞杰路德真的是「Dead End」，应该会哭着求饶吧……"

- 角色以为：鲁迪乌斯在填写申请表格时故意使用魔神语，希望隐瞒自己的人族身份，被别人当成年幼的魔族。
- 原文是否暗示另有真相：是。公会的魔法阵透明板能自动透过手掌直接读取并识别持有者的生理种族与实际年龄，直接在卡片上刻印了“种族：人族，年龄：十岁”。
- 原文依据："比起被当成人族，被误认为外表年轻的魔族反而比较方便。"及"不妙。原本想要隐瞒人族身分，结果年龄和种族名称都被显示出来了。"
