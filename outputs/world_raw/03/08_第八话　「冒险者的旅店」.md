# 第八话　「冒险者的旅店」 世界设定提取

## 一、地理与场所
- 名称：利卡里斯镇环形山谷日落特征
- 内容：由于利卡里斯镇坐落在高耸环形山的谷底，夕阳西下时高耸崖壁会早早投下阴影，导致城镇内部比外界天黑得更早。入夜后，崖壁上镶嵌的大量魔照石会发光照亮整座以泥土与石块建成的城镇。
- 原文依据："明明天色还亮，却只有城镇中显得莫名昏暗。过了几秒后，我才注意到是因为这城镇位于环形山的底部。由于周围有高耸的山壁，所以在夕阳西下时会形成阴影。"及"等太阳完全下山后，环形山的内部山壁照亮了以石头和泥土建造的这个城镇。让城镇看起来很像是晚上特地打灯照亮的游乐园。"

- 名称：狼之足爪亭
- 内容：利卡里斯镇内专为新人冒险者服务的实惠廉价旅馆。共拥有十二间客房，单晚住宿费为石钱五枚；加付一枚石钱附赠早晚两餐；两人以上组队入住同一房间可免收餐费；房间内部配备多张毛皮床且不加收房费。前厅兼营酒馆，划分有吧台区与用餐区。
- 原文依据："狼之足爪亭。共有十二间房，一晚石钱五枚。虽然建筑物陈旧，但保持针对冒险者新手服务的态度，价格很有良心。只要再多付石钱一枚，还会提供早晚餐。另外两人以上的冒险者组成队伍住在同一间房里，就可以免收饭钱。由于是服务新人的旅社，即使房间里有比较多张床，价钱还是一样。入口是酒馆兼大厅，位子实在不多，但有分为吧台区和用餐区。……房里并排着三张毛皮床。"

- 名称：梦境白色虚无空间
- 内容：人神（Hitogami）与鲁迪乌斯意识交汇的神秘领域，呈现纯白且空无一物的虚空之境。
- 原文依据："梦。这是个白色又空无一物的场所。同时，沉重又自卑的心情涌了上来。……眼前站着一个猥亵的家伙。"

## 二、组织与势力
- 名称：多库拉布村愚连队
- 内容：由多库拉布村出身的三名年轻魔族少年组成的冒险者小队，即将晋升至 D 级。成员包含队长库尔特（长角白发魔族少年）、巴奇洛（四臂魔族体魄强壮少年）、加布林（鸟嘴羽毛魔族少年）。
- 原文依据："少年先睁大双眼擦擦鼻子……开口报上名字：「……我叫库尔特，你呢？」……有四只手臂的大个子叫「巴奇洛」，长得像鸟的叫「加布林」……「三人组成『多库拉布村愚连队』！」……「因为我们快要升上D级，所以在讨论差不多想要找个女性魔术师加入。」"

## 三、力量体系 / 魔法 / 技能
- 名称：伯雷亚斯流格斗术（伯雷亚斯拳 / 伯雷亚斯踢）
- 规则：由艾莉丝祖父绍罗斯传授、经剑王基列奴严格训练磨砺而成的致命无武器实战体术。包括威力巨大、能直接将人打飞昏厥的转身直拳（伯雷亚斯拳）、正面正蹬踢（伯雷亚斯踢）以及连环膝撞追击。
- 原文依据："她才一回头，就使出伯雷亚斯拳。由绍罗斯传授，经过基列奴的训练才完成的转身直拳很正确地命中少年的脸。……伯雷亚斯踢。由绍罗斯传授，经过基列奴的训练才完成的正面抬脚踢正确地命中第二个人的胸口。……遭到艾莉丝以膝盖踢继续追击。"

- 名称：人神的入梦托梦能力
- 规则：自称神明的人神，能在特定时机强行潜入鲁迪乌斯的深层潜意识梦境，以全身打码的模糊人形显现，并给出极具诱导性且切中当前困境的预言建议（神谕）。
- 原文依据："「好啦，比起这种事情，我要给你下一个建议。」……「好好好……鲁迪乌斯，去承接寻找宠物的委托吧……那样一来你的不安就能解除……」"及"每次都挑准时机冒出来，那家伙绝对是邪神。是擅长刺激人心脆弱部分的邪神"

- 名称：生活魔术清洗衣物的物理损耗
- 规则：使用水魔术可快速洗净衣物，但若连续使用魔术强制烘干，魔力抽取水分的过程会严重损伤布料纤维，导致衣物脆化破损。
- 原文依据："虽说原本就是高档服装所以比较耐穿，而且利用魔术也能迅速洗好，但是靠魔术来烘乾其实很伤衣服质地，说不定以后会破掉。"

## 四、种族 / 生物
- 名称：长角魔族（库尔特所属族群）
- 特征：魔族亚种，额头生有独角，长有白发，具备一定肉体蛮力。
- 原文依据："那家伙额头上长着角，还有一头白发。"

- 名称：四臂魔族（巴奇洛所属族群）
- 特征：魔族亚种，生有四条手臂，肌肉发达魁梧。
- 原文依据："一个是长着四只手臂，有点粗壮，感觉成长后会人高马大的少年"及"有四只手臂的大个子叫「巴奇洛」"

- 名称：鸟型魔族（加布林所属族群）
- 特征：魔族亚种，长有鸟喙鸟嘴，头部长有羽毛，双眼疑似无眼白构造。
- 原文依据："另一个是长着鸟嘴，头上还有羽毛的少年。"及"让他那对应该没有眼白的双眼翻着白眼"

- 名称：斯佩路德族的野外警戒与睡眠习性
- 特征：拥有极强的战斗本能，即便处于半梦半醒状态也能借助第三只红眼敏锐洞察靠近的魔物；在外就寝习惯手握长枪席地靠墙蜷宿，极少安睡于柔软床铺上。
- 原文依据："他在半梦半醒之间也可以注意到有东西接近我们。所以我会因为在半夜听到有什么东西破裂的声音而清醒，然后发现原来是瑞杰路德和魔物战斗的声音"及"瑞杰路德在睡觉，但是不知道为什么没睡在床上，而是抱着枪窝在房间角落里。"

## 五、物品 / 道具 / 武器
- 名称：魔照石
- 说明：极为罕见珍稀的天然魔石。在白天能够吸收储存日光，待周围光线转暗后便释放柔和光芒照明，发光蓄能时长约为白天的一半不到。城镇悬崖峭壁上镶嵌的魔照石属于公共设施，严禁居民或外人私自拆卸取走。
- 原文依据："「魔照石可以在白天储存日光，等周围变暗后就会像那样发光。不过，发光时间只能持续不到白天的一半。」……「魔照石是相当稀少的石头。」……「据说基本上禁止私自取走魔照石，但我不清楚详情。」"

## 六、历史 / 传说 / 事件
- 事件名：魔界大帝搜集魔照石事件
- 内容：古时魔界大帝奇希莉卡・奇希里斯在位期间，仅仅为了让自己居住的奇希里斯城在黑夜中映衬得更宏伟美丽，便下令大量搜集稀有的魔照石镶嵌在利卡里斯环形山的山壁顶端。当时此举遭到批评为荒淫任性、颓废堕落，但在千年之后却成为了城镇永久的天然照明。
- 原文依据："「据说那些是魔界大帝在世的时候让人收集而来的，你看那边。」瑞杰路德指出的对象是在光线中隐约浮现的半毁城堡。「而且只是为了要让那座城看起来更美。」……「当时魔界大帝似乎被大肆批评为过于任性，但现在却像这样发挥作用。」「怎么可能，魔界大是出了名的颓废堕落。」"

- 事件名：历代剑神传承逸闻
- 内容：在历史历代剑神之中，存在某位名字发音与“雷○”（雷德等）相仿的传奇剑神。
- 原文依据："「雷○……？那是谁？好像有哪一代的剑神也叫类似的名字……？」"

## 七、社会规则 / 习俗 / 文化
- 内容：魔大陆服饰与职业刻板认知
  在魔大陆冒险者的普遍常识中，习惯性认为身披兜帽斗篷遮面者必定为魔术师。
- 原文依据："「你们该不会是看到戴着兜帽的艾莉丝，就认为她是魔术师？」「嗯。因为，会戴兜帽的人都是魔术师吧？」"

- 内容：冒险者委托等级与晋升晋级梯队
  公会等级梯队分明，低阶新人（F、E级）以城内清扫、记账、搬运等杂活维持温饱并积攒升级履历；D 级后城外采集委托增加；C 级及以上才开放魔物讨伐委托以换取高额佣金。晋级不可凭实力跳级，必须按部就班积累合格委托完成单量。
- 原文依据："F级的行情是五枚石钱上下，E级是一枚屑铁钱上下。如果是一个人，一天最少只要完成一件F级委托就能支付住宿费。之后能赚取的金额会随着层级上升而增加，也能存钱。F、E级基本上是城镇内的工作，升到D级以上之后采集的委托就会变多，所以要先承接F、E级来存钱，购买装备后再挑战D级任务……虽然我忘了问要完成几次委托才能够升级，不过至少似乎不可能凭着能力强大就跳着升级，所以只能脚踏实地一步步往上升。"

- 内容：阿斯拉贵族社交回避礼法
  阿斯拉贵族阶层在遭遇不愿交涉纠缠的对象时，有一套专门传授的优雅避人礼节（如艾德娜传授的“不想理睬对方时的贵族回避方式”），通过冷漠扭头、避开视线并迅速利落步离的方式示意拒绝。
- 原文依据："艾莉丝迅速移开视线，打算远离那群人。我知道那技巧是什么，是艾德娜女士直接传授的礼仪规矩。「不想理睬对方时的贵族回避方式・初步篇」！"

## 九、角色认知 vs 客观事实
- 角色以为：库尔特等魔族少年看到艾莉丝身穿兽耳兜帽，自以为对方是娇小柔弱的女性魔术师，试图强行搭讪并拉拢其入队。
- 原文是否暗示另有真相：是。艾莉丝实为剑神流上级剑士并兼通伯雷亚斯家族凶狠体术，瞬间以拳脚将三人全部打倒制服。
- 原文依据："「你们该不会是看到戴着兜帽的艾莉丝，就认为她是魔术师？」「嗯。因为，会戴兜帽的人都是魔术师吧？」「她不是佩着剑吗？」「咦？啊……真的有。」"及"一瞬间，三个人就丧失抵抗能力。"

- 角色以为：鲁迪乌斯一直以为艾莉丝在魔大陆毫无心理压力，完全是在尽情享受冒险。
- 原文是否暗示另有真相：是。艾莉丝夜深人静时在窗边蜷坐抱膝，极为害怕自己再也无法返回故乡，白天的急躁与暴力源于极度压抑的不安心理。
- 原文依据："我一直以为艾莉丝和以前一样。以为她不会感到不安，只是纯粹地享受着这个状况，享受冒险。但是我错了，她同样感到不安。只是表现出避免让我察觉到这一点的举止。艾莉丝应该累积了不少压力。"及"「我说……鲁迪乌斯。」「嗯。」「我们……能回去吗……？」声调听起来很不安。"

- 角色以为：鲁迪乌斯以为魔界大帝奇希莉卡当年在环形山壁大肆收集镶嵌魔照石是表面任性、暗中为了民众照明谋福利。
- 原文是否暗示另有真相：否（或存疑）。瑞杰路德直言魔界大帝生性荒淫颓废堕落，纯粹只是为了让自己的行宫城堡看起来更加耀眼美丽。
- 原文依据："「说不定她是为了人民才收集这些石头。」「怎么可能，魔界大是出了名的颓废堕落。」"
