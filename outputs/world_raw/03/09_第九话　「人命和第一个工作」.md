# 第九话　「人命和第一个工作」 世界设定提取

## 一、地理与场所
- 名称：奇里布排屋
- 内容：位于利卡里斯镇二号，是一栋只有一层楼的长方形建筑，设有四个出入口。居住者经济状况属于魔大陆上的一般阶层，不算富裕但也不至于像贫民窟那样贫困。
- 原文依据："利卡里斯镇二号，奇里布排屋。那是一栋只有一层楼的长方形建筑，设有四个出入口。住在这里的人虽然绝对算不上富裕，但也不至于像贫民窟那样受贫困所苦，而是魔大陆上的一般阶层。"

- 名称：利卡里斯镇贫民窟及地下窝点
- 内容：利卡里斯镇内的一片破败区域，房舍坍塌，外墙简陋粗糙，聚集着眼神危险的流氓、路边躺卧者和脏兮兮的小孩。贫民窟内有一处隐藏在地下楼梯后的建筑，外观类似地下酒馆，内部有昏暗走廊和小房间，最深处的房间摆满笼子，用于关押偷盗来的各类动物和宠物。
- 原文依据："穿过某条巷子后，周围的风景变了。变得比先前萧条了几分，有些房舍已经崩塌，外墙也变得简陋粗糙。有些家伙以危险的眼神瞪着我们，还有人躺在路边。也看到很多脏兮兮的小孩。这里是贫民窟。"、"眼前有一段往下的楼梯，楼梯前方是一扇门。看起来像是视觉系的人们会聚集的地下酒馆。……反而飘出一股动物的味道。……走廊深处有一扇门，门后是一个小房间，然后又有一扇门。穿过两道门后，喧嚣的动物叫声冲击耳朵。在最深处的房间里，排着很多笼子。塞满整间房的这些笼子里关着大量的动物。"

## 二、组织与势力
- 名称：冒险者队伍「Dead End」
- 内容：鲁迪乌斯在魔大陆接受委托并对外报出的冒险者队伍名号，意在通过实际善行逐步改善这一可怕名号给世人带来的恶劣印象。
- 原文依据："在下是『Dead End』的鲁迪乌斯。"、"我明白了，那么我们会去寻找，请交给『Dead End』吧！"

- 名称：宠物绑架盗窃团伙 [存疑]
- 内容：潜伏在利卡里斯镇贫民窟地下据点的犯罪分子团伙，由多名魔族组成，利用绳子和嘴套捕捉镇上居民的高级宠物并关押在笼中，疑似从事绑架高级宠物并高价倒卖的地下买卖。
- 原文依据："房间角落里随便丢着绳子和嘴套之类的东西。讲到从绳子能联想到的词语，就是『捕捉』。绑架别人的高级宠物，再高价卖到他处。这种买卖似乎也有可能存在。"、"我俯视着躺在房间角落的三个男女，共有两名男性和一名女性。"

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术应用（开锁与手铐拘束）
- 规则：土魔术具备精细塑形能力，可用于直接转动门锁开锁，也可用于凭空制造手铐拘束敌人。
- 原文依据："门锁着，我利用土魔术开锁。"、"我用土魔术让三人全都戴上手铐，再泼水让他们清醒。"

- 名称：斯佩路德族的感知与野外追踪能力
- 规则：额头上的宝石具备类似生物雷达的感知能力，可侦测周围是否存在人类或生物；同时具备高超的动物痕迹追踪技术，能通过模糊脚印的尺寸以及地盘残留气味的浓淡变化锁定动物的行踪。
- 原文依据："就算瑞杰路德拥有生物雷达，要在城镇中找出一只动物也不是容易的事情。"、"『是我们要找的动物的地盘已经被其他动物逐渐入侵。』……『没错，因为味道正在变淡。』"、"对了，他可以靠额头上的宝石判断。……『周围真的没人啊。』"

## 四、种族 / 生物
- 名称：霍加族
- 特征：魔族的一种，特征是拥有蜥蜴般的长尾巴，且舌头前端分成两岔。
- 原文依据："走出一个年龄大约七岁，特徵是蜥蜴般的长尾巴，还有舌头前端分成两个岔的霍加族。"

- 名称：复眼昆虫型魔族（蝉型 / 蜜蜂型） [存疑]
- 特征：魔族的一种。部分个体皮肤橘色、复眼无眼白、叫声粗野吵闹且唾液有毒；部分个体面部形似蜜蜂，同样生有复眼。
- 原文依据："皮肤是橘色的，眼睛没有眼白，而且是复眼。看起来有点恶心。大叫大闹跟蝉一样吵的家伙。……不过还记得因为这种族的唾液有毒，我还产生过『那接吻时该怎么办？』的疑问。"、"也是复眼，脸长得像蜜蜂，可以看得出来她很害怕。"

- 名称：蜥蜴型魔族
- 特征：外貌形似蜥蜴的魔族，不同个体或族群的面部形状与花纹存在差异，具备知性神色。
- 原文依据："长得很像蜥蜴，不过形状和花纹和门口卫兵有点不同。实在很难从蜥蜴脸上看出表情，不过眼中透露出的知性神色让我产生戒心。"

- 名称：小咪（黑豹型宠物魔兽）
- 特征：霍加族少女饲养的黑色宠物，外形如同一只黑豹，体格庞大，远超一般家猫，颈部佩戴刻有名字的项圈。
- 原文依据："我望向瑞杰路德指出的地方……里面装着一只像黑豹的动物。好大，真的很大。比少女张开双手比划的尺寸还大了两倍左右。……黑豹的项圈上的确写着『小咪』两个字。"

## 五、物品 / 道具 / 武器
- 名称：斯佩路德族短枪
- 说明：斯佩路德族战士瑞杰路德随身携带的近战兵刃，出招速度极快且极具杀伤力，能瞬间刺穿敌人咽喉。
- 原文依据："结果映入我眼帘的景象，是刺进男A喉咙里的短枪。瑞杰路德攻击了男A……短枪往横一转被拔了出来，鲜血喷出，在墙上形成红色斑点。"

- 名称：宠物项圈 / 脚环
- 说明：魔大陆居民为家养宠物佩戴的饰品，常刻有宠物名字，用于标识所有权与身份。
- 原文依据："黑豹的项圈上的确写着『小咪』两个字。"、"观察之后，发现戴着项圈或脚环的动物还不少。其中还有一些像『小咪』那样写着名字，不管怎么看都是宠物。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役中的「Dead End」凶名
- 内容：在四百多年前的拉普拉斯战役中，斯佩路德族虽然立下赫赫战功，却传闻连同伴也残虐杀害；「Dead End」则是其中被视作最凶暴残忍的个体，据说遭遇者必死无疑，在魔大陆已成为极度恐怖的代名词。
- 原文依据："Dead End。在四百多年前的拉普拉斯战役中立下许多战功，甚至对同伴也下手虐杀的恶魔，斯佩路德族。Dead End是在其中被视为最凶暴残忍的个体。据说只要碰上Dead End就会死。实际遭遇过那家伙的人也全都主张『要不是拚命逃走早就被杀』，在魔大陆上成了恐怖的代名词。"

## 七、社会规则 / 习俗 / 文化
- 内容：冒险者的人际相处与委托态度：魔大陆当地冒险者行事普遍粗暴野蛮，甚少使用敬语；面对委托人采取礼貌尊重的态度能快速消除戒心并赢得信任。
- 原文依据："在这一带的冒险者里，没有人讲话那么客气。所谓的冒险者，基本上都是一些粗野的家伙。"、"面对委托人时，要以恭敬的态度说话。"

- 内容：魔族与人族常识差异及杀戮标准：魔族与人族在激怒底线与常识上存在巨大分歧；瑞杰路德恪守绝不伤害小孩的准则，认为伤害或踢打孩童的恶人被杀乃是理所当然之事；但在世人眼光中，斯佩路德族杀人会被等同于失去理性的魔物滥杀，会彻底摧毁改变恶名的所有努力。
- 原文依据："洛琪希不是也有说过吗？『人族和魔族在常识上有许多不同之处，你无法预测讲了什么话会成为让对方发火的契机。』"、"『因为他踢了小孩。』瑞杰路德平静地说道，这语气就像是在表示他的行为很理所当然。"、"『因为斯佩路德族杀人跟其他人杀人的意义不同，被斯佩路德族杀掉就像是被魔物杀掉。』……『可是一旦杀人，就会毁掉一切。人们应该会觉得斯佩路德族果然是恶魔吧。』"

- 内容：「绝不杀人」的同伴誓约：为了让世人认可斯佩路德族具有理性，鲁迪乌斯说服瑞杰路德在今后的旅途与冒险中绝对不要夺取任何人的性命，瑞杰路德最终接受并做出了承诺。
- 原文依据："『请不要杀人。如果你真心为斯佩路德族着想，就不要杀任何人。』……『请你不要杀任何人，我们也不想看到你就感到害怕。』『……好吧。』"

- 内容：魔大陆底层社会的治安现状：贫民窟缺乏法制规范，底层弱肉强食，居民对强者的忌惮远胜于对冒险者的尊重；社会中存在绑架家养宠物再高价转卖的黑市产业链。
- 原文依据："在这个世界里，哪个人丧命根本是家常便饭的事情。"、"在这种地方，比起冒险者，或许对于强者的警戒心还比较高。"、"绑架别人的高级宠物，再高价卖到他处。这种买卖似乎也有可能存在。我是不觉得这世界会有关于这方面的法律，但这的确不是什么好事。"

## 九、角色认知 vs 客观事实
- 角色以为：霍加族委托人少女把走失宠物称为“猫咪”，张开双手比划尺寸，鲁迪乌斯据此以为宠物大约只有柴犬大小。
- 原文是否暗示另有真相：是
- 原文依据："根据听来的情报，那只宠物似乎是猫。……体型相当有分量，少女张开双手来表现宠物的大小。如果直接当成是那样，大概有柴犬般大吧？"与"我望向瑞杰路德指出的地方……里面装着一只像黑豹的动物。好大，真的很大。比少女张开双手比划的尺寸还大了两倍左右。……黑豹的项圈上的确写着『小咪』两个字。"

- 角色以为：鲁迪乌斯一度认为斯佩路德族只是受到世俗误解的温厚稳重种族，瑞杰路德是个好人、不会轻易伤害人。
- 原文是否暗示另有真相：是
- 原文依据："一直以为是个善良好人的瑞杰路德很乾脆地杀了人。原本我已经认定斯佩路德族只是受到误解的沉稳种族，但这想法错了。即使不确定整个种族是怎样，但至少瑞杰路德不是那样。他从拉普拉斯战役的时代起就一直持续杀死敌人，这次也是那种案例之一吧。"

- 角色以为：瑞杰路德认为“如果没有人看到，又有什么关系？”，只要用额头宝石侦测确认周围没有旁观者，杀死伤害小孩的恶人就无所谓。
- 原文是否暗示另有真相：是
- 原文依据："『如果没有人看到，又有什么关系？』……『这次有人看到喔。』……『我和艾莉丝不就看到了吗？』……『请你不要杀任何人，我们也不想看到你就感到害怕。』"
