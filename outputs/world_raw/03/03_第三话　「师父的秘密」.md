# 第三话　「师父的秘密」 世界设定提取

## 一、地理与场所
- 名称：魔大陆
- 内容：因人魔大战而被撕裂的大陆一部分，过去曾是魔神拉普拉斯统整的魔族领域。其面积约为中央大陆的一半。全境几乎没有植物，地面干涸龟裂，地势险峻，分布着大量高低落差极大宛如巨大阶梯的地形，且到处有比人还高的巨石阻挡去路，整片大陆犹如天然迷宫；土壤呈缺乏养分的破碎粒状，几近沙漠化。魔大陆魔力浓度高，栖息着大量凶猛魔物。若想以步行方式横越魔大陆，所耗时间约为横越中央大陆的三倍。
- 原文依据："因为人魔大战而被扯裂的巨大陆一部分。过去魔神拉普拉斯统整的魔族领域。面积虽然约有中央大陆的一半，但几乎没有植物，地面乾涸龟裂，有许多类似巨大阶梯的高低落差地形，还有比人高的岩石阻挡去路，是一片宛如天然迷宫的土地。而且魔力浓度很高，存在着许多强大的魔物。据说如果想要步行横越魔大陆，大概必须耗费横越中央大陆的三倍时间。"、"魔大陆遍地都是岩石，地形的高低落差也很剧烈。地面坚硬，土壤呈现碎裂的粒状。就是那种缺乏营养，差不多快化成沙漠的感觉。这里几乎看不到植物，顶多偶尔会出现类似仙人掌的奇妙岩石。"

- 名称：米格路德族之村（聚落）
- 内容：位于魔大陆东北方比耶寇亚地区的米格路德族聚落。规模较小，约有十几间房屋依附聚集，外围环绕着一圈简陋的防御栅栏。栅栏内侧开垦有小片农田，但因缺乏水源与河流灌溉，农作物长势和收成欠佳。
- 原文依据："虽然艾莉丝说是村庄，但看起来比较像是规模更小的聚落。只有约十几间的屋子聚集在一起，外围搭建着一圈简陋的栅栏。在栅栏内侧有一片不太宽广的田地。虽然不知道田里种着什么，但收成看起来并不好。在这种没有河川的地方培育作物是不是太勉强了呢？"、"就这样，我们进入了「米格路德族之村」。"

## 二、组织与势力
- 名称：米格路德族之村管理层
- 内容：聚落设有村长（现任为洛克斯）与入口警卫（如洛因），对外界访客与异常事件（如天降流星、年幼人族会说魔神语）抱有强烈戒备与排斥机制，外来者进村需经村长核准。
- 原文依据："「真可疑，不能让他们进入村内！」"、"「洛因，找村长来。」"、"「我是这聚落的村长，洛克斯。」"

## 三、力量体系 / 魔法 / 技能
- 名称：念话 / 种族同调心灵感应（米格路德族）
- 规则：米格路德族的种族天生能力。同族的亲近者之间即便相隔两地，也能通过闭目凝神等方式在心灵深处直接相互对话通讯；洛琪希天生缺乏这种能力。
- 原文依据："叫作洛因的少年闭上眼睛，就这样过了约十秒钟……"、"「米格路德族即使分处两地，也可以和同族彼此对话。」"、"洛琪希送来的书里有提到。上面写着米格路德族的亲近者之间能够互相通讯，还顺便提到她就是因为无法办到这件事才离开村子。"

- 名称：额部红宝石雷达探知（斯佩路德族）
- 规则：斯佩路德族额头中央红宝石感觉器官的特殊机能。具备如同雷达般的敌情预警与探查效果，即使肉眼看不到也能提前察知潜伏或阻挡前路的魔物，从而实施超视距奇袭。红宝石长在肉体上无法剥离挖出。
- 原文依据："洛琪希辞典上有注明，斯佩路德族额头上的红宝石具备类似雷达的机能。多亏有这个才能提早发现敌人，在魔物注意到我们之前就发动奇袭，瞬间打倒对方。"、"「打倒前方的魔物。」……「为什么明明没有看到，你却知道有魔物啊！」「我能够看到。」瑞杰路德说完，把浏海往上拨。他露出额头，还有那上面的红宝石。"、"「或许方便，但我好几次都觉得没有这种东西会比较好。」「那我可以好心收下！来！挖出来给我！」「没办法那样做。」"

## 四、种族 / 生物
- 名称：米格路德族
- 特征：魔族的一支。外表特征为拥有天生纯正的蓝色头发；身型普遍偏小，即使成年并年届数十甚至上百岁，外表依旧保持着宛如人类初中生（少年少女）般的娇小外貌。其种族自然寿命约为两百岁左右（指正常老死）。族人间拥有跨越距离的同族心灵通讯能力（念话）。
- 原文依据："他有着一头蓝发，让我联想到洛琪希。"、"拄着拐杖，但外表却像个小孩的家伙从村子内部走了过来。旁边带着两个国中女生……我的意思是年纪看起来像是国中生的少女。每个人的体型都偏矮小。难道米格路德族即使成人，外表也只会长成国中生左右的模样吗？"、"「米格路德族的寿命大约是两百岁，虽然也有不少人病死，但如果以老死来计算，大约是这个年龄。」"、"「米格路德族即使分处两地，也可以和同族彼此对话。」"

- 名称：斯佩路德族（身体能力补充）
- 特征：具备极其卓越强悍的身体机能与超绝敏捷性，跳跃翻越崇山峻岭如履平地；性格沉稳且极具耐心，面对外人的无理顶撞与戒备依旧能够温和包容。
- 原文依据："他敏捷地跳过岩山，三两下就不见人影。真是惊人的身体能力。虽然基列奴也很夸张，但如果以数值来显示敏捷性，说不定瑞杰路德会占上风。"、"瑞杰路德虽然话不多，但对于艾莉丝的发言都有一一回应。……在对话时，她偶尔会讲出非常没礼貌的发言让我心惊胆跳，不过瑞杰路德并没有生气。无论听到什么，都很乾脆地应付过去。到底是谁放出斯佩路德族很容易暴怒的谣言啊！"

- 名称：魔大陆魔物（生态分布补充）
- 特征：因魔大陆魔力浓度高而繁衍出大量强悍魔物，偏离主干道时的遇敌密度极高（几乎每十几分钟便遭遇一批）；但在比耶寇亚地区附近的魔物整体战斗力并不算顶尖，能被高阶战士一击制敌。
- 原文依据："而且魔力浓度很高，存在着许多强大的魔物。"、"「这附近并不算强，不过因为偏离道路，所以数量很多。」"、"「没问题，全都一击解决。」"

## 五、物品 / 道具 / 武器
- 名称：洛琪希赠与的项链（信物）
- 说明：洛琪希在鲁迪乌斯结业时赠予的胸前项链，被米格路德族村长一眼辨识出来，是米格路德族重要身份信物，直接化解了进村危机。
- 原文依据："最后他的视线停在我的胸前。「那个项链是从哪里来的？」「是我的师父送我的。」「你的师父是哪里的什么人？」「名字叫洛琪希。」"、"洛琪希送我的项链发挥出卓越的效果。"

## 六、历史 / 传说 / 事件
- 事件名：人魔大战（陆地裂解）
- 内容：古代爆发的人族与魔族的大决战，导致曾经完整相连的远古大陆崩坏被扯裂，其中一部分便形成了如今的魔大陆；该区域过去曾统合于魔神拉普拉斯的支配之下。
- 原文依据："因为人魔大战而被扯裂的巨大陆一部分。过去魔神拉普拉斯统整的魔族领域。"

- 事件名：洛琪希离家出走事件
- 内容：约二十余年前，洛琪希因为自身天生无法使用米格路德族的同族心灵通讯能力而感到疏离，未经允许擅自离开村庄远走他乡，自此断绝音讯二十余年。
- 原文依据："上面写着米格路德族的亲近者之间能够互相通讯，还顺便提到她就是因为无法办到这件事才离开村子。"、"「洛琪希是我的女儿！那家伙还活着吗！」……「快告诉我！她二十多年前离开这村子以后，就毫无音讯！」"

## 七、社会规则 / 习俗 / 文化
- 内容：米格路德族村落排外防范机制——对可疑的外来陌生人严加盘查禁入，尤其是反常掌握魔神语的异族幼童会被格外警惕，唯有村长具备裁断许可权。
- 原文依据："「真可疑，不能让他们进入村内！」"、"「这种年纪的人族为什么要学习魔神语！」"

- 内容：礼节规范与跨文化互敬——阿斯拉王国的贵族致意礼节具有严格的性别区分（男性与女性规矩不同）；即使语言不通，展现得体的礼仪规范亦能赢得魔族长者的好感与尊重回礼。
- 原文依据："「这位小姑娘该不会是在向我致意吧？」「是的，这是我们故乡的致意方式。」「哦？和你的方式似乎不同？」「因为男性和女性各有不同的规矩。」「这样啊。」洛克斯点点头，接着模仿我的动作对着艾莉丝弯腰行礼。"

## 九、角色认知 vs 客观事实
- 角色以为：外界传闻斯佩路德族性格极度残暴、一点就着极易暴怒。
- 原文是否暗示另有真相：否。瑞杰路德面对艾莉丝各种不礼貌、挑衅式的言辞，以及村落守卫的敌视拔剑，始终保持着极高涵养与克制耐心，反证外界对斯佩路德族性格的谣传严重失实。
- 原文依据："在对话时，她偶尔会讲出非常没礼貌的发言让我心惊胆跳，不过瑞杰路德并没有生气。无论听到什么，都很乾脆地应付过去。到底是谁放出斯佩路德族很容易暴怒的谣言啊！"

- 角色以为：鲁迪乌斯初见村门守卫洛因时，根据其初中生少年般的外表，以为他最多是洛琪希的同龄人或弟弟。
- 原文是否暗示另有真相：是。米格路德族即便成年后外观也终身维持如同人类少年少女般娇小，洛因实际上是洛琪希的亲生父亲，洛琪希实际年龄已达44岁，全族寿命约200岁。
- 原文依据："定睛一看，有一名年约国中的少年站在门边。" 对比 "「洛琪希是我的女儿！那家伙还活着吗！」"、"毕竟光看外表，他反而像是洛琪希的弟弟。"、"「洛琪希她应该………今年四十四岁。米格路德族的寿命大约是两百岁」"

- 角色以为：洛因根据常理认为一个年幼的人族幼童根本不可能也不应该学会复杂的魔神语，认定其必有阴谋。
- 原文是否暗示另有真相：否。村长洛克斯客观指出“语言这种东西只要学习，无论是谁都能学会”，打破了按种族常理定罪的思维定势。
- 原文依据："「这种年纪的人族为什么要学习魔神语！」" 对比 "「语言这种东西只要学习，无论是谁都能学会吧？」"
