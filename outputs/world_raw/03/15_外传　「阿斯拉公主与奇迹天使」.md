# 外传　「阿斯拉公主与奇迹天使」 世界设定提取

## 一、地理与场所
- 名称：王都亚尔斯
- 内容：阿斯拉王国的首都，是世界上人口最多、占地规模最为宏大的超级都城。
- 原文依据："阿斯拉王国的王都亚尔斯是世界上人口最多，而且规模最巨大的都城。"

- 名称：银之宫
- 内容：耸立在王都亚尔斯核心区域的白色宫殿，阿斯拉王国的王城，传闻是世上最大、最美丽的白色宫殿。然而其内部充斥着尔虞我诈的残酷政治暗斗，被形容为毫无信任可言的“魔境”。
- 原文依据："在巨大的都城中央，有据说果然也是世界上最大最美的白色宫殿。王城「银之宫」……据说宫殿内部，甚至是没有任何人能够信赖的魔境。"

- 名称：银之宫专属庭园群（蔷薇园、牡丹园、绣球花园、白百合园、木槿之森）
- 内容：银之宫内部依花卉颜色规划设立了数座各具特色的庭园：搜集各色红花植物的蔷薇园；搜集黑花植物的牡丹园；搜集蓝花植物的绣球花园；以及搜罗绽放白色花卉植物的白百合园。第二公主爱丽儿每隔三天必会前往白百合园享用下午茶。白百合园深处连结着被称为“木槿之森”的林区。
- 原文依据："银之宫内部除了有王族贵族的居住区域，还存在着许多庭园。蒐罗各式红花植物的蔷薇园。蒐罗各式黑花植物的牡丹园。蒐罗各式蓝花植物的绣球花园。还有，蒐罗会绽放白花的植物的庭园。通称，白百合园。这座白百合园是某个人物喜欢的地方。那个人物就是爱丽儿・阿涅摩伊・阿斯拉。"、"从白百合园深处，被称为木槿之森的区域里缓缓走出一只靠双脚步行的巨大野猪。"

- 名称：阿尔堤尔河
- 内容：流淌经王都亚尔斯边缘的河流，其上架设有名为通车大桥的重大工程，第二公主爱丽儿曾受邀主持大桥通车仪式并成为首位渡桥者。
- 原文依据："例如在流经王都旁边的阿尔堤尔河上盖好大桥时，她曾出席落成典礼，并成为第一个渡过大桥的人。"

- 名称：阿斯拉王国（地缘政治与周边环境）
- 内容：全境土地极其肥沃、粮食极其丰沛，无论贵族如何重税压榨，底层民众也绝无饥饿之虞，因而长达四百年以上与饥荒和战火绝缘，但也因此导致全国社会与体制陷入长期停滞状态。王国四周受到天险山脉环抱，自诩固若金汤；然而南方正面临工坊技术已凌驾于己的“王龙王国”的虎视眈眈，北方则毗邻魔术研究与造诣已超越自身的“魔法三大国”。
- 原文依据："在历史已经长达四百年以上，也一直和战争与饥饿无缘的这个阿斯拉王国中……"、"阿斯拉王国是和饥饿无缘的土地。甚至被认为无论贵族多么腐败，向人民榨取多少税金，民众都不会挨饿。因此不满情绪不容易累积，也不会出现有意愿改变现状的人，更不曾发生大规模叛乱或内战。正因为如此，这个国家处于停滞状态。……技术方面已经被南方的王龙王国，魔术方面已经被北方的魔法三大国超越。……现在的阿斯拉王国受到山脉保护，认定自国不会受到他国侵略，但是过了五十年后，万一技术方面已有发展的王龙王国真的来犯……"

- 名称：王龙王国
- 内容：阿斯拉王国南方的强国，在工程与制造技术方面的发展已经全面超越了阿斯拉王国，常年对土地肥美的阿斯拉王国怀抱觊觎之心。
- 原文依据："技术方面已经被南方的王龙王国……超越"、"南方的王龙王国对土地肥沃的阿斯拉王国总是虎视眈眈。"

- 名称：魔法三大国
- 内容：坐落于阿斯拉王国北方的三个国家，在魔术研发与学术水平方面已经超越了阿斯拉王国。
- 原文依据："魔术方面已经被北方的魔法三大国超越。"

## 二、组织与势力
- 名称：阿斯拉王室与王位继承派系
- 内容：
  - 现任国王：以拥有世间历史上最动人的顶级美音著称。
  - 第一王妃（正妃）：拥有倾国美貌与璀璨金发。
  - 爱丽儿·阿涅摩伊·阿斯拉：第二公主，正妃独生女，唯一完全继承正统王家纯血统的后嗣，天生具备金发绝色、天籁美音与倾倒众生的超凡领袖魅力。在民间知名度与拥护度极高。表面沉湎享乐，实则社交勤勉。
  - 第一王子格拉维尔：与第二王子形成两派激烈的夺储争端，重视宫廷内部政治；其麾下贵族派系视爱丽儿的高威望为心腹大患并密谋实施铲除。
  - 第二王子：王位争夺的双雄之一。
  - 第一公主：已安排外嫁。
- 原文依据："那个人物就是爱丽儿・阿涅摩伊・阿斯拉。阿斯拉王国的第二公主。她从被赞颂为绝世美女的第一王妃那里继承了美貌和灿烂金发，还从国王那里继承了被称为历史上最顶级的美丽声音。"、"「我上面有两位哥哥，一位姐姐。虽然姐姐已经确定会嫁往何处，但是哥哥们目前也以王位为目标互相激烈竞争。」"、"「不，您是正妃殿下的小孩，也是唯一继承正统阿斯拉王家血统的人物。」"、"你意思是，格拉维尔殿下果然认为爱丽儿殿下是威胁？……「这是为了格拉维尔殿下，也等于为了阿斯拉王国。正因为这样想，所以我早就做好了安排。」"

- 名称：格雷拉特家族（诺托斯家）
- 内容：阿斯拉王国坐拥四大领地的顶层统治名门之一。路克·诺托斯·格雷拉特系诺托斯家次男，担任第二公主爱丽儿的贴身护卫骑士；年未满十五，擅长剑神流中级，能言善道、风流倜傥。
- 原文依据："名为路克・诺托斯・格雷拉特。是四大领地的领主・格雷拉特家的次男，拥有剑神流中级实力的年轻骑士。城内没有哪个贵族子女不认识他。年龄尚未满十五岁。"

- 名称：雷特巴特家族
- 内容：阿斯拉王国地方上的知名中级贵族，保持着端正的传统常识家风，远离宫廷靡烂风气。迪利克·雷特巴特为家族三男，魔法学院高材生，获任爱丽儿的守护术师。
- 原文依据："守护术师的名字是迪利克・雷特巴特。是出名的雷特巴特家三男，从历史悠久的阿斯拉魔法学院毕业的上级魔术师。"、"雷特巴特原本是位于地方的中级贵族，也是和阿斯拉王国内部的颓废世界无缘的贵族。"

- 名称：阿斯拉魔法学院与王家魔术师团
- 内容：阿斯拉王国权威的国立魔学机构与王家直属法师部队。魔法学院定期组织学生同骑士学校开展实战模拟对抗，常年深入密林进行魔物实战，并主办年度大魔术舞斗会；学院与魔术师团内部普遍聚集有大量对执政官僚与腐败王公持尖锐批评观点的思想人士。贵族出身的上级魔术师在王国中极为尊贵罕见。
- 原文依据："从历史悠久的阿斯拉魔法学院毕业的上级魔术师。"、"单纯只是因为他在魔术学校的成绩优秀，毕竟具备贵族身分的上级魔术师很贵重。"、"魔术学院和魔术师团都是聚集了反社会思考人士的巢穴，有很多人会私下批判掌控当今政权的大臣以及王族贵族。"、"也曾以贵宾身分参加魔术学院举办的大魔术舞斗会"

- 名称：米里斯教
- 内容：崇奉古代圣人救世主圣米里斯的宗教信仰。迪利克为其虔诚门徒，在遭遇死亡威胁的绝境中向其祈祷救拔。
- 原文依据："身为米里斯教徒的他对着上天祈祷。（求求您，神啊，求您对这次危机伸出援手。我愿意以自身的生命来交换……）……圣米里斯是一位伟大的人物，也是救济众生的救世主"

## 三、力量体系 / 魔法 / 技能
- 名称：上级魔术与咏唱限制
- 规则：常规上级魔术师（如迪利克）在释放强大魔术时必须进行念咒咏唱。在面对速度奇快、突发逼近至身前的巨型魔物突袭时，根本来不及完成完整的咒语构筑，魔术师在失去距离屏障与前卫保护时极易被瞬间近战重创。
- 原文依据："魔术师到底想做什么呢？只隔着这点距离，还面对如此巨大的魔物。既然敌人已经如此逼近，咏唱根本不可能来得及完成。"

- 名称：剑神流中级剑技
- 规则：近战剑术流派的中坚战力（路克持此段位），在缺乏重装防具与周旋空间时，正面对决大型猛兽魔物（终结野猪）的刚猛冲撞往往力不能支，极易被正面击飞溃败。
- 原文依据："拥有剑神流中级实力的年轻骑士。"、"在路克的视线范围里，看到路克拔出佩剑，冲向终结野猪的光景。（你真傻啊，路克……你一个人怎么可能打得赢……）"、"路克已经被打飞，以绝望的表情望着这边。"

- 名称：无咏唱强袭魔术
- 规则：自高空坠落的神秘幼女（希露菲）无需任何言语咏唱，仅通过伸出双掌即可瞬间调动庞大魔力爆发强力冲击波，一击直接彻底轰碎并打飞终结野猪的整个上半身。
- 原文依据："伴随着叫声，天上掉下来一个天使。那是一个衣衫褴褛，外表年幼的白发天使。……她发出可以算是半疯狂的可怜吼叫，同时把双手伸向终结野猪，打飞魔物的上半身。"

- 名称：治愈术师
- 规则：王国内专门负责重伤救护的神圣/恢复系魔学从业人员，但面临内脏粉碎、脊柱碎裂、肺部刺穿并大失血的致死伤势时，施救需要极度苛刻的时效。
- 原文依据："「迪利克……！啊啊，天啊……必须立刻找治愈术师过来！」"

## 四、种族 / 生物
- 名称：终结野猪
- 特征：直立双足行走的巨型野猪魔物。单体威胁级别为D级，极擅长号令成群的「猛攻斗犬」协同作战，形成集群时威胁可飙升至C级乃至B级。性情嗜血贪婪，多栖息于深山老林，偶会突破森林扫荡人族聚落，掠杀家畜并吞吃孩童；历史上曾有带犬覆灭二十余人村庄的惨剧，因而成为阿斯拉王国家喻户晓、常被长辈用以吓唬不眠顽童的顶级代表性魔物。
- 原文依据："从白百合园深处，被称为木槿之森的区域里缓缓走出一只靠双脚步行的巨大野猪。那是终结野猪。单体是D级，不过会率领大量的猛攻斗犬，是能够成为C级甚至B级的凶恶魔物。一般来说只会在森林深处碰到，然而由于生存数量相当多，有时会离开森林袭击村庄，抓走并吃掉家畜或人类小孩。很久以前曾有一个小村庄被率领二十只以上猛攻斗犬的终结野猪袭击并遭到灭村，因此终结野猪被视为阿斯拉王国内知名度最高的魔物。"

- 名称：猛攻斗犬
- 特征：常被终结野猪成群编组役使的凶悍犬类魔物。
- 原文依据："不过会率领大量的猛攻斗犬，是能够成为C级甚至B级的凶恶魔物。"

- 名称：“奇迹天使”（白发幼女）
- 特征：自天而降、外形衣衫褴褛的幼龄白发少女（实为被灾害传送且因变故白发化的希露菲叶特），拥有双手瞬发粉碎巨兽的惊人无咏唱魔力。
- 原文依据："伴随着叫声，天上掉下来一个天使。那是一个衣衫褴褛，外表年幼的白发天使。"、"她发出可以算是半疯狂的可怜吼叫，同时把双手伸向终结野猪，打飞魔物的上半身。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地消灭/转移事件
- 内容：波及阿斯拉王国菲托亚领地的特大异变灾难。该事件不仅抹平了领地，更引发空间无差别传送，将领地内的凶恶魔物（终结野猪）及居民（希露菲叶特）毫无预兆地直接跨空间传送至防护严密的王都银之宫内苑，致使第二公主的守护术师迪利克舍命殉职，并成为爱丽儿公主思想觉醒、投身王位争夺战的历史起点。
- 原文依据："菲托亚领地消灭事件对这种政治斗争也带来非常大的影响。"、"然而就在这个瞬间，菲托亚领地发生了转移事件。"、"但这只终结野猪其实是被菲托亚领地消灭事件波及，刚刚才转移到此地。"、"转移事件害死一名魔术师，并促进爱丽儿・阿涅摩伊・阿斯拉改革自身意识。"

- 事件名：卡瓦尼斯·司里安·阿斯拉登基历史
- 内容：拉普拉斯抗战后期的杰出人族领袖，大战平息后即位为阿斯拉国王，励精图治，深得全民敬仰与爱戴。
- 原文依据："如果是这样的她，肯定会和拉普拉斯战役后期的人族领导者，战争结束后成为国王的卡瓦尼斯・司里安・阿斯拉一样，成为受到民众爱戴的君主。"

- 事件名：圣米里斯传说
- 内容：米里斯教神话中拯救世间苍生的伟大救主。
- 原文依据："圣米里斯是一位伟大的人物，也是救济众生的救世主……"

## 七、社会规则 / 习俗 / 文化
- 内容：阿斯拉贵族的奢靡腐化与畸形社会特权文化
- 内容：由于四百年未尝战火与饥寒，阿斯拉上层贵族阶层形成病态畸形的价值观念：将超越伦理与常轨的异常行径、变态性取向（如极端施虐、玩弄男女仆役、极端恋物等）视作彰显超然社会地位的时尚特权。第二公主爱丽儿表面圣洁如仙女，私下却深谙此道且为重度两性虐待狂；护卫路克亦嗜好猎艳。
- 原文依据："在历史已经长达四百年以上，也一直和战争与饥饿无缘的这个阿斯拉王国中，有很多人认为把异于他人的行为当成兴趣正代表一种社会地位。爱丽儿和路克虽然还年轻，但已经充分沾染这种贵族的嗜好。"、"许多阿斯拉的贵族王族都拥有超过限度的性癖好，爱丽儿也不例外。"

- 内容：阿斯拉宫廷暗斗残酷潜规则
- 内容：王都银之宫内部贵族派系相互倾轧、背叛暗害无所不用其极。第一王子派贵族为了确保储君之位，暗地里密谋以暗杀、投毒等阴险手段清除政治后顾之忧。王族成员若缺乏坚实根基或斗志，在政治斗争中极易遭暗箭绞杀。
- 原文依据："据说宫殿内部，甚至是没有任何人能够信赖的魔境。"、"就算迪利克在此使用魔术杀死两人，也没有任何意义。反而只会被认定是爱丽儿命令守护术师杀死第一王子派的贵族……"、"「爱丽儿殿下……这是我最后的请求……请您……请您一定要……成为女王。然后，让阿斯拉成为更好的国家……」"
