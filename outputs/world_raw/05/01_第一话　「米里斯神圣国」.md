# 第一话　「米里斯神圣国」 世界设定提取

## 一、地理与场所
- 名称：米里斯神圣国首都米里希昂
- 内容：从圣剑街道可一览城市全貌。来自青龙山脉的尼古拉斯河流进蓝色光芒的格兰湖，湖中央耸立着纯白色的王城「白之宫」。尼古拉斯河沿岸有大圣堂与冒险者公会总部。市容整齐呈棋盘状，外围有七座雄伟高塔包围整座城市，外侧为草原地带。全城无城墙，依靠七座魔术塔控制天候并维持结界，使首都免受自然灾害与疾病侵害。市内划分为四大区域：
  1. 北侧「居住区」：民宅林立，贵族和骑士团家人居所与一般市民居所有些差别，基本上只有民宅。
  2. 东侧「商业区」：汇聚各行各业，零售店规模不大，主要为大型商会展示势力的区域，设有打铁铺与拍卖场。
  3. 南侧「冒险者区」：以冒险者公会总部为中心，提供给冒险者的商店、旅社一应俱全，并有过气冒险者居住的贫民窟、赌场以及奴隶市场。
  4. 西侧「神圣区」：圣米里斯教会相关人士居住区域，有巨大的大圣堂、墓地以及米里斯圣骑士团总部。
- 原文依据："来自青龙山脉的尼古拉斯河流进闪耀着蓝色光芒的格兰湖。格兰湖的中央耸立着伟大的纯白色「白之宫」。尼古拉斯河继续往前流动，沿岸可见散发出金光的大圣堂，以及反射出银光的冒险者公会总部。周围是棋盘般井然有序的街景。还有设置地点像是要包围整座城市的七座雄伟高塔，外侧则是辽阔的草原地带……"；"是啦，听说以前真的很麻烦，不过现在是靠那七个魔术塔来完美控制天候，所以才能放心把王城盖在湖泊正中央。你看这城市没有城墙吧？同样是因为那些塔一直维持着结界。"；"米里希昂市内被划分为四个地区。北侧的「居住区」……东侧的「商业区」……南侧的「冒险者区」……西侧的「神圣区」……"

- 名称：青龙山脉
- 内容：尼古拉斯河的发源山脉。
- 原文依据："来自青龙山脉的尼古拉斯河流进闪耀着蓝色光芒的格兰湖。"

- 名称：尼古拉斯河
- 内容：流经米里希昂并注入格兰湖的河流，沿岸建有大圣堂和冒险者公会总部。
- 原文依据："来自青龙山脉的尼古拉斯河流进闪耀着蓝色光芒的格兰湖。格兰湖的中央耸立着伟大的纯白色「白之宫」。尼古拉斯河继续往前流动，沿岸可见散发出金光的大圣堂，以及反射出银光的冒险者公会总部。"

- 名称：格兰湖 与 白之宫
- 内容：占据米里希昂接近中心位置的巨大湖泊；湖中心耸立着纯白色的王城「白之宫」。
- 原文依据："格兰湖的中央耸立着伟大的纯白色「白之宫」……所以才能放心把王城盖在湖泊正中央。"

- 名称：圣剑街道
- 内容：米里希昂外围能够一览该城市全貌的街道。
- 原文依据："从圣剑街道上，就可以一览这城市的全貌。"

- 名称：米里斯到阿斯拉的地理距离
- 内容：两地之间距离约为绕行世界四分之一，沿途道路有人工整顿且平坦，但预计移动仍需耗时约一年。
- 原文依据："从米里斯到阿斯拉，有着几乎等于绕行世界四分之一的距离。就算路程再怎么好走，也不代表距离会跟着缩短。我想，果然还是要花上一年左右吧。"

- 名称：稻米产区（中央大陆北部至东部、西隆王国）
- 内容：以稻米为主食的地区是从中央大陆北部往东部一带。西隆王国也有稻米，主流吃法是混合肉、蔬菜、海鲜做成类似炒饭或海鲜炖饭的料理，但该带似乎没有养鸡，难以取得鸡蛋。
- 原文依据："以米作为主食的地区，是从中央大陆北部往东部那一带。洛琪希寄来的信件上有提到西隆王国也有米。听说主流的吃法是混合肉、蔬菜、海鲜等配料，做成类似炒饭还是海鲜炖饭的料理。不过，在那一带似乎没有养鸡。"

- 名称：黎明之光亭
- 内容：位于米里希昂冒险者区偏离大街小巷深处的旅社，适合C～B级冒险者。离贫民窟远，治安良好，服务充实，日照略显不足；房间干净整洁、有桌椅、能上锁并附百叶窗。
- 原文依据："叫「黎明之光亭」。这家旅社虽然位于稍微偏离大街的位置，不过离贫民窟很远，治安也不差。而且各种服务都很充实，可以说是适合C～B级冒险者的旅社。"

## 二、组织与势力
- 名称：米里斯圣骑士团
- 内容：总部设于米里希昂西侧神圣区。守卫极为严密，若有人对守护城市的七座塔发表危险言论，圣骑士即便当成玩笑也会进行逮捕。
- 原文依据："别讲那么危险的发言。万一被圣骑士那群人听到，就算只是开玩笑也会被逮捕喔。"；"西侧的「神圣区」……米里斯圣骑士团的总部也位于此处。"

- 名称：圣米里斯教会
- 内容：米里斯神圣国的宗教教会势力，集中在神圣区，拥有巨大的大圣堂与墓地。
- 原文依据："西侧的「神圣区」。这区是居住着许多圣米里斯教会相关人士的地区。有巨大的大圣堂以及墓地，米里斯圣骑士团的总部也位于此处。"

- 名称：冒险者公会总部
- 内容：位于米里希昂南侧冒险者区，建筑外表反射出银色光辉，周边围绕着专为冒险者服务的各种店铺与旅社。
- 原文依据："沿岸可见散发出金光的大圣堂，以及反射出银光的冒险者公会总部。"；"以冒险者公会总部为中心，针对冒险者提供服务的商店和旅社等一应俱全。"

## 三、力量体系 / 魔法 / 技能
- 名称：七座魔术塔结界天候控制体系
- 规则：米里希昂市内设置了包围城市的七座魔术塔，能够完美控制天候、维持结界。只要塔存在，城市不受暴雨灾害侵袭，亦无疾病蔓延，城市因此无需修筑城墙。
- 原文依据："不过现在是靠那七个魔术塔来完美控制天候，所以才能放心把王城盖在湖泊正中央。你看这城市没有城墙吧？同样是因为那些塔一直维持着结界。"；"根据基斯的情报，只要那七个塔还存在，首都就绝对不会受到灾害袭击，似乎也不会有疾病蔓延。"

- 名称：混合魔术「寒冷突风」
- 规则：由右手施放「冰结领域」将环境温度瞬间骤降三十度，同时左手施放「突风」放出狂乱暴风将敌人吹飞，兼具极寒体温夺取与强力击飞效果的混合魔术。
- 原文依据："把魔力灌注到右手上的那一瞬间，冷气在仓库内部急速扩散。温度一口气降低了三十度……我的左手吹出狂乱暴风，把女战士打飞出去。她在仓库的地面上翻滚，被推回入口附近。这正是混合魔术「寒冷突风」。"

- 名称：声音魔术
- 规则：鲁迪乌斯在德路迪亚村向兽族习得的魔术，通过声音震撼对手，能使对手在短时间内暂时停止动作。
- 原文依据："我使用跟兽族学来的声音魔术，让男子只有一瞬间暂停动作，然后趁此机会放出冲击波把他打飞。"

- 名称：属性反制（土/岩壁克制水魔术）
- 规则：面对水魔术攻击时，利用砂或土制造岩壁能够有效挡下并吸收水系统魔术。
- 原文依据："使出的魔术是岩壁。利用砂或土来挡下并吸收使用水的魔术！算是一种反制。"

- 名称：水弹魔术咏唱
- 规则：初级/中级水魔术，通过法杖前端高速发射出一团水球。其咏唱咒语为：“清凉之浅流在此显现『水弹』！”
- 原文依据："「──清凉之浅流在此显现『水弹』！」是魔术的咏唱！会受到水弹的攻击！……只见那个魔术师的杖朝着这边，而且前端正在高速击出一团水球。"

- 名称：水神流与野兽流二刀流剑术
- 规则：水神流具备斜举长剑格挡偏转飞行物（如岩炮弹）的防御与化解技巧；保罗在此基础上还展现出嘴咬一剑、手脚着地如野兽般跳跃突进、从奇特姿势大角度拔剑回旋斩击并将嘴上剑换手反手砍出的双剑术。
- 原文依据："男子的反应很快，他斜举右手的剑，顺势拨开岩炮弹。「是水神流吗！」「不只水神流！」"；"男子将一把剑插回剑鞘，用嘴咬住另一把。……保持手脚着地姿势的男子扭动身体跳了起来。然后在这种跟动物没两样的动作下拔出腰间那把剑。接着让身体从奇妙的姿势大幅转动，使出斩击。……同时，他把咬在嘴上的剑换到左手上，反手砍出一剑。"

## 四、种族 / 生物
- 名称：哥布林
- 特征：在人族领域相当于老鼠般的存在。身长约半个人高，手持棍棒等武器，皮肤呈黄绿色，繁殖力极强，对人类不利。能听懂人类语言因而被归类为魔兽，但大多顺从本能行动，一旦繁殖增多就会被人类驱除。属于E级冒险者或稍微练过剑术的小孩即可对付的弱小魔兽。魔大陆上不存在哥布林。
- 原文依据："所谓的哥布林，在这个世界是等同于老鼠的存在。繁殖力强大，而且会对人类不利。基本上能够听懂语言所以被分类为魔兽，然而尽管能听懂语言还是按照本能生存的个体却占了多数，因此要是增加（似乎）就会遭到驱除。"；"以层级来看，哥布林应该是E级冒险者就可以对付的敌人。因为魔大陆上没有哥布林所以我还没有实际看过，不过有听说过那是稍微练过剑术的小孩就能打倒的对手。"

- 名称：家鸡
- 特征：布耶纳村和米里斯神圣国均普遍饲养家鸡，产出的鸡蛋新鲜且价格极为便宜。中央大陆北部至东部一带则缺乏养鸡业。
- 原文依据："布耶纳村里有养鸡人家，米里斯似乎也很盛行养鸡。"；"鸡蛋的贩卖价格极为便宜。而且是新鲜的鸡蛋，今天刚采收的鸡蛋。"；"不过，在那一带似乎没有养鸡。不知道是因为气候不合还是因为没有鸡，总之要取得鸡蛋似乎很难。"

- 名称：斯佩路德族乘船限制 [存疑]
- 特征：斯佩路德族特征为翠绿色头发，被世人视为恐怖的象征。带其乘船前往中央大陆所需的费用极高或手续极为繁琐。
- 原文依据："现在是光头所以看不出来，但他的种族其实是拥有翠绿色头发的斯佩路德族。在这个世界，绿色头发的魔族被认定为恐怖的象徵。"；"而且，也不知道斯佩路德族要搭上船会需要多少钱。"

## 五、物品 / 道具 / 武器
- 名称：魔兽之蛋
- 说明：魔大陆商店偶有贩售，价格昂贵且不能作为普通食物食用，其用途是借助铭印作用来驯养魔兽。
- 原文依据："魔大陆上偶尔也会有卖蛋的商店，但不是鸡蛋，而是魔兽的蛋。据说是利用铭印作用来驯养魔兽。当然那并不是食物，价钱也没有便宜到可以随手拿来煎成荷包蛋。"

- 名称：黄豆类似植物 [存疑]
- 说明：植物辞典中记载有外观极为接近黄豆的植物，但该世界尚未有人将其发酵加工制成酱汁（酱油）。
- 原文依据："根据植物辞典，好像有非常类似黄豆的植物，但是没有人尝试过把那种植物拿来发酵并加工成酱汁。"

- 名称：比基尼型铠甲
- 说明：女性剑士穿着的超高暴露度铠甲。理论设计意图应为固定胸部避免战斗妨碍，但在实战中亦可能造成剧烈晃动，具有干扰诱惑敌方视线的效果。
- 原文依据："一个穿着比基尼型铠甲的女战士……只有女战士的裸露程度高得异常。连在魔大陆上，我也没见过这种活像暴露狂的女性。"；"真奇怪，比基尼型铠甲的功能之一应该是把胸部固定住，以免妨碍到战斗才对。"

- 名称：魔力附加品 [存疑/概念]
- 说明：仓库战斗中杂兵见到鲁迪乌斯快速释放强力魔术时，怀疑其身上穿戴或使用了能附加魔力的特殊装备道具。
- 原文依据："「那是怎么回事？对方使用了魔力附加品吗？」"

## 六、历史 / 传说 / 事件
- 事件名：布莱迪康德著《行遍世界》
- 内容：冒险家布莱迪康德所写的世界游记书籍，评价米里希昂为“尊严与调和，同时拥有两者的这里是世界上最美丽的都市”。
- 原文依据："尊严与调和，同时拥有两者的这里是世界上最美丽的都市。节录自《行遍世界》，冒险家，布莱迪康德着。"

- 事件名：菲托亚领地转移事件（经历时间与距离节点）
- 内容：约一年半前，以要塞都市罗亚为中心发生大规模灾害，鲁迪乌斯等人被卷入并转移至魔大陆；花费一年多横贯魔大陆、在大森林度过四个月（含在德路迪亚村任警卫三个月）后，终于抵达人族领域的米里斯神圣国。
- 原文依据："差不多在一年半前，我被灾害牵连，被迫转移到名为魔大陆的地方。"；"在魔大陆上花了一年多，在大森林里度过四个月。"；"转移之光从要塞都市罗亚往外扩张。"

## 七、社会规则 / 习俗 / 文化
- 内容：
  1. **米里希昂入城通行惯例**：外地人进入米里希昂如果从南侧冒险者区以外的区域进出，容易引起城防不必要的盘查与怀疑，浪费时间，因而外来者通常选择绕行自冒险者区进入。
  2. **马厩行李托运服务**：米里希昂大都市的马厩为了竞争，提供代客直接将大件行李送往所选旅社的服务。
  3. **米里斯货币与人族物价**：人族领域物价显著高于魔大陆；米里斯的货币价值极高，在全大陆仅次于阿斯拉王国位列世界第二。由于币值坚挺且委托报酬丰厚，冒险者通常会选择在此集中承接委托筹措后续长途旅费。
  4. **奴隶需求与绑架犯罪链**：由于当前世界总体处于相对和平时期，合法奴隶来源（战俘等）供给不足，主要仅从中北部流出；但阿斯拉王国和米里斯神圣国等富裕国家的贵族阶层对奴隶需求旺盛，导致诱拐绑架儿童成为极高暴利的灰色产业链，屡禁不绝。在米里希昂，奴隶市场甚至设立在冒险者区而非普通商业区。
  5. **跨国信件投递损耗率**：大陆跨国间平民信件传递容易遗失（如阿斯拉与西隆之间往来信件约七封丢失一封），通常需重复寄发数封以保证送达。
  6. **主食文化分布**：阿斯拉王国与米里斯神圣国均以面包为主食；以米为主食的文化圈分布在中央大陆北部往东部一带。
- 原文依据："我们绕了一大圈，从冒险者区进入市内。根据基斯所言，外地人要是从冒险者区以外进出，似乎会引起不必要的怀疑而浪费更多时间。"；"打听了一下，这里似乎还提供帮忙把行李送往旅社的服务。这是其他城镇都没有的服务。"；"米里斯的货币价值很高，仅次于阿斯拉王国，在世界上是第二名。虽然物价高，但听说委托报酬也高。"；"现今的世界上虽然有些纷争，不过基本上算是和平。讲到奴隶，顶多只会从中央大陆的中部和北部流通一些过来，然而想要奴隶的人却很多。尤其是米里斯神圣国与阿斯拉王国这种比较有钱的国家特别显着。……只要能掳到人，就可以卖到高价。因此绑架集团不会消失。另外，听说奴隶市场也不是位于商业区而是在这一区。"；"送出的信件能顺利寄到的可能性并不高。和洛琪希在阿斯拉与西隆之间书信往来时，七封会寄丢一封。"；"和阿斯拉王国相同，米里斯神圣国的主食似乎也是面包，没看到市场上有卖米。不过基本上，我已经确认过这世界有米。以米作为主食的地区，是从中央大陆北部往东部那一带。"
