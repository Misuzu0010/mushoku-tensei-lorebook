# 第五话　「再度确认方针」 世界设定提取

## 一、地理与场所
- 名称：菲托亚领地（灾后现状）
  - 内容：菲托亚领地内的物体几乎全数消灭，小至羽毛笔、墨水瓶等杂物，大至房屋、桥梁等建筑全部彻底消失无踪，仅随身携带的衣物物品一同转移。
  - 原文依据："根据保罗所说，菲托亚领地内的物体几乎全数消灭。小从羽毛笔墨水瓶这些杂物，大至房舍桥梁之类的建筑，所有一切全都消失无踪。似乎只剩下随身的衣服物品有一起转移。"
- 名称：米里斯至阿斯拉通商路线
  - 内容：从米里斯通往阿斯拉王国的路程，被视为世界上通行人数最多、居住商人最多的交通要道，相当于这个世界的“丝绸之路”。
  - 原文依据："从米里斯通往阿斯拉的路程。是这世界上被视为通行人数最多，也居住着最多商人的地方，等于是这世界的丝绸之路。"
- 名称：西部港
  - 内容：米里斯大陆渡海通往中央大陆的港口，海关由讨厌魔族的贵族（巴克席尔公爵）管理，对魔族渡海盘查极严。
  - 原文依据："现在还不清楚在西部港需要花多少钱，我想费用应该还是很惊人吧。……而且掌管西部港海关的贵族是出了名的讨厌魔族。就算准备好费用，或许也会坚持不放行。"
- 名称：白之宫
  - 内容：位于米里希昂中央大湖湖心的宫殿（神圣国统治中枢/教皇宫殿）。
  - 原文依据："如果比那里小，就不会是湖中央的白之宫。"
- 名称：奇希里斯城
  - 内容：魔大陆魔王奇希莉卡的城堡，规模极其宏大，被瑞杰路德用来对比贾修宅邸的大小。
  - 原文依据："『大约有多大？』『没有奇希里斯城那么大。』"

## 二、组织与势力
- 名称：菲托亚领地搜索团（米里希昂分部财务与职能）
  - 内容：阿尔冯斯从菲托亚领地寄放了一笔相当于20张王钞的资金在保罗处，专供接应用；资金由团员雪拉负责管理，雪拉记忆力强、熟悉各项海关与通行法律。
  - 原文依据："阿尔冯斯大人的确有寄放了一笔资金，供我们在找到伯雷亚斯家诸位时使用。……因为资金是由雪拉负责管理。"
- 名称：跨国走私组织
  - 内容：盘踞于各港口大陆之间的地下走私网络，各分支组织之间疑似互有联络并设有违规偷渡者的黑名单。
  - 原文依据："更何况之前的事也发生在同样这片大陆上。很有可能走私组织之间已经互相联系，把我们列在黑名单上。"
- 名称：塞妮丝娘家（米里斯贵族拉托雷亚家）
  - 内容：米里斯神圣国的名门贵族，在此次搜救过程中保罗借用其势力已经“几乎越线”，无法再拜托其插手海关放行事务。
  - 原文依据："「能不能靠母亲大人娘家的力量帮忙处理一下？」「抱歉，这次的事情已经让那边几乎越线，不能再添更多麻烦。」"

## 三、力量体系 / 魔法 / 技能
- 名称：无咏唱治愈魔术
  - 规则：极难掌握的高等技能。希露菲能够无咏唱施展治愈魔术，让塞妮丝非常吃惊；鲁迪乌斯虽然擅长四谷攻击魔术无咏唱，但无法无咏唱使出治愈魔术，因其无法理解利用魔力治好伤口的运作机制；魔术存在适性与才能差异。
  - 原文依据："「别担心，她甚至能无咏唱使出治愈魔术，无论去到哪里都能活下去。因为在米里斯大陆以外的地方，治愈术师都算是相当贵重。」""我无法省略咏唱直接使出治愈魔术，因为我不懂其中的原理。无论使用多少次，我都无法理解利用魔术治好伤口的机制。""虽然我不太清楚魔术的事情，但听说过魔术这种东西讲求适合与否。或许希露菲有那方面的才能吧？"
- 名称：斯佩路德族的额头之眼（「眼睛」）
  - 规则：斯佩路德族额头中央的第三只眼，具备远距离、广范围搜寻与感知人物动向的能力。
  - 原文依据："直到这次为了从冒险者区的入口进入城市内而绕着外围移动时，『眼睛』突然捕捉到贾修的身影，才又想起这件往事。"

## 四、种族 / 生物
- 名称：治愈术师
  - 特征：在米里斯大陆以外的地区（如魔大陆、中央大陆等）属于相当稀缺贵重的存在。
  - 原文依据："因为在米里斯大陆以外的地方，治愈术师都算是相当贵重。"
- 名称：斯佩路德族（法律处境）
  - 特征：在历史迫害斯佩路德族最为严重的时期，各国制定了针对该族的严苛歧视性法律，要求缴纳普通人百倍以上的渡海巨款（100张王钞），且掌管海关的贵族往往仍可能拒绝放行。
  - 原文依据："「雪拉，斯佩路德族渡海需要缴交多少钱？」「要一百张王钞。」……「为什么只有斯佩路德族的费用特别高啊？」「因为制定这条法律时，正好碰上对斯佩路德族的迫害最为严重的时期。」"

## 五、物品 / 道具 / 武器
- 名称：王钞
  - 说明：米里斯神圣国最高面额的货币。以石钱＝1日圆计算，1张王钞等于5万石钱（5万日圆）。20张王钞等于100万石钱/日圆（相当于1000枚绿矿钱，可在南部购置房屋）；100张王钞等于500万石钱/日圆。
  - 原文依据："相当于二十张王钞。……王钞是米里斯价值最高的货币。如果按照石钱＝日币一圆来计算，一张王钞等于五万。所以二十张换算之后……一百万圆！……我想大概可以在南部盖个房子，但是没办法一辈子吃喝玩乐啦。换算成绿矿钱是一千枚耶！连斯佩路德族都能搭上船！……要一百张王钞。……差不多等于五百万。"
- 名称：傲慢水龙王
  - 说明：鲁迪乌斯十岁生日获赠的高级贵重魔杖。
  - 原文依据："高价的魔杖，不过有着『傲慢水龙王』这种让人有点难为情的名字。"
- 名称：致巴克席尔公爵的介绍信（封蜡公文）
  - 说明：贾修・布拉修写给西部港海关负责人巴克席尔公爵的信函，背面封有带粗犷纹章花纹的红色彩蜡，此类信函一旦封蜡破损便会失效。
  - 原文依据："上面潦草地写着『巴克席尔公爵收』。背面盖着红色封蜡，花纹应该是家徽吧。感觉相当粗犷。……贾修就写了这东西，要瑞杰路德去到西部港时拿出来给海关看。……这种东西好像封蜡破了就会失去效用？"

## 六、历史 / 传说 / 事件
- 事件名：瑞杰路德与贾修・布拉修40年前的相遇
  - 内容：40年前在魔大陆，瑞杰路德解救了遭遇魔物袭击濒临全灭的人群，当时还是小孩的贾修就在其中；贾修离别时对瑞杰路德心怀感激并相约于米里希昂，40年后两人重逢相谈甚欢，贾修主动为其写通关介绍信。
  - 原文依据："据说瑞杰路德跟这个贾修是在四十年前相遇。地点是魔大陆。瑞杰路德帮助了遭到魔物袭击即将全灭的一行人，贾修似乎是其中之一。据说当时的贾修还是个小孩……"
- 事件名：菲利普的入赘协议信
  - 内容：在转移事件约一年前，菲利普私下致信保罗，称鲁迪乌斯与艾莉丝感情甚好且本人意志已定，欲安排鲁迪入赘伯雷亚斯家成为贵族，保罗回信予以同意。
  - 原文依据："大概是转移事件的一年前吧，我收到一封信，说你和艾莉丝的感情很好，你本人的意思也已经慢慢定下来了，所以想让你入赘他们家。虽然我认为阿斯拉贵族跟屎没两样，不过还是有回信说如果你已经决定，那就随你高兴……"

## 七、社会规则 / 习俗 / 文化
- 内容：阿斯拉王国十岁生日习俗：对于阿斯拉国民而言，十岁是人生的重要分水岭与吉日，会盛大庆祝并赠送贵重礼物。
  - 原文依据："对于阿斯拉王国的人民来说，十岁是人生的分水岭之一，也是极为重要的生日。虽然我依旧不懂为什么很重要，但总之是一种吉日吧。反正会盛大庆祝，还会赠送礼物。"
- 内容：保罗家一夫二妻的夫妻协定：塞妮丝与莉莉雅商议决定，平时保罗不得与莉莉雅发生性关系；但若塞妮丝怀了第三胎且保罗无法忍耐时，经塞妮丝许可方可同房。
  - 原文依据："听说经过塞妮丝与莉莉雅两人的多次讨论，后来演变成基本上保罗不能和莉莉雅有性接触的状况。不过如果塞妮丝怀了第三胎，保罗也实在无法忍耐，届时他能够徵求许可。"
- 内容：跨海通行法律限制：世界各国对陆路边境跨国查验较松，但对渡海管控极严，尤其魔族渡海需依专门法缴纳超额税金，并受海关领主好恶影响。
  - 原文依据："在这个世界里，渡海似乎具备某种特别的意义。如果是走陆路进入他国，多得是能蒙混过去的办法，只有想渡过大海时没那么简单。尤其是斯佩路德族。"

## 九、角色认知 vs 客观事实
- 角色以为：保罗以为鲁迪乌斯在罗亚早已与艾莉丝定情，旅途中整日缠绵卿卿我我，且早已知晓并同意入赘伯雷亚斯・格雷拉特家成为阿斯拉贵族。
- 原文是否暗示另有真相：是。鲁迪与艾莉丝并无私情，鲁迪此前根本不知道入赘一事，完全是菲利普瞒着鲁迪提前拉拢保罗设下的贵族政治圈套。
- 原文依据："「你怎么还问我什么时候？大概是转移事件的一年前吧，我收到一封信……想让你入赘他们家。」原来如此。也就是说在我十岁的时候，菲利普已经事先摆平了保罗这边。……看这情况，我们是中了菲利普的圈套。"
- 角色以为：鲁迪以为自己掌握了全套魔术技巧，希露菲施展治愈魔术也必定和自己一样需要念诵咒文。
- 原文是否暗示另有真相：是。保罗告知希露菲竟能无咏唱使用治愈魔术，而鲁迪自己因无法理解伤口愈合原理而完全无法省略咏唱施展治愈魔法。
- 原文依据："「请等一下，您说希露菲能无咏唱使用治愈魔术？」「嗯？噢，对啊，让塞妮丝很惊讶呢。不过，鲁迪你也会吧？」「治愈魔术的话就不会。我无法省略咏唱直接使出治愈魔术，因为我不懂其中的原理。」"
- 角色以为：艾莉丝坚信保罗不出席十岁生日、在鲁迪渡过千难万险后还将鲁迪打得身心崩溃，是个毫无辩解余地、不可原谅的恶劣父亲。
- 原文是否暗示另有真相：是。保罗在转移灾害中失去了家园和妻子女儿，独自背负整个搜索团的绝望重担而精神崩溃；鲁迪和保罗已坦诚相对并达成彻底和解。
- 原文依据："「那家伙连鲁迪乌斯过十岁生日时都没来！而且你后来先是在魔大陆上经历那么辛苦的旅程！……为什么你可以原谅他！」「父亲大人也是人，当然会有失败的时候。」"
