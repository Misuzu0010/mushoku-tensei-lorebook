# 第六话　「待在米里希昂的一星期」 世界设定提取

## 一、地理与场所
- 名称：菲托亚领地搜索团米里希昂根据地
  - 内容：平凡无奇的两层楼建筑，内部设有会议室、等候室，以及供难民与团员年幼子女玩积木玩具的托儿所等生活功能设施。
  - 原文依据："那是一栋平凡无奇的两层楼建筑。在其中类似会议室的一个房间里，保罗正在非常认真地工作。……并在某个房间里发现正在玩耍的诺伦。周围还有其他外表和诺伦差不多年纪的小孩，他们开开心心地玩着像是积木的东西。这里大概是托儿所之类的设施吧。……因此我回到像是等候室的地方，决定留在这里等保罗。"
- 名称：米里希昂冒险者公会总部
  - 内容：冒险者公会的总部所在地，外观宏伟的两层楼建筑，是鲁迪乌斯所见过的最大规模公会据点。
  - 原文依据："来到米里希昂的冒险者公会。不愧是冒险者公会的总部，拥有宏伟的外观。是一栋两层楼的建筑物，也是我至今看过最大规模的公会。"
- 名称：餐厅「Rage Milis」
  - 内容：位于米里希昂商业区的餐厅兼酒馆，无附设旅社，客人主要为普通市民，无严格着装守则，为搜索团平日定点聚餐处。招牌菜有南方海域的海鲜浓汤，以及当地农家饲养、口味浓厚扎实的炖煮牛肉。
  - 原文依据："好像是一间位于商业区，叫作『Rage Milis』的餐厅。……是一间没有附设旅店的酒馆，客人似乎以市民为主，没有那种浮躁危险的感觉。……『材料来自南方海域的海鲜浓汤，这很好吃。还有牛肉，这一带有很多养牛的农家，而且和阿斯拉的牛肉口味不同，通常采用炖煮方式调理，不过味道浓厚扎实，会让人上瘾。』"
- 名称：米里希昂市区治安与市容
  - 内容：小巷中潜伏众多绑架犯等不法分子；大街用餐高峰期常有售卖类似烤鸡串的摊贩，人流拥挤易生摩擦；近期频发奴隶绑架案与暴乱事件。
  - 原文依据："因为小巷子里有很多绑架犯，有的地方可能会刮起腥风血雨。然而大街上也充满危险。由于现在是用餐时间，有不少在摊位上买了类似烤鸡串的家伙正在路上晃来晃去。……最近经常发生奴隶被绑架之类的可疑案件，让骑士团原本就处于战战兢兢的状态……"
- 名称：米里希昂周边魔物环境
  - 内容：相比魔大陆魔物危险度极低、体型小，大多数仅及人类膝盖高度。常见魔物有体型偏大的蚱蜢「巨大蝗虫」、肉食性兔子「割肉兔」、巨大蚯蚓「岩石蠕虫」。
  - 原文依据："接下来我着手调查米里希昂周遭的魔物情报。和魔大陆相比，威胁度似乎有很大的落差。这里有名叫巨大蝗虫，但只是体型大了点的蚱蜢，还有名叫割肉兔的肉食兔子以及叫作岩石蠕虫的巨大蚯蚓等等。都是些危险度非常低的生物。……在米里希昂的周遭，大多数的魔物都只到人类的膝盖。"

## 二、组织与势力
- 名称：神殿骑士团（米里斯圣骑士团之一）
  - 内容：米里斯神圣国圣骑士团的分支，也是城市内排斥魔族派系的骨干力量。强烈主张将魔族逐出米里斯大陆，时刻监视市内动静，对在城内引发事端的魔族严厉刁难排挤。前几天护卫神子时遭遇袭击近乎全灭，仅剩部队长生还并被撤职。
  - 原文依据："米里希昂似乎有一个意图排斥魔族的派系。这派系的领导者，是米里斯圣骑士团之一的神殿骑士团。他们强烈主张应该把魔族赶出米里斯大陆。……神殿骑士团随时随地都在监视着城市内部。""前几天这附近似乎发生神子遭到袭击的大事件。负责护卫的神殿骑士团只剩下部队长，其余成员全灭。虽说神子在千钧一发之际获救，但部下全灭的部队长还是被迫扛起责任，听说遭到撤职。"
- 名称：米里斯教团教皇派（共存派）
  - 内容：由现任教皇领导的教团派系，主张与魔族和平共存，为目前米里希昂内部最强势力，因而遏制了神殿骑士团在明面上公开驱逐魔族的行径。
  - 原文依据："目前米里希昂内部势力最强大的派系并不是这些人，而是认为应该和魔族共存的一派。由于这一派的领导者是现任的教皇，因此神殿骑士团并没有明目张胆地排挤魔族。"
- 名称：守护骑士家系
  - 内容：米里斯神圣国的骑士贵族家系，家徽纹章为“羊、鹰、剑”。
  - 原文依据："「羊、鹰、剑……是守护骑士的家系。不过，我对贾修・布拉修这名字没有印象。毕竟我对米里斯贵族也不是那么清楚……」"
- 名称：塞妮丝娘家（拉托雷亚家）
  - 内容：培育出多名优秀骑士的米里斯名门骑士望族。因塞妮丝当年脱离家庭而与之断绝关系，起初不愿出资寻找塞妮丝，但见到外孙女诺伦后态度彻底转变为极其疼爱。
  - 原文依据："听说塞妮丝的娘家是培育出多名优秀骑士的名家，然而塞妮丝等于是被断绝了亲子关系，所以我的外祖父母原本似乎并不打算去寻找她的下落。不过见到诺伦后，态度却有了一百八十度的大转变。"
- 名称：阿斯拉王国伯雷亚斯家族统治层
  - 内容：绍罗斯为菲托亚领地领主，菲利普为市长。菲利普的兄长为詹姆士。保罗推测詹姆士在灾难后为自保极可能将领地覆灭的罪责全部推卸给绍罗斯与菲利普，甚至可能借混乱暗杀二人以绝政敌后患。
  - 原文依据："「也就是菲利普的哥哥詹姆士很有可能会为了自保，把所有的责任都推到哪个人身上。」……绍罗斯是领主，菲利普是市长。他们是领地的负责人。……甚至其他人为了堵死菲利普他哥哥的退路，并在政治面上彻底击溃他，所以趁着混乱谋杀这两人的可能性也很高。"
- 名称：原「黑狼之牙」成员基斯
  - 内容：在原S级冒险者队伍「黑狼之牙」解散后处境最艰难的成员。自身欠缺战斗能力，虽样样都会但样样不精，无法单独承接任务亦没有新队伍愿接纳，最终放弃冒险者职业。自称做事遵从“某种忌讳”。
  - 原文依据："基斯应该是因为队伍解散而吃了最多苦的成员。他没有战斗能力，什么事都会做但也什么事都做不到最好，因此其他队伍不愿意让他加入，他个人也无法单独达成任务，到最后不得不放弃冒险者这一行。……「因为有某种忌讳啊。」"

## 三、力量体系 / 魔法 / 技能
- 名称：魔眼（预知眼）
  - 规则：鲁迪乌斯在拥挤街道上解除魔眼封印，通过预知一秒后的未来景象，在熙攘人群中穿梭避开碰撞与沾染污渍。
  - 原文依据："因此，我解除魔眼的封印。一边确认一秒后的景象，同时华丽地避开混杂人群。"
- 名称：土魔术手办/人偶制作
  - 规则：利用土魔术对泥石进行极精密的微观塑形制造逼真人偶（如瑞杰路德像），受到兽族剑王与某国王子的高度评价；但在战斗专家眼里，人偶的武术姿势重心过高、充满破绽。
  - 原文依据："不过这种时候，就是这石像派上用场的机会了。……「对啊，鲁迪乌斯很擅长制作这种东西！」……毕竟是能受到兽族剑王大人以及某国王子赏识的绝佳作品。……「但是，这个姿势满是破绽。」「对啊，这姿势不太好。必须把重心放得更低……」"
- 名称：治愈魔术（治疗术）
  - 规则：鲁迪乌斯用治疗术治愈艾莉丝眼角的挫伤瘀青。
  - 原文依据："最后我说出这句话，并且对艾莉丝眼角的瘀青使出治疗术。"

## 四、种族 / 生物
- 名称：神子
  - 特征：米里斯教团的核心贵重人物，拥有极高地位与特殊护卫配置，前几天在米里希昂周边遭遇神秘袭击险遭杀害。
  - 原文依据："前几天这附近似乎发生神子遭到袭击的大事件。负责护卫的神殿骑士团只剩下部队长，其余成员全灭。虽说神子在千钧一发之际获救……"
- 名称：绿叶虎
  - 特征：B级魔物，原产大森林南部。体色为深浅交杂的绿色带褐色条纹，能完美伪装融入森林背景（极高隐蔽性），通常以数只结群行动；若单只出现在平地，危险性仅相当于D级。被艾莉丝一击斩杀。
  - 原文依据："讨伐对象是绿叶虎。原本是栖息于大森林南部的魔物，却因为某种理由而从大森林往南移动，在村庄附近定居下来。这只魔物的底色是有浓有淡的绿色，还混有褐色的花纹，所以一旦它潜伏在森林里，就会完全融入风景之中。由于具备高度隐密性，再加上通常以数只组成群体来行动，因此被视为是B级的魔物。然而这次的讨伐对象只有一只，而且地点又是平地……顶多只有D级吧。"
- 名称：魔物肉质共性
  - 特征：世界上的魔物肉基本上都极难入口。
  - 原文依据："是大王陆龟的肉吧？魔物的肉基本上都很难吃。"
- 名称：各地魔物形体大小对比
  - 特征：魔大陆的帕克斯郊狼身长两公尺以上，毒酸狼身长超三公尺，大王陆龟平均八公尺、最大超二十公尺；大森林雨季魔物多有人类等大；而米里斯大陆米里希昂周遭魔物普遍只有人类膝盖高。
  - 原文依据："在那片充满考验的大地上，魔物的大小随便都可以超过人类数倍。就连差点被我们赶尽杀绝（夸大）的帕克斯郊狼，身体长度也在两公尺以上。毒酸狼的体型可以超过三公尺。至于大王陆龟的平均大小是八公尺上下，最大的是二十公尺以上。还有在大森林雨季期间看过的那些魔物中，也有很多大小跟人类差不多。相较之下，在米里希昂的周遭，大多数的魔物都只到人类的膝盖。"

## 五、物品 / 道具 / 武器
- 名称：迷宫魔力附加品护手
  - 说明：保罗原定赠予鲁迪乌斯十岁生日的礼物。是保罗在迷宫深处仓库搜获的魔力附加装备，触感如羽毛般轻盈，尺寸不合保罗体型，适合少年鲁迪佩戴。
  - 原文依据："我是要送护手。虽说拿这种在仓库里翻到的东西送你让我有点过意不去，不过基本上那是在迷宫深处找到的魔力附加品。而且像羽毛般轻盈，对我来说尺寸不合，但鲁迪你应该可以使用。"
- 名称：莉莉雅上了锁的小箱子
  - 说明：莉莉雅原准备在鲁迪十岁生日赠送的神秘礼物，装在带锁小箱中，内装物品不明。
  - 原文依据："至于莉莉雅则是以满意表情看着一个上了锁的小箱子，我想那就是礼物吧。"
- 名称：瑞杰路德宣传用石像
  - 说明：鲁迪乌斯制作的瑞杰路德全身泥石塑像，试图作为推销物消除人们对斯佩路德族的恐惧。
  - 原文依据："只要展示这石像并提到瑞杰路德的名字，无论是外表多恐怖的斯佩路德族，对方的态度必定都会瞬间软化……所以，他把石像又塞回给我。"

## 六、历史 / 传说 / 事件
- 事件名：转移灾害前夕的森林魔物异常暴动
  - 内容：在鲁迪十岁生日约一个月前，布耶纳村周边森林里的魔物突然极度活跃，迫使保罗与塞妮丝全力投入清剿导致无暇寄送生日礼物；魔物骚动在生日的前一天平息，次日即爆发了菲托亚领地大转移事件。
  - 原文依据："听说在我十岁生日的约一个月前，森林里魔物的行动突然变活跃了。保罗和塞妮丝忙着因应这种状况，根本没有空寄出生日礼物。这种现象本身在我生日的前一天沉静下来，他们正打算要快点把礼物送出，结果却遭到转移。"
- 事件名：米里希昂神子遭袭事件
  - 内容：近期米里希昂近郊发生的神子暗杀事件。神殿骑士团护卫部队除队长外全灭，神子命悬一线获救，队长遭解职问责。导致神殿骑士团战备高度紧张、无暇兼顾周边村落魔物防卫。
  - 原文依据："前几天这附近似乎发生神子遭到袭击的大事件。负责护卫的神殿骑士团只剩下部队长，其余成员全灭。虽说神子在千钧一发之际获救，但部下全灭的部队长还是被迫扛起责任，听说遭到撤职。……教团和骑士团都在拚命处理。也因此，B级这种高危险的魔物被丢着没人管……"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯式就餐祈祷礼仪：用餐前众人双手在胸前交握、闭目静默数秒，属于米里斯地区的普遍餐前礼节，不论是否为教徒在餐桌上都会入乡随俗遵从。
  - 原文依据："「爸爸，不对！吃饭前要好好祈祷才行！」……之后，众人一起进行米里斯式的祈祷。这是只要握起双手，闭上眼睛几秒钟的祈祷。虽然我和艾莉丝，还有保罗恐怕都不是米里斯教徒，不过这就跟日本人吃饭前的『我要开动了』差不多。所谓入境随俗，因此没有任何人抱怨，大家都摆出这动作。"
- 内容：米里斯当地着装与色彩风尚：当时米里希昂居民穿着以蓝色为主流，因天气晴好，多穿着轻薄便服，有人披外衣有人不披；在人族领地注重体面外表以防受人轻视。
  - 原文依据："毕竟接下来是人族的领域。据说外表会造成先入为主的印象，所以我们至少要打扮成不会被人只看一眼就遭到轻视的模样。……虽说只是比例稍微高了一点，不过穿着蓝色衣服的人确实较多。更进一步来说，有些人穿着外衣也有些人没穿。而且因为天气好，上衣看起来也都比较轻薄。最近流行的颜色好像是蓝色。"
- 内容：米里斯教徒对魔族信物的排斥禁忌：米里斯教徒受教条影响极深，对魔族怀有根深蒂固的种族偏见，即便受到魔族个体的恩惠，也严厉拒绝在居住地收藏或摆放任何魔族的石像与雕塑。
  - 原文依据："他表示虽然对瑞杰路德个人很是感谢，但是这种程度的感谢并无法抵销对魔族全体的偏见。更何况自己等人身为米里斯教徒，对于收藏魔族石像会抱有抗拒感。所以，他把石像又塞回给我。"
