# 闲话　「洛琪希的归乡之旅」 世界设定提取

## 一、地理与场所
- 名称：米格路德族之村
- 内容：洛琪希的故乡，村子外貌历经数年未变，人口略有增加；因全村村民皆以心电感应交流而不开口发声，全村保持着安静到近乎阴森的独特氛围。
- 原文依据："米格路德族之村。村子本身的模样看起来没有改变，连认识的村民也几乎还是同样那些人。尽管居民增加，不过安静到有点阴森的特色倒是一如往常。洛琪希以前并不觉得阴森。只是见识过世界再回来后，这个村子就显得异常。因为明明一片安静也没有任何对话，村民之间却能够沟通。"

- 名称：利卡里斯镇
- 内容：魔大陆城镇，两年前曾发生「Dead End」事件；洛琪希在此处的酒馆与旧队友诺克巴拉重逢并确认鲁迪乌斯的情报。
- 原文依据："来到利卡里斯镇之后，洛琪希终于不得不承认。两年前发生的「Dead End」事件。过去队友诺克巴拉的证词。……现在，洛琪希和诺克巴拉正一起坐在酒馆里吃饭。"

- 名称：圣剑大道
- 内容：连接大森林与米里希昂的道路，本身是一条沿途空无一物的平坦道路，附近分布有长耳族与矿坑族的聚落。
- 原文依据："虽说正好碰上雨季，但圣剑大道是一条什么都没有的道路。只要他们没有绕往长耳族或矿坑族的聚落，那么应该已经到达米里希昂。"

- 名称：魔大陆西北地区
- 内容：魔大陆西北部地域，拥有许多城镇；洛琪希一行推测该地可能也流落有菲托亚领地的转移难民，将其定为接下来的搜寻区域。
- 原文依据："「去探寻魔大陆的西北地区吧。」虽然已经确定鲁迪乌斯的下落，不过依然没有找到另外三人。至今为止的路程中，曾经碰上好几个出身于菲托亚领地的难民。那么，西北地区应该也有难民吧。……「魔大陆还有很多城镇。我们就按照先前那样，一个个前去确认吧。」"

- 名称：温恩港
- 内容：魔大陆港口，半年前洛琪希一行在此处与鲁迪乌斯等人错过。
- 原文依据："彼此是在温恩港错过，之后过了半年。"

## 二、组织与势力
- 名称：Super Blaze
- 内容：洛琪希过去的旧队友布雷兹（猪脸战士）后来担任队长并率领的B级老牌冒险者队伍，最终在魔大陆被A级魔物赤食大蛇全灭。
- 原文依据："听说在他去世之前，已经成长为能率领B级冒险者队伍的老手。在魔大陆上，担任B级冒险者队伍的队长。……不过他取的队伍名称居然叫作Super Blaze。……听说让这种老手队伍全灭的魔物，后来被队伍成立没多久的鲁迪乌斯他们打倒了。"

- 名称：冒险者队伍「Dead End」 / 假Dead End
- 内容：由鲁迪乌斯（人族少年魔术师）、瑞杰路德（斯佩路德族战士）与艾莉丝组成的队伍，在魔大陆曾被称为「假Dead End」以及「Dead End的饲主」。
- 原文依据："因为获得「假Dead End」的情报时，总是会同时获得目击鲁迪乌斯的情报。所以旅途中塔尔韩德曾多次指出，即使认定「能无咏唱使出魔术的人族少年」与「假Dead End的饲主」是同一个人，应该也不算是过于夸大的推论。……「Dead End的饲主」就是鲁迪乌斯。"

## 三、力量体系 / 魔法 / 技能
- 名称：米格路德族心电感应能力（念话）
- 规则：米格路德族天生具备的心灵感应交流能力，无需发声即可彼此传达深层心意与爱情低语；洛琪希天生缺乏此能力，仅能听到类似杂音的声响而无法交流。
- 原文依据："洛琪希知道村民们是使用了米格路德族的特殊能力，也就是心电感应向自己搭话。然而洛琪希无法理解。她能稍微听到类似杂音的声响，顶多这样而已。无法回应他们的发言。……无法传达给不会使用米格路德族特殊能力的她。"

- 名称：无咏唱魔术
- 规则：无需咏唱咒文即可释放魔术的技巧。鲁迪乌斯熟练掌握该技巧，并宣扬源于师傅洛琪希，导致外界误以为洛琪希本人亦拥有无咏唱施法能力。
- 原文依据："即使认定「能无咏唱使出魔术的人族少年」与「假Dead End的饲主」是同一个人……""托他的福，连洛琪希都被视为能够无咏唱施展魔术。明明她根本不可能办到那种事。"

## 四、种族 / 生物
- 名称：米格路德族
- 特征：魔族的一支，成长期后外表长相长期保持幼态成年模样不再改变，寿命漫长（离乡归期常以数十年计）；以心电感应为主要沟通手段，对于他们来说口头语言属于“外国语言”，极少口头表达真挚感情。
- 原文依据："和诺克巴拉他们一起冒险的时候，洛琪希的外表已经是米格路德族的成年人。在那之后，体型等方面都没有明显变化。""「洛琪希……至少二十年要回来一次。」……「……或许五十年内会回来吧。」""对于他们来说，表达担心和欢迎的语言都是一种外国的语言。他们绝对不会把真正重要的话语说出口，尤其是诉说爱情的低语。"

- 名称：赤食大蛇
- 特征：魔大陆的A级强力魔物，曾全灭B级队伍Super Blaze并吞食队长布雷兹，后被初出茅庐的鲁迪乌斯队伍成功讨伐。
- 原文依据："「嗯，听说他被赤食大蛇给整个吞下。」""听说让这种老手队伍全灭的魔物，后来被队伍成立没多久的鲁迪乌斯他们打倒了。才刚开始冒险，立刻成功讨伐A级魔物。"

- 名称：石魔木
- 特征：魔大陆上的植物/魔木，其种子可炒制食用。
- 原文依据："这个豆子是石魔木的种子。根据洛琪希的味觉，她并不觉得好吃。只是，她依旧不由自主地一口接着一口。有种会让人上瘾的味道。"

- 名称：长耳族 / 矿坑族
- 特征：在米里斯大陆大森林至圣剑大道沿线设有聚落的种族。
- 原文依据："只要他们没有绕往长耳族或矿坑族的聚落，那么应该已经到达米里希昂。"

- 名称：斯佩路德族
- 特征：声名狼藉、令魔大陆住民洛琪希感到极度惧怕的魔族。
- 原文依据："甚至还在途中让洛琪希非常惧怕的斯佩路德族成为伙伴。"

## 五、物品 / 道具 / 武器
- 名称：石魔木的种子（炒豆子）
- 说明：魔大陆酒馆常见的下酒菜，味道虽称不上美味但具有让人一口接一口停不下来的成瘾性风味。
- 原文依据："洛琪希一边回答，一边吃着下酒用的炒豆子。这个豆子是石魔木的种子。根据洛琪希的味觉，她并不觉得好吃。只是，她依旧不由自主地一口接着一口。有种会让人上瘾的味道。"

- 名称：魔大陆特有的烈酒
- 说明：魔大陆酒馆提供的度数极高的特色烈酒。
- 原文依据："诺克巴拉啜饮着魔大陆特有的烈酒，喃喃说了这句话。"

## 六、历史 / 传说 / 事件
- 事件名：两年前的利卡里斯镇「Dead End」事件与赤食大蛇讨伐
- 内容：两年前鲁迪乌斯一行在利卡里斯镇登记为冒险者，斩杀全灭了B级队伍Super Blaze的A级魔物赤食大蛇，获得「Dead End的饲主」之名。
- 原文依据："两年前发生的「Dead End」事件。过去队友诺克巴拉的证词。还有故乡双亲的证言──统合所有情报后，洛琪希终于承认。「Dead End的饲主」就是鲁迪乌斯。""听说让这种老手队伍全灭的魔物，后来被队伍成立没多久的鲁迪乌斯他们打倒了。才刚开始冒险，立刻成功讨伐A级魔物。"

- 事件名：菲托亚领地灾害难民流散魔大陆
- 内容：大转移灾难后，菲托亚领地难民散落于魔大陆各地，洛琪希一行在北上搜寻途中曾多次遇见难民。
- 原文依据："虽然已经确定鲁迪乌斯的下落，不过依然没有找到另外三人。至今为止的路程中，曾经碰上好几个出身于菲托亚领地的难民。那么，西北地区应该也有难民吧。"

## 七、社会规则 / 习俗 / 文化
- 内容：米格路德族的情感与语言表达文化：心电感应是米格路德族最核心的交流方式，他们不习惯用口头语言传达真正重要的情感低语与爱意；口头发声被视为外来交流工具，因而亲人间的思念常借由肢体拥抱与泪水等无声形式传达。
- 原文依据："因为明明一片安静也没有任何对话，村民之间却能够沟通。……对于他们来说，表达担心和欢迎的语言都是一种外国的语言。他们绝对不会把真正重要的话语说出口，尤其是诉说爱情的低语。……这时，洛琪希终于明白。话语并不能代表一切。"

- 内容：魔大陆生存环境与冒险者分化法则：魔大陆生存环境严峻残酷，老手冒险者在同伴相继战死或队伍解散后，因生活所迫转入不可告人的偏门行业属于常见且无可奈何的现实。
- 原文依据："打听鲁迪乌斯的消息时，诺克巴拉表现出难以启口的态度。看样子他似乎转行去做了什么不可告人的行业。以洛琪希来说，她并不打算针对这点指责诺克巴拉。毕竟在魔大陆上，那也是无可奈何的选择。"

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希此前一直不愿承认传闻中声名狼藉的「假Dead End的饲主」与「无咏唱使出魔术的人族少年」就是自己的徒弟鲁迪乌斯。
- 原文是否暗示另有真相：是。客观事实两者确为同一人，塔尔韩德早有正确推断，洛琪希综合诺克巴拉及父母的证言后最终不得不承认该事实。
- 原文依据："「Dead End的饲主」的真实身分其实就是鲁迪乌斯・格雷拉特。洛琪希花了一些时间，才总算接受这个事实。……因为获得「假Dead End」的情报时，总是会同时获得目击鲁迪乌斯的情报。所以旅途中塔尔韩德曾多次指出，即使认定「能无咏唱使出魔术的人族少年」与「假Dead End的饲主」是同一个人，应该也不算是过于夸大的推论。不，其实洛琪希打从一开始就已经察觉。她只是不想承认自己没有注意到这点而和鲁迪乌斯不巧错过。"

- 角色以为：魔大陆上的外界冒险者与人们以为鲁迪乌斯的师傅洛琪希也精通无咏唱魔术。
- 原文是否暗示另有真相：否。客观事实是洛琪希根本无法做到无咏唱施展魔术，该传闻完全是鲁迪乌斯到处夸耀宣扬师傅所带来的误解。
- 原文依据："听说鲁迪乌斯动不动就宣传「一切都要感谢师傅的教诲」。托他的福，连洛琪希都被视为能够无咏唱施展魔术。明明她根本不可能办到那种事。"

- 角色以为：洛琪希以为鲁迪乌斯带着艾莉丝越过魔大陆是「轻轻松松」「轻松干脆」地完成的旅程。
- 原文是否暗示另有真相：是。鲁迪乌斯一行在魔大陆经历了被通缉、遭遇凶恶魔兽、与绑架犯搏斗等众多生死磨难，绝非轻轻松松。
- 原文依据："鲁迪乌斯就是带着那女孩，轻轻松松地越过魔大陆。一般来说应该会在某处遭遇挫折，他却如此轻松乾脆地解决。"
