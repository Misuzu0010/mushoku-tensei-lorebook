# 闲话　「艾莉丝的哥布林讨伐」 世界设定提取

## 一、地理与场所
- 名称：米里希昂市内的孤儿院
- 内容：位于米里希昂市内，是米里斯教团威信与权威的象征，资金充足，营运宽裕，孤儿成长不受限并可被领养。
- 原文依据："那家孤儿院位于米里希昂市内，可以说是米里斯教团之威信与权威的象徵。因此当然不需要为孤儿院的营运状况烦恼，孩子们在成长时也不会受到限制，一个个被领养离开。"

- 名称：神圣区与冒险者区
- 内容：米里希昂市内划分的不同区域，克里夫为了登记成为冒险者，从神圣区来到冒险者区。
- 原文依据："他带着养父在十岁生日时赠送的魔杖，从神圣区来到冒险者区，买了件看起来颇有魔术师风格的长袍……"

- 名称：米里希昂冒险者公会总部
- 内容：位于大街尽头，是冒险者区内最大的建筑物，内部大厅极其宽广（超过罗亚老家宴会厅），设有张贴海量委托的巨大告示板。
- 原文依据："米里希昂的冒险者公会位于大街的尽头。不愧是总部，是冒险者区里最大的建筑物。""但是看到规模惊人的大厅后，她差点不由自主地双手抱胸。因为这里不只比罗亚老家的宴会厅还大，也比过去见过的每一间冒险者公会都宽广。""比其他公会还大上许多的这面告示板上贴满了委托案件。"

- 名称：米里希昂东方森林与平原
- 内容：位于米里希昂东侧，平原与森林交界处栖息着哥布林，深处昏暗的森林中栖息着猩猩型魔物乌坦等。
- 原文依据："地点：米里希昂东方。""哥布林是栖息在森林和平原交界处附近的魔物。""两人踏进昏暗的森林。"

- 名称：中央大陆南部
- 内容：人族男孩子们向往冒险时讨论的进阶冒险区域，有高难度的委托和迷宫。
- 原文依据："将来再前往中央大陆的南部，挑战高难度的委托和迷宫。就是这类的梦想。"

## 二、组织与势力
- 名称：米里斯教团
- 内容：米里斯神圣国的宗教统治势力，在米里希昂设有孤儿院和战斗学校；内部存在激烈的派系权力斗争（教皇派与大主教派）。
- 原文依据："克里夫刚出生的那段时期，司铎正忙于权力斗争。克里夫的双亲受到波及而丧命。司铎为了让孙子克里夫能够远离这些权力斗争，把他暂时寄放到孤儿院里。之后，司铎在权力斗争中胜利并成为教皇……""那是目前正和祖父对立的大主教一派的王牌，据说拥有奇迹之力的神子。"

- 名称：圣堂骑士团
- 内容：米里斯三大骑士团之一，身穿白色铠甲，是负责米里斯本国防卫的精英集团。
- 原文依据："负责米里斯本国防卫的精英集团，圣堂骑士团。""圣堂骑士团是白。"

- 名称：教导骑士团
- 内容：米里斯三大骑士团之一，身穿银色铠甲，行径类似佣兵，负责在世界上推广米里斯教义并宣扬教团威势。
- 原文依据："还有行径类似佣兵，负责在世界上推广米里斯教义，宣扬米里斯教威势的教导骑士团。""教导骑士团是银。"

- 名称：神殿骑士团
- 内容：米里斯三大骑士团之一，身穿苍天色（蓝色）铠甲，拥有异端审问官，负责审判并定罪异教徒，在外界是恐怖的代名词；团内主张排除魔族。
- 原文依据："最后是拥有异端审问官，审判并定罪异教徒的恐怖代名词，神殿骑士团。""神殿骑士团则装备蓝色铠甲。即使从远方，也能看出来那铠甲是苍天色。""艾莉丝并不知道，神殿骑士团主张要排除魔族。"

- 名称：教皇派暗杀集团
- 内容：直属米里斯教皇派系的高手暗杀团队，平日担任克里夫的魔术与战斗教师，暗中执行针对政敌大主教派神子的刺杀行动。
- 原文依据："那群黑衣人一定是米里斯教皇手下的暗杀集团，全都是一些高手……""那些人是教导克里夫的老师们。克里夫之前就已经发现，他们必须负责这方面的工作。"

## 三、力量体系 / 魔法 / 技能
- 名称：多属性魔术分级（初级、中级、上级、圣级）
- 规则：魔术包含治疗、解毒、神击及四属性攻击魔术，分为初级到上级乃至圣级以上。一般魔术师多专精单一属性或圣级，全面达到上级水准者极为罕见。
- 原文依据："短短几年内就迅速学会治疗、解毒、神击等魔术的上级。攻击魔术方面也能使用所有属性的中级，甚至火魔术还达到了上级水准。""有能使用圣级治愈魔术的人，也有能使用圣级解毒魔术的人。然而如果所有魔术都要具备上级水准，就只有克里夫一个人办得到。""魔术可分为初级到上级，还有更高的等级"

- 名称：上级火焰魔术「狱炎火弹」
- 规则：需要冗长咏唱的高阶火属性攻击魔术，可瞬间消灭复数哥布林，但会将目标彻底烧成焦炭导致无法回收部位素材。
- 原文依据："上级火焰魔术「狱炎火弹」。她曾经看过鲁迪乌斯使用这一招。那时他并没有像克里夫这样啰哩啰嗦地咏唱了一大串，而且威力也强大得多。不过，如果是鲁迪乌斯，想必不会对区区哥布林用出这种魔术。因为鲁迪乌斯肯定不会犯下无法取得报酬用耳朵的失败。"

- 名称：剑神流上级技「无音之太刀」
- 规则：剑神流的上级剑技，位阶低于「光之太刀」，斩击时不会产生划破空气的风声，速度极快难以预判。
- 原文依据："这是剑神流上级技「无音之太刀」。比「光之太刀」等级较低的这个剑技不会造成任何划破空气的风声。"

- 名称：动静感知技术（气息察觉）
- 规则：停止自身行动，即使没有斯佩路德族的额头第三只眼，也能通过声音、空气流动以及魔力流动感知敌人的方位与战况。
- 原文依据："瑞杰路德也传授了探寻动静的方法。即使没有第三只眼睛，还是能够感觉到声音和空气，以及魔力的流动。"

- 名称：神子奇迹之力
- 规则：神子天生具备的未知特殊力量（被称为奇迹之力），使其具备极高政治与宗教价值，成为下任教皇候选人。
- 原文依据："那女孩是被视为下任教皇候选人的神子。也就是说……那是目前正和祖父对立的大主教一派的王牌，据说拥有奇迹之力的神子。"

## 四、种族 / 生物
- 名称：哥布林
- 特征：栖息在森林与平原交界处的弱小人形魔物，能使用简单武器，听不懂人族语言。数量少时危害不大，长期放置会大量繁殖并袭击村庄。栖息于森林外围能充当阻挡森林深处魔物的防波堤；在米里斯还被用作拷问敌国间谍的道具，因此不会被全面消灭；偶有大型哥布林出现。
- 原文依据："哥布林是栖息在森林和平原交界处附近的魔物。外观呈现人型，可以使用简单的武器，但听不懂人族语言。如果只有几只还可以放着不管，然而放置太久就会大量繁殖，最后成为开始袭击周遭村庄的有害魔兽。话虽如此，因为它们栖息于森林外围，所以也可以成为防波堤，抵御来自森林里的魔物。另外哥布林很弱，就算是稍微学习过剑术的少年也足以应付它们。……另外，尽管艾莉丝并不知道这件事，不过哥布林这种生物也能够拿来当成拷问敌国间谍的道具。基于以上种种理由，在米里斯并不会把哥布林赶尽杀绝，而是不纵放也不清光，会适度调整它们的数量。""新人要特别小心偶尔会出现的大型哥布林。"

- 名称：乌坦
- 特征：栖息在米里斯森林中的猩猩型魔物，危险度评级为D级。
- 原文依据："艾莉丝边说，边随手砍死一种叫作乌坦的猩猩型魔物。虽然这是D级的魔物，但不是艾莉丝的对手。"

- 名称：小人族
- 特征：亚人种族之一，可与人族通婚生育（克里夫的祖母即为小人族女性）。
- 原文依据："米里斯教团的一位司铎曾和小人族的女性落入情网。两人之间的孩子长大后和一名女性结婚，生下来的孙子就是克里夫。"

- 名称：帕克斯郊狼
- 特征：栖息于魔大陆的魔物，具备协同作战智力，懂得分别从上下夹击对手。
- 原文依据："也不像魔大陆上的帕克斯郊狼那样，懂得分别从上下夹击的互动战术。"

- 名称：斯佩路德族
- 特征：受到米里斯神殿骑士团极度厌恶并主张予以排除的魔族。
- 原文依据："一听到「斯佩路德族」，特蕾兹的表情变得很凝重。艾莉丝并不知道，神殿骑士团主张要排除魔族。……还自称为受到神殿骑士厌恶的种族"

## 五、物品 / 道具 / 武器
- 名称：哥布林耳朵
- 说明：冒险者讨伐哥布林的报酬凭据素材，一只耳朵可兑换十枚米里斯铜币。
- 原文依据："・报酬：一只耳朵支付十枚米里斯铜币。""哥布林们完全被烧成焦炭，呈现无法取得耳朵的状态。……因为鲁迪乌斯肯定不会犯下无法取得报酬用耳朵的失败。"

- 名称：涂毒短刀
- 说明：暗杀集团黑衣人使用的贴身武器，刀刃淬毒，命中一次即可造成致命伤。
- 原文依据："「那些家伙的短刀上有毒！要小心！」""而且对方的武器是涂着毒的短刀，是只要击中一次就能造成致命伤的武器。"

- 名称：克里夫的高级魔杖
- 说明：克里夫十岁生日时养父（现教皇）赠送的魔杖，镶嵌有相当高价的大型魔石。
- 原文依据："他带着养父在十岁生日时赠送的魔杖……手上的魔杖虽然没有鲁迪乌斯的「傲慢水龙王」那么高级，不过根据魔石的大小，还是看得出来使用了相当高价的材料。"

## 六、历史 / 传说 / 事件
- 事件名：米里斯教团派系斗争与神子遭暗杀未遂事件
- 内容：教皇派与大主教派在教团内争夺权力。克里夫年幼时其父母因斗争丧命，祖父成为教皇；如今大主教派拥立具备奇迹之力的神子为下任教皇候选人，教皇派派遣精锐暗杀黑衣人拦截并企图杀害神子，被偶然路过的艾莉丝击杀四名刺客破坏。事后教团内部争斗加剧，教皇将孙子克里夫送往外国避险。
- 原文依据："克里夫刚出生的那段时期，司铎正忙于权力斗争。克里夫的双亲受到波及而丧命。……之后，司铎在权力斗争中胜利并成为教皇……那是目前正和祖父对立的大主教一派的王牌，据说拥有奇迹之力的神子。……那群黑衣人一定是米里斯教皇手下的暗杀集团……之后，这次事件导致教团内的权力斗争更加激烈。认为克里夫留在米里希昂会有危险的教皇把孙子送往其他国家……"

- 事件名：菲托亚领地难民寻人公告
- 内容：米里希昂及赞特港冒险者公会公告栏外侧张贴有针对菲托亚领地转移难民的联络告示。
- 原文依据："在公告栏的外侧贴着一张留言。「出身于菲托亚领地的难民请与下列人员联络。」看到这边，艾莉丝转开视线。她在赞特港的冒险者公会也有看到同样的留言。"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯教团孤儿抚养与培养制度：在孤儿院成长的孤儿若十岁前未被收养，会送入教团附属学校接受五年剑术与魔术战斗训练，优秀者可任骑士，大多数成为冒险者。
- 原文依据："有很多出身于孤儿院的小孩成为冒险者。如果他们在十岁前没有找到愿意收养自己的家庭，就会被送进米里斯教团经营的学校。然后在学校里接受五年的训练，内容是剑术、魔术等用来战斗的课程。就这样，孩子们纷纷开始从事适合自身才能的行业。要是学问、剑术与魔术都很优秀，也有机会成为骑士。不过大部分的人还是选择冒险者这一行。"

- 内容：自由委托机制：国家定期提出的委托，虽然酬劳偏低但紧急度高，不限冒险者层级，所有人均可接取；委托单无需撕下，直接携带指定部位素材至柜台结算。魔大陆因无国家而不存在自由委托。
- 原文依据："所谓的自由委托，是指国家定期提出的委托。虽然报酬偏低，但由于紧急度较高，无论哪个层级的冒险者都可以承接。魔大陆上不会看到这类委托，因为那里没有国家。""此外，请不要撕下这张委托单，直接把收集到的素材拿到柜台即可。"

- 内容：冒险者公会队伍等级壁垒：冒险者队伍招募通常受冒险者等级限制，高阶或成熟队伍一般拒绝与新人低阶冒险者组队。
- 原文依据："「不，我们没办法跟你组队。」……「就说是因为彼此层级不同啊。」"

- 内容：米里斯骑士正规礼仪：米里斯骑士正式敬礼动作为握拳置于腹部前方。
- 原文依据："握拳放到腹部前方，以米里斯骑士的正式动作敬礼。"

## 九、角色认知 vs 客观事实
- 角色以为：艾莉丝以为鲁迪乌斯在冒险者公会不提菲托亚领地留言是出于温柔体贴、不想让自己不安，且当天分开行动也是为了难民之事调查。
- 原文是否暗示另有真相：是。客观事实是鲁迪乌斯完全没注意到公会外侧贴有该留言。
- 原文依据："鲁迪乌斯并不会提起菲托亚领地的事情。艾莉丝认为一定是因为他特别体贴，不愿让自己感到不安。今天的各自行动，大概也是因为鲁迪乌斯想为了这件事做点什么吧。……艾莉丝连作梦都没有想到，原来鲁迪乌斯根本不知道这留言的存在。"

- 角色以为：克里夫以为只要表明自己实力达到A级且是优秀魔术师，冒险者等级高低无所谓，高阶冒险者队伍便会争相接纳自己。
- 原文是否暗示另有真相：否。公会冒险者队伍严格遵守等级差异规则，直接拒绝与其组队。
- 原文依据："克里夫认为组成队伍这种事情跟冒险者层级高低没有关系。「不，我们没办法跟你组队。」所以当然会遭到拒绝。……「就说是因为彼此层级不同啊。」"

- 角色以为：神殿骑士特蕾兹以为红发剑士艾莉丝隐瞒真名、自称斯佩路德族且不求回报，是因为不想被卷入教团深层权力内斗的高风亮节之举。
- 原文是否暗示另有真相：是。艾莉丝完全不懂教团内斗，仅仅是因为崇拜鲁迪乌斯并模仿其平日宣扬「Dead End瑞杰路德」的行径，且根本不知道神殿骑士排斥魔族。
- 原文依据："特蕾兹放松表情。她判断对方不愿报上本名，还自称为受到神殿骑士厌恶的种族，是因为不想和自己等人，更不想和这次事件牵扯过深。艾莉丝这种出手救助重要人士却没有要求谢礼的态度，赢得特蕾兹的好感。……艾莉丝并不知道，神殿骑士团主张要排除魔族。"
