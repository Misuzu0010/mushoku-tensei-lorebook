# 第四话　「和保罗的再会」 世界设定提取

## 一、地理与场所
- 名称：魔大陆
  - 内容：魔大陆没有米里斯大陆和中央大陆那种魔物稀少且安全的平坦道路，无论走在哪里都会遭到C级以上的魔物袭击，魔物数量极多；且在魔大陆死亡连尸体都无法留下；传闻斯佩路德族在魔大陆上也已几乎灭绝。
  - 原文依据："首先，魔大陆没有你熟悉的那种道路。虽然有路是有路，但没有米里斯大陆和中央大陆那种魔物数量很少，走起来也很安全的道路。无论走在哪里，都会遭到C级以上的魔物袭击。""不，是真的。我刚刚没有说任何谎话，魔大陆就是那种地方。总之，魔物真的很多。""在魔大陆上，连尸体都不会留下。""因为听说连在魔大陆上，斯佩路德族也已经几乎灭绝。"
- 名称：米里希昂
  - 内容：冒险者公会总部所在地，情报容易汇集。当地食物美味，越靠近这里食物越好吃；早餐有刚出炉的面包、口味清爽的清汤、生菜沙拉与厚片培根，晚餐附赠甜点，流行年幼魔术师冒险故事的甜果冻。
  - 原文依据："所以，他才会把根据地设置于冒险者公会总部的所在地，而且也比较容易收集到情报的米里希昂。""米里希昂的食物相当美味。从大森林出发后至今，越靠近这里，东西就越好吃。今天的早餐是刚出炉的面包，口味清爽的清汤，生菜沙拉，还有厚片培根。昨晚没有食欲，不过听说晚餐甚至还有附上甜点。而且好像是很受年轻冒险者欢迎的甜果冻，源自于最近流行的诗歌，一个叙述年幼魔术师成为冒险者的故事。"
- 名称：旅社「黎明之光亭」
  - 内容：位于米里希昂的旅社，鲁迪乌斯一行下榻之处，保罗次日清醒后前往与鲁迪乌斯碰面的地点。
  - 原文依据："明天要清醒着去『黎明之光亭』，知道吗？"
- 名称：阿斯拉王国首都
  - 内容：菲托亚领地搜索团的另一处根据地所在地，由伯雷亚斯家的管家阿尔冯斯统领。
  - 原文依据："顺便一提，另一处根据地位于阿斯拉王国首都，那边是交给格雷拉特家的那个管家，阿尔冯斯先生。阿尔冯斯先生是这个搜索团的总负责人，目前似乎是还待在菲托亚领地救助难民。"
- 名称：赞特港
  - 内容：米里斯大陆北方的海港城市。保罗的搜索团在此留有寻人留言并常驻团员，负责向从魔大陆渡海而来的人探寻情报；艾莉娜丽洁在此传出猎食男人的传闻并渡海前往魔大陆。
  - 原文依据："我们在赞特港里，应该有确实留下讯息。而且我记得也有团员被派驻在那里。目的是要在有人从魔大陆渡海过来时，找对方探寻情报。""艾莉娜丽洁他们好像前往魔大陆了。我在赞特港听说有个到处猎食男人的长耳族，所以一定没错。"
- 名称：大森林 / 米尔泰特族村落
  - 内容：大森林中兽族分支米尔泰特族的聚落，有族长，村落规模相当大。基斯曾游历通知大森林各族村落，托付搜寻被转移的人类难民并送往米里希昂。
  - 原文依据："待在大森林的米尔泰特族那边时，听说德路迪亚村抓了个人族的小孩。""待在米尔泰特族的村庄。因为有族长，是个规模相当大的──""基斯，也就是说……你到处去通知大森林的各个种族，拜托他们要是找到迷路的人类，就把那些人送来米里希昂吗？"

## 二、组织与势力
- 名称：菲托亚领地搜索团
  - 内容：保罗招募志愿人士成立的救援搜索组织，负责搜寻菲托亚领地转移灾害中的失踪者。总负责人为管家阿尔冯斯（坐镇阿斯拉王国首都与菲托亚领地），保罗在米里希昂设立根据地负责米里斯大陆的搜寻与情报网络，在各地（如赞特港）设有留言与联络哨。团员包括原冒险者维拉、雪拉姐妹等，收容了许多在转移事故中遭盗贼迫害的女性难民。
  - 原文依据："保罗招募志愿人士，成立了搜索队。所以，他才会把根据地设置于冒险者公会总部的所在地，而且也比较容易收集到情报的米里希昂。顺便一提，另一处根据地位于阿斯拉王国首都，那边是交给格雷拉特家的那个管家，阿尔冯斯先生。阿尔冯斯先生是这个搜索团的总负责人，目前似乎是还待在菲托亚领地救助难民。""她以前是个普通的冒险者，却在那次转移事故中，没带装备就被传送往米里斯大陆。后来落入盗贼手中，成了泄欲的工具。……除了团员以外，还有好几个人也是这样。为了帮那些女孩挡下男性的视线，维拉才会随时保持那种装扮……"

## 三、力量体系 / 魔法 / 技能
- 名称：北神流「四脚之型」
  - 规则：北神流剑术中的特定招式，保罗在与鲁迪对决动真格时施展。
  - 原文依据："不但动了真格，甚至用上了原本不想使用的北神流「四脚之型」和剑神流「无音之太刀」。结果，我的剑却只有斩断他戴在头上的内裤绑绳。"
- 名称：剑神流「无音之太刀」
  - 规则：剑神流的高阶剑术招式，保罗在与鲁迪对决动真格时施展。
  - 原文依据："不但动了真格，甚至用上了原本不想使用的北神流「四脚之型」和剑神流「无音之太刀」。"
- 名称：无咏唱魔术
  - 规则：能够省略咒文咏唱直接发动魔术。基斯表示从未见过能够省略咏唱直接使用魔术的人，称鲁迪乌斯为百年一见的天才。
  - 原文依据："那家伙的确很了不起，我从来没见过能够省略咏唱直接使用魔术的家伙。看到他以魔术师身分和北圣贾尔斯打得不相上下时，我忍不住身子一震。的确，鲁迪乌斯是那种百年才会出现一个的天才。"
- 名称：治愈魔术
  - 规则：治愈术师能利用治疗术恢复外伤疼痛与损伤。
  - 原文依据："刚刚死要面子逞强，早知道应该让治愈术师使用治疗术。"
- 名称：土魔术造物
  - 规则：可用土魔术快速塑形制造出砂锅等生活用具。
  - 原文依据："什么叫作：『要不是有想到可以利用土魔术做出砂锅，搞不好这一年来都在吃那个难吃到爆炸的烤肉』？"
- 名称：「七大列强」
  - 规则：世间广为人知的顶尖强者称号/席位，代表极高战力与名望的象征。
  - 原文依据："要是做了这么多事还有办法去找出其他被转移的家伙，那可真是超人，真的是个超人。即使被列入『七大列强』也不为过。""七大列强吗？真是让人怀念的名称。以前，自己是不是也想变得那么有名？"

## 四、种族 / 生物
- 名称：矿坑族（炭坑族）
  - 特征：原文提及保罗的旧队友塔尔韩德是矿坑族，嗜酒如命。
  - 原文依据："反正一定是酒，这家伙比矿坑族的塔尔韩德还爱喝酒。"
- 名称：米尔泰特族
  - 特征：大森林中的兽族分支之一，长着类似兔子的长耳朵，有族长聚落。
  - 原文依据："米尔泰特族？我记得那应该也是兽族之一。长着类似兔子耳朵的种族。""待在米尔泰特族的村庄。因为有族长，是个规模相当大的──"
- 名称：德路迪亚族
  - 特征：大森林兽族分支。能闻出人类发情的气味；把被脱光衣服、关进牢房、戴上枷锁、泼冷水视为至死不忘的奇耻大辱，对族人泼水会引发极端愤怒。
  - 原文依据："对德路迪亚族来说，被脱光衣服、关进牢里、铐上枷锁，还有泼冷水等遭遇都是最严重的奇耻大辱。他们不会随便对其他人做这些行为，万一有人对自己这样做，到死都会不会忘记。我曾经对基列奴泼水想闹着玩，结果她真的动了火气恶狠狠地回瞪。""还有试图搭讪兽族女性却被闻出有发情的气味，即使如此依旧不死心……"
- 名称：长耳族
  - 特征：保罗旧友艾莉娜丽洁所属的种族，传闻其在赞特港四处猎食男人。
  - 原文依据："艾莉娜丽洁他们好像前往魔大陆了。我在赞特港听说有个到处猎食男人的长耳族，所以一定没错。"
- 名称：斯佩路德族
  - 特征：传言极其恐怖，且传闻连在魔大陆也几乎濒临灭绝；但保罗亲见瑞杰路德后认为其性情不错，感叹传言与实际并不一致。
  - 原文依据："关于斯佩路德族的事情，老实说我半信半疑。因为听说连在魔大陆上，斯佩路德族也已经几乎灭绝。""斯佩路德族……似乎是个性情不错的家伙，看来传言和实际并不一致呢。"
- 名称：魔物等级（C级 / A级）
  - 特征：在中央大陆，C级魔物只在森林深处出现，大多成群结队或具特殊能力；而在魔大陆到处都有C级以上魔物。A级魔物实力极为强悍，能独自讨伐A级魔物被视为怪物级战力。
  - 原文依据："在中央大陆，那是只会在森林深处出现的家伙。大部分都会成群结队，或是具备某些特殊能力。""而且连A级魔物都能独自打倒，跟怪物没两样的家伙当他的护卫。"
- 名称：大王陆龟
  - 特征：魔物，肉质极其难吃（“难吃到爆炸”）。
  - 原文依据："居然还针对大王陆龟的吃法啰哩啰嗦地讲个没完。什么叫作：『要不是有想到可以利用土魔术做出砂锅，搞不好这一年来都在吃那个难吃到爆炸的烤肉』？"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移事件特性
  - 内容：菲托亚领地建筑物全数消灭，居民全部被转移，确认大量死者与失踪者。转移现象的规则是：只要身体某处互有接触，就会被转移到同一个地点（诺伦因接触保罗而一同转移）。
  - 原文依据："建筑物已经全部消失。住在那里的人们也全都遭到转移。已经确认有大量的死者。还有许多人下落不明。""根据保罗所言，转移这种现象只要身体某处互有接触，似乎就会被传送到同一个地方。"
- 事件名：北神二世斩杀剑帝传说
  - 内容：北神二世亚历克斯・R・卡尔曼，传说在第一次实战中便斩杀了剑帝。
  - 原文依据："毕竟那个北神二世亚历克斯・R・卡尔曼，据说也是在第一次实战中就杀死剑帝。"

## 七、社会规则 / 习俗 / 文化
- 内容：未满十二岁在社会观念与家庭中仍被视为不能自立的小孩；保罗本人是在十二岁时离家。
  - 原文依据："「鲁迪乌斯还是个才十一岁的小鬼。」基斯又讲了一次，像是在特意强调这句话的意义。「就算是你自己，也是十二岁时才离家吧？」「嗯……」「你以前不是说过，未满十二岁还是小孩吗？」"
- 内容：米里希昂当地流行讲述“年幼魔术师成为冒险者”的诗歌，并带动了年轻冒险者之间吃甜果冻的风潮。
  - 原文依据："而且好像是很受年轻冒险者欢迎的甜果冻，源自于最近流行的诗歌，一个叙述年幼魔术师成为冒险者的故事。"
- 内容：德路迪亚族的禁忌与复仇观念：被脱光衣服、关进牢房、铐上枷锁、泼冷水被视作全族最大的奇耻大辱，若被施加此待遇至死不会忘记。
  - 原文依据："对德路迪亚族来说，被脱光衣服、关进牢里、铐上枷锁，还有泼冷水等遭遇都是最严重的奇耻大辱。他们不会随便对其他人做这些行为，万一有人对自己这样做，到死都会不会忘记。"

## 九、角色认知 vs 客观事实
- 角色以为：保罗以为鲁迪乌斯受到强悍魔族护卫，横越魔大陆轻轻松松，一路上如同贵族远足般悠哉游乐，甚至谈情说爱，因此责怪鲁迪为何不顺便调查家属下落。
- 原文是否暗示另有真相：是。基斯严厉指出魔大陆遍地是C级以上魔物，鲁迪年仅十一岁且毫无实战经验，带着艾莉丝既要防备魔族又要艰难求生，能平安到达已是奇迹般的极限；鲁迪在讲述旅途时显得轻松只是为了不让父亲担心。
- 原文依据："无论鲁迪乌斯有多天才，他毕竟是人类，总有个极限。更不用说那家伙还只是个小孩。""一个已经快到极限的家伙，为什么在讲述冒险经历时可以那么开心？……是因为不想让你担心吧。"
- 角色以为：鲁迪乌斯在初次争执时以为保罗在米里希昂过得风流快活，甚至在搜索团内搞婚外情（与衣着暴露的维拉有染）。
- 原文是否暗示另有真相：是。保罗被转移后从未想过女人，维拉穿比基尼装是为了替搜索团里受过盗贼虐待而罹患男性恐惧症的女性难民挡开视线，保罗与她绝无肉体关系。
- 原文依据："跟服装无关，反正那家伙是看到你的大胸部才会自己想歪。……为了帮那些女孩挡下男性的视线，维拉才会随时保持那种装扮……当然，我们之间没有肉体关系。怎么可能会有。"
- 角色以为：鲁迪反思以为自己此前是因为贪玩和松懈，才完全没有调查菲托亚领地的情况。
- 原文是否暗示另有真相：是。鲁迪在赞特港是因为拯救兽族儿童遭冤枉入狱而无法前往冒险者公会查看留言；且因不知道灾难发生，处于“不知情的幸福”中，得知真相后互相体谅重归于好。
- 原文依据："「鲁迪乌斯不知道情报也是无可奈何的事情，毕竟他没有前往赞特港的冒险者公会。」""我正是因为一无所知，才能过得那么轻松自在。毕竟不知道发生悲剧，也是一种幸福。"
