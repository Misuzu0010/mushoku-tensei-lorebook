# 外传一　「龙肉七星烧」 世界设定提取

## 一、地理与场所
- 名称：东部港
- 内容：王龙王国的领土，是世界上最大的港都。使用的语言和米里斯神圣国相同，但店名与整体氛围有所不同。
- 原文依据："东部港。这里是王龙王国的领土，也是世界上最大的港都。虽然使用的语言相同，然而店名和氛围都和米里斯神圣国有些不同。"

- 名称：王龙王国
- 内容：坐拥东部港、西部港等领土的国家。因特定历史原由而繁荣，境内贩卖大量刀剑，一般路边摊位亦摆满整排刀剑（但充斥着用来欺瞒初学者的劣质破铜烂铁）。王龙山脉座落于其领土附近。
- 原文依据："毕竟这个王龙王国是因为那种理由才繁荣起来，所以贩卖着大量刀剑。连一般的摊位也展示了整排的刀剑。看到这景象的艾莉丝本来兴奋得两眼放光，但似乎很快就发现那些商品都是些用来欺骗初学者的破铜烂铁。"、"王龙王国附近有一座王龙山脉，正如其名，山里栖息着名叫王龙的龙。"

- 名称：王龙山脉
- 内容：座落于王龙王国附近的山脉，山中栖息着名为“王龙”的强悍龙族。
- 原文依据："王龙王国附近有一座王龙山脉，正如其名，山里栖息着名叫王龙的龙。"

- 名称：南方海域
- 内容：王龙王国毗邻的海域，能捕获到该区域的食用鱼种“阿尔巴鱼”。
- 原文依据："阿尔巴鱼是可以在南方海域中捕到的鱼。"

- 名称：西部港
- 内容：王龙王国领内的港口城镇之一，鲁迪乌斯一行此前曾途经该地并品尝过炖煮阿尔巴鱼。
- 原文依据："也是这一带经常食用的鱼类，我有在西部港嚐过。"

## 二、组织与势力
- 名称：王龙王国军 / 王龙王国军方
- 内容：王龙王国的国家正规军队，最高级别军职包含“大将军”（夏加尔・加尔冈帝斯位居此职），麾下有数十名部下受其统领。
- 原文依据："王龙王国的大将军夏加尔・加尔冈帝斯成功招揽到某个人物。"、"而且只要去到适当的地点，会有好几十个部下对他低头行礼。"

- 名称：七大列强
- 内容：举世公认的至高顶尖强者顺位称号体系。其中排位在第五位的是名号为“死神”的蓝道夫・马利安。
- 原文依据："七大列强第五位的「死神」，蓝道夫・马利安。"

- 名称：蓝道夫祖传餐馆（两百五十年老铺）
- 内容：创业两百五十年、代代传承数百年的老字号餐馆，传统招牌菜为龙肉料理。传至蓝道夫这一代时由于常年经营困难、门可罗雀并背负高额负债，最终在被鲁迪乌斯严厉批评厨艺与选材后决定闭店歇业。
- 原文依据："「这是祖先代代传下来的店……当然，会坚持到我死为止……」"、"可是，龙肉是本店传承数百年的传统。"、"创业两百五十年。在自己这一代，要让自古传承至今的老店结束营业。"

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术制器与水魔术造冰
- 规则：熟练的高级魔术师（鲁迪乌斯）能够利用土魔术随手塑造并烧结出水杯，再注入水并加入冰块以作解渴清凉饮品；若由魔力控制尚显粗糙的初学者（艾莉丝）在室内施展水魔术，极易造成水流泛滥淹没店铺的危险。
- 原文依据："所以，我用土魔术来制作出杯子，装满水以后分给另外两人。这是所谓的自助式。只要顺便加上几颗冰块，就能成为让走累的身体消除疲劳的清凉剂。"、"如果在外面，我会叫艾莉丝自己使用魔术，然而目前在室内。总不能任由她没控制好魔术然后把整间店给淹了。"

- 名称：重力操控（王龙固有能力） [存疑]
- 规则：栖息于王龙山脉的王龙所传闻拥有的特殊能力，据称能够自由操控重力。
- 原文依据："据说那好像是能操控重力的龙……"

- 名称：武道 / 战斗才能（列强级）
- 规则：七大列强第五位“死神”蓝道夫・马利安虽在经商和厨艺上毫无天分，但在武力与战斗才能上达到极致，受到王国军方大将军的长年追随延揽。
- 原文依据："「可是，你拥有其他更专精的才能。人总是有擅长跟不擅长的事情，没错吧？」……七大列强第五位的「死神」，蓝道夫・马利安。"

## 四、种族 / 生物
- 名称：王龙
- 特征：栖息于王龙山脉中的龙类，传闻具备操纵重力之能。其肉质干柴粗硬，带有一股难以掩盖的浓厚肉腥味，若处理不当极为难吃。
- 原文依据："山里栖息着名叫王龙的龙。据说那好像是能操控重力的龙……这料理是使用了王龙的肉吗？"、"肉也又柴又硬。咬越多次，肉的腥味和油的臭味就会越占据鼻腔深处。"、"可是，龙肉是本店传承数百年的传统。"

- 名称：阿尔巴鱼
- 特征：栖息并捕捞于南方海域的鱼类，为王龙王国东部沿海一带居民常食用的代表性鱼种。
- 原文依据："阿尔巴鱼是可以在南方海域中捕到的鱼。也是这一带经常食用的鱼类，我有在西部港嚐过。"

- 名称：斯佩路德族进食习惯（瑞杰路德的饮食习性）
- 特征：进食速度极快，但饮水饮酒时不会大口狂饮，而是习惯一小口一小口慢慢饮尽。
- 原文依据："至于瑞杰路德还是跟平常一样，一小口一小口喝着。这个人吃饭很快，但不会一口气把饮料喝乾。"

## 五、物品 / 道具 / 武器
- 名称：龙肉七星烧（日式炸肉定食）
- 说明：蓝道夫祖传老店传承数百年的料理组合，形式类似日式炸肉定食，包含三个组成部分：
  1. 盐味蔬菜汤：类似清汤口感，风味清爽开胃，手艺合格。
  2. 杂粮饭（五谷米）：白米混合多种谷物的熟饭，水与火候烹煮合格。
  3. 炸龙肉（七星烧）：将龙肉裹粉后油炸的料理。因选用了肉腥味重且肉质干硬的龙肉，且未使用高温油、未能锁住水分、油炸前未事先调成咸甜口味，外皮湿软且伴随刺鼻油臭味。
- 原文依据："・龙肉七星烧。"、"这餐点分为三个部分。第一个部分是汤，透明的蔬菜汤……首先，位于左边的是我来到这世界后从来不曾目睹的主食。白银的帝王──白米。不对。要说是白米，这颜色有点奇怪。大概不只有白米，还混合了其他几种谷物吧，也就是杂粮饭。……呈现完美微焦黄金色的这东西无论怎么看都是……日式炸肉。换句话说，虽然汤并不是味噌汤，饭也不是白米饭。但是这个餐点正是「日式炸肉定食」。"、"表皮溼软又有油臭味，肉也又柴又硬。咬越多次，肉的腥味和油的臭味就会越占据鼻腔深处。"、"例如要使用更高温的油才行；或是无法把水分锁在肉里就没有意义；还有必须先把肉处理成咸甜口味后才能沾粉油炸，否则根本行不通等等。最后对方甚至指出：「而且最基本的问题，是在选肉的时候就犯了错」。"

- 名称：炖煮阿尔巴鱼
- 说明：使用阿尔巴鱼搭配浓汤炖煮制作的料理，风味类似石狩锅，为王龙王国的代表性特色风味餐点。
- 原文依据："・炖煮阿尔巴鱼。"、"虽然写着炖煮，但这里应该是指类似石狩锅的浓汤吧？是在王龙王国经常能吃到的代表性料理之一。"

- 名称：白米 / 杂粮饭
- 说明：世界中存在的谷物食粮。白米在王龙王国并非单独食用，而是常与多种杂粮谷物混合烹煮食用。
- 原文依据："白银的帝王──白米。不对。要说是白米，这颜色有点奇怪。大概不只有白米，还混合了其他几种谷物吧，也就是杂粮饭。"、"这次让我知道这世界有拿配菜搭白饭一起吃的文化，也存在着乾炸这种调理方式。"

- 名称：王龙王国路边摊刀剑
- 说明：王龙王国商摊公开陈列贩售的各色刀剑武器，充斥大量用来欺瞒外行新手、做工低劣的破铜烂铁。
- 原文依据："贩卖着大量刀剑。连一般的摊位也展示了整排的刀剑。看到这景象的艾莉丝本来兴奋得两眼放光，但似乎很快就发现那些商品都是些用来欺骗初学者的破铜烂铁。"

## 六、历史 / 传说 / 事件
- 事件名：蓝道夫老字号餐馆闭店停业
- 内容：创业长达两百五十年的传承餐馆，在蓝道夫・马利安经营期间因长年负债累累、难以为继，在经历顾客鲁迪乌斯的痛斥批评后，蓝道夫彻底认清自身缺乏经商与料理才能，正式决定结束营业。
- 原文依据："创业两百五十年。在自己这一代，要让自古传承至今的老店结束营业。今后的人生，就揹着这个耻辱继续活下去吧。我如此决定。"

- 事件名：「死神」蓝道夫接受大将军招揽入仕
- 内容：王龙王国大将军夏加尔・加尔冈帝斯历经数年纠缠延揽，原本屡遭七大列强第五位“死神”蓝道夫坚拒；在蓝道夫闭店当天，终于说动心灰意冷的蓝道夫应允加入王龙王国军。
- 原文依据："这一天。王龙王国的大将军夏加尔・加尔冈帝斯成功招揽到某个人物。七大列强第五位的「死神」，蓝道夫・马利安。面对长年的招聘也坚决不愿应允的他，为什么会在某一天突然接受夏加尔的邀请？没有多少人知晓其中内情。"

## 七、社会规则 / 习俗 / 文化
- 内容：餐馆无供水服务
- 原文依据："当然，没有水可以喝。这世界的餐馆基本上不提供那类服务。"

- 内容：无进门脱鞋习俗
- 原文依据："一个看起来恶形恶状的男子穿着鞋毫不客气地闯进店内。不，因为这世界没有脱鞋的习惯，其实我自己也穿着鞋。"

- 内容：西式餐具文化（无筷子）
- 原文依据："由于没有筷子，我利用叉子把杂粮饭放进嘴里。"

- 内容：米食配菜与干炸烹调文化
- 原文依据："这次让我知道这世界有拿配菜搭白饭一起吃的文化，也存在着乾炸这种调理方式。"

- 内容：魔大陆餐馆选择认知与本土差异
- 原文依据："在魔大陆上，外表漂亮与否会直接关系到料理的水准。……总而言之，如果是平常的我，应该不会光顾眼前这种地方吧。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯依据恶劣态度与对话，推测闯入餐馆的夏加尔是追债的高利贷流氓或谋求店铺地皮的土地投资商。
- 原文是否暗示另有真相：是。
- 原文依据："我想这间餐馆肯定是靠着借钱勉强支撑吧。至于那个活像流氓的家伙，大概是土地投资商之类。" vs "王龙王国的大将军夏加尔・加尔冈帝斯成功招揽到某个人物。七大列强第五位的「死神」，蓝道夫・马利安。"（客观事实是夏加尔贵为王龙王国大将军，真实意图是招揽身怀绝世武力的列强强者蓝道夫为军方效力，其流氓般的外貌举止仅为掩人耳目的伪装）。

- 角色以为：鲁迪乌斯在品尝到日式定食构成的七星烧时，误以为是天赐之物，甚至是人神感知到自己对米饭与炸肉的渴望而特意促成的安排。
- 原文是否暗示另有真相：是/否（角色主观臆想，与神明无直接因果）。
- 原文依据："没想到连这个世界也有日式炸肉……这是来自上天的赏赐吗？那个人神似乎总算明白我到底在追求什么事物。"（客观事实是该菜肴为王龙王国蓝道夫家传承数百年的传统料理，且炸龙肉极度难吃引发鲁迪暴怒，与人神赐予毫无实证关联）。

- 角色以为：外界世人普遍无法理解，为何面对大将军长年延揽皆坚辞不就的「死神」蓝道夫，会在某一天毫无征兆地突然接受邀请入仕。
- 原文是否暗示另有真相：是。
- 原文依据："面对长年的招聘也坚决不愿应允的他，为什么会在某一天突然接受夏加尔的邀请？没有多少人知晓其中内情。"（客观事实是由于鲁迪乌斯的一通严苛批评痛骂，彻底击碎了蓝道夫对祖传厨艺和守店的最后执念，自认毫无料理与经商才能，才心死闭店接受武力出仕）。

## 十、本章未涉及的类别
- 本章各主要设定类别均有涉及（无完全未涉及的类别）。
