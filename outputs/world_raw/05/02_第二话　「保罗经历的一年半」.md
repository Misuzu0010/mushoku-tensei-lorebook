# 第二话　「保罗经历的一年半」 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国南部城镇附近（莉莉雅故乡）
- 内容：保罗年轻时学习水神流剑术并结识莉莉雅的阿斯拉南部城镇草原。道场主人顶多为水神流上级剑士。保罗在此处醒来并发现自己被转移。
- 原文依据："这里是阿斯拉王国的南部，过去待过的城镇附近。当时是在那城镇里学习水神流……也就是说，这里是莉莉雅的故乡附近。"；"就连道场主人顶多也只是水神流的上级剑士，是个把自身无能放一边去，整天只会主张精神论的老废物。"

- 名称：菲托亚领地与难民营
- 内容：转移灾害致使菲托亚领地整体消失，布耶纳村和要塞都市罗亚被彻底消灭。伯雷亚斯家管家阿尔冯斯自掏腰包并在调用人脉后，在当地组织建立了收容菲托亚灾民的难民营，后续获得王都送达的复兴资金。
- 原文依据："菲托亚领地已经消失。我感到极度混乱。到底发生什么事？布耶纳村跑哪里去了？塞妮丝呢？莉莉雅呢？连要塞都市罗亚也已经消灭……"；"发誓要效忠伯雷亚斯・格雷拉特家的他，即使处于这种状况也没有改变自身的意志。他拿出私人的财产，开始设置难民营。"；"人脉很广的阿尔冯斯调用各处关系，聚集人才后建立起难民营。……到了这时期，王都那边的权力斗争似乎已分出胜负，开始有复兴资金送到阿尔冯斯手上。"

- 名称：米里斯大陆与中央大陆南部难民分布区
- 内容：菲托亚领地有相当多领民被转移至米里斯大陆与中央大陆南部。经过保罗等人早期行动与半年至一年的搜索，两地幸存难民绝大多数已被找到（获救者以数千人为单位），但死者人数远远多于幸存者。
- 原文依据："在米里斯展开活动后过了半年。有相当多的领民被转移到米里斯大陆。"；"能在中央大陆南部与米里斯大陆找到的人，可以说大部分都找到了。……多亏这种做法，才能够救出以数千人为单位的难民。"

- 名称：菲托亚领地搜索团米里斯仓库
- 内容：位于米里斯神圣国首都米里希昂，紧邻搜索团员常去的酒馆，主要用作保管团员衣物的备用据点。
- 原文依据："是搜索团的仓库之一，保管团员衣物的场所。被对方找到这里很不妙，说不定有必要换个根据地。"

## 二、组织与势力
- 名称：菲托亚领地搜索团
- 内容：保罗号召聚集在菲托亚难民营的年轻人组织成立的搜救团体。设立初衷为救助流散各地的菲托亚领民并寻找保罗的失踪家人。保罗随后带队前往米里斯神圣国设立分部，开展救济、赎买与武力夺回沦为奴隶的领民。成员多为不擅战斗的村民、农夫及初级冒险者，无法涉足魔大陆、中央大陆北部及贝卡利特大陆。一年半后因资金消耗过巨且难民大多已找到或罹难，计划组织护卫老弱病残返回菲托亚领地，并缩小搜索规模。
- 原文依据："我也号召前来难民营的年轻人，组织起「菲托亚领地搜索团」。这组织是为了拯救被转移到各地并成为难民的人们。"；"搜索团的成员并不擅长战斗。大部分的人原本只是农民或村人。虽然也有冒险者，但人数不多。况且看在我眼里，那些在阿斯拉王国活动的冒险者顶多只能算是初学者。以这样的成员，无法负荷魔大陆和中央大陆北部、贝卡利特大陆的战斗。"；"半年后，搜索团开始实行把在米里斯大陆找到的人们送回菲托亚领地的作战。……尽管包括我在内的主要成员会留在米里斯，但搜索活动将在这作战后告一段落，规模也会缩小。"

- 名称：塞妮丝的娘家（米里斯贵族名门）
- 内容：塞妮丝在米里斯神圣国的母族，为当地具备相当实力的名门贵族，曾培育出多名优秀骑士。保罗借助其权力背景与关系，为解放沦为奴隶的难民奠定了基础。
- 原文依据："她（塞妮丝）的娘家在米里斯是具备相当实力的贵族，也是培养出多名优秀骑士的名门。靠着他们，我培养出解放奴隶的基础。"

- 名称：米里斯教团 / 教皇
- 内容：米里斯神圣国的宗教权威最高统治体系，最高领袖为教皇。
- 原文依据："要是有哪个人敢对诺伦出手，就算是米里斯教团的教皇，我也已经做好与对方为敌的心理准备……"

- 名称：阿斯拉王国菲托亚领主权力交接
- 内容：菲托亚领地转移灾害发生后，菲利普与绍罗斯下落不明，领主由菲利普的兄弟继任；但因承担重大灾害责任面临被追责垮台危机；王都内部围绕灾害爆发激烈权力斗争。
- 原文依据："转移灾害的范围遍及菲托亚领地整体。菲利普和绍罗斯都下落不明，现在是菲利普的兄弟当上领主。然而，菲利普的兄弟被迫要负起灾害的责任，似乎随时有可能垮台。"；"到了这时期，王都那边的权力斗争似乎已分出胜负，开始有复兴资金送到阿尔冯斯手上。"

- 名称：「黑狼之牙」后续现状
- 内容：保罗过去的冒险者队伍，解散时曾发生严重冲突交恶。转移灾害发生一年半内，黑狼之牙成员中仅有一人曾与保罗联络过一次，之后不知所踪。
- 原文依据："我以前所属的队伍「黑狼之牙」的那些家伙如果也在，应该会帮忙搜索魔大陆和贝卡利特大陆吧。然而，前来跟我联络的成员只有一个。而且那个人联络过一次后就不知道晃到哪里去了，也完全不清楚目前在做什么。"

## 三、力量体系 / 魔法 / 技能
- 名称：转移魔法阵 / 转移陷阱 / 禁术
- 规则：转移魔术不存在咏唱咒文，必须依赖魔法阵或魔力附加品引发。转移现象会将接触到的所有物体/人员一并瞬间移动。转移魔法阵的制造技术早已被列为禁术且失传已久；转移用魔力附加品在全世界皆被列为违禁道具。在迷宫探索中，转移陷阱是最凶恶致命的陷阱，会拆散队伍成员并传送到未知危险区域，常导致高难度冒险队伍全灭。
- 原文依据："转移魔术没有咏唱咒语。所以必须使用魔法阵或魔力附加品。转移用的魔力附加品在全世界都是禁制道具，转移魔法阵的技术也被指定为禁术，失传已久。"；"所谓转移会让接触到的对象瞬间移动。所以被我抱着的诺伦才会跟着一起过来。"；"「因为转移陷阱而全灭」。在冒险者时代，有实力闯入迷宫后，我曾经多次听说这句话。转移是最需要防备的陷阱。因为队伍成员会被拆散，也会搞不清楚自己目前身处何方。是绝对不可以踩到的陷阱。"

- 名称：水神流剑术阶级体系
- 规则：水神流剑术存在初级、中级、上级等阶级划分，保罗年轻时学习迅速达到中级，而普通门生徘徊在初级出口，普通地方道场馆长顶多为上级。
- 原文依据："程度低到当我到达中级的领域时，他们还只能在初级的出口附近徘徊。就连道场主人顶多也只是水神流的上级剑士，是个把自身无能放一边去，整天只会主张精神论的老废物。"

## 四、种族 / 生物
- 名称：小人族
- 特征：外貌身型如同人类孩童，善于隐蔽和欺骗伪装，成年个体具备独立的高强战斗能力。
- 原文依据："恐怕是小人族吧？他们拥有小孩般的外型，还会若无其事地欺骗他人。小人族的高手……"

## 五、物品 / 道具 / 武器
- 名称：冒险者卡片（魔力注入与层级记录）
- 说明：公会发放的身份卡片。长期未进行业务更新，卡片上的字迹与记录会隐去，向卡片注入魔力可重新激活显现冒险者信息。
- 原文依据："柜台小姐把魔力注入很久没有更新所以文字已经消失的卡片后，因为上面注明的层级是S级而吓了一跳"

- 名称：阿斯拉货币汇率
- 说明：在阿斯拉南部城镇公会，一枚阿斯拉金币可兑换9枚银币和8枚大铜币（兑换手续费相较以往有所提升）。
- 原文依据："我前往冒险者公会，把一枚阿斯拉金币换成零钱，拿到了九枚银币和八枚大铜币。不知何时手续费变高了，不过有这些钱已经十分足够。"

- 名称：转移用魔力附加品
- 说明：可储存或引发转移魔法的特制道具，在全大陆被严格列为禁制违禁品。
- 原文依据："转移用的魔力附加品在全世界都是禁制道具，转移魔法阵的技术也被指定为禁术，失传已久。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移灾害（全面受灾与惨烈死伤）
- 内容：灾害爆发瞬间全境被白光包围，接触者一并被转移流散。整个菲托亚领地彻底化为空地，布耶纳村与罗亚都市均告消失。灾害造成的人员死亡数量远远超过幸存者，布耶纳村村民及罗亚居民（如艾特、克洛耶、罗尔兹、柏尼、连恩、马利昂、蒙提等）大量罹难；保罗的妻子塞妮丝、女仆莉莉雅及次女爱夏全部下落不明。
- 原文依据："突然被白色光芒包围。……菲托亚领地已经消失。我感到极度混乱。到底发生什么事？布耶纳村跑哪里去了？塞妮丝呢？莉莉雅呢？连要塞都市罗亚也已经消灭……"；"死者人数其实远远超过幸存者的人数。艾特、克洛耶、罗尔兹、柏尼、连恩、马利昂、蒙提……"

## 七、社会规则 / 习俗 / 文化
- 内容：
  1. **公会对S级冒险者的特权**：持有S级评级的冒险者在承接公会紧急送货委托时，公会提供无偿借用名马的特权优待（任务完成后需归还）。
  2. **米里斯贵族对奴隶的占有与冲突**：在米里斯神圣国，强行解放或夺走奴隶触犯法律。部分米里斯贵族将遭灾沦落的阿斯拉人民收为奴隶并拒绝放人，保罗强行绑回奴隶的行为引发当地贵族极大仇视，甚至遭到贵族私兵武装袭击并导致团员丧命。
  3. **冒险者对转移陷阱的禁忌认知**：在迷宫探险文化中，“转移”被视为最恐惧的团灭陷阱，因无法确定落点且会强行拆散人员，极度凶险。
- 原文依据："基于公会提供给S级冒险者的优待，承接紧急送货委托时，可以无偿借用马匹。"；"其中也有一些领民被当成奴隶卖掉。强行解放奴隶有牴触米里斯法律的风险……米里斯的贵族厌恶强行夺走奴隶的我们，甚至有人率领自己兵马前来袭击。团员中有人丧命。"；"「因为转移陷阱而全灭」。在冒险者时代，有实力闯入迷宫后，我曾经多次听说这句话。转移是最需要防备的陷阱。因为队伍成员会被拆散，也会搞不清楚自己目前身处何方。是绝对不可以踩到的陷阱。"

## 九、角色认知 vs 客观事实
- 角色以为：
  1. 保罗刚被转移到阿斯拉南部草原醒来时，以为是过去水神流道场的同门师兄弟怀恨在心、为了夺走莉莉雅而冒险动用禁术将他转移。
  2. 保罗认为一年半毫无音讯的家人（塞妮丝、莉莉雅、鲁迪乌斯等）已经在未知险境中哭泣着死去了，自己因错误决策遗弃了最重要的人。
  3. 保罗听到仓库被袭、对手是实力强大的蒙面小孩时，以为是米里斯贵族派来的“小人族高手”。
- 原文是否暗示另有真相：是
- 原文依据：
  1. 灾害是席卷整个菲托亚领地的大规模转移灾害，并非同门报复；
  2. 鲁迪乌斯不仅健在，而且已经平安跨越魔大陆来到米里斯神圣国首都米里希昂；
  3. 袭击仓库的蒙面小孩并非贵族派来的小人族高手，而是把内裤套在头上行侠仗义的亲生儿子鲁迪乌斯。
