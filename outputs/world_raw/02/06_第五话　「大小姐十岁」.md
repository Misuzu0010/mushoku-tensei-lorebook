# 第五话　「大小姐十岁」 世界设定提取

## 一、地理与场所
- 名称：罗亚领主府高塔
- 内容：伯雷亚斯宅邸内唯一一座特别高耸的塔楼，内部由极长的螺旋楼梯通向最顶层。顶层设有仅能容纳一人的狭窄小房间与向外凸出的窗户，从该窗口向外可远眺浮在半空中的红色宝珠；绍罗斯常在此与兽族女仆幽会并对着宝珠祈祷。
- 原文依据："唯一一座特别高的塔，虽然被告知最好不要靠近，但我还是很有兴趣。……乱晃一阵之后，发现了一道似乎很有趣的螺旋梯。……最后发现是绍罗斯在最上层。那里有个大概勉强只能挤进一人的小房间……「我是在对着那边的宝珠祈祷。」……从那扇外突窗往外看，的确有一颗浮在半空中的红色珠子。"

- 名称：伯雷亚斯宅邸设施（大厅、中庭、舞厅、马厩）
- 内容：大厅与通往大厅的中庭在举办大型生日宴会及舞会时对外开放；宅邸内配有专门练习舞蹈的舞厅，以及后方堆放高大乾草堆的马厩。
- 原文依据："艾莉丝生日那天，宅邸的大厅以及通往大厅的中庭都会开放。"、"她仰躺在马厩后方的一大落乾草堆上。"、"我跟着她回到舞厅。"

- 名称：贝卡利特大陆
- 内容：世界上的大陆之一，具有广袤的沙漠地形。
- 原文依据："「沙漠……是贝卡利特大陆那边吗？」"

- 名称：魔大陆
- 内容：世界上的大陆之一，为魔族聚居之地，其上分布着许多风俗各异的小部族。
- 原文依据："「说不定是魔大陆的魔族舞蹈，听说那里有很多小部族，或许也有拿剑当舞蹈道具的人们吧。」"

## 二、组织与势力
- 名称：中级贵族与下级贵族
- 内容：菲托亚领地内依附于高级领主（如伯雷亚斯·格雷拉特家）的阶层。在社交宴会上积极迎合领主，并渴望将自家的子嗣引荐给领主千金或有潜力的家族血脉以建立政治盟友关系。
- 原文依据："菲利普提议要让附近的中级贵族也便于参加，才变更为舞会形式。"、"面对试图拉拢格雷拉特家而大量聚集的中级贵族和下级贵族，菲利普和夫人一一巧妙应付……话句话说，那些人是认为即使我现在是分家或小妾的儿子，但总有一天肯定会成为名士，所以纷纷把自己的女儿或孙女送上门来。"

- 名称：骑士阶层
- 内容：领地与王国的正式武职人员，正规普通水准的骑士其实力标杆等同于剑术中级水平。
- 原文依据："所谓中级，就是实力能和一般水准的骑士相抗衡的水准。"

- 名称：行商
- 内容：在各城镇与大陆间辗转买卖货物的流动商人，曾以1枚金币从鲁迪乌斯手中买下其制作的洛琪希手办并带往各地。
- 原文依据："顺便说一下，第一个做出的洛琪希八分之一模型被行商以一枚金币的价钱买走了。现在应该在世界各地旅行吧。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑神流・中级 / 上级（位阶与战术特性）
- 规则：剑神流中级的实力等同于正规普通骑士水平；剑神流动作与个性偏向高速突进与锐利斩击，本能追求以最快速度破坏对手节奏；日常训练包含辨识杀气并闪避假动作的攻防反应；弟子对师父拜领赏赐时行单膝跪地礼节。
- 原文依据："她在剑术方面似乎拥有不错的素质，十岁前就已经成为中级。所谓中级，就是实力能和一般水准的骑士相抗衡的水准。根据基列奴所说，艾莉丝应该能在几年内就提升到上级。"、"艾莉丝的个性和动作很适合剑神流。……艾莉丝基于本能排斥自己的节奏被打乱，无论何时，她都想要维持自己的步调，不会受到他人影响。这在战斗时的确是出色的才能"、"也就是闪避基列奴攻击的课程。她在做出假动作时会喊出一声「喝！」我们必须只闪避真正的攻击，不能被假动作影响。"、"基列奴一听完这句话就缓缓起身，接着以恭敬态度单膝跪下。啊，我知道这动作，是剑神流的弟子对师父表示敬意时的姿势。"

- 名称：四大系统魔术与个人相性
- 规则：初级魔术按属性分为火、水、风、土四大系统。魔术并非仅靠背诵念诵咒文即可施展，受个人属性相性影响极大（艾莉丝除土系统外初级大多掌握，基列奴仅擅长火系统而水风土皆不通）。
- 原文依据："艾莉丝除了土以外，其他系统几乎都已经学会；相较之下，基列奴却只会火系统。明明接受同样的课程，为什么会出现差距呢？水、风、土是基列奴不擅长的系统吗？……总之，魔术似乎并不是按照教科书上面写的咒文咏唱出来就能够使用的东西。"

- 名称：无咏唱魔术的学习壁垒
- 规则：无咏唱施法无法通过常规训练轻易普及给普通人，教导已有一定年龄的剑士（如艾莉丝与基列奴）练习无咏唱魔术成效极低，可能依赖极特殊的幼年早慧或天生资质。
- 原文依据："另外，我最近有让她们练习无咏唱，但成效不彰。当初希露菲很快就会了，是年龄的问题吗？还是因为希露菲拥有特别的才能？说不定我是在让她们浪费时间力气"

- 名称：土魔术精密形塑
- 规则：高精度的土魔术能够精细捏塑微小零件并进行组装，免去雕刻与开模工序，可用于制造结构极其复杂的仿真手办或器物。
- 原文依据："利用土魔术做出的各种精密模型。例如龙或是船，还有希露菲的人偶模型也都排在一起。……因为我愉快又热中地投入用土魔术来制作出一个个零件然后组装完成的过程，因此制作得相当精密。"

- 名称：天空浮空红色宝珠 [存疑]
- 规则：位于半空中、外观如红色球体的未知天体/魔力现象，约于甲龙历411年出现，悬空静止无法触及，内部疑似有轻微蠕动，成因与本质完全不明。
- 原文依据："从那扇外突窗往外看，的确有一颗浮在半空中的红色珠子。或许是因为光线影响，总觉得里面的东西似乎稍微动了。那是什么？好神奇啊，果然是靠魔力才能飘浮吗？「不知道。」绍罗斯摇摇头。「我在三年前左右发现的，不过，不是不好的东西。」"

## 四、种族 / 生物
- 名称：兽族（不同分支与习俗）
- 特征：宅邸中可见狗耳朵女仆与猫耳朵女仆等不同亚种特征；兽族部族内部没有逢生日赠送礼物的社会习惯。
- 原文依据："可以看到有狗耳朵的女仆在走廊上奔跑。"、"他正在和猫耳女仆喵喵嗯嗯啊啊。"、"「抱歉，我的种族没有这种习惯，所以我什么都没准备。」"

- 名称：恶狼
- 特征：兽族部族流传中夜间会袭击旅人或村落的危险野兽；亦被基列奴用来戏称半夜意图不轨的保罗。
- 原文依据："「这是一族流传的驱魔戒指，据说只要带着，晚上就不会受到恶狼侵袭。」"、"「嗯，那是个难以入眠的夜晚。保罗来找我去泡个凉……」"

- 名称：魔族
- 特征：居住在魔大陆上的种族，存在许多文化习惯迥异的小部族。
- 原文依据："说不定是魔大陆的魔族舞蹈，听说那里有很多小部族，或许也有拿剑当舞蹈道具的人们吧。"

## 五、物品 / 道具 / 武器
- 名称：入门魔杖
- 说明：魔术老师指导弟子达到阶段成果后赠予弟子的纪念媒介法杖，鲁迪乌斯亲手制作了两根分别赠予艾莉丝与基列奴。
- 原文依据："「我的师父告诉我，魔术老师似乎该准备魔杖送给徒弟。因为我之前不知道该怎么制作，再加上没钱购买材料所以拖了很久……如果你们愿意，请收下吧。」"

- 名称：兽族驱魔戒指
- 说明：基列奴所属兽族一族流传的木雕戒指，带有磨损伤痕，在光照下反射绿色微光（材质或魔术附魔不明），部族传说佩戴后夜晚不受恶狼侵袭，被基列奴称作迷信。
- 原文依据："那是一个木雕戒指，已经相当陈旧还带着伤痕，但不知道是光线问题还是材质问题，亦或是上面可能施加了什么魔术，反射出来的光芒看起来有点像是绿色。「这是一族流传的驱魔戒指，据说只要带着，晚上就不会受到恶狼侵袭。」「真……真的可以给我吗？」「嗯，因为那只是迷信。」"

- 名称：精密土制模型（洛琪希手办等）
- 说明：鲁迪乌斯以土魔术制作的精密写实人偶模型，因涂料昂贵未上色；其中第一个洛琪希八分之一手办被行商以1枚金币买走。
- 原文依据："由于这世界的涂料昂贵，再加上没有喷枪，所以并没有上色。……顺便说一下，第一个做出的洛琪希八分之一模型被行商以一枚金币的价钱买走了。"

- 名称：涂料
- 说明：该世界制作的有色涂料价格昂贵，且社会缺乏喷笔喷枪等喷涂工具。
- 原文依据："由于这世界的涂料昂贵，再加上没有喷枪，所以并没有上色。"

- 名称：廉价酒
- 说明：罗亚城镇中出售的廉价酒精饮品，鲁迪乌斯藏于柜后用于私下招待。
- 原文依据："从橱柜后方拿出之前在城镇里买来并藏起的廉价酒。"

- 名称：空中红色宝珠
- 说明：悬浮于高空、泛着红光的神秘珠状天体。
- 原文依据："从那扇外突窗往外看，的确有一颗浮在半空中的红色珠子。"

## 六、历史 / 传说 / 事件
- 事件名：贵族逢五生日大庆（艾莉丝十岁生日舞会）
- 内容：伯雷亚斯家为艾莉丝举办的大型十岁舞会。绍罗斯大声宣布开场，菲利普夫妇圆滑应付前来攀附的中下级贵族；鲁迪乌斯以回避假动作的剑术步调引导艾莉丝完成开场舞；绍罗斯酒后吐露鲁迪乌斯的格雷拉特血统，导致鲁迪乌斯被大批贵族名媛争相邀舞；最终鲁迪乌斯与艾莉丝跳了一曲即兴欢快的变调舞圆满收尾。
- 原文依据："贵族有个习惯，会在五岁、十岁、十五岁生日时举办大规模宴会并热烈庆祝。"、"面对试图拉拢格雷拉特家而大量聚集的中级贵族和下级贵族，菲利普和夫人一一巧妙应付……"、"好像是有人询问一开始和艾莉丝跳舞的少年是谁，于是绍罗斯就自豪地把我是格雷拉特家一员的事实给抖了出来。"、"我握着艾莉丝的手，像平常练习剑术那样，有时往前踏有时往后退。虽然有配合音乐，但脚步却很不规则……不过，艾莉丝乐在其中。"

- 事件名：罗亚空中红色宝珠出现
- 内容：约甲龙历411年（距今三年前），绍罗斯在领主府高塔突窗外首次目睹一颗红色宝珠悬浮于天际，此后长年悬挂空中。
- 原文依据："「我在三年前左右发现的，不过，不是不好的东西。」"

- 事件名：保罗与基列奴的昔日纠葛
- 内容：保罗年轻时曾在夜晚邀约基列奴去“泡个凉”意图不轨，被基列奴引以为恶狼来犯的典型事例。
- 原文依据："「嗯，那是个难以入眠的夜晚。保罗来找我去泡个凉……」「啊，果然还是不用说了。我可以预测到接下来的发展。」……「算了，你当然也不会想知道父亲的艳遇。」"

## 七、社会规则 / 习俗 / 文化
- 内容：【贵族逢五庆生传统】贵族阶层严格遵循在五岁、十岁、十五岁举行大规模庆祝宴会的风俗，一生仅此三次大庆，十岁作为半成人标志备受重视，通常以舞会形式展示子女教养并进行政治联谊。
- 原文依据："贵族有个习惯，会在五岁、十岁、十五岁生日时举办大规模宴会并热烈庆祝。"、"在十岁的生日成为遭人嘲笑的对象，实在太可怜了。在这个世界，有每五岁就要盛大庆祝的习惯。所以是五岁、十岁、十五岁。总共只有三次机会。"

- 内容：【法定饮酒年龄】国家法律明文规定年满十五岁方能合法饮酒。
- 原文依据："这个国家似乎要到十五岁才能喝酒，但今天不计较那么多。"

- 内容：【师徒传承与门风礼节】
  - 魔术界传统：魔术老师在弟子有所成就或特定节点，有赠送魔杖给弟子的习惯；
  - 剑神流礼法：弟子拜领师长赏赐或表示敬重时，必须单膝下跪端正受领；
  - 雇佣习惯：社会并无受雇人员必须向雇主进献生日礼物的硬性习俗。
- 原文依据："「我的师父告诉我，魔术老师似乎该准备魔杖送给徒弟。……如果你们愿意，请收下吧。」"、"基列奴一听完这句话就缓缓起身，接着以恭敬态度单膝跪下。啊，我知道这动作，是剑神流的弟子对师父表示敬意时的姿势。"、"虽然这世界似乎没有受雇者必须送礼物给雇主的习惯"

- 内容：【贵族联姻与门户偏见】中小贵族阶层极度看重顶级大贵族（格雷拉特家）血缘，即便面对旁系私生子，只要展现优异才能，亦会争相送上女儿孙女联姻；但贵族内部对像保罗般四处沾花惹草的行径十分反感，视为“伤害家族名誉”。
- 原文依据："那些人是认为即使我现在是分家或小妾的儿子，但总有一天肯定会成为名士，所以纷纷把自己的女儿或孙女送上门来。"、"「不过，如果像保罗那样把每个女孩都带上床就会伤害到家族名誉，千万别那样做。」"

## 九、角色认知 vs 客观事实
- 角色以为：
  1. 礼仪老师艾德娜断言艾莉丝极度欠缺跳舞才能。
  2. 基列奴以为获赠入门魔杖后便能正式对外自称魔术师。
  3. 绍罗斯断定天空中的红色宝珠“不是不好的东西”，理由是“因为这样想比较正面”。
- 原文是否暗示另有真相：
  1. 否。艾莉丝并非欠缺才能，而是剑神流的动作习惯与艾德娜的刻板教法冲突，结合假动作节奏后能够协调起舞。
