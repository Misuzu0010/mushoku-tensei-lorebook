# 第一话　「大小姐的暴力」 世界设定提取

## 一、地理与场所
- 名称：罗亚（要塞都市）
- 内容：菲托亚地区附近规模最大的都市，充满活力。整座城市被高约七至八公尺的坚固城墙包围，城门巨大。城门附近设有公共马车候车处、马厩、旅社以及整排露天摊贩。城市采用防卫构造，外侧遭受敌人袭击时由大门周边人员负责抵御，城镇居民则可趁机逃往深处避难；因此越深入城镇建筑物越大间、以高级品为取向的商店越多，住得越靠近中央越有钱。城镇中心为最庞大的建筑物——领主宅邸（构造如城堡）。在四百年前与魔族的战争中曾作为最终防卫线，历史悠久，但在王都贵族眼中只是充斥粗鄙冒险者的偏僻之地。
- 原文依据："罗亚这城镇不愧是这附近规模最大的都市，充满活力。首先映入眼帘的是城墙。大概有七～八公尺高，看起来很坚固的城墙包围着整座城市。城墙上的巨大城门周围有马车来来往往，进入城门后，可以看到整排的露天摊贩。在进入城镇后没多远的位置，有好几间类似马厩和旅社的店家。"、"当外侧有敌人来袭时，首先由大门周边的人们负责抵御，城镇的居民则可以趁这段期间逃到城镇深处或是相反方向。因为采用这种构造，当然再往前继续深入之后，可以发现建筑物愈来愈大间，以高级品为取向的商店也变多了。在这城镇，住得愈靠近中央就愈有钱。而位于城镇中心的是一栋最庞大的建筑物。『那就是领主的宅邸。』『与其说是宅邸，更像是城堡呢。』『因为这里是要塞都市啊。』在四百年前与魔族的战争中，罗亚发挥出作为最终防卫线的功能，是一座历史相当悠久的城镇。所以，位于中央的似乎是城堡。不过，也只有历史悠久，对于住在王都的贵族们来说，这里似乎只是有很多粗鄙冒险者的偏僻地方。"

- 名称：布耶纳村与罗亚的相对距离
- 内容：布耶纳村与罗亚之间相隔搭乘马车需一天的距离，换算实际时间约为六至七小时左右。
- 原文依据："布耶纳村和罗亚之间似乎隔着搭乘马车需要一天才能到达的距离。换算成实际时间大概是六七个小时左右吧？"

- 名称：公共马车候车处
- 内容：设于城门附近的类似候车亭设施，供拿大型行李的人们等待公共马车，用于城镇间的移动。
- 原文依据："这时，我突然注意到有拿着大型行李的人们坐在类似候车亭的地方。……『那是公共马车的候车处。一般来说要从一个城镇移动到另一个城镇时就会使用那种马车，或是付给行商一些钱换取搭便车的机会。』"

- 名称：菲托亚领
- 内容：罗亚所在的领地，领主为绍罗斯・伯雷亚斯・格雷拉特。
- 原文依据："是菲托亚的领主，绍罗斯・伯雷亚斯・格雷拉特大人。"

## 二、组织与势力
- 名称：伯雷亚斯・格雷拉特家
- 内容：菲托亚领地的领主家族，在王国中地位高贵。当主为绍罗斯・伯雷亚斯・格雷拉特（保罗的叔父），下有菲利普・伯雷亚斯・格雷拉特（大少爷，保罗的堂兄弟）及领主孙女（大小姐）。保罗曾因讨厌拘谨规矩而离开老家，与该家门断绝关系。
- 原文依据："是菲托亚的领主，绍罗斯・伯雷亚斯・格雷拉特大人。也是保罗大人的叔父。"、"我是菲利普・伯雷亚斯・格雷拉特。"、"保罗利用了已经被断绝关系的自家门路。话说回来，没想到他的老家身分地位如此高贵……"、"职业：菲托亚领主的孙女。"

- 名称：冒险者公会（支部）
- 内容：在罗亚设有支部，罗亚城门附近的街区集中了专为冒险者服务的店铺（武器店、防具店、酒馆等）。
- 原文依据："基列奴指着一间间的店铺，告诉我哪间是武器店，哪间是酒馆，哪间是冒险者公会的支部，哪间是「那种」可疑的店。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑神流（等级阶位）
- 规则：剑神流分为七个阶级，从上数来第三位是「剑王」级（基列奴具备此地位）。大小姐的剑术等级为初级。
- 原文依据："她是剑技高超的剑士，拥有剑神流七阶级从上数来第三位的「剑王」级地位。"、"剑术：剑神流・初级。"

- 名称：治愈魔术 / 治疗术
- 规则：使用治愈魔术必须进行咏唱；如果无法咏唱，就无法使用治愈魔术。可用于治愈肉体伤口。
- 原文依据："开什么玩笑，如果无法咏唱，就无法使用治愈魔术。"、"我喃喃地咏唱治疗术，治好伤口。"

- 名称：风魔术
- 规则：可以产生冲击波进行攻击或击退对手。
- 原文依据："接着利用风魔术来产生冲击波，打中大小姐的脸。"

## 四、种族 / 生物
- 名称：兽族（泰德鲁帝亚族）
- 特征：拥有野兽般的耳朵和尾巴，肤色为巧克力色，体格高大且满身肌肉。在罗亚领主宅邸的女仆中有许多兽族人士。
- 原文依据："那是一位拥有野兽般耳朵和尾巴，在巧克力色的身躯上穿着暴露的皮革制服饰，身材高大且满身肌肉的男子汉──错了，是女剑士。名字叫作基列奴・泰德鲁帝亚。"、"讲到聘雇人员，不知为何，女仆中有很多兽族人士。虽然听说这国家对魔族特别歧视，但兽族不一样吗？"

- 名称：魔族
- 特征：四百年前曾与人族发生大战；在该国家受到特别歧视。
- 原文依据："在四百年前与魔族的战争中，罗亚发挥出作为最终防卫线的功能，是一座历史相当悠久的城镇。"、"虽然听说这国家对魔族特别歧视，但兽族不一样吗？"

- 名称：长耳族
- 特征：具备长耳族血统的人，即使长大体型（胸部）也大多不会变很大 [存疑]。
- 原文依据："既然拥有长耳族的血统，即使长大应该也不会变得那么大吧。"

## 五、物品 / 道具 / 武器
- 名称：公共马车
- 说明：用于在城镇与城镇之间移动的公共交通工具，设有专门的候车处。
- 原文依据："那是公共马车的候车处。一般来说要从一个城镇移动到另一个城镇时就会使用那种马车，或是付给行商一些钱换取搭便车的机会。"

## 六、历史 / 传说 / 事件
- 事件名：四百年前与魔族的战争
- 内容：四百年前曾爆发与魔族的战争，罗亚在战争中发挥了最终防卫线的功能，城中央建有城堡。
- 原文依据："在四百年前与魔族的战争中，罗亚发挥出作为最终防卫线的功能，是一座历史相当悠久的城镇。所以，位于中央的似乎是城堡。"

## 七、社会规则 / 习俗 / 文化
- 内容：要塞都市的防御构造与居住阶级分布：要塞都市罗亚外围大门周边为商贩与冒险者设施，战时用于抵御敌人；越往内民居建筑越大越奢华，越靠近中央越有钱，最核心为领主城堡。
- 原文依据："当外侧有敌人来袭时，首先由大门周边的人们负责抵御，城镇的居民则可以趁这段期间逃到城镇深处或是相反方向。因为采用这种构造，当然再往前继续深入之后，可以发现建筑物愈来愈大间，以高级品为取向的商店也变多了。在这城镇，住得愈靠近中央就愈有钱。"

- 内容：王都贵族的偏见文化：王都的贵族看不起边境要塞都市罗亚，认为这里只是充斥很多粗鄙冒险者的偏僻地方。
- 原文依据："不过，也只有历史悠久，对于住在王都的贵族们来说，这里似乎只是有很多粗鄙冒险者的偏僻地方。"

- 内容：贵族问候礼节与伯雷亚斯式问候：贵族打招呼时标准礼仪是将右手放在胸前并稍微低头；而伯雷亚斯家大老爷绍罗斯更偏好工匠般抬头致意的气魄方式；大小姐则仅掌握粗暴的“伯雷亚斯式的问候”。
- 原文依据："「贵族打招呼时要把右手放在胸前，然后稍微低下头。你的方式应该让大老爷生气了吧？」「像这样吗？」我模仿菲利普的动作，试着把头抬高。「没错。不过，刚才的致意方式也很有礼貌，不算坏事。如果是工匠那样打招呼，感觉父亲会喜欢。你坐下吧。」"、"礼仪规矩：只会伯雷亚斯式的问候。"

- 内容：城际交通方式：从一个城镇移动到另一个城镇，一般使用公共马车，或者付钱给行商搭便车。
- 原文依据："一般来说要从一个城镇移动到另一个城镇时就会使用那种马车，或是付给行商一些钱换取搭便车的机会。"

- 内容：种族待遇差异：国家对魔族特别歧视，但对兽族并不相同，领主宅邸中雇用了大量兽族作为女仆。
- 原文依据："讲到聘雇人员，不知为何，女仆中有很多兽族人士。虽然听说这国家对魔族特别歧视，但兽族不一样吗？"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯看到领主城堡般的宅邸，以为自己要教导的大小姐身分极其高贵，甚至以为是领主的女儿。
- 原文是否暗示另有真相：是。
- 原文依据："「不过，既然来到这里，表示我要教导的大小姐身分相当高贵呢。」「也不是那样。」基列奴摇了摇头。……「原来对象是领主的女儿啊。」「不是。」「不是吗？」「……有点不一样。」"（实际上对象是领主的孙女，且性格与传统高贵大小姐完全相反）

- 角色以为：鲁迪乌斯根据前世概念，以为大小姐是那种梳着法国卷、虽任性但靠武力或威吓就能让她屈服的典型千金。
- 原文是否暗示另有真相：是。
- 原文依据："眼前这玩意儿和我知道的大小姐不同。不是那种梳着钻头状法国卷发型，然后会做出杂技般的任性旋转特技的大小姐！而是不良少年漫画的主角。……「靠力量让她屈服」。这是这一次绝对不能使用的选项。"（实际上是极其崇尚暴力、被反击就会以十倍报复且毫不手软的凶暴小孩）

- 角色以为：鲁迪乌斯听说该国家对魔族特别歧视，推测兽族可能也会受歧视。
- 原文是否暗示另有真相：是。
- 原文依据："讲到聘雇人员，不知为何，女仆中有很多兽族人士。虽然听说这国家对魔族特别歧视，但兽族不一样吗？"（客观上领主宅邸雇佣了大量兽族女仆，待遇与被歧视的魔族不同）
