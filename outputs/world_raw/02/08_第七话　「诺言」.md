# 第七话　「诺言」 世界设定提取

## 一、地理与场所
- 名称：要塞都市罗亚领主宅邸（生活设施补充）
  - 内容：虽为阿斯拉王国上级贵族伯雷亚斯家的宅邸，但内部并未配备浴室，日常生活中无法每天沐浴洗头。
  - 原文依据："虽说是上级贵族，但这宅邸没有浴室。所以，并不是每天都能洗头。"

- 名称：菲托亚领地与罗亚市
  - 内容：阿斯拉王国的偏远乡下地方，政治与经济资源匮乏，很难累积争权夺利的实力。菲利普在继承家业的政争中败北后被分派担任罗亚市长。
  - 原文依据："詹姆士成为伯雷亚斯的当家后，安排菲利普担任菲托亚领地的罗亚市长。菲利普当时尚未认输也试图东山再起，然而菲托亚领地是个乡下地方，很难累积实力。"

- 名称：阿斯拉王都
  - 内容：阿斯拉王国的政治枢纽，伯雷亚斯主家宗室所在地。詹姆士在王都担任大臣，并在王都收养管教伯雷亚斯各分支的男孩。
  - 原文依据："只是一出生就被住在王都的哥哥夺走了。"、"詹姆士没有离开王都，趁菲利普还在困苦挣扎时已经当上大臣，建立起磐石般的地位……"

## 二、组织与势力
- 名称：格雷拉特四大上级贵族家系（诺托斯、伯雷亚斯、艾乌洛斯、泽费洛斯）
  - 内容：阿斯拉王国的四大名门上级贵族家系。四家彼此牵制且保持微妙政争均势：
    - 诺托斯家：保罗出身之本家（保罗全名保罗·诺托斯·格雷拉特），保罗早年被逐出家门断绝关系；现任当家为保罗的弟弟或堂兄弟，手段阴狠，内部存在试图推翻现任当家的反对派；当家为防被取代，对可能威胁自己地位的人选极度敏感，会派出刺客排除威胁。
    - 伯雷亚斯家：绍罗斯及菲利普所在的家族，设有残酷的男丁收养继承制度以防止内乱；宗家掌控在王都大臣詹姆士手中。
    - 艾乌洛斯家：绍罗斯的次子高登入赘的家族。
    - 泽费洛斯家：四大贵族之一，若伯雷亚斯家擅自与诺托斯家开战，泽费洛斯家与艾乌洛斯家将结盟共同对抗伯雷亚斯。
  - 原文依据："保罗的本名是保罗・诺托斯・格雷拉特。「诺托斯」是他的贵族名。保罗在很久以前被诺托斯家断绝关系……也就是因为诺托斯现任当家是比保罗还糟糕的人渣，因此试图把他拉下来换人上台的一派。现任当家也对这些动静很敏感，因此极力排除那些可能取代自己的人选。……最糟的情况，说不定会派出刺客对付我。"、"而且开战是不行的，泽费洛斯家与艾乌洛斯家也会和我们为敌！"

- 名称：伯雷亚斯男嗣收养制（权力继承规则）
  - 内容：伯雷亚斯家族残酷的防范权力斗争制度。新当家选出后，所有分家与兄弟生下的男孩一律由当家强行带往王都收为养子抚养，在懂事之前让其认当家为父。此制度旨在剥夺权力斗争失败者在下一代拥立儿子卷土重来的政治筹码。菲利普的两个儿子（艾莉丝的哥哥与弟弟）皆因此制度被詹姆士夺走。
  - 原文依据："在伯雷亚斯・格雷拉特家出生的男孩全都由下任当家养育。这种措施，是为了让权力斗争中的败者无法参加下一代的权力斗争。也就是避免败者拥立儿子并参加权力斗争。这是常有的事情，以前的阿斯拉王国似乎也经常中了这招。所以把男孩带走是为了防止这一点的对策。"

- 名称：阿斯拉王国宫廷魔术团
  - 内容：阿斯拉王国的官方宫廷级魔术团体，拥有如“首屈一指的魔杖制作师”权・布罗奇翁等顶尖工匠。
  - 原文依据："制作者则是阿斯拉王国，宫廷魔术团中首屈一指的魔杖制作师，权・布罗奇翁。"

## 三、力量体系 / 魔法 / 技能
- 名称：水圣级魔术破坏力与特征
- 规则：水圣级魔术呈现为极端狂暴的暴风与雷雨。若全力施展，威力足以将一整座城镇彻底淹没；施展该等级魔术需消耗相当庞大的魔力；通常需到远离城镇（如骑马两小时车程）的开阔地带进行示范以避免波及平民。
- 原文依据："「水圣级是暴风和雷雨，要是好好加油，大概可以把这个城镇淹没吧。」"、"「使用圣级魔术会消耗相当多魔力……」"

- 名称：魔杖构造与威力增幅机制
- 规则：魔杖的品阶与效力由杖柄木材与魔石共同决定：
  - 杖柄木材：影响特定系统的魔术适性（如角乌木适性偏向火、土系统；槐木适性偏向水、风系统），但适性不合亦不减弱威力。
  - 魔石增幅：魔力通过魔石即可产生威力增幅；魔石质地越透明、体积越大，增幅效果越显著，造价按天文学幅度飙升；有属性颜色的魔石能大幅特化对应系统的魔术威力。
- 原文依据："首先魔杖的等级是根据杖柄使用的木材，以及前端的魔石来决定。木材方面会影响到和各系统间的适性。例如和火、土系统相配的角乌，还有和水、风系统相配的槐木都很常见。不过，就算适性不合也不会造成威力减弱，因此其实什么材料都行。重点是魔石。光是让魔力通过魔石，就能增加魔术的威力。虽然魔石有好有坏，但魔石越透明而且体积越大，效果就会越好。……更不用说这颗魔石是群青的水魔石。有颜色的魔石能大幅强化和颜色相对应的系统。"

- 名称：魔力结晶 vs 魔石
- 规则：迷宫产出的魔力结晶属于魔石的一种，但与普通魔石不同，魔力结晶自身并不具备增幅流经魔力的效果。其特性是自身内含大量魔力，因此不用于制作魔杖，而是专用于魔道具制造及作为消耗巨大魔力的大型魔术的能源来源。
- 原文依据："在迷宫里能取得的魔力结晶也是一种魔石，然而和魔石不同，不具备让魔力增幅的效果。不过相对的，魔力结晶内含魔力，因此不会被用来制作魔杖，而是使用在魔道具和必须消耗大量魔力的大型魔术上。"

- 名称：语言体系关联规律
- 规则：世界上的多种语言（如斗神语、人类语等）文法基础共通，单字与部分惯用表达有差异，掌握一种语言后可较易触类旁通学习其他语言；推测可能受到波及全世界的古代战争融合影响。
- 原文依据："斗神语和人类语相当类似，没费太大工夫。……只有单字和一些惯用说法不同，文法的基础和人类语言一样。这个世界的语言并不是那么困难，只要学会一种，就可以应用到其他语言上。是不是因为受到波及全世界的战争影响呢？"

## 四、种族 / 生物
- 名称：长老魔木
  - 特征：A级魔物，栖息于米里斯大陆大森林东部。由小型魔木吸收妖精之泉的养分变异诞生的上级亚种，自身能使用水魔术。其手臂木材是制作高阶水系魔杖的极品素材。
  - 原文依据："魔杖的素材使用了栖息于米里斯大陆，大森林东部的长老魔木的手臂制成。我想博学的鲁迪乌斯大人应该知道，长老魔木据说是小型魔木从妖精之泉吸取养分后才会诞生的上级亚种，也是能使用水魔术的A级魔物。"

- 名称：落单的海龙
  - 特征：A级珍贵魔兽，出没于贝卡利特大陆北部。其体内蕴含的高纯度群青色水魔石极为珍罕昂贵。
  - 原文依据："魔石是在贝卡利特大陆北部，从落单的海龙身上取得，这也是层级A的珍品。"

- 名称：兽人族（感知特长与生理肌肉特性）
  - 特征：对声音极其敏感，非常擅长夜间警卫警戒；生理结构上长有尾巴且尾巴连接处骨肉结实，肉体肌肉极其紧密坚硬，兼具极佳韧性与红白肌特质。
  - 原文依据："因为你有说过兽人族对声音很敏感，所以也很擅长夜里的警戒。"、"可以感觉到柔软度。要怎么形容……是理想？是让人崇拜的肌肉……是同时兼具红肌与白肌双方性质的粉红色肌肉！"

## 五、物品 / 道具 / 武器
- 名称：傲慢水龙王
  - 说明：阿斯拉王国宫廷魔术团首席魔杖制作师权・布罗奇翁打造的高级木制权杖。
    - 材质：杖柄采用米里斯大陆大森林东部A级魔物“长老魔木”的手臂；前端镶嵌产自贝卡利特大陆北部A级魔物“落单的海龙”之拳头大小群青水魔石（单魔石价值超过一百枚金币）。
    - 特征：外观为凹凸弯曲的木杖，重心平衡极佳，重量轻盈挥舞顺畅，专精强化水魔术。
  - 原文依据："是一把有着凹凸弯曲的木制权杖，前端装着一颗似乎很高价的大型魔石。……眼前这个拳头大小的魔石应该随随便便就会超过一百枚金币吧。更不用说这颗魔石是群青的水魔石。"、"名称是『傲慢水龙王』。"、"和外观相反，这把杖相当轻。我用双手拿起魔杖挥动几下，挥起来相当顺手。明明魔石很大一颗，但整体重心的平衡却抓得很好。"

## 六、历史 / 传说 / 事件
- 事件名：伯雷亚斯当家之争（菲利普、高登、詹姆士之争）
  - 内容：绍罗斯十个儿子中选拔下任当家，菲利普、高登、詹姆士展开继承权竞逐。詹姆士设计让高登与艾乌洛斯家千金陷入热恋并入赘该族出局；随后詹姆士凭借在王都年长六岁建立的人脉、资财及大臣助理实权击败菲利普夺得当家大位。菲利普被排挤至偏远菲托亚领地任罗亚市长，儿子尽遭詹姆士剥夺收养。
  - 原文依据："绍罗斯有十个儿子。其中有三个特别优秀。菲利普。高登。以及詹姆士。……下任当家是詹姆士。菲利普和高登都输了。……詹姆士让高登私底下结识艾乌洛斯・格雷拉特家的千金。……闪电入赘。成为伯雷亚斯当家的路也断了。……詹姆士比菲利普年长六岁，在王都交游广泛，还担任大臣的助理。……菲利普就是输了。詹姆士成为伯雷亚斯的当家后，安排菲利普担任菲托亚领地的罗亚市长。"

- 事件名：菲利普拉拢鲁迪乌斯夺权密谋
  - 内容：菲利普在十岁庆生会后向鲁迪乌斯吐露争位失败原委及家族传统，试探提议让鲁迪乌斯迎娶艾莉丝，由菲利普主导夺回伯雷亚斯当家之位，鲁迪乌斯婉拒卷入。
  - 原文依据："「如何，你要不要和艾莉丝结婚，一起篡夺伯雷亚斯家呢？……篡夺由我来负责，你只要坐着就好。」"

- 事件名：鲁迪乌斯与艾莉丝的五年之约
  - 内容：鲁迪十岁生日当晚，艾莉丝穿睡衣前往鲁迪房间探望，鲁迪欲更进一步触碰其大腿内侧时被艾莉丝殴打拒绝；随后艾莉丝返回并约定在鲁迪十五岁正式成人之前的五年内需克制忍耐。
  - 原文依据："「不过……这……这种事情还太早了，所以……五年！再过五年，等鲁迪乌斯成为大人之后，那时候……那个……在那之前，你必须好好忍耐！」……得到五年后的承诺！那个艾莉丝！居然给出承诺！……五年后。那时我十五岁。"

## 七、社会规则 / 习俗 / 文化
- 内容：**贵族十岁生日习俗与政治风险规避**。在阿斯拉王国贵族社会中，十岁生日为极具纪念意义的重大日子，惯例会广邀各方宾客举办盛大公开宴会。但若出身敏感（如保罗遭诺托斯流放，鲁迪若公开可能招致现任诺托斯当家派遣刺客），则需隐匿身份，仅能在宅邸内部举办小型家庭庆生派对。
  - 原文依据："就连在贵族中是惯例中的惯例，算是特别日子的十岁生日都不能大张旗鼓地举办庆生宴会。……最糟的情况，说不定会派出刺客对付我。所以必须隐瞒我的身分。……只有宅邸内成员参加的小型家庭派对。"

- 内容：**成人年龄界定**。社会默认的成人法定年龄为十五岁（十五岁即成为大人，可以正式谈及婚配与成人关系）。
  - 原文依据："「五年！再过五年，等鲁迪乌斯成为大人之后，那时候……」……五年后。那时我十五岁。"

- 内容：**地域饮酒风俗**。阿斯拉王国各区域流行饮用不同酒类，菲托亚罗亚一带平日多饮用麦子酿造的麦酒，逢喜庆宴席时则会特别准备葡萄酒。
  - 原文依据："阿斯拉王国各区域会喝不同的酒。这一带通常是用麦子酿造的酒，不过庆祝时会准备用葡萄酿成的产品。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯起初以为自己无法举办十岁盛大宴会，是因为自己是保罗的儿子或在雇主家地位如仆人不受欢迎。
  - 原文是否暗示另有真相：是。
  - 原文依据：真实原因是保罗为诺托斯家被逐长男，诺托斯现任当家为防止失势对潜在竞争者极度警惕，若大肆宣扬鲁迪乌斯受伯雷亚斯庇护，将招来诺托斯当家暗杀刺客，私下举办是为保护其人身安全。原文依据："大肆声张现在受到伯雷亚斯家庇护的我是诺托斯成员是一种不太妙的做法。……最糟的情况，说不定会派出刺客对付我。所以必须隐瞒我的身分。"
