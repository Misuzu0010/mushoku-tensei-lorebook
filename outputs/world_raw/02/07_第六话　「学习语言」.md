# 第六话　「学习语言」 世界设定提取

## 一、地理与场所
- 名称：太古七世界（人的世界、魔的世界、龙的世界、兽的世界、海的世界、天的世界、无的世界）
  - 内容：十万年以上之前的太古神之时代，世界分为七个，各自受到对应的神支配。世界之间被类似结界隔绝，各世界的居民无法随意穿行，亦不知道其他世界存在。后除人的世界外，其余世界皆在两万至一万年前的神魔浩劫中崩毁，仅剩人的世界（即现在的世界）。
  - 原文依据："分为七个世界，似乎各自受到神的支配。这时被称为「太古的神之时代」。七个世界和神明如下：人的世界，人神。魔的世界，魔神。龙的世界，龙神。兽的世界，兽神。海的世界，海神。天的世界，天神。无的世界，无神。世界被类似结界的东西隔绝开来，无法随便前往其他世界。单一世界的居民并不知道其实还有其他世界。……最后只剩下人的世界。也就是这个世界。"

- 名称：巨大陆
  - 内容：一万至八千年前的混沌时代，中央大陆和魔大陆彼此相连，被称为巨大陆。约四千两百年前在第二次人魔大战终结时，被黄金骑士阿尔德巴朗的大招打出一个大洞，分裂为中央大陆和魔大陆，并在中央形成林古斯海。
  - 原文依据："当时中央大陆和魔大陆彼此相连，据说被称为巨大陆。"、"最后施展的大招把当时的巨大陆打出一个大洞，所以分成中央大陆和魔大陆，并创造出林古斯海。"

- 名称：中央大陆（环境特征与语言区域分布）
  - 内容：拥有丰富自然、适宜居住的土地。全境主要使用人类语，分为北部、西部、南部三地，各地语言微有口音差异。若来自西部，在其他地区易被视为有钱人而招来不怀好意之徒。在拉普拉斯战役中曾遭赤龙封锁山区，并被魔神拉普拉斯由南北双向夹击。
  - 原文依据："中央大陆是拥有丰富自然适合居住的土地。"、"使用人类语的中央大陆分为北、西、南三个部分，各地的人类语也略有不同，不过顶多只是美式英语和英式英语的差别。我使用的是中央大陆西部的人类语。在北部使用西部的语言也可以通用，不过据说在其他地区最好不要使用西部的语言。原因就是来自西部的人会被视为有钱人，所以会有一些不怀好意分子试图靠近。"

- 名称：魔大陆（环境特征）
  - 内容：容易形成魔力沉滞的荒废大地。在第二次人魔大战后，被人类联合其他种族运用长达三千年以上的渐进外交手段彻底封锁，魔族为争夺匮乏资源长期陷于内乱内耗。
  - 原文依据："魔大陆是容易形成魔力沉滞的荒废大地。人族为了把下贱的魔族困在魔大陆上，花了三千年以上逐步推进，就像是温水煮青蛙那般把魔大陆封锁起来。"、"于是，他们为了在严苛的环境里争夺仅有的资源，自然会形成内乱状态。魔族因此锻炼得更强，但却造成人数减少。"

- 名称：林古斯海
  - 内容：约四千两百年前第二次人魔大战终结时，因黄金骑士阿尔德巴朗与魔界大帝决战的大招轰穿巨大陆而新形成的大海，位于中央大陆与魔大陆之间。
  - 原文依据："最后施展的大招把当时的巨大陆打出一个大洞，所以分成中央大陆和魔大陆，并创造出林古斯海。"、"虽然关于大陆的部分值得怀疑，但据说事实上大陆的确是在这场战争中一分为二，中央出现新的大海。"

- 名称：米里斯大陆（大森林与南部）
  - 内容：分为北部与南部。北部为大森林，是兽族聚落所在地，使用兽神语，环境较为封闭；南部使用人类语，坐落着米里斯神圣国，拥有圣米里斯结界与强大的圣骑士团，地形不利大军登陆。四百年前大森林兽族曾与魔族结盟牵制米里斯神圣国。
  - 原文依据："米里斯大陆并没有遭到侵略。……包括圣米里斯的结界和强大的圣骑士团，以及不利大军登陆的地形等等。此外，让他们畏缩不出的原因是位于北部的大森林。大森林里的兽族和魔族缔结同盟，牵制着米里斯神圣国的行动。"、"米里斯大陆使用的语言也分成北部和南部。北部使用兽神语，南部使用人类语。"

- 名称：贝卡利特大陆
  - 内容：全境主要使用斗神语的大陆。
  - 原文依据："・斗神语：贝卡利特大陆使用的语言。"

- 名称：天大陆
  - 内容：全境主要使用天神语的大陆。
  - 原文依据："・天神语：天大陆使用的语言。"

- 名称：海域（世界大海）
  - 内容：世界所有海域主要使用海神语，大海中居住着名为海人族（或称海鱼族）的种族。
  - 原文依据："・海神语：所有海域使用的语言。"、"至于所有海域，听说这世界的大海里居住着名为海人族的种族。虽然我好像有在哪里听过海鱼族这名词，但是没在城镇里见过。"

- 名称：王龙王国（社会风气/犯罪现象）
  - 内容：流行着某种利用书信文字交流的跨阶层诈欺犯罪。贼人伪装成贵族青年写信结识贵族家子女，长久博取信任后诱出绑架卖给奴隶商店。
  - 原文依据："话说起来，在王龙王国那边好像正流行着这种诈欺。据说有能够读写的贼人伪装成贵族青年写信给贵族家子女，耗费长时间取得信任后，在某天突然把对方找出来，然后绑架卖给奴隶商店。"

## 二、组织与势力
- 名称：五龙将
  - 内容：太古邪恶龙神的部下高级将领，由龙帝担任领袖，包含龙帝与四名龙王。在仅存最后一个世界时背叛龙神，以五对一与龙神进行死斗，最终两败俱伤导致龙的世界崩毁。
  - 原文依据："掌控名为「五龙将」的部下，毁灭其他世界。……在只剩下最后一个世界时，「五龙将」背叛龙神。身为「五龙将」领袖的龙帝和其他四名龙王挺身和拥有压倒性力量的龙神战斗。五对一的死斗，结果是不分胜负。受到这场战斗的余波影响，龙的世界崩毁。"

- 名称：五大魔王
  - 内容：第一次人魔大战期间魔族麾下的五位顶级魔王，最终被勇者亚尔斯率领六名同伴全数打倒。
  - 原文依据："一直到勇者亚尔斯率领六名同伴打倒「五大魔王」和「魔界大帝奇希莉卡」后才宣告结束。"

- 名称：魔界统一帝国
  - 内容：一千年前由魔神拉普拉斯建立的魔族统合政权，拉普拉斯平定魔大陆后花费长久岁月构建，使魔族全族变得刚毅而强韧。
  - 原文依据："魔神拉普拉斯诞生。……拉普拉斯迅速统合整个魔族，平定魔大陆。……建立起类似魔界统一帝国的组织，让魔族这个种族全体都变得刚毅而强韧。"

- 名称：米里斯圣骑士团
  - 内容：米里斯神圣国的精锐强大武装力量，四百年前在七名英雄带领下突袭拉普拉斯大本营。
  - 原文依据："包括圣米里斯的结界和强大的圣骑士团……"、"开战后过了一阵子，七名英雄率领米里斯圣骑士团和兽族突袭拉普拉斯的大本营。"

- 名称：阿斯拉王国（拉普拉斯战役时期）
  - 内容：四百年前拉普拉斯战役中中央大陆唯一幸免沦陷的人族国家，在最后决战中倾全国全部战力正面对抗魔神大军。
  - 原文依据："中央大陆唯一剩下的人族国家阿斯拉王国倾全力迎向决战。"

- 名称：剑神流派层级体系
  - 内容：剑神流内部的位阶架构，自上而下已知包含剑神、剑帝、剑王、剑圣、上级、中级、初级。其中剑王位阶名额极其严苛狭窄（推测剑帝两人，剑王一人，基列奴为全流派第四强的高手）。
  - 原文依据："毕竟她可是剑神流中第四强的高手。……因为有剑神、剑帝、剑王……嗯？啊，是不是因为剑帝有两个人？意思是剑王只有一个吗？我听说世界上有许多剑神流的剑士，所以还以为拥有剑王称号的人大概也有十来个左右，没想到意外是个窄门。"

## 三、力量体系 / 魔法 / 技能
- 名称：斗气
- 规则：剑士肉身激发的特殊能量气场。只要能凭借自身意志掌控「斗气」，即可正式晋升为剑神流上级剑士；若能完全随心驾驭「斗气」，则达到剑圣位阶。
- 原文依据："身上也开始会出现「斗气」。只要能基于自我意志来掌控「斗气」，就能正式成为剑神流的上级剑士。若能完全驾驭，那就是剑圣。"

- 名称：无咏唱施法训练与实战门槛
- 规则：在完全习得魔术后，通过专门的控制力训练达成省略咒文直接施放。实战核心优势在于两手受制无法动弹时依然能施法，且能配合高速位移并混合妨碍与攻击魔术。但该法极难后天习得，艾莉丝与基列奴历经两年严苛训练依然无法掌握。
- 原文依据："或许是鲁迪乌斯的教育方针吧？他没有立刻换成中级，而是进行了在学会魔术后，要以无咏唱来施展的训练。就算两手都无法动弹也能够使出简单魔术的理论非常合理。……不过呢，即使努力还是无法办到。"、"魔术：完全无法学会无咏唱。"

- 名称：部族独创魔术
- 规则：魔族各个部族中流传着许多人族不知晓的独特独创魔术，无文献流传，唯有通晓魔神语并与该部族建立深厚信赖关系才可能被传授。
- 原文依据："魔族的各部族里，存在着许多人族不知道的独创魔术。虽然应该没有留下文献，但只要你懂魔神语，将来或许可以前往部族的聚落，请对方教导你那些魔术。当然，前提是要能建立起良好的关系。一般的魔术师虽然不可能学会，但鲁迪乌斯或许能够充分掌握那些魔术。"

- 名称：剑术流派风格差异（剑神流 vs 北神流/水神流）
- 规则：
  - 剑神流：讲究以千锤百炼的基础为核心的绝对合理性，要求仅凭单一步伐踏步瞬间洞察并决一生死。思虑过多、试图让合理基础更加合理的思考模式反而不契合剑神流。
  - 北神流与水神流：战术灵活多变，更适合善于结合实战情况与配合魔术的剑士。
- 原文依据："但是，鲁迪乌斯不具备剑神流的才能。因为他过于追求合理性，所以会想太多。他试图让已经采用合理动作的基础变得更合理，最后反而会造成不合理的结果。……然而，这种做法并不适合必须只靠一个踏步就判断一切，并在一瞬间的交锋中决定出胜负的剑神流。保罗似乎没有教他，但北神流或水神流应该比较适合鲁迪乌斯。"

- 名称：实战魔术师价值准则
- 规则：在对人战斗中，最可靠的并非耗费漫长咏唱施展大威力魔术的上级魔术师，而是能配合高速移动、瞬发灵活施展初中级行动妨碍与攻击魔术的魔术师。
- 原文依据："在实战中最可靠的并不是花费长时间咏唱才能使用出强大魔术的上级魔术师，而是能因应状况，巧妙用出初级、中级魔术的魔术师。……对剑士来说，那种能一边以高速不断移动，还可以同时使出行动妨碍与攻击魔法的对手，就是最难对付的强敌。"

- 名称：不死身魔术 [存疑]
- 规则：鲁迪乌斯根据部分魔族种族与魔王没有寿命限制、魔界大帝死后数百年能复活等现象，推测世上或许存在能让身体变成不死身的魔术（未证实）。
- 原文依据："顺便提一下，之所以可以留下这么长的历史，好像是因为有些种族没有寿命限制。魔界大帝奇希莉卡就是其中一例，另外似乎也还有许多被称为不死身的魔王。说不定也有能让身体变成不死身的魔术。"

## 四、种族 / 生物
- 名称：太古起源七族（人族、魔族、兽族、海族/海人族、天族、龙族、无族）
  - 特征：太古时代分别居住于各自的神之世界，后因灭世流入人的世界：
    - 兽族：居住在森林中（米里斯大陆北部大森林）。
    - 海族 / 海人族（海鱼族）：支配大海，居于世界各处海域中。
    - 天族：掌控高地。
    - 龙族：神魔死斗后所剩无几，避开人耳目悄然隐居。
    - 无族：适应力极强，在任何环境下都能生活，到处可见。
    - 人族与魔族：起初在平原平地上争斗不休。
  - 原文依据："兽族住在森林里，海族支配大海，天族掌控高地。龙族已经所剩无几，但还是避开他人耳目悄悄隐居。无族在哪里都能生活，因此也在哪里都看得到他们。只有人族和魔族在平地上争斗。"、"至于所有海域，听说这世界的大海里居住着名为海人族的种族。虽然我好像有在哪里听过海鱼族这名词，但是没在城镇里见过。"

- 名称：亚人复合种族（长耳族、矿坑族、小人族）
  - 特征：分类上多被算作魔族，但学术界亦有学说推论其为混沌时代诞生的新种族，或与太古无族具有亲缘关联。
  - 原文依据："世界上有长耳族、矿坑族、小人族等各式各样的种族。他们在分类上似乎会被算是魔族。然而，也有一说认为他们是在混沌时代诞生的新种族。说不定和一开始提到的无族也有关系。"

- 名称：米格路德族（习性补充）
  - 特征：魔大陆魔族部族之一，洛琪希的出生种族。洛琪希编写的辞典中记录该族具有特殊的部族禁忌与体貌特征，且记录“基本上，米格路德族都喜欢甜食”。
  - 原文依据："尤其是米格路德族的项目花了五页，写得最为详细。……「基本上，米格路德族都喜欢甜食」。上面写了这种情报，不过是真的吗？"

- 名称：赤龙
  - 特征：五百年前拉普拉斯战役期间，被魔神拉普拉斯大量投放到中央大陆山区的凶暴生物，导致中央大陆山区完全无法通行，阻断人族兵力南北调动。
  - 原文依据："在中央大陆放出赤龙，让山区无法通行，然后派出另一支部队从北方入侵，截断人族兵力后一口气攻下南部。"

- 名称：不死身魔王 / 魔帝
  - 特征：没有寿命限制的魔族高级存在。如魔界大帝奇希莉卡为不死身，即使被杀死亡也能在数百年后再次复活；此类长生种使漫长历史得以传承。
  - 原文依据："结果她似乎是不死身的魔帝，即使死亡也能在数百年后复活。……之所以可以留下这么长的历史，好像是因为有些种族没有寿命限制。魔界大帝奇希莉卡就是其中一例，另外似乎也还有许多被称为不死身的魔王。"

## 五、物品 / 道具 / 武器
- 名称：《希格的召唤魔术》
  - 说明：讲解召唤魔术的书籍，要价约五枚金币，鲁迪乌斯打工攒钱准备购买，但稍一疏忽便被其他买家买走。
  - 原文依据："这是为了购买《希格的召唤魔术》而存的钱。然而，才稍微没注意，那本书就被买走了。……五枚金币能够买到的东西。"

- 名称：洛琪希手写魔神语教科书兼辞典
  - 说明：洛琪希耗费近半年时间亲手为鲁迪乌斯编撰的手抄教科书兼辞典。封面为动物皮革，内容网罗魔神语词汇、语法、发音方法及与人类语对照；后半部详载魔族各部族情报、禁忌、插图与特征说明（其中米格路德族详占五页）。
  - 原文依据："放在木箱里面的东西，是一封信和一本厚厚的书。这本书没有书名，外皮是动物的皮革……这不但是教科书，也是辞典。已经把所有的魔神语都翻成人类的语言。……后半部写着洛琪希知道的所有部族情报。包括每一个部族的说明，以及洛琪希的主观解说。……尤其是米格路德族的项目花了五页，写得最为详细。"

- 名称：《佩尔基乌斯的传说》

  - 原文依据："也因为用来当作教科书的书籍，是叙述在《佩尔基乌斯的传说》里也有登场的兽族英雄故事。即使被视为外传，但只要手边有一本《佩尔基乌斯的传说》，要辨认单字就不是难事。"

## 六、历史 / 传说 / 事件
- 事件名：太古的神之时代
  - 内容：十万年以上之前，世界分为七个，各自受人神、魔神、龙神、兽神、海神、天神、无神支配，彼此隔绝。
  - 原文依据："十万年以上之前……分为七个世界，似乎各自受到神的支配。这时被称为「太古的神之时代」。"

- 事件名：龙神灭世与五龙将死斗
  - 内容：两万至一万年前，龙世界诞生极端邪恶的龙神，率领部下五龙将打碎结界毁灭其余世界。当仅剩人的世界时，五龙将（龙帝与四龙王）背叛龙神与之决死战斗，结果不分胜负，龙世界崩溃，残存各种族避难至唯一幸存的人的世界。
  - 原文依据："两万～一万年前……龙的世界诞生出一名极为邪恶的龙神。……毁灭其他世界。……在只剩下最后一个世界时，「五龙将」背叛龙神。……五对一的死斗，结果是不分胜负。受到这场战斗的余波影响，龙的世界崩毁。最后只剩下人的世界。"

- 事件名：混沌时代
  - 内容：一万至八千年前，避难流入的人族祖先与其他世界的居民互相交战混战，历经长久年月后各自寻得栖身之所。
  - 原文依据："一万年前～八千年前……这段时期被称为混沌的时代。是原本住在这里的人族祖先与其他世界的居民互相交战的时代。……历经长久年月后，各种族分别找了地方栖身。"

- 事件名：第一次人魔大战
  - 内容：约七千年前至六千年前，人魔正面冲突爆发全面战争，波及其他种族持续千年。最终由勇者亚尔斯率六名同伴打倒五大魔王与魔界大帝奇希莉卡，宣告结束。
  - 原文依据："约七千年前……这时发生第一次人魔大战。……约六千年前……持续了千年，据说一直到勇者亚尔斯率领六名同伴打倒「五大魔王」和「魔界大帝奇希莉卡」后才宣告结束。"

- 事件名：人族争霸时代与魔族奴役
  - 内容：约五千五百年前起持续近五百年，人族因战胜魔族而自傲，挑起与其他种族战争并陷入人族内乱，期间魔族被普遍作为奴隶对待。
  - 原文依据："约五千五百年前……误以为打倒魔族的自己一族非常强大，于是挑起与其他种族间的战争，或是人族之间彼此相争……据说魔族被当成奴隶对待。这种战国时代似乎持续了将近五百年。"

- 事件名：第二次人魔大战与巨大陆分裂
  - 内容：约五千年前至四千两百年前，魔界大帝奇希莉卡复活率领魔族联合兽族、海族发难，激战八百年将人族逼入绝境。最终人族英雄黄金骑士阿尔德巴朗挺身力挽狂澜，以一敌万单挑奇希莉卡，决战大招轰碎巨大陆，将大陆一分为二（分裂成中央大陆与魔大陆）并创造林古斯海，促成和平。
  - 原文依据："约五千年前……爆发第二次人魔大战。……魔族在「魔界大帝奇希莉卡」的率领下发难。……约四千两百年前……终结。……靠一位名叫黄金骑士阿尔德巴朗的英雄出面奋战。……最后施展的大招把当时的巨大陆打出一个大洞，所以分成中央大陆和魔大陆，并创造出林古斯海。"

- 事件名：魔大陆封锁与魔族内耗
  - 内容：约四千两百年前至一千年前，人族运用漫长外交手段（三千年以上），联合其他种族逐步将魔族困于环境荒废的魔大陆，魔族因争夺稀缺资源陷入长期内乱，人数减少但战力精悍。
  - 原文依据："约四千两百年～一千年……人族很狡猾，运用外交手段，把魔族关进魔大陆。……为了在严苛的环境里争夺仅有的资源，自然会形成内乱状态。魔族因此锻炼得更强，但却造成人数减少。"

- 事件名：拉普拉斯统合魔族与拉普拉斯战役
  - 内容：一千年前魔神拉普拉斯诞生并平定魔大陆建立帝国。五百年前拉普拉斯说服海族、兽族进军中央大陆，分南北夹击并以赤龙封山。四百年前，七名英雄突破海路并威逼兽族协助，联合米里斯圣骑士团及阿斯拉王国发起决战，最终四名英雄战死，封印魔神拉普拉斯，拉普拉斯亲信全灭。
  - 原文依据："一千年前……魔神拉普拉斯诞生。……平定魔大陆。……五百年前……爆发拉普拉斯战役。……四百年前……走投无路的人族决定押下最后的赌注。……七名英雄率领米里斯圣骑士团和兽族突袭拉普拉斯的大本营。在激战过后，七名英雄中有四人死亡，但也让拉普拉斯的亲信们全灭，并成功封印魔神拉普拉斯。"

- 事件名：杀死魔神的三英雄与战后人魔条约
  - 内容：决战后生还的三位英雄：龙神乌尔佩、北神卡尔曼、甲龙王佩尔基乌斯（被称为“杀死魔神的三英雄”，实为封印）。战后人族筋疲力竭，与留在魔大陆的稳健派魔王缔结和平条约，废除魔大陆封锁，保障魔族在各大陆自由行动与禁止歧视。
  - 原文依据："活下来的三人包括：龙神乌尔佩、北神卡尔曼、以及甲龙王佩尔基乌斯。他们似乎被称为「杀死魔神的三英雄」……等等，没杀死啊。……人族和无法跟随拉普拉斯，还留在魔大陆上的稳健派魔王缔结条约。魔大陆的封锁被取消，魔族在其他大陆上也能正大光明地行动。除此之外，因为是魔族而遭到歧视的部分也基于条约而受到禁止。"

## 七、社会规则 / 习俗 / 文化
- 内容：**数字吉凶文化**。受历史传说深刻影响，世界普遍将“七”视为吉利数字（如七世界、七神、七名英雄），而将“六”视为不吉利的数字（如五龙将+龙神首领为六，五大魔王+魔帝首领为六）。
  - 原文依据："七被视为吉利数字的原因。这是受到历史的影响。七英雄、七世界，带来吉兆的数字都是七。不吉利的数字则是六。例如有「五龙将」和「五大魔王」，再加上头目就是六。"

- 内容：**大陆语言体系与神名命名习俗**。各大陆语言除人类语外，皆以当地信仰之神命名（兽神语、斗神语、天神语、魔神语、海神语）。人类语之所以不称“人神语”，是因民间认为直接借用人神之名会招致天罚。
  - 原文依据："如果粗略区分，则是根据居住在各大陆上的种族信仰什么神，就使用那位神的名字作为语言的名称。不过只有人类不是人神语，那是会遭天罚的行为嘛。"

- 内容：**伯雷亚斯家族的兽族嗜好血统**。伯雷亚斯·格雷拉特家族成员（如绍罗斯、菲利普、艾莉丝）普遍对兽族（尤其是兽耳与兽尾）抱有强烈的执念与特殊喜爱视线。
  - 原文依据："原来是耳朵和尾巴。不管是艾莉丝大小姐，绍罗斯大人，还有菲利普大人都一样。……菲利普大人面不改色地断言：「因为『伯雷亚斯』喜欢兽族。」"

- 内容：**剑神流不盗窃戒律**。剑神流师门教育极为严苛，门规明确禁止对他人所有物出手、禁止盗窃犯罪。
  - 原文依据："但是师父严格教育过我不能对他人所有物出手，因此也无法动手窃盗……"
