# 第二话　「自导自演」 世界设定提取

## 一、地理与场所
- 名称：威汀（城镇）
- 内容：距离罗亚有两个城镇距离的城镇。规模不大（虽然没有小到算是村庄等级，但也是个不大的城镇），没有城墙。城门处有警卫，入口附近设有公共马车候车处（附带厕所），候车处墙壁上写有利用方法和费用。
- 原文依据："逃出仓库后，眼前是陌生的城镇。由于没有城墙，至少一定不是罗亚。虽然规模并没有小到算是村庄等级，但也是个不大的城镇。"、"「这里好像叫作威汀，是距离罗亚两个城镇的地方。」"、"前往在入口附近的公共马车候车处。墙壁上写着利用方法和费用，不过这些已经先查好了。"

- 名称：威汀与罗亚之间的隔壁城镇（中途城镇）
- 内容：位于威汀与罗亚之间的城镇，从威汀搭乘公共马车需三小时到达。镇上有如废屋般的简陋落脚处（床铺为稻草堆）。从威汀前往罗亚必须转乘两次公共马车，若下午搭第四班车抵达此城镇后，当天便没有前往罗亚的马车可搭，必须留宿一晚。
- 原文依据："话说回来，刚刚我去看了车费，从这边出发必须转乘两次公共马车才行。"、"从这里到隔壁城镇需要花三小时，而现在要出发的这班车是第四班，所以……就算到达隔壁城镇，也没有前往罗亚的马车可搭。也就是必须在隔壁城镇住一晚。"、"我们顺利移动到隔壁城镇。为了让大小姐体会这世界到底有多严苛，我选择了跟废屋没两样的地方作为落脚处。床铺只是一堆稻草。"

## 二、组织与势力
- 名称：拐卖人口与赎金绑架团伙 / 犯罪者
- 内容：存在专门绑架贵族孩童、联系变态贵族买家高价贩卖或向领主勒索高额赎金的职业犯罪者/无赖。有跨国犯罪与销赃渠道，得手后会逃往邻国避难。
- 原文依据："「所以，要卖给那个家伙吗？」「不，拿来交换赎金吧。」「不会留下让人追查的线索吗？」「也没差吧，那时候我们早就到邻国了。」"、"「我认识那种变态贵族，愿意出高价购买身分高贵的小女孩。而且还听说这里的领主很宠孙女，所以也可以要求赎金。要多少钱对方都会愿意出。」"

- 名称：泰德鲁帝亚族（兽族氏族）
- 内容：基列奴所属的兽族部族。部族中的每一位战士都具备极高战斗力，能瞬间秒杀寻常剑士级别的对手。
- 原文依据："抬头一看，可以看到长着动物耳朵的后脑。原来是基列奴・泰德鲁帝亚。"、"面对那种程度的对手，每个泰德鲁帝亚族的战士都可以瞬间解决。"

## 三、力量体系 / 魔法 / 技能
- 名称：治愈魔术规则与阶级
- 规则：
  1. 治愈魔术并非灌注越多魔力就能得到越好效果的类型。
  2. 初级治疗术（Healing）：可治愈轻度伤势并止血（能缓解内脏受损吐血）。咏唱咒文："神圣之力是香醇之粮，赐予失去气力之人再次站起来的力量吧……『Healing』。"
  3. 中级治疗术（ExHealing）：可治愈骨折等严重肉体创伤。咏唱咒文："宛如母亲的慈爱女神，请治愈此人之伤口，让他恢复健康的身体……『ExHealing』。"
- 原文依据："治愈魔术并不是灌注越多魔力，就能得到越好效果的类型。"、"居然断了两根骨头。「宛如母亲的慈爱女神，请治愈此人之伤口，让他恢复健康的身体……『ExHealing』。」我低声咏唱中级治疗术，治愈大小姐的身体。"、"「神圣之力是香醇之粮，赐予失去气力之人再次站起来的力量吧……『Healing』。」总之，我施展初级治疗术稍微治愈伤势。看她不再吐血，这样就不会死了吧……大概。"

- 名称：魔术机制与特殊操作
- 规则：一般咏唱魔术到发射为止通常是自动进行，未经系统学习者往往不知道魔术在发射前可以取消消掉。无咏唱施法者可在发射前精细操作魔力调整内部结构（例如在火球中制作另一个特殊火球引发高空爆鸣强光，或调整火球射速）。
- 原文依据："他为什么不叫我把火球消掉呢？不，或许他并不知道可以消掉。毕竟咏唱魔术到发射为止都是自动进行。对于没有确实学习过魔术的人来说，大概不太清楚这部分的详情吧。"、"我在发射出去之前，操作魔力调整手上的火球。在火球之中制作出另一个特殊的火球。然后发射。咻～砰！火球发出不怎么样的声音并升上天空。然后在空中引发剧烈的爆炸。"、"射出速度则是缓慢。"

- 名称：复合/混合魔术应用
- 规则：
  1. 土与火复合：填补门缝并熔化固定金属门把；土魔术可筑起高大土墙阻断道路。
  2. 水魔术：可冲刷泥土结构拆卸金属铁栏杆。
  3. 风与火混合：在脚边制造冲击波反冲弹飞自身实现高速位移脱离。
  4. 水与土复合（泥沼）：改变地面使之成为高黏性泥浆，封锁目标下半身移动。
  5. 风中级魔术「真空波」：能切断人体肢体。
  6. 土中级魔术「岩炮弹」：高硬度弹体，但可被高阶剑士斩断。
- 原文依据："首先我使用土和火魔术，填满大门的缝隙。接着利用火魔术慢慢熔化门把，让门把固定住无法转动。"、"我利用水魔术来一点点冲掉铁栏杆周围的土，最后成功把整个铁栏杆给拆了下来"、"施展出的魔术在他们面前制造出一道高高的土墙。"、"右手是风的中级魔术「真空波」。左手是土的中级魔术「岩炮弹」……真空波切断了正看向空中的粗鲁家伙的手。"、"他在把岩炮弹一切为二。……他居然能斩断岩石。"、"我在脚边使出风和火的混合魔术，制造出冲击波并借此把自己弹飞。"、"使出水和土魔术，让那家伙的脚边出现泥沼。即使那家伙能对应火球，但膝盖以下都陷入高黏性的泥浆里，行动也遭到封锁。"

- 名称：北神流（剑术）
- 规则：技巧灵活多变，包含在脚部受伤或面对远距离敌人时投掷飞剑刺击对方的技巧；北神流剑士即便身处濒死绝境也不会放弃攻击。
- 原文依据："在北神流中，有一种脚受伤时可以掷剑攻击的技巧。也就是有一种在面对远距离的敌人时，丢出剑来刺击对方的技巧。"、"那些家伙连临死前都不会放弃，你要小心。"

- 名称：剑王级剑术（超远距离斩击）
- 规则：剑王级剑士出剑速度快至仅见红色剑光掠过，能在对手身处数公尺之外、物理剑刃触碰不到的距离外直接斩断对手首级。
- 原文依据："当她把手移向腰间佩剑的那瞬间──红色剑光划过半空……脚陷在泥沼里的男子脑袋掉了下来。明明他身在远处，剑应该砍不到的位置。……接着在基列奴的尾巴稍微动了一下的那瞬间，另一人的脑袋也掉了。"

## 四、种族 / 生物
- 名称：魔族
- 特征：魔族中存在着外表维持幼童模样、但实际年龄已经不小的长寿/特殊种族。
- 原文依据："「嘿嘿，你虽然外表是那模样，但其实已经年纪不小了吧？……从刚才的魔术，还有这种冷静的态度就能看出来。我听说过魔族里也有那样的种族。你应该因为外表而吃过不少苦头吧？」"

- 名称：泰德鲁帝亚族（兽族）
- 特征：长着动物耳朵与尾巴，部族战士具备极强战斗本能与实力。
- 原文依据："抬头一看，可以看到长着动物耳朵的后脑。原来是基列奴・泰德鲁帝亚。……面对那种程度的对手，每个泰德鲁帝亚族的战士都可以瞬间解决。"

## 五、物品 / 道具 / 武器
- 名称：阿斯拉大铜币
- 说明：阿斯拉王国货币，价值为银币的十分之一。五枚大铜币足以支付行贿警卫、两次公共马车车费以及一晚简陋住宿。
- 原文依据："首先我拿出藏在内裤里的五枚阿斯拉大铜币。这是目前拥有的所有财产。顺便解释一下，大铜币的价值是银币的十分之一，算是很靠不住的金额。"、"我手上虽然有四个大铜币，不过从这里前往隔壁城镇，住一个晚上，再从隔壁城镇前往罗亚……如果要把钱各自用在这三件事情上面，只能说是勉强。"

- 名称：金币
- 说明：高面值货币。普通人每月雇用酬劳仅一两枚金币左右（绑架犯语中的“寒酸金额”）；而变态贵族购买贵族小女孩或领主赎金可达一百枚金币左右。
- 原文依据："「可不是一个月一两枚金币那种寒酸金额，大概会有一百枚金币吧。」"

## 六、历史 / 传说 / 事件
- 事件名：大小姐绑架自导自演作战与突发变故
- 内容：鲁迪乌斯为让任性大小姐主动学习读写、算术与魔术，向菲利普提议自导自演绑架事件。然而实际执行中出现意外，遭遇真正的拐卖无赖绑架（或假戏真做重伤大小姐并打算卖掉或索要赎金），险些导致两人丧命，最终由鲁迪乌斯携大小姐逃亡并由基列奴赶到击杀劫匪收场。
- 原文依据："为了拉拢大小姐，作战计画的内容如下：……六、这时，听从格雷拉特家指示的绑架犯出现。七、轻松让我和大小姐昏倒，带到隔壁城镇监禁。八、我使用魔术逃出监禁地点。……"、"可以听见他们似乎真的想把我们卖了的对话。现在的情况大概类似原本拜托认识的人去袭击女孩子，结果却偶然碰上「本行人士」来插手吗？到底是哪个环节出错呢？……"、"「因为看到空中突然发生爆炸所以赶来看看，结果是正确答案。」"

## 七、社会规则 / 习俗 / 文化
- 内容：公共马车运营规则：公共马车从每日清晨8点开始发车，每2小时一班，全天共5班车；各城镇班次规律相同；车费与利用方法张贴于候车处墙面。
- 原文依据："公共马车从早上八点开始，每两个小时会发出一班车，每天总共五班。每个城镇都一样。从这里到隔壁城镇需要花三小时，而现在要出发的这班车是第四班"、"前往在入口附近的公共马车候车处。墙壁上写着利用方法和费用"

- 内容：找零欺诈与市井风气：商家（旅社与公共马车雇员）面对年幼孩童常认定其不懂算术而故意克扣找零，但一旦被当场指出错误通常会退还正确零钱。
- 原文依据："旅社和公共马车的人看到像我们这样的小孩，应该会认为我们不会算术吧。这样一来，说不定他们会在找零的时候故意少找钱。只要当场指出错误，大概就会还给我们正确的零钱。但是，如果不会算术……"

- 内容：贵族称谓特例：在贵族家庭中，下人或低阶亲属直呼贵族小姐名字需获得特例许可（艾莉丝在脱险后正式特例允许鲁迪乌斯称呼其名字“艾莉丝”）。
- 原文依据："「我特别允许你可以叫我艾莉丝！」「就说是特例！」「谢谢您！艾莉丝大小姐！」「不用加大小姐！叫艾莉丝就好！」"

## 九、角色认知 vs 客观事实
- 角色以为：绑架犯看到鲁迪乌斯能无咏唱使用强力魔术且神情过于冷静，断定他是外表长得像小孩、实际年纪很大的魔族护卫。
- 原文是否暗示另有真相：是。
- 原文依据："「真的是被外表骗了！原来你是魔族！」……「嘿嘿，你虽然外表是那模样，但其实已经年纪不小了吧？从刚才的魔术，还有这种冷静的态度就能看出来。我听说过魔族里也有那样的种族。」"（实际上鲁迪乌斯是人族儿童，但精神意识是四十多岁的转生者，并非魔族）

- 角色以为：鲁迪乌斯起初以为绑架完全是菲利普安排的人手在按照计划演戏。
- 原文是否暗示另有真相：是。
- 原文依据："身上到处都痛，总之先确认没有骨折后，我低声使出治愈魔术。……一切正如作战计画。……不过，现状和预定有点不同。……听起来不像是。该不会，或许是「那种」情况吧？"（实际上对方是真正的凶残犯罪者，或者出现重大意外，对艾莉丝施加了足以致死的残暴殴打并打算索要赎金或卖给变态贵族）

- 角色以为：鲁迪乌斯以为带着艾莉丝抵达罗亚城墙内、看见领主宅邸后就已经绝对安全，因而放松戒备。
- 原文是否暗示另有真相：是。
- 原文依据："通过那可靠的城墙，看到远处的领主宅邸后，我心中涌上一股强烈的放心感。我下意识认为到这里就安全了。……彷佛逮住了这一瞬间的空档──大小姐突然被拖进小巷里。我太大意了。"（实际上绑架犯的同伙就潜伏在罗亚巷弄内，立刻再度实施绑架）

- 角色以为：艾莉丝刚逃出仓库时以为已经脱离危险，立刻开始大呼小叫。
- 原文是否暗示另有真相：是。
- 原文依据："「哼！到这里就没问题了吧！」大小姐大概是误以为已经甩开追兵了，突然大呼小叫起来。……下一瞬间，远方传来怒吼声。「臭小鬼！跑哪里去了！」……「……咿！」大小姐低声惨叫，立刻又回到我身边。"（实际上绑架犯就在附近，大叫立刻招来了追捕）
