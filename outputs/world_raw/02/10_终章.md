# 终章 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国石板干道
  - 内容：阿斯拉王国从国土的这头到那头都铺设着平整的石板路干道。在他国大概只有首都附近才能见到如此平整的道路。灾难后在菲托亚领地界线处石板路断裂消失，化为一片空无一物的草原。
  - 原文依据："现在洛琪希脚下的干道是阿斯拉王国铺设的石板路。在他国，大概只有首都附近才能见到如此平整的道路。然而阿斯拉王国却从国土的这头到那头都铺设着这种石板路。……然而，眼前的景象中，过了某条界线后道路就消失了。只有一整片草原，彷佛什么都不曾发生。"

- 名称：菲托亚领地难民营
  - 内容：菲托亚领地消失后在遗址上搭盖的收容所，有数栋木造建筑，具备一个村落的规模。人口众多且忙碌，气氛沉重阴郁。原为富饶土地，拔草可当粮食不会挨饿。营内设有临时冒险者公会，告示栏贴满死者与失踪者名单及寻人委托。
  - 原文依据："其实有个菲托亚领地的难民营，你要去那里看看吗？"、"难民营里搭载着好几栋木造建筑，形成可以算上一个村的规模。人很多，大家都显得很忙碌。然而聚落里却缺乏活力，笼罩着一股沉重阴郁的空气。"、"这个聚落里看起来不像是缺乏食物。毕竟这里原本就是富饶的土地。只要拔起附近的草当粮食，就不会挨饿。"、"她来到难民营里的临时冒险者公会。原本应该张贴着几张委托书的告示栏前方。"

- 名称：阿斯拉王国（地理环境与风貌补充）
  - 内容：洛琪希认知中世界上最富足的国家，处处可见快活笑容，食物丰富，魔物很少，是最能轻松生活的国家。
  - 原文依据："洛琪希认识的阿斯拉王国是世界上最富足的国家。在这里，处处可见洋溢着快活气息的表情和笑容。食物丰富，魔物也很少。是最能轻松生活的国家。"

- 名称：米里斯神圣国首都米里希昂
  - 内容：米里斯大陆的国家米里斯神圣国的首都，是塞妮丝出生的故乡，设有冒险者公会，保罗前往该地设立搜索据点。
  - 原文依据："我要去米里斯大陆，因为那里是塞妮丝出生的故乡。"、"・联络对象 米里斯大陆米里斯神圣国首都米里希昂冒险者公会"

- 名称：中央大陆北部
  - 内容：横渡中央大陆的最大干道是主要交通路线。中央大陆北部是保罗在留言中让鲁迪乌斯前去搜寻家人的地区，也是洛琪希考虑前往的搜寻备选地之一（相较于魔大陆和贝卡利特大陆更具安全性）。
  - 原文依据："她经过的路线是横渡中央大陆的最大干道。"、"我要你去中央大陆北部寻找。"、"如果要注重安全性，该去中央大陆北部……"

- 名称：贝卡利特大陆
  - 内容：据洛琪希听说，是魔物和迷宫都很多的土地，极度危险，普通人难以涉足。洛琪希本人未曾去过。
  - 原文依据："洛琪希并没有去过贝卡利特大陆，不过曾听说过那里是魔物和迷宫都很多的土地。"、"正因为是充满危险的土地，能踏上那些地方的人想必不多。如果是自己，有机会加入能力足以前往那两个大陆的队伍。"

- 名称：魔大陆（危险环境特征补充）
  - 内容：充满肃杀气氛，魔物凶险，是不适合一人旅行的危险大陆。
  - 原文依据："即使依旧会发生让人不快的事情，但不会出现魔大陆那样的肃杀气氛。"、"对魔大陆虽然多少有点地理知识，然而那里却是不适合一人旅行的危险场所。"

- 名称：王龙王国东部港口
  - 内容：位于王龙王国的东部港口，阿斯拉王国往米里斯方向的必经枢纽之一，保罗留下传话的推定据点之一；也是招募与加入前往贝卡利特大陆或魔大陆队伍的集散港口。
  - 原文依据："阿斯拉王国的国境，王龙王国的东部港口，还有米里斯神圣国的西部港口。至少在这三个地点应该都有留下传话。"、"先移动到王龙王国的东部港口吧。到了那里，要寻找准备前往贝卡利特或魔大陆的队伍。"

- 名称：米里斯神圣国西部港口
  - 内容：米里斯神圣国西部的港口，阿斯拉前往米里斯的通道节点港口之一，保罗留下传话的推定据点之一。
  - 原文依据："阿斯拉王国的国境，王龙王国的东部港口，还有米里斯神圣国的西部港口。至少在这三个地点应该都有留下传话。"

## 二、组织与势力
- 名称：菲托亚领地搜索团 / 布耶纳村民搜索队
  - 内容：保罗在米里斯大陆米里斯神圣国首都米里希昂冒险者公会成立的搜寻菲托亚灾民的团体与分队。
  - 原文依据："・联络对象 米里斯大陆米里斯神圣国首都米里希昂冒险者公会 队伍名称『布耶纳村民搜索队』 团体名称『菲托亚领地搜索团』 ──保罗・格雷拉特笔。"

- 名称：「黑狼之牙」
  - 内容：保罗以前隶属过的冒险者队伍，现已解散（旧成员），旧成员们对保罗抱有不满。
  - 原文依据："此外，给认识我本人和我家人的人物，以及『黑狼之牙』的旧成员们：希望你们也能帮忙寻找。『黑狼之牙』的旧成员们对我应该抱着不满吧？"、"传言上面写的「黑狼之牙」大概是保罗以前隶属过的队伍吧？"

- 名称：菲托亚领主势力
  - 内容：在难民营最明显位置以菲托亚领主名义发出征求失踪者与死者情报的官方公告。
  - 原文依据："在最明显的位置以菲托亚领主的名义，发出徵求失踪者与死者情报的公告。"

- 名称：米里斯教团
  - 内容：信奉神明的宗教教团，成员包括僧侣与信徒，僧侣持有米里斯教团的象征物作为谋生道具。面对领地全灭的灾难，部分僧侣信仰崩溃，怒斥神明为嘲笑并杀害人类的冷酷恶魔。
  - 原文依据："某个僧侣把自己的谋生道具，也就是米里斯教团的象徵物狠狠砸向地面。「我再也不相信任何神！你们根本不是神！而是只会嘲笑并杀害人类的冷酷恶魔！」"

## 三、力量体系 / 魔法 / 技能
- 名称：菲托亚领地魔力灾害（转移现象规则补充）
  - 规则：天空出现异变后爆发的大规模魔力灾害。其现象特点为：非爆炸类型，但规模极其庞大；菲托亚领地内的建筑物与树木不知所踪，原址变为草原；领地内的人们全被传送分散至世界各地（包括山上、半空中、海里、魔物栖息地等危险地点，导致死伤惨重）。
  - 原文依据："在天空出现异变后，整个菲托亚领地都发生大规模的魔力灾害。虽然不是伴随着爆炸的类型，但规模却非常庞大，菲托亚领地的人们全都被传送到世界各地。建筑物和树木不知道消失到哪里去了，只有人们被各自送往世界上的某处。"、"毕竟这次转移的目的地是世界各地。应该有人受到魔物袭击而死亡，连骨头都不剩。被传往山上、半空中、海里等处，结果立刻丧命的人大概也为数不少。"

## 四、种族 / 生物
- 名称：米格路德族（寿命与时间感知补充）
  - 特征：寿命极长，对米格路德族而言相当长的时间在感官上依然属于很短的时间。
  - 原文依据："吵架之后她负气离开聚落，已经过了相当长的年月。在不久之前，洛琪希觉得对米格路德族来说是很短的时间。岁月匆匆流逝。或许写封信回去会比较好。"

## 五、物品 / 道具 / 武器
- 名称：米里斯教团的象征物
  - 说明：米里斯教团僧侣随身携带的象征信物，同时也是僧侣的谋生道具。
  - 原文依据："某个僧侣把自己的谋生道具，也就是米里斯教团的象徵物狠狠砸向地面。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地魔力灾害（灾害发生半年后的现状）
  - 内容：天空异变后菲托亚领地整体发生大规模魔力灾害，领地彻底消失化为草原，领民被无差别随机传送到世界各地。半年后，少数幸存者历经艰险返回废墟，在遗址建立了难民营与临时冒险者公会；保罗与诺伦幸存并前往米里斯大陆设立搜索团，鲁迪乌斯、塞妮丝、莉莉雅、爱夏等人列于失踪者名单；无数家庭离散，死伤及失踪者难以估量。
  - 原文依据："菲托亚领地消失后过了半年。总算到达菲托亚领地的洛琪希面对眼前这片空无一物的「草原」，只能瞪大双眼。"、"建筑物和树木不知道消失到哪里去了，只有人们被各自送往世界上的某处。这些人当中有一部分费了千辛万苦才回到菲托亚领地。接着发现故乡已经什么都不剩，因此失去希望。"、"在失踪者的名单上找到了鲁迪乌斯等人的名字。鲁迪乌斯・格雷拉特。塞妮丝・格雷拉特。莉莉雅・格雷拉特。爱夏・格雷拉特。……保罗和诺伦的名字被划掉了。"

## 七、社会规则 / 习俗 / 文化
- 内容：冒险者公会的灾后信息枢纽功能。重大灾害发生后，灾民、领主及各方救援者皆利用冒险者公会的告示栏张贴死者与失踪者名单、留言及寻人委托。
  - 原文依据："她来到难民营里的临时冒险者公会。原本应该张贴着几张委托书的告示栏前方。……上面写着「死者」和「失踪者」的名字。旁边还贴着许多给家人的传言，以及内容是：「如果旅途中遇到这样的人，请带对方来这里」的委托。在最明显的位置以菲托亚领主的名义，发出徵求失踪者与死者情报的公告。"
- 内容：跨危险大陆组队出行习俗。前往魔大陆、贝卡利特大陆等高危危险地带，通常不适合单人旅行，必须在重要港口（如王龙王国东部港口）寻找实力足够承接跨大陆委托的冒险者队伍共同行动。
  - 原文依据："对魔大陆虽然多少有点地理知识，然而那里却是不适合一人旅行的危险场所。……正因为是充满危险的土地，能踏上那些地方的人想必不多。如果是自己，有机会加入能力足以前往那两个大陆的队伍。……先移动到王龙王国的东部港口吧。到了那里，要寻找准备前往贝卡利特或魔大陆的队伍。"

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希初听传闻时，认为领地消失、鲁迪乌斯和保罗一家消失的消息是不可能的、被骗了，深信他们平安无事地活着。
  - 原文是否暗示另有真相：是（领地与布耶纳村消失为客观现实；但保罗与诺伦确实幸存，鲁迪乌斯也并未死在当场，而是被传送至他处）。
  - 原文依据："在来此的途中，洛琪希曾经多次听说这个消息。但是她却觉得不可能。自己一定是被骗了。总之，洛琪希不愿相信。她深信那些人一定还活着，一定还平安无事地存在着。一直抱着最后一缕希望。直到亲眼目睹眼前的现实……"

- 角色以为：保罗在留言中认为鲁迪乌斯适应力极高，即使只剩一个人也能自行返回菲托亚领地，因此把搜寻他的行动往后延，并指示鲁迪乌斯前去中央大陆北部寻找塞妮丝和莉莉雅。
  - 原文是否暗示另有真相：是（鲁迪乌斯实际被传送到了极其遥远且凶险的魔大陆，并非在中央大陆，亦无法轻易返回菲托亚）。
  - 原文依据："给鲁迪乌斯：……我不知道你现在人在哪里。然而，我认为你即使只剩下自己一个人也能回到这里。所以找你的行动会往后延。……我要你去中央大陆北部寻找。"

- 角色以为：马车夫认为十岁的小孩在这样的大灾难中恐怕很难幸存。
  - 原文是否暗示另有真相：是（十岁的鲁迪乌斯实际幸存）。
  - 原文依据："「他才只有十岁。」「这……年纪轻轻就……」……「是啦，十岁恐怕很难幸存，但说不定他会在那里。」"
