# 第四话　「职员会议与星期天」 世界设定提取

## 一、地理与场所
- 名称：要塞都市罗亚
- 内容：菲托亚领地内规模最大的城镇。四周建有高约7～8米的外墙环绕，依地形起伏而建，绕城墙外围一圈约需2小时，城镇涵盖面积约三十平方公里。城内划分为贵族住宅区、靠近贵族区的高级商业街及摊位、以及外围聚集平民与冒险者的普通商业集市。
- 原文依据："菲托亚领地的要塞都市罗亚在这一带是最大的城镇。……即使走出城门绕外墙走一圈，大概也只要两小时左右就能走完。然而，这里的规模其实很大。毕竟是用高约七～八公尺的外墙把整个城镇都围住。因为不是一个完美的圆形，而是会根据地形有凹有凸，所以无法得知正确的长度，不过涵盖面积大概有三十平方公里吧？"、"我边想着这些边通过有钱人的住宅区，来到有许多行人的广场。这附近是商业区域。靠近贵族区域的这一带虽然有很多高级商店，但也有一些零星的摊位。"、"至于那些光鲜亮丽的高级商店门槛太高所以自动回避，往城镇的更外围移动。稍微走一点路之后，贩卖的商品内容整个变了。……从贵族风格的人到像是冒险者的人都有。"

- 名称：空中要塞「Chaos Breaker」
- 内容：浮在半空云层中的巨大空中城堡，由甲龙王佩尔基乌斯在拉普拉斯战役中复活并驾驶，未用于君王统治，至今仍持续在世界各地的空中巡回。
- 原文依据："空中却浮着一座城堡。混在云层里，有点若隐若现，但是却昂然存在。……「那是『甲龙王』佩尔基乌斯的空中要塞。」"、"他控制拥有这些别号的最强使魔，让古老的空中要塞「Chaos Breaker」复活，和拉普拉斯展开决战。"、"「甲龙王」佩尔基乌斯并没有以君王之姿支配或统治天下，只是控制着空中要塞在世界各地的空中巡回。"

- 名称：魔法大学
- 内容：传授高阶魔法的高等学府，菲利普承诺为鲁迪乌斯负担该学府的学费。
- 原文依据："而且还有要帮我负担魔法大学学费的附加条件。"

## 二、组织与势力
- 名称：冒险者公会
- 内容：历史悠久的中介/组织，早在大战前年轻的龙神乌尔佩就曾带领佩尔基乌斯在此留下活动记录；在罗亚商业集市也有冒险者出没。
- 原文依据："当时还年轻也尚未出名的龙神乌尔佩带着他来到冒险者公会……这就是最古老的纪录。"、"从贵族风格的人到像是冒险者的人都有。"

- 名称：阿斯拉王国
- 内容：世界上的大国之一，在拉普拉斯战役终结后为颂扬甲龙王佩尔基乌斯功绩而宣布采用新年号“甲龙历”；王国内部书籍《阿斯拉王宫宫廷仪式》为书店中最昂贵的典籍。
- 原文依据："阿斯拉王国为了颂扬他的功绩，在战争终结的同时也宣布了新的年号。就是现在的「甲龙历」。（顺便一提，现在是甲龙历四一四年。）"、"最贵的书是《阿斯拉王宫宫廷仪式》"

- 名称：佩尔基乌斯麾下（十二使魔）
- 内容：甲龙王佩尔基乌斯通过精湛召唤魔术创造的12名最强仆从/使魔集团，各自拥有专属别号：空虚、暗黑、光辉、波动、生命、大震、时间、轰雷、破坏、洞察、疯狂、赎罪。
- 原文依据："佩尔基乌斯使用自己擅长的召唤魔术，创造出十二个使魔。空虚、暗黑、光辉、波动、生命、大震、时间、轰雷、破坏、洞察、疯狂、赎罪。他控制拥有这些别号的最强使魔，让古老的空中要塞「Chaos Breaker」复活，和拉普拉斯展开决战。"

- 名称：龙神同盟小队 / 五龙将
- 内容：在古老传说中，龙神乌尔佩曾与佩尔基乌斯、北神卡尔曼以及双帝米格斯、格米斯组成战无不胜的队伍；传说中龙神的属下被称为“五龙将”，其中一名号即为“甲龙”。
- 原文依据："佩尔基乌斯很快就展现出自己的实力，和龙神乌尔佩、北神卡尔曼以及双帝米格斯、格米斯等人组成队伍，打败了所有敌人。或许是因为他就像是乌尔佩的小弟，不知不觉间，人们都以古老传说中的龙神属下「五龙将」名号之一的「甲龙」来称呼佩尔基乌斯。"

## 三、力量体系 / 魔法 / 技能
- 名称：数字“七”与位阶体系
- 规则：在这个世界中，“七”被视为特别且吉利的数字，剑术等技艺层级普遍划分为七级。
- 原文依据："在这个世界里，七这个数字似乎很特别。被视为吉利的数字，像剑术等的层级也是区分为七级。"

- 名称：剑术流派与位阶（剑神流・初级 / 剑王）
- 规则：剑术层级分为七级，艾莉丝目前处于“剑神流・初级”；基列奴拥有高级别的“剑王”头衔，被公认为具备极高实力与成就的战力。
- 原文依据："剑术：剑神流・初级。"、"基列奴有实际成就，而且还拥有剑王这个头衔。另外，她也兼任你的护卫，薪水当然会比较高。"

- 名称：召唤魔术
- 规则：魔术大类之一，能够创造或使役使魔，《希格的召唤魔术》是关于此道的专门书籍；甲龙王佩尔基乌斯以此见长并创造了十二使魔。
- 原文依据："虽然我很想看看《希格的召唤魔术》，但是要十枚金币。"、"佩尔基乌斯使用自己擅长的召唤魔术，创造出十二个使魔。"

- 名称：初级魔术（水弹、水落）与魔力消耗机制
- 规则：初级水系统魔术包含水弹与水落；每个人一天内能够调动的魔力总量有限，无法无限制施法。
- 原文依据："魔术虽然也必须每天练习，不过一天能使用的魔力有限，因此不需要太长的时间。"、"「今天使用了X次水弹，Y次水落，那么，还可以使用几次水弹呢？」"

- 名称：造墙魔术 [存疑]
- 规则：鲁迪乌斯推测是否存在制造7～8米高城墙的大规模魔术，若存在推测属于王级或帝级。
- 原文依据："是不是有能够制造出城墙的魔术呢？如果有，一定是王级或帝级吧。"

- 名称：兽族身体机能（敏锐听觉）
- 规则：兽族拥有远超人类的敏锐听力，只要在听觉范围内发出呼救便能及时察觉并迅速赶往救援。
- 原文依据："只要是在她听得到的范围内，不管在哪里基列奴都会赶来吧？听力似乎也很灵敏。"

## 四、种族 / 生物
- 名称：兽族
- 特征：身材高大（如基列奴身高接近两米），听觉极其发达敏锐，在伯雷亚斯家族享有特殊的优待传统与高薪待遇。
- 原文依据："由于基列奴的身高接近两公尺，即使我长高大概还是得抬头吧。"、"听力似乎也很灵敏。"、"伯雷亚斯・格雷拉特家的不良传统……「对兽族女性将提供特别待遇！」"

- 名称：使魔（十二使魔）
- 特征：由甲龙王以召唤魔术创造的最强使魔，各自拥有独特的自然力量或精神权能别号（空虚、暗黑、光辉、波动、生命、大震、时间、轰雷、破坏、洞察、疯狂、赎罪）。
- 原文依据："佩尔基乌斯使用自己擅长的召唤魔术，创造出十二个使魔。空虚、暗黑、光辉、波动、生命、大震、时间、轰雷、破坏、洞察、疯狂、赎罪。他控制拥有这些别号的最强使魔"

## 五、物品 / 道具 / 武器
- 名称：书籍（奢侈品）
- 说明：在该世界属于昂贵物品。普通书籍约需1枚金币，锁在专柜中的珍贵书籍平均8枚金币、最高达20枚金币。
  - 《植物辞典》：标价7枚金币。
  - 《希格的召唤魔术》：标价10枚金币。
  - 《阿斯拉王宫宫廷仪式》：全店最贵书籍（约20枚金币级别）。
  - 《佩尔基乌斯的传说》：记载甲龙王与拉普拉斯决战始末的史实书籍。
- 原文依据："书架共有两个……一本书大概是一枚金币上下。剩下的空间则是使用上锁的陈列柜来摆放书籍。这些书的平均价格是八枚金币，最贵的是二十枚金币。"、"「植物辞典，七枚金币……」是塞妮丝在我五岁生日时送我的书。"、"虽然我很想看看《希格的召唤魔术》，但是要十枚金币。"、"顺便说一下，最贵的书是《阿斯拉王宫宫廷仪式》"、"《佩尔基乌斯的传说》。我还以为那一定是童话呢，看样子似乎是史实。"

- 名称：生活/违禁道具
- 说明：
  - 媚药：街市可疑摊位标价10枚金币。
  - 小装饰品：在靠近贵族区的高级摊位售价5枚金币，在平民摊位售价4枚金币5枚银币。
- 原文依据："媚药是十枚金币。"、"「在刚刚那摊位上卖五枚金币的东西，在这里却只卖四枚金币加五枚银币呢。」"

- 名称：货币体系与薪资物价
- 说明：
  - 货币单位包括金币、银币、大铜币。
  - 购买力参考：鲁迪乌斯主观推算一枚金币约相当于十万日元（《植物辞典》折合约七十万日元）。
  - 薪资水平：鲁迪乌斯（无资历家教）月薪2枚银币加魔法大学学费；无技能新人（如艾莉丝打工）极限月薪1枚银币；基列奴（剑王兼护卫）月薪2枚金币。
- 原文依据："赚个一枚大铜币当情报费吧。"、"如果假设一枚金币相当于十万日币，这本书可要价七十万啊！"、"「你知道教导你可以让我每个月拿到多少钱吗？」「……差不多金币五枚吧？」「是银币两枚。」"、"「可是基列奴说她是拿两枚金币……！」"、"「大小姐不会魔术也不会剑术，再加上没有实际成绩。就算薪水的价钱给得再好，一枚银币也已经是最大极限了吧。」"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：约四百年前发生的史诗战役。魔神拉普拉斯为敌对首脑，甲龙王佩尔基乌斯率领十二使魔驾驶空中要塞Chaos Breaker与拉普拉斯展开决战。因力量尚欠一步无法彻底消灭拉普拉斯，最终以将其“封印”告终。
- 原文依据："佩尔基乌斯就是打倒魔神拉普拉斯的三英雄之一！……在拉普拉斯战役中，他的实力也充分发挥。……他控制拥有这些别号的最强使魔，让古老的空中要塞「Chaos Breaker」复活，和拉普拉斯展开决战。然而，他的力量还是差了一步，无法完全消灭拉普拉斯，最后只能以封印的结果告终。"

- 事件名：甲龙历改元
- 内容：在拉普拉斯战役终结时，阿斯拉王国为颂扬甲龙王佩尔基乌斯的伟大功绩，宣布确立新的年号为“甲龙历”；当前故事时间为甲龙历414年。
- 原文依据："阿斯拉王国为了颂扬他的功绩，在战争终结的同时也宣布了新的年号。就是现在的「甲龙历」。（顺便一提，现在是甲龙历四一四年。）"

- 事件名：龙神同盟与五龙将传说
- 内容：年轻的龙神乌尔佩曾带领未成名的佩尔基乌斯现身冒险者公会，并与北神卡尔曼、双帝米格斯、格米斯并肩作战，佩尔基乌斯由此继承了古老传说中“五龙将”之一“甲龙”的名号。
- 原文依据："当时还年轻也尚未出名的龙神乌尔佩带着他来到冒险者公会……这就是最古老的纪录。佩尔基乌斯很快就展现出自己的实力，和龙神乌尔佩、北神卡尔曼以及双帝米格斯、格米斯等人组成队伍，打败了所有敌人。或许是因为他就像是乌尔佩的小弟，不知不觉间，人们都以古老传说中的龙神属下「五龙将」名号之一的「甲龙」来称呼佩尔基乌斯。"

## 七、社会规则 / 习俗 / 文化
- 内容：【历法与休假】世界有月、日的纪年历法，但没有“星期/周”的概念，一年中有数次特定公休日，没有规律性的“星期日/周末”。鲁迪乌斯因习惯与“七”的吉利寓意，在宅邸开创了“每七天轮休一天”的教学休假制。
- 原文依据："顺道一提，这世界也有历法，有几月几日的概念。不过，并没有「一星期」的用法。一年中似乎有好几次休息日，但是没有所谓的「星期日」。使用「七」这数字的原因，是因为对我来说比较好记。而且不知道为什么，在这个世界里，七这个数字似乎很特别。被视为吉利的数字"

- 内容：【作息与计时方式】社会缺乏时钟等精细计时工具，日常生活与授课时间依靠早饭、午饭、点心、晚饭等用餐节点来粗略划分早、中、下、傍晚时段。
- 原文依据："由于没有时钟，所以并不是每堂课各上几小时，而是以用餐和点心时间来分为早上中午下午傍晚时段，每天只上其中三个科目。早饭→上课→午饭→上课→点心→上课→晚饭→自由时间。"

- 内容：【贵族精英教育科目】贵族千金的核心教育课程通常固定为六大科目：读写、算术、魔术、历史、剑术、礼仪规矩。
- 原文依据："艾莉丝目前学习的科目包括读写、算术、魔术、历史、剑术、礼仪规矩这六项。"

- 内容：【家庭教师契约规则】家庭教师采用固定月薪制，即使个别课程休假或授课次数减少，薪水亦不缩水；遇突发情况教师间可协商代课。
- 原文依据："艾德娜介意的重点，是「薪水会不会因为上课次数减少而跟着减少」的问题。……而且原本就采取月薪制度，就算连一堂课都没上还是可以拿到钱。"、"要是有空档，可以由我代为授课。所以，如果您想要长期休假也没有问题。"

- 内容：【贵族千金的安全与金钱认知】大贵族千金严禁单独外出，必须由专职护卫寸步不离跟随以防绑架；且贵族子嗣通常无零用钱，想要物品皆由长辈直接代买，普遍缺乏对金钱价值与有限预算的概念。
- 原文依据："「奸诈！我从来不曾一个人外出！」「因为，大小姐要是一个人外出就会被绑架啊。」"、"「基列奴也会一起去吧？」「嗯，我的任务是大小姐的护卫。」"、"「要……要不然我也可以买一本送你！」「讲得这么容易……艾莉丝你有钱吗？」「祖父大人会帮忙出钱！」……虽说极限，但艾莉丝其实连零用钱都没有。"

- 内容：【商业交易道德】在集市中利用不同摊位差价进行当场倒买倒卖（转卖）被视为“不受肯定的投机行为”；但向店家透露同行售价收取“情报费”则是可行的商业做法。
- 原文依据："「我说少爷，那样叫作转卖，不是什么受肯定的行为，千万不可以做喔。」「我当然不会那样做。如果真要行动，大概只会去告诉对面摊位说这里卖四枚金币，然后赚个一枚大铜币当情报费吧。」"

## 九、角色认知 vs 客观事实
- 角色以为：
  1. 艾莉丝以为甲龙王佩尔基乌斯“打倒（击杀）”了魔神拉普拉斯。
  2. 鲁迪乌斯原以为《佩尔基乌斯的传说》是编造的童话故事。
  3. 鲁迪乌斯怀疑四百年过去佩尔基乌斯是否还活着，亦或空中要塞已无主自巡 [存疑]。
- 原文是否暗示另有真相：
  1. 是。史书《佩尔基乌斯的传说》明确记载佩尔基乌斯力量差了一步，无法彻底消灭拉普拉斯，最终战果是“封印”。
  2. 是。空中要塞真实悬浮于天际，佩尔基乌斯为真实史实人物，阿斯拉王国的甲龙历纪年正是为此确立。
  3. 不明。书中记载佩尔基乌斯操纵要塞在空中巡回，但对其400年后是否存活未作确凿结论。
- 原文依据："「佩尔基乌斯就是打倒魔神拉普拉斯的三英雄之一！」" vs "然而，他的力量还是差了一步，无法完全消灭拉普拉斯，最后只能以封印的结果告终。"、"《佩尔基乌斯的传说》。我还以为那一定是童话呢，看样子似乎是史实。"、"是说，都已经四百年了……这个人真的还活着吗？应该不是没有主人的城堡自己到处乱晃吧？"
