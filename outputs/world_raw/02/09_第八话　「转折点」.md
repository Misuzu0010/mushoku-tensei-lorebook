# 第八话　「转折点」 世界设定提取

## 一、地理与场所
- 名称：西隆王宫
  - 内容：西隆王国的权力核心王宫，位于阿斯拉王国的东方，洛琪希曾在此担任限定宫廷魔术师与第七王子的家庭教师。西隆王国的国家体量远小于阿斯拉王国（阿斯拉王国国土约为西隆王国的十倍）。
  - 原文依据："西隆王宫。洛琪希・米格路迪亚望着窗外皱起眉头。"、"「那方向是东边……是阿斯拉王国吗？……」"、"「阿斯拉是比西隆大十倍的国家。」"

- 名称：赤龙山脉
  - 内容：栖息着不可胜数凶猛赤龙的险峻山脉，赤龙在中央大陆被视为绝对的强者，但当代龙神奥斯帝德可在此自由穿行，并能一击秒杀冒犯的赤龙。
  - 原文依据："◆在赤龙山脉◆……踏过刚刚才一击解决的赤龙尸体。周围虽然有数量多到数不清的赤龙在徘徊，但没有任何一只对他出手。"、"赤龙在中央大陆是绝对的强者。"

- 名称：空中要塞
  - 内容：由甲龙王佩尔基乌斯在数百年前以类似超大规模召唤魔术创造的浮空城塞。佩尔基乌斯与其十二位仆从使魔长年驻留于要塞王座之上，居高临下监视地面动静，以防宿敌魔神拉普拉斯解开封印复活。
  - 原文依据："◆在空中要塞◆三大英雄之一，「甲龙王」佩尔基乌斯俯视北方天空。……「和我创造出空中要塞时很类似。」……今天他依然坐在空中要塞的王座上，率领十二名仆人。继续监视地上。他的目的只有一个。要在憎恨的仇人，魔神拉普拉斯复活后立刻打倒对方。"

- 名称：剑之圣地
  - 内容：当代剑神加尔・法利昂传授剑术、指导其两位剑帝爱徒修炼对决的剑神流发源圣地。
  - 原文依据："◆在剑之圣地◆「剑神」加尔・法利昂抬头望向南方天空。"

- 名称：要塞都市罗亚郊外山丘
  - 内容：要塞都市罗亚外围的高地平原，鲁迪乌斯、艾莉丝与基列奴在此测试新魔杖“傲慢水龙王”并准备展示圣级水魔术。灾难爆发时，被自罗亚方向扩散蔓延而来的光之洪流完全吞噬抹消。
  - 原文依据："我来到要塞都市罗亚郊外的山丘。为了实现生日那天讲好的承诺，要让基列奴看看圣级水魔术。"

- 名称：菲托亚领地（全境物理消灭）
  - 内容：罗亚上空产生褐色、黑色、紫色、黄色交织的魔力漩涡异变后，从白色天空降下一道直通地面的光柱，随后暴涨为如海啸般的光之洪流，吞没并抹消了城镇、城墙、宅邸与草木，使整个菲托亚领地在物理上彻底消灭。
  - 原文依据："当那道光接触地面的瞬间──我看到那道光以非常惊人的速度开始膨胀，化为光之洪流吞没所有事物……也看到那道光让宅邸消失，让城镇消失，让城墙消失，吞噬着花草树木并步步进逼。……那一天，菲托亚领地消灭了。"

## 二、组织与势力
- 名称：西隆王室
  - 内容：西隆王国的最高统治王室：
    - 第七王子帕库斯・西隆：15岁，王位继承权极低且缺乏实权，性格乖戾淫靡，曾强占数名女仆并以亲友为人质胁迫；对身材幼小的洛琪希怀有异常执念；在洛琪希击退其袭击离去后向国王诬告洛琪希，反遭西隆国王严厉惩戒。
    - 西隆国王：西隆王国的君主，重视高阶魔法人才，因第七王子未能拉拢留住“水王级魔术师洛琪希・米格路迪亚”而对其严厉责罚。
  - 原文依据："西隆第七王子帕库斯・西隆，是今年十五岁的调皮小鬼。……充其量只是第七王子。王位继承权很低，也几乎不具备什么权限。"、"据说国王反而斥责无法拉拢「水王级魔术师洛琪希・米格路迪亚」投入自国的第七王子，并且处以严厉惩罚。"

- 名称：限定宫廷魔术师（西隆王国）
- 内容：西隆王国的特约宫廷级职务契约。契约明文规定魔术教师拥有高度自主酌情处置权，不必无条件服从王子的无理指令。
- 原文依据："因为和国家订下的契约中有明记，即使王子耍任性，教师也可以自行酌情判断。……如果只看拥有的权利，身为限定宫廷魔术师的洛琪希甚至更了不起。"

- 名称：佩尔基乌斯与十二使魔
  - 内容：甲龙王佩尔基乌斯麾下的十二位侍从仆役。已知成员包括佩戴白乌鸦面具、生有黑色羽翼的天族女性，以及佩戴黄色狐狸面具的金发使魔“光辉的阿尔曼菲”。其长年执行监视地上魔族与准备诛杀魔神拉普拉斯的使命。
  - 原文依据："今天他依然坐在空中要塞的王座上，率领十二名仆人。"、"身边那个戴着白乌鸦面具，拥有黑色羽翼的天族女性低声说道。"、"阿尔曼菲……佩尔基乌斯的十二使魔之一，光辉的阿尔曼菲。"

- 名称：阿斯拉四大世袭军人领主
  - 内容：阿斯拉王国的诺托斯、伯雷亚斯、艾乌洛斯、泽费洛斯四大家族，在阿斯拉王国一旦爆发战争时代代由军人率先领兵出战，在国际上享有崇高威望，出访他国重大仪式亦受极高规格礼遇。
  - 原文依据："阿斯拉王国的诺托斯、伯雷亚斯、艾乌洛斯、泽费洛斯这四大地方领主很有名。是阿斯拉王国一旦发生战争，就会率先挺身而出的存在，代代都由军人担任。西隆王国举行仪式时，即使这些贵族来访也是很正常的事情。"

- 名称：德路迪亚族
  - 内容：基列奴所属的兽族大部族（基列奴全名基列奴・泰德路迪亚），其部族名誉在异世界具有极高的信誉效力与誓言约束力。
  - 原文依据："「我以师父剑神加尔・法利昂与德路迪亚族的名誉起誓！」「泰德路迪亚……好吧，如果你们不是真的无罪，佩尔基乌斯大人将会再做出判决。」"

## 三、力量体系 / 魔法 / 技能
- 名称：水王级魔术师位阶
  - 规则：水系统魔术的高阶位阶（高于水圣级、次于水帝级）。洛琪希已被西隆王国及世间官方确认为水王级魔术师。
  - 原文依据："据说国王反而斥责无法拉拢「水王级魔术师洛琪希・米格路迪亚」投入自国的第七王子……"

- 名称：火焰结界魔术『Burning Place』
  - 规则：洛琪希使用的火系统防御与反击魔术。能在自身周围展开火焰结界将贴身偷袭者震飞弹开。咏唱咒文为：“爆焰缠绕我身……『Burning Place』！”。
  - 原文依据："「爆焰缠绕我身……『Burning Place』！」洛琪希让身上出现火焰结界，把背后的人物弹飞出去。"

- 名称：省略咏唱 / 缩短咏唱技巧
  - 规则：介于完整咏唱与无咏唱之间的魔术修习技巧。通过精炼大幅缩减咒文字数以提升施法速度；但仍需发声驱动，完全不发声的无咏唱施法对寻常魔术师而言极难习得。
  - 原文依据："虽然还无法像鲁迪乌斯那样完全不咏唱，但过了这五年，她已经能让咏唱缩短不少。听说鲁迪乌斯也有让自己的徒弟练习无咏唱，所以自己也试着开始练习省略咏唱，不过这并不是简单就能办到的事情。"

- 名称：剑神流剑圣技「光之太刀」
  - 规则：剑神流标志性的必杀奥义。将基础拔剑与挥斩推升至极致，登峰造极时剑锋速度可达光速，出招瞬间无法以肉眼辨识捕捉，是剑神流雄霸最强流派的根基绝技。
  - 原文依据："剑神流──剑圣技「光之太刀」。据说如果能练到登峰造极，剑锋就会到达光速的剑神流奥义。基列奴告诉我，就是因为剑神流有这个剑技，所以才能成为最强的剑术流派。"

- 名称：魔眼
  - 规则：具备特异视觉感知与感应能力的特殊眼瞳：
    - 基列奴的深绿魔眼：长年以眼罩遮蔽，摘下后能直视周围环境中魔力的流动轨迹与浓度分布。
    - 奇希莉卡的多元魔眼：魔界大帝别名“魔眼的魔帝”，一人独具十种以上魔眼，具万里透视及识破魔力之能，但对高等级封闭结界存在视线局限。
  - 原文依据："基列奴默默拿下眼罩。眼罩下方出现一只深绿色的眼睛。原来她不是只剩下一边眼睛啊。……那只眼睛能看得到魔力吗？过了三年我才知道基列奴的真正能力……魔眼。"、"魔界大帝别名是「魔眼的魔帝」。她拥有超过十种的魔眼，只要看一眼，就能知道有什么。即使相隔再远，也依旧一目了然。……奇希莉卡的魔眼并非万能……居然看不到。是不是架起了结界？"

- 名称：傲慢水龙王实际属性倍率
  - 规则：
    - 水系统魔术：增幅约5倍（威力提升至5倍或魔力消耗减至五分之一）。
    - 土系统魔术、风系统魔术：各增幅约3倍。
    - 火系统魔术：增幅约2倍。
    - 短板：由于各系魔术增幅倍率差异显著，运用其施展多系复合/混合魔术时平衡调整极为不易。
  - 原文依据："测试约三十分钟后，我明白在水魔术方面大概可以获得五倍左右的效果。……之后我又测试了一阵子，确定火魔术是两倍，土和风魔术各自都会变成三倍。要使用这根魔杖来混合魔术似乎不是易事。"

- 名称：菲托亚领地光之洪流（魔力失控/超大规模召唤现象）
  - 规则：天空先显现褐色、黑色、紫色、黄色交织的大理石状魔力漩涡；其后天际降下一道纯白光柱，触地后呈海啸般暴涨扩散，物理性吞灭所过之处一切物质与生命（伴随将人拉入未知维度的空间牵引感）。此光芒与魔法大学及佩尔基乌斯创造空中要塞时的召唤魔法光极其吻合。
  - 原文依据："天空的颜色很奇怪。褐色、黑色、紫色、黄色。……和召唤魔法的光芒很像。"、"「和我创造出空中要塞时很类似。」"、"当那道光接触地面的瞬间──我看到那道光以非常惊人的速度开始膨胀，化为光之洪流吞没所有事物……也看到那道光让宅邸消失，让城镇消失，让城墙消失……下一瞬间，纯白的光芒支配了附近一带。在自己似乎被拖向某处，但不确定是地面还是天空的感觉中，我失去意识。"

## 四、种族 / 生物
- 名称：龙神奥斯帝德
  - 特征：当代龙神称号持有者，被赤龙族及世人公认为跳脱世界常理的传说中世界最强男子。赤龙群体对其极其敬畏顺从，轻举妄动的年轻赤龙会被其瞬间击成肉块。
  - 原文依据："「龙神」奥斯帝德抬头望向西方天空。……踏过刚刚才一击解决的赤龙尸体。周围虽然有数量多到数不清的赤龙在徘徊，但没有任何一只对他出手。……那是龙神。跳脱世界常理的存在。是绝对不能与之为敌的对象。……那是传说中世界最强的男子。"

- 名称：赤龙（智力与社会性特征补充）
  - 特征：中央大陆的绝对霸主级魔兽，不仅战力凶悍，且具备极高智力，通晓弱肉强食与避险自保。在龙神经过时绝不贸然进攻，全数滞留空中目送以保全性命。
  - 原文依据："赤龙在中央大陆是绝对的强者。然而，并非仅限于战斗能力。正因为赤龙很聪明，所以才是强者。赤龙们很明白。那是传说中世界最强的男子。是无论多少只赤龙联手都无法打赢的对手。"

- 名称：光之精灵（光辉的阿尔曼菲）
  - 特征：执掌光的精灵，佩尔基乌斯十二使魔之一。外观为戴黄狐面具、穿白色立领制服的金发男子，手持双刃匕首；能以光速移动，凡目力所能辨识之处皆可瞬间传送抵达。肉身反应能避开剑圣技光之太刀，文献记载常规剑刃无法伤及其身。
  - 原文依据："「……光辉的阿尔曼菲，这就是我的名字。」……我记得光辉的阿尔曼菲是职掌光的精灵。书里面有写到，如果是能以肉眼辨识的部分，无论距离多遥远也可以瞬间移动过去。……正如字面所示，以光速移动。"

- 名称：天族（佩尔基乌斯侍从）
  - 特征：佩尔基乌斯身边的侍从之一，生有黑色羽翼，佩戴白乌鸦面具。
  - 原文依据："身边那个戴着白乌鸦面具，拥有黑色羽翼的天族女性低声说道。"

## 五、物品 / 道具 / 武器
- 名称：剑神七剑之一・名刀「平宗」
  - 说明：剑神流流派传承的七柄名剑之一，剑身刻有刀铭。现由剑神流剑王基列奴・泰德路迪亚佩戴，是证实其剑王身份的核心凭证。
  - 原文依据："「看吧！这是剑神七剑之一的名刀『平宗』！即使看到了这把剑的名字，你也无法相信吗！」依然握着剑的基列奴把手往前伸，让阿尔曼菲看清楚。"

- 名称：双刃匕首（光辉的阿尔曼菲）
  - 说明：光辉的阿尔曼菲配备的大型双刃匕首，用于配合光速瞬间突袭与格挡。
  - 原文依据："右手握着一把大型的双刃匕首。就是那个，扫过我头上的东西就是那玩意儿。"

## 六、历史 / 传说 / 事件
- 事件名：佩尔基乌斯创造空中要塞
  - 内容：四百年前拉普拉斯战役时期，甲龙王佩尔基乌斯曾以极大规模的召唤魔法光芒在世间创造出浮空的空中要塞。
  - 原文依据："「和我创造出空中要塞时很类似。」佩尔基乌斯继续前进。今天他依然坐在空中要塞的王座上，率领十二名仆人。"

- 事件名：魔界大帝三百年复活与隐退
  - 内容：魔界大帝奇希莉卡在三百年前死亡后再次复活，但因世界大体处于和平状态，并未掀起动乱，拜访旧友亦被劝阻安分，三百年来无所事事地四处流浪。
  - 原文依据："「复活三百年来，魔界大帝安分得让人觉得不对劲。」"、"在复活的那瞬间，她大喊……但是却没有人在场。……之后，一直没有人愿意理睬她。奇希莉卡前去拜访以前的友人，但对方却说现在很和平，要她安分一点。"

- 事件名：菲托亚领地灾害爆发（领地消灭事件）
  - 内容：罗亚上空出现巨大魔力漩涡，光辉的阿尔曼菲奉佩尔基乌斯之命前来调查并险些误杀鲁迪乌斯；随后一道通天光柱触地并爆发毁灭性光之海啸，瞬间抹消整片菲托亚领地的一切地貌与城池，鲁迪乌斯、艾莉丝、基列奴等人被卷入未知光芒中。
  - 原文依据："有错的人是在这种地方做出可疑行为的你们。……有道光从被染成白色的天空伸向地面。当那道光接触地面的瞬间──我看到那道光以非常惊人的速度开始膨胀，化为光之洪流吞没所有事物……那一天，菲托亚领地消灭了。"

## 七、社会规则 / 习俗 / 文化
- 内容：**武人誓约的至高约束力**。在异世界强者与武人阶层中，以师门宗师（如剑神）与部族名誉立下的誓言具有极高的公信力与裁断效力，足以使神话级使魔立时罢手并认可其清白。
  - 原文依据："「你敢向师父和一族发誓吗？」「我以师父剑神加尔・法利昂与德路迪亚族的名誉起誓！」「泰德路迪亚……好吧，如果你们不是真的无罪，佩尔基乌斯大人将会再做出判决。」"

- 内容：**剑神流欲望至上哲学**。剑神流宗师加尔・法利昂信奉纯粹力量与为所欲为，认为剑术不需要虚浮名声，决死战场上存活并攀登顶峰的关键在于永无止境的原始欲望与任性。
  - 原文依据："剑神觉得这两个家伙还是老样子，没什么品味。虽然他们被称为剑帝而得意忘形，但充其量只有这点程度。无聊，真无聊！剑术不需要名声。只要能变强就够了。……只要变强就可以为所欲为。为所欲为就是所谓的活着。……在决死的战场上活下去的诀窍，就是永无止尽的欲望。"

## 九、角色认知 vs 客观事实
- 角色以为：光辉的阿尔曼菲认为天空中的巨大魔力异变是罗亚郊外行为可疑的鲁迪乌斯施法所致，杀死鲁迪乌斯或可阻止异变；洛琪希亦曾猜测是否是鲁迪乌斯在施展召唤魔术。
  - 原文是否暗示另有真相：是。
  - 原文依据：鲁迪乌斯仅仅是依照承诺向基列奴展示圣级水魔术并测试新魔杖，异变与鲁迪乌斯完全无关，即使基列奴证实清白后阿尔曼菲停手，大范围的毁灭性光之洪流依旧瞬间暴涨降临吞噬领地。原文依据："「女人，闪开。只要杀了那小鬼，说不定能让异变停止。」……「我是剑王基列奴・泰德路迪亚！那东西和我们无关，快退下！」……「既然犯人不是你们，那就算了。」"

- 角色以为：鲁迪乌斯一直以为基列奴戴眼罩是因为过去战斗受创只剩下一只眼睛。
  - 原文是否暗示另有真相：是。
  - 原文依据：基列奴眼罩下方实际拥有一只完好的深绿色魔眼，能够清晰观测魔力的浓度与流动。原文依据："基列奴默默拿下眼罩。眼罩下方出现一只深绿色的眼睛。原来她不是只剩下一边眼睛啊。……那只眼睛能看得到魔力吗？过了三年我才知道基列奴的真正能力……魔眼。"

- 角色以为：佩尔基乌斯推测异变光芒可能是复活三百年来异常安分的魔界大帝试图解开魔神拉普拉斯的封印。
  - 原文是否暗示另有真相：是（误判）。
  - 原文依据：魔大陆上的奇希莉卡此时正因无人理睬而漫无目的闲晃踢石头，她本人亦对西方的魔力异变一头雾水，甚至因看不透发生何事而发牢骚。原文依据："「该不会是魔界大帝试图解开拉普拉斯的封印？」……奇希莉卡踢着地上的石头，抬头望向形成魔力漩涡的西方天空。……「什么嘛……居然看不到。是不是架起了结界？做出那么大规模的勾当却不露脸……」"

- 角色以为：帕库斯・西隆以为洛琪希有秘密恋人，且凭借自己的第七王子权威与禁卫队可以肆意构陷处死对方或越境暗杀，以此强逼洛琪希屈服。
  - 原文是否暗示另有真相：是。
  - 原文依据：信件来自其弟子鲁迪乌斯；鲁迪身处十倍于西隆的大国阿斯拉且受顶级领主伯雷亚斯庇护，宅邸有剑王基列奴镇守，禁卫队根本无法跨境或渗透；且帕库斯事后被西隆国王严加惩处。原文依据："「阿斯拉是比西隆大十倍的国家。……要以子虚乌有的罪名把阿斯拉上级贵族的子弟送上处刑台，想必需要非常高度的政治力和谋略。凭殿下的权力实在不可能办到。」……据说国王反而斥责无法拉拢「水王级魔术师洛琪希・米格路迪亚」投入自国的第七王子，并且处以严厉惩罚。"
