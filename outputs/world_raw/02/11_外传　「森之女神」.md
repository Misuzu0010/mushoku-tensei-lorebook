# 外传　「森之女神」 世界设定提取

## 一、地理与场所
- 名称：纷争地带
  - 内容：从阿斯拉王国越过山脉往正东方，位于中央大陆中心的战乱区域。由许多小国构成，各小国为了争夺霸权互相争斗，频繁建国又灭亡，因此被称为纷争地带。马尔齐渊佣兵国位于纷争地带偏北区域。
  - 原文依据："从阿斯拉王国越过山脉往正东方。位于中央大陆中心的这个区域由许多小国构成，而这些小国为了取得这一带的霸权总是互相争斗。于是，人们把总是有小国建国又灭亡的这个区域称为纷争地带。"、"毕格告诉基列奴，这里是在中央大陆南部中位于偏北区域的「纷争地带」，而且在纷争地袋中也是位于北方的马尔齐渊佣兵国的森林。"

- 名称：马尔齐渊佣兵国
  - 内容：纷争地带的小国之一。甲龙历四一五年由大佣兵马尔齐渊建立（甲龙历四一七年时建国刚满两年）。以派遣佣兵作为经济支柱与生计的战斗国家，一视同仁地向各方派遣支援。曾遭迪库特王国与布罗兹帝国联合进攻濒临灭绝，在大盆地决战中因基列奴介入而逆转胜利。战后存续百年，国内独有崇拜森之女神列奴的习俗。
  - 原文依据："位于纷争地带的小国之一，马尔齐渊佣兵国。由某个大佣兵确立的这个国家，是靠着把佣兵派往附近国家来作为生计的战斗国家。"、"甲龙历四一七年。在阿斯拉王国发生转移事件的这一年，马尔齐渊佣兵国是佣兵王马尔齐渊宣布建国后才只过了两年的新兴国家。"、"之后又过了一百年，森之女神列奴被视为马尔齐渊的守护神并受到崇拜"

- 名称：迪库特王国
  - 内容：邻接马尔齐渊佣兵国的国家之一。因戒备马尔齐渊佣兵国的实力而与布罗兹帝国结盟进攻马尔齐渊。其国王生性胆小，在大盆地决战中因营帐背对厄禁森林，遭奇袭后十秒内被基列奴斩杀。
  - 原文依据："让邻接马尔齐渊佣兵国的两个国家，迪库特王国和布罗兹帝国都产生戒心并暗中筹划，在外交上失败后，就面临同时遭到两国提出宣战布告的发展。"、"迪库特王死在基列奴的剑下。"

- 名称：布罗兹帝国
  - 内容：邻接马尔齐渊佣兵国的敌对国家之一。与迪库特王国结成脆弱同盟进攻马尔齐渊。拥有皇帝精锐禁卫队。皇帝巡视阵地时遭魔物擦伤，派禁卫队入林猎杀魔物反遭全灭；决战中皇帝被基列奴斩首。
  - 原文依据："让邻接马尔齐渊佣兵国的两个国家，迪库特王国和布罗兹帝国都产生戒心并暗中筹划"、"虽然毕格他并不知道，但他们眼前的敌人其实是负责保护布罗兹皇帝的禁卫队。"、"在这个黑胡男……布罗兹皇帝的脑袋被砍掉的那瞬间。"

- 名称：马尔齐渊决战遗迹（大盆地）
  - 内容：马尔齐渊存亡大决战发生地，后世称为「马尔齐渊决战遗迹」的大盆地。两侧是被魔物森林夹峙的险要地形，严重限制军队通行，是战后控制首都周边支配权的最重要枢纽。
  - 原文依据："而最后一场决战，就在后世称为「马尔齐渊决战遗迹」的大盆地上演。面对两国联合军的马尔齐渊佣兵国集结战力，在大盆地上布阵。至今为止两国都是分别侵略，但身为要点的盆地两侧是会有魔物出没的森林，因此通行受到极为严格的限制。所以他们不得不会合。此外也因为同样原因，这个盆地是最重要的地点。在马尔齐渊佣兵国灭亡后，为了获得首都附近的支配权，占领这盆地正是第一要务。"

- 名称：厄禁森林
  - 内容：位于大盆地侧面的险恶森林，魔物大量出没。自古以来这附近的统治者就禁止人民通行，连樵夫都无法进入。栖息着红叶虎以及被称为森林主人的五公尺巨蜥冈雷特蜥蜴。基列奴转移后的落地森林。
  - 原文依据："被称为厄禁森林的这里有大量魔物出没。甚至危险到自古以来，这附近一带的统治者就已经禁止人民通行。附近的人都异口同声地表示，连樵夫都无法进入厄禁森林。"

- 名称：卢德敏 / 阿尔兹堡垒
  - 内容：马尔齐渊佣兵参与过的激烈战役要塞。卢德敏防卫战中补给曾被截断；阿尔兹堡垒东门曾遭遇侧面袭击险遭全灭。
  - 原文依据："「嘿嘿，你看。这是在卢德敏防卫战里受的伤。」……「阿尔兹堡垒的东门，那里根本就是地狱……只差一点，我就会失去这心爱的右手。」……「卢德敏防卫战也差不多吧？我听说那边的补给被截断，没钱给佣兵吃饭。」"

## 二、组织与势力
- 名称：马尔齐渊佣兵团 / 部队编制
  - 内容：由佣兵王马尔齐渊统领的精锐部队，设有第三部队等编制。佣兵作战勇猛，号称士兵以一当千、指挥官冷静沉着、军师深谋远虑，在战场上是胜利与恐怖的象征。
  - 原文依据："马尔齐渊佣兵国一视同仁地支援每个国家。而且派出的佣兵们也是他国畏惧的对象。据说，士兵们能以一当千。据说，指挥官常保冷静沉着。据说，军师深谋远虑。只要开始战斗，一定会为同一阵营的势力带来胜利。在战场上，是胜利和恐怖的象徵。"、"马尔齐渊佣兵团，第三部队长毕格・马塞纳鲁率领十名部下在森林中前进。"

- 名称：布罗兹皇帝禁卫队
  - 内容：护卫布罗兹皇帝的精锐部队，由水神流圣级剑士（水圣）克莱因・帝诺鲁塔斯率领，全员皆为水神流或北神流中级以上剑士，训练极精良。
  - 原文依据："虽然毕格他并不知道，但他们眼前的敌人其实是负责保护布罗兹皇帝的禁卫队。"、"「你们应该知道吧，我是禁卫队长克莱因・帝诺鲁塔斯！水圣克莱因！还以为能打赢我吗！」"、"他们全都是水神或北神流的中级以上剑士。实力绝对不差。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑神流・光之太刀
  - 规则：剑神流的高阶极意剑技。出刀速度快如闪光，破坏力极其惊人，能一击斩断水圣防守反击的剑刃，并将铠甲、衣物、皮肉与骨骼一并横向腰斩。
  - 原文依据："克莱因是水圣。水神流是化解所有攻击，再使出必杀反击的流派。原本应该是这样……「居……居然是光之太刀……剑……剑神流吗……」接下野兽的剑之后，克莱因的剑断成两半。而且就像是还没有结束，克莱因的铠甲也出现一直线的裂痕，然后衣服、皮肤、肌肉、骨头全被斩断……最后，克莱因的上半身和下半身分开了。"

- 名称：兽族威慑吼叫
  - 规则：兽族在战斗中发出的特异吼声，具有直接威慑敌方精神、令对手身体与心理产生畏缩受制的效果。
  - 原文依据："野兽的动作快如闪光，吼声有让人萎缩的效果。没有人能跟得上野兽。"

- 名称：水神流特性
  - 规则：水神流的核心机制为化解对手的所有攻击，再伺机施展必杀的反击。然而在遭遇破坏力与速度凌驾其承受极限量级的攻击时，防守反击会被瞬间击穿瓦解。
  - 原文依据："克莱因是水圣。水神流是化解所有攻击，再使出必杀反击的流派。"

- 名称：剑神流致敬礼节
  - 规则：单膝跪下、头部向前探伸的姿态，是剑神流中向强敌与对手表达降伏与至高尊敬的传统动作。
  - 原文依据："毕格边说，边摆出向师父学来的剑神流致敬动作。跪下单膝把头往前伸的这个姿势，是在向对手表示降伏和尊敬。"

- 名称：魔术师在纷争地带的稀缺性
  - 规则：在纷争地带，魔术师属于极度贵重的人才，普通佣兵部队中极难配备能够施展治愈魔术的成员。
  - 原文依据："毕格本身是剑神流的上级剑士，但是这群人中没有能使用治愈魔术的成员……在这一带，魔术师是贵重的人才"

## 四、种族 / 生物
- 名称：兽族（狂化狂战士机制补充）
  - 特征：巧克力色皮肤，灰色头发，头顶竖起一对尖锐兽耳。在遭遇极限状态或激烈战斗时会陷入极度兴奋而丧失理智，沦为不分敌我屠戮周遭所有持械者的狂暴状态；若有熟识剑神流礼节之人单膝致敬并呼唤其尊名，可使其恢复清醒理智。
  - 原文依据："是拥有巧克力色皮肤，灰色头发，以及往上竖起的一对尖耳的兽族。"、"只是，一旦陷入极限状态就会失去理智，有时候还会不分敌我地全部攻击，所以受到大家的厌恶。"、"「您是剑王基列奴・泰德路迪亚大人吗？」这句话刚说出口──野兽就停止动作。过了一会儿之后，基列奴恢复正常理智。"

- 名称：冈雷特蜥蜴
  - 特征：A级魔物，被称为厄禁森林的主人。体长约五公尺的巨大鲜绿色蜥蜴，身躯强悍庞大，拥有将B级下层魔物重创的力量。
  - 原文依据："据说是只A级的魔物，巨大身躯长达五公尺的蜥蜴──冈雷特蜥蜴。虽然毕格不知道冈雷特蜥蜴是否真的存在，但如果是这只魔物，的确有可能将位于B级下层的红叶虎打成重伤。"、"那是鲜绿色的蜥蜴，体长恐怕有五公尺。然而原本很雄伟的身躯上已经伤痕累累，到处都在流血。"

- 名称：红叶虎
  - 特征：B级下层魔物，擅长潜伏于厄禁森林的草丛中偷袭猎物，被周边视为该森林最危险的凶恶魔物之一。
  - 原文依据："明明有提高警觉，他们却没能发现躲在草丛里的红叶虎。遭到袭击后，有一名部下被杀害。魔物已经遍体鳞伤，似乎在躲避什么东西的追杀。被视为这森林最恐怖魔物的红叶虎居然在躲避什么……"、"将位于B级下层的红叶虎打成重伤。"

## 五、物品 / 道具 / 武器
- 名称：基列奴的佩剑
  - 说明：薄刃单刃剑，剑身绽放着诡异的红色光芒，是威力惊人的知名名剑。
  - 原文依据："野兽手上拿着剑，那是一把单刃剑，薄薄剑身绽放出诡异的红色光芒。能看出应该是一把有名的名剑。"、"在巧克力肤色的女人使出的红色剑光之下"

- 名称：森之女神列奴浮雕坠子与红刃短剑
  - 说明：马尔齐渊佣兵随身配备的宗教护身道具。项链坠子是以木头雕刻的长有兽耳的女性侧脸浮雕，短剑剑刃则涂成鲜红色，用以模仿基列奴当年的外貌与佩剑，作为祈求胜利与保命的咒术圣物。
  - 原文依据："其中一名佣兵从怀中拿出一条项链，坠子是用木头雕刻而成的浮雕，图案则是一名拥有野兽耳朵的女性侧脸。看到那项链后，另一名佣兵拔出腰间的短剑。剑刃被涂料染成了红色。「那，来敬森之女神列奴一杯吧，乾杯！」"、"他在脖子上挂着刻有野兽侧脸的浮雕坠子，把自己佩剑的剑身涂成红色。「这是一种咒术。」"

## 六、历史 / 传说 / 事件
- 事件名：甲龙历纪年系统
  - 内容：世界通用的历史纪年历法，转移事件发生当年记为「甲龙历四一七年」，同年马尔齐渊佣兵国建国满两周年。
  - 原文依据："甲龙历四一七年。在阿斯拉王国发生转移事件的这一年，马尔齐渊佣兵国是佣兵王马尔齐渊宣布建国后才只过了两年的新兴国家。"

- 事件名：拉普拉斯战役与英雄传说
  - 内容：距今四百年前爆发拉普拉斯战役，大英雄「双帝米格斯・格米斯」战死沙场成为流传百世的英灵，其荣誉赴死事迹被后世佣兵传颂奉为楷模。
  - 原文依据："「请不必担心，我会成为将这场大战导向胜利的英灵，被人们持续传颂下去。和过去的大英雄『双帝米格斯・格米斯』一样，这不是很荣誉的事情吗？」毕格以四百年前在拉普拉斯战役中死去的英雄为例，主动扛下了这重大任务。"

- 事件名：马尔齐渊决战遗迹之战
  - 内容：甲龙历四一七年，马尔齐渊佣兵国遭遇迪库特王国与布罗兹帝国围攻濒临灭亡。毕格率敢死队潜入厄禁森林企图挑拨两国同盟，恰遇被魔力灾害转移至此的狂暴剑王基列奴。基列奴单枪匹马连斩布罗兹禁卫队长、迪库特国王与布罗兹皇帝，致使两国兵团互相残杀破裂，马尔齐渊佣兵国趁势全线反攻赢得决定性胜利并成功建国立国。
  - 原文依据："甲龙历四一七年。在阿斯拉王国发生转移事件的这一年……而最后一场决战，就在后世称为「马尔齐渊决战遗迹」的大盆地上演。"、"决战由马尔齐渊佣兵国获得胜利。"

- 事件名：森之女神列奴信仰起源
  - 内容：决战获胜后毕格晋升为救国大将军，佩戴兽耳木雕并涂红佩剑作为纪念救命女神的咒术，引发部下与国民效仿传播。「基列奴」之名在中央大陆南部因口音难读，经百年流传讹变发音为「列奴」，最终被神化确立为马尔齐渊独有的守护神「森之女神列奴」，而基列奴本人对此信仰毫无所知。
  - 原文依据："根据他的咒术和发言，人们创造出森之女神列奴。女神的名字是基列奴。但是「基列奴」在中央大陆南部是个有点难发音的名字。之后发音越来越不准，最后就被称为列奴。从森林中现身，拯救大将军的救国神「森之女神列奴」。之后又过了一百年，森之女神列奴被视为马尔齐渊的守护神并受到崇拜……当然，基列奴本人从来不曾知晓这个称呼。"

## 七、社会规则 / 习俗 / 文化
- 内容：马尔齐渊佣兵的饮酒祈祷仪式。每次战斗生还后，佣兵一手持兽耳木雕浮雕或红刃短剑，另一手举杯一饮而尽，向森之女神列奴敬酒以祈祷下次作战获胜并保命。
  - 原文依据："两人各自拿着项链和短剑，用另一只手举起酒杯，一口气喝乾。这就是他们的祈祷方式。"、"「那，来敬森之女神列奴一杯吧，乾杯！」「请保佑我们下次战斗也能获胜！乾杯！」"
- 内容：佣兵的名誉与国家认同。佣兵自幼为了金钱和生存而战，唯有骑士才会为名誉赴死；但在为了保卫自己唯一的归属与故乡时，佣兵亦会自视为国家骑士，甘愿以无名弃子的身份赴死换取祖国存续。
  - 原文依据："他在佣兵团里练习剑术，学习战术，只为了金钱和性命而活到现在。真没想到会在最后的最后，要为了名誉而战。（真像是哪里的骑士大人啊。）只有骑士会为了名誉而死。不过……毕格突然想到。（或许我是马尔齐渊佣兵国的骑士。）"
- 内容：纷争地带的地缘政治环境。小国频繁建立与覆灭，国家间勾心斗角，战时同盟脆弱不可信，各方均在算计决战后的利益分配，极易因突发奇袭而全面内讧火拼。
  - 原文依据："在这个纷争地带，总是有小国建国后又灭亡。人们打着只要有机会就能拥有自己国家的算盘，抱着要统一周遭这一带来建立一个大国的野心"、"直到打倒马尔齐渊佣兵国为止，两国之间似乎缔结了同盟，不过既然双方会在这场决战后为了争夺霸权而开战，那么这种同盟有跟没有一样。"

## 九、角色认知 vs 客观事实
- 角色以为：马尔齐渊佣兵相信「森之女神列奴」是真正的救国女神，当佣兵濒临死亡时就会现身相救。
  - 原文是否暗示另有真相：是（所谓森之女神列奴完全是基于剑王基列奴当年狂化杀敌、拯救毕格部队的真实历史被神化演变而来；基列奴的名字因南方发音困难讹变成“列奴”，基列奴本人也完全不知道自己成为了神明）。
  - 原文依据："所以马尔齐渊的佣兵们都相信当自己濒临死亡时，森之女神列奴就会从不知何处现身，拯救自己。"、"根据他的咒术和发言，人们创造出森之女神列奴。女神的名字是基列奴。但是「基列奴」在中央大陆南部是个有点难发音的名字。之后发音越来越不准，最后就被称为列奴。……当然，基列奴本人从来不曾知晓这个称呼。"

- 角色以为：布罗兹禁卫队长克莱因认为遭遇身着布罗兹铠甲的毕格小队是企图逃避战事的自军逃兵。
  - 原文是否暗示另有真相：是（毕格等人是马尔齐渊伪装成布罗兹军企图发动奇袭的敌国敢死队，而非逃兵）。
  - 原文依据："「是逃兵吗！可恶！」布罗兹帝国的队长判断突然出手的毕格等人是逃兵。虽然他弄错了，但就算弄错，要采取的行动还是不会改变。"

- 角色以为：迪库特王被从森林冲出的毕格部队奇袭时，因对方身穿布罗兹帝国铠甲，认定是同盟国布罗兹帝国背信突袭。
  - 原文是否暗示另有真相：是（实际为马尔齐渊敢死队借道厄禁森林制造的挑拨假象，但迪库特王在十秒内被基列奴斩杀，误会导致两国同盟彻底破裂反目）。
  - 原文依据："看到毕格等人从森林中冲出，迪库特王极为惊讶。再加上那身服装，让他认为是布罗兹帝国从森林中发动奇袭。迪库特王立刻叫来亲信，命令自军对布罗兹帝国发动攻击"

- 角色以为：布罗兹帝国军队看到持红剑的女人（基列奴）斩杀迪库特军、且身后跟着穿布罗兹铠甲的毕格，误以为她是自军的援军。
  - 原文是否暗示另有真相：是（基列奴仅是斩倒挡路之人，毕格亦是敌国士兵，随后基列奴直接斩落了布罗兹皇帝的首级）。
  - 原文依据："拿着红色长剑的陌生女人闯进战场的状况虽然让布罗兹帝国感到讶异，但看到她把迪库特王国士兵一一砍倒，加上负责保护后方的是身穿布罗兹帝国铠甲的毕格，因此误以为是援军。"、"在这个黑胡男……布罗兹皇帝的脑袋被砍掉的那瞬间。"

- 角色以为：基列奴回过神后，听闻自己身处纷争地带马尔齐渊佣兵国，认为“怎么可能”。
  - 原文是否暗示另有真相：是（基列奴确实通过魔力灾害转移被传送到了纷争地带）。
  - 原文依据："毕格告诉基列奴，这里是在中央大陆南部中位于偏北区域的「纷争地带」……「怎么可能。」基列奴并不相信。因为她不明白自己来到这种地方的理由。"
