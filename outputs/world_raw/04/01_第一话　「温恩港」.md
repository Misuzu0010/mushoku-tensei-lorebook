# 第一话　「温恩港」 世界设定提取

## 一、地理与场所
- 名称：温恩港
- 内容：魔大陆唯一的港都。城镇内地势起伏多坡道，从入口即可一眼看尽街景。建筑以魔大陆特色的土石造为主，但零星有自米里斯大陆进口木材建造的木造房舍。城镇角落设有造船厂。入口处摊位较少，越靠近港口的区域越具活力。港口外为广阔海洋，搭船渡海的目的地为米里斯神圣国领土。
- 原文依据："温恩港。这里是魔大陆唯一的港都。城镇内的地形有许多起伏坡道，从入口就能一眼看尽街景。虽然大部分都是符合魔大陆特色的土石造建筑，不过也可以零星看到一些木造房舍。大概是从米里斯大陆进口木材吧。城镇角落还有造船厂。或许因为是港都，入口附近没有多少摊位，反而是靠近港口的区域显得充满活力。"、"这个城镇虽然位于魔大陆，然而搭船后到达的目的地却是米里斯神圣国的领土。"

- 名称：温恩港外海域
- 内容：外海栖息着大量魔物，极度危险，不适宜下水游泳。
- 原文依据："「不，最好不要在这片海域游泳。」……「因为海里有很多魔物。」"

- 名称：迷宫 [概念]
- 内容：极度危险的探索地点，内部具有无法靠生物感应（眼睛/雷达）识破的物理或魔法陷阱。迷宫内部可产出高价值的魔力结晶与魔力附加品。
- 原文依据："「迷宫很危险，会出现靠我的眼睛也无法完全识破的陷阱。」瑞杰路德的眼睛虽然能够辨别生物，但是对迷宫产生的陷阱似乎不会有反应。"、"前往迷宫，取得魔力结晶和魔力附加品。虽然辛苦，不过或许能一口气就赚到足以前往对岸的金额。"

## 二、组织与势力
- 名称：冒险者公会（温恩港分部）
- 内容：聚集形形色色的冒险者，人族比例相对魔大陆腹地明显偏高。公会对冒险者私下的打架斗殴通常采取放任态度，甚至有职员会参与开赌。公会不插手涉及国家界限的出入境事务。
- 原文依据："温恩港的冒险者公会。里面挤满了形形色色的冒险者们。虽说是熟悉的景象，不过感觉人族似乎变多了。"、"顺便一提，冒险者之间的冲突似乎是家常便饭，公会方面并不太插手。甚至反而有那种会积极开赌的职员。"、"「这类问题请去询问关卡。」「关卡？」「因为搭船后会跨越国境。」"

- 名称：米里斯神圣国
- 内容：领土位于米里斯大陆，与魔大陆温恩港隔海相望。设立关卡严格管制来自魔大陆的入境人员与物资，并按人头与种族征收高昂通关税费。
- 原文依据："这个城镇虽然位于魔大陆，然而搭船后到达的目的地却是米里斯神圣国的领土。携带货物入境时要缴纳税金，入国时也必须支付金钱。"

- 名称：温恩港关卡
- 内容：负责管理从温恩港乘船跨国前往米里斯神圣国的出入境口岸机构。负责征收出入境人头费和货物税金，并在登船时逐一仔细调查种族；官员态度唯利是图，暗示只要肯支付大笔金钱连假冒种族也能放行通关。
- 原文依据："携带货物入境时要缴纳税金，入国时也必须支付金钱。"、"「你们就是那个『Dead End』吧？冒牌的斯佩路德族。搭船时会仔细调查种族，就算在这边打肿脸充胖子付了两百枚绿矿钱，也只是在浪费钱喔。」……「要是假冒别的种族会被罚款吗？」「……只要付出大把金钱就不会。」"

- 名称：冒险者队伍「Dead End」（死路）
- 内容：由鲁迪乌斯、艾莉丝、瑞杰路德三人组成的A级冒险者队伍。在魔大陆已具备极高知名度，被流传为「冒牌斯佩路德族」或「真货」，评价两极（「凶恶但本性不坏」）。三人各具外号：「狂犬艾莉丝」、「看门犬瑞杰路德」、「饲主鲁杰鲁德」（被传为最黑心、幕后专干坏事的主使者）。
- 原文依据："「光头和凶暴的红发小丫头……！你们几个难道是『Dead End』吗？」「『Dead End』是指那个斯佩路德族的……？」「白痴！是队伍名称！就是最近传闻中的那个冒牌货！」「不过我也听过他们是真货的传言。」……「你是说『狂犬艾莉丝』和『看门犬瑞杰路德』吧？」……「那，那个站在远处的矮子就是『饲主鲁杰鲁德』吗！」「我听说『饲主』是其中最黑心的家伙。」「是啊，据说他专门干一些坏事。」"

## 三、力量体系 / 魔法 / 技能
- 名称：斯佩路德族额头感觉器官
- 规则：额头中央镶嵌红宝石状的感觉器官，具有活体生物雷达功能，可感知周围数百公尺内的所有生物动向；但对非生物类的物理/机械陷阱无感应能力。
- 原文依据："瑞杰路德的额头上嵌着一颗看起来像是红宝石的感觉器官。这器官拥有活体雷达般的功能，似乎能够掌握数百公尺范围内的所有生物。"、"瑞杰路德的眼睛虽然能够辨别生物，但是对迷宫产生的陷阱似乎不会有反应。"

- 名称：航海推进魔术 [存疑]
- 规则：鲁迪乌斯推测帆船逆风航行可能是依靠魔术师施展气流魔术制造顺风来推动前进。
- 原文依据："不，既然是这世界，想必是利用靠魔术师制造顺风来前进之类的方式吧。"

## 四、种族 / 生物
- 名称：斯佩路德族
- 特征：魔族的一支，特征为翠绿发色与额头红宝石感觉器官。历史上被世人视为恐怖残暴的象征并饱受污名与排斥。在温恩港关卡乘船渡海至米里斯大陆时被要求缴纳高达两百枚绿矿钱的天价费用，被米里斯大陆防恐政策视为潜在危险分子（炸弹）。
- 原文依据："不过他其实是拥有翠绿发色的斯佩路德族。在这个世界里，拥有绿色头发的魔族被视为恐怖的象徵。"、"「斯佩路德族要绿矿钱两百枚。」……「我猜是防恐对策吧。例如是为了防止有人把斯佩路德族当成奴隶送到米里斯大陆，然后在那边作乱闹事。」"

- 名称：骑乘用蜥蜴
- 特征：魔大陆长途旅行常用的驯化骑乘爬行动物，到达港都后需寄放于马厩。
- 原文依据："刚到达此地，一名红发少女立刻跳下我们骑乘的蜥蜴往前跑。"、"我们决定投宿地点并把蜥蜴暂时交给马厩保管后，首先前往冒险者公会。"

- 名称：海洋魔物
- 特征：群居在魔大陆周边海域的大量魔物，极具攻击性，导致海域无法作为安全泳池使用。
- 原文依据："「因为海里有很多魔物。」"

## 五、物品 / 道具 / 武器
- 名称：米里斯大陆货币体系
- 说明：米里斯大陆流通的六种法定货币：王钞、将钞、金币、银币、大铜币、铜币。若以魔大陆基础货币「石钱」对标1日币折算：王钞=50,000石钱、将钞=10,000石钱、金币=5,000石钱、银币=1,000石钱、大铜币=100石钱、铜币=10石钱。米里斯大陆的任务报酬与物价水平约为魔大陆的10倍。
- 原文依据："米里斯大陆的货币分为六种：王钞、将钞、金币、银币、大铜币、铜币。如果把魔大陆最低价的货币「石钱」设定成一日币并进行比较，大概会是以下的感觉：王钞　五万 / 将钞　一万 / 金币　五千 / 银币　一千 / 大铜币　一百 / 铜币　十 / 在魔大陆上，B级委托的报酬大约是十五到二十枚屑铁钱，换算成石钱就是一百五到两百枚。至于米里斯大陆的B级工作，如果假设是大铜币十五枚，换算成石钱就是一千五百枚。相差十倍，所以当然是去米里斯赚钱比较有利。"

- 名称：魔大陆货币体系（铁钱、绿矿钱、屑铁钱、石钱）
- 说明：魔大陆流通货币。最低面额为石钱；屑铁钱1枚折合10石钱；另有铁钱与高价值的绿矿钱。人族出海需铁钱5枚，一般魔族约绿矿钱1~2枚，斯佩路德族则被索要绿矿钱200枚。
- 原文依据："在魔大陆上，B级委托的报酬大约是十五到二十枚屑铁钱，换算成石钱就是一百五到两百枚。"、"「人族是铁钱五枚……魔族是哪个种族？」「斯佩路德族。」……「斯佩路德族要绿矿钱两百枚。」"、"实际上，人族是铁钱五枚，其他魔族顶多也只要绿矿钱一枚或两枚。"

- 名称：魔杖「傲慢水龙王」
- 说明：装嵌大型色魔石，阿斯拉王国制造的顶级名品魔杖。艾莉丝赠予鲁迪乌斯的十岁生日礼物，估值极高，其价值被认为足以匹敌让斯佩路德族渡海的天文数字金额。
- 原文依据："那就是卖掉我的魔杖「傲慢水龙王」。这把杖是装着大型色魔石，由阿斯拉王国制造的珍品，应该能卖到足以让斯佩路德族渡海的价钱吧。不过，略过损失和利益不论，其实我尽可能不想卖掉这东西。毕竟这是艾莉丝特地送我的生日礼物，也一直谨慎使用至今。"

- 名称：魔力结晶 / 魔力附加品
- 说明：在地下迷宫探索中获取的高价值产物。魔力结晶售价极高，在通关关卡时亦具备作为大额硬通货或抵扣通关费用的效力。
- 原文依据："第二种方法是前往迷宫，取得魔力结晶和魔力附加品。虽然辛苦，不过或许能一口气就赚到足以前往对岸的金额。魔力结晶可以卖得高价。虽然我并不清楚具体能卖多少钱，不过只要在关卡交给官员，应该至少会通融斯佩路德族渡海。"

## 六、历史 / 传说 / 事件
- 事件名：斯佩路德族受迫害与跨海限制
- 内容：斯佩路德族在历史上传言恶劣并遭受迫害。米里斯神圣国因担忧有人将斯佩路德族作为奴隶运输至本国境内暴动破坏，制定了极端严苛的渡海防恐审查与高达两百枚绿矿钱的人头税限制。
- 原文依据："斯佩路德族是个受人厌恶嫌弃的种族，也曾经遭受无凭无据的迫害。"、"「我猜是防恐对策吧。例如是为了防止有人把斯佩路德族当成奴隶送到米里斯大陆，然后在那边作乱闹事。」"

- 事件名：人神时隔一年的梦境托梦
- 内容：鲁迪乌斯在温恩港旅社入睡后，人神再次现身于纯白梦境空间给予神谕，指示他「去摊位购买大量食物，只身前往小巷子里寻找」。人神还透露此前在利卡里斯镇事件中，若鲁迪乌斯正常将恶人移交卫兵亦可建立与瑞杰路德的信任，并坦言鲁迪乌斯思考复杂化对其而言极具观赏娱乐性。
- 原文依据："那天晚上，我在梦里获得了神谕。人神说，要我去摊位购买大量食物，只身前往小巷子里寻找。"、"「你问我正确答案喔……其实只要正常地把那些家伙交给卫兵，应该就能和瑞杰路德建立起良好关系。」"、"「对我来说，你想得复杂点反而有趣。」"

## 七、社会规则 / 习俗 / 文化
- 内容：**S级冒险者特权与等级限制规则**：公会规定A级冒险者即有资格接取S级委托；晋升为S级冒险者可获得公会优待（更优惠的住宿折扣、公会代为接洽高报酬工作、对部分违规行为睁一只眼闭一只眼等），该优待主要惠及长期迷宫探索型冒险者；但升至S级后将无法再接取B级日常委托。
- 原文依据："基于这理由，我们不打算把冒险者层级提升到无法承接B级委托的S级。既然成为A级冒险者就能够承接S级的委托，那么为何还要设定S级冒险者呢？……向职员请教后，才知道成为S级冒险者后似乎可以获得一些优待。……好像可以获得更优惠的住宿费折扣，公会方面也会帮忙接洽更好赚的工作，还会对一些违规行为睁一只眼闭一只眼等等。然而基本上，能从这类优待中获得较多好处的人，其实是那些以探索迷宫为主的冒险者。"

- 内容：**跨国关卡出入境与收费规则**：从魔大陆渡海前往米里斯大陆需经过官方关卡。入国人员须缴纳人头入国金，携带货物须缴纳货物税。收费标准根据种族差异极大（人族铁钱5枚，一般魔族绿矿钱1~2枚，斯佩路德族绿矿钱200枚）。登船前有严格的种族盘查，但官员受贿风气盛行，只要肯付巨资便可免于受罚通关。
- 原文依据："携带货物入境时要缴纳税金，入国时也必须支付金钱。"、"「人族是铁钱五枚……魔族是哪个种族？」「斯佩路德族。」……「斯佩路德族要绿矿钱两百枚。」"、"「搭船时会仔细调查种族……」「要是假冒别的种族会被罚款吗？」「……只要付出大把金钱就不会。」"

- 内容：**社会羞耻观念与玩水习俗**：该世界同样存在裸体为羞耻的社会公序良俗。但日常生活中缺乏专门的「泳衣」概念，前往河川或海边玩水通常以直接穿着内衣为主。
- 原文依据："「你没有泳衣吧？」「泳衣？那是什么？不需要呀！」……这世界也存在着认为赤身裸体很丢脸的文化。所以……我知道了，大概是穿着内衣吧。直接穿内衣下水。"

- 内容：**冒险者公会内部治安默契**：公会内部冒险者之间的争执与斗殴极为普遍，被公会管理者视为家常便饭，公会职员通常不加干涉，甚至有职员积极坐庄开盘下注。
- 原文依据："顺便一提，冒险者之间的冲突似乎是家常便饭，公会方面并不太插手。甚至反而有那种会积极开赌的职员。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯认为渡海费用很低，只要稍微承接几次委托攒点钱就能立刻搭船渡海。
- 原文是否暗示另有真相：是。人族与一般魔族费用确实较低，但斯佩路德族渡海需天价费用（两百枚绿矿钱），单靠常规委托短期内根本无法攒齐。
- 原文依据："老实说对于渡海费用，我估算得很乐观。原本以为只要稍微赚点钱就能很快搭上船。实际上，人族是铁钱五枚，其他魔族顶多也只要绿矿钱一枚或两枚。只有斯佩路德族的价钱异常昂贵。"

- 角色以为：鲁迪乌斯自认这一年担任队伍智囊参谋，在外人眼里名声应该偏向智慧文雅（如忠犬）。
- 原文是否暗示另有真相：是。外界对鲁迪乌斯的印象不仅名字被误传为「鲁杰鲁德」，而且形象是「最黑心、专门干坏事的饲主」。
- 原文依据："要我自己取名的话就是奶油犬……但是这一年以来，我自认自己都是以队伍参谋的身分来行动，所以果然会是个比较知性的外号吧。例如忠犬之类。「那，那个站在远处的矮子就是『饲主鲁杰鲁德』吗！」「我听说『饲主』是其中最黑心的家伙。」「是啊，据说他专门干一些坏事。」"

- 角色以为：鲁迪乌斯根据人神线索自以为推断出隔天必定是救了某个造船公会老板的孙子。
- 原文是否暗示另有真相：不明（本章人神仅回应"这部分要到明天才会真相大白，敬请期待"，本章无从验证其是否猜中）。
- 原文依据："接下来，救了那小孩之后，才知道原来对方是造船公会老板的孙子～就是这么回事吧？「呼呼呼，这部分要到明天才会真相大白，敬・请・期・待。」"
