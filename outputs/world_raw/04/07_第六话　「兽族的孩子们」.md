# 第六话　「兽族的孩子们」 世界设定提取

## 一、地理与场所
- 名称：走私据点（两层木造建筑物）
- 内容：位于大森林/城镇附近的昏暗森林中，为走私贩子藏匿人质与货物的秘密据点。一楼设有昏暗的囚禁房间与刻有魔法阵结界的大厅；二楼设有供给结界魔力的小型魔法阵与魔力结晶提灯。
- 原文依据："那房间里没什么光线。在一片昏暗中，可以看到脸上带着不安表情的全裸少年少女们扭动着身子。"、"我前往建筑物二楼。在魔法阵正上方的房间里发现了小型的魔法阵，里面还放着一个以木头制成，外型类似提灯的物品。在提灯的正中央，有看起来应该是魔力结晶的东西。"、"回到一楼确认，围住狗的魔法阵也消失了。"
- 名称：大森林周边的港口城镇
- 内容：大森林外围的城镇，设有港口与卫兵管辖，在雨季来临前夕会有最后一班船出港；雨季来临后离开城镇将无处可去。
- 原文依据："没时间了，明天最后一班船就会出港。"、"而且据说雨季快要到了，就算离开城镇也无处可去。"
- 名称：兽族的村子
- 内容：位于森林深处，兽族战士抓捕到可疑分子或走私犯后会押往村中牢房审问。
- 原文依据："可以先把这小子带回村里，盘问他到底把人带到哪里去了。"、"老人点点头，迈步冲进昏暗的森林。裘耶斯目送他离开……于是，我被裘耶斯扛着，往森林深处移动。"

## 二、组织与势力
- 名称：泰德路迪亚族（兽族部族）
- 内容：大森林的兽族部族之一（战士裘斯塔夫・泰德路迪亚、裘耶斯等所属），对本族的象征“圣兽”极度崇敬，负责保护村落与救援被拐儿童。
- 原文依据："我叫裘斯塔夫・泰德路迪亚。这份恩情必当回报，不过首先必须把孩子们送回父母身边。"、"因为圣兽大人是一族的象徵喵，所以不能把它丢在那种地方喵。"
- 名称：走私组织
- 内容：拐卖兽族幼童与圣兽的走私犯罪网络，内部派系并不团结一致，存在内讧与利益冲突。
- 原文依据："然而贾尔斯也说过，走私组织并没有那么团结一致。"、"就算是因为走私组织自己内哄才带来这个委托，然而瑞杰路德真心为他们着想也是事实。"

## 三、力量体系 / 魔法 / 技能
- 名称：治愈魔术 / 结界
- 规则：施加治疗术时必须用手直接接触患部才能奏效；结界本质上属于治愈魔术的一种。
- 原文依据："施加治疗术时，必须用手接触患部才行。"、"看来这个魔法阵形成了结界，而所谓的结界，其实是一种治愈魔术。但是我对原理一窍不通。"
- 名称：火魔术特性
- 规则：使用火魔术时若想增强威力，火球的尺寸体积也会随之变大。
- 原文依据："面对发出呛鼻气味的尸体堆，制作出火弹。……使用火魔术时，如果想增强威力，不知道为什么尺寸也会跟着变大。"
- 名称：魔术陷阱与魔法阵供能机制
- 规则：典型魔术陷阱依靠魔力结晶提供能量；魔法阵发光代表有魔力传输，切断魔力结晶供能魔法阵便会消失；强行破坏供能魔法阵可能引发未知危险状况。
- 原文依据："这个魔法阵发出蓝白色光芒，隐约照亮房间。既然会发光，就代表有魔力传输过来吧？只要切断魔力的供给来源，魔法阵就会消失。洛琪希有教过我这些知识。典型魔术陷阱的解除方法。讲到魔力供给的来源，通常是魔力结晶。"、"我慎重地拿起提灯，于是地板上的魔法阵立刻消失。回到一楼确认，围住狗的魔法阵也消失了。"
- 名称：兽族的咆哮（音波冲击/麻痹技能）
- 规则：兽族战士（裘耶斯）把手搭在嘴边发出带有实质质量感般的巨大咆哮，能剧烈震动鼓膜、冲击脑部，使目标倒地陷入四肢无法动弹、无法集中魔力施法的失能状态。
- 原文依据："男子把手放在嘴边。正在想难道他什么也没做吗？男子却在这瞬间发出咆哮声。'呜喔喔喔喔喔喔喔喔！'压倒性的音量，似乎比艾莉丝尖叫时还大上数倍。而且还让人感觉到这声音彷佛带有实际质量。我的鼓膜振动，脑部受到冲击。等我回神时，自己已经倒在地上。无法站起。真不妙，得使用治疗术……手也没办法动弹，这是怎样？是某种魔术吗？……无法使用魔术吗？我试着集中魔力……不行。"
- 名称：魔眼（预知眼）
- 规则：启动后可预知一秒后的未来影像，但存在死角，背对视野的方向无法看到。
- 原文依据："虽说我在进入房间之前就发动魔眼，并设定好可以看见一秒后的未来，但是背对房门就什么都看不到。"

## 四、种族 / 生物
- 名称：兽族（猫耳族、犬耳族等）
- 特征：外貌长有不同的兽耳（如猫耳、犬耳）或尾巴，肤色有巧克力色，战士肌肉发达茂密；猫耳兽族说话句尾天然会带“喵”口癖；嗅觉极其敏锐，能分辨个体具体气味（如托娜、魔族/斯佩路德族气味），甚至能闻出人族发情时的气味。
- 原文依据："他们各自长着不同的兽耳。……有兽耳或精灵耳朵的他们全都一丝不挂……"、"这女孩是真正的猫耳兽族，而且并不是因为她讲兽神语才会听起来像喵。是她真的讲到句尾就加了个喵。"、"巧克力色的皮肤，动物般的耳朵，类似老虎的尾巴。……在基列奴有着傲人双峰的位置，现在看到的却是发达胸肌。这家伙是男性。"、"老人就动了动鼻子。'有气味。'……'味道很淡，是托娜他们的气味没错。而且还有另外一人……『那个』魔族的气味。'"、"这个少年身上散发出人族发情时的气味。"
- 名称：圣兽
- 特征：德路迪亚等兽族的一族象征与尊崇生物；外表看似幼犬但体型长达约两公尺（类似大型豆柴），银色毛发会闪烁光芒，长相优雅聪明；毛质柔软蓬松且体重沉重；能听懂人类语言和兽神语，并能与兽族进行特殊的意念/吠声沟通。
- 原文依据："被铁链拴在魔法阵里的动物是一只小狗。明明一看就知道是小狗，但体型却特别庞大。长度大约有两公尺吧，为什么这世界的狗猫都这么大块头？看到第一眼时，我还以为它长着白毛，看样子实际上是银色。而且或许是因为受到光线影响，感觉好像在闪烁着光芒。总之是一只Large size的豆柴，有一脸优雅聪明的长相。"、"因为圣兽大人是一族的象徵喵，所以不能把它丢在那种地方喵。"、"看样子它真的听得懂人话。异世界真是方便，居然跟狗都可以沟通。"、"他们真的可以沟通吗？在我听起来小狗只是在汪汪叫。"
- 名称：斯佩路德族
- 特征：额头上长有第三只眼（可用护额遮盖），能捕捉高速接近者的动向；瑞杰路德在四百年前拉普拉斯战役时学会了兽神语。
- 原文依据："在拉普拉斯战役那时学会后，一直没什么机会使用……"、"这时，我的'眼睛'捕捉到有什么人正在急速接近。"

## 五、物品 / 道具 / 武器
- 名称：抑制力量的铁链与项圈
- 说明：走私贩子束缚圣兽的特殊刑具。铁链上刻有神秘图案，能抑制被束缚者的体力与力量，可用魔术切断；项圈无钥匙孔，为卡紧接缝结构，需用外力或魔术撑开接缝方能拆卸。
- 原文依据："不，那个铁链很可疑，上面还刻着显然有什么含意的图案。"、"如果是铁链在抑制住这只狗的力量……"、"总之，我试着用魔术切断铁链，铁链一下子断了。于是，那只狗迅速恢复精神。"、"但是却找不到钥匙孔，没有钥匙孔就无法开锁。……最后总算发现接缝，看样子这玩意儿似乎是卡上就不会松开的类型。……我慎重地使用土魔术让接缝处出现土，把接缝撑大。'啪'地一声，项圈开了。"
- 名称：魔力结晶提灯装置
- 说明：以木头制成外型类似提灯的装置，正中央镶嵌魔力结晶，放置在传输魔法阵中央为下方的大型结界魔法阵供能。
- 原文依据："在魔法阵正上方的房间里发现了小型的魔法阵，里面还放着一个以木头制成，外型类似提灯的物品。在提灯的正中央，有看起来应该是魔力结晶的东西。"
- 名称：兽族老战士的佩剑
- 说明：兽族老战士（裘斯塔夫）佩戴的武器，刀身厚实，外形类似柴刀。
- 原文依据："是个兽族男性，拿着一把刀身厚实，类似柴刀的剑。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：四百年前的历史战争，瑞杰路德在战役期间学会了兽神语。
- 原文依据："在拉普拉斯战役那时学会后，一直没什么机会使用……"
- 事件名：走私贩拐卖兽族儿童与圣兽事件
- 内容：走私组织突袭森林抓走了兽族的七名幼童以及圣兽，关押在森林据点，准备赶在雨季前最后一班船出港前运走贩卖。
- 原文依据："我们在森林里玩，就突然被奇怪的男人抓住了喵！"、"没时间了，明天最后一班船就会出港。只能放弃，必须抱着能救出圣兽大人已是意外幸运的想法。"

## 七、社会规则 / 习俗 / 文化
- 内容：圣兽在兽族文化中具有至高无上的神圣地位，是一族的象征，兽族战士见圣兽必须单膝跪地行礼致歉，绝不容许外人侮辱或不敬抚摸。
- 原文依据："你这家伙！在对圣兽大人做什么！"、"因为圣兽大人是一族的象徵喵，所以不能把它丢在那种地方喵。"、"那个叫裘耶斯的男子在它面前屈膝跪下。'真是非常抱歉，圣兽大人。本该尽快赶来，却晚了一步才将您救出。'"
- 内容：兽族的刑狱习俗是不屑于人族那种残酷的严刑拷打，抓到嫌犯或俘虏顶多扒光衣物关进牢房。
- 原文依据："兽族不会做出人族那样的拷问行为，顶多只会把他扒光丢进牢里。"
- 内容：在这个世界的奴隶走私行业中，对被绑架的小孩没有同情心，会施以粗暴殴打、折断肋骨或大腿骨虐待，并脱光衣服反绑双手。
- 原文依据："在这个世界里，对绑来的小孩并没有多少同情心。所以那些不客气的虐待……"
- 内容：大森林兽族通行兽神语，猫耳兽族说话句尾天然带有“喵”口癖。
- 原文依据："少年使用的语言是兽神语让我一时没有反应过来，但是我已经确实学会兽神语。"、"这女孩是真正的猫耳兽族，而且并不是因为她讲兽神语才会听起来像喵。是她真的讲到句尾就加了个喵。"
- 内容：雨季即将来临，一旦进入雨季，离开城镇将寸步难行、无处可去，海上航运也会停航。
- 原文依据："而且据说雨季快要到了，就算离开城镇也无处可去。"、"没时间了，明天最后一班船就会出港。"

## 九、角色认知 vs 客观事实
- 角色以为：裘耶斯认为鲁迪乌斯是走私贩同伙之一，并认为鲁迪乌斯身上散发发情气味，正以下流笑容猥亵和袭击尊贵的圣兽。
- 原文是否暗示另有真相：是。鲁迪乌斯其实是打倒走私贩后折返回来解救被囚禁圣兽的恩人；抚摸圣兽是因为圣兽解开项圈后扑倒他舔脸示好，其柔软毛发引起鲁迪喜爱；身上的“发情气味”是先前治疗全裸兽族少女时产生的好色反应，绝非对圣兽发情。
- 原文依据："这家伙一边摸着圣兽大人，一边露出下流的笑容。说不定他的实际年龄和外表并不一致。"、"这个少年身上散发出人族发情时的气味。居然对圣兽大人产生性冲动，实在难以置信。"
- 角色以为：鲁迪乌斯怀疑兽族战士带有物理冲击感、震荡脑部并导致浑身瘫痪无法使用魔术的咆哮是“某种魔术”。
- 原文是否暗示另有真相：不明 [存疑]。原文仅记录鲁迪乌斯的疑问“是某种魔术吗？”，并未明确定性是魔术还是兽族特有的音波体术或技能。
- 原文依据："手也没办法动弹，这是怎样？是某种魔术吗？"
- 角色以为：裘耶斯闻到现场有斯佩路德族魔族的气味，认为托娜等孩子们是被魔族绑架掳走的。
- 原文是否暗示另有真相：是。孩子们其实是被瑞杰路德（斯佩路德族）从走私贩手中救出并护送往城镇，裘斯塔夫也推测“说不定是救走了”。
- 原文依据："您意思是那个魔族把原本在这里的托娜等人抓走了？"、"这个嘛……说不定是救走了。"
