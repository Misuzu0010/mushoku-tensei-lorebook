# 闲话　「阴错阳差？外传」 世界设定提取

## 一、地理与场所
- 名称：温恩港
- 内容：魔大陆的港都，街景与米里斯大陆最北端的赞特港相似，在此处可搭船前往米里斯大陆。
- 原文依据："她刚结束海上的旅程，踏上魔大陆的港都温恩港。""温恩港和米里斯大陆最北端的赞特港有着相似的街景，即使是初次造访，也会让人产生某种似曾相识的感觉吧。"

- 名称：赞特港
- 内容：米里斯大陆最北端的港口城镇，街景与魔大陆温恩港相似。
- 原文依据："温恩港和米里斯大陆最北端的赞特港有着相似的街景，即使是初次造访，也会让人产生某种似曾相识的感觉吧。"

- 名称：米里希昂
- 内容：米里斯神圣国的首都，位于米里斯大陆，能品尝到人族制作的美味点心。
- 原文依据："然而到达米里斯大陆，在米里希昂嚐到人族制作的点心后，洛琪希才发现原来这世上有如此美味的食物，在魔大陆上绝对吃不到，也因此下定决心再也不要回来。""途中并没有前往米里斯神圣国的首都米里希昂。"

- 名称：东部港
- 内容：王龙王国的港都，洛琪希在此处的冒险者公会遇见争执的艾莉娜丽洁与塔尔韩德。
- 原文依据："洛琪希是在王龙王国的港都「东部港」遇见两人。""对于对于在冒险者公会里争吵的他们，洛琪希一开始当作没看见。"

- 名称：西部港
- 内容：米里斯大陆的港都，洛琪希一行自王龙王国乘船抵达成后，在此处购买马匹与马车。
- 原文依据："到达米里斯大陆的港都西部港后，花大钱买下八脚神马斯雷普尼尔品种的马匹和马车。"

- 名称：青龙山脉
- 内容：位于米里斯大陆，分布着矿坑族的聚落。
- 原文依据："所以也避开了青龙山脉的矿坑族聚落和大森林的长耳族聚落，直接往赞特港前进。"

- 名称：大森林
- 内容：位于米里斯大陆，分布着长耳族的聚落；该地存在极长的雨季，雨季期间在大森林内无法通行移动。
- 原文依据："避开了青龙山脉的矿坑族聚落和大森林的长耳族聚落，直接往赞特港前进。两人主张毕竟大森林的雨季快要到了，还是多赶点路会比较好。因为雨季很长，而且那段期间内无法在大森林里移动。"

- 名称：贝卡利特大陆 [存疑]
- 内容：塔尔韩德较为熟悉的大陆之一。
- 原文依据："塔尔韩德主张应该前往熟悉的贝卡利特大陆或中央大陆北部。"

- 名称：中央大陆北部
- 内容：塔尔韩德较为熟悉的地区之一。
- 原文依据："塔尔韩德主张应该前往熟悉的贝卡利特大陆或中央大陆北部。"

- 名称：西隆王国郊外地下迷宫
- 内容：西隆王国郊外的地下二十五层迷宫，洛琪希曾单人将其成功攻略突破。
- 原文依据："而且突破西隆王国郊外的地下二十五层迷宫。之后，还获得西隆王国宫廷魔术师这位子。"

- 名称：米格路德族之村
- 内容：洛琪希离乡前的出生故乡聚落。
- 原文依据："那是自称为「利卡里斯愚连队」的三名少年，对当时刚离开米格路德族之村，还像个土包子分不清楚上下左右的洛琪希伸出援手。"

## 二、组织与势力
- 名称：黑狼之牙
- 内容：中央大陆最出名的冒险者队伍之一，全员各有怪癖和独特特质，组队后仅花数年便升上S级并随即解散。昔日成员包括保罗、塞妮丝、艾莉娜丽洁、塔尔韩德等人。
- 原文依据："更进一步交谈后，才知道这两人过去曾和保罗与塞妮丝共组队伍。队伍名是「黑狼之牙」。……是中央大陆上最出名的队伍之一。据说队伍成员全都是些各有怪癖和不同特质的人物，当时引起各式各样的话题。虽然他们在组队之后只花了几年就升上S级，然后立刻解散，不过洛琪希还是很有印象。"

- 名称：利卡里斯愚连队
- 内容：昔日由三名少年新手冒险者组成的队伍，曾对刚离开村庄的洛琪希提供帮助并共同行动，后因一名队员在旅途中丧命，该队伍在抵达温恩港后解散。成员包括诺克巴拉、布雷兹等。
- 原文依据："那是自称为「利卡里斯愚连队」的三名少年，对当时刚离开米格路德族之村，还像个土包子分不清楚上下左右的洛琪希伸出援手。……和他们的队伍在到达温恩港后解散……"

- 名称：Dead End（小队传闻）
- 内容：温恩港近来声名大噪的新锐三人冒险者队伍。成员分别自称为“狂犬艾莉丝”（红发少女持剑）、“看门犬瑞杰路德”（高大白皮肤光头持枪）、“饲主鲁杰鲁德”（矮个子，使用类似杖的魔力附加品）。外间风评不佳，但亦流传看门犬是个喜欢小孩、惩奸除恶的好人。
- 原文依据："收集情报的途中，他们得知名叫「Dead End」的队伍正待在这城镇里。据说他们是这阵子突然声名大噪的新锐冒险者。……从塔尔韩德获得的情报可以知道，「Dead End」是三人组。似乎分别自称为「狂犬艾莉丝」、「看门犬瑞杰路德」、「饲主鲁杰鲁德」，后面这两个人好像是兄弟。狂犬的外表特徵是红发，看门犬非常高大，饲主是个小矮子。狂犬用剑，看门犬用枪，饲主好像是使用类似杖的魔力附加品。"

- 名称：阿斯拉王国
- 内容：历史最悠久的大国，但存在腐败的传统与权力操控。对菲托亚领地灾害的对应被评为差劲；虽提供寻人援助资金，但公会并不主动代为征求，必须由受灾当事者以委托人身份在各地公会签名提出委托，王国才会在委托成功时负担报酬。
- 原文依据："阿斯拉王国有提供寻找菲托亚领地居民用的援助资金。只要在各城镇的公会以委托的形式提出需求，阿斯拉王国会负担委托成功时必须支付的报酬，之后就靠冒险者去寻找。不过基本上必须有人以委托人的身分签名，因此除非有哪个人主动去委托工作，否则公会不会帮忙徵求。……看到阿斯拉王国对这场大灾害的对应如此差劲，洛琪希感到很气愤。……因为是历史最悠久的国家，所以受到腐败的传统和权力操控。"

- 名称：米里斯神圣国
- 内容：米里斯大陆的国家，其首都是米里希昂。
- 原文依据："途中并没有前往米里斯神圣国的首都米里希昂。"

## 三、力量体系 / 魔法 / 技能
- 名称：治疗术
- 规则：水系/神圣体系魔术，可用于恢复体力与治疗身体创伤。
- 原文依据："「你还好吗，塔尔韩德先生？要不要我使用治疗术呢？」"

- 名称：冰霜击
- 规则：水系/冰系攻击魔术，咏唱咒文为“雄伟的水之精灵，登上天空的雷帝之王子啊！以英武的冰之剑击落目标吧！『冰霜击』！”，威力足以将旅社建筑物半毁。
- 原文依据："「雄伟的水之精灵，登上天空的雷帝之王子啊！以英武的冰之剑击落目标吧！『冰霜击』！」旅社半毁。"

- 名称：魔力结晶
- 规则：魔术师在准备与高等级强敌战斗时可预先准备的消耗性辅助道具。
- 原文依据："要和那种等级的对手战斗，必须准备魔力结晶。说不定还有必要用到画好魔法阵的卷轴。"

- 名称：魔法阵卷轴
- 规则：预先画好魔法阵的便携卷轴，可供战斗备用。
- 原文依据："说不定还有必要用到画好魔法阵的卷轴。"

- 名称：重装魔术师战法
- 规则：缺乏敏捷度、移动迟缓且无法有效闪避敌人攻击的魔术师，可穿戴坚固的重型铠甲，从而能够站在队伍前线承受攻击并施放魔术。
- 原文依据："答案是因为他脚步迟缓，几乎没有敏捷度可言。万一遭到魔物攻击，甚至连闪避都有困难。所以才会像这样穿着坚固的铠甲，让自己即使待在队伍前方也能够使用魔术。"

- 名称：冒险者层级与组队机制
- 规则：冒险者层级自F级起，依次涵盖D级、B级、A级、S级、SS级等。通常不同层级之间难以跨级组队；公会委托中，讨伐恶魔Dead End等级别的任务被默认归入S级，若完成可达SS级。
- 原文依据："「反正还是会因为层级不同而无法组队吧。」洛琪希现在的冒险者层级是A级。会听信吟游诗人诗歌的稚气少年们平均层级是D。……然而如果要悬赏讨伐委托，毫无疑问会是S级任务。而且还会是那种一旦成功，就能成为SS级的委托。"

## 四、种族 / 生物
- 名称：长耳族
- 特征：长耳、金发、身材高挑、纤细腰肢与肉感体态，聚落分布于米里斯大陆大森林。艾莉娜丽洁即为此种族。
- 原文依据："对方拥有造型类似法国面包的蓬松金发，其间还隐约可见一对长耳。那名女性是长耳族。高挑的身材，纤细的腰肢，还有肉感的翘臀。……大森林的长耳族聚落"

- 名称：矿坑族
- 特征：身形矮小但体宽为常人两倍以上，蓄粗犷胡须，脚步迟缓、敏捷度极低；聚落分布于青龙山脉。塔尔韩德即为此种族。
- 原文依据："一名矿坑族的老人从洛琪希后方摇摇晃晃地走下船。……身高和洛琪希差不多，身体的宽度却有两倍以上。……因为他脚步迟缓，几乎没有敏捷度可言。万一遭到魔物攻击，甚至连闪避都有困难。……青龙山脉的矿坑族聚落"

- 名称：米格路德族
- 特征：蓝发，成年后外形依然如娇小少女般缺乏起伏，极度长寿，数十年容颜不改；其成年外貌无法被人类轻易分辨，但逃不过斯佩路德族额头“眼睛”的观察。
- 原文依据："据说这个人是来自魔大陆的蓝发少女……彼此分别之后已经过了二十年。……只有自己不会改变。……（不……那不是少女。）是米格路德族的成年女性。虽然乍看之下很难判断，但无法骗过瑞杰路德的「眼睛」。"

- 名称：斯佩路德族 / 恶魔“Dead End”
- 特征：被魔大陆居民普遍视为极其危险、专挑小孩抓走的恐怖恶魔怪物；额头生有能看穿虚实的“眼睛”。
- 原文依据："讲到「Dead End」，是魔大陆上无人不知无人不晓的恶魔之名。被认为是斯佩路德族中特别危险，总是挑小孩子下手的怪物。……虽然乍看之下很难判断，但无法骗过瑞杰路德的「眼睛」。"

- 名称：八脚神马斯雷普尼尔
- 特征：米里斯大陆出产的良种马匹品种，拥有八只脚，价格极其昂贵，速度与耐力出众。
- 原文依据："到达米里斯大陆的港都西部港后，花大钱买下八脚神马斯雷普尼尔品种的马匹和马车。"

## 五、物品 / 道具 / 武器
- 名称：斩击真空波刺剑（魔力附加品）
- 说明：艾莉娜丽洁在迷宫深处获得的刺剑武器，比普通剑更坚固，挥动即可发出能斩断数公尺外树干的真空波。刺剑本身通常多为阿斯拉贵族决斗或北方剑斗士着甲战斗所用。
- 原文依据："艾莉娜丽洁拥有的这把刺剑是在迷宫深处取得的魔力附加品，不但比众多的一般剑类武器更加坚固，而且只要挥动一下，就会产生能斩断数公尺外树干的真空波。"

- 名称：冲击缓和圆盾（魔力附加品）
- 说明：艾莉娜丽洁在迷宫深处获得的小圆盾，具备能够减缓所承受冲击的魔力效果。
- 原文依据："另外小圆盾也是魔力附加品，具备的能力是可以减缓承受到的冲击。"

- 名称：魔杖（类似魔力附加品的杖）
- 说明：传闻中Dead End“饲主”所使用的类似杖的魔力附加品（实为鲁迪乌斯所持魔杖）。

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地消灭与转移大灾害（一年前）
- 内容：一年前阿斯拉王国菲托亚领地遭遇消灭灾害，大批居民失踪并分散转移至魔大陆等地，至今受灾当事者仍在外四处搜寻家眷。
- 原文依据："然而听到争执内容是想要前往魔大陆寻找在菲托亚领地失踪的人物后……菲托亚领地消灭后已经过了一年，或许被转移来的人们早已全部死去。"

- 事件名：吟游诗人传唱的洛琪希冒险诗歌
- 内容：讲述离开故乡的蓝发少女魔术师与三名新人冒险者在魔大陆旅行并踏上米里斯大陆的故事。因创作者不了解米格路德族，将其夸大为“十二岁离家、一至两年内走遍魔大陆并升上A级”。
- 原文依据："她冒险经历前期的故事被吟游诗人写成诗歌，因此变得相当有名。诗歌内容叙述一名离开故乡的少女魔术师遇上三名新手冒险者，在魔大陆旅行，最后踏上米里斯大陆的故事。……没想到吟游诗人并不认识米格路德族，所以误以为洛琪希是在十二岁左右开始旅行，花了大约两年升上A级。而且现在诗歌的内容被更加夸大，已经成了洛琪希只花一年就走遍魔大陆并升上A级的故事。"

- 事件名：恶魔“Dead End”的民间传说
- 内容：在魔大陆流传的民间恐怖传说，被视作魔大陆最恐怖的恶魔魔物，大人常用其恐吓不乖的孩子“不乖就会被抓走”。
- 原文依据："讲到「Dead End」，是魔大陆上无人不知无人不晓的恶魔之名。被认为是斯佩路德族中特别危险，总是挑小孩子下手的怪物。洛琪希小时候也被母亲吓唬过好几次。告诫她要是不乖，就会被「Dead End」抓走。在魔大陆上，「Dead End」大概是最恐怖的魔物吧。"

## 七、社会规则 / 习俗 / 文化
- 内容：冒险者抵达陌生城镇后，将前往冒险者公会作为行动的第一步是基本常识。
- 原文依据："第一个行动是前往冒险者公会，这是身为冒险者的基本常识。"

- 内容：阿斯拉王国对灾害失踪者的援助金申报规则：公会不主动发起搜寻委托，必须由受灾人亲自在城镇公会签名提出需求，王国才在达成时报销委托报酬。
- 原文依据："阿斯拉王国有提供寻找菲托亚领地居民用的援助资金。只要在各城镇的公会以委托的形式提出需求，阿斯拉王国会负担委托成功时必须支付的报酬，之后就靠冒险者去寻找。不过基本上必须有人以委托人的身分签名，因此除非有哪个人主动去委托工作，否则公会不会帮忙徵求。"

- 内容：艾莉娜丽洁的“性诅咒”：艾莉娜丽洁自称身负某种必须与男性发生关系的诅咒，极度喜欢男性，随时随地享受一夜情，甚至同时与多名男性在彼此同意下共处。
- 原文依据："尽管本人宣称是因为中了某种诅咒，然而她即使被陌生男人侵门踏户也没有表现出悲痛感，看起来反而像是乐在其中。……房间里有五个男人。……在洛琪希的常识里，并不知道「这种行为」居然可以在彼此同意的情况下和复数对象进行。"

- 内容：迷宫残酷现实与冒险者浪漫幻想的脱节：冒险者间流传在迷宫深处邂逅并共结连理的传闻；但实际迷宫极其险恶，第五层起已不见单人冒险者，第十层以上单人极难维生，单枪匹马深入伴随着强烈的生死危机。

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希以为冒名恶魔“Dead End”的三人队伍是一群脑子不正常的危险不良分子，且认为“看门犬是个喜欢小孩、惩奸除恶的好人”只是他们为了避免名声太差而故意操作放出的洗白传言；在海滩偷看时，以为看门犬回头与自己对视是产生了将自己视作猎物的凶暴杀气。
- 原文是否暗示另有真相：是
- 原文依据："「居然假冒『Dead End』的名字，我不认为那些人的脑袋正常。」……「看门犬是个好人」这点，恐怕也是他们为了避免自己风评变得太差才放出来的消息。……面对这强烈的视线，洛琪希感到难以言喻的恐惧。还产生彷佛自身成了猎物的错觉。" 与后文瑞杰路德的视角形成强烈反差："（不……那不是少女。）是米格路德族的成年女性。虽然乍看之下很难判断，但无法骗过瑞杰路德的「眼睛」。……只是觉得稀奇所以想参观一下吗？瑞杰路德正在观察对方，少女突然把脸转开，不知道跑哪里去了。（唔……吓到她了……？）" 表明看门犬瑞杰路德正是货真价实的斯佩路德族且真心关爱保护儿童，当时回头纯粹是发现并打量对方，事后还以为是自己吓到了她。

- 角色以为：坊间冒险者及诗歌听众以为洛琪希是十二岁离乡、花一至两年便升上A级的天才少女。
- 原文是否暗示另有真相：是
- 原文依据："没想到吟游诗人并不认识米格路德族，所以误以为洛琪希是在十二岁左右开始旅行，花了大约两年升上A级。而且现在诗歌的内容被更加夸大，已经成了洛琪希只花一年就走遍魔大陆并升上A级的故事。开什么玩笑……洛琪希心想。实际上她花了五年左右才升上A级。"
