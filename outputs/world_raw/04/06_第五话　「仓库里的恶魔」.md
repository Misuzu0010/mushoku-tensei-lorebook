# 第五话　「仓库里的恶魔」 世界设定提取

## 一、地理与场所
- 名称：赞特港（城市风貌与布局）
- 内容：米里斯大陆北方的港都，街景与魔大陆温恩港相似，多坡道，港口区域比市区更加繁荣，冒险者公会位于靠近港口地带。城内木造建筑比温恩港多且外墙刷有抵御海风侵蚀的丰富彩色涂料；街道种植整排行道树，城外延伸出茂密森林与大面积绿植；城内建有贫民窟，治安较为恶劣。
- 原文依据："港都赞特港。这里拥有和温恩港很相似的街景。城镇里同样有许多坡道，港口那边也同样比市区更加热闹。还有连冒险者公会并不在城镇中心，而是位于靠近港口的区域这点也是一模一样。不过，可以找到几个不同之处。首先这里的木造建筑比温恩港多，而且或许是为了对抗海风的侵蚀，都漆着色彩丰富的涂料。城镇里有整排的行道树，往城外望去，还可以看到远方有一片茂密的森林。到处都是绿色。""讲白一点，就是在贫民窟附近落脚。"

- 名称：赞特港埠头第三号仓库及地下密道
- 内容：位于赞特港埠头四栋并列大型木造仓库之一，仓库深处有一座约可容纳五人的大木箱作为伪装，推开后露出通往下方的阶梯，连接一条潮湿湿滑的洞窟密道，步行穿行约一小时可直达城镇外部森林。
- 原文依据："在埠头角落，并排着四栋大型木造仓库。我溜进写着「第三号仓库」的建筑物里后……那里有一个差不多可以容纳五个人的大木箱……推开木箱。下面出现楼梯……通往一个潮湿的洞窟。……在洞窟里移动了约一小时。走出洞窟后，我们来到森林里。看样子似乎已经离开城镇。"

- 名称：走私组织林中秘密洋房（走私据点/二〇二号室）
- 内容：隐藏在城镇外森林深处的大型建筑物，外表形似富豪别墅。地上楼层堆放海关税收正常的常规货物作为伪装掩护，并有众多恶棍打手驻守；地下楼层则为关押逃税高额关税品、重罪违禁走私品、被绑架的兽族幼童奴隶以及被魔法阵束缚的大型未知名生物的牢房。挂有“二〇二”门牌的房间位于地下，为关押瑞杰路德之处。
- 原文依据："走出洞窟后，我们来到森林里。……出现一栋像是藏在树木之间的大型建筑物。外表看起来并不像仓库，反而更像是有钱人的别墅。……「原来在地下啊。」「上面只是幌子。」据说地上楼层放的是被发现也不会出什么问题的货物，至于地下就是那些通过海关会被收取相当高的税金，或是走私会被判重罪的商品。……莫霍克发型男在挂有二○二门牌的房间前停下。"

- 名称：大森林
- 内容：米里斯大陆的广阔森林地带，存在特有的漫长“雨季”，持续降雨约三个月，届时森林暴发大洪水导致道路彻底阻断无法通行。
- 原文依据："雨季指的是米里斯大陆「大森林」地区的特有天候，据说会降下持续约三个月的大雨。大森林里会淹起大洪水，道路当然无法通行。"

## 二、组织与势力
- 名称：赞特港走私与人口贩运集团
- 内容：与魔大陆温恩港走私网络对接的跨国走私与奴隶拐卖犯罪团伙。以港口三号仓库暗道与城外森林洋房为秘密中转据点，下辖白发执事、莫霍克看守等人员，雇用大批凶悍保镖打手，并培养有专门暗杀背叛者的刺客。地下拐骗关押兽族幼童等走私奴隶。对泄密与背叛零容忍。
- 原文依据："要是有顾客背叛，走私组织会派出他们自己培养的刺客。等待背叛者的下场只有凄惨的死亡。虽然我不确定贾尔斯会怎么行动，不过他也有可能为了封住我们的嘴而送来刺客。""「这里有小孩子被抓，共七个。……是兽族的小孩。似乎是被强行掳来」"

- 名称：冒险者公会（赞特港分部）
- 内容：设立在赞特港靠近港口区域的公会组织，常年发布各类失物寻获委托（如替失主寻找遗失戒指或钱币），该类委托不限冒险者层级，任何人均可承接。
- 原文依据："连冒险者公会并不在城镇中心，而是位于靠近港口的区域这点也是一模一样。""内容是「如果帮忙找到愿意付钱酬谢」的这类委托不看层级高低，任谁都可以承接。"

- 名称：无照汇兑商
- 内容：未加入公会私下开展跨大陆货币兑换业务的黑市地下汇兑业者，兑换时会克扣抽取巨额手续费。
- 原文依据："要是必须去麻烦没有加入公会的无照汇兑商，大概会被抽掉更多费用。"

## 三、力量体系 / 魔法 / 技能
- 名称：控温与除螨热风魔术
- 规则：将火魔术与风魔术结合生成高温干燥热风吹向床铺，用于彻底消灭床褥上的尘螨。
- 原文依据："我能做的只有用魔术制造出热风吹向床铺，把尘蟎都杀光而已。"

- 名称：生物拘束魔法阵
- 规则：刻画于地面发出微弱光芒的特殊拘束型魔法阵，配合沉重铁链用于压制、禁锢强力的大型动物或魔兽。
- 原文依据："只见在发出微弱光芒的魔法阵中央，有一只被铁链拴着的大型动物躺在地板上。"

- 名称：岩炮弹威力调节技巧
- 规则：鲁迪乌斯在战斗中刻意控制、微调土魔术“岩炮弹”的魔力注入与发射杀伤力，将其降低至不会造成死亡的击昏/压制水准，以避免破除杀人禁忌。
- 原文依据："然而仔细研究自己做过的事情，并没有真正下定杀人的决心，而是去调节岩炮弹的威力。为了避免威力太强大而不小心杀死对象，我总是把魔术的威力降低到不会致命的程度。"

- 名称：斯佩路德族无声潜行击杀技术
- 规则：作为身经百战的精锐战士，瑞杰路德在近身刺杀与全速奔跑突进中能够保持完全无声无息，瞬间夺取敌手性命。
- 原文依据："瑞杰路德无声无息地给他致命一击，然后冲向楼梯，依然没有造成任何声响。"

## 四、种族 / 生物
- 名称：米里斯大陆人形种族群体
- 特征：与魔大陆外形杂乱荒唐的魔族不同，米里斯大陆的居民外貌基本贴近人类，主要由人族、兽族、长耳族、矿坑族、小人族五大类人形种族构成。
- 原文依据："连路上行人的外表都不是那种会让人感到荒唐无稽又显得杂乱的魔族，反而几乎都是人族、兽族、长耳族、矿坑族和小人族这些看起来和人类相近的种族。"

- 名称：兽族（及兽族幼童）
- 特征：米里斯大陆的主要种族之一，外形贴近人类，其幼童遭到走私团伙强行暴力拐掳并作为走私奴隶关押在地下暗室。
- 原文依据："「这里有小孩子被抓，共七个。……是兽族的小孩。似乎是被强行掳来，在这里也能听见哭声。」"

- 名称：小人族
- 特征：米里斯大陆常见的人形种族之一。
- 原文依据："反而几乎都是人族、兽族、长耳族、矿坑族和小人族这些看起来和人类相近的种族。"

- 名称：雨季出没的高价素材魔物 [存疑]
- 特征：栖息于大森林，仅在雨季期间活跃，有时会误入赞特港附近；身上的素材可卖出极高价格，吸引大量冒险者在雨季滞留猎捕。
- 原文依据："后来才知道只在雨季出没的魔物好像也会误闯到城镇这边，而且那个魔物身上的素材可以卖得高价，因此这时期会有很多冒险者选择在此长期停留。"

- 名称：被拘禁的未知大型动物
- 特征：走私洋房地下铁栏房间内被魔法阵和铁链拴住的未知大型动物，非魔大陆物种，疑似米里斯大陆本地珍奇生物。
- 原文依据："只见在发出微弱光芒的魔法阵中央，有一只被铁链拴着的大型动物躺在地板上。虽然因为太暗而看不清楚，但是我在魔大陆上没看过那样的动物。是米里斯大陆的生物吗？"

## 五、物品 / 道具 / 武器
- 名称：跨大陆货币系统与购买力体系
- 说明：
  - 魔大陆货币：绿矿钱、铁钱、屑铁钱、石钱。
  - 米里斯大陆货币：米里斯银币、米里斯大铜币、米里斯铜币。
  - 兑换实例：鲁迪乌斯所持魔大陆货币“绿矿钱两枚、铁钱十八枚、屑铁钱五枚、石钱三枚”，在官方汇兑处扣除手续费后，兑换为“米里斯银币三枚、米里斯大铜币七枚、米里斯铜币两枚”。
  - 购买力参考：赞特港贫民窟低级旅社住宿费用为一晚大铜币三枚（不含餐费）。
- 原文依据："以魔大陆的货币来计算，我们只有绿矿钱两枚、铁钱十八枚、屑铁钱五枚以及石钱三枚。兑换之后，成了米里斯银币三枚、米里斯大铜币七枚、还有米里斯铜币两枚。……在贫民窟附近落脚。一晚大铜币三枚，吃饭要另外付钱，也没有提供其他服务。"

- 名称：走私联络暗语与暗号
- 说明：
  - 仓库接头暗语：“嗨，史提夫。海边的珍过得好吗？”，身份表明为“是主人派我来领取货物”。
  - 接头介绍人假名：“迪兹”。
  - 据点敲门节奏暗号：“咚～咚～咚咚～咚～咚咚～”。
- 原文依据："「嗨，史提夫。海边的珍过得好吗？」据说这是暗语。……「是主人派我来领取货物。」……莫霍克发型男在入口敲了敲门。咚～咚～咚咚～咚～咚咚～敲门方式大概也有什么既定规则吧。……「你是谁介绍的？」「是迪兹。」迪兹是贾尔斯指示我提出的名字。"

## 六、历史 / 传说 / 事件
- 事件名：赞特港走私据点突袭救出行动
- 内容：鲁迪乌斯与瑞杰路德前往林中走私据点接应并解开瑞杰路德的手铐，发现被关押的七名受害兽族幼童后，双方决定全歼据点内所有走私保镖与守卫。瑞杰路德持枪展开无声杀戮，鲁迪乌斯则前往牢房营救被囚儿童。
- 原文依据："「这里有小孩子被抓，共七个。是兽族的小孩。似乎是被强行掳来，在这里也能听见哭声。……把他们杀光。……那些家伙可是绑架小孩的犯人啊！」……莫霍克发型男是第一个牺牲品。瑞杰路德无声无息地给他致命一击，然后冲向楼梯……当我到达房门前时，一楼开始传来惨叫声。"

## 七、社会规则 / 习俗 / 文化
- 内容：大森林雨季对交通出行与赞特港住宿的连锁影响：大森林每年雨季降下持续三个月暴雨并引发大洪水，道路完全无法通行；加上特殊高价魔物出没，导致滞留避雨的旅客与赶来猎捕魔物的冒险者将赞特港优良旅社全数订满。
- 原文依据："「雨季已经快要来临，比较好一点的地方大概全都满房了吧」。雨季指的是米里斯大陆「大森林」地区的特有天候，据说会降下持续约三个月的大雨。大森林里会淹起大洪水，道路当然无法通行。因此，似乎有很多客人在这个时期会住宿比较久。……而且那个魔物身上的素材可以卖得高价，因此这时期会有很多冒险者选择在此长期停留。"

- 内容：走私组织防范留证与残酷处置背叛者的行规：走私黑道避讳留下书面文字合同（且部分种族没有指纹），一切凭口头承诺与黑话运作；对泄密者与违约背叛者，走私组织会派出秘密培养的专职刺客追杀至死。
- 原文依据："「我想你应该知道，千万别泄漏这里的事情。要是你敢说出去……」「我很清楚。」……是因为有些种族没有指纹吗？还有，大概也因为彼此都不想留下书面文章吧。毕竟还是不要有具体证据最好。……要是有顾客背叛，走私组织会派出他们自己培养的刺客。等待背叛者的下场只有凄惨的死亡。"

- 内容：米里斯大陆对恶魔“Dead End”的低知晓度：在魔大陆威震各地的斯佩路德族“Dead End”恶名，在米里斯大陆知名度甚低，冒险者无法依赖借用该名号制造震慑效果。
- 原文依据："调查之后，我才知道「Dead End」这号人物在米里斯大陆上似乎不太有名。或许无法继续利用知名度的日子很快就会到来。"

## 九、角色认知 vs 客观事实
- 角色以为：走私看守人员（莫霍克发型男与白发执事）以为瑞杰路德是普通的被擒奴隶，且听信鲁迪乌斯“他会听从指示”的解释，以为解开手铐也不会有暴走危险。
- 原文是否暗示另有真相：是
- 原文依据："「喂！你为什么有办法打开手铐！」莫霍克发型男满脸惊慌。「不要紧，他会确实听从我的指示。」「真……真的吗？」听到我的回答，莫霍克发型男换上略为放心的表情。我把枪交给瑞杰路德。「不过，会听话并不代表他不会抓狂。」「咦？」莫霍克发型男是第一个牺牲品。瑞杰路德无声无息地给他致命一击"

- 角色以为：鲁迪乌斯初见瑞杰路德脸色极为难看、额头青筋暴跳时，以为他只是被当成奴隶关押了一星期、饿着肚子在闹脾气。
