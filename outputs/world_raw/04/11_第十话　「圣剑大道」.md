# 第十话　「圣剑大道」 世界设定提取

## 一、地理与场所
- 名称：圣剑大道
- 内容：由圣米里斯开拓、笔直贯穿整座大森林并直达米里斯神圣国首都的宏伟干线大道。道路延伸至青龙山脉后，于狭窄的谷底将整座山脉一分为二，宽度约容两辆马车交错而过。整条大道残留有圣米里斯的强大魔力加护，路面完全平整干燥，即使周围大水蔓延也绝不起泥，常年没有任何魔物出没，且受加护庇佑几乎不会发生落石塌方。沿途每隔固定距离开辟有旅行露营地，道路两侧野生辛香料植物繁茂。乘马车穿越整座大森林仅需一个月，穿行青龙山脉山谷需三天，是穿越大森林通往人族领地的核心通道。
- 原文依据："圣剑大道。这是一条直线贯穿大森林的道路。过去由圣米里斯开拓出的这条大道上充满魔力。明明周围淹大水，大道本身却很乾燥。此外，据说这条路上不会出现任何魔物。我们接下来要使用德路迪亚族送的马车沿着这条路移动，前往南方。""这条大道真的是一路直线。而且这条直线会通往地平线的另一端，米里斯神圣国的首都。完全没有出现魔物，排水功能又特别优异。""每隔一段固定距离，大道旁边就会出现类似露营区的地方。""大道旁边长着很多能当成辛香料使用的花草。""一个月，才花了短短一个月就成功穿越整座大森林。道路从头到尾都是一直线，也完全不会出现魔物，可以专心移动。""圣剑大道逐渐深入青龙山脉。宽度差不多可让两辆马车交错而过的这条路把整座山一分为二。我们的位置是谷底。不过，或许是因为米里斯的加护，听说很少出现落石。如果没有这条路，要前往米里斯必须往北绕很大一圈。因为尽管这座山很少出现青龙，依旧有许多魔物，要通过会伴随着极大风险。""我们花了三天穿过山谷，完全脱离大森林的范围。继续往前就会进入米里斯神圣国。终于回到人族的领域。"

- 名称：铁匠城（青龙山脉山谷入口城镇 / 大道分岔点）
- 内容：座落于青龙山脉山谷入口处的重要枢纽聚落，由矿坑族自主运营的旅馆商业街，未设冒险者公会。作为著名的锻造工坊城镇，街道两旁遍布武器店与防具店，以出产价格公道且质地优良的刀剑甲胄闻名。该地亦是大道的关键分岔口：沿山脉向东可至矿坑族本土城池，向东北通达长耳族领地，向西北通往小人族领地。邻近山中存在天然温泉资源，但在雨季刚过时山道泥泞难行。
- 原文依据："在通过青龙山脉的山谷入口有一个城镇。这城镇是矿坑族经营的旅馆街，没有冒险者公会。不过似乎是出名的铁匠城，可以看到一间接着一间的武器店和防具店。基斯告诉我这里贩卖的剑不但便宜品质也好""根据基斯的情报，这里似乎是大道的分岔点。沿着山脉往东移动会到达矿坑族的城市，往北东是长耳族，往北西则是小人族的领域。或许正是因为地理位置的问题，这城镇里才没有冒险者公会。另外，山上似乎有温泉。""是山里冒出的热水，在那里洗澡会非常舒服喔。""因为雨季才刚结束，我想山上应该很难走喔。"

## 二、组织与势力
- 名称：米里斯教团
- 内容：异世界最庞大的主流宗教教派之一。尊崇远古劈山开路的圣米里斯为开山祖师，其开拓圣剑大道的传说神迹与残留千年的魔力奇迹，构成了教团庞大宗派声望与崇高社会影响力的基石。
- 原文依据："开拓出这条大道的人，是世界主流宗教之一的米里斯教团之开山祖师──圣米里斯。""让人能够理解为什么米里斯教团会是力量那么强大的宗教。"

- 名称：冒险者队伍体系与杂务分工（以基斯昔日队伍为例）
- 内容：高阶迷宫攻略队伍（通常为六人编制）内部高度重视专精型战斗人才（如纯剑术、纯魔术等单一极致专精者）；而通晓营地杂务、后勤整备、野外生火烹饪与探索技能的万能型人才（如基斯），虽能保障全队稳定运转，但往往因缺乏不可替代的顶尖战斗硬实力，在特定队伍解散后难以被其他高水准队伍单独招募（因高级队伍通常由全员分担杂事）。
- 原文依据："他以前似乎待过有能力潜入迷宫的队伍。那是一支六人队伍。据说除了他以外，其他人都是一些只会做一件事的笨拙家伙。""话虽如此，基斯是个万能的人才。尽管欠缺剑术和魔术的才能，但除此之外什么都会。因此，他认为自己一定很快就能找到下一支队伍。结果是惨败。明明当时基斯是个还算有名的冒险者，却没有其他队伍愿意收留。基斯什么都会。只要是冒险者会做的事情，基本上他都没问题。换句话说这也代表基斯会做的事情，全都是能找到别的人来处理的事情。也就是在高层级的队伍里会由所有人共同分担的杂事。所以基斯察觉到。只有那支队伍是自己能栖身的地方。因为有那些笨拙的家伙，自己的价值才能发挥。"

## 三、力量体系 / 魔法 / 技能
- 名称：圣米里斯残留魔力（圣道加护场）
- 规则：远古圣米里斯在此地遗留的长存神圣魔力。其魔力场具备强大的环境改造与保护机制：有效驱散与阻绝一切凶恶魔物、赋予路面极强的排水避水性能（即使大雨倾盆道路依然干燥顺畅）、以及镇伏青龙山脉松散岩壁以避免山谷落石坍塌。
- 原文依据："过去由圣米里斯开拓出的这条大道上充满魔力。明明周围淹大水，大道本身却很乾燥。此外，据说这条路上不会出现任何魔物。""照理说会觉得这故事未免太扯了吧，然而这条路上却还残留着圣米里斯的魔力。证据就是直到目前为止，我们真的完全没碰上魔物。马车也不曾因为道路泥泞而放慢速度。""不过，或许是因为米里斯的加护，听说很少出现落石。"

- 名称：七大列强石碑的动态自动更新魔术
- 规则：遍布于世界各地的及膝石碑系统。其正面刻有各列强的专属纹章与位次，核心蕴含未知的自适应更新魔术机制，能够实时感知全世界巅峰战力的变动、退位与陨落，并自动对石碑表面的文字与图案进行改写刷新。
- 原文依据："那东西大概高度及膝，表面上刻着奇妙的图案。有七个图形围住一个文字，正中央的文字应该是斗神语的「七」吧？""「这石碑看起来也相当古老，说不定现在顺序已经有了变化。」我喃喃发表意见，基斯却摇了摇头。「不，听说这东西会靠魔术自动变化。」"

- 名称：世界马匹的生理/魔力持久机制
- 规则：异世界驯养马匹具备超乎寻常的耐受力，每日高强度奔跑十小时几乎不知疲惫，休整一夜即可完全恢复充沛体力，推测其体内具有某种支持肉体机能运转的潜在魔力系统。
- 原文依据："这个世界的马不知道什么叫作疲劳。一天里面几乎有十个小时都在不停往前跑，可是到了隔天依旧活蹦乱跳。或许有用到某种魔力吧"

- 名称：魔力的负面效应假说
- 规则：魔力在带来高度便利与神迹效果的同时，亦伴随着不可控的剧烈负面影响，包括诱发常规野兽异变为凶残魔物、以及诱发造成两大陆空间混乱的大规模转移灾难。
- 原文依据："魔力这种东西的确很方便。然而，魔力也会引起负面效应，例如会让动物变成魔物，还会把两个小孩从中央大陆转移到魔大陆。所以魔力充沛也是一件很恐怖的事情。"

## 四、种族 / 生物
- 名称：兽族（生理特征与幼童服饰）
- 特征：具备动物耳与尾巴的亚人种族。幼年雌性在就寝时习惯穿着后臀特设开孔以伸出尾巴的轻薄皮革连身裙。
- 原文依据："她们身上穿着单薄的皮制连身裙，屁股位置开了个洞，露出尾巴。是兽族特有的睡衣。"

- 名称：猴面魔族（基斯的种族归属）
- 特征：面貌呈猴类特征的魔族分支，基斯即属于此族。自幼代代流传关于斯佩路德族残暴凶悍的恐惧传说。寿命远长于普通人族，三十年前即以年轻冒险者身分在大陆活动。
- 原文依据："不知为何来了个猴脸男。""「当然很怕啊。因为我也是魔族，从小就经常听说斯佩路德族有多恐怖。」""毕竟是三十年前的事情嘛。基斯开始叙述。……当基斯还是个新手冒险者时曾遭到魔物袭击差点丧命，那时似乎是瑞杰路德救了他。"

- 名称：大森林普通野生动物
- 特征：大森林中除了具备威胁的魔物之外，亦栖息着兔子、野猪等纯粹的普通自然野兽，其肉质相较魔大陆更为优良肥美，简易烤制即可成为鲜美肉食。
- 原文依据："大森林的食材品质优于魔大陆。不只有魔物，也有普通的动物，例如兔子或山猪之类的普通野兽。虽说这类动物的肉只要用火烤一下就很好吃"

- 名称：青龙山脉栖息魔物群
- 特征：密集分布在青龙山脉险峻峰峦与非道路密林中的各类凶暴魔物，对试图越过山岭的外来者构成极高生存威胁。
- 原文依据："因为尽管这座山很少出现青龙，依旧有许多魔物，要通过会伴随着极大风险。"

## 五、物品 / 道具 / 武器
- 名称：七大列强石碑
- 说明：散见于主要道路旁的及膝古老石质立碑。正中刻有斗神语字符「七」，外围环绕七枚当前天下前七强战士的专属纹章图案，内部铭刻有自动感应并调整排名的常设魔术。
- 原文依据："某天，我在休息地点的路旁发现奇妙的石碑。那东西大概高度及膝，表面上刻着奇妙的图案。有七个图形围住一个文字，正中央的文字应该是斗神语的「七」吧？""那是各个人物的纹章，显示出目前的七人。""听说这东西会靠魔术自动变化。"

- 名称：铁匠城武器与铠甲
- 说明：青龙山谷入口处矿坑族工坊打造贩售的各类刀剑与护具，做工精湛、造价廉宜，但重型甲胄兵刃对年轻体弱者而言较为沉重。
- 原文依据："出名的铁匠城，可以看到一间接着一间的武器店和防具店。基斯告诉我这里贩卖的剑不但便宜品质也好""被负责顾店的矿坑族嘲笑说这些东西恐怕不适合小朋友。"

- 名称：兽族特制皮质连身睡衣
- 说明：专为长有尾巴的兽族量身剪裁的薄皮革质地睡袍，在后侧臀部留有孔洞以便尾巴自由摆动。
- 原文依据："她们身上穿着单薄的皮制连身裙，屁股位置开了个洞，露出尾巴。是兽族特有的睡衣。"

- 名称：大森林野生辛香植物
- 说明：大森林道路两旁天然丛生的具有浓烈香气的草叶与木本种子，经研磨调制后可作为强力调味香料，大幅改善野外肉食风味。
- 原文依据："大道旁边长着很多能当成辛香料使用的花草。""他变魔法般地利用我采收的野草和树木种子来制造出辛香料，赋予肉华丽丰富的味道。"

## 六、历史 / 传说 / 事件
- 事件名：圣米里斯开拓圣剑大道与斩魔王传说
- 内容：米里斯教团传颂的远古神迹。传说开山始祖圣米里斯挥剑斩击，以破天之威斩裂山脉、劈开密林开辟出贯穿大陆的通道，并顺势将魔大陆上的魔王拦腰斩断，该道路亦因此被定名为「圣剑大道」。
- 原文依据："开拓出这条大道的人，是世界主流宗教之一的米里斯教团之开山祖师──圣米里斯。据说当初米里斯拿剑一挥，结果不但劈开山脉和森林，还把魔大陆上的魔王也一刀两断。所以根据这个传说，这条路被称为「圣剑大道」。"

- 事件名：七大列强榜单创立
- 内容：第二次人魔大战落幕之际，被公认为当世第一强者的「技神」设立了「七大列强」这一荣誉榜单，评选出世间最强悍的七大战士，并在世界多地立下魔法石碑。传说其创立意图是为了网罗天下强者以寻求能战胜自身之人。
- 原文依据："那是七大列强。……就是这世界上最强的七名战士。据说这是在第二次人魔大战结束那时，由被称为「技神」的人物所选出的名单。技神是当时被视为世上最强的人物。而这样的人物选出了世界最强的七人。至于这块石碑，就是用来确认这一份名单。""有听说过是为了找出能打倒自己的人，但我也不清楚详情。"

- 事件名：拉普拉斯战役引发的七大列强断代与衰颓
- 内容：在四百年前的拉普拉斯战役中，除技神未现身外，其余列强几乎全员参战，导致惨重伤亡（三人阵亡、一人失踪、一人遭到封印），仅龙神全身而退。此后列强席位虽由后补人员递补并经历数百年争夺，但整体实力已远无法企及昔日「最强」之名；且目前榜单前四席（技神、龙神、斗神、魔神[封印中]）长期全体失联隐匿，导致七大列强威名逐渐瓦解，甚至被世人淡忘。
- 原文依据："因为在拉普拉斯战役之后，『七大列强』的名声不再闻名天下。……因为拉普拉斯战役时产生剧烈变动，这里面有一半人都不知去向。除了技神，听说当时的『七大列强』似乎全都参加了拉普拉斯战役。然而，其中三人死亡，一人下落不明，一人遭到封印。当时似乎只有龙神四肢健全地活了下来。基本上，当时被视为候补名单的人们往上递补进入排行榜，之后还花了数百年争夺后段排名，然而他们的实力却和『最强』这名词有着遥不可及的距离。况且目前位居前四名的人都不知身处何方。技神：下落不明。龙神：下落不明。斗神：下落不明。魔神：遭到封印。……因此『七大列强』逐渐没落，也从人们的记忆里慢慢消失"

- 事件名：瑞杰路德三十年前营救基斯与基斯前队伍解散
- 内容：三十年前基斯尚为新手冒险者时遭遇魔物袭击濒死，获瑞杰路德救助得以生还。其后基斯曾效力于一支能攻克迷宫的精锐六人队，后因指导一名女性队友学习厨艺追求队内男成员，促成两人成家退队，继而引发整支队伍失去核心主力与凝聚力而迅速解散；基斯随后体会到自身专精短板，遂逐步淡出正规冒险者领域。
- 原文依据："毕竟是三十年前的事情嘛。……当基斯还是个新手冒险者时曾遭到魔物袭击差点丧命，那时似乎是瑞杰路德救了他。""他以前似乎待过有能力潜入迷宫的队伍。那是一支六人队伍。……有一天，一个女性队友对基斯表示她想要学会烹饪。目的是为了追到队伍里的另一位男性成员。……那两人再怎么说都是重要人物，离开之后让队伍陷入混乱。争执和漠不关心席卷整个队伍，也无法好好处理委托，很快就决定解散。""之后，他算是半放弃冒险者这个职业。似乎决定改以赌徒的身分活下去。"

## 七、社会规则 / 习俗 / 文化
- 内容：兽族家庭对人类异性的防范训诫。兽族长辈在教育晚辈时具有高度警戒心，向幼童传授「人族男性始终处于发情状态」的刻板警示，告诫年轻雌性随意接近极易招致侵犯。
- 原文依据："可是裘耶斯叔叔有说过人族男性随时都在发情，要是随便靠近会遭到侵犯。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯看到石碑外观沧桑古老，以为石碑上所刻的七大列强名单仅仅是古代固定的静态名单，现实中的位次或许早已脱节变动。
- 原文是否暗示另有真相：是。
- 原文依据：基斯纠正指出该石碑是由未知的自动感应魔术所构建，一旦现实中各列强排名发生变化，石碑文字与纹章便会自动刷新演变（第 721-729 行）。

- 角色以为：基斯深信昔日迷宫队伍的解体覆灭全因自己破戒向女性队友传授了烹饪技能，并由此将不教女性做菜当作不可逾越的禁忌。
- 原文是否暗示另有真相：是（原文说明队伍崩溃的根本原因在于两名不可或缺的核心战力因婚恋离队后造成的队伍结构失衡与士气瓦解，传授烹饪仅为偶然导火索；同时基斯离开后因自身仅通杂务而缺乏核心专精战力，无法被其他高阶队伍接纳）（第 544-580 行）。
