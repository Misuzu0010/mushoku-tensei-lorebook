# 第八话　「十万火急」 世界设定提取

## 一、地理与场所
- 名称：大森林・德路迪亚族村庄中心
- 内容：大森林树上村庄的核心区域，建有主要居所。火灾初起时火势尚未延烧至此，但遭受到人族武装走私贩的纵火协同突袭，多处房屋着火树木倒塌，后被鲁迪乌斯施展大雨魔术扑灭。
- 原文依据："火势还没有延烧到村子中心。……然而不知道是因为人族的数量比较多，还是因为眼睛鼻子已经因为浓烟受创，很遗憾他们都无法顺利行动……"
- 名称：赞特港
- 内容：米里斯神圣国管辖的港口城市，设有造船厂与官方管理机构（官员）。雨季来临前夕有最后一班客/货轮出海，雨季期间海面封航三个月；米里斯官员在此曾接受走私贩贿赂对人口拐卖视而不见，并在港口前与德路迪亚战士团形成对峙，最终赔款妥协。
- 原文依据："因为他们袭击了雨季前的最后一班船，所以赞特港的官员出面干涉。官员宣称雨季前的船只载运了重要的货物，袭击船只的行为是重罪。"、"然而赞特港却完全没有抓到任何犯人，甚至官员还收取贿赂，对此视而不见。"、"双方甚至似乎在赞特港的入口前对峙起来。最后，赞特港方面做出退让，决定对兽族支付高额的赔偿金。"、"为了干这一票，他甚至威胁造船厂老板偷偷造了一艘船……"
- 名称：阿斯拉王国
- 内容：中央大陆的大国，国内有特别嗜好兽族幼童并愿意斥巨资购买的贵族家庭。
- 原文依据："德路迪亚族的小孩可以卖到相当高的价钱。阿斯拉王国那边有特别喜欢兽族的变态贵族，那一族愿意花大钱买这些小孩。"

## 二、组织与势力
- 名称：德路迪亚战士团
- 内容：德路迪亚族的精锐战士武装集团，由族长裘斯塔夫与裘耶斯统率。嗅觉极其敏锐，擅长利用树林和敏捷动作战斗；在雨季前夕为防范拐卖而严加戒备，但因走私集团声东击西被调往外村援防，后在赞特港集结与米里斯官员对峙。
- 原文依据："抓准时机把情报放给德路迪亚的战士团，让他们碰上你们。"、"在裘耶斯的号令下，村里召集了战士团，双方甚至似乎在赞特港的入口前对峙起来。"
- 名称：走私犯罪网络与诱拐集团联盟
- 内容：大规模联合犯罪网络，收买赞特港官员，在雨季前雇佣当地所有诱拐团伙并组建武装集团，同时突袭多个兽族村庄，暗中策划劫持圣兽及大量幼童送往魔大陆贩卖。
- 原文依据："这次的绑架事件似乎是相当特殊的案例。是走私组织筹划的大规模绑架作战。……他们雇用附近一带的所有诱拐集团成员并暂时按兵不动。之后到了某个时期才一口气袭击各地，绑走女性和小孩。"
- 名称：贾尔斯的分遣队
- 内容：贾尔斯所属的走私组织小分支。因走私组织内部派系倾轧互不团结，贾尔斯故意向德路迪亚战士团走漏主队情报扯同伙后腿，同时私造船只，企图在村落防守空虚时独自掠夺德路迪亚族小孩大赚一笔。
- 原文依据："我们的组织并没有那么团结，我当然要好好扯一下其他人的后腿。……放走同伙抓到的奴隶，卖掉自己抓到的奴隶。"、"他找了能相信的同伴一起绑走小孩，想要自己大赚一笔。"
- 名称：米里斯神圣国官方（赞特港管理机构）
- 内容：与兽族大森林族长签署了禁止拐卖兽族为奴的和平条约；但赞特港部分官员腐败堕落，收受走私集团贿赂，对大规模人口拐卖装聋作哑，在兽族战士团兵临城下后被迫支付巨额赔偿。
- 原文依据："在米里斯神圣国和大森林的族长之间，有订下禁止诱拐兽族以及将兽族作为奴隶的条约。"、"然而赞特港却完全没有抓到任何犯人，甚至官员还收取贿赂，对此视而不见。"、"双方甚至似乎在赞特港的入口前对峙起来。最后，赞特港方面做出退让，决定对兽族支付高额的赔偿金。"

## 三、力量体系 / 魔法 / 技能
- 名称：上级水魔术「大雨」
- 规则：将魔力聚集压缩并在高空制造大范围灰色雨云，通过调控云层膨胀释放倾盆暴雨（如同瀑布），能在极短时间内大面积熄灭森林火灾。操作技巧源自于「豪雷积雨云」的控云原理。
- 原文依据："首先来灭火吧，使用的魔术是上级水魔术「大雨」。我把魔力灌注在右手上，在空中制造出灰色的雨云。接着设定出偏大的威力和范围。……『豪雷积雨云』让我学会如何操控云。首先要压抑住魔力使齐聚集凝结并转化成云，接着促使云层膨胀变大却不至于直接化为雨水落下。"
- 名称：初中级水/土魔术配合战术（「泥沼」、「岩炮弹」）
- 规则：以「泥沼」瞬间破坏敌方脚下立足点使其失去平衡倒地，再无缝接续发射「岩炮弹」击昏对手，形成极高胜率的连续打击。
- 原文依据："『泥沼』。我在他们脚边制造出泥沼。突然失去立足点的那些人失去平衡一一倒下。『岩炮弹』。我立刻趁机击出岩炮弹，打昏那些家伙。真简单。"
- 名称：火魔术「Explosion」与冲击波
- 规则：在目标近身制造局部爆炸阻碍视线与动作；或在二人之间激发空气冲击波使双方强制拉开距离。
- 原文依据："『Explosion』！配合圣兽跳起来的动作，我在贾尔斯眼前制造出小规模的爆炸。"、"使用魔术，让贾尔斯和人质之间出现冲击波。……人质与贾尔斯双双被弹飞，距离也因此拉开。"
- 名称：北神流（阿托菲派与奇诡派）
- 规则：
  - 阿托菲派：北神流分支，不使用奇特偏门招式，专精于实战与一对多战斗；擅长利用人肉盾牌、挟持人质限制对手，并擅于利用动作诱导对手走位（如将对手逼退至可拾取武器的尸体旁）。
  - 奇诡派与特定战术习惯：包含各种阴招暗器（如鞋尖藏短剑以腿踢暗射）。北神流剑士听到奇诡派秘术招名“落泪弹”（致盲用的撒灰袋）时，会产生下意识条件反射抬起双手护住面部，从而露出巨大破绽。
- 原文依据："那是北神流，而且是阿托菲派，不使用奇招，擅于一对多战斗的实战派。"、"我就是北圣『清扫专家』贾尔斯。"、"北神流其实很有趣喔，因为连利用人质战斗的方法都有。"、"是脚，贾尔斯利用脚来丢出短剑。大概是鞋子里预先藏好的暗器！"、"『北神流奇诡派妙计，落泪弹！』……『北神流的家伙只要听见落泪弹这名词，就会立刻用双手遮住脸！』"
- 名称：魔眼（预知眼）的战斗局限
- 规则：预知眼虽能看见未来动作影像，但若对手利用隐蔽死角暗器（如脚尖射出短剑）或施展者身体速度跟不上时，即使预知未来也难以躲避；且过分依赖预知影像容易被经验丰富的老手诱导走位。
- 原文依据："一瞬间，我无法理解自己看到的影像。也无法理解贾尔斯为什么要做这种动作。……回神时，才发现从正上方掉下来的短剑已经贯穿我的脚背。……就算看得到未来，这样根本没有意义。"、"这时我才注意到，不知何时自己已经往后退到兽族战士的尸体旁边。……原来我一直受到他的诱导。"

## 四、种族 / 生物
- 名称：兽族（德路迪亚族）
- 特征：对烟味和强刺激气味极其敏感脆弱，黑烟会熏损其眼睛与鼻子，导致嗅觉和视力受挫丧失战力；但只要用水洗净面部恢复嗅觉，就能凭借惊人的身体机能与嗅觉追踪重整旗鼓；能手脚并用在林木间高速跳跃飞奔。
- 原文依据："尽管兽族的战士们试图阻止这些状况，然而不知道是因为人族的数量比较多，还是因为眼睛鼻子已经因为浓烟受创，很遗憾他们都无法顺利行动……"、"『刚才的雨让我把脸洗乾净了，只要鼻子能用，才不会败在你们这些小喽啰的手下！』"、"有几个人从树上或草丛中一跃而出，也有人先打倒眼前的敌人，然后手脚并用地赶来。"
- 名称：圣兽
- 特征：德路迪亚族的守护神；体魄强健，勇猛忠诚，即便被击飞重撞树木也能迅速恢复并再度加入战斗；具备高度战斗智慧，会配合友方动作绕背偷袭、撕咬敌人握剑手臂或肩膀制造空隙；性格亲人，喜好玩捡拾丢掷武器的游戏，欢喜时会剧烈摇尾巴。
- 原文依据："德路迪亚族的守护神，『圣兽』。尽管我不懂他们为什么会想要绑走这种东西，不过毕竟圣兽是特别的生物，似乎有很多人想要得到它。"、"白色物体咬住贾尔斯拿剑的那只手。"、"圣兽咬住贾尔斯的肩膀。……圣兽被他打飞出去，狠狠撞上树木。"、"我充满戒心地观察贾尔斯，然后把掉在他附近的剑拿起来丢向远方。于是，圣兽也跟着冲出去，然后咬着剑回来。尾巴还摇得非常起劲。"
- 名称：斯佩路德族（瑞杰路德）
- 特征：额头上的第三只眼具备透视与远距离搜寻能力，能够无视遮蔽物或气味伪装，直接查明被绑架者被藏匿在港口哪艘船只中。
- 原文依据："然而裘斯塔夫却表示无法赞同，因为那些家伙懂得如何瞒过兽族的鼻子，所以不知道孩子们被关在哪艘船上。不过基本上，这种问题靠瑞杰路德解决就好。听说他充满自信地回答可以靠额头上的眼睛查明正确的目标。"

## 五、物品 / 道具 / 武器
- 名称：北神流落泪弹
- 说明：装有灰烬的黑色小布袋，掷向敌人面部炸开散布灰烬用于刺激双眼致盲；即使是伪招也能诱使北神流剑士本能护脸。
- 原文依据："『北神流奇诡派妙计，落泪弹！』……是个黑色袋子。……袋子命中贾尔斯的脸，同时有像是灰烬的东西从里面喷出。这似乎是攻击眼睛的手段。"
- 名称：鞋中暗器短剑
- 说明：贾尔斯鞋部特制的隐藏暗器短剑，可在翻腾跳跃中以脚部甩踢抛射，从正上方垂直穿刺对手，极其隐蔽阴险。
- 原文依据："是脚，贾尔斯利用脚来丢出短剑。大概是鞋子里预先藏好的暗器！"
- 名称：走私专用隐蔽船只
- 说明：贾尔斯威胁造船厂老板秘密建造的船只，用于在雨季封航期间偷运奴隶。
- 原文依据："为了干这一票，他甚至威胁造船厂老板偷偷造了一艘船……"

## 六、历史 / 传说 / 事件
- 事件名：大森林雨季圣兽与幼童诱拐事件
- 内容：走私组织利用雨季前夕各村忙碌且海面即将封航三个月的时机，先在各地策动攻击引开德路迪亚主力，随后突袭德路迪亚村拐走圣兽及族长孙女托娜。瑞杰路德与裘斯塔夫在赞特港最后一班船上救出近五十名各村幼童，引发兽族与赞特港官方对峙并索赔；贾尔斯趁德路迪亚守备空虚放火袭村，最终被鲁迪、基斯与圣兽联手制服。
- 原文依据："这次的绑架事件似乎是相当特殊的案例。是走私组织筹划的大规模绑架作战。……雨季会持续三个月。……在裘耶斯的号令下，村里召集了战士团，双方甚至似乎在赞特港的入口前对峙起来。最后，赞特港方面做出退让，决定对兽族支付高额的赔偿金。"、"贾尔斯的计画以失败告终，他被移交给赞特港的官员。"
- 事件名：米里斯神圣国与大森林禁止奴隶条约
- 内容：米里斯神圣国与大森林各族族长之间缔结的正式条约，明文严禁诱拐兽族以及将兽族作为奴隶买卖，违反条约将严重危害两国和平甚至引发战争。
- 原文依据："在米里斯神圣国和大森林的族长之间，有订下禁止诱拐兽族以及将兽族作为奴隶的条约。"、"这是违反条约的行为。如果继续对这种状况不予理会，兽族和米里斯神圣国之间将产生巨大的裂痕。最糟的结果就是引发战争。"

## 七、社会规则 / 习俗 / 文化
- 内容：大森林的雨季持续长达三个月，雨季期间海面无法派船出海，林间积水泛滥无法远行，兽族各村落几乎与外界隔绝无法离村。雨季前夕是防范拐卖与储备物资的关键备战期。
- 原文依据："雨季会持续三个月。为了因应雨季，各村的战士们都拿出全副心力准备，每个村落也都很忙碌。当然，雨季期间无法派船出海。"、"在雨季的期间，几乎无法离开村庄。"
- 内容：圣兽在德路迪亚族中被视作部族的绝对“守护神”，其地位甚至高于族长之亲孙女，当危机发生时，族长会优先调配力量寻找与护卫圣兽。
- 原文依据："德路迪亚族的守护神，『圣兽』。"、"族长裘斯塔夫首先决定放弃孩子们，他组织战士团，命令战士们防卫村子后，自己则带人开始寻找圣兽。看来对于这个村子来说，圣兽是特别的存在。"
- 内容：德路迪亚族等兽族儿童在人类黑市能卖出极高价格，阿斯拉王国的部分贵族格外嗜好购买兽族幼童。
- 原文依据："德路迪亚族的小孩可以卖到相当高的价钱。阿斯拉王国那边有特别喜欢兽族的变态贵族，那一族愿意花大钱买这些小孩。"

## 九、角色认知 vs 客观事实
- 角色以为：贾尔斯被圣兽突袭撕咬后，认为鲁迪乌斯在故意利用训练过的凶犬袭击他，符合“性兽/犬使变态”的卑鄙传言。
- 原文是否暗示另有真相：是。圣兽完全是自发冲出来相助撕咬贾尔斯，鲁迪不仅未指使它，反而在情急之下施展冲击波将人质与贾尔斯弹开拉开距离，在贾尔斯看来却像是在主动配合狗发起攻击。
- 原文依据："果然和传言一样！居然利用狗攻击……真是卑鄙……！"、"到底是什什么鬼传言啊……！不，其实我刚刚啊，反而算是在帮助你耶。"
- 角色以为：鲁迪乌斯在牢中一直怀疑瑞杰路德是否出了连他也无法摆平的事故，或者跟老战士发生冲突，或者在找孩子亲属时耽误。
- 原文是否暗示另有真相：是。瑞杰路德其实是在赞特港最后一班船上救下了五十名被拐孩童，进而引发了兽族战士团与赞特港官方的重大政治军事对峙，耗费了一整周进行交涉与遣返。
- 原文依据："这状况却被贾尔斯趁隙而入。因为裘耶斯把保护村庄的战士团叫去赞特港……"、"为了处理这些交涉和把被抓的孩子们送回父母身边，花了大约一星期的时间。当然我的事情就往后延，被丢着一星期无人闻问。"
- 角色以为：贾尔斯原本计划让斯佩路德族与德路迪亚战士团相斗两败俱伤，趁机偷袭村庄。
- 原文是否暗示另有真相：是。瑞杰路德非但没有和战士团自相残杀，反而凭借额头第三眼直接协助救出五十名儿童，并在赞特港威慑官方，导致贾尔斯偷袭的计划虽然部分达成（引开守军）却最终全盘破产。
- 原文依据："虽然和预定有点不同，不过斯佩路德族到头来还是让德路迪亚的战士团卡在赞特港动弹不得。"
