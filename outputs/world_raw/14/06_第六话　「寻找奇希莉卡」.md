# 第六话　「寻找奇希莉卡」 世界设定提取

## 一、地理与场所
- 名称：利卡里斯镇
  - 内容：魔大陆东北端的环形山城镇，也是鲁迪乌斯在魔大陆成为冒险者的据点。城镇建立在环形山外围斜坡处，入口处有守卫把守，对外来者采取来者不拒的开放态度。镇内有繁荣的多族混杂露天集市、冒险者公会、肉铺等店铺，以及各类档次的冒险者旅社。城镇中央坐落着旧奇希莉卡城。若离开该镇前往下一个城镇，路线通常向南或向西（西南方有山脉阻隔）。
  - 原文依据："利卡里斯镇。这里是我在魔大陆成为冒险者的城镇……我们走下斜玻，绕着环形山的外围移动，来到了入口。"、"基本上魔大陆的城镇都是来者不拒。"、"这个利卡里斯镇位于魔大陆的东北端。如果要前往下一个城镇，不是往南就是往西。我记得西南方向有山脉，往那边去的可能性很低……"、"据说，现在魔王好像滞留在位于这个利卡里斯镇中央的城堡，也就是旧奇希莉卡城。"

- 名称：旧奇希莉卡城
  - 内容：坐落于利卡里斯镇中央的城堡。目前被加斯罗地区的不死魔王阿托菲拉托菲暂时驻留占用，其亲卫队亦布防于城堡及镇上。城堡地下设有培植索卡司草的药草园。
  - 原文依据："据说，现在魔王好像滞留在位于这个利卡里斯镇中央的城堡，也就是旧奇希莉卡城。"、"就连那座奇希莉卡城底下也有栽培呢！"

- 名称：加斯罗地区
  - 内容：魔大陆的一个地区，与利卡里斯镇所在的领地相邻。是不死魔王阿托菲拉托菲统治的领地（本国），阿托菲亲卫队即从加斯罗被传唤而来。该地区地下亦有栽培索卡司草。
  - 原文依据："我等是加斯罗地区不死魔王，阿托菲拉托菲大人的亲卫队。"、"应该是在大约一年前，隔壁领地的魔王大人就千里迢迢来到这里。"、"索卡司草在加斯罗地区也有栽培，我等也知道栽培方法。"

- 名称：盖古拉地区
  - 内容：魔大陆的某个地区，以出产特产美酒闻名。
  - 原文依据："这是因为在一年前，本应由阿托菲大人在这里收下的盖古拉地区特产美酒，被奇希莉卡大人一个人全数饮尽。"

- 名称：梦幻之都迈欧
  - 内容：古老传说都市，位于赤龙山脉一角（赤龙之尾）南方。在第二次人魔大战尾声因龙神与斗神激战导致大陆崩裂开洞而不复存在[存疑：已毁灭]。
  - 原文依据："在梦幻之都迈欧。"、"位于那里北方的赤龙山脉一角，有个被称为赤龙之尾的溪谷。在那个溪谷深处有个龙尾洞窟。丛生在那洞窟深处的，就是索卡司草。"、"在第二次人魔大战的尾声，由于龙神与斗神一番激战，导致大陆开了个大洞，已不复存在。"

- 名称：赤龙之尾与龙尾洞窟
  - 内容：位于古代迈欧北方赤龙山脉一角的溪谷及其深处的洞窟，是历史上最早发现索卡司草的地点。在第二次人魔大战尾声中已随大陆破裂而毁灭。
  - 原文依据："位于那里北方的赤龙山脉一角，有个被称为赤龙之尾的溪谷。在那个溪谷深处有个龙尾洞窟。丛生在那洞窟深处的，就是索卡司草。"、"严格说起来，龙尾洞窟只是最早发现那种草的场所而已。"

- 名称：狼之足爪亭
  - 内容：利卡里斯镇内的冒险者旅社，适合新手投宿。鲁迪乌斯、瑞杰路德、艾莉丝曾在此住宿。
  - 原文依据："在寻找旅社的途中，我们经过「狼之足爪亭」。是我们过去曾住过的旅社。"

## 二、组织与势力
- 名称：阿托菲亲卫队（加斯罗地区不死魔王阿托菲拉托菲亲卫队）
  - 内容：侍奉加斯罗地区不死魔王阿托菲拉托菲的精锐部队，兼具私兵与骑士团性质。全员穿戴带刺的漆黑全身铠甲及全罩式头盔，手持制式佩剑。成员均为散发着强大气场的实力派高手，能熟练使用人类语。队长为灰发老战士，恪守职责且态度谦逊真挚。因一年前阿托菲的美酒被奇希莉卡喝光，整支亲卫队被阿托菲从加斯罗本国传唤至利卡里斯镇执行搜捕命令。
  - 原文依据："我等是加斯罗地区不死魔王，阿托菲拉托菲大人的亲卫队。"、"分散在镇上的那些黑铠士兵，不知该说是那个魔王的私兵还是骑士，总之是亲卫队那样的存在。"、"毫无疑问，亲卫队的成员都是实力派高手。他们散发出一股平凡的骑士团完全无法相提并论的强者氛围。"、"这是阿托菲大人的命令。将奇希莉卡大人交给我们，现在立刻前往城堡。"

- 名称：冒险者公会（利卡里斯镇分部）
  - 内容：魔大陆利卡里斯镇的冒险者组织机构，提供拉诺亚金币与魔大陆货币兑换服务，设有委托留言板。委托发布系统支持指定搜索目标特征并由委托人设定报酬金（搜索类委托等级通常较低）。公会留言板长期保留既往委托，包括多年前发布的转移事件受灾者搜索委托。
  - 原文依据："我们前往柜台，将一些拉诺亚金币换成魔大陆的货币。"、"接着，我们向冒险者公会提出搜索奇希莉卡的委托。……因为只是搜索，所以委托等级很低，不过我将报酬设定得较高。"、"不经意地看到委托留言板的角落，张贴着搜索菲托亚领地居民的搜索委托。"

- 名称：西隆王国（势力声望）
  - 内容：中央大陆南部的人族小国。在魔大陆完全没有国际知名度，其王族身份与纹章无法作为求见魔王的有效凭证。
  - 原文依据："札诺巴出示西隆王国的纹章，并由我进行翻译，提出想要晋见魔王，卫兵却说：『我没听说过那种国家。阿托菲大人很忙的！她不会晋见任何人！』"、"如果是阿斯拉王国、王龙王国或是米里斯神圣国那还好说，毕竟西隆王国只算小国，也是无可奈何。"

- 名称：P-Hunter
  - 内容：利卡里斯镇曾经由贾利尔与威丝凯尔组成的小恶棍冒险者队伍兼宠物店。两年前贾利尔在调教魔兽失败时丧命，一年前威丝凯尔离开城镇，店铺已转让为魔物肉铺。
  - 原文依据："也把这件事告诉P-Hunter他们吧。我记得名字叫作贾利尔和威丝凯尔。是擅长寻找宠物的的小恶棍。"、"那家伙在两年前调教魔兽失败时就挂了。……威丝凯尔？那家伙在一年前就离开这个镇喽。毕竟贾利尔不在她也没办法工作嘛。这间店是威丝凯尔让给我的。"

## 三、力量体系 / 魔法 / 技能
- 名称：土魔术塑形应用
  - 规则：魔法师可消耗魔力直接在路边改变物质构造生成石质或土质椅子，无需繁琐工序即可提供落座用具。
  - 原文依据："我照她的吩咐，使用魔力，在路边生成椅子。"

- 名称：魔眼赋予与报恩规则
  - 规则：魔界大帝奇希莉卡·奇希里斯在接受他人恩情（如挽救其饥饿状态）后会赐予愿望奖励，其最有名的奖励方式是赋予受术者魔眼。但其报恩规则严格限定为"只能有一人获得奖励"。
  - 原文依据："但是，能得到本宫奖励的只有一人！只能有一人而已！就是你，克里夫•格利摩尔。想要什么都尽管说吧。"、"说到魔界大帝奇希莉卡•奇希里斯的奖励，当然就是魔眼……这件事在这个世界相当有名。"

- 名称：不死魔族体质
  - 规则：具有不死属性的高位魔族（如巴迪冈迪与阿托菲拉托菲）拥有跨越数千年的漫长寿命（经历过拉普拉斯战役甚至七千年前的神话时代），且其生理机制似乎天然与普通疾病无缘[存疑：角色推测]。
  - 原文依据："她和巴迪冈迪有血缘关系，应该也具有不死属性。换句话说，她也有可能是从七千年前就活到现在。"、"巴迪冈迪也是如此，那些家伙虽然活了很长一段时日，但是感觉和疾病无缘。"

- 名称：魔力感知辨识
  - 规则：奇希莉卡具备辨识他人魔力特质的能力，能一眼识破人族体内蕴含的异常/庞大魔力（形容鲁迪乌斯为"区区人族却具有恶心魔力的男人"），并借此回忆起故人。
  - 原文依据："喔喔！是你啊！区区人族却具有恶心魔力的男人！本宫当然记得你啦！是本宫当初赐予魔眼的男人。"

## 四、种族 / 生物
- 名称：奇希莉卡·奇希里斯（魔界大帝 / 特殊魔族）
  - 特征：肤色苍白，长有一头蓬松紫色卷发以及类似山羊的角。外形为娇小幼女，身穿带绑缚风格的暴露皮制热裤、皮制小可爱与及膝长靴。具备极强抗饥饿耐受力，可长达半年不进食；一旦大量进食，可维持整整一年不需要吃东西。性格狂妄自大、行事粗线条但极其单纯好哄，常发出响彻城镇的狂妄大笑（"呼～哈哈哈哈哈"）。
  - 原文依据："外貌身材娇小的女孩，一头紫发，穿着绑缚风服装，自称为魔界大帝，特徵是会发出狂妄的笑声"、"及膝长靴、皮制热裤、皮制小可爱。肤色苍白，锁骨、腰部、肚脐和大腿。然后最具特徵的，就是那一头蓬松的紫色卷发，还有类似山羊的角。"、"毕竟本宫已经半年没吃东西了！"、"呼～吃饱了吃饱了。这样还能再撑一年呐！"

- 名称：阿托菲拉托菲（不死魔王）
  - 特征：巴迪冈迪的姐姐，加斯罗地区的统治者。经历过拉普拉斯战役的武斗派魔王，实力极端恐怖（冒犯她会招致一招身首异处）。性格被奇希莉卡评价为"魔王里面首屈一指的蠢货"且难以理性沟通，行事极为粗枝大叶，酷爱美酒。
  - 原文依据："是阿托菲大人。是巴迪大人的姐姐，她是非常可怕的魔王。……毕竟，她可是经历过拉普拉斯战役的武斗派魔王。要是冒犯了她，一招就会让你身首异处。"、"毕竟阿托菲在魔王里面也是首屈一指的蠢货！"、"阿托菲可不是能沟通的家伙！"

- 名称：马头魔族（如诺克巴拉）
  - 特征：魔大陆的魔族之一，长有马头外表，情绪高昂时会发出马嘶声笑，善于察言观色与收集城镇各路情报。
  - 原文依据："那是一名有着马头的男人。"、"诺克巴拉发出马的叫声笑了出来，蹭了蹭鼻子。"

- 名称：刺猬体毛魔族
  - 特征：魔大陆的魔族之一，体表长有如刺猬一般的浓密刚硬体毛。
  - 原文依据："由于一名有着刺猬体毛的男子正在顾店，我决定开口询问。"

- 名称：大王陆龟
  - 特征：魔大陆的爬行类魔兽。肉质坚韧难吃，可风干制成肉干，或以大量辛香料制成烤串贩售。
  - 原文依据："我顺便打听奇希莉卡的情报，作为情报费用，我买了大王陆龟的肉干……大王陆龟的肉还是一样难吃。"、"卖的是使用大量辛香料，魔大陆特有的辣肉串。"、"奇希莉卡不停地吃着大王陆龟的串烧好一阵子。"

- 名称：蜥蜴型魔兽
  - 特征：魔大陆商人与冒险者用来作为骑乘载具的爬行类魔兽。
  - 原文依据："形形色色种族的商人以及冒险者。他们骑着宛如蜥蜴的魔兽。"

## 五、物品 / 道具 / 武器
- 名称：索卡司草 / 索卡司茶
  - 说明：一种原本生长在不见天日的深邃洞窟深处的药草。将其叶子泡茶（煎服）饮用，能将体内杜莱病的病原随粪便一同排出从而实现彻底治愈。味道鲜美可口，各大魔王城堡地下均有栽培，不死魔王血亲代代饮用，据传能大幅延长平均寿命。加斯罗地区亦有成熟栽培技术与盆栽。
  - 原文依据："那种玩意儿，只要把索卡司草的叶子拿来泡茶喝下，就会随大便一起排出了。"、"索卡司草会生长在不见天日的深邃洞窟深处。所以，本宫就下令在所有魔王的城堡地下开始栽培药草！因为索卡司茶很好喝嘛。况且喝了那个的人平均寿命都很长喔，毕竟，每个不死魔王的血亲都在喝嘛"、"索卡司草在加斯罗地区也有栽培，我等也知道栽培方法。如果需要的话也可以帮忙准备盆栽"

- 名称：绿矿钱
  - 说明：魔大陆通行的主要货币。可在冒险者公会用拉诺亚金币兑换。在物价低廉的魔大陆购买力较高，数枚绿矿钱即是一笔颇具诱惑力的情报报酬。
  - 原文依据："将一些拉诺亚金币换成魔大陆的货币。……把将近百枚的绿矿钱一口气丢入金币袋。"、"绿矿钱两枚。如果找到人的话就再付两枚如何？四枚？真……真的好吗？"

- 名称：盖古拉特产美酒
  - 说明：魔大陆盖古拉地区产出的名贵酒品，为魔王阿托菲翘首企盼之物，因被奇希莉卡喝光而引发阿托菲长达一年的缉捕行动。
  - 原文依据："本应由阿托菲大人在这里收下的盖古拉地区特产美酒，被奇希莉卡大人一个人全数饮尽。由于阿托菲陛下引颈翘望喝到那些酒，此举实在是令她怒火中烧……"

- 名称：阿托菲亲卫队制式漆黑铠甲与佩剑
  - 说明：带刺的黑色全身铠甲，配备全罩式头盔，外形不祥凶悍；配有精锐长剑，拔剑动作整齐划一，声势逼人。
  - 原文依据："甚至还穿上漆黑的全身铠甲，全罩式头盔。铠甲上头带刺，给人一种不祥的感觉。"、"所有士兵一起拔出了腰间的剑。剑出鞘后发出了锵的一声，这个声音重叠在一起，发出了震耳欲聋的巨大声响。"

## 六、历史 / 传说 / 事件
- 事件名：第二次人魔大战尾声之战（大陆破裂开洞之谜）
  - 内容：历史传说中认为大陆崩裂出现大空洞是奇希莉卡与黄金骑士交战所致。但奇希莉卡亲口证实，真正原因是第二次人魔大战尾声中"龙神与斗神激烈交战"直接轰穿大陆，导致梦幻之都迈欧及其北方赤龙山脉一角的龙尾洞窟彻底毁灭。
  - 原文依据："在第二次人魔大战的尾声，由于龙神与斗神一番激战，导致大陆开了个大洞，已不复存在。"、"大陆上之所以会开了个大洞，不是因为奇希莉卡和黄金骑士交战的结果导致的吗？不对，奇希莉卡就战斗力来说好像不是那么高……算了。所谓传说这种东西，总是因个人方便而穿凿附会。"

- 事件名：奇希莉卡偷饮美酒遭通缉事件
  - 内容：约一年前，原本运抵利卡里斯镇交付给阿托菲的盖古拉特产美酒被奇希莉卡私自喝光。阿托菲大发雷霆，自加斯罗本国调动亲卫队进驻利卡里斯镇进行为期一年的大搜捕。但由于阿托菲粗枝大叶，下发的通缉画像误画为妖艳成年美女（形似成年梦魔），且不知奇希莉卡实际为幼女形态，导致搜捕一年无果，直到奇希莉卡在街头自报家门才被抓获。
  - 原文依据："这是因为在一年前，本应由阿托菲大人在这里收下的盖古拉地区特产美酒，被奇希莉卡大人一个人全数饮尽。由于阿托菲陛下引颈翘望喝到那些酒，此举实在是令她怒火中烧，所以才从本国将我等亲卫队传唤过来，下令搜索奇希莉卡陛下，然而我等并不知晓陛下如今的尊容，人像画也如各位所见，因此迟迟没有抓到……"

- 事件名：菲托亚领地难民搜索委托的延续与变更
  - 内容：米里斯神圣国的菲托亚领地难民搜索团早已解散且保罗已故，但在魔大陆利卡里斯镇的冒险者公会留言板角落，仍旧悬挂着当年的搜索委托。鲁迪乌斯发现后，将联络人信息由米里斯的保罗更正为难民营的阿尔冯斯。
  - 原文依据："不经意地看到委托留言板的角落，张贴着搜索菲托亚领地居民的搜索委托。明明米里斯的搜索团都已经解散了，这边的搜索委托却依旧维持原样。联络人依旧是米里斯神圣国的保罗。……我前往柜台，将联络人的名字更改为难民营的阿尔冯斯。"

- 事件名：P-Hunter宠物店倒闭与人员变故
  - 内容：两年前贾利尔在利卡里斯镇调教魔兽失败死亡，一年前威丝凯尔离开城镇，原来的宠物店被转让给一名刺猬体毛男子改作魔物肉铺。
  - 原文依据："那家伙在两年前调教魔兽失败时就挂了。……威丝凯尔？那家伙在一年前就离开这个镇喽。毕竟贾利尔不在她也没办法工作嘛。这间店是威丝凯尔让给我的。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯根据传闻认知，以为第二次人魔大战尾声大陆破裂开出大洞是奇希莉卡与黄金骑士交战的结果。
  - 原文是否暗示另有真相：是。奇希莉卡指出真正原因是第二次人魔大战尾声"龙神与斗神的一番激战"将大陆轰穿，所谓奇希莉卡与黄金骑士大战的传说是后人附会。
  - 原文依据："『在第二次人魔大战的尾声，由于龙神与斗神一番激战，导致大陆开了个大洞，已不复存在。』……是说，跟我知道的状况不一样耶。大陆上之所以会开了个大洞，不是因为奇希莉卡和黄金骑士交战的结果导致的吗？不对，奇希莉卡就战斗力来说好像不是那么高……算了。所谓传说这种东西，总是因个人方便而穿凿附会。" (L849-859)

- 角色以为：根据士兵展示的妖艳成熟美女画像，鲁迪乌斯等人一度怀疑奇希莉卡是否在数年间迅速长成了成年美女，或阿托菲不知道奇希莉卡是幼女。
  - 原文是否暗示另有真相：是。奇希莉卡并未长大，依然是幼女形态；造成误导的原因是阿托菲本人粗枝大叶，胡乱提供了成年美女画纸，且亲卫队全员此前并未见过奇希莉卡如今的幼女尊容。
  - 原文依据："『魔王大人对这方面很粗枝大叶，搞不好她觉得年龄根本无关紧要。』" (L487)、"然而我等并不知晓陛下如今的尊容，人像画也如各位所见，因此迟迟没有抓到……" (L1011)

- 角色以为：鲁迪乌斯以为索卡司草最早发现地已毁灭，可能已绝迹，或者必须组建百人冒险队深入凶险万分的未开拓迷宫地下采撷。
  - 原文是否暗示另有真相：是。虽然原始野生洞窟被毁，但奇希莉卡早在远古就命令各大魔王在城堡地下大规模人工种植，且至今奇希莉卡城和加斯罗城堡地下均有栽培，亲卫队甚至熟知栽培方法并能准备盆栽。
  - 原文依据："所以，本宫就下令在所有魔王的城堡地下开始栽培药草！……就连那座奇希莉卡城底下也有栽培呢！" (L875, 887)、"索卡司草在加斯罗地区也有栽培，我等也知道栽培方法。如果需要的话也可以帮忙准备盆栽……" (L993)

- 角色以为：札诺巴以为凭借西隆王国第三王子的正统身份与王家纹章，足以让城堡守卫放行晋见魔王阿托菲。
  - 原文是否暗示另有真相：是。客观事实是西隆王国只是人族小国，在魔大陆毫无威望与知晓度，直接被魔大陆守卫鄙视并拒之门外。
  - 原文依据："札诺巴出示西隆王国的纹章，并由我进行翻译，提出想要晋见魔王，卫兵却说：『我没听说过那种国家。阿托菲大人很忙的！她不会晋见任何人！』" (L535-538)
