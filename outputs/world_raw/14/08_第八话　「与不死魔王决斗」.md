# 第八话　「与不死魔王决斗」 世界设定提取

## 一、地理与场所
- 名称：利卡里斯周边遗迹与地下监狱
  - 内容：位于魔大陆阿托菲领地利卡里斯城附近的遗迹。地下监狱深处隐藏着古代转移魔法阵，可直通甲龙王佩尔基乌斯的空中要塞。阿托菲军在决斗前已先行占领并派士兵进入该洞穴探索。
  - 原文依据："虽然，一旦将转移魔法阵连结到利卡里斯，吾也应该要多少考虑到这样的可能性才是。""他正好到达地下监狱的入口。""阿托菲比我们抢先抵达这里。想必当时便已发现通往转移魔法阵的入口，命令士兵进入里面探索。"
- 名称：空中要塞（佩尔基乌斯城堡 / 混沌城）
  - 内容：甲龙王佩尔基乌斯居住的浮空城堡。城内设有医务室，有古代转移魔法阵与魔大陆利卡里斯地下监狱相连。被误入魔法阵的阿托菲黑铠士兵弄脏了鲜血，引来佩尔基乌斯亲自反向突入战场。战后希瓦莉尔停止了该转移魔法阵，切断了空中要塞通往魔大陆的道路。
  - 原文依据："「你那些肮脏士兵的鲜血，弄脏了吾的城堡。」""因为空中要塞被魔族大闹了一番。""当所有人都完成转移后，希瓦莉尔停止了转移魔法阵。这样一来，就没有通往魔大陆的道路了。""因触电负伤的我们，被送往医务室。"

## 二、组织与势力
- 名称：阿托菲军（黑铠亲卫队）
  - 内容：不死魔王阿托菲拉托菲麾下的精锐士兵部队。全员身穿具备高魔术抗性的黑色铠甲，由老练战士兼魔术师穆亚统帅，受过严格战术训练，能在受到大范围冰结时全员协同咏唱火魔术解除冰冻。
  - 原文依据："周围所见都是黑铠士兵。""「居然能冻住我等的黑铠……这是何等魔力！全员，咏唱BurningPlace！」「是！遍布天地的火之精灵啊──」穆亚向周遭大喊之后，被冻结的黑铠之中传来的咏唱声。没有死。没有任何人死。"
- 名称：佩尔基乌斯阵营（甲龙王与十二使魔）
  - 内容：以空中要塞为据点的势力，主脑为曾参与封印魔神拉普拉斯的英雄「甲龙王佩尔基乌斯」，麾下统领十二名具备特异能力与职能的使魔（如光辉之阿尔曼菲、空虚之希瓦莉尔等），战力极强。
  - 原文依据："佩尔基乌斯和十二名使魔。原来如此，如果是他的话或许会愿意来救我们。毕竟他可是封印了拉普拉斯的英雄。""从他的身后陆续地冒出其他成员。光辉的阿尔曼菲、空虚的希尔瓦莉，还有其他分不清谁是谁的家伙。总共六名。"
- 名称：「五大魔王」
  - 内容：历史上第二次人魔大战期间魔族顶尖领袖的群体称号，阿托菲的生父「不死的涅克罗斯拉克罗斯」为五大魔王之一。
  - 原文依据："她是「五大魔王」不死的涅克罗斯拉克罗斯的女儿。"

## 三、力量体系 / 魔法 / 技能
- 名称：龙门召唤（前龙门、后龙门）
  - 规则：甲龙王佩尔基乌斯掌握的龙门秘术。通过吟唱长篇龙之咒文（「那头龙仅为忠义而生……以甲龙王佩尔基乌斯之名召唤──」），在目标左右召唤出一扇雕刻龙形浮雕的白银之门（后龙门）与一扇黄金之门（前龙门）。开门后魔力与能量从右侧门流向左侧门，以超越奥尔斯帝德龙门的速率和吸力，强行高速吸取范围内目标的魔力与体力，甚至能够彻底消除目标身上的斗气，使阿托菲体型肉眼可见地变小一圈。
  - 原文依据："「那头龙仅为忠义而生。双爪长而锐利，绝不握拳。另一头龙愤怒之时，绝不握拳。纵使断爪折牙，但总有一天方能得知。紧握忠义之龙，是抱着何种思念舍弃忠义！第三头死去之龙。拥有一双最为锐利的瞳孔，白银鳞的龙将。以甲龙王佩尔基乌斯之名召唤──」回过神来，在阿托菲的左右，就像要把我们全员包夹似的，出现了两道门。……一扇为装饰华美的白银之门。一扇为装饰华美的黄金之门。「打开吧，『后龙门』。」「吸引吧，『前龙门』。」佩尔基乌斯一声低喃，两道门同时应声开启。……是魔力。那道门……这种召唤魔术会吸收魔力。我感觉到魔力从身体表面一阵一阵地流失而去。和奥尔斯帝德那时不同。比起当时，感觉身体的魔力以及体力更快遭到吸收。……她的身体，看起来比刚才还要小了一圈。难道说她身上的斗气被那道门消除了吗？"
- 名称：甲龙手刀『一断』
  - 规则：佩尔基乌斯的高阶体术/必杀技。将右手染上纯白光芒并笼罩四周，挥落时发出笔直光芒贯穿目标，能将不死魔王强悍的身躯瞬间一刀两断、重创并震飞至视野之外。
  - 原文依据："佩尔基乌斯举起右手，手逐渐染上一层白色。不久之后，右手开始发出光芒，一道炫目的白光笼罩四周。「甲龙手刀『一断』。」佩尔基乌斯的手应声挥下。一道光芒笔直往阿托菲飞去，直接贯穿。……阿托菲突然僵硬。然后，经过了一瞬间的延迟，被打飞到后面去了。她的身体一分为二飞了出去，转眼间已经从我的视野范围消失。"
- 名称：电击魔术
  - 规则：混合属性或高阶攻击魔术，释放紫电。若四周地面被水浸湿，雷电会顺着潮湿积水无差别向周围所有人传导扩散，造成全员触电、肌肉翻折抽搐与神经麻痹。产生的电灼伤渗透至皮下组织，若不及时接受高阶治愈魔术治疗会留下永久后遗症。
  - 原文依据："「电击！」我将魔力控制不足以电死人的程度，释放电击。一瞬间，紫电朝向穆亚奔驰。随后磅的一声轰隆巨响，引起惊人的放电现象。紫电无差别地向四周蔓延，落在地面。电击顺利地在潮湿的地面扩散──所有被水浸湿的人都受到电击。……黑铠士兵们冒着烟倒了下去。艾莉娜丽洁、札诺巴，阿托菲，以及正试图解冻的人也是。而且，穆亚也一样。包括我在内。""克里夫一边说着：「从来没见过这种烫伤……」，同时用治愈魔术漂亮地治好我们因电击所受的伤势。他说烫伤已经渗透到皮下组织，尽管不会致死，但如果置之不理，这次的伤势严重到甚至会留下后遗症。"
- 名称：BurningPlace（爆炎）
  - 规则：火系统魔术。咏唱句包括「──之力，爆炎缠绕我身……『BurningPlace』！」及「遍布天地的火之精灵啊──」。施术时周身爆发扩散炽热爆炎热气，能直接中和并熔解高位冰霜魔术的冰封效果。
  - 原文依据："「──之力，爆炎缠绕我身……『BurningPlace』！」从一个男人身上，有道足以将周围燃烧殆尽的热气爆发性地扩散开来。那股热气和我的冰霜新星对抗，击发魔术的男人以及在他身旁两侧的黑铠士兵，冒出一股热气解冻身体。""穆亚向周遭大喊之后，被冻结的黑铠之中传来的咏唱声。"
- 名称：浓雾
  - 规则：水系统魔术。咏唱句为「水之精灵啊，赐给我力量──『浓雾』」。在施术者周围召唤浓密烟雾遮挡视线以规避远程攻击。熟练魔术师可缩短咏唱。
  - 原文依据："「水之精灵啊，赐给我力量──『浓雾』。」穆亚用魔术将自己包裹在一团浓雾之中。看来是打算用烟雾来回避我的岩炮弹。不过话说回来，咏唱时间很短。因为他像洛琪希一样，缩短了咏唱的时间。"
- 名称：土枪
  - 规则：土系统魔术。咏唱句为「不确知之神啊！请回应我的呼唤，自大地直冲天际！『土枪』！」。令坚固土枪自脚边或地表突起，不仅可作为刺击武器，亦可临机用作借力跳台飞跃泥沼等陷阱。
  - 原文依据："「不确知之神啊！请回应我的呼唤，自大地直冲天际！『土枪』！」穆亚立刻朝向自己脚边施放魔术，他将从脚边冒出的土枪作为跳台，转眼间就跃过泥沼。"
- 名称：乱魔
  - 规则：水神流系/反魔术技术。在对手构筑或释放魔术的瞬间发射魔力波动，精准击中对手正在成型的魔术并将其彻底消除瓦解。
  - 原文依据："我和希露菲一起练习的这个魔术，分毫不差地命中穆亚正在制作的魔术将其消除。「什么！竟然是乱魔？」穆亚满脸错愕地看着自己的手。"
- 名称：风缚
  - 规则：风系统魔术。将风化为长鞭进行拘束或捕捉移动中的目标。
  - 原文依据："穆亚刚释放出的风之鞭，一瞬间就遭到抹消。""「『风缚』！」"
- 名称：风裂
  - 规则：风系统魔术。释放猛烈烈风吹散浓雾与烟尘。
  - 原文依据："「风裂！」我的法杖产生烈风，吹散了烟雾"
- 名称：雷光
  - 规则：王级单体雷魔术，具备极高杀伤火力，但攻击范围容易波及施术者周围的同伴。
  - 原文依据："如果是要追求对单体的火力，那应该用王级魔术的「雷光」比较恰当，但是这个距离，会波及我们所有人。"
- 名称：冲击波剑技与斗气防御
  - 规则：
    1. 水神流具备反弹魔术的技术；阿托菲亦能以精湛剑技改变或斩偏高速岩炮弹。
    2. 剑士踏步突刺可由剑尖释放不可视的冲击波；高段位战士挥动大剑可直接产生范围冲击波斩击，若无盾牌防护极易致命。
    3. 肉身覆盖高强度斗气时，刀剑斩击在皮肤表面会发出如同金属交碰的「锵」声并被直接弹开。
  - 原文依据："水神流有将魔术反弹回来的技巧。""剑与岩炮弹接触，迸出惊人火花。岩炮弹的方向遭到改变""艾莉娜丽洁……利用离心力的斩击确实地击中了阿托菲的颈部以及肌肤。然而，那道斩击却伴随着锵的一声遭到弹开。那不是人类肌肤能发出的声音。是用斗气防御住了吗？""她架着盾牌，踏出步伐猛然一刺，从剑身发出了不可视的冲击波，直击阿托菲。""阿托菲只是把剑一挥就能产生冲击波。但如果没有及时防御，艾莉娜丽洁的身体说不定已被一刀两断。"

## 四、种族 / 生物
- 名称：不死魔族（不死魔王）
  - 特征：
    1. 拥有近乎无法杀死的超强肉体恢复再生能力。头部被击碎能迅速复原；身体被一刀两断腰斩亦不会死亡；电击麻痹的恢复速率远超普通人类。
    2. 血液颜色为黑色（受到重压时吐出黑血）。
    3. 背部长有可煽动的双翼（翅膀）。
    4. 性格通常被外人评价为智能不足、残虐凶暴，战斗中极易大意轻敌，被佩尔基乌斯讥讽为「不死魔王家族的传统技艺」。
  - 原文依据："她是「五大魔王」不死的涅克罗斯拉克罗斯的女儿。身为魔族方急先锋的她，尽管智能不高，却拥有极为高超的战斗力与耐久力，作为残虐凶暴的魔王，受到人们畏惧。""被札诺巴的拳头打得稀巴烂的头部也几近完全复活。""札诺巴灌注宛如老虎钳般的力道，使得阿托菲口吐黑血。""不死种族的恢复速度肯定比我快速。""一颤一颤地挥动翅膀，想要累积力量高高跃起""佩尔基乌斯看到眼前这幕，愉快地笑了。「怎么？你的动作还真是可笑啊，阿托菲拉托菲。你又大意了吗？大意轻敌是你们不死魔王家族的传统技艺吗？」""「哼，反正她也死不了吧。」"
- 名称：魔界大帝（奇希莉卡·奇希里斯）
  - 特征：魔界大帝。身形娇小如幼女，体质耐力脆弱但极具韧性，身上气味难闻（长期不洗澡）。即使在对立的甲龙王佩尔基乌斯面前，佩尔基乌斯也未予以逮捕或加害（表示「别管她」）。
  - 原文依据："贴到阿托菲脸上的，是刚刚还骑在札诺巴肩膀上的奇希莉卡。「喂！臭死了！你至少洗个澡啊笨蛋！」「本宫也不是喜欢才……呜呀啊啊啊！」「魔界大帝奇希莉卡也同样在场。」……「别管她。」"
- 名称：龙族（甲龙王）及其使魔
  - 特征：佩尔基乌斯拥有灿烂银发、金色三白眼，身着白袍，精通魔神语，掌握强大的古代龙门秘术与甲龙手刀。十二使魔各具特异外貌与职能（如光芒闪耀的阿尔曼菲、戴面具的希瓦莉尔等）。
  - 原文依据："灿烂的银发。金色的三白眼。身上的白色衣服被溅上了斑斑血迹。「是不死魔王阿托菲拉托菲啊。」他说着一口流利的魔神语……从他的身后陆续地冒出其他成员。光辉的阿尔曼菲、空虚的希尔瓦莉，还有其他分不清谁是谁的家伙。总共六名。"

## 五、物品 / 道具 / 武器
- 名称：黑铠
  - 说明：阿托菲亲卫队的重型防具。具有出色的魔法与物理减伤抗性，能承受冰霜新星而不破裂，保护内部士兵不致冻死；同时能有效减免风系统魔术的冲击。
  - 原文依据："穆亚头也不回，紧追着克里夫。明明身穿铠甲，穆亚却十分快速。""「居然能冻住我等的黑铠……这是何等魔力！全员，咏唱BurningPlace！」……没有死。没有任何人死。是那具铠甲吗？那具铠甲对冰魔术拥有抗性吗？""我的法杖产生烈风，吹散了烟雾，但穆亚依旧不为所动。那家伙甚至还踏稳步伐，，继续紧追克里夫。那身黑铠甚至可以减轻风系统的威力吗？"
- 名称：魔道具义手（吸魔石义手）
  - 说明：扎诺巴与克里夫协助制作的装在鲁迪乌斯左臂的义手。即使佩戴者肉身因电击麻痹无法行动，依靠向左臂灌注魔力仍能驱动义手活动。手掌中嵌有吸魔石，通过口令「『臂膀啊，吸收殆尽！』」张开手掌，可瞬间将敌人释放的魔术（如风缚）完全吸收消除。
  - 原文依据："就算肉身麻痹动弹不得，还有义手可以动。我张开左手的义手，将手掌朝向穆亚。「『风缚』！」「『臂膀啊，吸收殆尽！』」穆亚刚释放出的风之鞭，一瞬间就遭到抹消。"
- 名称：傲慢水龙王
  - 说明：鲁迪乌斯使用的长法杖，质地坚固且具相当份量。
  - 原文依据："法杖呢？法杖跑哪去了？我没有那家伙可不行。好，找到了。原来被我压在身体下面。对不起，傲慢水龙王，很重吧？"
- 名称：转移魔法阵
  - 说明：利卡里斯地下监狱的古代转移魔法阵，单步跨入即可瞬移至空中要塞内部。希瓦莉尔拥有控制其运作并彻底停止/关闭魔法阵的技术。
  - 原文依据："阿托菲比我们抢先抵达这里。想必当时便已发现通往转移魔法阵的入口，命令士兵进入里面探索。然后，一旦士兵们发现转移魔法阵，自然会踏入其中一探究竟。所以，他才会出现在这里。因为空中要塞被魔族大闹了一番。""当所有人都完成转移后，希瓦莉尔停止了转移魔法阵。这样一来，就没有通往魔大陆的道路了。"
- 名称：部下契约（魔王契约）
  - 说明：阿托菲在击败猎物后强制其签署的从属契约，迫使战俘成为其部下，服役十年乃至一生，接受严酷的肉体锻炼。

## 六、历史 / 传说 / 事件
- 事件名：第二次人魔大战阿托菲征战与被封印
  - 内容：第二次人魔大战期间，阿托菲作为五大魔王涅克罗斯拉克罗斯之女充当魔族急先锋，战力高强残暴。但因其智能不足，补给路线被敌方切断致使部下全灭，本人亦被人族捕获封印。
  - 原文依据："不死魔王阿托菲拉托菲相当有名。她在历史上开始崭露头角，是在第二次人魔大战的期间。她是「五大魔王」不死的涅克罗斯拉克罗斯的女儿。身为魔族方急先锋的她，尽管智能不高，却拥有极为高超的战斗力与耐久力，作为残虐凶暴的魔王，受到人们畏惧。然而却也因为智能不足，导致补给路线被敌方切断，部下也因此全灭。她本人也遭到人族捕获，遭到封印。"

  - 内容：阿托菲黑铠士兵误入地下监狱转移魔法阵，闯入空中要塞大闹并流血。佩尔基乌斯率六名使魔突入利卡里斯，利用龙门抽干阿托菲魔力与斗气，以甲龙手刀『一断』将阿托菲腰斩击飞，救走鲁迪乌斯一行，随后关闭该转移魔法阵。

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯等人以为地下监狱通道是空旷安全的，只要克里夫穿过穆亚与黑铠包围网进入地下监狱入口即可安全逃入转移魔法阵。
- 原文是否暗示另有真相：是。
- 原文依据："「只有克里夫也好，设法让他逃进转移魔法阵吧。」……他正好到达地下监狱的入口。和那边冒出来的黑铠士兵撞个正着……「不会吧？」里面……居然……也有黑铠士兵？「啊……」为什么我没有想到这点？既然眼前有洞穴，就算是阿托菲，也肯定会派人进入查看。"（真相是阿托菲部队早就派遣士兵进入洞穴探索，甚至部分士兵已跨入魔法阵传送到空中要塞）。

- 角色以为：阿托菲以为佩尔基乌斯撕毁盟约，派鲁迪乌斯等人当诱饵刺客来谋杀她。
- 原文是否暗示另有真相：是。
- 原文依据："「这些家伙是你派来的吗！为了杀我，居然耍这种小技俩……你打算无视和卡尔的盟约吗！」……佩尔基乌斯宛如看到绝佳猎物的老虎般地注视着阿托菲。「别搞错了。那些家伙只是为了拯救朋友，请求吾助他们一臂之力。」……「你那些肮脏士兵的鲜血，弄脏了吾的城堡。」我懂了。阿托菲比我们抢先抵达这里。想必当时便已发现通往转移魔法阵的入口，命令士兵进入里面探索。然后，一旦士兵们发现转移魔法阵，自然会踏入其中一探究竟。所以，他才会出现在这里。因为空中要塞被魔族大闹了一番。"

- 角色以为：鲁迪乌斯看见黑铠士兵被冻结，以为自己痛下杀手杀死了包围的士兵（「然后，我……终于也杀了人……」）。
- 原文是否暗示另有真相：是。
- 原文依据："「居然能冻住我等的黑铠……这是何等魔力！全员，咏唱BurningPlace！」「是！遍布天地的火之精灵啊──」穆亚向周遭大喊之后，被冻结的黑铠之中传来的咏唱声。没有死。没有任何人死。是那具铠甲吗？那具铠甲对冰魔术拥有抗性吗？"（真相是黑铠防具抗性极高，内部士兵毫发无损并立刻咏唱火魔术脱困）。

- 角色以为：阿托菲与卡尔曼有子嗣、阿托菲习得北神流剑术、教导卡尔曼二世剑术等皆为世间传闻。
