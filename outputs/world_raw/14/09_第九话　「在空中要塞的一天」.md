# 第九话　「在空中要塞的一天」 世界设定提取

## 一、地理与场所
- 名称：空中要塞（庭园与设施）
  - 内容：空中要塞内设有长廊、医务室/病房以及能俯瞰云海夕阳的宽阔庭园。庭园内栽种有修剪整齐的盆栽及罕见花草，夜间庭园内的桌子与花草会散发出蓝白色的光芒提供照明。要塞内严格禁止魔族进入。
  - 原文依据："尽管我也不是很喜欢站在高的地方，但还是会想从呈现在眼前的宽敞又美丽的庭园里，眺望云海中的夕阳。……修剪整齐的盆栽，以及从未见过的花草。这样的景象在沉入云层之中的夕阳照耀之下，营造出一幅幻想般的风景。"、"虽说也想对洛琪希做出同样举动……无奈这里禁止魔族进入。"、"周围却不显得阴暗。是因为桌子和周围的花草正散发出蓝白色的光芒。『这张桌子是以魔照石制成。你也坐下吧，再多聊一会儿。』"
- 名称：魔大陆
  - 内容：四百年前拉普拉斯战役后，北神卡尔曼临终前禁止佩尔基乌斯与阿托菲互相残杀，佩尔基乌斯此后便再未踏上魔大陆。
  - 原文依据："而且他还在临死之际，禁止佩尔基乌斯和阿托菲互相残杀，之后自己也没再踏上魔大陆，因此失去复仇机会。"

## 二、组织与势力
- 名称：空中要塞（甲龙王佩尔基乌斯阵营）
  - 内容：由甲龙王佩尔基乌斯统御，麾下有十二使魔（本章登场/提及使魔包括侍从希瓦莉尔、负责听觉警戒的「轰雷」克里亚奈特、负责远行接引的「光辉」阿尔曼菲）。佩尔基乌斯本人极度厌恶魔族并严禁魔族登城，但为人重信义与恩情；热爱并精通艺术鉴赏与工艺造诣。
  - 原文依据："希瓦莉尔从怀中取出一个宛如龙盘高塔般的笛子。『只要在和吾有因缘的场所使用这个，便会传入轰雷的克里亚奈特耳里，到时阿尔曼菲自然会去迎接你。』"、"佩尔基乌斯憎恨魔族。尽管他在某种程度上还算宽容，但是他抱持着我至今见过的人之中最为严重的偏见。"、"『斯佩路德族的名誉与吾无关……但是，这份恩情必须要还。』"
- 名称：拉普拉斯战役人类方阵营
  - 内容：四百年前拉普拉斯战役期间对抗魔族军的人类势力。佩尔基乌斯年轻时作为冒险者加入人类阵营，于最前线屡次遭遇魔族将军阿托菲并多次陷入死境，得益于龙神乌尔佩与初代北神卡尔曼相救才幸免于难。阿斯拉王室成员在该战役中伤亡殆尽，仅剩卡瓦尼斯一人幸存。
  - 原文依据："在拉普拉斯战役时还是个毛头小子的佩尔基乌斯，作为一名冒险者加入了人类方的阵营。"、"每次都被宛如大哥的龙神乌尔佩以及北神卡尔曼所救，留下不堪回首的回忆。"、"他是在拉普拉斯战役时，阿斯拉王族最后一名幸存者。"
- 名称：拉普拉斯战役魔族军
  - 内容：四百年前由拉普拉斯率领的军队。不死魔王阿托菲担任前线指挥将军；拉普拉斯利用具有心智操控诅咒的长枪将斯佩路德族作为杀戮工具投入暗处行动。
  - 原文依据："在最前线的战场，作为魔族一方的将军在前线指挥的就是阿托菲。"、"拉普拉斯给了他一把会凶暴化的长枪，才导致他遭到操控，玷汙了自己一族的名誉，不仅如此，还对自己的家人痛下杀手……"
- 名称：阿斯拉王国王室与贵族
  - 内容：拉普拉斯战役后由卡瓦尼斯王整合重建的国家。国内拥有极为优秀的石匠，但贵族多将石头工艺用于满足个人虚荣并建造雕像。目前第二公主爱丽儿正致力于争取甲龙王佩尔基乌斯的支持以竞争王位。
  - 原文依据："他将因为战争而四分五裂的阿斯拉王国重新整合，是一位伟大的君王。"、"『阿斯拉王国的石头工艺，只不过是贵族为了满足自己的虚荣而做的吧？那种东西没有任何乐趣可言。』"

## 三、力量体系 / 魔法 / 技能
- 名称：魔眼「识别眼」
  - 规则：魔界大帝奇希莉卡赋予克里夫的魔眼。功能为辨识映入眼帘的物体类别与信息；在眼中世间万物皆会浮现名称与解说文字。持有者若尚未能熟练驾驭，会因视线充满文字而寸步难行，日常需要佩戴眼罩遮蔽该眼。
  - 原文依据："克里夫得到的魔眼是『识别眼』。可以判断映入眼帘的物体是什么东西。……他现在眼前看到的世上所有物品，似乎都会浮现出名字和说明文。换句话说，就是充满着文字的世界。因此，现在要是没有艾莉娜丽洁牵手引路，他就寸步难行。……在那之前得先戴着眼罩。"
- 名称：世界魔力分布法则与杜莱病机制
  - 规则：世界上无论空气或食物中皆寄宿着魔力，生活在该世界无法完全避免魔力接触。来自异世界的人类（如七星）身体缺乏对魔力的免疫机制，体内会累积魔力并引发杜莱病等异常病症，且存在诱发连奇希莉卡都未知的远古疾病的风险。该病无法完全根治，但饮用索卡司草煎煮的茶可促进排泄、暂时排出体内魔力；日常规律饮用索卡司茶可抑制魔力过度囤积。
  - 原文依据："七星患的杜莱病无法完全治好。尽管索卡司草能够暂时性地排泄体内魔力，但要是置之不理，总有一天身体似乎又会累积魔力。说不定是因为她原本就不是这个世界的人类，因此没办法免疫。基本上，只要在日常经常饮用索卡司茶，就不会囤积太多魔力。然而不变的是，哪怕只是微量的魔力，都会有罹患疾病的可能性。而且，那种疾病也有可能会是远古时期流传下来，就连奇希莉卡也不得而知的疾病。只要活在这个世上，就没有办法在不接触魔力的情况下生活。因为无论是在空气还是食物之中，都寄宿着魔力。"
- 名称：赎罪的尤尔兹的能力 [存疑]
  - 规则：能够将体力转移给受术者，鲁迪乌斯怀疑该能力是否会连同性格一同转移 [存疑]。
  - 原文依据："难道使用赎罪的尤尔兹的能力，不仅是体力，就连性格也会一并转移吗？"
- 名称：土魔术塑型技术（手办/人偶制作）
  - 规则：利用土魔术凭空塑出基本形状，再精细削减部件进行雕琢造型。鲁迪乌斯展示了制作希瓦莉尔佩戴鸟面具黏土人手办的技术，佩尔基乌斯对能将土魔术用于此类精细艺术制作表示吃惊与赞赏。
  - 原文依据："以土魔术做出外型，再根据部件进行削除，雕塑出形状"、"『居然有人能将土魔术运用在此等事情，真是令人吃惊。』"
- 名称：召唤魔术与转移魔术
  - 规则：高深的古代魔术门类。甲龙王佩尔基乌斯精通召唤术，并承诺在七星康复后亲自指导鲁迪乌斯学习召唤术。
  - 原文依据："『不然，等到七星的身体好转，就由吾亲自指导你召唤术吧。』……更何况，我也想要更加了解召唤魔术还有转移魔术。"

## 四、种族 / 生物
- 名称：矿坑族
  - 特征：手艺极为精巧的工匠种族，擅长各类工艺品制作。其工艺品在第二次人魔大战前夕达到历史顶峰；虽因战争失去聚居地但种族并未灭绝，仍具诞生顶尖神工巨匠的潜质。
  - 原文依据："『矿坑族的工艺品，果然是在第二次人魔大战前夕那时最为出色。』『是啊。如果不是那场战争消灭了矿坑族的住处，如今想必已经完成杰出的作品。』……『但是，矿坑族并没有灭绝。那个种族的手艺精巧，想必早晚就会出现能巧夺天工的杰出工匠。』"
- 名称：斯佩路德族
  - 特征：魔族部族之一。在世人眼中被视作潜伏阴影嗜杀平民的恐怖一族；实则是四百年前拉普拉斯战役中遭拉普拉斯赐予的狂暴长枪诅咒操纵心智，导致残杀同胞与无辜平民。族人（如瑞杰路德）为此深陷羞愧自责，周游世界以洗刷一族污名。
  - 原文依据："『吾讨厌斯佩路德族。他们躲藏在影子之中暗中活跃，杀尽无辜民众……然而，要是没有瑞杰路德帮助，吾也活不到今日……可是……』"、"『是的。因为他被拉普拉斯所欺骗。拉普拉斯给了他一把会凶暴化的长枪，才导致他遭到操控，玷汙了自己一族的名誉，不仅如此，还对自己的家人痛下杀手……他对这样的自己感到羞愧，憎恨着拉普拉斯。如今，他为了取回自己一族的名誉周游世界。』"
- 名称：异世界转移者（异世界人类）
  - 特征：来自异世界的人类，身体无法像本世界原住民一样自然免疫魔力环境，长期暴露在含魔力的空气与食物中会在体内积存魔力并导致病发。
  - 原文依据："说不定是因为她原本就不是这个世界的人类，因此没办法免疫。"

## 五、物品 / 道具 / 武器
- 名称：索卡司草 / 索卡司茶
- 说明：用于冲泡煎煮的药草，饮用后可引发便意并促使体内积累的魔力排出体外，是缓解非本世界人类罹患杜莱病的核心对症药饮。
- 原文依据："喝下我们带回来的茶叶煎煮的茶后，七星就说有了便意。"、"她用装着索卡司茶的杯子暖着手……"、"尽管索卡司草能够暂时性地排泄体内魔力，但要是置之不理，总有一天身体似乎又会累积魔力。……基本上，只要在日常经常饮用索卡司茶，就不会囤积太多魔力。"
- 名称：龙盘高塔之笛
- 说明：由希瓦莉尔转交给鲁迪乌斯的联络道具，外观呈龙盘绕高塔状。只要在与佩尔基乌斯有因缘的地点吹奏，声音便能被使魔「轰雷」克里亚奈特捕捉，随后使魔「光辉」阿尔曼菲便会前去接引持有者。
- 原文依据："希瓦莉尔从怀中取出一个宛如龙盘高塔般的笛子。『只要在和吾有因缘的场所使用这个，便会传入轰雷的克里亚奈特耳里，到时阿尔曼菲自然会去迎接你。』"
- 名称：魔照石（魔照石桌）
- 说明：空中要塞庭园所用材料，以魔照石制成的桌子在夜幕降临后能与周边植物一同散发出柔和的蓝白色光芒，提供夜间照明。
- 原文依据："周围却不显得阴暗。是因为桌子和周围的花草正散发出蓝白色的光芒。『这张桌子是以魔照石制成。你也坐下吧，再多聊一会儿。』佩尔基乌斯如此说道"
- 名称：会凶暴化的长枪
- 说明：四百年前拉普拉斯战役中魔神拉普拉斯交给斯佩路德族战士的兵器，带有凶暴化精神操控诅咒，导致持枪者理智尽失、残杀族人与无辜平民。
- 原文依据："拉普拉斯给了他一把会凶暴化的长枪，才导致他遭到操控，玷汙了自己一族的名誉，不仅如此，还对自己的家人痛下杀手……"
- 名称：瑞杰路德人偶
- 说明：由茱丽制作、札诺巴计划投入商市贩售的人偶作品，具动态张力。佩尔基乌斯念及拉普拉斯战役中瑞杰路德的救命之恩，特许了该人偶的贩售。
- 原文依据："从箱子里出现的，是茱丽制作的瑞杰路德人偶。和我做的成品有着不同风格，是带有一种跃动感的杰出设计。"、"『斯佩路德族的名誉与吾无关……但是，这份恩情必须要还。……随你们喜欢吧。』"

## 六、历史 / 传说 / 事件
- 事件名：四百年前拉普拉斯战役
- 内容：
  1. 佩尔基乌斯参战往事：年少时的佩尔基乌斯以冒险者身份加入人类阵营在前线作战，多次与魔族统帅阿托菲激战并险遭杀害，皆由如兄长般的龙神乌尔佩与初代北神卡尔曼解救。
  2. 决战中的救命之恩：在讨伐拉普拉斯的最终决战中，瑞杰路德曾协助佩尔基乌斯，佩尔基乌斯亲口承认若无瑞杰路德相助自己无法存活至今。
  3. 卡尔曼与阿托菲结缡及临终誓言：拉普拉斯战役后北神卡尔曼与阿托菲结为夫妻，并在临死前要求佩尔基乌斯与阿托菲立誓不得互相残杀，佩尔基乌斯随后未再前往魔大陆。
  4. 阿斯拉王国的复兴：阿斯拉王室成员在战争中几乎全员战死，幸存的卡瓦尼斯登基为王，将四分五裂的王国重新归拢平定。
- 原文依据："在拉普拉斯战役时还是个毛头小子的佩尔基乌斯，作为一名冒险者加入了人类方的阵营。在最前线的战场，作为魔族一方的将军在前线指挥的就是阿托菲。佩尔基乌斯当时在战场上多次与阿托菲交手。然而，当时佩尔基乌斯不过是个初出茅庐的年轻小伙子，始终无法战胜阿托菲，好几次都差点被杀。每次都被宛如大哥的龙神乌尔佩以及北神卡尔曼所救，留下不堪回首的回忆。之后，佩尔基乌斯心想迟早有天要报一箭之仇，没想到北神卡尔曼居然和不死魔王阿托菲结为连理。而且他还在临死之际，禁止佩尔基乌斯和阿托菲互相残杀，之后自己也没再踏上魔大陆，因此失去复仇机会。"、"以前曾听佩尔基乌斯大人提及，和拉普拉斯进行的最终决战之中……曾助佩尔基乌斯大人一臂之力的人，便是那位瑞杰路德大人。"、"『要是没有瑞杰路德帮助，吾也活不到今日……』"、"他是在拉普拉斯战役时，阿斯拉王族最后一名幸存者。他将因为战争而四分五裂的阿斯拉王国重新整合，是一位伟大的君王。"
- 事件名：第二次人魔大战
- 内容：古代爆发的种族大战，战火摧毁了矿坑族的聚居处，使矿坑族辉煌的工艺品巅峰时代遭遇重创，但矿坑族并未灭绝。
- 原文依据："『矿坑族的工艺品，果然是在第二次人魔大战前夕那时最为出色。』『是啊。如果不是那场战争消灭了矿坑族的住处，如今想必已经完成杰出的作品。』『但是，矿坑族并没有灭绝。』"

## 七、社会规则 / 习俗 / 文化
- 内容：空中要塞禁绝魔族入境的排他性规则
  - 原文依据："虽说也想对洛琪希做出同样举动……无奈这里禁止魔族进入。"、"算了，毕竟她来不了这里，也只能作罢。"
- 内容：阿斯拉贵族的虚荣石工文化
  - 阿斯拉王国拥有高超的石工技艺，但贵族阶层多将工艺用于炫耀虚荣和建造统治者雕像，被佩尔基乌斯斥为剥削民税享乐且毫无艺术情趣。
  - 原文依据："『阿斯拉王国的石头工艺，只不过是贵族为了满足自己的虚荣而做的吧？那种东西没有任何乐趣可言。』……『难不成对你来说的王，是要使用人民的税金，享尽荣华富贵而已？』"
- 内容：君王的核心素质观念（佩尔基乌斯之道 vs 爱丽儿的君王观）
  - 爱丽儿认为王者应当博学、纳谏并具君王担当；佩尔基乌斯则以阿斯拉中兴君主卡瓦尼斯为例指出，王者无需具备过人武艺才能或圣人之德，真正的核心素质在于能让身边周围之人甘愿舍身相助、共同成就大业的人格魅力与凝聚力。
  - 原文依据："『对你来说，所谓的王是什么？你认为真正的王，究竟代表什么？』『我想……是知识渊博，会倾听大臣的谏言，具有身为王的自觉……』『不对。』佩尔基乌斯打断爱丽儿的话，摇头否定。……『他可不伟大。他这个男人既胆小，又不喜好战争，总是不停逃避。他不擅念书，也没有练武才能……然而，那家伙具有身为王最重要的素质。正因如此，吾才会认为他是真正的王者。』"、"『是啊，卡尼瓦斯也并非尽是为民众着想。然而，周围的人却还是愿意出手相助，因此才能进而平定阿斯拉。』"

## 九、角色认知 vs 客观事实
- 角色以为：七星态度一改常态变得毕恭毕敬，鲁迪乌斯推测使用尤尔兹的能力是否会连同性格一同转移。
  - 原文是否暗示另有真相：是。七星态度诚恳是因为大病虚弱、感念鲁迪乌斯冒生命危险为自己取药而由衷感激，并非尤尔兹能力转移了性格。
  - 原文依据："难道使用赎罪的尤尔兹的能力，不仅是体力，就连性格也会一并转移吗？" vs "不，肯定是因为身体虚弱，连个性也跟着懦弱了吧。"、"明明是那么危险的地方，你却特地跑一趟为我取药。那个……承蒙相助。"
- 角色以为：佩尔基乌斯认为初代北神卡尔曼遗言禁止的是「互相残杀」，因此自己趁阿托菲虚弱时痛殴对方不算违约。
  - 原文是否暗示另有真相：是。鲁迪乌斯指出佩尔基乌斯是在强词夺理钻空子，只为了宣泄数百年积怨。
  - 原文依据："『请问您没遵守和北神卡尔曼之间的约定，这样好吗？』『卡尔禁止的是「互相残杀」。如果只是单方面的痛殴，想必他也不会有怨言。』不惜强词夺理，也想要痛殴无法抵抗的对手，实在野蛮。然而，这也表示他们之间的因缘就是如此深厚。"
- 角色以为：佩尔基乌斯认为斯佩路德族本性阴险凶残，暗中滥杀平民。
  - 原文是否暗示另有真相：是。斯佩路德族当年是受魔神拉普拉斯所赠的长枪精神诅咒操纵，失去理智残杀族人与平民，瑞杰路德对此悔恨莫及并深恨拉普拉斯。
  - 原文依据："『吾讨厌斯佩路德族。他们躲藏在影子之中暗中活跃，杀尽无辜民众……』" vs "『是的。因为他被拉普拉斯所欺骗。拉普拉斯给了他一把会凶暴化的长枪，才导致他遭到操控，玷汙了自己一族的名誉，不仅如此，还对自己的家人痛下杀手……他对这样的自己感到羞愧，憎恨着拉普拉斯。』"
- 角色以为：鲁迪乌斯与爱丽儿认知中的卡瓦尼斯王是平定战乱、才干盖世的传统伟大君王。
  - 原文是否暗示另有真相：是。佩尔基乌斯指出卡瓦尼斯为人胆怯避战、毫无武艺文学天赋且贪杯好色，毫无成王野心；但他具有让周围众人甘心相助平定天下的独特王者素质。
  - 原文依据："他将因为战争而四分五裂的阿斯拉王国重新整合，是一位伟大的君王。阿斯拉也因为拉普拉斯战役饱受摧残，即使如此，战争过后也没有发生内乱，漂亮地重新整合，据说有很大一部分是因为他的本领所至。" vs "『他可不伟大。他这个男人既胆小，又不喜好战争，总是不停逃避。他不擅念书，也没有练武才能，总是偷偷跑到镇上的酒馆喝酒，色眯眯地看着酒馆的女孩，就是那样的男人。当然，他也没有试图成王的野心。然而，那家伙具有身为王最重要的素质。正因如此，吾才会认为他是真正的王者。』"
- 角色以为：爱丽儿以为所谓的王应当是博学聪颖、虚心纳谏、具备君主自觉之人，并试图以立雕像迎合佩尔基乌斯。
