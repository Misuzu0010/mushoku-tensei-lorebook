# 第十一话　「结束与开始」 世界设定提取

## 一、地理与场所
- 名称：米里斯神圣国
  - 内容：拥有高阶解毒魔术知识的国家。在老人的历史线中，为了治疗感染魔石病的洛琪希，鲁迪乌斯曾前往该国求取神级解毒魔术的咏唱。
  - 原文依据："我为了设法解救洛琪希前往米里斯神圣国，最后成功获得了神级解毒魔术的咏唱……然而途中发生了许多事，花费太多时间。当我回来的时候已经太迟了，洛琪希的身体有一半遭到结晶化，死了。"

- 名称：阿斯拉王国
  - 内容：大型王国。在老人的历史线中，爱丽儿因未能拉拢佩尔基乌斯而身处劣势，受路克（被人神托梦操控）进言孤注一掷前往阿斯拉王国发动内乱，最终惨败，跟随前往的希露菲亦战死。
  - 原文依据："路克会向爱丽儿进言，导致希露菲决定抛下我前往阿斯拉王国。和无法拉拢佩尔基乌斯的爱丽儿一起！身处劣势的爱丽儿，决定孤注一掷引发内乱……然后败北。希露菲……也会跟着一起战死。"

- 名称：剑之圣地
  - 内容：剑士修行的圣地，地理位置距离魔法都市夏利亚并不遥远，艾莉丝离开鲁迪乌斯后在此处刻苦修行。
  - 原文依据："『是剑之圣地。你也隐约察觉到了吧。』剑之圣地啊。离夏利亚并没有那么远。应该说如我所料吗？她果然在那里修行。"

- 名称：空中要塞
  - 内容：甲龙王佩尔基乌斯的居所要塞。老人推测潜入夏利亚家中的带病老鼠可能是混入从空中要塞带回的行李中被带回家的 [存疑]。
  - 原文依据："我不清楚那只老鼠是从哪里，什么时候跑进家门。恐怕是在空中要塞的家伙混进行李里面一起跟回来的吧。算了，它来自何处跟本无关紧要。"

- 名称：人神的所在处
  - 内容：人神所处的未知空间/场所。据来自未来的老人所述，该处位于这个世界的某处，但在老人生活的时代缺乏抵达该处所必需的条件或关键道具（“必要之物”），因此无法抵达。
  - 原文依据："因为，我没有办法抵达人神的所在处。……没有办法抵达人神的所在处，换句话说，那个场所果然位于这世界的某处吗？……在我生存的时代，没有能够抵达人神所在处的必要之物。"

- 名称：鲁迪乌斯宅地下室
  - 内容：位于夏利亚家中的地下室，内部存放有魔力附属品以及爱夏用于家庭菜园的肥料等杂物，深处设有通往神龛的隐藏通道；为带病老鼠潜藏并被鲁迪乌斯施术冻杀的场所。
  - 原文依据："尽管地下室还放着魔力附属品以及爱夏用在家庭菜园的肥料云云……它在通往神龛的隐藏通道附近，已经被冻成一片纯白死去。"

## 二、组织与势力
- 名称：魔术公会
  - 内容：具备进行魔术与病理/生物医学研究能力的公会机构。鲁迪乌斯在捕获带有魔石病的老鼠尸体后，决定将其送交魔术公会进行分析研究并核实病原情报。
  - 原文依据："或者说，要交给魔术公会让他们进行研究比较恰当？……只要综合老人提及的魔石病情报一起报告上去，就可以确认这件事是否属实。"

- 名称：阿斯拉王国爱丽儿派（爱丽儿势力）
  - 内容：以第二王女爱丽儿为核心的势力（成员包括路克、希露菲等）。在老人的历史线中，因未能获得佩尔基乌斯支持，在阿斯拉王位争夺内乱中彻底溃败身死。
  - 原文依据："和无法拉拢佩尔基乌斯的爱丽儿一起！身处劣势的爱丽儿，决定孤注一掷引发内乱……然后败北。希露菲……也会跟着一起战死。"

## 三、力量体系 / 魔法 / 技能
- 名称：过去转移魔术（时间穿越魔术）
  - 规则：以特定物品（如日记簿）为时空锚点或起点，跨越时间飞跃回到过去的魔术。由未来的鲁迪乌斯研发，但在施展时属于未完全成功的失败品：
    1. 无法将施术者的完整肉体全部带回过去（老人的腹部被截断缺失、内脏几乎全无）；
    2. 施术会消耗施术者近乎全部魔力，穿越后因魔力耗尽无法自愈；
    3. 时间穿越一旦成立，原本所处的历史无法被改变，但降临过去的干预行为会促使当前世界线历史产生变动；
    4. 未能得到克里夫协助完善，存在技术缺陷。
  - 原文依据："抱歉，我没有时间向你说明过去转移魔术的理论。""不仅如此，我现在甚至能穿越时间，回到过去……不过，这个魔术失败了。""因为我以日记为起点，飞跃回来……所以就带回来了…………上面写着，我经历过的一切…………""哈！因为，没有完成啊……我的过去转移，无法把身体，全部都带过来……""因为，我已经没有魔力了。抱歉啊……至少，要是克里夫还活着，过去转移肯定能，更加地……""况且，我像这样来到这里，历史应该已经改变。现在，无论我说什么，都不一定会成真。而且，既然过去转移以这种形式实现，那么我所走过的历史，也无法有任何改变……"

- 名称：魔术万能论（魔术本质规则）
  - 规则：这个世界的魔术体系在理论上具有万能性，只要施术者意识到其本质，并付出长期的研究、练习与心血，理论上任何现象与事情都能通过魔术实现。
  - 原文依据："你也隐隐约约感觉到了吧？这个世界的魔术是万能的。只要注意到这点，基本上任何事情都能办到。只是必须花费许多心血、研究和练习才行。"

- 名称：重力魔术（重力操控 / 浮游）
  - 规则：能够随心所欲操控重力场的高级魔术应用，既能隔空操控物体（如使墨水瓶轻缓悬浮又落下），也能使施术者自身在空中自由漂浮移动。
  - 原文依据："无论重力还是电击我都能自在操控，那家伙却还是不在我触手可及的范围。这样说完，老人伸手指向摆在桌上的墨水瓶。墨水瓶轻飘飘地浮起，很快地又轻轻落下。墨水也应声飞溅到桌上。我可以在空中漂浮"

- 名称：电击魔术（紫电操控）
  - 规则：能够将高强度雷电力量（紫电）凝聚缠绕在身体拳头上，激荡飞散火花，爆发时能将室内照亮如白昼并瞬间对接触物体造成烧焦痕迹。
  - 原文依据："有种宛如紫电的物体霹雳啪啦地缠绕在拳头上。……看到老人拳头周围飞散的火花……那个瞬间，紫电向周围飞散而去，房内瞬间亮得有如白昼。尽管光芒瞬间消失，桌子依然留下了烧焦痕迹。"

- 名称：远距离通讯魔术
  - 规则：能够跨越遥远地理距离直接与远方特定对象进行实时联络通讯的魔术。
  - 原文依据："也可以和远方的对象通讯。"

- 名称：肢体再生魔术（高级治愈魔术）
  - 规则：高阶治愈魔术能力，能够使完全断裂缺失的肢体（如断臂）重新长出恢复肉身，但依赖庞大魔力驱动。
  - 原文依据："也能让手臂再生。……老人的左手不是义手。他真的是我吗？还是说，他在今后的五十年之间用恰当的治疗魔术治好了吗？……他说是自己再生的……表示他的治愈魔术也具有相当水准。""咦？可是，你刚才说……可以让手臂再生……因为，我已经没有魔力了。"

- 名称：神级解毒魔术
  - 规则：解毒魔术的最高等级体系，必须依靠特定咏唱咒文发动，是治愈魔石病的唯一已知有效手段。
  - 原文依据："魔石病。感觉曾经在哪听过。对了，我记得是只有用神级的解毒魔术才有办法治好的疾病。""我为了设法解救洛琪希前往米里斯神圣国，最后成功获得了神级解毒魔术的咏唱……"

- 名称：冰魔术·冰霜新星
  - 规则：以冰为形象的大范围冷冻魔术。发动后极寒冷气能够瞬间完全覆盖并彻底冻结整个房间的每个角落，可将活物瞬间冻成纯白尸体。
  - 原文依据："想像的是冰，范围要涵盖整个房间。……『……冰霜新星。』我喃喃说道，房间一转眼便遭到冻结。为了以防万一，再来一发。『冰霜……新星。』冷气完全蔓延到房间的每个角落。……它在通往神龛的隐藏通道附近，已经被冻成一片纯白死去。"

- 名称：土魔术塑形与封锁应用
  - 规则：土系统魔术的高度精细化应用，能够从外侧改变墙体结构封锁房间通道，亦能即时制作严密无缝的密封石盒用于保存危险病原体，或塑形出骨灰坛等器具。
  - 原文依据："我用土魔术从外侧封锁了二楼所有家人的房间周遭……我用土魔术作出箱子，用棒子夹起老鼠的尸体放进那里面，再将其完全封死。……燃烧尸体后，我用魔术作出壶器，放进老人的骨灰。"

- 名称：魔眼
  - 规则：鲁迪乌斯所持有的特殊瞳术能力，在进入未知危险环境前可主动发动提升观察与警惕能力。
  - 原文依据："接下来的目的地是地下室。我已经发动魔眼。"

## 四、种族 / 生物
- 名称：带有魔石病的老鼠
  - 特征：外貌特殊的小型啮齿生物，其显著特征为牙齿如紫色透明魔石结晶。一部分老鼠体内对魔石病菌带有免疫抗性，是魔石病的天然传播媒介。被其啃咬过的食物会残留病原菌。
  - 原文依据："地下室八成有老鼠。而且是一只带病的老鼠。它的特徵是长得像紫色魔石一样的牙齿。……魔石病会以老鼠作为传播媒介。不知为何，一部分的老鼠对其拥有抗性。病原体一目了然，牙齿会变成紫色的结晶。然后，被老鼠咬到的东西就会沾上病原菌。……从它半开的嘴巴，可以看到紫色透明的牙齿。那牙齿宛如魔石。"

- 名称：魔王阿托菲
  - 特征：实力超乎想象的强大魔王。在老人的历史线中，鲁迪乌斯曾大意与其再战，导致艾莉丝为掩护鲁迪乌斯而战死。
  - 原文依据："是啊，为了保护我而死的。我记得……那是和阿托菲再战的时候吧。认真的魔王大人超乎想像地强，我太大意了。"

- 名称：光之精灵
  - 特征：封存于特定卷轴中的光属性使魔精灵，释放后可遵从施术者的命令移动巡视并照亮阴暗密闭空间。
  - 原文依据："我从怀里取出光之精灵的卷轴，照亮四周。……我命令光之精灵从洞口入侵照亮房间，再窥探洞口，确认房间里面已经完全冻结。"

## 五、物品 / 道具 / 武器
- 名称：老人的日记簿（未来日记）
  - 说明：未来鲁迪乌斯贴身携带的厚重记录书籍，外表破旧，与鲁迪乌斯当前刚制作完成的日记簿完全一致。详尽记录了未来五十年间老人所经历的一切悲剧与人生，同时也是老人施展“过去转移魔术”跨越时空的起始坐标与媒介。
  - 原文依据："因为我以日记为起点，飞跃回来……所以就带回来了…………上面写着，我经历过的一切…………你就……努力让自己不要后悔吧……从起毛的长袍之中，取出了一本宛如厚重文件夹的书。尽管看起来相当老旧，但是我有印象。这是我刚刚才做好的日记簿。"

- 名称：光之精灵的卷轴
  - 说明：一种便携式魔法消耗卷轴，展开后能释放出光之精灵，用于驱散黑暗与侦察照明。
  - 原文依据："我从怀里取出光之精灵的卷轴，照亮四周。"

- 名称：紫色魔石 / 魔石
  - 说明：世界中存在的魔力结晶矿物。带病老鼠的牙齿呈紫色魔石结晶状，魔石病发作时亦会将生物肉体转变为魔石结晶。
  - 原文依据："它的特徵是长得像紫色魔石一样的牙齿。……是一种会使患者身体逐渐化为魔石的难治之症。……那牙齿宛如魔石。"

- 名称：魔力附属品
  - 说明：放置在夏利亚宅邸地下室内的魔法相关器材或附魔杂物。
  - 原文依据："尽管地下室还放着魔力附属品以及爱夏用在家庭菜园的肥料云云"

## 六、历史 / 传说 / 事件
- 事件名：魔石病病理与感染机制
  - 内容：一种罕见的恶性致死疾病。
    1. 媒介与宿主：老鼠为主要媒介（抗性老鼠牙齿呈紫色结晶），人类罹患率极低；
    2. 传播途径：仅通过口腔接触被污染的食物传染；
    3. 病菌特性：病原菌体外生命力极弱，脱离媒介后最多半天即自行死灭，传染力薄弱；
    4. 感染对象：病原菌进入宿主体内后无法寄生于普通宿主，主要/只会感染孕妇体内的胎儿；
    5. 病理演进：病菌在胎儿体内繁殖生长，逐步取代胎儿并将母体全身组织晶体化（如自脚尖开始结晶），直至母体一半以上魔石化致死；
    6. 救治手段：唯有神级解毒魔术方可治愈。
  - 原文依据："魔石病。感觉曾经在哪听过。对了，我记得是只有用神级的解毒魔术才有办法治好的疾病。是一种会使患者身体逐渐化为魔石的难治之症。……人类罹患魔石病的机率非常少见。那种病原菌会寄宿在体内，只会感染到另一个生命。……没错，就是胎儿。只有孕妇才会罹患那种疾病。……魔石病会以老鼠作为传播媒介。不知为何，一部分的老鼠对其拥有抗性。病原体一目了然，牙齿会变成紫色的结晶。然后，被老鼠咬到的东西就会沾上病原菌。这种病只会经由口腔传染，而且病原菌无法久活。顶多半天就会死灭，而且感染力薄弱，会罹患这种疾病的，只有在孕妇体内的胎儿。病原菌会在胎儿体内成长，就这样代替胎儿，将母体魔石化。……洛琪希会动弹不得，一直卧病在床。当她的脚尖开始结晶化，我才知道那是魔石病。……洛琪希的身体有一半遭到结晶化，死了。"

- 事件名：老人所在世界线的未来悲剧历史（原本的时间线分支）
  - 内容：来自未来的老人经历的历史事件序列：
    1. 洛琪希感染死亡：鲁迪遵从人神建议去地下室，惊动带病老鼠逃至厨房啃食剩饭。怀有身孕的洛琪希食用残留剩饭后感染魔石病。鲁迪赴米里斯神圣国求得神级解毒魔术咏唱归来时已迟，洛琪希半身结晶化身亡；
    2. 希露菲孤立战死：鲁迪因丧妻沉湎悲痛冷落希露菲。人神趁虚托梦操控路克，促使路克进言爱丽儿，希露菲随爱丽儿奔赴阿斯拉王国发动内乱，最终全军覆没战死；
    3. 人神摊牌嘲弄：三十年后人神现身嘲笑鲁迪，坦白一切诱导与谋害皆在其算计之中（“多亏你是个笨蛋，才能让事情按照我所想的发展喔”）；
    4. 艾莉丝死于阿托菲战役：鲁迪因不解艾莉丝苦心与艾莉丝常年对立，艾莉丝暗中守护鲁迪，最终在与魔王阿托菲激战中为保护鲁迪战死，鲁迪受到基列奴谴责；
    5. 克里夫死亡：在未来漫长岁月中克里夫离世；
    6. 七星绝望退场：七星返乡的研究在最后一刻彻底失败，绝望消沉崩溃；
    7. 复仇受挫与时间跳跃：鲁迪虽掌握万能魔术（操控重力、紫电、肢体再生），但因无法抵达人神所在处且缺乏关键条件而无法复仇。最终借助未完成的过去转移魔术以日记为起点跨越50年回到过去，告知鲁迪防范老鼠、致信艾莉丝及警惕人神后重伤力竭身亡。

## 九、角色认知 vs 客观事实
- 角色以为（关于艾莉丝的离开）：
  - 角色以为：鲁迪乌斯以为艾莉丝早已弃自己而去，伤害了自己的心灵并导致ED，彼此过去已经彻底终结。
  - 原文是否暗示另有真相：是。
  - 原文依据：来自未来的老人指出艾莉丝始终深深爱着鲁迪乌斯并愿意为他赌上性命，只是极端笨拙不善表达："艾莉丝只是想要陪在我的身边而已。那家伙，其实一直喜欢着我。喜欢我，为了我赌上性命……但是，她不善言词，不知道该怎么表达才好，所以到头来只能殴打我而已。""如果，这名老人说的话都是事实，那她并没有打算抛弃我，我只是没有明白这件事。仔细想想，她那么不会讲话，当然也没办法写好信表达自己的心情。于是，我们两人擦身而过，产生了不幸吗？"

- 角色以为（关于人神的真实立场与地下室）：
  - 角色以为：鲁迪乌斯以为人神虽然可疑但此前并未撒谎，以为人神真的是在善意提供指引；认为地下室可能真如人神所言空无一物。
  - 原文是否暗示另有真相：是。
  - 原文依据：老人揭发人神此前的诚实全是铺垫，目的是骗取鲁迪毫无防备地开启地下室释放带病老鼠："那家伙乍看之下，尽是说些好像为我着想的话。……确实，他直到现在这个瞬间为止都没撒过谎。从没撒过我听得懂的谎言。……这一切，全都是为了这一次！为了让疑心病重的你，毫不犹豫地遵照他的指示行动的这个瞬间！"随后鲁迪在地下室确实发现了带有紫色魔石牙齿的致命带病老鼠。

- 角色以为（关于洛琪希的受孕情况）：
  - 角色以为：鲁迪乌斯以为洛琪希当前尚未怀孕（“洛琪希还没……”）。
  - 原文是否暗示另有真相：是。
  - 原文依据：老人肯定洛琪希已经怀孕："她应该已经怀孕了。不过这也没啥问题。既然该做的事情有做，这也是理所当然。"洛琪希随后下楼时也难为情地提到最近有在意的事情，印证已受孕。

- 角色以为（关于人神是否绝对无法战胜）：
  - 角色以为：老人认为人神绝对无法战胜，且无法抵达人神的所在地，因而告诫过去的自己绝对不要与人神为敌。
  - 原文是否暗示另有真相：不明 / 存疑。
  - 原文依据：老人宣称："我憎恨人神。但是，我无法战胜那家伙。没有战胜他的方法。因为，我没有办法抵达那家伙的所在之处。在我生存的时代，没有能够抵达人神所在处的必要之物。所以，别和那家伙战斗。……千万别和他为敌。"[存疑：老人同时也提到奥尔斯帝德或拉普拉斯可能知道人神的目的与内情，老人无法抵达并不代表客观上绝对无法被击败]。
