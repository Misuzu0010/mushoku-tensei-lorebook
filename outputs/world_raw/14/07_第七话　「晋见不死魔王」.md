# 第七话　「晋见不死魔王」 世界设定提取

## 一、地理与场所
- 名称：旧奇希莉卡城
- 内容：外观为以特殊石材建造成的黑铁魔王城，重视实用性，疑似天守阁的位置开有大洞。城堡平时作为观光景点对外开放参观并收取门票，划分为可供观光的区域（如广阔金碧辉煌的王座之间）与不可参观的实用性区域（如狭窄务实的晋见之间）。城堡地下设有可通往城外的秘密通道，且地下环境适合避光植物（如索卡司草）的栽培。
- 原文依据："旧奇希莉卡城。这里的外观一言以蔽之，就是魔王城。是以特殊石材建筑而成的黑铁之城。尽管没有佩尔基乌斯的空中要塞那么纤细优美，但也是座相当出色的城堡。如果是重视实用性的人类，肯定更中意这边。疑似天守阁的场所位置开了一个大洞，算是美中不足之处。平常这座城堡作为观光胜地开放参观，甚至还会收取门票，似乎分为能作为观光景点供人参观的场所，以及无法参观的场所。我们被带到的场所，是晋见之间。不是开放参观的广阔又金璧辉煌的王座之间，而是狭窄务实的场所。"

- 名称：城堡地下密道
- 内容：位于旧奇希莉卡城地下的秘密通道，能够直接通往城镇外部，出口位于城外环形山斜坡的古代转移魔法阵入口附近。曾被奇希莉卡声称在拉普拉斯战役中被巴迪冈迪打坏[存疑]，但实际上畅通可用。
- 原文依据："城堡地下有一条通往城镇外面的密道，请从那里逃走吧。""仔细一看，通往转移魔法阵的入口附近还开着另外一个洞。该不会，地下通道的出口就是这里……？""十名黑铠士兵从地下绕过来"

- 名称：环形山城镇（夜晚景象与出入口）
- 内容：城镇建立在环形山内部，环形山的峭壁在夜间会投射辉煌的光芒，使得城镇夜晚的大街依然相当明亮。城镇入口位于环形山的龟裂处，有守卫驻守放行。穿过入口沿着环形山外围斜坡往上，可抵达古代转移魔法阵遗迹。
- 原文依据："原本想要摸黑逃跑，但周围还相当明亮。这都要归咎于环形山的峭壁投射了辉煌的光芒。""于是，我们来到了环形山的龟裂处，也就是城镇的入口。尽管没看到黑铠士兵，但是守卫还在。是蜥蜴头和猪头。他们见到我们之后虽然感到些许困惑，但还是坦率放行。""我们沿着环形山的外围进行移动。……往这个方向，有我们使用过的转移魔法阵。"

## 二、组织与势力
- 名称：阿托菲亲卫队
- 内容：不死魔王阿托菲拉托菲·雷白克麾下的精锐亲卫队，全员装备黑色全身铠甲。其行动具有极高的纪律约束，在未收到命令时无法擅自行动，但一旦收到命令便会绝对执行、全力追捕目标。亲卫队大部分成员为自愿加入，但也有不少是在与阿托菲决斗败北后被迫签订终身契约的人族等成员，人族往往对此深感哀怨。穆亚为亲卫队代表及阿托菲的得力心腹。
- 原文依据："在这样狭窄的房间中，身穿黑色全身铠甲的一群人并排而站。""能穿上魔大陆最棒的铠甲，接受魔大陆最顶级的训练，加入号称魔大陆最强的亲卫队。""「只要没有命令，我等亲卫队就无法行动。但是一旦收到命令……绝不会让你们逃走。」""「在这里的人大半都是出于自愿才成为阿托菲陛下的亲卫队，但并非如此的人也不在少数。尤其人族多数都为此哀怨。我们也有点于心不忍。」"

## 三、力量体系 / 魔法 / 技能
- 名称：不死身的肉体再生
- 规则：不死魔王阿托菲拉托菲·雷白克等不死魔族具备极强的身体再生与不死特性。被切断的肢体会转化为柔软的肉块，掉落后可自行蠕动回归原位并迅速黏合复原；即使头面部骨骼被重击粉碎或墙壁撞碎打飞，也能迅速恢复完好；普通的物理冲击和物理斩击对其无法构成致命伤害。老战士穆亚被大剑正面劈裂头盔并头部大出血后，也能通过头部冒白烟迅速自愈复原。
- 原文依据："离开阿托菲身体的那瞬间，手臂就化为柔软的肉块。当札诺巴松开手后，肉块啪地一声掉在地下。随后开始不断蠕动，回到阿托菲身上并黏在她的手臂。然后，转眼之间就形成原来的手臂模样。……物体伤害对他们无效吗？""阿托菲的脸剧烈变形，宛如会发出「咻」的一声似的，在空中画出一条美丽的抛物线飞了出去。然后撞上了王座后面的墙壁，伴随着嘎啦嘎啦的声音连同墙壁一起破坏，飞出城堡之外。……毕竟是不死魔王嘛""老士兵若无其事地站了起来。他的脑袋冒出腾腾白烟，同时向阿托菲低头致意。看来似乎没事。该不会这个人也是不死系一族吗？"

- 名称：神子体质与弱点
- 规则：神子（如札诺巴）天生拥有常人无法匹敌的怪力与坚韧肉体，普通物理攻击无法伤其分毫，对物理冲击具有极高抗性。但神子并非绝对无敌，札诺巴存在怕火的弱点，面对过量或特殊毁灭性攻击仍可能死亡。
- 原文依据："札诺巴紧紧抓住逼近而来的阿托菲的手臂。阿托菲打算把札诺巴一脚踢开继续前进，然而，札诺巴却阻止了阿托菲的行进。该说不愧是神子之力吗？""札诺巴是神子。普通的攻击无法伤他一根寒毛，但他也并非无敌。……札诺巴也有怕火这个弱点。他只是对物理冲击具有相当抗性，不代表他不会受到伤害。"

- 名称：斗气
- 规则：战士缠绕于肉体上的防御与强化能量。阿托菲在以剑打、脚踢发现无法撼动札诺巴的肉体后，误以为札诺巴肉体坚硬是因为身上缠绕了高水准的斗气。
- 原文依据："「你这家伙真坚硬啊。看来你缠绕了颇有水准的斗气在身上！有趣！」"

- 名称：电击魔术
- 规则：通过魔导义手瞬间释放紫电的魔术。施术时带有闪烁电光与劈啪声响，能在一瞬间对目标施加强烈麻痹与电击伤害，打断强力招式的蓄力过程，但施术者的手臂下端也会出现麻痹反冲。
- 原文依据："我的义手朝向阿托菲发出紫电。随着啪哩一声，眼前视野瞬间闪烁。「呜嘎啊！」阿托菲弓起身子，大剑自手中脱落。同时，我的左手肘以下也整个发麻，但不要紧。我并没有灌注足以电死人的魔力。"

- 名称：北神流剑术及奥义
- 规则：由北神卡尔曼·雷白克创立的流派。阿托菲作为卡尔曼之妻熟稔该剑术，出剑速度快至肉眼无法捕捉，大剑可摆出大上段架势发动"北神流奥义"。
- 原文依据："阿托菲拔出宝剑，以视线也无法捕捉的一刀砍向老士兵。""我是不死魔王阿托菲拉托菲•雷白克！北神流开祖，卡尔曼•雷白克的妻子！就让你见识一下真正的北神流！""阿托菲举起大剑，摆出大上段架势。……「呼哈哈哈哈哈！受死吧！北神流奥义……」"

## 四、种族 / 生物
- 名称：不死魔族 / 不死系一族
- 特征：阿托菲拉托菲·雷白克具有蓝黑色肌肤、白色头发、深红色眼睛、额头突出单根大角，背部长有蝙蝠般的翅膀（可用于在空中快速飞行）。肉体拥有接近不灭的再生能力，断肢化为软肉后可重新吸附愈合。亲卫队的穆亚等人士兵亦展现出被击穿头部依然不死的极强生命力与自愈特性。此外，阿托菲听不懂人类语，仅使用魔神语沟通。
- 原文依据："蓝黑色肌肤、白色头发、深红色眼睛、犹如蝙蝠的翅膀，还有从额头突出的一根大角。""离开阿托菲身体的那瞬间，手臂就化为柔软的肉块。当札诺巴松开手后，肉块啪地一声掉在地下。随后开始不断蠕动，回到阿托菲身上并黏在她的手臂。然后，转眼之间就形成原来的手臂模样。""他的脑袋冒出腾腾白烟，同时向阿托菲低头致意。看来似乎没事。该不会这个人也是不死系一族吗？""正确说来，她好像听不懂人类语。""「哼，用飞的马上到了。你们奔跑的身影，我也看得一清二楚。」阿托菲一边动着背后的翅膀一边回答。"

- 名称：蜥蜴头魔族 / 猪头魔族
- 特征：魔大陆的魔族居民，头部呈现蜥蜴或猪的形态，在环形山城镇的龟裂入口担任城镇守卫。
- 原文依据："尽管没看到黑铠士兵，但是守卫还在。是蜥蜴头和猪头。他们见到我们之后虽然感到些许困惑，但还是坦率放行。"

## 五、物品 / 道具 / 武器
- 名称：黑铠（阿托菲亲卫队铠甲）
- 说明：阿托菲亲卫队配发装备的黑色全身铠甲，号称“魔大陆最棒的铠甲”。阿托菲本人所穿的黑铠遍布伤痕、装饰剥落，属于身经百战的古旧铠甲。
- 原文依据："服装和士兵们相同，都是黑色铠甲。不，看得出来铠甲使用得比其他人更有历史。铠甲的表面遍布伤痕，装饰也早已剥落。是身经百战的铠甲。""「来人啊，给这两个家伙预备用的黑铠，并准备签订契约！」「能穿上魔大陆最棒的铠甲，接受魔大陆最顶级的训练，加入号称魔大陆最强的亲卫队。」"

- 名称：阿托菲的大剑 / 宝剑
- 说明：阿托菲佩戴于腰间的巨剑，剑鞘比普通士兵更为气派。威力极大，一击便可将头盔劈成两半并击碎头骨。
- 原文依据："而且她的腰间插着一把大剑，让人难以想像她是否能用那双纤细的手臂挥舞。剑鞘也比士兵们佩带的更为气派。""阿托菲拔出宝剑，以视线也无法捕捉的一刀砍向老士兵。……头盔滚到了我的面前，从正中间开出一道裂痕。好惊人的威力。我不经意地捡起一看，发现里面满是鲜血。"

- 名称：索卡司草
- 说明：一种药用植物，叶子呈褐色，外形类似干瘪的芦荟。其特性是禁不起日光照射，必须栽种在无光的地下环境中。伴有专门记录栽培注意事项的笔记（由魔神语书写）。
- 原文依据："您的同伴现在应该也已经采好索卡司草了""他们两人把背包里面塞满了茶叶，两手还拿着盆栽。叶子呈现褐色，造型像是干瘪的芦荟。这就是奇希莉卡提到的草吗？「听说这种草禁不起日光照射，必须放在地下才能栽培。只是虽然有拿到栽种的笔记，但我看不懂内容。」"

- 名称：古代转移魔法阵
- 说明：留存在魔大陆环形山外部斜坡洞穴中的古代魔法阵设施，仍具备跨空间转移功能。
- 原文依据："「往这个方向，有我们使用过的转移魔法阵。」「哦，转移魔法阵啊？居然还留着那种东西」""在斜坡之上。我们曾经使用过的转移魔法阵的入口。阿托菲就挡在那里。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：历史上的大战役。奇希莉卡提及旧奇希莉卡城的地下通道在拉普拉斯战役期间被巴迪冈迪破坏[存疑]。
- 原文依据："「其实地下通道应该早在拉普拉斯战役就遭巴迪冈迪打坏，现在依旧维持原样。」"

- 事件名：阿托菲的战史与婚姻
- 内容：阿托菲拉托菲·雷白克在长达五千年的历史中未尝败绩，唯二能战胜她的只有丈夫北神卡尔曼·雷白克以及魔神拉普拉斯。阿托菲是已故魔界“五大魔王”之一的女儿，也是北神流开祖卡尔曼·雷白克的妻子，生有一子且已有一百年未曾见面。
- 原文依据："「在这五千年来，除了北神卡尔曼大人以及魔神拉普拉斯大人以外无人能敌的吾等之王，你认为能战胜她吗？」""「过去身为五大魔王之一的令尊肯定会非常失望！不光只是如此，您的丈夫雷白克大人的……」""「北神流开祖，卡尔曼•雷白克的妻子！就让你见识一下真正的北神流！」""「我自己也已经有一百年没见到儿子了，没有消息就是平安无事的证据。」"

- 事件名：三大魔王赐予能力的民间传闻
- 内容：魔族传统传闻中，魔界三位魔王各自拥有授予他人的能力特质：奇希莉卡授予他人魔眼，巴迪冈迪授予他人智慧，阿托菲拉托菲则是授予他人力量。
- 原文依据："「这件事情，我就想说以前曾经在哪里听过。奇希莉卡授予他人魔眼，巴迪冈迪授予他人智慧，阿托菲拉托菲则是授予他人力量。」"

- 事件名：魔王与勇者对决传统
- 内容：在阿托菲的认知与民间传说中，勇者经历漫长旅程挑战魔王，步入王座之间决战具有极高荣耀；击败阿托菲者会被授予“勇者”称号，败北者则成为其傀儡奴隶。
- 原文依据："「你知道吗？勇者经过漫长旅程才得以挑战魔王，据说当他步入王座之间准备和魔王交战时，心情可是非常骄傲喔。」""「只要能打赢我，就赐予你们勇者的称号！要是输了，就成为我的傀儡，被我使唤到断气为止！」"

## 七、社会规则 / 习俗 / 文化
- 内容：阿托菲的“奖赏”与强制契约制度：阿托菲向建立功勋或被其看中的人赐予“奖赏”，实质上是强迫对方加入其亲卫队，接受其日夜无休长达十年的严苛修行。若拒绝奖赏，阿托菲会视为挑衅并提出决斗；决斗战败失去意识后会被强制缔结不可违抗的终身奴隶契约，服役直到死亡为止。亲卫队服役待遇为“每服役十年可获得两年休假”（相当于做五休一），受契约约束者无法反抗阿托菲的命令。
- 原文依据："「另外，还请两位不要收下阿托菲大人赐予的奖赏。」「如果事情演变成要收下奖赏，到时我们也无能为力。」""「我要赐予你的，就是加入我的亲卫队锻炼身体的权力！」「今后十年，会由我日夜无休，好好严格锻炼你。怎样？荣幸吧？」""「一旦在决斗中败北，将会在失去意识的情况下被强制缔结契约。届时，你们就再也无法违抗阿托菲大人的命令。」「请……请问契约期间会持续多久？」「当然是到死为止。」「不过，每十年就可以获得为期两年的休假。」"

- 内容：城堡观光经营模式：魔大陆的魔王城堡（旧奇希莉卡城）兼具行政与商业观光功能，划分为收费开放的观光区域（宽阔华丽的王座大厅）以及非公开的实用区域（实际办公/晋见的狭小晋见室）。
- 原文依据："平常这座城堡作为观光胜地开放参观，甚至还会收取门票，似乎分为能作为观光景点供人参观的场所，以及无法参观的场所。我们被带到的场所，是晋见之间。不是开放参观的广阔又金璧辉煌的王座之间，而是狭窄务实的场所。"

- 内容：亲卫队行动准则：亲卫队受军规与绝对命令约束，未收到主上阿托菲的明确命令前无法擅自行动（甚至主君被打飞时也仅能驻足围观等待命令），但一旦收到追击或作战命令则绝不放过目标；对于未涵盖在命令内的对象（如奇希莉卡逃走）则会视而不见。
- 原文依据："「只要没有命令，我等亲卫队就无法行动。但是一旦收到命令……绝不会让你们逃走。」""「我可以把奇希莉卡大人也一起带走吗？」「……可以，因为我等的任务，只到抓住奇希莉卡大人。」"

## 九、角色认知 vs 客观事实
- 角色以为：奇希莉卡以为旧奇希莉卡城的地下通道早在拉普拉斯战役中就已被巴迪冈迪打坏，如今依然维持原样无法通过，劝阻鲁迪乌斯等人走地下密道。
- 原文是否暗示另有真相：是。
- 原文依据："「刚才被你背叛让本宫很不开心，因此闷声不说，但其实地下通道应该早在拉普拉斯战役就遭巴迪冈迪打坏，现在依旧维持原样。」" vs "仔细一看，通往转移魔法阵的入口附近还开着另外一个洞。该不会，地下通道的出口就是这里……？……十名黑铠士兵从地下绕过来，其他人则从地上追踪。"（客观事实是地下通道不仅可以使用，而且正是直通城外转移魔法阵的快捷出口，黑铠士兵已借此先行设伏）。

- 角色以为：阿托菲以为鲁迪乌斯在收受奖赏一事上反反复复，是在故意戏弄她、嘲讽她脑子愚笨。
- 原文是否暗示另有真相：是。
- 原文依据："「是吗，原来你在耍我啊！一会儿说要奖赏一会儿又说不要收下！肯定是认为我脑袋不好在耍我对吧！」" vs 鲁迪乌斯的真实想法是："尽管我不清楚奖赏是什么……总之，我也无意收下。借由出卖奇希莉卡换取某种利益，我不打算做出这种畜生的举动。""既然她说什么都想给的话，那还是收下比较好。……但是穆亚先生刚才说不要收下比较好。……因为我还有家人在等我，实在无法离家十年之久。"（客观事实是鲁迪因穆亚警告与顾及家人而不想入队，并非戏弄阿托菲，但阿托菲性格暴躁粗线条，无法理解常人顾虑）。

- 角色以为：阿托菲认为札诺巴肉身异常坚硬、能接下重击是因为“缠绕了颇有水准的斗气”。
- 原文是否暗示另有真相：是。
- 原文依据："「你这家伙真坚硬啊。看来你缠绕了颇有水准的斗气在身上！有趣！」" vs "该说不愧是神子之力吗？……札诺巴是神子。普通的攻击无法伤他一根寒毛，但他也并非无敌。……他只是对物理冲击具有相当抗性，不代表他不会受到伤害。"（客观事实是札诺巴的坚韧是作为神子的肉体天生对物理冲击具有抗性，而非后天修炼斗气的结果）。

- 角色以为：鲁迪乌斯起初以为穆亚放走他们并提供地下密道是出于同情与善意。
- 原文是否暗示另有真相：是。
- 原文依据："穆亚走近我们。……「快逃吧。」穆亚清清楚楚地这样说道。「您的同伴现在应该也已经采好索卡司草了，城堡地下有一条通往城镇外面的密道，请从那里逃走吧。」" vs 奇希莉卡指出："「刚才那个男人是个骗子。毕竟穆亚是相当于阿托菲右手的存在。满嘴胡言乱语，为的是将事情导向对阿托菲有利的方向。」"以及最终结果："「不愧是穆亚，如他所料啊。待会儿必须好好夸夸他才行。」……阿托菲从空中追赶。十名黑铠士兵从地下绕过来，其他人则从地上追踪。从三方向进行追击……退路也遭到封锁，我们已无处可逃。"（客观事实是穆亚身为参谋，深谙阿托菲喜好亲自追捕的习性，表面放行实则布下地下、空中、地面的三路包夹之局）。

- 角色以为：鲁迪乌斯以为阿托菲所谓赐予的“力量”是类似奇希莉卡授予魔眼或某种神秘引导提升潜能的方式。
- 原文是否暗示另有真相：是。
- 原文依据："「请问您要赐予我什么呢？」这样提问后，阿托菲满足地眯起眼睛。「力量。」……奇怪？不是像那种把手放在头上借此激发我的潜在能力，或是像奇希莉卡那样，赐予我魔眼吗？" vs "「我要赐予你的，就是加入我的亲卫队锻炼身体的权力！」「你看起来很软弱，但没关系，只要修行个十年，想必就能达到一定水准。」「今后十年，会由我日夜无休，好好严格锻炼你。怎样？荣幸吧？」"（客观事实是阿托菲所说的力量纯粹指通过十年的高强度亲卫队体能操练来变强）。
