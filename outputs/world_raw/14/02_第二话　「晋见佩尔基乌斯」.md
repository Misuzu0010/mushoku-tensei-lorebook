# 第二话　「晋见佩尔基乌斯」 世界设定提取

## 一、地理与场所
- 名称：空中要塞大厅（王座之厅）
  - 内容：佩尔基乌斯城堡内的晋见大厅。空间十分宽敞，高耸天花板由树木般的大柱支撑，悬挂着散发灿烂亮光的巨大吊灯，金碧辉煌。墙上挂着描绘阿斯拉王国、米里斯神圣国名产及未知纹章的标语布条。丝绒地毯前方高出两层处设有王座。
  - 原文依据："这里的空间十分宽敞。高耸的天花板被像大树般的柱子支撑。只要抬头仰望，即可看见巨大的吊灯正发出灿烂亮光。实在非常豪华，可谓金碧辉煌。再加上墙上也挂着几幅宛如悬挂标语的布条，上头描绘着许多复杂的纹章。举凡阿斯拉王国和米里斯神圣国的名产，或是随处可见的东西以至未曾见过的东西都应有尽有。然后，站在我们踏步前行的这条丝绒地毯两侧的，是十一名男女。"、"距离不过短短十步的前方，有个被摆放在高出两层位置的王座。佩尔基乌斯坐在那里，一语不发地俯视我们。"

- 名称：空中要塞客房区域
  - 内容：城堡内接待客人的区域，有将近二十间内部装潢完全相同的房间。屋内陈设深色木雕家具、极其柔软的羽毛床、巨大透明的镜子及酒类，仅装饰画内容略有不同。整个广阔要塞仅由佩尔基乌斯的十二名使魔打扫管理，打扫得一尘不染但缺乏常人生活气息。
  - 原文依据："在希瓦莉尔的带领下，我们抵达了客房。客房所在的区域，有将近二十间内部装潢完全相同的房间。绽放出深色光彩的木雕家具以及羽毛床。巨大又极为透明的镜子。在柜子摆着疑似酒类的物品。要说到不同之处，顶多就是装饰在房间的绘画内容而已。"、"『这么宽广的场所，仅仅由十二人来进行管理吗……』我对爱丽儿说的这句话留下了很深的印象。尽管所有地方都打扫得一尘不染，但丝毫没有人类的气息。"

- 名称：空中要塞宝物殿
  - 内容：佩尔基乌斯要塞中的宝库，收藏着许多「狂龙王」卡奥斯制作的艺术品与活动人偶。
  - 原文依据："佩尔基乌斯眯起眼睛，开心地笑了。『看样子你还懂得欣赏艺术。好。这座城堡的宝物殿之中，也有许多卡奥斯的作品。待会儿再让你见识一番。』"

- 名称：拜乌的迷宫
  - 内容：大约两百年前佩尔基乌斯的好友救出艾莉娜丽洁的古代迷宫。
  - 原文依据："『艾莉娜丽洁•杜拉冈罗德。吾记得，你应该在大约两百年前由吾的好友亲手从拜乌的迷宫拯救出来才是。』"

## 二、组织与势力
- 名称：佩尔基乌斯麾下的十二使魔
  - 内容：侍奉佩尔基乌斯的十二名仆役（包含希瓦莉尔、光之阿尔曼菲等）。外表与人类完全无异，身穿不同设计的白色衣服（白领阶级），脸上佩戴各种各样不同造型的面具（模仿动物外形、遮眼射激光状、露出嘴巴的头盔、水桶状等）。推测八成皆具备剑王级的实力（阿尔曼菲曾与剑王基列奴打成平手），负责护卫佩尔基乌斯及管理要塞全境。
  - 原文依据："他们所有人都身穿白色衣服。尽管每个人身上衣服的设计都略有不同，但颜色同样是白色。是白领阶级。所有人脸上都戴着面具。他们所戴的面具也都大相迳庭。有模仿动物外形设计的面具，感觉像是能从眼睛射出强力雷射，只遮住眼部的面具。还有像机器型警察那种只露出嘴巴的头盔，甚至还有那种看起来就像水桶的。想必他们就是佩尔基乌斯麾下的十二名使魔。虽说是使魔，外表和人类却别无二致。以前，阿尔曼菲曾经和基列奴战得难分难解。换句话说，包含希瓦莉尔在内的这十二个人，八成都具有剑王级的实力。"

- 名称：五龙将 [存疑/角色记忆]
  - 内容：相传在神话时代由一名龙帝与四名龙王组成的五人团体，曾以五敌一抗衡龙神。成员称号包括：甲龙王佩尔基乌斯•朵拉、冥龙王马克士威、狂龙王卡奥斯、圣龙帝席拉德，尚有一名龙王姓名未明。现存持有该称号者并非神话时代的本人，应当冠有代数。
  - 原文依据："我记得那群人叫作『五龙将』来着。据说在神话时代，他们曾经以五敌一和龙神战得平分秋色。但再怎么说也不会是当时的本人，应该会在名字前附加个第几代才对。甲龙王佩尔基乌斯，冥龙王马克士威，还有狂龙王卡奥斯。而在转移遗迹的咏唱中出现的是圣龙帝席拉德。这样一来就四个人了。我记得是一名龙帝和四名龙王，所以还有一名龙王吗？"

- 名称：阿斯拉王国王位争夺阵营
  - 内容：第二公主爱丽儿•阿涅摩伊•阿斯拉在阿斯拉王国的王位争夺战中败北逃出，企图挑起泥沼战争争夺王位，并希望借助佩尔基乌斯的力量作为后盾。佩尔基乌斯当面指出其企图，但因命运巧合仍准许其留在城堡。
  - 原文依据："佩尔基乌斯叹了一口气。『吾知道你。就是在阿斯拉王国的肮脏王位争夺战中败北，依旧恬不知耻，想挑起一场泥沼战争，想把所有人都卷入其中的愚蠢女人。』……『来到这里，是盼望有机会的话可以仰仗吾的力量吗？』……『不过，既然来到这里，那么这也是命运。就给你机会吧。允许你滞留在吾的城堡。』"

## 三、力量体系 / 魔法 / 技能
- 名称：转移魔术的魔力限制规则
  - 规则：佩尔基乌斯所使用的该套转移魔术存在限制，无法施加在魔力量超过施术者自身的目标身上；且若对方认真抵抗，亦无法强行实施转移。
  - 原文依据："『要把你转移过来，让吾稍微费了一番工夫。』『……？』『原本那套转移魔术，无法使用在魔力超过自身之人身上。』佩尔基乌斯不屑地这样说道。『你的魔力让吾联想到拉普拉斯。如果你认真抵抗，那吾也没办法将你转移吧。』"

- 名称：召唤术的法则与限制
  - 规则：
    1. 施术者无法召唤拥有比自身魔力更庞大的对象。
    2. 七星属于异世界肉身召唤，佩尔基乌斯直言连自己都无法办到召唤七星，推断当世无人能够凭人力做到，因此认定七星转移事件为偶然引发的意外 [存疑，佩尔基乌斯个人认知]。
    3. 探求召唤知识是龙族宿命；七星与佩尔基乌斯达成交易，七星以异世界召唤研究成果换取本世界召唤术精髓。
  - 原文依据："『成果……探求知识，才是吾等龙族的宿命。』……『希望您能按照约定，将有关这个世界的召唤术知识倾囊相授。』『好吧。』"、"『要召唤这个人，就算是吾也办不到。既然如此，在这世上就没有任何人能办到此事。』『也就是说？』『那并非是人为导致，而是偶然引发的意外。』"、"佩尔基乌斯说无法召唤拥有比自己的魔力还要巨大的对象。"

- 名称：迷宫核心机制与人类变质（神子/咒子转化）
  - 规则：古老的迷宫会捕捉人类作为自身运作的心脏。成为心脏的人类因魔力产生质变，无一例外均会丧失记忆，并获得被称为“咒子”或“神子”的神秘力量（诅咒或特殊体质）。塞妮丝及两百年前的艾莉娜丽洁均因充当迷宫心脏而陷入此状态。
  - 原文依据："『吾曾听闻古老的迷宫会捕捉人类，使其充当自己的心脏运作。然后，成为心脏之人会由于魔力产生变化，无一例外均会丧失记忆，并且会获得神秘的力量。』『神秘的力量？』『就是被称为咒子，或者是神子之人所拥有的力量。』"、"『艾莉娜丽洁•杜拉冈罗德。吾记得，你应该在大约两百年前由吾的好友亲手从拜乌的迷宫拯救出来才是。』"

- 名称：迷宫乐园假说 [存疑]
  - 规则：佩尔基乌斯听闻的一说，认为迷宫是古代魔族为了制造乐园而诞生的魔物，从核心魔力结晶将魔力平等分配给内部生物，使内部生物免于饥饿。但鲁迪乌斯依据洛琪希在迷宫中依然饥饿的实际经验，认为此说法言过其实。
  - 原文依据："『不知。但吾曾听闻一说，迷宫是古代魔族为了制造乐园而诞生的魔物。会从核心的魔力结晶将魔力平等地分给迷宫内部的人。生存于里面的生物会成为与饥饿无缘的存在，得到繁荣。古老的迷宫为了提高分配魔力的效率而将人吞至体内，也没什么不可思议。』"、"不对喔，我听洛琪希说她在迷宫里面也会感到饥饿。会给内部的人平均分配魔力，想必这种说法言过其实。"

- 名称：鲁迪乌斯的魔力性质
  - 规则：鲁迪乌斯的魔力量庞大至能让人直接联想到魔神拉普拉斯，佩尔基乌斯对其魔力感到作呕并严加警戒，警告其不可在城内妄用该股魔力。
  - 原文依据："『你的魔力让吾联想到拉普拉斯。如果你认真抵抗，那吾也没办法将你转移吧。』……『罢了。但是，你可别妄想在这个城内，使用那股强大又令人作呕的魔力。』"

## 四、种族 / 生物
- 名称：龙族
  - 特征：龙神奥尔斯帝德与「甲龙王」佩尔基乌斯•朵拉皆属于龙族而非人族。外貌特征包含亮丽银发、三白眼以及金色眼眸，散发压倒性的王者气息与令人战栗的威压感。以“探求知识”为种族宿命。
  - 原文依据："光辉亮丽的银发，彷佛在震慑对手般的三白眼以及金色眼眸。加上从全身散发出来的王者气息。他，即为王者。『甲龙王』佩尔基乌斯。"、"『成果……探求知识，才是吾等龙族的宿命。』龙族，他是龙族吗？虽然我至今对此并无特别在意，这才明白了。龙神，还有甲龙王，他们并非人族，而是龙族啊。难怪他们给人的感觉相像，原来是因为种族相同。"

- 名称：长耳族（艾莉娜丽洁•杜拉冈罗德）
  - 特征：拥有豪奢金发与长耳的长寿种族。艾莉娜丽洁在两百年前曾被从拜乌的迷宫中救出，当时为失忆少女，体内带有类似咒子/神子的诅咒。
  - 原文依据："佩尔基乌斯送出的视线前方，是名有着一头豪奢金发的长耳族女性。艾莉娜丽洁缓缓地抬起头来。『艾莉娜丽洁•杜拉冈罗德。吾记得，你应该在大约两百年前由吾的好友亲手从拜乌的迷宫拯救出来才是。』……『丧失记忆的长耳族少女啊。过去吾曾见过你一次。看来你成长了不少，如今已经不记得吾了吧？』"

- 名称：神子 / 咒子
  - 特征：身负神秘力量的人群，可因魔力变质（如被古老迷宫当成心脏）而产生。神子倾向于拥有特殊恩赐/正面神秘力量，咒子则带有诅咒性质力量。
  - 原文依据："『就是被称为咒子，或者是神子之人所拥有的力量。』"、"何况塞妮丝的诅咒似乎也不至于危及性命，我猜想或许是成为神子，又或者是没有任何变化……"

- 名称：暴食恶魔
  - 特征：大量栖息于转移迷宫内部的魔物，数量极多。
  - 原文依据："话说起来，在转移迷宫内部有着大量的魔物。特别是暴食恶魔多到让人觉得恶心。"

## 五、物品 / 道具 / 武器
- 名称：自动人偶设计图与札诺巴的小册子
  - 说明：札诺巴在夏利亚鲁迪乌斯住宅（原废屋）地下发现的册子与字条，其上用未见过的文字记载着会自行活动的人偶设计图，工艺技术极其精湛。册子表面刻有「狂龙王」卡奥斯的纹章。卡奥斯本人制作了许多人偶与艺术品。
  - 原文依据："札诺巴干脆地这么说完后，从怀里取出一本小册子。在册子的表面上画着一个纹章。……『当然知道。你手上拿的，是属于「狂龙王」卡奥斯的纹章。』"、"『这是……在本王子师傅位于魔法都市夏利亚的住家，过去还曾是栋废屋时发现的。上面还画着会自行活动的人偶设计图。』……『刻划在细节部分的技术让人心醉神迷，充分表达出制作者对人偶的热爱！』"、"虽说那份字条上的语言是我从来没见过的……"

- 名称：龙族各纹章
  - 说明：悬挂于空中要塞大厅墙壁上的各龙族纹章，彼此风格极其酷似：
    1. 龙神奥尔斯帝德的纹章（亦刻于七大列强石碑上）。
    2. 圣龙帝席拉德的纹章（曾刻于隐藏转移遗迹的魔道具上）。
    3. 冥龙王马克士威的纹章（刻于要塞门上）。
    4. 甲龙王佩尔基乌斯•朵拉的纹章。
    5. 狂龙王卡奥斯的纹章（刻于人偶图纸与小册子上）。
  - 原文依据："札诺巴的视线，投向并排挂在上面的纹章，在那之中有我眼熟的纹章。其中一个是刻在列强石碑上的纹章。那是龙神奥尔斯帝德的纹章。另外一个则是在隐藏着转移遗迹的魔道具上所画的纹章。按照当时的咏唱推断，应该是圣龙帝席拉德的纹章。然后，在其旁边，和札诺巴手上的是相同的纹章。『当然知道。你手上拿的，是属于「狂龙王」卡奥斯的纹章。』"

- 名称：客房羽毛床与高级家具
  - 说明：空中要塞客房内的设施，配备深色木雕家具、高透明度大镜子，以及极其柔软、宛如整个人要沉入地底般的羽毛床。
  - 原文依据："绽放出深色光彩的木雕家具以及羽毛床。巨大又极为透明的镜子。"、"床柔软到就像要这样直接沉入地底似的。"

## 六、历史 / 传说 / 事件
- 事件名：神话时代五龙将抗衡龙神传说 [存疑/角色记忆]
  - 内容：神话时代，五龙将（一名龙帝与四名龙王）曾以五敌一与龙神战得平分秋色。
  - 原文依据："我记得那群人叫作『五龙将』来着。据说在神话时代，他们曾经以五敌一和龙神战得平分秋色。"

- 事件名：四百年前封印魔神拉普拉斯
  - 内容：魔神拉普拉斯在四百年前被佩尔基乌斯等英雄联手封印。
  - 原文依据："拉普拉斯。据说是在四百年前遭到佩尔基乌斯等人封印的魔神之名。在评价我的魔力时，每个人都会道出这个名字。"

- 事件名：约两百年前艾莉娜丽洁被救出事件
  - 内容：大约两百年前，佩尔基乌斯的好友亲手将失忆的长耳族少女艾莉娜丽洁从拜乌的迷宫中救出。佩尔基乌斯曾见过她一次。
  - 原文依据："『艾莉娜丽洁•杜拉冈罗德。吾记得，你应该在大约两百年前由吾的好友亲手从拜乌的迷宫拯救出来才是。』『是的。』『丧失记忆的长耳族少女啊。过去吾曾见过你一次。看来你成长了不少，如今已经不记得吾了吧？』"

- 事件名：狂龙王卡奥斯去世
  - 内容：「狂龙王」卡奥斯在几十年前已经离世，佩尔基乌斯不知其是否有后继者。
  - 原文依据："『死了。而且是在几十年前。至于是否有后继者，吾也不知情。』"

- 事件名：菲托亚领地转移事件与奥尔斯帝德遭遇事件
  - 内容：转移事件发生之际，阿尔曼菲曾因鲁迪乌斯试图朝天空施法而展开袭击；后来鲁迪乌斯遭遇龙神奥尔斯帝德并让其手部擦伤，此事传入佩尔基乌斯耳中，使其对鲁迪乌斯怀有高度戒心。佩尔基乌斯曾怀疑转移事件与拉普拉斯有关，但后因召唤七星所需力量过大而断定并非人为。

## 九、角色认知 vs 客观事实
- 转移事件的性质：
  - 角色以为：佩尔基乌斯认为连自己都无法召唤出七星，因此推断世上没有任何人能做到，断言转移事件"并非是人为导致，而是偶然引发的意外"；希露菲与鲁迪乌斯表面上接受了此说法。
  - 原文是否暗示另有真相：是 / 不明。鲁迪乌斯在内心质疑并想到："不对等等，说不定有比佩尔基乌斯更擅长召唤魔术的高手。像是奥尔斯帝德。"佩尔基乌斯自己也承认"这点还未有结论"，断言属个人主观推断，并非定论。
  - 原文依据："『这点还未有结论。当初吾认为可能是拉普拉斯，或是与他勾结的家伙所为，但是……要召唤这个人，就算是吾也办不到。既然如此，在这世上就没有任何人能办到此事。』『也就是说？』『那并非是人为导致，而是偶然引发的意外。』"、"不对等等，说不定有比佩尔基乌斯更擅长召唤魔术的高手。像是奥尔斯帝德。"

- 迷宫乐园假说 vs 实际生存状态：
  - 角色以为：佩尔基乌斯听信一种传闻，认为迷宫是古代魔族为了创造乐园诞生的魔物，能从魔力结晶平等分配魔力，使内部生物免受饥饿。
  - 原文是否暗示另有真相：是。鲁迪乌斯明确指出反例："不对喔，我听洛琪希说她在迷宫里面也会感到饥饿。会给内部的人平均分配魔力，想必这种说法言过其实。"证实该传闻并非完全的客观事实。
  - 原文依据："『不知。但吾曾听闻一说，迷宫是古代魔族为了制造乐园而诞生的魔物。会从核心的魔力结晶将魔力平等地分给迷宫内部的人。生存于里面的生物会成为与饥饿无缘的存在，得到繁荣。』"、"不对喔，我听洛琪希说她在迷宫里面也会感到饥饿。会给内部的人平均分配魔力，想必这种说法言过其实。"

- 佩尔基乌斯对鲁迪乌斯实力的误判：
  - 角色以为：佩尔基乌斯根据传闻得知鲁迪乌斯击伤龙神奥尔斯帝德，且魔力量堪比拉普拉斯，误以为鲁迪乌斯实力极强且会因此心高气傲，甚至有信心与佩尔基乌斯一战，因而高度戒备。

  - 原文依据："『像你这般具有才能的人，有时会过于相信自己的力量。让那名龙神负伤，想必会增长你的气焰。但是，如果你打算与吾一战，可得抱着必死的觉悟。』"、"……难不成，他以为我和奥尔斯帝德战得不分轩轾，最后甚至两败俱伤吧。别开玩笑了。我根本是单方面被虐杀，只是趁机用偷袭的方式打中一发而已。"

- 塞妮丝病状与艾莉娜丽洁的隐瞒：
