# 第五话　「再次前往魔大陆」 世界设定提取

## 一、地理与场所

- 名称：空中要塞（佩尔基乌斯的城堡）
  - 内容：位于天空中的悬浮城堡，具有极高战略防御优势（敌方无法攻入）。城堡地下三层设有转移魔法阵房间。佩尔基乌斯严禁魔族踏入该城堡。
  - 原文依据："换句话说，如果是从这座城堡，就能在一瞬间移动到魔大陆上的大部分城镇。""毕竟可以从位于天空的这座城堡瞬间移动到其他城镇。代表一旦战争爆发，就可以无视地形或守备杀进敌方的领地。当然，对方也没有攻入这座城堡的方法。""佩尔基乌斯好像不管怎样都不想让魔族踏入城堡，我曾试着拜托，但却遭到拒绝。""希瓦莉尔带领我们抵达的房间，应该位于地下三楼。"

- 名称：魔大陆
  - 内容：环境极其险恶的土地。地面呈现红褐色，地势起伏巨大，地平线上四散着岩石，分布着宛如鱼骨的特有森林。栖息着大王陆龟等魔大陆特有生物，魔物巨大凶暴且成群结队。当地居民几乎没有米里斯教徒，通用魔神语。
  - 原文依据："视野下方是一片红褐色的大地。高低起伏很大，四散着岩石的地平线呈现在眼前。在远方可看到宛如鱼骨的森林，是魔大陆特有的景观。在那里移动的是大王陆龟吧？""克里夫前辈，魔大陆有许多巨大又凶暴，而且成群结队的魔物，请你当心。""这里是危险的土地。如果抱着在中央大陆和米里斯大陆时相同心态，就算是高强的战士也会命丧黄泉。""还有，这里恐怕几乎没有米里斯教徒。因此想法会有很大的落差……""因为克里夫不懂魔神语。"

- 名称：利卡里斯镇
  - 内容：魔大陆三大都市之一。整座城镇座落在巨大的天然环形山内部，环形山作为天然城壁可阻挡魔物入侵。环形山内壁埋有魔石，入夜后会发光照亮整座城镇。环形山中央坐落着半毁的黑铁城堡（旧奇希莉卡城）及周围环绕的庞大城镇。
  - 原文依据："我们正站在巨大环形山的边缘地带。视野下方，有座城镇呈现在眼前。在环形山的中央，有一座半毁的黑铁城堡，以及围绕着城堡的巨大城镇。""我知道这个城镇。是魔大陆三大都市之一。环形山形成天然的城壁，防止魔物入侵。而且在入夜之后，埋在环形山内壁的魔石便会发光，照亮整座城镇。……是利卡里斯镇。"

- 名称：旧奇希莉卡城
  - 内容：位于利卡里斯镇中央的半毁黑铁城堡。从前魔界大帝奇希莉卡·奇希里斯曾将此处作为根据地，后来在拉普拉斯和魔王的战斗中有一半遭到破坏。
  - 原文依据："在环形山的中央，有一座半毁的黑铁城堡，以及围绕着城堡的巨大城镇。""我也知道这座城堡的由来。从前，魔界大帝奇希莉卡•奇希里斯曾将此处作为根据地，后来在拉普拉斯和魔王的战斗之中有一半遭到毁坏。别名「旧奇希莉卡城」。"

- 名称：利卡里斯镇外环形山崖壁地下监狱遗迹（废弃转移魔法阵密室）
  - 内容：位于利卡里斯镇外环形山斜坡地下的石造密室与监牢设施。最底层为无门窗的密室，墙壁厚达50公分，内部设有古代单向失效的废弃转移魔法阵；破墙后连通约十平方公尺的废弃监狱房间，地板遗留带铁镣的魔族白骨；顺着走道和楼梯往上，顶端是一扇被沙土掩埋的向上开启式金属盖板门，通往室外陡峭斜坡。
  - 原文依据："转移之后，眼前是一间阴暗的房间。充满了一股霉味和满满的灰尘，感觉已经有很长一段时间没有使用。""上面没有类似门的物品。没有楼梯，天花板上也没有洞。就算仔细观察地面，也果然找不着理应能通往外面的道路。这里是间密室。""厚度应该有五十公分的厚重墙壁上开了一个大洞。""大小约十平方公尺的房间呈现在眼前。……在灰暗房间的地板上，躺着好几具白骨尸体。……「看样子这里似乎是监狱呢。」听艾莉娜丽洁这样说后，我望向骸骨，发现手脚上链着生锈的镣铐。""在楼梯前方有个金属盖子。……有沙土从上方落下。""从门的缝隙之间照射进来的是阳光。看样子是室外没错。……外面是一片陡峭的斜坡。"

- 名称：魔法都市夏利亚
  - 内容：鲁迪乌斯及其家人的现居城市，相比魔大陆危险度相对较低。
  - 原文依据："但是，比起魔大陆，魔法都市夏利亚的危险度应该相对较低才是。"

## 二、组织与势力

- 名称：阿斯拉王国
  - 内容：中央大陆的大国，王室/国内秘藏有功能独特的珍稀魔道具（如成对感应发光的戒指）。
  - 原文依据："爱丽儿将自己带在身上的戒指魔道具提供给我。……似乎是阿斯拉王国秘藏的魔道具。"

- 名称：冒险者公会
  - 内容：在魔大陆各城镇均设有据点，可通过在公会发布悬赏委托来搜寻特定人物（如奇希莉卡）。
  - 原文依据："关于这点，我认为还是仿效洛琪希，在每个镇上的冒险者公会提出搜索委托就可以解决。悬赏魔界大帝，狩猎奇希莉卡。"

- 名称：米里斯教团
  - 内容：发源于米里斯神圣国的宗教势力。魔大陆几乎没有米里斯教徒，当地文化观念与米里斯教义存在极大鸿沟。
  - 原文依据："「唔……愿你们能受米里斯大人的庇佑。」""还有，这里恐怕几乎没有米里斯教徒。因此想法会有很大的落差，还请不要因为多余的事情和人起争执。"

## 三、力量体系 / 魔法 / 技能

- 名称：转移魔法阵（转移术式）
  - 规则：
    1. 成对原则：转移魔法阵以两个一组运作。若其中一端被破坏，另一端就会失去效力。
    2. 重连与绘制：甲龙王佩尔基乌斯掌握了绘制与再连结技术，能绘制新阵并连结至魔大陆单端失效、不再使用的古代废弃魔法阵上。
    3. 运行表象与体感：激活时发出蓝白色光芒；转移时的感觉宛如从梦中清醒。
    4. 无差别传送：魔法阵无法识别使用者身份，若凶暴魔物踏入也会被传送。
    5. 禁忌属性：因能无视地形要塞进行定点瞬移、改变战争形态，很久以前即被视为禁忌并遭到封存，但佩尔基乌斯、奥尔斯帝德等人仍在暗中掌握与使用。
  - 原文依据："换句话说，如果是从这座城堡，就能在一瞬间移动到魔大陆上的大部分城镇。""不过，所谓的转移魔法阵，实在是很可怕的技术。毕竟可以从位于天空的这座城堡瞬间移动到其他城镇。代表一旦战争爆发，就可以无视地形或守备杀进敌方的领地。……可以理解为何会在许久以前就将其视为禁忌，佩尔基乌斯和奥尔斯帝德会暗中使用。""「这是佩尔基乌斯大人新绘制的魔法阵。已经与魔大陆上不再使用的魔法阵相连。」「不再使用？」「转移魔法阵会因为某种理由而使得其中一边遭到破坏，导致另一边失去效力。这种事情屡见不鲜。」转移魔法阵是以两个一组。意思是他将其中一边遭到破坏，已经无法使用的魔法阵重复利用吗？""凶暴的魔物运气不好踏入转移魔法阵，这种事情也很有可能发生。""由于魔法阵发出蓝白色光芒，里头并不暗。""对这种宛如从梦中清醒的感觉，也没来由地就习惯了。"

- 名称：神子体质（札诺巴）
  - 规则：神子生来具有超越常理的怪力与钢铁般坚硬的肉体。札诺巴能徒手将50公分厚的坚硬石壁挖开粉碎，即使失足坠落悬崖也能毫发无伤。
  - 原文依据："再怎么说，札诺巴都是神子。就算遇上九头龙那样的对手，应该也有办法应付。""厚度应该有五十公分的厚重墙壁上开了一个大洞。札诺巴进而以洞口为着手点，宛如在破坏砂雕似的将洞口挖开，做出足以让一个人通过的大小。""毕竟他是就算失足坠崖也会毫发无伤的男人。"

- 名称：斗气
  - 规则：缠绕于身用于强化肉体与防御力的能量。鲁迪乌斯无法缠绕斗气，导致肉体防御力十分薄弱。
  - 原文依据："不会让斗气缠身的我防御力薄弱，但拜乱魔和吸魔石所赐，具有高水准的魔法防御。"

- 名称：乱魔
  - 规则：能够扰乱并消解敌方魔法的高阶魔法防御技能。
  - 原文依据："不会让斗气缠身的我防御力薄弱，但拜乱魔和吸魔石所赐，具有高水准的魔法防御。"

- 名称：土魔术
  - 规则：可用于搬运、清除塌落的大量沙土碎石。
  - 原文依据："扎诺巴使劲开门，我用土魔术除去掉落下来的沙土。"

## 四、种族 / 生物

- 名称：魔族
  - 特征：魔大陆的原住民与主要族群。体貌特征极为多样，遗骸骨骼形态五花八门，甚至宛如人造物。由于历史原因，佩尔基乌斯极其厌恶魔族，绝不允许魔族进入天空城堡。
  - 原文依据："在灰暗房间的地板上，躺着好几具白骨尸体。应该说不愧是魔大陆吗？骨头的模样五花八门，宛如人造物。""佩尔基乌斯好像不管怎样都不想让魔族踏入城堡，我曾试着拜托，但却遭到拒绝。""但是，克里夫从来没有去过到处都是魔族的场所。"

- 名称：长耳族（艾莉娜丽洁）
  - 特征：听觉高度敏锐，能隔着厚达50公分的墙壁仅凭敲击声音分辨后方是否有空洞空间。
  - 原文依据："艾莉娜丽洁发现墙壁后面有个空间。她好像是借由敲打墙壁之后发出的声音加以判断。不知是不是这道墙壁很厚，我就算贴上耳朵聆听也分不清差异。真不愧是长耳族。"

- 名称：大王陆龟
  - 特征：魔大陆特有的巨型陆龟生物，活动于鱼骨森林地带。
  - 原文依据："在远方可看到宛如鱼骨的森林，是魔大陆特有的景观。在那里移动的是大王陆龟吧？真令人怀念。"

- 名称：魔大陆魔物
  - 特征：体型巨大、性情凶暴，且喜好成群结队出没，极度危险，实力高强的战士稍有大意也会丧命。
  - 原文依据："「克里夫前辈，魔大陆有许多巨大又凶暴，而且成群结队的魔物，请你当心。」……这里是危险的土地。如果抱着在中央大陆和米里斯大陆时相同心态，就算是高强的战士也会命丧黄泉。"

- 名称：九头龙
  - 特征：实力极为恐怖的强力魔兽（在鲁迪乌斯的认知中被视为衡量防卫战力上限的危险对手）。
  - 原文依据："再怎么说，札诺巴都是神子。就算遇上九头龙那样的对手，应该也有办法应付。……只要有札诺巴担任前卫，就算是九头龙也可以与之一战。"

## 五、物品 / 道具 / 武器

- 名称：成对戒指魔道具（阿斯拉王国秘藏）
  - 说明：爱丽儿随身携带的阿斯拉王国秘藏魔道具，由两只成对的戒指构成。只要往其中一只灌注魔力，两只戒指上的宝石便会同时发光，用于危机时刻的远距离通讯/联络。
  - 原文依据："「既然这样，那我就提供魔道具吧。」爱丽儿将自己带在身上的戒指魔道具提供给我。这副魔道具是成对的戒指，一旦灌注魔力，两只戒指的宝石就会同时发光。这样可以在危急时告知对方。似乎是阿斯拉王国秘藏的魔道具。"

- 名称：吸魔石
  - 说明：能够吸收魔力的特殊矿石道具，与乱魔配合构成高水准魔法防御。
  - 原文依据："不会让斗气缠身的我防御力薄弱，但拜乱魔和吸魔石所赐，具有高水准的魔法防御。"

- 名称：七大列强石碑迎接魔道具 [存疑]
  - 说明：佩尔基乌斯准备的后备救援道具。若转移魔法阵无法运作，使用者只需在七大列强石碑前激活该魔道具，佩尔基乌斯便会派遣部下前去接应。
  - 原文依据："佩尔基乌斯说，假设转移魔法阵没办法使用，只要在七大列强的石碑前使用魔道具，自会派人迎接。"

- 名称：光之精灵的卷轴
  - 说明：封存有光之精灵魔法的卷轴道具，展开使用后可释放光芒照亮大范围黑暗空间。
  - 原文依据："除此之外，也带上了光之精灵的卷轴等几项方便道具。""我照艾莉娜丽洁所说，使用光之精灵的卷轴，照亮四周。"

- 名称：转移遗迹地图
  - 说明：记录了世界各地古代转移遗迹位置的地图。
  - 原文依据："因此，我准备了许多金钱和用来换钱的东西，并携带了转移遗迹的地图。"

- 名称：环形山魔石
  - 说明：利卡里斯镇周围环形山内壁所埋设的魔石，入夜后会自动发光照亮整座城镇。
  - 原文依据："而且在入夜之后，埋在环形山内壁的魔石便会发光，照亮整座城镇。"

## 六、历史 / 传说 / 事件

- 事件名：拉普拉斯与魔王之战（利卡里斯城半毁）
  - 内容：在过去的战乱中，魔神拉普拉斯与魔王在此交战，导致魔界大帝奇希莉卡·奇希里斯昔日的根据地城堡有一半遭到破坏，后被称为「旧奇希莉卡城」。
  - 原文依据："我也知道这座城堡的由来。从前，魔界大帝奇希莉卡•奇希里斯曾将此处作为根据地，后来在拉普拉斯和魔王的战斗之中有一半遭到毁坏。别名「旧奇希莉卡城」。"

- 事件名：转移魔法阵被列为禁忌
  - 内容：转移魔法阵能够实现跨大陆瞬间移动，无视任何地形与城防，具有极度破坏战争平衡的力量，因而早在很久以前便被世间列为禁忌并遭到封存破坏。
  - 原文依据："不过，所谓的转移魔法阵，实在是很可怕的技术。毕竟可以从位于天空的这座城堡瞬间移动到其他城镇。代表一旦战争爆发，就可以无视地形或守备杀进敌方的领地。……可以理解为何会在许久以前就将其视为禁忌，佩尔基乌斯和奥尔斯帝德会暗中使用。"

- 事件名：古代转移魔法阵入口封闭
  - 内容：古代为了彻底隐藏转移魔法阵不被发现，常会将出入口直接破坏封闭，使魔法阵房间变成密室废墟。
  - 原文依据："「出口也有遭到封闭的可能性，还请多加留意。」「遭到封闭？」「意思是为了隐藏转移魔法阵，已经将入口破坏。」要是没有入口自然不会被发现。"

## 七、社会规则 / 习俗 / 文化

- 内容：佩尔基乌斯严禁魔族登城
  - 说明：甲龙王佩尔基乌斯坚持绝不准许任何魔族踏足其天空要塞城堡（洛琪希因此无法入城）。
  - 原文依据："佩尔基乌斯好像不管怎样都不想让魔族踏入城堡，我曾试着拜托，但却遭到拒绝。"

- 内容：魔大陆语言与信仰文化
  - 说明：魔大陆通行语言为魔神语；且魔大陆几乎没有米里斯教信徒，当地居民的人生观与思维方式与米里斯教区存在巨大差异，外来者若以中央大陆或米里斯习惯行事极易产生争端。
  - 原文依据："「还有，这里恐怕几乎没有米里斯教徒。因此想法会有很大的落差，还请不要因为多余的事情和人起争执。」……「不要紧的，因为克里夫不懂魔神语。」"

- 内容：灾难环境下儿童自立认知
  - 说明：在经历大规模转移等灾难后，流落异乡失去双亲的孩子被迫早早自立。世界主流观念中，哪怕父母不在身边，孩子也能独立成长。

## 九、角色认知 vs 客观事实

- 角色认知与客观情况1：关于奇希莉卡的具体位置
  - 角色以为：佩尔基乌斯表示该魔法阵最接近奇希莉卡，似乎掌握了其行踪方向；鲁迪乌斯则基于奇希莉卡飘忽不定的性格，怀疑很可能扑空或出现估计误差。
  - 原文是否暗示另有真相：是。希瓦莉尔明确传达佩尔基乌斯本人也承认存在估计错误的可能性，且到达利卡里斯镇外后周围并未直接见到奇希莉卡。
  - 原文依据："「佩尔基乌斯大人说，这道魔法阵最接近魔界大帝。」「意思是佩尔基乌斯大人对奇希莉卡的所在地有什么眉目吗？」「当然。」……「但是，大人说也有估计错误的可能性。」「……我想也是。」我认识的魔界大帝奇希莉卡，是无法预测她行动的类型。就算以为她人在这里，回过神来，有可能她已经移动到了别的地方。""周围看不见城镇。奇希莉卡真的在这种地方吗？"

- 角色认知与客观情况2：关于密室遗迹白骨囚徒的死因
  - 角色以为：鲁迪乌斯推测这里的囚犯是被转移到该密室后，外面的转移阵被关闭，导致他们被活活困死在密室监狱里。
  - 原文是否暗示另有真相：不明。文中仅为鲁迪乌斯基于遗迹现场与希瓦莉尔说明所作的主观猜测，并未证实当年的真实历史背景。
  - 原文依据："换句话说，他们是被转移到这里之后，才关闭了另外一头的魔法阵吧。如果真是那样，这种兴趣有点低级啊。"

- 角色认知与客观情况3：关于七星的病症是否与诅咒相通
  - 角色以为：鲁迪乌斯认为七星的突发吐血怪病和诅咒十分相似，推测调整克里夫的诅咒抑制魔道具研究或许能制造出延续七星生命的道具。
  - 原文是否暗示另有真相：不明。鲁迪乌斯将其作为寻找奇希莉卡落空时的备选方案，并未确证该怪病与诅咒的内在机理相同。
  - 原文依据："七星的疾病和诅咒很像。因此只要稍加调整克里夫的研究，说不定就有办法制作出延续七星生命的魔道具。"
