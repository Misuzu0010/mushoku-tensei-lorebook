# 特稿短篇小说 世界设定提取

## 一、地理与场所
- 名称：鲁迪乌斯的家（自家 / 寝室）
- 内容：鲁迪乌斯的住宅，内部设有带床铺的寝室、房门以及梳妆镜，周围环境清幽闲静，能听见鸟鸣。
- 原文依据："回过神来，场面跳转，映照在眼帘的是自家的风景。"、"我站在自己家的床上，好像是起床时一时用力过猛顺势站了起来。"、"明明不是一大清早，却依旧听得见鸟儿唧唧的叫声。真是闲静。"、"打从内心发出的和平笑声在寝室里静静回荡。"

## 二、组织与势力
- 名称：奥尔斯帝德麾下
- 内容：以奥尔斯帝德为首的势力，鲁迪乌斯在决战后选择归顺于其麾下。
- 原文依据："昨天发生了各种状况之后，我归顺于奥尔斯帝德麾下。"
- 名称：人神势力 [存疑]
- 内容：人神是奥尔斯帝德寻找与敌对的目标；鲁迪乌斯在恶梦中曾恳求奥尔斯帝德放弃寻找人神。
- 原文依据："请你……放弃寻找人神。求求你……"

## 三、力量体系 / 魔法 / 技能
- 名称：治愈魔术 / 治愈魔术师
- 规则：掌握治愈魔术的魔术师在队伍战斗中因具备治疗伤势与复原能力，通常会被敌方视为首要优先集火歼灭的目标。
- 原文依据："因为她是治愈魔术师，所以第一涸受到攻击。尽管在场所有人都打算做出应对，然而敌人连续击出宛如把线穿过针孔般的精确攻击，最后还是击中了她。"
- 名称：断肢恢复（高级治愈手段）
- 规则：失去的肢体能够通过高超的治疗能力得以完全恢复肉身（奥尔斯帝德拥有此项能力，治愈恢复了鲁迪乌斯失去的左臂）。
- 原文依据："理应已经失去的左臂确实就在这里。是奥尔斯帝德帮我恢复的手臂。"

## 四、种族 / 生物
- 名称：长耳特征种族（希露菲）
- 特征：外貌具有白色秀发与细长耳朵特征。
- 原文依据："白色秀发，细长耳朵，看了头马上就能一目了然。是希露菲。"

## 五、物品 / 道具 / 武器
- 名称：奥尔斯帝德赠予的手环
- 说明：奥尔斯帝德所赠送的陌生手环，佩戴在鲁迪乌斯恢复后的左手腕上。
- 原文依据："然后那只手上佩戴着一只陌生的手环，同样是奥尔斯帝德所赠。"
- 名称：法师长袍 / 睡衣
- 说明：长袍为鲁迪乌斯日常及战斗时的服饰，睡衣为寝居时的衣物。
- 原文依据："身上穿的是睡衣。但我完全不记得自己是何时换上。直到刚才为止，我应该都还穿着长袍才对啊。"

## 六、历史 / 传说 / 事件
- 事件名：鲁迪乌斯与奥尔斯帝德决战及归顺事件
- 内容：鲁迪乌斯与奥尔斯帝德展开大战并失去左臂；战斗结束后鲁迪乌斯选择臣服并归顺其麾下。奥尔斯帝德并未伤害希露菲、洛琪希、艾莉丝及其他家眷，并出手为鲁迪乌斯恢复了断臂且赠予手环。鲁迪乌斯返家后脱力昏迷，希露菲通宵守候照料。
- 原文依据："理应已经失去的左臂确实就在这里。是奥尔斯帝德帮我恢复的手臂。然后那只手上佩戴着一只陌生的手环，同样是奥尔斯帝德所赠。"、"昨天发生了各种状况之后，我归顺于奥尔斯帝德麾下。希露菲、洛琪希还有艾莉丝都没有被杀，他当然也没有对我的家人出手。"、"是吗，昨天和奥尔斯帝德的战斗结束之后，我一回到家就失去了意识。后来希露菲就像这样一直陪在我身边吗……"

## 七、社会规则 / 习俗 / 文化
- 内容：战斗战术常识：当敌方阵营中有治愈魔术师存在时，战术上应优先集火击杀治愈魔术师。
- 原文依据："因为她是治愈魔术师，所以第一涸受到攻击。尽管在场所有人都打算做出应对，然而敌人连续击出宛如把线穿过针孔般的精确攻击，最后还是击中了她。"

## 九、角色认知 vs 客观事实
- 角色以为：
  1. 鲁迪乌斯在恶梦中以为希露菲、洛琪希、艾莉丝均在交战中阵亡，莉莉雅、爱夏、诺伦、塞妮丝全部倒地遇害，女儿露西被奥尔斯帝德残忍捏碎头颅，世界走向毁灭。
  2. 希露菲在恶梦中以为鲁迪乌斯在战斗中失去了头部。
- 原文是否暗示另有真相：否（文本明确证实上述惨剧纯属两人的战后恶梦，现实中全员生还且家人安然无恙）
- 原文依据：
  - "「是梦……啊……」是的，没错。昨天发生了各种状况之后，我归顺于奥尔斯帝德麾下。希露菲、洛琪希还有艾莉丝都没有被杀，他当然也没有对我的家人出手。"
  - "「早安，鲁迪……嗯。和梦里不同，你的头还在。」"、"希露菲放心地吐了口气。看到这个动作，我大概猜到她作了什么梦。"
