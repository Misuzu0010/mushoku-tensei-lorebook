# 第二话　「日记　后篇」 世界设定提取

## 一、地理与场所
- 名称：魔法都市夏利亚
- 内容：未来的鲁迪乌斯在希露菲死后堕落度日、四处出入酒馆与妓院的所在城镇，艾莉丝也曾居住于此并在此阻拦、痛揍鲁迪乌斯。
- 原文依据："尽管没有明确写出地点，但里面出现了好几个我知道的店名，这里恐怕是魔法都市夏利亚吧。"、"她好像也住在夏利亚，每次碰面都会一脸不爽地狠狠揍我一顿。"

- 名称：赤龙山脉
- 内容：位于中央大陆的山脉，在军事地理上对进攻方构成压倒性的地形不利。
- 原文依据："要是在中央大陆开战，只要有赤龙山脉，对于进攻的一方来说便是压倒性的不利。"

- 名称：阿斯拉王国首都
- 内容：未来的鲁迪乌斯曾将该首都的一部分烧毁，但阿斯拉王国官方并未查出凶手是他。
- 原文依据："阿斯拉王国好像还不知道我就是把首都的一部分烧毁的犯人。一群愚蠢的家伙。尽是些垃圾。"

- 名称：贝卡利特大陆内地（古代龙族遗迹）
- 内容：位于贝卡利特大陆据说从未有人踏足过的内地深处，存有一座古代龙族遗迹，遗迹内的壁画记录了世界由六面组成以及无之世界、人神的真相。
- 原文依据："这里是贝卡利特大陆的内地。我在据说从未有人踏足过的这块土地上，找到了某座遗迹。这里是古代龙族的遗迹。残留在里面的壁画记述着这样的内容。"

- 名称：魔大陆深山（第二座古代龙族遗迹）
- 内容：位于魔大陆深山极其隐蔽且危险的场所，周边盘踞着大量棘手的魔物，内部存有古代龙族关于前往无之世界中心方法的完全版壁画。
- 原文依据："我发现了第二座古代龙族的遗迹。这里位于魔大陆的深山。古代龙族为什么会在如此难以寻获又危险的场所制造遗迹啊？这一带尽是棘手的魔物。"

- 名称：佩尔基乌斯的空中要塞（空中城堡）
- 内容：甲龙王佩尔基乌斯的要塞，鲁迪乌斯推断其本质上也属于古代龙族的遗迹之一，且其城堡地下同样存在古代壁画。
- 原文依据："仔细想想，佩尔基乌斯的空中要塞也算是遗迹之一吧。"、"佩尔基乌斯的城堡地下也有壁画。那也是古代龙族所写的其中一种吗？"

- 名称：六面世界与无之世界
- 内容：整个世界由六个部分组成，分别为龙的世界、人的世界、魔的世界、兽的世界、海的世界以及天的世界。六个世界如同骰子的六个面相互连接。中心内部的空洞部分被称为“无之世界”，若不使用特殊方法便无法通过。人神正位于无之世界的中心。转移魔术的“吸入地底感”即是因为穿过地底通过了无之世界，但无法从普通地面挖洞抵达。
- 原文依据："这个世界分为六部分。龙的世界、人的世界、魔的世界。兽的世界、海的世界以及天的世界。这些世界就像六个面一样，换句话说，就是以骰子形状连接在一起。而其中中心部位，也就是骰子的内侧被称为无之世界。当想要从其中一面移动到另一面，就必须通过无之世界才行。然而，如果不使用某种特殊方法，就无法通过无之世界。……「人神，就位在无之世界的中心。」"、"这个世界是骰子，中间的空洞部分则是无之世界。而人神就如同字面上所示，位于该世界的中心。原来如此。转移魔术之所以会让人有种吸入地底的感觉，其实正是因为穿过地底，通过了无之世界的缘故。虽说是在地下，但就算从地面上挖洞往下钻，想必也不可能抵达无之世界吧？"

## 二、组织与势力
- 名称：魔法三大国
- 内容：包含拉诺亚王国等在内的同盟国家，重视自身国家利益；只要鲁迪乌斯有利用价值便拒绝米里斯的引渡要求，并作为稳定客户向札诺巴采购量产型自动人偶作为军事战力。
- 原文依据："米里斯神圣国透过阿斯拉王国，向拉诺亚王国提出引渡我的要求，但只要我还有利用价值，想必魔法三大国是不会答应的吧。"、"我们决定量产芙蒂的姊妹机，出售给魔法三大国。有国家当忠实顾客是件好事。"

- 名称：米里斯教团 / 米里斯神圣国 / 神殿骑士团
- 内容：米里斯教团曾在未来对鲁迪乌斯与札诺巴发出通缉悬赏，派遣赏金猎人与刺客追杀；米里斯神圣国曾试图透过阿斯拉王国要求拉诺亚王国引渡鲁迪乌斯；其下属的神殿骑士团曾秘密潜入拉诺亚王国，将札诺巴、金洁、茱丽及爱夏残酷杀害并焚毁房屋，随后被赶来的鲁迪乌斯全歼。
- 原文依据："这个时期的我和札诺巴好像遭到米里斯教团悬赏，奖金猎人和刺客会频繁地出现在我面前。"、"米里斯神圣国透过阿斯拉王国，向拉诺亚王国提出引渡我的要求"、"神殿骑士团在不知不觉间侵入了拉诺亚王国。当我赶到的时候，一切都太迟了。房屋遭到烧毁，札诺巴在地下室的门口被烧成焦炭，金洁和茱丽，还有麻烦札诺巴照顾的爱夏，她们躺在门后，全身都是刀伤。我把远在拉诺亚王国的神殿骑士团赶尽杀绝了。"

- 名称：阿斯拉王国
- 内容：中央大陆强国，曾协助米里斯神圣国向拉诺亚王国转交对鲁迪乌斯的引渡要求；其首都部分区域曾遭鲁迪乌斯焚毁，却始终未能查清凶手。
- 原文依据："米里斯神圣国透过阿斯拉王国，向拉诺亚王国提出引渡我的要求"、"阿斯拉王国好像还不知道我就是把首都的一部分烧毁的犯人。一群愚蠢的家伙。尽是些垃圾。"

- 名称：魔法大学
- 内容：位于拉诺亚王国的学府，协助鲁迪乌斯将无咏唱魔术正式纳入教学课程。
- 原文依据："另外，由于魔法大学的协助，我的无咏唱魔术将要正式纳入课程。"

- 名称：阿托菲亲卫队
- 内容：魔王阿托菲直属的武装亲卫部队，成员包括精通魔术的高手穆亚等人，在战斗中与阿托菲协同作战。
- 原文依据："这场战斗的对手是阿托菲以及阿托菲亲卫队所有成员。我认为会有胜算，但果然还是遭到穆亚妨碍，是我彻底大意了。我明明深知穆亚这个男人是个十分干练的魔术高手。都怪我把注意力完全放在阿托菲身上。"

- 名称：五龙将 [存疑]
- 内容：古代龙族的五位大将/核心强者，各自持有古代龙族创造的一件秘宝。在未来时间线中一人已确认死亡（秘宝下落不明），最后一人下落不明（佩尔基乌斯称其几十年内现身）。
- 原文依据："古代龙族创造的五样秘宝，分别由五龙将各自持有，而通往世界的大门似乎要借由龙神的秘术才能开启。然而，五龙将其中一人已经死亡。他所持有的秘宝不知去向，五龙将的最后一人也下落不明。据佩尔基乌斯所说，最后那一人将会在几十年内现身。"

## 三、力量体系 / 魔法 / 技能
- 名称：无咏唱魔术课程化
- 规则：鲁迪乌斯的无咏唱魔术在未来正式被魔法大学纳为正式课程传授。
- 原文依据："另外，由于魔法大学的协助，我的无咏唱魔术将要正式纳入课程。"

- 名称：斗气与身体强化缺陷
- 规则：战士通常借由在身上缠绕斗气以增幅肉体的速度与防御力；鲁迪乌斯自身无法缠绕斗气，导致在近战的速度和防御应对上处于劣势。
- 原文依据："问题在于防御和攻防应对这方面，我无法在身上缠绕斗气，在速度和防御这方面会略逊一筹。"、"仔细想想，虽然我无法缠绕斗气，只要把魔力注入义手，就可以发挥超越平时的威力。"

- 名称：圣级以上高阶魔术的实战特性
- 规则：圣级以上的魔术通常只是波及与破坏规模更大，在针对个体的直接战斗中并不实用（但电击魔术属于例外）。
- 原文依据："不，照目前的模式来看，圣级以上的魔术只是规模更大，不太适合在战斗中使用。尽管也有像电击那样的例外，但以现状看来，我并不缺攻击手段。"

- 名称：多属性魔术开发与万能论
- 规则：未来的鲁迪乌斯开发了操控重力、操控电、操控声音等全新领域的魔术，治愈魔术也精进至圣级水准，并得出“魔术是万能的，只要掌握感觉就无所不能”的心得。
- 原文依据："操控重力的魔术、操控电的魔术、操控声音的魔术，甚至连治愈魔术也达到圣级水准。我下了一个结论，魔术是万能的，只要掌握感觉就无所不能。"

- 名称：召唤术与转移魔术的本质
- 规则：召唤术与转移魔术在历史上并非独立魔术，其起源与本质是古代为了穿过“无之世界”抵达六面世界其他各面而尝试开发所衍生出的产物。
- 原文依据："壁画上面记述着为了前往无之世界的中心而进行多方尝试，从失败中找出历史。所谓的召唤术以及转移魔术，似乎是为了通过无之世界抵达其他世界的魔术所衍生出来的产物。"

- 名称：时间回溯转移魔术（时空穿越/旅行）
- 规则：将召唤魔术与古代龙族遗迹壁画上的魔术结合并更改步骤，可实现跨越时间的转移。回溯几十秒就需要庞大魔力；以年为单位进行长距离时间回溯消耗的魔力量极度庞大，甚至足以导致魔力近乎无限的施法者耗尽魔力濒死。需借助具有时间锚定作用的物体（如历经长年的日记）作为起点坐标。可能伴随未知的时间悖论风险。
- 原文依据："在研究转移魔术的过程中，我确立了一个假设。「召唤魔术」，以及位于龙族遗迹壁画上的魔术。只要更改这两套魔术的使用步骤，说不定就有办法转移到过去。不过以理论上来说，光是要转移到几十秒前的过去就得消耗庞大的魔力。要是以年为单位传送回去，究竟要消耗多少魔力才足够？"、"我的手边有这本日记。只要把日记作为起点使用，说不定就能回到动笔写这本日记的瞬间。"、"想必未来的我在写完最后的日记后，立刻就转移到我这来了。然后他立刻就领悟自己的魔力不足。"

- 名称：龙神秘术
- 规则：通往无之世界中心的世界大门，除了需要古代龙族的五样秘宝外，还需要借由龙神的秘术才能够开启。佩尔基乌斯推测龙神奥尔斯帝德可能掌握该秘术。
- 原文依据："古代龙族创造的五样秘宝，分别由五龙将各自持有，而通往世界的大门似乎要借由龙神的秘术才能开启。"、"佩尔基乌斯说，奥尔斯帝德的话或许知道如何使用秘术……"

- 名称：水帝 / 北帝
- 规则：剑术流派（水神流、北神流）的高段位帝级称号与强者，实力极强，但未来的鲁迪乌斯在旅行中曾击败并击杀过水帝与北帝级别的高手。
- 原文依据："在交过手的对手之中，也包含了水帝以及北帝这样的高手。……仅仅留下「杀了○○。这家伙也不认识人神」这样一句话。"

## 四、种族 / 生物
- 名称：不死魔族
- 特征：寿命极度漫长，代表人物为魔王阿托菲；因长寿而较常人更可能掌握关于神话时代的隐秘历史情报。
- 原文依据："虽然我不认为那个满脑子肌肉的笨蛋知道些什么，但不死魔族十分长寿，因此她很有可能知道关于人神的情报。"

- 名称：古代龙族
- 特征：古代的高智慧强大种族，曾在贝卡利特大陆和魔大陆等险恶地带建造遗迹与要塞。掌握极高水准的转移、召唤技术与魔术理论，曾尝试前往无之世界中心并制造了五样秘宝与龙神秘术。
- 原文依据："这里是贝卡利特大陆的内地。我在据说从未有人踏足过的这块土地上，找到了某座遗迹。这里是古代龙族的遗迹。残留在里面的壁画记述着这样的内容。"、"看样子，古代龙族似乎打算制作出前往无之世界的中心所需的物品。"、"古代龙族创造的五样秘宝，分别由五龙将各自持有……"

- 名称：魔物
- 特征：栖息于魔大陆深山等险恶地区的生物，极度危险且难以对付。
- 原文依据："这里位于魔大陆的深山。古代龙族为什么会在如此难以寻获又危险的场所制造遗迹啊？这一带尽是棘手的魔物。"

## 五、物品 / 道具 / 武器
- 名称：诺伦的画册与瑞杰路德人偶
- 说明：在拉诺亚王国等地贩售的文化商品，销量极佳。
- 原文依据："诺伦的画册和瑞杰路德人偶卖得非常好。"

- 名称：自动人偶（希露菲人偶、芙蒂及其量产姊妹机）
- 说明：札诺巴与鲁迪乌斯耗时数年共同研发的魔导人偶。希露菲型人偶拥有独立思想、能自主思考行动，性情顺从且嫉妒心强，但鲁迪乌斯认为无法替代真人而亲手将其破坏。第十四号杰作“芙蒂”则不再仿照熟人制作；其量产型姊妹机出售给魔法三大国作为军备，战斗力凌驾于普通骑士与冒险者。
- 原文依据："札诺巴的自动人偶已经接近完成。"、"自动人偶完成了。做得和希露菲如出一辙的自动人偶。她拥有自己的思想，会自己思考并付诸行动。……我破坏了希露菲人偶。"、"制作了和希露菲以及洛琪希不同的人偶。这具个体由札诺巴命名为芙蒂。我问他为什么取这个名字，他得意地说因为这是他第十四号杰作。我们决定量产芙蒂的姊妹机，出售给魔法三大国。……肯定比平庸的骑士和冒险者还强。"

- 名称：札里夫义手
- 说明：鲁迪乌斯的义手装备，能够通过注入魔力发挥远超肉体常态的巨大威力。
- 原文依据："就是把「札里夫义手」覆盖全身。仔细想想，虽然我无法缠绕斗气，只要把魔力注入义手，就可以发挥超越平时的威力。"

- 名称：斗神黄金铠甲
- 说明：文献中记载斗神所身穿的黄金铠甲，能够将穿戴者的身体能力增幅数倍。
- 原文依据："某份文献上提到了斗神。据说斗神身穿黄金铠甲，能藉此将自己的身体能力增幅数倍。"

- 名称：魔导铠（Magic armor）
- 说明：鲁迪乌斯效法斗神铠甲与游戏概念，由札诺巴协助开发的全身重装铠甲。以覆盖全身的札里夫义手为基础结构，外部装甲采用最高硬度土魔术硬化制作。全高超过两公尺，魔力消耗量巨大，仅有鲁迪乌斯能够驾驭。全力运转时限约半天，但能赋予穿戴者匹敌列强的惊人破坏力、敏捷度与防御力，即便以30%出力也能压制泛泛之辈。
- 原文依据："在札诺巴的协助之下，完成了我专用的全身铠甲。高度超过两公尺，成品的尺寸相当庞大。而且魔力的消耗量过于巨大，除了我以外没有人能驾驭。……将其命名为「魔导铠」（Magic armor）。"、"魔导铠──借由将札里夫义手覆盖全身，让我获得与列强匹敌的威力、速度以及防御力。日记上提及，尽管能全力运转的时间顶多半天就是极限，但就算是以三十％程度的出力也不会输给泛泛之辈。"

- 名称：古代龙族的五样秘宝
- 说明：古代龙族创造的五件神秘宝物，分别由五龙将持有，是前往无之世界中心不可或缺的必备关键道具，其具体制作原理与构成无法被鲁迪乌斯理解。
- 原文依据："古代龙族创造的五样秘宝。只要使用这个，就可抵达无之世界。"、"古代龙族创造的五样秘宝，分别由五龙将各自持有，而通往世界的大门似乎要借由龙神的秘术才能开启。然而，五龙将其中一人已经死亡。他所持有的秘宝不知去向……"、"我无法取得五龙将的秘宝。无论是秘宝也好秘术也罢，都不是我能制作出来的。根本就搞不懂原理为何。"

- 名称：未来的日记
