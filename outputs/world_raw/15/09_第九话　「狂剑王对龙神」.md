# 第九话　「狂剑王对龙神」 世界设定提取

## 一、地理与场所
- 名称：魔法都市夏利亚
- 内容：拉诺亚王国的城市，鲁迪乌斯宅邸所在地，设有冒险者公会，城内人尽皆知鲁迪乌斯的名号。
- 原文依据："几天前，两名女子的身影出现在魔法都市夏利亚的入口。"
- 原文依据："进入拉诺亚王国之后就较为顺利地来到了魔法都市夏利亚。抵达夏利亚后的行动也十分顺利。因为在冒险者公会收集情报时，知道鲁迪乌斯宅邸的人为数不少。"

- 名称：鲁迪乌斯宅邸
- 内容：位于魔法都市夏利亚，规模宏大堪比旅社，庭院宽阔可用作剑术锻炼场。宅邸门口放置/栽种着从贝卡利特大陆带回的珍奇魔兽与在魔大陆栽培的古怪魔木。
- 原文依据："从门口就可看见他从贝卡利特大陆带回来的珍奇魔兽，以及在魔大陆栽培的古怪魔木，想必马上就能找到。实际上，她们确实马上就找到了目的地。尽管鲁迪乌斯宅邸和艾莉丝的老家相比简直是天差地远，但是依旧有着被称为旅社也不为过的大小。庭院很大，拿来作为锻炼场使用也不坏。"

- 名称：贝卡利特大陆
- 内容：世界上的大陆之一，鲁迪乌斯曾前往该处并带回珍奇魔兽。
- 原文依据："从门口就可看见他从贝卡利特大陆带回来的珍奇魔兽"

- 名称：魔大陆
- 内容：世界上的大陆之一，鲁迪乌斯曾在其上培育古怪魔木；艾莉丝长年同甘共苦的无名爱剑亦是在魔大陆的米格路德村获得。
- 原文依据："以及在魔大陆栽培的古怪魔木"
- 原文依据："改摆在位于腰间左侧，置于米格路德村拿到的无名爱剑上。"

- 名称：拉诺亚王国
- 内容：魔法都市夏利亚所属的王国。
- 原文依据："进入拉诺亚王国之后就较为顺利地来到了魔法都市夏利亚。"

- 名称：西隆王国
- 内容：爱夏曾在此遇险并被拯救的王国。
- 原文依据："但在西隆王国拯救自己的人之中，艾莉丝无疑也是其中一员。"

- 名称：米格路德村
- 内容：位于魔大陆的村庄，艾莉丝在此获得了同甘共苦的无名爱剑。
- 原文依据："改摆在位于腰间左侧，置于米格路德村拿到的无名爱剑上。"

## 二、组织与势力
- 名称：冒险者公会
- 内容：为冒险者提供登记与情报流通的组织，在夏利亚设有分部，可在此打听城镇重要人物与其宅邸信息。
- 原文依据："因为在冒险者公会收集情报时，知道鲁迪乌斯宅邸的人为数不少。"

- 名称：魔法大学
- 内容：拉诺亚王国的学府机构，鲁迪乌斯被誉为魔法大学最强，希露菲与洛琪希在此上学。
- 原文依据："被誉为魔法大学最强，尽管遭到旁人畏惧，行事目中无人，却站在弱者这边"
- 原文依据："在爱夏去叫上学的希露菲和洛琪希回来的这段期间"

- 名称：米里斯教
- 内容：注重一夫一妻戒律的宗教，娶两名妻子会被教徒与世人指责违背教规。
- 原文依据："「居然娶两个妻子，根本不算是米里斯教徒」之类。"

- 名称：剑神流派
- 内容：以当代剑神加尔·法利昂为顶点的剑术门派，拥有剑帝、剑王、剑圣等位阶。门派内部传承最高规格的七把宝剑（剑神七剑），由掌门人根据弟子资质转让。
- 原文依据："剑神加尔•法利昂把艾莉丝传唤至自己的寝室，排好三把剑并这样说道：「你要哪一把？」"
- 原文依据："现在只有七剑中的三把，是因为剑神持有一把，两名剑帝各自持有一把，另外则是剑王基列奴持有一把。剩下的两把，等现在还是剑圣的两名年轻人再稍微成长之后，应该也会转让给他们吧。"

- 名称：龙神阵营
- 内容：由奥尔斯帝德统领的阵营，能够为盟友提供"龙神之庇护"，隔绝人神的干涉与窥探。本章末尾鲁迪乌斯正式宣誓臣服，成为龙神的部下。
- 原文依据："背叛人神，跟随我吧！"
- 原文依据："只要……得到我的龙神之庇护，人神应该也没有办法轻易对你出手。现在这些对话，也不会传到他的耳中！"
- 原文依据："「……我……要臣服在龙神麾下。请你救救我。」那天，鲁迪乌斯•格雷拉特成为了龙神的部下。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑神流战法与奥义
- 规则：
  1. 理念战则：以"先发制人"为绝对守则，必定先下手为强；门派内不存在二刀流；单手无法施展光之太刀。
  2. 奥义「光之太刀」：极致速度与威力的单发必杀斩击，唯有光之太刀能粉碎龙神的龙圣斗气；顶尖强者（如奥尔斯帝德）甚至可以纯凭手刀击发光之太刀。
  3. 奥义「光返」：专门用于破解光之太刀的型，在对方光之太刀尚未达到最高速度的位置，以最高速度追上并将其两断。
- 原文依据："剑神流以先发制人为绝对守则。"
- 原文依据："剑神流一定会率先进攻。那就是那样的剑术。"
- 原文依据："剑神流没有二刀流。二刀流是北神流的型之一。"
- 原文依据："即使是被称为魔剑的凤雅龙剑，也不可能以单手放出光之太刀。"
- 原文依据："「剑神流奥义『光之太刀』。」在奥尔斯帝德的手以惊人速度击发剑招的同时──「剑神流奥义『光返』。」艾莉丝把剑往下挥。反复训练了几千次的型之一。对应光之太刀的方法。在尚未抵达最高速度的位置，以最高速度追上并将其两断。"
- 原文依据："那家伙能以手刀击发『光之太刀』。"
- 原文依据："除了光之太刀以外，无法粉碎龙神的龙圣斗气。即使是「凤雅龙剑」也难以办到。"

- 名称：水神流反击体系
- 规则：以严阵以待的防守反击著称，反击技不存在失败二字；只要不存在绝对实力差距，水神流可谓胜券在握；进攻的剑神与防守的水神是最糟糕的克制组合；奥尔斯帝德的水神流造诣已达神级领域。
- 原文依据："那家伙的水神流达到了神级的领域。你会被反击技杀死。"
- 原文依据："对于严阵以待的水神流绝对不能轻易出手。进攻的剑神和防守的水神，是最糟糕的组合。水神流的反击不存在失败二字。只要没有一定程度的实力差距，水神流可谓胜券在握。"

- 名称：北神流实战技巧
- 规则：二刀流是北神流的型之一；崇尚灵活实战，具有「被逼到绝境的北神流会把剑掷出」的招式。艾莉丝曾从北帝奥贝尔处学得在收鞘状态下单手最速将剑投掷出的奇袭招法。
- 原文依据："剑神流没有二刀流。二刀流是北神流的型之一。"
- 原文依据："那就是从北帝奥贝尔身上学来的北神流技巧。从前只看过一次的招式。艾莉丝试着在剑收入剑鞘的状态下，练习到能以单手最速发招。尽管招式还没成型，但能确实夺走对方的性命。「被逼到绝境的北神流会把剑掷出」。"

- 名称：斗气与龙圣斗气
- 规则：战士运用魔力附体形成的防御机制。龙神奥尔斯帝德拥有的"龙圣斗气"具备极其强大的防御力，普通投掷飞剑直击会被弹开，即使是破防魔剑「凤雅龙剑」的非光之太刀斩击亦无法伤其分毫，唯有光之太刀能将其粉碎。
- 原文依据："但致密地锤炼在刀身的魔力，可将对手用斗气形成的防御几乎无效化。尽管不能将龙神那具有犯规般防御力的斗气一并无效化，但可以达到轻减的效果。"
- 原文依据："除了光之太刀以外，无法粉碎龙神的龙圣斗气。即使是「凤雅龙剑」也难以办到。"
- 原文依据："尽管投掷过去的无名之剑击中了奥尔斯帝德的身体，但却被龙圣斗气弹开，往艾莉丝的遥远后方飞去。"

- 名称：治愈魔术
- 规则：用于恢复创伤的高阶魔术。顶尖水平的治愈魔术可在抓住断肢的瞬间重新接合并彻底修复断掌，且仅凭单次施法即可抹消全身所受的一切严重创伤；亦可用于治愈断臂伤势。
- 原文依据："他用左手抓住飞舞在空中的手掌，迅速接回手臂。……艾莉丝望向奥尔斯帝德，发现他原本被斩落的手掌已经修复完毕。同样的，刚才他身上那些疑似鲁迪乌斯造成的伤害也消失得无影无踪。是治愈魔术。趁刚才一瞬间的攻防，奥尔斯帝德使用了治愈魔术。而且，只用仅仅一次的治愈魔术就治疗了所有伤势。"
- 原文依据："答应的话，你对我发动奇袭一事可以付诸流水，你被砍下的手臂伤势也由我来治疗！"

- 名称：龙神行动特性与诅咒 / 庇护
- 规则：奥尔斯帝德因某种理由无法使出全力，对敌时尽量仅依靠斗气和体术（不足时才追加魔术）；面对未曾见过的招式有先观察的习惯；自身携带引起世人莫名恐惧敌视的诅咒，但鲁迪乌斯的体质对该诅咒完全免疫；奥尔斯帝德具备提供"龙神之庇护"的能力，可阻挡人神下手并屏蔽人神的听觉感知。
- 原文依据："那家伙因为某种理由而无法使出全力。明明他还会使用剑术及魔术，却尽可能地只靠斗气和体术想办法撂倒敌人。尤其是在对上自己知之甚深的流派的时候。斗气和体术，如果还不够的话也会用魔术，以最合适的行动打倒敌人。不过当他不知道的时候……那家伙对第一次见到的招式，会有想要观察的习惯。那搞不好就是那家伙的弱点。"
- 原文依据："以及我的诅咒无法发挥效果的体质，有利用的价值！"
- 原文依据："只要……得到我的龙神之庇护，人神应该也没有办法轻易对你出手。现在这些对话，也不会传到他的耳中！"

- 名称：人神的能力与局限
- 规则：人神拥有强大的"未来视"，但并非能洞察全部未来，亦非全知全能；其言语不可轻信；在龙神庇护下的言行无法传达至其耳中。
- 原文依据："「人神所说的话无法信任……」"
- 原文依据："「现在这些对话，也不会传到他的耳中！」"
- 原文依据："「有！尽管那家伙拥有强大的未来视，但不是看得见全部，也并非全知全能。」"

- 名称：拉普拉斯因子
- 规则：鲁迪乌斯身上所具备的体质因子，带来异常庞大的魔力。
- 原文依据："有着拉普拉斯因子的那股魔力"

## 四、种族 / 生物

- 特征：外貌具备兽类体征（如基列奴身材高大健硕，一头灰发，身高比人族艾莉丝高出一颗头）。
- 原文依据："有着一头灰发的兽族女性，以及一头华丽红发的人族女性。兽族女性比人族女性高出一颗头。"

- 原文依据："从门口就可看见他从贝卡利特大陆带回来的珍奇魔兽，以及在魔大陆栽培的古怪魔木"

## 五、物品 / 道具 / 武器
- 名称：凤雅龙剑
- 说明：剑神七剑之一，由绝世名匠「龙皇」授予初代剑神的魔剑。刀身细薄，略带弧度的单刃剑，外型朴实透澈无不祥气息。刀身内致密锤炼魔力，拥有"无视防御"的能力，可将对手依靠斗气构筑的防御几乎完全无效化，对龙圣斗气亦能达到轻减效果，能最大限度发挥剑神流技术。
- 原文依据："艾莉丝握着剑神七剑之一的「凤雅龙剑」摆出大上段的架式"
- 原文依据："这把正是绝世名匠「龙皇」授予初代剑神的「凤雅龙剑」。能够最大限度运用剑神流的技巧。是为了剑神而存在的剑。"
- 原文依据："刀身细薄，稍微有些弯曲的单刃剑。完全没感觉到一丝不祥气息，这把剑甚至让人感到清心透澈。"
- 原文依据："「那把剑是魔剑。乍看之下没有任何能力，但致密地锤炼在刀身的魔力，可将对手用斗气形成的防御几乎无效化。尽管不能将龙神那具有犯规般防御力的斗气一并无效化，但可以达到轻减的效果。」无视防御。那就是「凤雅龙剑」具备的能力。"

- 名称：剑神七剑
- 说明：剑神流派世代传承的七把绝世宝剑。现存由加尔·法利昂持有一把，两位剑帝各持一把，剑王基列奴持有一把，艾莉丝挑选了「凤雅龙剑」，剩余两把待年轻剑圣成熟后转让。
- 原文依据："现在只有七剑中的三把，是因为剑神持有一把，两名剑帝各自持有一把，另外则是剑王基列奴持有一把。剩下的两把，等现在还是剑圣的两名年轻人再稍微成长之后，应该也会转让给他们吧。"

- 名称：奥尔斯帝德的佩剑（弯曲的剑） [存疑：本章未言明具体剑名]
- 说明：奥尔斯帝德所配佩剑，刀身弯曲，蕴含着远远凌驾于剑神珍藏宝剑之上的恐怖力量。平时空手对敌，仅在面对致命伤势威胁时才拔剑。
- 原文依据："另外，右手还拿着弯曲的剑。艾莉丝从没看过奥尔斯帝德那把剑，她也不觉得自己有选定剑的眼力。可是，她能够理解那把剑是相当不得了的兵器。与自己手上的这把剑神的珍藏宝剑相比，那把剑潜藏着远远凌驾其上的惊人力量。"

- 名称：艾莉丝的无名之剑
- 说明：艾莉丝在魔大陆米格路德村获得并随身佩戴的爱剑，伴随艾莉丝身材成长显得略短。在本章中被艾莉丝以北神流手法掷出以制造攻隙，击中奥尔斯帝德后被龙圣斗气弹飞。
- 原文依据："改摆在位于腰间左侧，置于米格路德村拿到的无名爱剑上。"
- 原文依据："伴随着个子长高，那把剑变得越来越不合身，正想要一把稍微长一点的剑。"
- 原文依据："和艾莉丝长久以来同甘共苦的无名之剑，剑尖直指奥尔斯帝德飞翔过去。……击中了奥尔斯帝德的身体，但却被龙圣斗气弹开"

- 名称：魔导铠
- 说明：鲁迪乌斯开发的战斗装甲，被奥尔斯帝德指出是模仿传说中的"斗神"制造。具备惊人战力，但在与奥尔斯帝德战斗后被彻底打碎摧毁。
- 原文依据："魔导铠也同样有着惊人的力量。她认为没有对手能战胜那具装甲。"
- 原文依据："但是，你模仿斗神制造的那套铠甲，有着拉普拉斯因子的那股魔力，以及我的诅咒无法发挥效果的体质，有利用的价值！"

## 六、历史 / 传说 / 事件
- 事件名：「龙皇」授予初代剑神凤雅龙剑
- 内容：绝世名匠「龙皇」锻造了魔剑「凤雅龙剑」并赠予初代剑神，该剑成为剑神流代代传承的至宝。
- 原文依据："这把正是绝世名匠「龙皇」授予初代剑神的「凤雅龙剑」。能够最大限度运用剑神流的技巧。是为了剑神而存在的剑。"
