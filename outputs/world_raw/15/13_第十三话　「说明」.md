# 第十三话　「说明」 世界设定提取

## 一、地理与场所
- 名称：龙界
- 内容：古代龙族原本所在的世界，如今已经崩坏。第二代龙神魔龙王拉普拉斯当年从崩坏的龙界逃出流浪至此世界。
- 原文依据："那家伙从崩坏的龙界逃出，以第二代龙神的身分带着使命在这个世界上流浪。"

- 名称：古代龙族的遗迹
- 内容：古代龙族遗留下来的遗迹，内部藏有魔龙王拉普拉斯在第二次人魔大战丧失记忆前留下的手记。
- 原文依据："我在古代龙族的遗迹看了拉普拉斯的手记。""原来他在失去记忆前有留下纪录。然而讽刺的是，失去记忆的拉普拉斯并没有发现自己的手记。"

## 二、组织与势力
- 名称：古代龙族
- 内容：太古以前便存在的古老种族与势力。因初代龙神遭到人神杀害，第二代以后的龙神皆以打倒人神为世代夙愿。奥尔斯帝德为初代龙神之子，魔龙王拉普拉斯为初代五龙将幸存者兼第二代龙神；族中有数人（包括奥尔斯帝德、佩尔基乌斯等）通过初代龙神创造的转生法转移到现代。
- 原文依据："他是透过所谓的转生法，从太古以前转生到现代的古代龙族。""一切的起因是由于初代龙神遭到人神杀害所致。第二代以后的龙神都是为了打倒人神而存在，打倒人神正是龙族的夙愿。""在古代龙族之中，就有几人是透过这种转生法转移到现在的时代。佩尔基乌斯也是其中一人。"

- 名称：五龙将
- 内容：初代龙神旗下的五名部下。魔龙王拉普拉斯是初代五龙将唯一的幸存者。[存疑] 鲁迪乌斯认知中回忆五龙将最后以五对一和初代龙神战斗，导致两败俱伤。
- 原文依据："魔龙王拉普拉斯，他是初代五龙将的幸存者。""五龙将。我记得是龙神旗下的五人，那群人在最后以五对一和龙神战斗，两败俱伤。"

- 名称：七大列强
- 内容：由技神拉普拉斯为了传授招式与钻研技术而制作的石碑序列与强者名录，技神本人位列第一名。
- 原文依据："我记得技神这名人物是七大列强第一名……""因此技神制作『七大列强』的石碑，努力钻研自己的技术。""七大列强是技神制作的。这件事之前我曾听说。"

- 名称：魔术公会
- 内容：负责经手、变卖魔法物品与魔石的机构，提供将有色魔石兑换成资金的服务。
- 原文依据："只要拿去魔术公会变卖，应该能凑到不少钱吧。"

## 三、力量体系 / 魔法 / 技能
- 名称：龙族转生法
- 规则：初代龙神创造的奥秘技法。可将自身灵魂送往未来，侵占其他生命体进而复活。由于肉体与灵魂原本皆为独一无二，直接寄生其他身体会引发排斥反应导致复活失败；初代龙神制定的方案为先对数个个体注入自身「因子」，经过后代繁衍产生细微变化，历经数百数千世代重塑该物种身体，制造出与灵魂完全契合的容器。当重塑的身体与灵魂完全一致时，侵占原本将要出生的灵魂之身体诞生。
- 原文依据："初代龙神创造了转生法。这个技法可以将自己的灵魂送往未来，侵占其他生命体进而复活。""然而，肉体和魂魄原本都是独一无二的存在。即使寄生在其他身体，也会发生排斥反应导致复活失败。因此，初代龙神想到一个方法，那就是先对几个人注入自己的因子。一旦那名人物生下小孩，就会导致肉体产生细微变化。在经过几百几千世代之后，即可将所有那种生物的肉体重新打造，借此制作出和灵魂契合的容器。""于是，当借由『因子』重新打造的身体与灵魂完全一致时，即可执行转生。侵占原本将要出生的灵魂拥有的身体，取代那家伙诞生在这世上。"

- 名称：奥尔斯帝德所受的秘术与诅咒
- 规则：
  1. 秘术：以自身魔力恢复极其迟缓为代价，让自己脱离人神的视野监控，并获得粗略的未来视能力。
  2. 诅咒：遭到世上所有生物忌讳与排斥的诅咒。
- 原文依据："身上被施加了诅咒以及秘术。所谓诅咒，就是遭到这个世上所有生物忌讳的诅咒。所谓秘术，是以魔力恢复迟缓为代价，让自己跳脱到人神的视野之外，并得到粗略的未来视能力。"

- 名称：拉普拉斯的因子
- 规则：魔神拉普拉斯四百年前肉体被封印前分散出去的转生因子。携带因子者的特征为：极高的魔力与魔术素质、绿色头发、刚出生即拥有魔眼。因子仅提供能内藏庞大魔力的肉体素质容器，魔力总量的实际增长仍需依赖幼年期锻炼（若不锻炼则仅比常人略多）。因子的身体具备强力魔力素质，若容纳惊人魔力总量，原生灵魂可能不堪负荷而在胎内死亡。此外拉普拉斯无法转生为女性。
- 原文依据："他在被佩尔基乌斯等人打倒后，趁肉体遭到封印前分散因子，把自己的灵魂送往未来。""而现在，具有拉普拉斯因子，和那家伙有相同特征之人接二连三地出现。他们具有很高的魔力以及魔术素质，绿色头发，刚出生就拥有魔眼。""当然。那家伙无法变成女人。""你的身体只不过是拥有能内藏如此魔力的素质。如果你没趁幼年期锻炼魔力，顶多只是比常人稍微多一点魔力就终此一生。""具有拉普拉斯的因子这件事，意味着在出生的那一刻就会拥有强力的魔力素质。更何况那具身体能够内藏像你这种惊人的魔力总量，就算灵魂不堪负荷也不足为奇。"

- 名称：魔力吸收招式
- 规则：类似召唤魔术的特殊招式，佩尔基乌斯与奥尔斯帝德皆掌握，能吸收魔力，但吸收的魔力不一定能直接储存到施术者体内转化为自身魔力恢复。
- 原文依据："佩尔基乌斯之前曾用过会吸收魔力，类似召唤魔术的招式，奥尔斯帝德应该也会那招。只要透过那个吸收魔力，应该就能解决这方面的问题……不对，能的话他老早就做了。毕竟用那个召唤魔术吸收的魔力不一定能直接储存到自己体内……"

- 名称：斗气与魔力限制
- 规则：魔神拉普拉斯虽然具有惊人的魔力总量，但身体无法缠绕斗气。
- 原文依据："还有他虽然有惊人的魔力总量，却无法缠绕斗气。"

- 名称：光之太刀
- 规则：剑术招式，艾莉丝所掌握的剑技。
- 原文依据："就让会使用光之太刀的艾莉丝，见识一下我所习得的光之触摸吧。"

## 四、种族 / 生物
- 名称：古代龙族
- 特征：太古以前的世界主宰种族之一，具有极长寿命（如奥尔斯帝德转生后已生活两千年）或能跨越漫长时间转生，掌握高深秘术、转生法及传承使命。
- 原文依据："他是透过所谓的转生法，从太古以前转生到现代的古代龙族。""在古代龙族之中，就有几人是透过这种转生法转移到现在的时代。"

- 名称：人神
- 特征：被奥尔斯帝德称为「人渣」的存在。杀害了初代龙神，为龙族全体的宿敌；会挑选并操控使徒（如第二次人魔大战中操控斗神）阻碍龙神；其视野无法看见施加了龙族特定秘术的奥尔斯帝德。
- 原文依据："一切的起因是由于初代龙神遭到人神杀害所致。""会有人不对那个人渣抱有恨意吗？""以魔力恢复迟缓为代价，让自己跳脱到人神的视野之外""但是拉普拉斯在第二次人魔大战和成为人神使徒的斗神战斗，导致灵魂被一分为二。"

- 名称：魔神拉普拉斯
- 特征：魔龙王拉普拉斯在第二次人魔大战灵魂分裂后堕落的化身。失去了龙之力，丧失记忆，只记得必须杀害「人」的目的，保留庞大魔术知识；统率魔族试图消灭人族；无法变为女性；肉体被封印前将因子分散到未来，预计还要过数十年才会真正转生诞生。
- 原文依据："『魔神拉普拉斯』的真正身分……他是『魔龙王拉普拉斯』堕落之后的化身。""『魔神』拉普拉斯失去了龙之力。那家伙只记得自己的目的是必须将『人』杀害，并保有着原本庞大的魔术知识。他之所以会统率魔族，为的就是要消灭『人族』。""当然。那家伙无法变成女人。""拉普拉斯应该还要再过几十年才会出生。"

- 名称：技神拉普拉斯
- 特征：魔龙王拉普拉斯灵魂分裂后的另一半化身。失去了魔力，但保留了大量武技招式，只依稀记得要将技术传授给某人的目的；位居七大列强第一名，制作了七大列强石碑。
- 原文依据："分裂为憎恨人类存在的『魔神』，以及试图打倒神明的『技神』。""『技神』拉普拉斯失去了魔力。那家伙保有大量的招式，然而他只依稀记得自己的目的是必须把这些技巧传授给某人。因此技神制作『七大列强』的石碑，努力钻研自己的技术。"

- 名称：王龙王卡夏库特
- 特征：龙王之一，其骨头质地极佳，被魔界名刀匠用作锻造高级魔剑的核心材料。
- 原文依据："这是魔界的名刀匠尤里安•哈利斯可用王龙王卡夏库特的骨头打造的四十八把魔剑之一，魔剑『指折』。"

- 名称：尤里安·哈利斯可
- 特征：魔界著名的顶尖刀匠，曾使用王龙王卡夏库特的骨头打造了四十八把魔剑。
- 原文依据："这是魔界的名刀匠尤里安•哈利斯可用王龙王卡夏库特的骨头打造的四十八把魔剑之一，魔剑『指折』。"

- 名称：斯佩路德族
- 特征：四百年前在人魔战争中曾遭到魔神拉普拉斯陷害的种族。
- 原文依据："还有曾经陷害过斯佩路德族，大概是这些事吧。"

## 五、物品 / 道具 / 武器
- 名称：魔剑『指折』
- 说明：魔界名刀匠尤里安·哈利斯可用王龙王卡夏库特的骨头打造的四十八把魔剑之一。剑鞘上镶有华丽装饰的短剑/小刀。价值极其高昂，变卖至少可换得十万枚阿斯拉金币。
- 原文依据："是在剑鞘上镶有华丽装饰的小刀。不对，应该是短剑吧。他把短剑轻轻地放在桌上。""这是魔界的名刀匠尤里安•哈利斯可用王龙王卡夏库特的骨头打造的四十八把魔剑之一，魔剑『指折』。拿去卖掉至少能换到十万枚阿斯拉金币。你就暂时拿去充当资金吧。"

- 名称：有色魔石
- 说明：各种颜色的高纯度透明魔石（包含蓝色、红色、绿色、黄色、黑色以及白色），体积虽小但价值甚高，可在魔术公会换取大量资金（估算足够十年开销）。
- 原文依据："发现里面放了许多各种颜色的透明石头。有蓝色、红色、绿色、黄色、黑色以及白色。""是魔石。尽管小颗，但我帮你挑选了带有颜色的魔石。只要拿去魔术公会变卖，应该能凑到不少钱吧。"

- 名称：七大列强石碑
- 说明：技神拉普拉斯为了传授与钻研技巧而设立的世界石碑，刻有七大列强强者的座次。
- 原文依据："因此技神制作『七大列强』的石碑，努力钻研自己的技术。""七大列强是技神制作的。这件事之前我曾听说。"

- 名称：拉普拉斯的手记
- 说明：魔龙王拉普拉斯在古代龙族遗迹留下的记录文献，记载了龙界崩坏、人神恩怨及转生法等太古内幕。失去记忆后的拉普拉斯自身未能找到该手记，后被奥尔斯帝德寻获阅读。
- 原文依据："我在古代龙族的遗迹看了拉普拉斯的手记。""原来他在失去记忆前有留下纪录。然而讽刺的是，失去记忆的拉普拉斯并没有发现自己的手记。"

- 名称：未来日记
- 说明：鲁迪乌斯从未来带回的记录未来历史情报的日记，字迹难认，奥尔斯帝德需花费一天通读，用以与自身粗略的未来视相互对照。
- 原文依据："我把未来的日记递给奥尔斯帝德。他打开日记随手翻了几页。接着皱起眉头，抬头说道：『这会稍微花点时间，而且字也很难看懂。』""奥尔斯帝德可以做到粗略的未来视。那么，只要和我的日记互相比照，就有可能从中发现什么。"

## 六、历史 / 传说 / 事件
- 事件名：初代龙神遇害与龙神代代使命确立
- 内容：太古时代，初代龙神遭到人神杀害。此后第二代以后的龙神皆为了消灭人神而存在，打倒人神确立为龙族全族世代夙愿。初代龙神将自身幼子奥尔斯帝德通过秘术与转生法送往未来。
- 原文依据："一切的起因是由于初代龙神遭到人神杀害所致。第二代以后的龙神都是为了打倒人神而存在，打倒人神正是龙族的夙愿。因此，身为初代龙神之子的奥尔斯帝德才会想打倒人神。"

- 事件名：龙界崩坏与拉普拉斯流浪传法
- 内容：古代龙界崩坏，初代五龙将幸存者魔龙王拉普拉斯逃脱，以第二代龙神身份肩负使命在这个世界流浪。拉普拉斯钻研招式与术法，自称龙神并将技术传授给有才能之人以促进发展，旨在将力量传承给送往未来的最强龙族奥尔斯帝德。
- 原文依据："那家伙从崩坏的龙界逃出，以第二代龙神的身分带着使命在这个世界上流浪。""那家伙为了打倒人神钻研术法与招式。自称龙神，传授技术给具有才能的人，花费长时间促进发展。为的就是把这股力量交付给被送到未来的我，具有最强力量的龙族。"

- 事件名：第二次人魔大战与拉普拉斯灵魂分裂
- 内容：约两千年前爆发的第二次人魔大战中，拉普拉斯与成为人神使徒的斗神交手战斗，导致灵魂被一分为二并丧失记忆，分别蜕化为憎恨人族的「魔神拉普拉斯」与传承招式的「技神拉普拉斯」。
- 原文依据："但是拉普拉斯在第二次人魔大战和成为人神使徒的斗神战斗，导致灵魂被一分为二。""被一分为二的拉普拉斯丧失了记忆，分裂为憎恨人类存在的『魔神』，以及试图打倒神明的『技神』。""毕竟人魔大战是两千年以前的事了吧。"

- 事件名：奥尔斯帝德转生现代
- 内容：距今约两千年前，初代龙神之子奥尔斯帝德通过转生法降临转生至现代世界。
- 原文依据："『您大概是在几年前转生到现代的呢？』『这个嘛……应该是距今两千年前吧。』"

- 事件名：四百年前的人魔战争与拉普拉斯封印
- 内容：四百年前魔神拉普拉斯发动战争将人族逼至绝境并陷害斯佩路德族，最终被佩尔基乌斯与另外两名同伴击败封印；拉普拉斯在肉体被封印前将自身因子分散，把灵魂送往未来。
- 原文依据："他是在四百年前引发战争的人物，我知道他曾把人族逼到绝境。……尽管他实力非常强大，却遭到佩尔基乌斯大人和另外两名同伴封印……还有曾经陷害过斯佩路德族""他在被佩尔基乌斯等人打倒后，趁肉体遭到封印前分散因子，把自己的灵魂送往未来。"

- 事件名：转移事件与世界异变
- 内容：七星被召唤到该世界引发的大规模转移灾难。对于经历无数历史轮回记忆的奥尔斯帝德而言，无论是七星与鲁迪乌斯的出现，还是转移事件本身，都是历史上首次发生的未知异变。
- 原文依据："『我听说转移事件是因为七星被召唤过来而导致的，请问可以让我询问详细状况吗？』『……关于那起事件，还有很多未解的谜团。这种事情是我第一次遇上。』""毕竟无论是七星还是你，甚至是那起转移事件，都是至今未曾发生过的状况。"

## 七、社会规则 / 习俗 / 文化
- 内容：阿斯拉王国的阿斯拉金币具备极高购买力。1枚阿斯拉金币折合鲁迪乌斯原世界约10万日圆；十万枚阿斯拉金币相当于约100亿日圆，足以让人挥霍一辈子甚至建造一座城堡，只有大国顶级王族与顶级大贵族（如阿斯拉王族、爱丽儿的兄弟）可能具备购买相应价值物品（如名刀匠魔剑）的财力。

- 内容：雇佣与责任对等原则。鲁迪乌斯遵循金钱即责任的雇佣理念：雇主支付报酬代表要求对方负责，雇员收取报酬代表承担义务；同时提出需保障休假与陪伴家人的权利。奥尔斯帝德认可照顾家庭的必要性，并以预付魔剑与魔石作为资金支持。
- 原文依据："所谓的钱就是责任。支付薪水意味着要他人负起责任。收领薪水意味着要承担责任。与钱无关的工作就会成为没有责任的工作……""因为我还有家室，所以想要定期有个休假之类的。还有跟家人碰面的时间，如果有的话我会非常感激。""你不惜舍命也想保护家人，那我不可能把你和家人拆散。至于要带着你好几年到处奔波……目前也没那个打算。""我会尽可能通融。"

## 九、角色认知 vs 客观事实
### 1. 鲁迪乌斯对自身庞大魔力成因的认知
- 角色以为：自己的庞大魔力纯粹是通过幼年期自身努力锻炼而获得的成果。
- 原文是否暗示另有真相：是
- 原文依据："『……我以为魔力是因为我自己努力才有所成长。』『当然是这样没错。你的身体只不过是拥有能内藏如此魔力的素质。如果你没趁幼年期锻炼魔力，顶多只是比常人稍微多一点魔力就终此一生。希露菲叶特也是如此。那庞大的魔力是你自己努力得来的收获，大可为此自豪。』"
- 说明：奥尔斯帝德指出，鲁迪乌斯的肉体具备的是拉普拉斯因子赋予的「能内藏如此魔力的容器素质」；如果幼年不加锻炼，也仅比常人略多。因此庞大魔力是「因子素质容器」与「幼年锻炼」两者共同造就的结果，并非纯粹单方面原因。

### 2. 鲁迪乌斯对魔神拉普拉斯身份的认知
- 角色以为：拉普拉斯从一开始就是纯粹的魔族魔神。
- 原文是否暗示另有真相：是
- 原文依据："拉普拉斯是魔龙王。他曾是龙族？但他应该是魔神才对吧？""『关于「魔神拉普拉斯」的真正身分……他是「魔龙王拉普拉斯」堕落之后的化身。』……『没错，那家伙曾经是古代龙族。』『魔龙王拉普拉斯，他是初代五龙将的幸存者。』"
- 说明：客观事实是拉普拉斯原为古代龙族初代五龙将之一，并曾担任第二代龙神。因在第二次人魔大战中与斗神战斗导致灵魂分裂，失去龙之力并丧失记忆后才堕落成为统率魔族的「魔神」。

### 3. 鲁迪乌斯对自己转生是否剥夺原主生命的认知
- 角色以为：自己转生到异世界，可能夺走了原本名为鲁迪乌斯·格雷拉特之人的生命与人生。
- 原文是否暗示另有真相：是
- 原文依据："『放心吧。虽说你也是转生者……但在我的记忆中，不存在鲁迪乌斯•格雷拉特这名人物。』……『具有拉普拉斯的因子这件事，意味着在出生的那一刻就会拥有强力的魔力素质。更何况那具身体能够内藏像你这种惊人的魔力总量，就算灵魂不堪负荷也不足为奇。』……『……想必原本就已胎死腹中。你是刚好滑进去的。』"
- 说明：奥尔斯帝德根据既往历史记忆中不存在鲁迪乌斯这名人物，以及拉普拉斯因子肉体负荷极高进行推断：婴儿原本的灵魂极可能不堪负荷而在腹中早夭胎死，异世界的鲁迪乌斯灵魂只是刚好滑入了死胎躯体，并未剥夺他人存活的人生。

### 4. 鲁迪乌斯怀疑希露菲或自己是拉普拉斯本人
- 角色以为：希露菲叶特（绿发、高魔力）或自己（惊人魔力总量）可能是拉普拉斯本人转生。
- 原文是否暗示另有真相：是
- 原文依据："『她应该不是拉普拉斯本人吧？』『当然。那家伙无法变成女人。』""『那个，我应该不是拉普拉斯本人吧？』『不是。拉普拉斯应该还要再过几十年才会出生。』"
- 说明：客观事实是希露菲叶特为女性，而拉普拉斯无法转生为女性；鲁迪乌斯所处时代偏早，真正的拉普拉斯还要再过数十年才降生。两人均仅为拉普拉斯因子的持有者，而非其本人。

### 5. 鲁迪乌斯怀疑转移事件是否由自己引发
- 角色以为：自己是转生者且事故时身在现场，转移事件有可能是由自己引起的。
- 原文是否暗示另有真相：不明
- 原文依据："『……关于那起事件，还有很多未解的谜团。这种事情是我第一次遇上。』……『我不否定有这个可能性。毕竟无论是七星还是你，甚至是那起转移事件，都是至今未曾发生过的状况。』"
- 说明：奥尔斯帝德表示这是至今历史中从未发生过的突发异变，七星、鲁迪乌斯与转移事件皆为前所未见，无法确证亦无法否定鲁迪乌斯是否与事件成因相关，真相尚不明晰。
