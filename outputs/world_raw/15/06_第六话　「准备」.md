# 第六话　「准备」 世界设定提取

## 一、地理与场所
- 名称：夏利亚郊外的小屋（魔导铠工房）
- 内容：鲁迪乌斯在魔法都市夏利亚郊外购置的小屋。由于装甲龙王佩尔基乌斯不允许在空中要塞制造魔导铠，鲁迪乌斯在此设立秘密工房，召集札诺巴、克里夫、洛琪希、希露菲等人一同研发与组装「魔导铠」。
- 原文依据："因此，我首先在魔法都市夏利亚郊外买下了一间小屋。原本我打算在空中要塞制作，但没有获得佩尔基乌斯的允许。"

- 名称：夏利亚废屋地下（地下黑市据点）
- 内容：位于魔法都市夏利亚废屋的地下室，由阿斯拉王国第二王女爱丽儿引荐的地下犯罪集团（黑手党/暴力团）设立的秘密交易据点。室内弥漫着甘甜香气的烟雾，暗中进行毒品、管制私售品以及各种暗杀用毒药、麻痹药、媚药的交易。
- 原文依据："在成员的带领下，我来到魔法都市夏利亚的废屋地下，那房间弥漫着闻起来甘甜的烟。在那里等我的人是负责交涉的独眼男子。"

- 名称：无之世界
- 内容：人神（HITOGAMI）所在的纯白无物之异度空间，鲁迪乌斯在梦中被拉入该空间的中心与人神对话。
- 原文依据："白色的场所。我位于无之世界的中心。"

- 名称：鲁迪乌斯宅邸地下室
- 内容：鲁迪乌斯家中存放杂物魔力附加品与洛斯切特神龛的地下仓库。两个月前曾因魔石病老鼠事件而遭到「冰霜新星」冻结封闭。在经过两个月确认病毒灭绝后被鲁迪乌斯正式解禁。
- 原文依据："最后，我解禁地下室，面向神龛做了战胜祈愿。杀死老鼠后过了两个月。如果要相信未来的我所说的话，经过了这么久的时间，魔石病的病菌和病毒应该已彻底灭绝。……顺带一提，我也试着翻找这里，试图寻找是不是有好东西能拿来对抗奥尔斯帝德。然而，放在地下室的魔力附加品尽是些破铜烂铁。这些破铜烂铁虽然因为「冰霜新星」的影响而一度遭到冻结，不过还是能顺利运作。"

## 二、组织与势力
- 名称：夏利亚地下工作集团（黑手党 / 暴力团）
- 内容：活跃于魔法都市夏利亚地下的隐秘犯罪网络，性质属于盗贼团升级版的黑手党或暴力团组织。与阿斯拉王国第二王女爱丽儿有暗中私交往来，专门经营毒品、私售管制物资，并承接定制特种暗杀剧毒、麻痹药与媚药等业务。交涉人是一名独眼男子。
- 原文依据："不过，即使如此她还是帮我介绍与自己有交情的地下工作集团。那个集团就像是盗贼团的升级版，所以正确的说法应该是黑手党或暴力团，算是交易毒品和私售品的组织，似乎也愿意为我制作暗杀用的毒。"

- 名称：冒险者公会（夏利亚分部）
- 内容：夏利亚的冒险者据点。除了承接委托与日常交流外，还具备情报集散功能。鲁迪乌斯在此公开发布募集远离城镇、杳无人烟且适合设置陷阱的作战场地情报，并可经由人脉介绍具备暗杀经验的前冒险者传授对人陷阱技巧。
- 原文依据："我在冒险者公会募集那种场所的情报，获得情报后，就自己亲自造访该处进行探勘。另外，关于制作陷阱的方法，我也麻烦艾莉娜丽洁介绍冒险者讲解技巧。指导我的冒险者原本是名暗杀者，因此知道许多专门用来对付人的陷阱。"

## 三、力量体系 / 魔法 / 技能
- 名称：世上不可为敌之三人
- 规则：根据佩尔基乌斯所述，世界上有三个人绝对不可与之为敌，分别为「技神」、「斗神」以及「龙神」。尤其是龙神奥尔斯帝德，在这三人之中更是特别强大且冷酷毫不留情。
- 原文依据："佩尔基乌斯还这么说：「在这个世上，有三个人不能与之为敌。那就是技神、斗神以及龙神。尤其龙神奥尔斯帝德在这三人之中更是特别强大，而且毫不留情。」"

- 名称：魔导铠技术体系与魔法阵构成
- 规则：
  1. 强化魔法阵：克里夫能够编排提升外壳高硬度岩石物理强度的魔法阵；
  2. 术式选型：躯干部位的魔法阵不适合使用「温德式」，而应采用「亚雷斯塔尔式」；
  3. 双层自修复结构：机体尺寸加大虽会增加能量损耗，但允许在主魔法阵下方铺设底层追加魔法阵，编入用于修复破损魔法阵的功能，使机体在大面积受损时仍能正常运转；
  4. 装甲加工：唯有鲁迪乌斯能以自身魔力制造并加工出作为物理外壳与关节的高硬度岩石。
- 原文依据："「克里夫的话，应该有办法编成魔法阵提高岩石本身的硬度。你只要负责处理物理硬度所需的外壳和关节部分即可。然后，身体部位的魔法阵别用温德式，只要应用亚雷斯塔尔式就好。这样伤脑筋的部分应该就可获得解决。」……「再来，你可以跟札诺巴说大小要再稍微大一号。尽管这样一来会更加损耗能量，但可以在魔法阵下面再铺上别的魔法阵。只要在追加的魔法阵上编入用来修复其他魔法阵的魔法阵，这样一来就算机体的大部分都遭到破坏应该也能运转喔。」"

- 名称：魔道具魔力驱动与对抗乱魔机制
- 规则：
  1. 魔道具只需注入魔力即可击发魔术，无需经过自身咏唱构筑，因此可有效对付奥尔斯帝德的「乱魔」并增加攻击频次；
  2. 市售大众化魔道具会压低魔力消耗以适应常人，但刻意拔高魔力消耗时并无上限；
  3. 若魔道具的单发魔力消耗过大，连续击发时可能会反噬并彻底吸尽使用者的魔力致死。
- 原文依据："「那你就用魔道具吧。只要注入魔力就能击发魔术的魔道具，在夏利亚应该到处都有得买才是。为了让一般人可以使用，那种东西会抑制消耗魔力，不过只要有心想提高消耗魔力的话其实并不存在上限。就像你们做的『札里夫义手』一样。只要事先准备好几个只能透过你的魔力才有办法使用，能够击发大出力魔术的魔道具，这样一来不仅可以用来对付乱魔，还可以增加攻击次数。」……「可是，如果按照你要求的方式制作，每一发都会消耗过大的魔力，你很有可能会被魔道具吸尽魔力而死喔。」"

- 名称：乱魔
- 规则：奥尔斯帝德所掌握的能扰乱并打消对手魔术的秘技。发动乱魔的前提是能够用肉眼观测到对手的施术位置；若处于超远距离肉眼无法辨识之处，则无法发动乱魔。
- 原文依据："如果距离远到对方无法用肉眼确认我的位置，自然也无法使用乱魔。"

- 名称：龙门
- 规则：龙神奥尔斯帝德所拥有的另一项招牌绝招/秘技，鲁迪乌斯将其视为必须防范的未知高危能力之一 [存疑]。
- 原文依据："然而，奥尔斯帝德除了乱魔以外还有龙门。除此之外肯定还有其他压箱绝活吧。"

- 名称：解毒魔术的局限性
- 规则：虽然世界中存在解毒魔术，但并非所有毒素与疾病都能被解毒魔术治愈，依然存在着现存解毒魔术无法医治的烈性剧毒与特殊疾病。
- 原文依据："虽然在这世界有解毒魔术，但也存在着现存的解毒魔术无法医治的疾病和剧毒。"

- 名称：人神的未来视限制与强命运法则
- 规则：
  1. 人神无法观测到龙神奥尔斯帝德的未来，也无法预知与奥尔斯帝德战斗的胜负结果；
  2. 人神能够观测到自身未来的情景（如自身未来被鲁迪的后代与包括奥尔斯帝德在内的人围困并残忍杀死）；
  3. 拥有极强命运的个体及其核心因果（如鲁迪乌斯与洛琪希结合生子的事实），无论人神在现实中进行多少次修正干涉，未来仍会不可逆地收束并达成既定结果；
  4. 人神受命运法则限制无法亲手直接杀死拥有强命运的鲁迪乌斯或奥尔斯帝德。
- 原文依据："「我看不见奥尔斯帝德的未来。这当然也包括你们战斗的结果。所以我不知道啊。」……「虽然我看不见奥尔斯帝德，但至少能看见自己的未来。我看见你的后代和不认识的男人一起包围我，其中也包含了奥尔斯帝德。」……「因为你们就是会生下啊。无论我再怎么苦口婆心，你还是会和洛琪希生下小孩。仿佛未来已经那样注定似的。就算我再怎么修正……无论修正再多次，最后还是会到达那个未来。」……「我确实杀不了你，也杀不了奥尔斯帝德。……那是因为你的命运很强，我只是想利用这点早点摘除幼苗而已……」"

- 名称：鲁迪乌斯的魔力量层级
- 规则：人神指出鲁迪乌斯的魔力量与魔神拉普拉斯相当；鲁迪自估每日击发的全威力岩炮弹极限不只一两万发。
- 原文依据："「你的魔力和拉普拉斯相当。只要全力以赴，应该会有不错的成果吧。」……但是我一天可以击发的岩砲弹应该不只一两万发吧。大概。"

- 名称：神子体质的防御局限
- 规则：神子（如札诺巴）虽然天生具备极其惊人的怪力与强悍肉体防御力，但并非绝对防御，面对阿托菲等上位至强者的强力物理攻击依然会受到有效伤害。
- 原文依据："尽管我有想过拥有高强臂力以及绝大防御力的札诺巴或许有机会一战……但是阿托菲可以对身为神子的札诺巴造成物理伤害。我不认为奥尔斯帝德办不到这点。"

## 四、种族 / 生物
- 名称：长耳族
- 特征：在魔法都市夏利亚一带较为少见。外表特征普遍为眉清目秀、容姿俊美。亦有长期埋头从事魔道具工匠行业而导致指甲乌黑、面孔焦黑的特例从业者。
- 原文依据："她是在这一带很少见的长耳族女性。虽然长耳族都是眉清目秀，但那个人整片指甲乌漆抹黑，脸也黑不溜丢的，俨然是个行家。"

- 名称：巨大的龙
- 特征：世界上的大型强悍龙族魔兽/生物。但在世界顶尖至强者龙神奥尔斯帝德面前极其脆弱，奥尔斯帝德仅需一击即可将其斩杀。
- 原文依据："我和他在一起有几年的时间，但从来没看过他陷入苦战。就连巨大的龙也只用仅仅一击……"

- 名称：米戈路德族（孕期生理特征）
- 特征：洛琪希怀孕初期尚无孕吐反应，但味觉与食欲会出现明显变化，并在心理与行为上刻意回避房事接触。
- 原文依据："虽然还没有开始孕吐，但可以看出味觉已产生变化。"

## 五、物品 / 道具 / 武器
- 名称：魔导铠（一式原型）
- 说明：鲁迪乌斯以未来日记为蓝本，联合札诺巴（驱动设计）、克里夫（魔法阵与义手系统）、洛琪希（统筹监督）、希露菲（魔法阵辅助）打造的动力装甲机兵。高约3公尺，体积较日记记载的原版扩大一号；外壳由鲁迪乌斯的高硬度岩石构成，内部刻有亚雷斯塔尔式魔法阵以及底层自修复备用魔法阵，能使穿着者获得匹敌世界列强的体能。
- 原文依据："假使日记上所写属实，只要打造出魔导铠，我就能获得与列强并驾齐驱的体能。……高约三公尺，大小约为奥○拜特拉的一半。日记上记载的魔导铠顶多覆盖我全身，不过成品比那还要再大一些。试着做大一点后也发现了许多事情。以技术层面来说大的比较轻松，坚固性也相对更高。"

- 名称：斗神铠
- 说明：人神知晓的传说级战甲兵器，为人界三大至强之一「斗神」所拥有的武装。人神正是参考斗神铠的构造与特性向鲁迪提出改良魔导铠的建议。
- 原文依据："「我是人神嘛，因为我知道斗神铠，好歹也能帮你提出建议。」"

- 名称：十连装加特林型岩炮弹魔道具
- 说明：鲁迪乌斯设计、夏利亚长耳族工匠受托打造的近距离重火力武装。将十把经过改造、能承受鲁迪庞大魔力负荷的高出力魔杖捆绑组合而成，可通过连续注入巨量魔力实现如加特林机枪般的岩炮弹高速连发。
- 原文依据："要是我进一步增加出力，使其能灌注源源不绝的魔力达到连发效果，再把这些做出十把捆在一起的话──是不是就能把我平常使用的岩砲弹变成像加特林机枪那样连续射击？……总之，这样一来就取得了近距离战斗的武器。就祈祷它能派上用场吧。"

- 名称：普及型魔杖魔道具
- 说明：夏利亚市面常见的大众化魔道具，外形呈短杖状。使用者只要握持并念出关键词「射穿」即可发动，发射威力较低的初级魔术，常被缺乏魔术能力的盗贼用于远程偷袭。
- 原文依据："那是有着魔杖外型的魔道具。只要喊一声「射穿」就能启动，发射初级魔术。以魔道具来说比较大众化，威力也没什么了不起。如果是想要远距离攻击的盗贼什么的偶尔也会拿来使用。"

- 名称：黑市药物（致死剧毒、麻痹药、媚药）
- 说明：魔法都市夏利亚地下犯罪集团调配与贩卖的非法药剂。包括：缓慢折磨致死毒药、瞬息致命剧毒、致双腿麻痹瘫痪药剂、专门麻痹舌头以封印魔术师咏唱的药剂，以及令女性剧烈动情的强效媚药。
- 原文依据："「你今天想要什么货啊？是可以慢慢折磨对方的，还是一下就让人倒下去的？会让双脚麻痹动弹不弹的，还是针对魔术师的那种会让舌头麻痹的？也有会让女人倾盆大水的那种。如果办起事来枯燥乏味，我推荐你不妨一试。」从毒药到麻痹药，甚至连媚药都有经手。正合我意。「我全都要。」"

- 名称：地下室废弃魔力附加品
- 说明：鲁迪乌斯宅邸地下室存放的奇特魔力道具，虽经「冰霜新星」冰冻但仍可运转，功能多属古怪鸡肋：
  1. 喷水帽子：戴上后再脱下时内部会涌出水流；
  2. 发光头盔：额头宝石会发光，可用作手电筒照明；
  3. 滚浓烟小箱：开启后内部喷出滚滚浓烟（鲁迪计划选作战术烟雾弹）；
  4. 橡胶短剑：突刺攻击对手时刀身会变软如橡胶；
  5. 散发恶臭的鞋子：穿上后会持续散播刺鼻恶臭。
- 原文依据："然而，放在地下室的魔力附加品尽是些破铜烂铁。这些破铜烂铁虽然因为「冰霜新星」的影响而一度遭到冻结，不过还是能顺利运作。一旦戴上，想要脱下的时候就会从里面冒出水的帽子。戴上后额头的宝石就会发光，用来代替手电筒的头盔。打开后会从里面冒出滚滚浓烟的小箱子。想要突刺对手时，刀身会变得像橡胶一样松软的短剑。穿上后会散播恶臭的鞋子。"

- 名称：万灵药 [存疑]
- 说明：传说中能够治愈一切毒素与异常状态的神奇药剂。鲁迪乌斯在考量奥尔斯帝德是否具备毒杀免疫时，推测其可能携带有万灵药之类的道具。
- 原文依据："或者说他对毒药具有抗性，还是持有着万灵药之类的道具也说不定。"

- 名称：瑞杰路德人偶与十字架摆饰
- 说明：札诺巴制作赠予七星的瑞杰路德木雕人偶，以及克里夫赠予七星的密里斯十字架摆饰，陈列在七星空中要塞居室的窗台边。
- 原文依据："放在窗边的瑞杰路德人偶，想必是札诺巴送的礼物。十字架的摆饰应该是克里夫送的吧。"

## 六、历史 / 传说 / 事件
- 事件名：人神真名与JINSHIN称呼的由来
- 内容：人神自述其真正名字为「人神（HITOGAMI）」，在这个世界上流传的「JINSHIN」只是类似绰号的称谓，因不知不觉间普及而为人所知。

- 原文依据："杀死老鼠后过了两个月。如果要相信未来的我所说的话，经过了这么久的时间，魔石病的病菌和病毒应该已彻底灭绝。"

- 内容：空中要塞待死者以宽大礼遇。装甲龙王佩尔基乌斯虽拒绝介入与奥尔斯帝德的战斗，但对主动踏上赴死道路之人抱持敬佩与宽容态度，特许其自由进出城堡进行临终诀别。

- 原文依据："指导我的冒险者原本是名暗杀者，因此知道许多专门用来对付人的陷阱。是看穿对方心理的陷阱。事实上我自己也测试了几个，不论我再怎么小心，依然还是中了招。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯原以为人神只能在彼此“波长相得”且只能与“限定对象”在梦境中接触。
- 原文是否暗示另有真相：是。
- 原文依据：人神亲口坦白之前关于波长相得以及限定接触对象的说法纯粹是谎言。"「表示你以前说必须波长相得才能出现是骗我的吗？」「嗯，是骗你的。」……「照这样看来，你说只能和限定的对象进行接触也是骗我的吧？」「嗯，是骗你的。不过这样有被神选中的感觉，很特别对吧？」"

- 角色以为：人神声称自己此前只在地下室老鼠事件上骗过鲁迪乌斯一次，其余建议均非谎言。
- 原文是否暗示另有真相：是。
- 原文依据：人神在同一段对话中刚坦承关于出现条件（波长相得、限定对象）都是谎言，其“只有地下室那一次是谎言”的说法本身就是谎言。"「真过分啊，我话先说在前头，会让你吃亏的谎言，只有在地下室的那一次而已喔。」"

- 角色以为：鲁迪乌斯质问人神是否曾对奥尔斯帝德做过过分之事导致对方复仇，人神坚称自己对奥尔斯帝德毫无印象。
- 原文是否暗示另有真相：不明 [存疑]。
- 原文依据：人神自称对奥尔斯帝德完全没有印象，但鲁迪乌斯明确指出人神满嘴谎言，其陈述真实性无法判定。"「这个嘛，这我就不清楚啦。对于他这个人我完全没有印象。」……算了，怎么样都无所谓。你的话里满是谎言，反正不管你说什么都无法让人相信。"

- 角色以为：鲁迪乌斯与七星设想利用下毒（现存解毒魔术无法医治的剧毒、麻痹药、媚药）与心理陷阱来对付奥尔斯帝德，认为即便无法正面击败也能借此制造破绽和消耗。
- 原文是否暗示另有真相：不明 [存疑]。
- 原文依据：鲁迪乌斯自身也推测奥尔斯帝德可能对毒素有抗性、持有万灵药或随时防备毒杀，毒药与陷阱能否奏效完全无法保证。"尽管我不认为这种耍小聪明的技俩会对奥尔斯帝德管用……不，就算是耍小聪明，只要反复运用就能延续攻势。应该不可能完全不管用才是。"以及"奥尔斯帝德好像拥有被人讨厌的诅咒，所以他对毒杀应该也有所防范。或者说他对毒药具有抗性，还是持有着万灵药之类的道具也说不定。"

- 角色以为：佩尔基乌斯与希尔瓦莉尔认定鲁迪乌斯挑战奥尔斯帝德必死无疑，已将其视作“即将赴死之人”。
- 原文是否暗示另有真相：不明。
- 原文依据：希尔瓦莉尔表示："佩尔基乌斯大人对即将赴死之人非常宽大。倘若您想和七星大人做最后的道别，自然也会允许这样的行为。"鲁迪亦自述："看样子，我好像已经被认定会惨败然后死去。"

- 角色以为：鲁迪乌斯认为只要战胜奥尔斯帝德，人神就会履行约定不再干涉鲁迪乌斯及其家族。
- 原文是否暗示另有真相：不明 [存疑]。
