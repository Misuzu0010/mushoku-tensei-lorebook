# 第十话　「遭遇瓶颈」 世界设定提取

## 一、地理与场所
- 名称：罗亚（Roa）
- 内容：位于阿斯拉王国菲托亚领地的都市，设有教育机构（学校），负责教导读书写字、算数、历史、礼仪规矩等知识，领地内附近的贵族子弟多在此就学。
- 原文依据："「所谓学校，是指位于菲托亚领地的都市『罗亚』的教育机构，会教导读书写字、算数、历史、礼仪规矩之类的知识。」"

- 名称：龙鸣山 与 龙神孔
- 内容：位于中央大陆赤龙山脉的灵峰──「龙鸣山」，其山麓坐落着迷宫「龙神孔」。龙神孔是目前已知存在时间最长、范围最深的迷宫，文献记载一万年前已存在，推测最底层深达二千五百层。龙鸣山山顶上的大洞并非火山口，而是龙神孔为了捕食赤龙而开启的洞口，经过其上方的龙会被吸入其中。相传从山顶洞穴跳入能瞬间抵达最底层附近，但尚无人以此法生还并爬出。
- 原文依据："在目前已经发现的迷宫中，存在时间最长范围最深的迷宫是位于中央大陆赤龙山脉的灵峰──「龙鸣山」山麓的「龙神孔」。根据文献，据说这里在一万年前就已经存在，而推测出的最底层是二五○○层。还有种说法指出此迷宫和龙鸣山山顶上的洞穴相连，只要从山顶上跳入洞穴内，就能瞬间到达最底层附近，然而还没有人用这种方法下去并爬上来过。顺道一提，那个山顶上的洞并不是火山口。而是「龙神孔」为了捕食赤龙而开启的洞口。要是有龙经过洞口上方，似乎就会被吸入。"

- 名称：赤龙山脉
- 内容：横亘于中央大陆的山脉，山脉上栖息着赤龙，极其危险导致无法直接穿越通行，从阿斯拉前往中央大陆南部诸国必须避开山脉从南边大幅绕行。
- 原文依据："在目前已经发现的迷宫中，存在时间最长范围最深的迷宫是位于中央大陆赤龙山脉的灵峰──「龙鸣山」山麓的「龙神孔」""然而，这个中央大陆的山脉上居住着赤龙因此无法通行，必须避开山脉从南边绕很远的路才能到达。"

- 名称：地狱（迷宫）
- 内容：位于天大陆的巨大迷宫，与「魔神窟」并列为目前已知难度最高的迷宫。光是前往入口就极度困难，且无法顺利进行物资补给，难以稳定推进探索。
- 原文依据："再顺便讲一下，目前被视为难度最高的迷宫是天大陆的「地狱」，以及林古斯海中央的「魔神窟」。两个都位于光是要到达入口就很困难，而且也无法顺利进行补给的地方。不但迷宫本身就很庞大，也无法稳定下来探索，因此被评价为最高难度。"

- 名称：魔神窟（迷宫）
- 内容：位于林古斯海中央的巨大迷宫，同样因入口险恶、补给困难、规模庞大而被公认为最高难度迷宫之一。
- 原文依据："以及林古斯海中央的「魔神窟」。两个都位于光是要到达入口就很困难，而且也无法顺利进行补给的地方。不但迷宫本身就很庞大，也无法稳定下来探索，因此被评价为最高难度。"

- 名称：西隆王国
- 内容：位于中央大陆南部偏东方的小国。王都建有王宫与藏书丰富的书库，其中藏有水王级魔术的书籍；王国内设有宫廷魔术师编制。
- 原文依据："目前我滞留在西隆王国的王都。之前以冒险者身分前往迷宫后，不知何时似乎打出了名号，最后就被聘为王子殿下的家庭教师。……西隆王国的书库里，有水王级魔术的相关书籍。""原来是位于中央大陆南部偏东方的小国。直线距离并没有很远。然而，这个中央大陆的山脉上居住着赤龙因此无法通行，必须避开山脉从南边绕很远的路才能到达。"

- 名称：拉诺亚（魔法大学所在地）
- 内容：位于阿斯拉王国西北方，路途遥远，需往西北绕一大圈。该地建有著名的拉诺亚魔法大学，是高深魔术的研究与教学中心。
- 原文依据："而且，魔法大学所在的拉诺亚也必须往西北绕一大圈才能到达。""如果在魔术方面遇上了瓶颈，请去敲响拉诺亚魔法大学的大门。"

## 二、组织与势力
- 名称：罗亚的学校
- 内容：位于菲托亚领地都市罗亚的教育机构。主要招收附近的贵族子弟，教授读写、算术、历史、规矩礼仪等，内部充斥贵族阶级意识与霸凌排挤风气。
- 原文依据："「所谓学校，是指位于菲托亚领地的都市『罗亚』的教育机构，会教导读书写字、算数、历史、礼仪规矩之类的知识。」""「因为这附近的贵族家死小鬼们都会前往学校，而且全是一些自己不是第一就不甘心的家伙。看到像你这样的人，应该会成群结党地来霸凌你吧。」"

- 名称：拉诺亚魔法大学
- 内容：享负盛名的魔术高等学府。无推荐函者入学必须通过入学考试；其学费较为昂贵，寻常骑士家庭难以同时承担两人份学费。
- 原文依据："如果在魔术方面遇上了瓶颈，请去敲响拉诺亚魔法大学的大门。没有推荐函的话必须接受入学考试，但鲁迪乌斯你应该可以轻松过关。""魔法大学的学费并不便宜，我们家也不是有金山银山。"

- 名称：西隆王国（王室与宫廷魔术师）
- 内容：中央大陆南部的小型封建国家，拥有王室，会雇佣高阶冒险者担任王子的家庭教师，并聘任高位魔术师担任宫廷魔术师。
- 原文依据："最后就被聘为王子殿下的家庭教师。……虽然仅限于一段时间，但王宫似乎打算任命我为宫廷魔术师。我也想要继续研究魔术，所以这样正好。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑术阶级划分与身体机能
- 规则：
  1. 剑术分为中级、上级、圣级等阶段。初级到中级大致相当于常规骑士合格水准；“上级”据称是有才能者专心钻研单一流派约十年方能抵达的水准；圣级则是具备六段以上顶尖造诣的高段位实力。保罗在剑神流、水神流、北神流三个流派皆达到上级，但在各流派中都算半途而废。
  2. 高阶剑士实力超乎常理：全力奔跑时最高时速可达约五十公里，动态视力与反射神经极其敏锐。由于治愈魔术能够挽救重伤，因此剑士在实战交手中往往追求一击必杀。
- 原文依据："剑神流：上级。水神流：上级。北神流：上级。三种流派都是上级。而这个「上级」，据说是拥有才能的人专心钻研一个流派约十年后才能到达的水准。……一般的骑士如果能达到中级似乎就算是合格。至于圣级，必须拥有被称为高段位的六段以上的实力，不过这部分先姑且不论。""这个世界的剑士都强得超出常理。只要拿出实力，能以最高时速约五十公里的速度奔跑，动态视力跟反射神经也超乎寻常。因为治愈魔术能让生物不会随便死去，所以他们出手时都会试图一击必杀。"

- 名称：高级魔法阶级（圣级、王级、帝级、神级）
- 规则：在圣级之上，魔术师阶级还存在王级（如水王级）、帝级（如水帝级）、神级（如水神级）。洛琪希在西隆王国阅读王级魔术书籍后成功掌握水王级魔术，并确立以水神级魔术师为目标。
- 原文依据："对了，我总算也能够使用水王级魔术了。西隆王国的书库里，有水王级魔术的相关书籍。学会圣级时，我本来还以为自己已经无法再更进一步了。不过只要努力，还是能够办到。鲁迪乌斯是不是已经能使用水帝级魔术了呢？……我的目标是水神级魔术师。"

- 名称：上级火魔术「熔岩」
- 规则：能够凭空生成熔岩/岩浆的上级魔术。虽然本质特征包含土与火的复合，但在正规魔法体系中被正式归类为火系统上级魔术。增强威力除了直接注入更多魔力，还可通过可燃性气体提升燃烧效率。
- 原文依据："顺便说一下，还有一种叫作「熔岩」，能产生岩浆的上级魔术。虽然怎么看那都是土和火的合成魔术，却被归类于火系统的上级魔术。而且虽然简单分类为某系统，但实际上却和所有方面都互有关连。想要加强火力时只需注入更多魔力，不过只要利用可燃性的气体，就能以更有效率的方式输出高火力。"

- 名称：魔术分类体系（治愈魔术与召唤魔术）
- 规则：除常规的攻击/元素魔术外，魔法体系中还明确存在「治愈魔术」与「召唤魔术」等专门系统分支。
- 原文依据："我想你那么用功，也许已经开始涉猎治愈魔术和召唤魔术了吧。"

- 名称：迷宫的生态机制与法则
- 规则：
  1. 迷宫本质上是一种特殊的“魔物”，原本是单纯的洞穴，因魔力长时间沉滞变异而成。刚形成的幼期迷宫可能因崩塌或魔力结晶被魔物吃掉而毁灭。
  2. 迷宫最深处存在力量核心兼诱饵「魔力结晶」，并由强大的守护者（Boss）守护。魔力结晶散发极强诱惑力，吸引魔物深入，魔物因饥饿、陷阱或被守护者击杀后，迷宫会吸收其尸体魔力持续壮大。
  3. 迷宫历经数年吸收大量死者魔力后，会将魔力注入被吞噬的魔物和冒险者遗留的装备中，孕育出「魔力附加品」作为新的诱饵，吸引贪图财富的人类冒险者涉险送命，从而形成恶性膨胀循环。
- 原文依据："根据书上所写，迷宫这种东西似乎是一种魔物。原本只是单纯洞窟的地方因为魔力沉滞而发生变异，最后变化成迷宫。迷宫最深处有着可称为迷宫力量来源的魔力结晶，还有保护结晶的守护者(Boss)。魔力结晶也是诱饵，散发出强大的诱惑力。魔物会受到结晶引诱而深入迷宫，之后饿死、中了陷阱死亡，或是被保护魔力结晶的守护者杀死。迷宫则会吸收死去魔物的魔力。不过呢，刚形成的迷宫有可能会反过来被魔物吃掉魔力结晶，偶尔还会出现因为崩塌而毁掉的案例。""经过一段时间后，迷宫会花费数年，把魔力注入之前吃掉的魔物和冒险者的装备里。利用这种做法来制造出新的诱饵。那就是魔力附加品。"

## 四、种族 / 生物
- 名称：猛攻斗犬
- 特征：外形类似受过训练的杜宾犬的犬型魔物，动作迅捷敏锐，常与其它魔物结队行动。
- 原文依据："敌人是四只魔物。动作像是受过训练的杜宾犬的狗型魔物「猛攻斗犬」三只。"

- 名称：终结野猪
- 特征：双脚直立行走的野猪型魔物，长有四条强壮手臂，常常作为头领率领猛攻斗犬等低阶魔物群体从森林出没。
- 原文依据："还有以双脚行走，却有四条手臂的野猪型魔物「终结野猪」一只。它们以野猪率领着狗的队形从森林深处出现。"

- 名称：赤龙
- 特征：居住在中央大陆各大山脉（如赤龙山脉）的强悍龙族生物。因其盘踞，导致该区域空中与山脉无法直接通行；赤龙亦是万年迷宫「龙神孔」捕食猎杀的目标。
- 原文依据："然而，这个中央大陆的山脉上居住着赤龙因此无法通行，必须避开山脉从南边绕很远的路才能到达。""而是「龙神孔」为了捕食赤龙而开启的洞口。要是有龙经过洞口上方，似乎就会被吸入。"

- 名称：鬼族
- 特征：保罗讲述的迷宫冒险逸话中提及的智慧异种族（如“鬼族青年”），可与人族剑士组队探索迷宫。
- 原文依据："接下来，保罗大致说了个鬼族青年和人族的剑士们一起闯入已经成为海鱼族巢穴的迷宫……"

- 名称：海鱼族
- 特征：栖息筑巢于特定迷宫水域中的水生魔物/种族，曾占据迷宫成为其巢穴并击杀多名人族冒险者。
- 原文依据："闯入已经成为海鱼族巢穴的迷宫，虽然失去同伴却成功打倒海鱼族的故事……"

- 名称：人族
- 特征：人类种族。拥有力量的巅峰生命期相对短暂，必须在有限青年期快速拼搏成长。
- 原文依据："明明人族拥有力量的时期很短暂，但却没有人要往前冲。"

## 五、物品 / 道具 / 武器
- 名称：魔力结晶
- 说明：迷宫最深处的核心力量源泉，同时亦是高价值的魔术触媒。在市场上交易价值极其惊人，即使是微小块的结晶，也能换取足以供普通人吃喝玩乐一年以上的财富。
- 原文依据："迷宫最深处有着可称为迷宫力量来源的魔力结晶，还有保护结晶的守护者(Boss)。""这是因为魔力结晶是魔术的触媒，因此交易的价钱非常惊人。虽说实际价格会根据结晶大小而定，然而即使是小块结晶，也可以卖出能让人吃喝玩乐一年以上的金额。"

- 名称：魔力附加品
- 说明：迷宫自然浸染魔力孕育而生的魔法装备。与需要使用者消耗自身魔力驱动的“魔道具”不同，魔力附加品即使使用者不消耗魔力也能发挥特殊能力。大多数赋予的是实用性极低的能力，但偶尔也会诞生具备能让神级强者闻风丧胆的逆天效果，在冒险者黑市中能卖出难以想象的昂贵高价。
- 原文依据："那就是魔力附加品。魔力附加品和魔道具不同，似乎是一种使用者不需消耗魔力也能使用的魔法道具。只是，大部分的魔力附加品都不会具备什么有用的能力。据说大半是一些没用的垃圾能力。不过，偶尔好像也会附加上那种能让神级人物闻之色变的作弊能力。那类装备可以卖得高价，因此有许多梦想一夕致富的人们潜入迷宫。"

- 名称：魔道具
- 说明：魔法技术制造的特殊器具，使用者通常需要消耗自身的魔力才能驱动使用（与魔力附加品形成鲜明机制对照）。
- 原文依据："魔力附加品和魔道具不同，似乎是一种使用者不需消耗魔力也能使用的魔法道具。"

- 名称：各流派代代相传之剑
- 说明：剑神流、水神流、北神流等各大剑术流派宗家代代相传的神兵利器，相传源自初代三剑士在挑战传说地下一百层迷宫中所斩获的战利品。
- 原文依据："「没那回事，据说现在各流派代代相传的剑就是在那个迷宫里得到的东西。」"

- 名称：《三剑士与迷宫》
- 说明：世界知名的历史冒险传记书籍。详细记载了日后被称为剑神、水神、北神的三名青年天才剑士相遇、组队攻克地下一百层险恶迷宫并获得传承佩剑的全过程。
- 原文依据："「是《三剑士与迷宫》吗？如果能像那样前往传说中的迷宫探索，就能在历史上留名喔，你要不要努力看看？」──《三剑士与迷宫》。这是叙述后来被称为剑神、水神、北神的三名年轻天才剑士们相遇，几番波折后一起挑战巨大迷宫……书里他们挑战的迷宫只有地下一百层。"

## 六、历史 / 传说 / 事件
- 事件名：龙神孔万年存在史
- 内容：灵峰龙鸣山山麓的迷宫「龙神孔」拥有极其古老的历史，根据现存文献记载，至少在一万年前便已存在，是目前已知世界最古老且最深的迷宫巨构。
- 原文依据："在目前已经发现的迷宫中，存在时间最长范围最深的迷宫是位于中央大陆赤龙山脉的灵峰──「龙鸣山」山麓的「龙神孔」。根据文献，据说这里在一万年前就已经存在，而推测出的最底层是二五○○层。"

- 事件名：初代三剑士挑战百层迷宫

  2. 贵族学校社交文化与霸凌现象：阿斯拉领地贵族学校极度讲究家世背景、门第等级、传统礼仪与社交虚荣。平民或小贵族若展现出超越大贵族子嗣的才华，往往招致群起霸凌与排挤。贵族女性多靠浓妆、束腹等修饰外表。
  3. 迷宫淘金与冒险者文化：由于迷宫深处的魔力结晶与极品魔力附加品能带来暴利，大量向往一夕致富的年轻人前赴后继成为冒险者潜入迷宫，构成了冒险者行业高死亡率、高收益的核心驱动力。
  4. 王室宫廷魔术师与御前家教制度：王室贵族会根据冒险者在迷宫中打响的名望，特聘其担任王子的私人家庭教师；王宫内设有兼具研究与施法职务的“宫廷魔术师”高阶官职。
  5. 婚姻家庭观念 [存疑]：鲁迪乌斯在看到女仆莉莉雅被正式接纳与全家同桌用餐时，内心产生“这个国家是不是可以一夫多妻呢？”的疑问，但本章尚未明确该国法律对此的正式条文。

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯以为《三剑士与迷宫》只是虚构的奇幻冒险故事。
- 原文是否暗示另有真相：是。保罗明确指出那是真实历史事件，各大剑术流派宗家相传的宝剑正是从该迷宫中获取的。
- 原文依据："「那个不是虚构故事吗？」「没那回事，据说现在各流派代代相传的剑就是在那个迷宫里得到的东西。」"

- 角色以为：鲁迪乌斯原本以为洛琪希一直没有传授自己王级以上的更高深魔术是另有缘由或有所保留。
- 原文是否暗示另有真相：是。洛琪希来信坦白自己离开格雷拉特家时实际上并不会王级魔术，是直到最近在西隆王国阅读藏书后才终于习得水王级魔术。
- 原文依据："洛琪希完全没有教过我王级以上的魔术……这样啊，原来是因为她不会用。"

- 角色以为：鲁迪乌斯在家庭会议上恳请保罗帮忙介绍高薪工作赚取两人学费，见保罗一口答应并声称“既然是这样，我就找人问问吧”，以为父亲会顺应自己的请求去联络工作。
- 原文是否暗示另有真相：是。保罗视角揭示其内心认定希露菲对鲁迪如同无自主意志的断线木偶般过度依赖，鲁迪也在沉沦依赖，因此暗中谋划写信找人彻底将两人强行拆散五年，甚至做好了“乾脆来硬的”动武打算。
- 原文依据："「我明白了。既然是这样，我就找人问问吧。」" vs "「不过呢，还是让他再继续被父亲束缚一阵子吧。」……希露菲会成为没有鲁迪就什么事也不会做的大人。……希望在这五年内，你能待在全新的环境学习……我看，乾脆来硬的好了。"

- 角色以为：鲁迪乌斯见莉莉雅同桌用餐，困惑“这个国家是不是可以一夫多妻呢？”。
- 原文是否暗示另有真相：不明/存疑。阿斯拉王国的一般婚姻制度与法律在本章并未正面界定，保罗家目前处于事实上的两妻共同生活状态。
- 原文依据："在上次的怀孕骚动后，莉莉雅也和我们一起同桌用餐。……这个国家是不是可以一夫多妻呢？算了，怎样都好。"
