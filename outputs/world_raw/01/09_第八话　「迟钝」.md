# 第八话　「迟钝」 世界设定提取

## 一、地理与场所
- 名称：格雷拉特家二楼浴室
- 内容：该世界家庭无现代淋浴或浴缸泡澡文化，日常清洁是以装有热水的木桶配合大毛巾擦拭全身。
- 原文依据："走进自己房间后，我看到一个装有热水的大桶子。这个世界当然没有冲澡这回事，甚至连在浴池里泡澡的文化也没有，所以是用这种方式来擦洗身体。不过根据洛琪希的讲法，似乎有温泉。"

## 二、组织与势力
- 名称：人族神官战士阶层
- 内容：人族内部掌握神击系魔术的宗教/武装阶级，刻意将神击系魔术的原理与咒文进行技术垄断隐瞒，即便拉诺亚魔法大学等顶级学府亦未获传授。
- 原文依据："神击系似乎是能对幽灵系魔物以及邪恶的魔族产生有效伤害的魔术。然而这种魔术受到人族的神官战士刻意隐瞒，听说魔法大学并未传授，因此洛琪希也不清楚。"

## 三、力量体系 / 魔法 / 技能
- 名称：属性相性与后天心理经历规律（擅长与不擅长系统）
- 规则：每个人对特定魔术系统的擅长程度主要取决于后天生活环境与心理创伤体验，而非单纯种族先天决定。若幼年曾受火伤则易形成潜意识恐惧而不擅长火系；长期生活在山区挖矿打铁者擅长火土，而遭遇温泉烫伤或山洪易排斥水系。
- 原文依据："是洛琪希以前教过我的「擅长系统、不擅长系统」的问题吧。正如字面所示，每个人都有自己擅长的系统与不擅长的系统。"、"例如矿坑族，有很多人都不擅长水系统。因为他们矿坑族居住在山地附近，从小就和泥土玩在一起，而且成长时还会跟着父亲学习锻造、挖矿等等，所以比较擅长火跟土。可是在山上活动时，经常会被突然涌出的温泉烫伤或因为大雨造成的洪流而溺水，所以容易变得不擅长水系统。"

- 名称：治愈魔术四大分支体系
- 规则：治愈魔术分为七大层级，细分为四大独立系统：
  1. **治疗系**：肉体损伤复原。初级仅能治疗小割伤，帝级可实现断肢完全再生；但即便达到最高的神级，也绝对无法让已死生物复活。
  2. **解毒系**：中和毒素与疾病。层级提高可调配毒药与解毒药；异常状态干涉魔术达圣级以上，难度极高。
  3. **结界系**：构筑防御屏障与辅助抗性，洛琪希等常规魔术师无法施展。
  4. **神击系**：针对幽灵系魔物及恶性魔族的专门杀伤魔术，受人族神官隐瞒。
- 原文依据："治愈魔术果然也是分成七个层级，由治疗、结界、解毒、神击四个系统组成。"、"治疗是复原伤口的魔术。一开始顶多只能治疗小割伤，只要提升到帝级，据说连断掉的手臂都能够再生。只是，就算达到神级，也无法让死去的生物复活。解毒也是如字面所示，是治疗中毒或疾病的魔术。只要层级提升，似乎还能制作出毒药和解毒药等等。至于异常状态的魔术则是圣级以上，据说很难。结界则是提高防御力，制造出屏障的魔术。"

- 名称：治愈术师位阶称谓规范
- 规则：治愈魔术不同于攻击魔术（火圣、水圣等），其称号直接以职能系统命名，称为“圣级治疗术师”、“圣级解毒术师”等。
- 原文依据："话虽如此，治愈魔术和攻击魔术不一样，并没有火圣、水圣之类的帅气名称。而是使用圣级治疗术师、圣级解毒术师之类的称呼。"

- 名称：无咏唱施法的认知原理门槛
- 规则：无咏唱施法必须在大脑中清晰构建该现象的能量转化原理。若施法者不理解物质或肉体变化的客观机制（如人体细胞再生愈合过程、念动力原理），即使魔力庞大亦无法施展无咏唱治愈术。
- 原文依据："只要不清楚原理，就无法以无咏唱方式来使用魔术，这点实在很不方便。"、"我对于伤口痊愈的过程也只剩下模糊的印象。我想正是因为这样，所以我无法以无咏唱使用治疗术。"

- 名称：无咏唱教学与掌握法则
- 规则：无咏唱核心在于跳过咒文，在脑海中重现“体内魔力向指尖聚集”的肉体直觉，并通过想象直接对魔力施加塑形（大小、速度、形态）。即使先前习惯咏唱的幼儿，在指导下亦能迅速掌握无咏唱初级魔术。
- 原文依据："「那么，平常在咏唱时，会觉得魔力从身体里往指尖集中吧？你试试不咏唱然后重现那个感觉。等到你觉得魔力已经聚集之后，再想像出要使用的魔术，然后试着从指尖挤出魔力……」"、"希露弗高兴地大叫，连续射出水弹。虽说他一直都有咏唱，但毕竟只持续了一年。或许能靠类似把脚踏车辅助轮拆掉的感觉来办到。"

- 名称：中级水魔术「冰柱」
- 规则：从地面瞬间催生出粗壮结实的尖锐冰棱柱体，在阳光下坚硬反光。
- 原文依据："仔细一看，原来他成功使出了中级的水魔术「冰柱」。地面长出一根相当粗的冰柱，在阳光下闪闪发亮。"

## 四、种族 / 生物
- 名称：矿坑族
- 特征：多聚居于山区地带，擅长采矿与冶炼锻造，幼年起接触土石，魔法上普遍擅长火系与土系魔术，多因环境因素排斥水系。
- 原文依据："例如矿坑族，有很多人都不擅长水系统。因为他们矿坑族居住在山地附近，从小就和泥土玩在一起，而且成长时还会跟着父亲学习锻造、挖矿等等，所以比较擅长火跟土。"

- 名称：幽灵系魔物
- 特征：真实存在于异世界的不定形或灵体类魔物，常规物理与普通魔术效果有限，受到神击系魔术直接克制杀伤。
- 原文依据："神击系似乎是能对幽灵系魔物以及邪恶的魔族产生有效伤害的魔术……我并没有亲眼看过幽灵，但这个世界似乎真的会出现。"

## 五、物品 / 道具 / 武器
- 名称：儿童灯笼短裤（内裤）
- 说明：异世界孩童日常穿着的棉麻制贴身下着衣物。
- 原文依据："接着我把手伸向儿童用的灯笼短裤……我把手伸向他的内裤，一口气往下拉。"

## 六、历史 / 传说 / 事件
- 事件名：希露菲三岁暖炉烫伤事件
- 内容：希露菲三岁时趁父母不备抓取暖炉赤热铁棍，手掌留下严重烧伤疤痕，由此对火产生潜意识恐惧，致使其在魔术学习中长期难以掌握火系。
- 原文依据："我曾经问过希露弗是不是怕火。他虽然摇头否定，不过却给我看了他的手掌。上面有一道丑陋的烧伤。听说他差不多三岁时，曾经趁着双亲不注意，伸手去抓暖炉里的铁棍。"

## 七、社会规则 / 习俗 / 文化
- 内容：**异世界沐浴文化缺失**。平民与下级贵族家庭缺乏冲澡或大型泡澡设施，以烧热水毛巾擦洗为主；天然温泉存在但分布于特定地质区域。
- 原文依据："这个世界当然没有冲澡这回事，甚至连在浴池里泡澡的文化也没有，所以是用这种方式来擦洗身体。不过根据洛琪希的讲法，似乎有温泉。"

- 内容：**识字率与知识壁垒**。社会普遍识字率极低，异世界不存在能直接让人识字的辅助魔法；掌握读写能力具有巨大阶级优势；人族神官等特殊阶层对高端魔法知识（如神击系）实行严密的信息封锁。
- 原文依据："虽然我不清楚这个世界的识字率是多少，但肯定不会像现代日本那样接近百分之一百吧。这个世界并没有能让人识字的魔术。识字率越低，拥有阅读能力就会越有利。"

- 内容：**发色霸凌下的衣着妥协**。因绿色头发在社会上遭受极端歧视，贫困家庭女性幼童被迫将长发剪成超短发以减少色彩暴露，并因常年逃跑躲避霸凌而唯一选择活动方便的男式短裤，由此导致性别外貌特征极度模糊。
- 原文依据："希露菲是因为头发颜色而遭到欺负，所以才会把头发剪短，好让发色不要那么显眼。而被人欺负时必须跑着逃走，所以比起裙子，当然会选择裤子。再加上希露菲家并不富裕。因此做了一条裤子后，就没有多余的钱可以做裙子了。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯在认识希露菲整整一年时间里，因其超短绿发、男童衣裤装束及瘦弱体格，一直确信对方是“美少年男孩子”。
- 原文是否暗示另有真相：是。
- 原文依据：鲁迪在淋雨后强行脱其湿衣服内裤时，亲眼确认希露菲完全不具备男性生理器官，实为真正的女孩子；保罗亦斥责鲁迪“眼睛有毛病”，指出其外貌一直都很可爱。

- 角色以为：世俗与魔术学界普遍认定无咏唱属于神技或失传技巧，魔法大学教师仅一人能做到，幼儿难以掌握。
- 原文是否暗示另有真相：是。
- 原文依据：在鲁迪去除心理神秘感、引导感知指尖魔力聚集的教学下，六岁的希露菲第一次尝试便成功实现无咏唱连续发射水弹，证明无咏唱并非特定天赋专利，而是教学认知与想象机制问题。

- 角色以为：鲁迪以为索马尔之母频频登门指责是小孩闹假车祸勒索。
- 原文是否暗示另有真相：是。
- 原文依据：索马尔之母实际上是对帅气的前冒险者保罗有意，屡次借口小孩子抓扯擦伤登门制造接触机会。
