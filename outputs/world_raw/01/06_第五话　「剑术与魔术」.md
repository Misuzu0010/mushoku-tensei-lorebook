# 第五话　「剑术与魔术」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚王国
- 内容：拥有拉诺亚王国魔术学校与拉诺亚魔法大学的国家。
- 原文依据："据说像贵族子弟就读的拉诺亚王国魔术学校"

- 名称：拉诺亚魔法大学
- 内容：各大国魔术学校中规模最大的最高学府，位于拉诺亚。拥有充足的优良设备与师资，提供现代且高水准的课程。学风开明，不拘泥形式与尊严，接纳各族学生，各种族独有魔术研究进展迅速。洛琪希的母校。
- 原文依据："「其中规模最大的果然还是拉诺亚魔法大学吧。」"、"「有充足的优良设备和教师，比起其他学校，应该能接受更现代且更高水准的课程吧。」"、"「拉诺亚魔法大学并不会拘泥于奇怪的形式和尊严。就算再怎么异想天开，只要是正确的理论就不会被直接舍弃。由于那里接纳了各式各样的种族，所以各种族独有魔术的研究也很有进展。」"

- 名称：拉诺亚王国魔术学校
- 内容：拉诺亚王国专供贵族子弟就读的传统魔术学校，社会地位很高，排斥魔族（非人类种族审查时直接被淘汰）。
- 原文依据："据说像贵族子弟就读的拉诺亚王国魔术学校，光是种族并非人类就会在审查时被淘汰。"

## 二、组织与势力
- 名称：各大国魔术学校
- 内容：每个大国均设有魔术学校，地位尊贵，是正规培养上级魔术师的机构。
- 原文依据："「嗯，每个大国都有魔术学校。」"、"「在魔术学校里确实用功直到毕业的人……换句话说如果是上级魔术师，大约是一百个魔术师里才会出现一个吧。」"

- 名称：拉诺亚魔法大学
- 内容：顶尖学术与魔术研究机构，规模居各国之冠，开放包容多民族，重实效理论而非门第。
- 原文依据："「其中规模最大的果然还是拉诺亚魔法大学吧。」"、"「由于那里接纳了各式各样的种族，所以各种族独有魔术的研究也很有进展。」"

- 名称：宫廷骑士
- 内容：侍奉王廷以防守为主的骑士群体，多学习防御型的水神流剑术。
- 原文依据："是宫廷骑士和贵族那种以防守为主的人物们会学习的剑术。"

- 名称：剑术三大流派门派
- 内容：剑神流、水神流、北神流在世界各地均设有道场门派，求道剑士会周游各地门派研习。
- 原文依据："这些被称为三大流派，世界各地都有使用者。想以剑士身分达到极致的人似乎会前往各门派拜访，持续挥剑直到死亡为止。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑术三大流派
- 规则：
  1. 剑神流：高攻击性，主张「攻击正是最佳防御」，重视速度，以制敌机先、一击必杀为宗旨。若未得手则以打带跑战术持续消耗。
  2. 水神流：以顺势卸招与反击为核心的防御型剑术。专职防守，主动招式极少；顶尖境界可反击包含魔术与远距离武器在内的一切攻击。
  3. 北神流：更接近实战兵法，无特定招式特征，主打临机应变、出奇制胜；即使身体负伤或残缺亦能作战，深受佣兵与冒险者欢迎。
- 原文依据："──第一种是剑神流。这是一种具备高攻击性，彷佛在主张「攻击正是最佳防御」的剑术，重视速度，以总之要抢先击中目标为目的的流派。制敌机先并一击必杀。如果没能打倒对方，就持续使用打带跑战术，直到获胜为止。"、"──第二种是水神流。这流派和剑神流完全相反。是以顺势卸招与反击为中心的防御型剑术。……只是如果到达高手的境界，似乎能对所有攻击做出反击。所有攻击──甚至包括魔术和远距离攻击武器。"、"──第三种是北神流。这个流派与其说是剑术，反而更像是兵法。似乎没有具备特徵的招式，而是以能根据状况临机应变做为卖点。……由于这是身上有在治疗的伤势或是有缺损的部位也能继续战斗的流派，因此受到佣兵与冒险者的欢迎。"

- 名称：位阶体系与称谓规范
- 规则：剑术与魔术均划分为七个等级阶层：初级、中级、上级、圣级、王级、帝级、神级。流派带“神”字源自始祖通称。剑士通常直接称呼（如「水神」、「水圣」）；魔术师称呼则加「级」字（如「水神级」、「水圣级魔术师」）。洛琪希为水圣级魔术师。
- 原文依据："顺便说一下这些剑术也分成了以下的层级：初级、中级、上级、圣级、王级、帝级、神级。此外各流派的名称中有「神」这个字，是源自于流派始祖的通称。"、"一般来说称呼剑士时会称为「水神」、「水圣」，不过称呼魔术师时就会再加上「级」字，称为「水神级」、「水圣级」之类。例如洛琪希就是「水圣级魔术师」。"

- 名称：剑术魔力强化原理
- 规则：剑术高手能高速移动、发出剑气或斩断岩石（保罗能一剑劈开岩石），其原理推断为剑士无意识中调用体内魔力强化了自身肉体以及刀剑金属。
- 原文依据："如果能成为高手，甚至能一剑斩断岩石，或是发出剑气攻击远方的对手。实际上，保罗就能够一剑把岩石劈成两半。"、"虽然这只是我的推测，但这世界的剑术大概有受到魔力的影响。正如眼睛所见，魔术会以类似魔法的形式显现；但剑术不同，专门针对的方面是肉体和强化刀剑等金属。……当然保罗并没有察觉到自己使用了魔力。所以他无法解释。"

- 名称：混合魔术造雾与消雾
- 规则：按顺序发动「水瀑」、「地热」、「冰结领域」可制造大雾；再次使用「地热」魔术加热地面可使雾气消散。
- 原文依据："「按顺序发动水瀑、地热、冰结领域后会造成什么状况？」「会产生雾。」「没错。那么，如果想让雾气消散该怎么办？」「呃……再度使用地热魔术来加热地面。」「正是如此，实际试试看吧。」按照顺序使用好几个系统造成某种现象。这被称为「混合魔术」。"

- 名称：魔术师比例与上级稀缺度
- 规则：每20人中约有1人有战斗能力；20个有战斗能力的人中约有1个魔术师（即约400人中有1名魔术师）。魔术师中能毕业达到上级水平的仅约百分之一（即四万人中才有1名上级魔术师），在社会上极为吃香受追捧。
- 原文依据："二十个人中大概会有一个人有战斗能力。而二十个有战斗能力的人中大概只有一个是魔术师。据说是这样的比例。……「在魔术学校里确实用功直到毕业的人……换句话说如果是上级魔术师，大约是一百个魔术师里才会出现一个吧。」不过上级魔术师却是四万分之一。"

- 名称：各种族独有魔术
- 规则：不同种族拥有自身独有的魔术体系与研究。
- 原文依据："由于那里接纳了各式各样的种族，所以各种族独有魔术的研究也很有进展。"

## 四、种族 / 生物
- 名称：斯佩路德族（武器特征补充）
- 特征：该族惯用三叉枪，在民间和故事书中被彻底妖魔化，被视作不分敌我一律屠戮的恶魔杀人鬼；导致世俗将长枪视作不祥的恶魔兵刃。
- 原文依据："没有人用长枪，这是因为那个惹人厌的斯佩路德族正是使用三叉枪。所以长枪是恶魔的武器，这是常识。书上也出现过好几个这样的恶魔，担任的角色是那种不分敌我一律统统咬死的杀人鬼。"

- 名称：魔族（在拉诺亚王国的处境）
- 特征：在部分传统贵族学府（如拉诺亚王国魔术学校）仍受严重歧视，审查时非人类种族会被直接淘汰；但拉诺亚魔法大学则平等接纳。
- 原文依据："据说像贵族子弟就读的拉诺亚王国魔术学校，光是种族并非人类就会在审查时被淘汰。虽然对魔族的歧视行为逐渐变少，但似乎还是会遭到不公平的对待。"

## 五、物品 / 道具 / 武器
- 名称：初级魔杖
- 说明：长约三十公分，顶端镶有一颗小小的红色石头，外观朴素。由洛琪希亲手制作，作为弟子掌握初级魔术时的师承礼物。
- 原文依据："从洛琪希那里得到了一根魔杖。在长约三十公分的棒子前端镶着一颗小小的红色石头，看起来很朴素。「这是我前几天制作的东西。……身为师傅该制作魔杖给能使用初级魔术的弟子。」"

- 名称：剑与木剑
- 说明：保罗在鲁迪五岁时赠送的两把剑，包括一把经过锻造且已开锋的成人真剑，以及一把短木剑。象征直面战斗的觉悟。
- 原文依据："保罗送的贺礼是剑。共有两把。一把是对五岁小孩太长太重的真剑，另一把是比较短的木剑。真剑是锻造而成，也已经开锋了。"

- 名称：长枪 / 三叉枪
- 说明：因与斯佩路德族紧密关联而在世俗观念中被定为“恶魔的武器”，正规英雄故事中几乎无人选用。
- 原文依据："没有人用长枪，这是因为那个惹人厌的斯佩路德族正是使用三叉枪。所以长枪是恶魔的武器，这是常识。"

- 名称：书籍（植物辞典）
- 说明：本世界已有造纸技术但尚未发明印刷术，全部靠手工抄写，价格高昂。塞妮丝赠予的植物辞典篇幅厚重，附有详尽插画与说明。
- 原文依据："这世界的书籍很贵。即使有制纸技术，但似乎没有印刷技术，所以全都靠手写。这本植物辞典很厚，还利用插画提供仔细易懂的说明。"

## 六、历史 / 传说 / 事件
- 事件名：三大剑术流派与初代水神传说
- 内容：三大剑术流派名称中的“神”字源自始祖通称。传说水神流第一代始祖剑士同时也是掌握水神级魔术的强大魔术师，剑魔双通。
- 原文依据："此外各流派的名称中有「神」这个字，是源自于流派始祖的通称。据说水神流的第一代剑士同时也是能使用水神级魔术的魔术师。剑术是神级，魔术也是神级，当然强得跟怪物一样。"

## 七、社会规则 / 习俗 / 文化
- 内容：年龄赠礼规矩与成人界定
  - 规则：当地无每年庆祝生日的习惯，而是习惯在五岁、十岁、十五岁由家人赠予特定礼物；满十五岁即被视为正式成年。
  - 原文依据："这个国家似乎没有每年庆祝生日的习俗。不过另外有种惯例，是到达一定年龄后家人就会送些礼物。所谓一定的年龄是指五岁、十岁、十五岁。因为十五岁就算是成人，这个年龄设定非常好懂。"

- 内容：师门赠杖习俗
  - 规则：魔术师师徒间的行规，师傅应当亲手制作魔杖赠送给能使用初级魔术的弟子。
  - 原文依据："「但身为师傅该制作魔杖给能使用初级魔术的弟子。真是抱歉。」好像有这种惯例。"

- 内容：武器文化偏好与禁忌
  - 规则：剑术备受世人推崇，英雄多为用剑者，少数用斧锤；长枪被贴上“恶魔武器”的负面标签而受排斥回避。
  - 原文依据："在这个世界中，剑术相当受到重视。书里登场的英雄们基本上也都是用剑，偶尔会有用斧头或槌子的人，不过也只是少数派。没有人用长枪，这是因为那个惹人厌的斯佩路德族正是使用三叉枪。所以长枪是恶魔的武器，这是常识。"

- 内容：流派兼修与魔法剑士路径
  - 规则：剑士为求实战变强通常兼习多门流派（如保罗主攻剑神流同时涉足水神流与北神流）；亦可先考取骑士头衔再去魔法大学留学，成为兼具两者的“魔法剑士”。
  - 原文依据："如果想尽快变强，针对多个流派的好处稍事学习似乎是最基本的做法。实际上保罗也是以剑神流为主，但同时也略微涉足水神流和北神流。"、"有些人会先取得骑士的头衔，再前往魔法大学留学。请不要认为只能在剑和魔术之间选择其一，因为也有魔法剑士这条路可走。"

- 内容：传统学府的种族准入门槛
  - 规则：拉诺亚王国传统贵族魔术学校在审查时严厉排斥非人类种族，魔族往往只能报考接纳多元种族的魔法大学。
  - 原文依据："据说像贵族子弟就读的拉诺亚王国魔术学校，光是种族并非人类就会在审查时被淘汰。虽然对魔族的歧视行为逐渐变少，但似乎还是会遭到不公平的对待。"

## 九、角色认知 vs 客观事实
- 角色以为：保罗认为剑术劈开巨石全凭肉身用力方式（“哼地往前踏然后唰地砍下去！”），完全没有意识到自己使用了魔力。
- 原文是否暗示另有真相：是
- 原文依据："虽然这只是我的推测，但这世界的剑术大概有受到魔力的影响。正如眼睛所见，魔术会以类似魔法的形式显现；但剑术不同，专门针对的方面是肉体和强化刀剑等金属。……当然保罗并没有察觉到自己使用了魔力。所以他无法解释。"（鲁迪乌斯推断剑术本质上是无意识的肉体与金属魔力强化）

- 角色以为：保罗主观鄙视北神流，认为“只是用剑战斗，根本不算剑术”，是在耍小聪明。
- 原文是否暗示另有真相：否/有偏见
- 原文依据："「说这什么蠢话，那只是用剑战斗，根本不算剑术。」……在三大流派中，北神流似乎受到歧视。或者只是因为保罗个人不喜欢？虽然不喜欢，但他的北神流也有上级。"（保罗个人持偏见，但客观上北神流位列世界公认的三大流派之一，在佣兵与冒险者中深受欢迎，保罗自身亦修炼至上级）

- 角色以为：世人普遍将长枪视为“恶魔的武器”。
- 原文是否暗示另有真相：是
- 原文依据："没有人用长枪，这是因为那个惹人厌的斯佩路德族正是使用三叉枪。所以长枪是恶魔的武器，这是常识。"（世俗成见，因四百年前斯佩路德族使用三叉枪大闹而将枪类兵刃妖魔化）
