# 第七话　「朋友」 世界设定提取

## 一、地理与场所
- 名称：布耶纳村周边森林
- 内容：位于布耶纳村外围。森林中容易发生魔力沉滞，魔物出现概率较高；村内每月举行一次魔物扫荡狩猎，但森林深处仍可能潜伏凶恶魔物。
- 原文依据："我记得好像是因为森林里容易发生魔力沉滞所以比较危险……容易发生魔力沉滞的地方，魔物出现的机率也比较高。因为魔物产生的原因正是魔力造成的突然变异。"、"每个月举行一次，好像会由骑士、猎人、还有民间的治安维持会等众男性成员们全面出击，进入森林扫荡。"

- 名称：大树山丘
- 内容：布耶纳村内地势最高的小山丘，顶端生长着一棵这一带最大且孤零零的大树，站在山丘上可俯瞰全村确认地势走向。
- 原文依据："我一边思考着这些事情，同时爬上一座小山丘。山丘上有一棵孤零零的大树。那是这一带最大的树。如果想确认自己走过的村内地势，最好前往高处。"

- 名称：森林监视塔楼
- 内容：设立在森林边缘的防卫哨塔，用于监视是否有魔物从森林窜出，二十四小时皆有村内男性成年人轮流值班驻守。
- 原文依据："他待在森林旁边的塔楼上，单手持弓，监视着森林。"、"据他所说，这座塔楼是用来监看是否有魔物跑出森林，二十四小时都有村里的男人负责轮流在此看守。当然保罗也有值班……"

## 二、组织与势力
- 名称：村庄治安维持会
- 内容：布耶纳村由民间男性村民组成的治安防卫组织，与驻村骑士、专业猎人协作，负责每月定期森林扫荡及塔楼轮值警戒。
- 原文依据："每个月举行一次，好像会由骑士、猎人、还有民间的治安维持会等众男性成员们全面出击，进入森林扫荡。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔物生成规律（魔力沉滞异变）
- 规则：魔物是由自然界中魔力发生突发性变异而诞生，因此在魔力流动停滞（沉滞）的环境（如密林、深处）最易滋生。
- 原文依据："容易发生魔力沉滞的地方，魔物出现的机率也比较高。因为魔物产生的原因正是魔力造成的突然变异。"

- 名称：复合温度魔术应用（温水与暖风）
- 规则：通过火魔术与水魔术结合，将水调整至约四十度的人体舒适温水；以及通过火魔术加热气流送出如吹风机般的干燥暖风。
- 原文依据："我利用火魔术把水调整成适当温度。制造出不会太冷也不不会热，大约四十度的热水。然后把热水浇在少年头上。"、"由于泥巴已经被冲掉了，于是我利用火魔术把风加热到适当温度，一边像是吹风机般送出暖风，同时用手帕仔细擦拭少年的脸。"

- 名称：战斗步法与魔术结合
- 规则：剑术步法（保罗传授）可用于短距离高速回避投掷物，同时配合无咏唱土魔术制造泥弹进行反击压制。
- 原文依据："被三倍奉还了。我利用保罗传授的步法和魔术，漂亮地回避攻击。"

## 四、种族 / 生物
- 名称：长耳族（精灵族）特征与习性
- 特征：通常寿命极长，耳朵修长尖锐，容貌普遍为俊男美女；擅长弓箭与魔法（尤其水属性与风属性）。洛琪希证实其社会并不如外界传言般自我封闭。
- 原文依据："讲到故事里会出现的精灵，通常很长寿，过着封闭的生活，个性傲慢，瞧不起其他种族。擅长弓箭与魔法，尤其是水和风魔法。还有正如「长耳族」这名字，他们的耳朵很长。根据洛琪希的说法，据说这些设定「大致上符合，不过他们并没有特别封闭」。"

- 名称：混血儿遗传与返祖现象（长耳族×兽人族×人类）
- 特征：多族混血后代在外貌上可能产生隔代遗传或返祖现象。如罗尔兹（半长耳族半人类）与妻子（人类混四分之一兽人）所生的希露菲叶特，其尖耳朵比半精灵父亲更长，且长出罕见的翠绿色头发。
- 原文依据："「……他说他只有一半是长耳族，另一半是人类。」「母亲呢？」「人类，可是混了一点兽人族的血统……」"、"「我们家的孩子虽然有这种外貌，但这只是一点返祖现象而已。希望你和他好好相处。」"

- 名称：斯佩路德族鉴别法则（红宝石额头）
- 特征：真正的斯佩路德族特征为“翠绿色头发 + 额头中央嵌有红宝石般的肉质器官”，若仅仅拥有绿色头发而额头无红宝石，并非斯佩路德族。
- 原文依据："「绝对不要接近拥有翠绿色头发，额头上还有红宝石般物体的种族。」对了，这样才对。是额头上还有红宝石般物体的的种族。但眼前少年的额头是漂亮白皙的宽额头。OK，安全。他不是危险的斯佩路德族。"

## 五、物品 / 道具 / 武器
- 名称：猎弓
- 说明：罗尔兹在监视塔楼上值守使用的单手持制式远程武器。
- 原文依据："他待在森林旁边的塔楼上，单手持弓，监视着森林。"

## 六、历史 / 传说 / 事件
- 事件名：保罗离家出走与父亲决裂事件
- 内容：保罗少年时期因受不了顽固严格的父亲不分青红皂白斥责，在大吵一架后离家出走；其父在病危弥留之际仍对当日争吵深感后悔。保罗以此为戒，警惕自己在教育鲁迪时重蹈覆辙。
- 原文依据："其实我本身就是因为在百般限制的家里受到严格父亲不容分说地斥责，才厌恶地和他大吵一架后离家出走。我继承了父亲的血，继承了那顽固又不知变通的父亲的血。"、"我听说父亲似乎在我离家旅行后没多久就病倒过世。而且根据传言，他在弥留之际似乎还在后悔那天和我吵架的事情。"

- 事件名：保罗与塞妮丝成家年龄
- 内容：保罗现年二十四岁，十九岁时即已成家生下长子鲁迪乌斯（鲁迪现年五岁）。
- 原文依据："「嗯？我是二十四岁，怎么？」……意思是他十九岁就结婚生下我吗？"

## 七、社会规则 / 习俗 / 文化
- 内容：**发色偏见与儿童欺凌**。村民儿童对翠绿色头发抱有极度恐惧与歧视偏见，将其直接代入“恶名昭彰的魔族（斯佩路德族）”，仗着人多势众对异色发幼童进行恶性群体霸凌（丢泥巴、辱骂）。
- 原文依据："田里有三个浑身是泥的小孩，正朝着走在旁边路上的一名少年丢泥巴。"、"「打中头得十分！」「是魔族的宝物吗！」「一定是从哪里偷来的！」"、"小孩子很残酷。会因为哪个人稍微有点不同就排斥对方。「你也真辛苦，只是因为头发颜色和斯佩路德族很像就被欺负。」"

- 内容：**边境骑士的家规教诲**。保罗明确立下训诫：“不可以因为自己力量比较强而且会使用魔法就摆架子。因为男人的力量并不该用来耀武扬威”，应当用来保护弱者。
- 原文依据："「还有，不可以因为自己力量比较强而且会使用魔法就摆架子。因为男人的力量并不该用来耀武扬威。」"

- 内容：**语言礼仪与敬语规范**。面对尊长必须使用特定敬语表达尊重，而同龄无拘束玩伴之间则使用平语；此规则在偏远村民儿童中并非人人皆知。
- 原文依据："「嗯？噢，因为要是没有看对象改变用词会很失礼呀。对于尊长要使用敬语。」「敬语？」「就是我刚刚用过的说话方式。」"

## 九、角色认知 vs 客观事实
- 角色以为：霸凌孩童索马尔向母亲谎称遭到鲁迪殴打打伤；艾特太太全盘听信并怒气冲冲上门向保罗问罪；保罗以为鲁迪恃强凌弱、打伤平民幼童，逼迫鲁迪认错道歉。
- 原文是否暗示另有真相：是。
- 原文依据：鲁迪并未实施肉体殴打，仅仅在回避泥球时以魔术制造泥巴还击；索马尔眼角淤青属于小孩子自身跌撞或虚报伪造；保罗在鲁迪据理力争并以“离开家族”表态后认识到自身主观武断并诚恳道歉。

- 角色以为：鲁迪乌斯初见希露菲叶特时，因其短发、白瓷般皮肤及俊秀五官，误以为对方是“少年”、“正太”、“男孩子”。
- 原文是否暗示另有真相：是（原文多处伏笔暗示，如长发修剪、内向害羞及后续性别揭晓）。
- 原文依据："至于那名受攻击的少年……眼前出现一个让人不觉得彼此同年龄的美少年。"、"如果是那种正太控的大姐姐，应该看一眼就会湿了吧。"

- 角色以为：村民儿童以为只要是绿头发就是魔族的同类或小偷。
- 原文是否暗示另有真相：是。
- 原文依据：希露菲叶特额头并无斯佩路德族标志性的红宝石器官，其绿发为多族混血导致的返祖现象，完全不是魔族。
