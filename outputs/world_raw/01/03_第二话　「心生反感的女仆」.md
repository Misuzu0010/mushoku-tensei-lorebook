# 第二话　「心生反感的女仆」 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国 / 王都
- 内容：拥有王宫、后宫的大国，王族内部存在王位继承人争夺，设有禁卫侍女与大臣等官职体系。
- 原文依据："莉莉雅原本是阿斯拉王国后宫的禁卫侍女。"、"莉莉雅离开了王都。"、"虽然对不起公主，然而莉莉雅希望王族的继承人之争可以在和自己无关的地方随他们怎么闹都行。"

- 名称：菲托亚领地
- 内容：阿斯拉王国边境广大的农业领地，除了领主居住的要塞都市「罗亚」外，放眼望去全是悠闲的麦田；当地许多人擅长剑术，但受过正规训练的家事侍女稀少。
- 原文依据："莉莉雅转搭了好几班公共马车，最后来到有着广大农业地区的边境，菲托亚领地。除了领主居住的要塞都市「罗亚」，这里是放眼望去全是麦田的悠闲地区。"、"在这个边境有许多能使用剑术或传授剑术的人，但是受过完美家事训练的侍女却很少。"

- 名称：要塞都市「罗亚」
- 内容：菲托亚领主居住的要塞都市。
- 原文依据："除了领主居住的要塞都市「罗亚」，这里是放眼望去全是麦田的悠闲地区。"

- 名称：布耶纳村
- 内容：位于菲托亚区域边缘的小村庄，极度偏远的农村（“乡下中的乡下”），保罗·格雷拉特在此担任下级骑士并定居。
- 原文依据："在菲托亚区域的布耶纳村，有个下级骑士正在招揽侍女。"、"布耶纳村位于菲托亚区域的边缘，是一个小村庄。也是乡下中的乡下，换句话说超级乡下。"

- 名称：中央大陆
- 内容：故事发生的地理大陆，存在广泛通用的语言。
- 原文依据："至少那些并不是中央大陆普遍使用的语言。"

## 二、组织与势力
- 名称：阿斯拉王国王宫 / 后宫
- 内容：王族统治中心及妃嫔居住地，安保复杂且派系斗争严酷；侍女失去能力后会被立刻解雇且无补偿，甚至可能因知晓后宫构造被秘密处决或被王宫作为引出暗杀黑手的诱饵。
- 原文依据："莉莉雅原本是阿斯拉王国后宫的禁卫侍女。"、"既然失去能力，被解雇也是当然。虽说连当前的生活资金都没能拿到，不过光是没有因为在后宫工作就被秘密处决，就必须抱着已经赚到的想法。"、"或许王宫正是故意放她自由行动，打算借此引出幕后黑手。"

- 名称：菲托亚领主与上级贵族
- 内容：统辖菲托亚领地的贵族势力，与王都保持着紧密的政治联系，会利用前王宫人员作为政治筹码。
- 原文依据："然而被菲托亚领主或是同等的上级贵族雇用会有危险。因为那种人当然和王都方面也有联系。要是雇主知道莉莉雅原本是后宫的侍女，很有可能会被当成政治上的筹码。"

- 名称：剑术道场
- 内容：传授剑术的机构，保罗曾因与父亲吵架离家出走住进莉莉雅学剑的道场研习。
- 原文依据："某天突然闯进莉莉雅学习剑术的道场。似乎是因为和父亲吵架所以被断绝关系，于是住进道场里开始学习剑术。"

## 三、力量体系 / 魔法 / 技能
- 名称：禁卫侍女与剑术流派
- 规则：禁卫侍女兼具侍女和禁卫兵双重性质，平素打理家务，危急时持剑护主；剑术存在不同流派与才能差异；腿部伤残（无法全力奔跑或前踏）会导致剑士生涯终结。
- 原文依据："所谓的禁卫侍女，是指同时具备禁卫兵性质的侍女。平常负责侍女的工作，紧急时则要拿起剑保护主人。"、"即使流派不同，但在家里学过剑术的他很快就追过了莉莉雅。"、"即使日常生活不受影响，但再也无法以全力奔跑或是迅速往前踏。那一天，莉莉雅身为剑士的生命就此告终。"

- 名称：治疗魔术
- 规则：能够迅速治愈肉体伤口，但在面对烈性暗杀毒药时无法阻止毒素造成的身体机能损害与后遗症。
- 原文依据："虽然伤口马上被治疗魔术治好，医生也试着解毒而让她总算保住一命，却留下了后遗症。"

- 名称：暗杀毒药与解毒魔术
- 规则：存在专门用于暗杀王族的烈性毒药，且该毒药不存在对应的解毒魔术可用于治疗，只能依赖医生抢救。
- 原文依据："短剑上涂着毒，是那种用来暗杀王族的毒。也就是没有解毒魔术可用来治疗的棘手毒药。"

- 名称：除魔仪式 [存疑，民间迷信]
- 规则：莉莉雅故乡流传的民间习俗，在道具店购买相应物品并在深夜实施，意图祛除恶魔附身或诅咒，但实际对转生者毫无效果。
- 原文依据："她急忙前往道具店，用掉仅有的一点钱买下必要的东西。之后在格雷拉特家的人都熟睡后，她进行了故乡流传的除魔仪式。"、"昨晚是白费力气。"

## 四、种族 / 生物
- 名称：恶魔 [存疑，民间传说/后宫怪谈]
- 特征：传说中能附身在人类（如王子）身上的邪恶实体，被附身者会在夜间趴在地上爬行，并趁人不备以小刀刺穿侍女心脏。
- 原文依据："「过去曾经发生过阿斯拉的王子每天晚上都趴在地上，在后宫到处爬来爬去的事件。王子是被恶魔附身了。如果在不知情的状况下随便把王子抱起，王子就会用藏在身后的小刀，朝向侍女的心脏一刀把她刺死。」"

## 五、物品 / 道具 / 武器
- 名称：公共马车
- 说明：阿斯拉王国境内连接各领地与都市的公共长途交通工具。
- 原文依据："莉莉雅转搭了好几班公共马车，最后来到有着广大农业地区的边境，菲托亚领地。"

- 名称：淬毒短剑
- 说明：刺客用于暗杀王族的武器，刀刃涂有无解毒魔术可救治的致命毒药。
- 原文依据："碰上有刺客试图暗杀刚出生的公主时，她一时大意，被对方用短剑伤了脚。短剑上涂着毒，是那种用来暗杀王族的毒。"

- 名称：除魔道具
- 说明：道具店售卖的民俗用品，用于布置除魔仪式。
- 原文依据："她急忙前往道具店，用掉仅有的一点钱买下必要的东西。之后在格雷拉特家的人都熟睡后，她进行了故乡流传的除魔仪式。"

## 六、历史 / 传说 / 事件
- 事件名：阿斯拉王国王女（公主）暗杀未遂事件
- 内容：有刺客潜入后宫试图暗杀刚出生的王女，禁卫侍女莉莉雅为护卫公主遭淬毒短剑刺伤脚部，虽保全性命但落得终身残疾并遭解雇；幕后黑手至今未查明。
- 原文依据："碰上有刺客试图暗杀刚出生的公主时，她一时大意，被对方用短剑伤了脚。"、"企图暗杀公主的幕后黑手还没被找到。"

- 事件名：恶魔附身王子的后宫传闻 [存疑]
- 内容：阿斯拉后宫流传的恐怖故事，称曾有王子被恶魔附身每晚四处爬行，并暗藏匕首刺杀抱起他的侍女。
- 原文依据："「过去曾经发生过阿斯拉的王子每天晚上都趴在地上，在后宫到处爬来爬去的事件。王子是被恶魔附身了。如果在不知情的状况下随便把王子抱起，王子就会用藏在身后的小刀，朝向侍女的心脏一刀把她刺死。」"

## 七、社会规则 / 习俗 / 文化
- 内容：贵族阶层雇佣侍女：边境下级骑士会出资招募具备助产知识和照顾小孩经验的熟练侍女；因边境正规家事侍女稀缺，薪资报酬相对优厚。
- 原文依据："在菲托亚区域的布耶纳村，有个下级骑士正在招揽侍女。上面还注明会优先采用拥有照顾小孩的经验，具备助产知识的人。"、"在这个边境有许多能使用剑术或传授剑术的人，但是受过完美家事训练的侍女却很少。既然供给较少，自然薪水也会提升。"

- 内容：冷酷的宫廷政治与裁员：失去战斗或服务能力的王宫人员会被即刻辞退且无抚恤；接触王室机密者更可能面临秘密处决或被当成引出刺客的弃子筹码。
- 原文依据："王宫很乾脆地解雇她。……虽说连当前的生活资金都没能拿到，不过光是没有因为在后宫工作就被秘密处决，就必须抱着已经赚到的想法。"、"说不定他们只是想雇用可以用过就丢的女仆。"

- 内容：人口贩卖与女奴隶：王都大臣等权贵阶层存在购买年轻女奴隶的社会风气与事实。
- 原文依据："传言中买下许多年轻女奴隶的大臣会露出的笑容。"

- 内容：民间育婴常识/迷信：民间经验认为刚出生不哭的婴儿往往身体存在缺陷或异常。
- 原文依据："据说出生之后没有立刻哭泣的婴儿通常有哪里异常。"

- 内容：中央大陆通用语言：中央大陆各地区存在广泛普及与通用的官方/主流语言。
- 原文依据："至少那些并不是中央大陆普遍使用的语言。"

## 九、角色认知 vs 客观事实
- 角色以为：莉莉雅见鲁迪乌斯出生不哭、整天乱爬、面露成年好色大臣般的恶心笑容并埋胸，主观认定鲁迪乌斯是被恶魔附身或受到诅咒，迟早会在深夜觉醒并用小刀刺杀全家人。
- 原文是否暗示另有真相：是。鲁迪乌斯并非恶魔附身，其行为举止源于前世34岁家里蹲御宅族的心理习惯与转生认知。
- 原文依据："这个婴儿有哪里不对劲。说不定是被什么邪恶的东西附身了，或是受了诅咒。"、"鲁迪乌斯就是那样。没错，他肯定是那种恶魔。虽然现在还很安分，但是总有一天他会觉醒，并且趁着夜深人静时，把全家人一个又一个的杀掉……"对比前文主角前世回忆与转生认知。
- 角色以为：莉莉雅暗中观察鲁迪乌斯在书房看书喃喃低语时，起初认为他不到认字学话年纪，“只是婴儿看着书随便发出声音而已”。
- 原文是否暗示另有真相：是。鲁迪乌斯实际上正在凭借前世经验积极识字并学习该异世界的语言与知识。
- 原文依据："鲁迪乌斯还不到学说话的年纪，当然也没有教他认识文字。所以，这只是婴儿看着书随便发出声音而已。如果不是这样就太不合常理了。然而，莉莉雅总觉得那听起来像是有意义的成串语言。"
