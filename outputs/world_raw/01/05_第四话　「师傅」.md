# 第四话　「师傅」 世界设定提取

## 一、地理与场所
- 名称：罗亚（罗亚镇）
- 内容：邻近的城镇，设有魔术师公会与冒险者公会，保罗与塞妮丝前往张贴招聘家庭教师告示之处。
- 原文依据："「亲爱的，明天就去罗亚镇上贴出求才告示吧！必须好好培育孩子的才能！」"、"「亲爱的！要找家庭教师！罗亚那边一定可以找到优秀的魔术老师！」"

- 名称：米里斯大陆北方
- 内容：长耳族现今居住的地理区域。
- 原文依据："「长耳族是现在居住在米里斯大陆北方的种族。」"

- 名称：魔大陆比耶寇亚地方
- 内容：魔族的一支米格路德族的居住地。
- 原文依据："「嗯，正式讲法是魔大陆比耶寇亚地方的米格路德族。」"

- 名称：巴比诺斯地方
- 内容：魔族的一支斯佩路德族原先所在的地区。
- 原文依据："「在巴比诺斯地方有一支发色为绿色，名叫斯佩路德族的魔族。」"

- 名称：王都
- 内容：大国都城，宫廷魔术师多在此工作。
- 原文依据："年轻人都不会想来这种乡下地方，而且宫廷魔术师在王都那边多的是工作。"

- 名称：主角所处村庄与边境 [存疑]
- 内容：位处国内角落的乡下边境，连魔术师都极为罕见；村中没有旅舍；保罗为当地少有的骑士（下级贵族）。（注：本章尚未提及该村具体名称）
- 原文依据："保罗是这一带少有的骑士，基本上似乎也有着下级贵族的身分"、"不过，毕竟这里在国内也是位处角落的乡下地方。换句话说算是边境，别说优秀的人才，连魔术师都很罕见。"、"因为这村庄里没有旅舍，对方好像要住在我们家。"

## 二、组织与势力
- 名称：魔术师公会
- 内容：魔术师相关的公会组织，可供雇主提出招聘魔术教师等委托。
- 原文依据："即使向魔术师公会和冒险者公会提出委托，也不知道会不会有人应聘……"

- 名称：冒险者公会
- 内容：冒险者组织，拥有内部成员实力排行（如中上等），可承接外来委托。
- 原文依据："即使向魔术师公会和冒险者公会提出委托，也不知道会不会有人应聘……"、"换句话说以冒险者的排行来看，大约是中上或是更高的位置。"

- 名称：宫廷魔术师
- 内容：服务于王都的官方魔术师职位/势力，工作机会多。
- 原文依据："而且宫廷魔术师在王都那边多的是工作。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔术教师任职资格
- 规则：规定只有上级以上的魔术师才有资格担任魔术教师；以冒险者排行来看大约对应中上或更高的位置。
- 原文依据："在这个世界中，规定只有上级以上的魔术师有资格担任魔术教师。换句话说以冒险者的排行来看，大约是中上或是更高的位置。"

- 名称：水系统魔术（水弹与水炮）
- 规则：初级水弹咏唱咒文为「愿伟大的水之加护降临汝所求之处，清凉之浅流在此显现──『Water Ball』」，威力可击断树干；中级水炮魔术威力足以打穿房屋墙壁。
- 原文依据："「愿伟大的水之加护降临汝所求之处，清凉之浅流在此显现──『Water Ball』。」"、"打算试验中级魔法的我抱着不当一回事的心情咏唱了水炮魔术。……结果却放出了水量惊人的水柱，还把墙壁打出一个大洞。"

- 名称：治愈魔术 / 治疗术
- 规则：能够治愈折断的树木使其恢复原样；洛琪希与塞妮丝均能使用至中级；洛琪希表示只要好好训练，每个人都能达到中级程度。
- 原文依据："树干逐步恢复成折断前的模样。"、"「原来老师你也能使用治愈魔术吗！」「嗯？是啊，到中级为止都没有问题。」……「不，只要好好训练，每个人都能达到这种程度。」"、"之后，塞妮丝用治疗术华丽地治好那棵树，转身走回家中。"

- 名称：召唤魔术
- 规则：非纯战斗用魔术，能够召唤出拥有特定能力的魔兽或精怪魂灵；洛琪希自身无法使用。
- 原文依据："例如只要使用召唤魔术，也能召唤出拥有需要能力的魔兽或精怪魂灵。"、"「召唤魔术！以后会教我吗！」「不，因为我无法使用。」"

- 名称：混合魔术
- 规则：按顺序结合不同系统的魔术以达成特定效果。例如先用水魔术打湿大石周围土壤，再用土魔术将土壤变成泥巴，使巨石沉入地底。
- 原文依据："「这是先用水魔术打溼石头周围的土壤，再用土魔术把土壤变成泥巴的混合魔术。」"

- 名称：土魔术对矿物与金属的干涉
- 规则：土魔术对金属和矿物能造成一定程度影响，可用于开锁、上锁或改变形状；金属硬度越高，变化消耗的魔力越多。
- 原文依据："也试过练习上锁或开锁。土魔术对金属和矿物似乎也能造成一定程度的影响。只是金属如果是越硬的种类，要消耗的魔力就会越多。"

- 名称：魔力消耗规律
- 规则：
  1. 缩放效应：加大魔术规模消耗魔力加速增长；反之将魔术设定得极小（如产生一滴水），消耗的魔力同样急剧增加，该现象目前尚未有原理解释。
  2. 精细度与速度效应：操作对象越小、越要求复杂精细迅速正确，消耗魔力呈指数级庞大。
  3. 跨系统并用消耗：同时发动两个不同系统的魔术，魔力消耗约为同系统并用的三倍以上。
  4. 衰退性推测 [存疑]：主角推测魔力与体力类似，若长期偷懒疏于训练可能衰退。
- 原文依据："所谓魔术这种东西，一旦进行「变化大小」的动作，必须消耗的魔力就会改变。例如把咏唱时没有特别设定大小的情况假设为一，之后越是加大，消耗的魔力也会加速增长。……可是，不知道为什么反过来设定得越小时，消耗魔力也一样会增加。……比起制造出拳头大的水弹，产生一滴水时反而会消耗高上许多的魔力。……问过洛琪希之后，她只回答「就是会这样」。"、"还有操作的对象越小，以及越想做出复杂精细又正确迅速的动作，都会让消耗的魔力量变得更加庞大。"、"此外，我还试着同时使用不同系统的魔术。和同时使用同系统魔术相比，感觉要耗费三倍以上的魔力。"、"就像体能训练，只要稍微偷懒体力就会衰退。或许魔力也是一样，即使暂时增加，依然不可以疏于训练。"

- 名称：上级魔术特性
- 规则：上级魔术中包含大量广范围影响/范围攻击魔术（如大范围地区降雨，可用于农田抗旱）。
- 原文依据："或者该说上级魔术有很多是范围攻击，总觉得用起来颇受限制。例如让大范围地区下雨……这有什么用？本来我这样想，后来听说在一段都放晴没雨的日子后，洛琪希好像有前往麦田降雨，还获得村人们的大力颂扬。"

## 四、种族 / 生物
- 名称：长耳族（古代长耳族）
- 特征：古代魔术的创造者。在人魔大战前的混沌战乱时期，古代长耳族与森灵对话、操纵风与土抵御外敌；现居住在米里斯大陆北方。
- 原文依据："首先魔术这种东西，据说是古代长耳族创造的。"、"「长耳族是现在居住在米里斯大陆北方的种族。」"、"古代长耳族曾经和森灵们对话，操纵风和土抵御外敌。传说这就是历史上最古老的魔术。"

- 名称：人族
- 特征：擅长发明与将事物型态化的种族。现代魔术即人族在战争中模仿长耳族并型态化后的产物。
- 原文依据："现在的魔术，是人族在战争中模仿长耳族魔术并予以型态化后才得到的技术。因为人族特别擅长这部分。"、"「嗯，每次创造出新事物的都是人族。」"

- 名称：魔族
- 特征：人族在古代交战时期给敌方起的名称。最通俗的定义是“在上次战争中加入魔族阵营的种族”，内部包含多种生理与文化特征不同的族群分支。
- 原文依据："魔族这种讲法是人族在很久以前和魔族交战的时期，给敌方起的名称。"、"「在上一次战争中加入魔族阵营的种族」是最容易理解的定义。"

- 名称：米格路德族
- 特征：魔族的一支，聚居于魔大陆比耶寇亚地方。外表娇小端正、不易随年龄衰老、水蓝色头发（光照下偶显绿色）、雪白肌肤。与斯佩路德族相近，过去曾受较严重的偏见。洛琪希属于该族。
- 原文依据："「嗯，正式讲法是魔大陆比耶寇亚地方的米格路德族。」"、"水蓝色头发绑成麻花辫，表现出的模样可以用娇小端正来形容。没有被阳光晒黑的雪白肌肤"、"「由于米格路德族是和斯佩路德族相近的种族，所以我有听说过以前曾受到满严重的偏见。」"

- 名称：斯佩路德族
- 特征：原居巴比诺斯地方的魔族分支。特征为翠绿色头发，额头中央长有如红宝石般的第三只眼（用于观察魔力流动，不会变色）。正常拥有男女两性。被世人视为极其凶暴危险，四百年前大战后遭全种族厌恶并驱逐出魔大陆。
- 原文依据："「在巴比诺斯地方有一支发色为绿色，名叫斯佩路德族的魔族。」"、"「绝对不要接近拥有翠绿色头发，额头上还有红宝石般物体的种族。即使逼不得已必须交谈，也绝对不可以惹怒对方。」"、"「对，他们可以靠额头上的那东西来观察魔力流动，等于是第三只眼睛。」"、"「没那回事，很正常的有男有女。」"、"「不会变色，至少我没听过这种事情。」"

- 名称：魔物与魔兽
- 特征：魔物由过去动物变异产生；若变异生物数量繁衍固定并经历世代演化出智能，即称为魔兽。若产生智能后依然袭击人类或退化凶暴化，则被称为魔物。世俗分界模糊，大致为“袭击人类为魔物，不袭击人类为魔兽”。
- 原文依据："所谓魔物，基本上是过去就存在的动物突然变异而产生。如果这种生物幸运地增加数量，成为固定种族，经历许多世代后产生智能，那就是魔兽。不过呢，那些在拥有智能后依然会袭击人类的魔兽似乎经常被称为魔物。据说也有魔兽经过好几代后反而变凶暴，最后退化为魔物的案例。"

- 名称：森灵 / 精怪魂灵
- 特征：自然界的超自然存在，古代长耳族可与之沟通，召唤魔术亦可召唤精怪魂灵。
- 原文依据："古代长耳族曾经和森灵们对话"、"召唤出拥有需要能力的魔兽或精怪魂灵。"

## 五、物品 / 道具 / 武器
- 名称：魔术教科书
- 说明：市面上作为实用书出版的魔术普及书籍，记载基础至进阶魔术与咏唱咒文，但书中未记载无咏唱魔术的方法。
- 原文依据："虽然在这种书会被当成实用书出版的这个世界里"、"魔术教科书上也没有记载无咏唱的方法。"

- 名称：魔道具
- 说明：具备特殊魔法效果的道具，内部刻有魔法阵，非魔术师也能使用，部分魔道具启动时会消耗大量魔力。
- 原文依据："「是具备特殊效果的道具，内部刻有魔法阵，不是魔术师也能够使用。不过，有的魔道具会消耗大量的魔力。」"

- 名称：魔术师之杖
- 说明：魔术师标配的施法手杖，洛琪希随身携带一根。
- 原文依据："手上只有一个皮包，以及一根看起来就像是魔术师持有物品的杖。"

## 六、历史 / 传说 / 事件
- 事件名：古代长耳族创立魔术传说
- 内容：在人魔大战前混沌战乱时代，古代长耳族与森灵对话、操纵风土抵御外敌，被传为历史上最古老的魔术。后由人族在战争中模仿并型态化为现代魔术。
- 原文依据："很久以前，在人魔大战之前，世界还处于混沌状态且战火不断的时期，古代长耳族曾经和森灵们对话，操纵风和土抵御外敌。传说这就是历史上最古老的魔术。……现在的魔术，是人族在战争中模仿长耳族的魔术并予以型态化后才得到的技术。"

- 事件名：人魔大战
- 内容：人族与魔族之间爆发的长期冲突。第一次大战距今约七千年前；距今四百年前双方再次爆发战争，数千年间断断续续交战。
- 原文依据："「就是刚刚提到的人魔大战吗？」「对，第一次战争大概是七千年前吧。」"、"「因为四百年前，人族和魔族之间也曾发生战争。自从在七千年前起头后，人族和魔族就一直断断续续地交战。」"

- 事件名：四百年前斯佩路德族战乱与被逐事件
- 内容：四百年前的大战中，斯佩路德族在十余年战乱中极度疯狂大闹，屠杀同族聚落妇女幼童，全灭敌军后亦歼灭友军；战后遭到敌我双方共同厌恶憎恨，并在残酷迫害下被驱逐出魔大陆。
- 原文依据："「在巴比诺斯地方有一支发色为绿色，名叫斯佩路德族的魔族。由于他们在四百年前的战争中疯狂大闹，所以才开始流传这样的说法。……由于他们在仅有十几年的战争中放纵闹事，到了被敌我双方的所有种族都厌恶嫌弃的地步。是一支危险到在战争结束后，甚至在迫害下被赶出魔大陆的种族。」"

## 七、社会规则 / 习俗 / 文化
- 内容：贵族子弟家庭教师制度
  - 规则：贵族子弟家庭教师收入丰厚；世界明文规定只有上级以上的魔术师才有资格担任魔术教师；边境偏远乡村极为罕见魔术师，聘任难度高。
  - 原文依据："贵族子弟的家庭教师似乎是收入相当不错的工作。"、"在这个世界中，规定只有上级以上的魔术师有资格担任魔术教师。"、"换句话说算是边境，别说优秀的人才，连魔术师都很罕见。"

- 内容：身边用具优先于日常魔术
  - 规则：日常生活（如照明）通常优先使用蜡烛或提灯等廉价现成道具，而非依赖魔术。
  - 原文依据："不过还有个理由是即使不依靠魔术，也只需使用身边的东西就能够达到目的。例如若是需要照明，使用蜡烛或提灯就行了。"

- 内容：魔术委托收费常识
  - 规则：魔术师接受村民委托运用魔术解决生活与农事问题，通常按常规收取报酬，村民也普遍接受该商业逻辑（Give and Take）。
  - 原文依据："村民们似乎也能接受。因为村里没有能做这些事情的人，他们似乎对洛琪希赞不绝口。……一般来说会收取酬劳。这才叫作普通，叫作常识。"

- 内容：魔术师师徒尊卑与实力伦理
  - 规则：魔术师界讲究实力主导的师徒关系，若徒弟实力超越师傅却称其为师傅会被视为丢人现眼；缺乏实力仅凭长者架子施教容易引起猜忌与对立。
  - 原文依据："「要是被比自己优秀的人称为师傅，简直是丢人现眼的事情。」"、"「光是因为年纪较长就摆出架子是不行的！没有伴随着实力的师生关系只会让人不快！」"

- 内容：对绿发魔族的迷信与接触斯佩路德族的禁忌
  - 规则：民间流传“发色越绿越危险”的迷信观念；遇到斯佩路德族时，绝对不可刺激或激怒对方，亦不可慌乱逃跑，应若无其事找借口脱身，交谈需保持尊重且避免挖苦讽刺。
  - 原文依据："「一般相信，在魔族中发色越接近绿色的种族越凶暴危险。……认为发色越鲜艳越危险的讲法根本是迷信。」"、"「绝对不要接近拥有翠绿色头发，额头上还有红宝石般物体的种族。即使逼不得已必须交谈，也绝对不可以惹怒对方。」"、"「嗯，要是遇到，请摆出若无其事的态度，再装作还有其他事情逃离现场。因为突然逃跑有可能会刺激到对方。」"

- 内容：格雷拉特家育儿约定

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯推想这个世界可能把魔术视为异端处以火刑（如中世纪猎巫），或规定小孩子绝对不可以使用魔术。
- 原文是否暗示另有真相：是
- 原文依据："说不定这里的常识是：「必须等长大后才能使用魔术」。……「小孩子或许不可以使用魔术」的推论看来只不过是我在杞人忧天。"（父母得知后不仅完全不加制止，反而极为欣喜地四处张罗请家庭教师）

- 角色以为：世人普遍相信魔族中发色越鲜艳、越接近绿色的种族越凶暴危险。
- 原文是否暗示另有真相：是
- 原文依据："「那么回到原来的话题，认为发色越鲜艳越危险的讲法根本是迷信。……因此，其实发色和危险与否并没有关系。」"（洛琪希明确指出发色危险论纯属偏见与迷信，是因斯佩路德族四百年前的暴行波及同类）

- 角色以为：民间传说斯佩路德族屠杀同胞村落女人小孩、全灭友军、夜间吃小儿等暴虐行径。
- 原文是否暗示另有真相：不明 [存疑]
- 原文依据："「他们做了什么？」「这个嘛，我也不是很清楚……只是从小就听说过很多轶事，例如他们袭击同为魔族的聚落，杀光女人小孩；或是在战场上全灭敌人后，连友军也一起被全部消灭；还有要是晚上熬夜不睡觉，斯佩路德族就会来吃人之类……」"（洛琪希本人亦表示不清楚具体细节，仅是从小听闻的传闻轶事）

- 角色以为：按照常理缩放，生成的水滴越小消耗的魔力理应越少。
- 原文是否暗示另有真相：是
- 原文依据："可是，不知道为什么反过来设定得越小时，消耗魔力也一样会增加。这个理论我实在想不透。比起制造出拳头大的水弹，产生一滴水时反而会消耗高上许多的魔力。……问过洛琪希之后，她只回答「就是会这样」。似乎尚未找出解释。"（客观事实上，越极度微缩的操作反而消耗暴增，原理不明）

- 角色以为：鲁迪乌斯初见洛琪希时以为对方是国中生年纪的稚嫩少女。
- 原文是否暗示另有真相：是
- 原文依据："年纪大概是国中生左右吧？……「看起来很小。」「你没有资格说我小。」"、"「我才不小。」洛琪希一脸不高兴地立刻反驳"（洛琪希实际是寿命与外观机制有别于人族的魔族米格路德族，且早已取得上级魔术师资格并担任家庭教师，并非真正的人类初中幼童）
