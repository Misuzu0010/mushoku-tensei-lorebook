# 第六话　「尊敬的理由」 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国
- 内容：布耶纳村所属的大国。
- 原文依据："这个村子所在地位于阿斯拉王国东北部的菲托亚领地，似乎是叫作布耶纳村。"

- 名称：菲托亚领地
- 内容：阿斯拉王国东北部的领地区域，布耶纳村所在地。
- 原文依据："这个村子所在地位于阿斯拉王国东北部的菲托亚领地，似乎是叫作布耶纳村。"

- 名称：布耶纳村
- 内容：鲁迪乌斯出生成长的农业村庄。村里约有三十多户农家，农田广阔，建有水车小屋，周边为一望无际的草原与远处的群山。村内平时由年轻人轮值警戒，保罗担任驻村骑士。
- 原文依据："根据洛琪希的说法，这个村子所在地位于阿斯拉王国东北部的菲托亚领地，似乎是叫作布耶纳村。村里大约有三十多户靠务农度日的人家。"、"从脚边到地平线的尽头为止，全都是草原。不，隐约可以看到远处有山脉。"

- 名称：王都（阿斯拉王国王都）
- 内容：阿斯拉王国的都城，布耶纳村种植的芭缇尔丝花收成后会送往此处加工成香料。
- 原文依据："芭缇尔丝花会送往王都加工，成为香料。"

## 二、组织与势力
- 名称：驻村骑士 / 领地派遣骑士
- 内容：由国家或领主派遣至乡村的常驻骑士职位。职责为监督村民切实工作、调解村内民事纠纷并进行仲裁、在魔物来袭时保护村庄。保罗担任此职务。
- 原文依据："我的父亲保罗是被派遣到这个村子的骑士。他的职责是监视村民们是否有确实工作，同时在村内发生争执时也要负责仲裁，还有在魔物来袭时必须保护村子。简而言之就是国家公认的保镖。"

## 三、力量体系 / 魔法 / 技能
- 名称：水圣级攻击魔术「豪雷积雨云」（Cumulonimbus）
- 规则：水圣级攻击魔术，制造大范围伴随雷电的特大暴雨。常态施法机制为在中等高度空中制造云层，同时通过精细操作使其化为雷云，必须持续注入魔力维持，否则会在风吹下消散。咒语咏唱历时一分钟以上（咏唱词："雄伟的水之精灵，登上天空的雷帝之王子啊！实现我的愿望，带来凶暴的恩惠，让矮小的存在见识您的力量！以神之铁锤敲击铁砧，显现您的可畏，让洪水淹没整片大地！啊，雨啊！冲垮一切，驱逐所有事物吧！『Cumulonimbus』！"）。若结合科学气象原理（利用混合魔术加热下方空气引发上升气流，同时冷却上方空气加速，配合斜向龙卷风循环推升），云层可无需魔力持续维持而自主膨胀扩散；驱散时需大范围降温地面、加热上空导出下沉气流并辅以风魔术强行吹散。
- 原文依据："「接下来我会使用水圣级攻击魔术『豪雷积雨云』，这是制造出大范围豪雨并伴随着雷电的魔术。」"、"「雄伟的水之精灵，登上天空的雷帝之王子啊！……『Cumulonimbus』！」"、"在中等高度的空中制造出云层，同时进行复杂的操作使其形成雷云。……而且必须持续注入魔力，否则云层会停止流动并迅速消散。"、"「当然了，水圣级的魔术依然是魔术，如果没有使用魔力维持，就会被风吹散。」「可是我已经让云层不会被吹散了耶……？」「……这样啊，利用斜向往上的龙卷风把云推上去……！」"

- 名称：中级治疗术（ExHealing）
- 规则：中级治愈魔术，咒文为「宛如母亲的慈爱女神，请治愈此人之伤口，让他恢复健康的身体──『ExHealing』」。能迅速治愈被雷击重创垂危的马匹，但无法复活已经死亡的目标。
- 原文依据："「宛如母亲的慈爱女神，请治愈此人之伤口，让他恢复健康的身体──『ExHealing』。」"、"洛琪希慌慌张张施展中级治疗术后，马很快就醒了。看来马并没有立刻死亡。因为中级的治愈魔术无法让死者复苏。"

- 名称：土系上级魔术「土堡」
- 规则：土系上级防御魔术，可迅速升起类似雪洞的半圆形坚固土制圆顶遮蔽物，能够抵御强雷暴雨。施法后维持约一个小时即会自行消散，若中途施法者分心失去控制会开始崩坏。
- 原文依据："眼前出现了一个类似雪洞的半圆形土制遮蔽物。这是土系的上级魔术『土堡』。……这个土堡会在一个小时后消失"、"土堡开始一点点崩坏。喂喂，你要确实控制啊。马会被活埋啦。……我急忙接手控制"

## 四、种族 / 生物
- 名称：米格路德族（护身符与身份特征）
- 特征：魔族分支，持有米格路德族的护身符在遇到棘手的魔族时报上名字可能获得通融[存疑]。
- 原文依据："「米格路德族的护身符。万一哪天遇见不好惹的魔族，拿出这个并报上我的名字，对方会稍微通融……或许会。」"

- 名称：魔物（布耶纳村周边分布）
- 特征：布耶纳村周围只要不靠近森林便极少有魔物出没；即便出现也多为低阶弱小魔物，单名上级魔术师即可独自清剿。
- 原文依据："「只要别靠近森林，这附近很少会碰到魔物。而且就算碰到也是一些很弱的魔物，我一个人就能解决。」"

- 名称：马（家畜）
- 特征：重要的代步与劳作牲畜。保罗家中唯一的一匹马名为“卡拉瓦乔”，被保罗视若挚友。
- 原文依据："卡拉瓦乔是这匹马的名字。"、"这是我们家唯一的一匹马。保罗每天都仔细照料它……他还大剌剌宣称对这匹马的爱仅次于对塞妮丝的爱。"

- 名称：阿斯朗麦
- 特征：布耶纳村农田主要栽培的粮食作物，为制作面包的面粉原料。
- 原文依据："「主要是阿斯朗麦，是面包的原料。」"

- 名称：芭缇尔丝花
- 特征：布耶纳村栽培的经济作物，收成后运往王都加工制作为香料。
- 原文依据："「应该还有少量的芭缇尔丝花和蔬菜吧。芭缇尔丝花会送往王都加工，成为香料。」"

## 五、物品 / 道具 / 武器
- 名称：米格路德族的护身符
- 说明：洛琪希在鲁迪毕业时赠送的护身符项链。采用皮绳悬挂，链坠以散发绿色光泽的金属制成，外形犹如三根长枪交错组合。据称遇到不好对付的魔族时亮出此符并报上洛琪希的名字可能获得关照或通融[存疑]。
- 原文依据："洛琪希将手伸进长袍内侧，摸索一阵之后后掏出一条皮绳项链。链坠使用泛着绿色光泽的金属制作，外型像是由三根长枪组合而成。……「米格路德族的护身符。万一哪天遇见不好惹的魔族，拿出这个并报上我的名字，对方会稍微通融……或许会。」"

## 六、历史 / 传说 / 事件
- 事件名：布耶纳村去岁大旱事件
- 内容：一年前布耶纳村遭遇严重干旱，洛琪希利用水魔术前往麦田施法降雨，成功解救农田旱情，因而赢得了全体村民的赞誉与由衷接纳。
- 原文依据："「但是你在去年乾旱时帮了很大的忙。村里那些家伙一定也会欢迎你。」"

## 七、社会规则 / 习俗 / 文化
- 内容：魔术师毕业考核规矩
  - 规则：魔术师学习结束时需通过师傅主持的实地毕业考核。高阶范围攻击魔术（如水圣级）考核因破坏力惊人，会严重损害农田作物及人身安全，必须移步至村外荒野草原等无人空旷地带进行。
  - 原文依据："毕业考试要在村外进行。……「接下来我会使用水圣级攻击魔术『豪雷积雨云』，这是制造出大范围豪雨并伴随着雷电的魔术。请模仿我并试着使用这个魔术。」"、"「不是，是因为担心会有人和农作物遭受损害。」"

- 内容：毕业赠礼习俗
  - 规则：弟子学成毕业之际，师傅会赠送有纪念意义或庇护性质的信物礼品（洛琪希将自己贴身的米格路德族护身符赠给鲁迪乌斯）。
  - 原文依据："「这是毕业的贺礼。因为没有时间准备，请你勉强收下这个吧。」"

- 内容：魔族在人族边境乡村的融入现实
  - 规则：阿斯拉王国乡下地区普遍对魔族抱有深厚的歧视与戒心；但若魔族展现出实用才能并积极助人（如解旱抗灾、排忧解难），经过长久相处亦能打破种族成见建立深厚信任与威信。
  - 原文依据："明明这个国家对魔族的态度还带着歧视。越乡下的地方，这种倾向应该越显着才对。但是只过了短短两年，洛琪希在这村中已经成了众人会致意的对象。"、"是因为身为魔族，原本村民应该不可能会正面看待的洛琪希。"

- 内容：阿斯拉乡村警卫与行政自治制度
  - 规则：村庄内部日常警戒由村内年轻壮丁轮流承担；国家委派骑士负责宏观治安巡视、农耕监督与纠纷司法仲裁。
  - 原文依据："他的职责是监视村民们是否有确实工作，同时在村内发生争执时也要负责仲裁，还有在魔物来袭时必须保护村子。……话虽如此，这个村里由年轻人轮流负责警戒。所以保罗上午巡视完后，下午通常都会待在家里。"

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希以为鲁迪乌斯之所以抗拒踏出家门是出于幼童对高大马匹的恐惧。
- 原文是否暗示另有真相：是
- 原文依据："「我知道了，你是怕马吧？」……洛琪希弄错了。可是，我无法老实承认自己其实是害怕外出。"（鲁迪乌斯内心其实喜爱马匹，抗拒出门的根源在于前世长年遭受残酷霸凌及被逐车祸留下的严重创伤后遗症）

- 角色以为：洛琪希认为施展水圣级魔术「豪雷积雨云」后，施法者必须在外面持续注入魔力控制维持一小时，否则云层必会被大风吹散。
- 原文是否暗示另有真相：是
- 原文依据："「不要光说是，要在外面认真控制雷云一个小时。」「你说控制吗？……有必要控制吗？」「当然了，水圣级的魔术依然是魔术，如果没有使用魔力维持，就会被风吹散。」「可是我已经让云层不会被吹散了耶……？」「……这样啊，利用斜向往上的龙卷风把云推上去……！」"（鲁迪乌斯运用现代气象物理原理制造对流循环闭环，使得云层不仅未散反而自主急剧扩大，洛琪希见后深感震撼）

- 角色以为：洛琪希认为遭遇不好惹的魔族时，只要亮出米格路德族的护身符并报出她的名字，对方就会给予通融关照。
- 原文是否暗示另有真相：不明 [存疑]
- 原文依据："「米格路德族的护身符。万一哪天遇见不好惹的魔族，拿出这个并报上我的名字，对方会稍微通融……或许会。」「我会好好珍惜。」「只是或许喔，不可以过于相信。」"（洛琪希自身对其效力亦心存疑虑，特别叮嘱不可盲目轻信）

- 角色以为：认为中级治愈魔术能救活死者。
- 原文是否暗示另有真相：否
- 原文依据："洛琪希慌慌张张施展中级治疗术后，马很快就醒了。看来马并没有立刻死亡。因为中级的治愈魔术无法让死者复苏。"（中级治愈魔术无法逆转死亡，马匹能够苏醒仅因其受击后并未立刻丧命）
