# 第八话　「独当一面」 世界设定提取

## 一、地理与场所
- 名称：赤龙山脉
- 内容：中央大陆广袤险峻的巨大山脉地带，诸峰连绵，将整个中央大陆分割成三块。整座山脉均栖息着数量庞大的赤龙，被世人称作“无法通行的死亡山脉”。山脉外围的中央大陆平原地势则以平缓的原野与森林为主。
- 原文依据："所谓的赤龙山脉，是位于中央大陆的广大山脉地带。属于赤龙山脉的诸山峦绵延相连，将中央大陆分割成三块，而且整个山系都栖息着赤龙。"、"无法通行的死亡山脉……这就是赤龙山脉。"、"中央大陆上的山脉虽然都很高，但基本上大部分的地形都是平缓的原野和森林。"

- 名称：赤龙下颚 与 赤龙上颚
- 内容：赤龙山脉中唯二可供通行的通道，呈现为悬崖绝壁的天然溪谷。自第二次人魔大战时期便已存在，是当年唯一足以通行军队的要冲。其中「赤龙下颚」连接中央大陆南部与西部，穿过该峡谷即进入阿斯拉王国领地，是自南部前往阿斯拉王国的必经入口。
- 原文依据："在栖息着大量赤龙的这座赤龙山脉中，只有两处可以通行的场所。那就是被称为「赤龙下颚」与「赤龙上颚」，呈现出悬崖绝壁的溪谷。这两个地方是从第二次人魔大战那时就已经存在的溪谷，据说即使是在当时，也是宽度足以让军队通过的唯一通路。而拉普拉斯正是因为预料到这一点，才会把赤龙放到这座山脉中。这是瑞杰路德告诉我的事情，所以肯定没错。"、"我们让马车前往连接中央大陆南部和西部的「赤龙下颚」。只要通过那里，我们就会进入阿斯拉王国的领土。"、"从西隆王国出发后经过四个月。我们终于到达通往阿斯拉王国的入口，「赤龙下颚」。"

- 名称：中央大陆南部公路与北部战乱地带
- 内容：西隆王国通往阿斯拉王国的大道平坦温暖，两旁为广阔草原。因其北面接壤战火连绵的诸小国（纷争地带），战乱流民四起导致沿线治安欠佳，常有因贫困饥饿而拦路打劫过往旅人金属贵重物品的流窜盗贼。
- 原文依据："通往阿斯拉王国的道路很平坦，周围充满让人忍不住打盹的温暖空气。大道左右都是一望无际的草原，正面隐约可见的是赤龙山脉。"、"虽然这里是中央大陆，不过这段道路一带的治安有点差。"、"要是再往北边一点移动，听说有许多小国乱纷纷地彼此征战，盗贼好像也是受到战争影响才会变多……"

## 二、组织与势力
- 名称：七大列强（实力阶梯）
- 内容：世界上最顶尖强者的序列。列强中排名前列者拥有令赤龙之王称臣或横渡赤龙群的绝对战力；昔日列强全盛期即便排名第七亦能穿越赤龙领地；但如今列强中位列下方的强者（如剑神、北神），面对数百只赤龙昼夜不休的围攻亦会耗尽体力被迫中途折返。此外，被封印的第四名「魔神」与排在第五名的「死神」之间存在着难以逾越的巨大实力鸿沟。
- 原文依据："「真要说谁能做到，只有在『七大列强』中名列前茅的那些人。恐怕就算是北神或剑神，也会在半途折返吧。」……「嗯，他们大概会在途中就耗尽体力。因为连要睡一觉都办不到。」……「不过，拉普拉斯曾经让赤龙的王服从于自己之下。所以如果是『七大列强』中排行前几名的那些人，起码可以通过赤龙山脉吧。话又说回来，若是过去的『七大列强』，即使是排行第七，至少也能够办到穿越赤龙地盘这种程度的事情。」看来封印中的第四名「魔神」，和现在名列第五的「死神」之间似乎有无法跨越的实力差距。"

## 三、力量体系 / 魔法 / 技能
- 名称：战士的认定资格
- 规则：在斯佩路德族及异域武者评价体系中，「战士」与单一技术流派的「剑士」截然不同。被公认为「战士」标志着个体已具备独当一面的强大力量与成熟心智，不再被视作需要受庇护的孩子，而是平等的独立战斗者。瑞杰路德依据艾莉丝实力的长足进步（逼近全盛预知眼鲁迪乌斯近战极限），正式宣布其为独当一面的战士。
- 原文依据："「从今天开始，你可以自称为战士。」瑞杰路德一边以沉着严肃的态度坐到地上，同时开口如此宣布。……「你已经独当一面了。」瑞杰路德平静回答。……「没问题，你已经具备充分足以成为战士的力量。」……「但是，你不可以自鸣得意。我的意思是不会再把你当成小孩看待，懂了吗？」"

- 名称：近战魔力眼压制界限
- 规则：鲁迪乌斯的预知眼在面对普通对手或一年前的艾莉丝时能实现近战轻松压制；但在艾莉丝剑技飞跃式进化后，即便鲁迪乌斯全力解放魔眼与自身魔力，近身战斗也仅能勉强惊险获胜，唯有拉开距离通过远距离魔术方可轻松取胜。
- 原文依据："一年前，我只要使用魔眼就能轻松获胜。……可是现在已经办不到了。虽说只要全力使用魔眼和魔力，最后还能站着的人应该会是我，不过大概会是一场勉强惊险获胜的对战。当然，如果在战斗时能保持距离，我想必可以轻松取胜。"

## 四、种族 / 生物
- 名称：赤龙
- 特征：中央大陆公认的最强魔物与绝对霸主，也是龙类中性情最为凶猛、危险度最高的品种。单一个体即具备S级后段战力（所有龙类单体均达A级以上），能喷射火焰，数百只结群并具备极高集团狩猎智能。拥有尚未探明原理的绝对索敌感知能力，对侵入其领地的任何生物（即便犬类体型）皆无差别集结围杀啃噬至死。
- 飞行缺陷：飞行能力极为拙劣，无法在平地上直接起飞，必须从悬崖向下跃下或沿长距离陡坡滑行方能升空。因此平原定居的人类极少受到赤龙主动袭击。
- 原文依据："赤龙被认为是中央大陆最强的魔物。或许该称为绝对的强者。赤龙光是单一个体就拥有相当强大的实力，还会以数百只为单位形成群体。尤其该特别提及的是它们的探知能力，赤龙们绝对不会放过入侵自己地盘的生物。就连狗这种大小的生物也无法幸免。无论是多么强大的魔物，一旦闯入赤龙的地盘就会遭到围攻，最后被啃食殆尽，连骨头都不会剩下。"、"不管哪一种龙的单一个体都是A级以上的魔物，其中被认为最危险也最凶猛的种类就是赤龙。虽说赤龙的单一个体顶多只能算是S级后段，但是毕竟群体的数量和地盘的规模都大得惊人。"、"尽管赤龙是危险的生物，其实存着一个弱点。战斗能力强大的它们由于飞行能力相当粗劣，所以无法从平地起飞。如果想要飞行，赤龙只能从高崖上往下跳，或是沿着有一定长度以上的斜面滑行后升空。"

- 名称：脱队龙（坠地赤龙）
- 特征：因气流乱流等意外坠落平地的赤龙个体。因平地无法起飞而失去制空霸权，但依然保留等同于A级前段的压倒性物理破坏力与吐息。一旦落入人类聚集区周边，公会会发布S级紧急讨伐委托，通常需组织近十组高级冒险者队伍利用陷阱方可合力围剿；基列奴早年在剑圣前曾与4名上级剑士围攻脱队龙，付出2人阵亡的沉重代价方才讨伐成功。
- 原文依据："只是赤龙之中似乎偶尔也会出现一些特别愚笨的个体，因为被乱流之类卷入而摔落到平地上。这样的龙会被视为迷途的脱队龙。天空的霸王坠地后将会丧失力量……但是，当然不可能失去所有力量，还保留有等同于A级前段的实力。要是掉到人类的居住区域附近，赤龙将以压倒性的力量大肆破坏……委托虽然是S级，不过为了安全起见，会派出将近十组的队伍并使用陷阱……「基列奴说成员是五个实力跟她差不多的上级剑士。」「最后死了几个人？」「说是两个。」"

- 名称：王龙 / 黑龙
- 特征：龙类的其他分支。王龙虽结群但通常仅数只小规模同行；黑龙则为完全独来独往、绝不成群的个体。
- 原文依据："如果是虽然会形成群体，但顶多只会几只一起行动的王龙；或是根本不会成群结队的黑龙还可以另当别论，面对以百只为单位袭击而来的成群赤龙，怎么可能以寡击众嘛。"

## 五、物品 / 道具 / 武器
- 名称：赤龙素材（龙肉、龙骨、龙皮）
- 说明：猎杀赤龙所获取的超高价值战利品。龙肉与龙骨皆为顶级装备制造素材，龙皮作为艺术品价值连城，全身各部位均极具用途。单头赤龙市价可达一百枚阿斯拉金币，十人队伍均分收益足以让每名成员尽情挥霍享乐整整一年。
- 原文依据："顺便说一下，龙肉和龙骨都是近乎最高级的装备素材，龙皮连作为艺术品也具备高价值。当然不只龙皮，龙的全身上下所有部分都能派得上某种用场。听说即使由十个人一起去讨伐一只龙并均分报酬，每个人也能获得挥霍享乐一整年的金额。讲的具体一点，一只龙似乎能换得阿斯拉金币一百枚。"

- 名称：银币护身符
- 说明：鲁迪乌斯在临睡前交给瑞杰路德塞在胸前缝线间的护身物品。
- 原文依据："「请把一枚银币放到你胸前的口袋里。」……「所以这是做什么？」「是一种护身符。」"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯布置赤龙山脉防线
- 内容：在第二次人魔大战期间，「赤龙下颚」与「赤龙上颚」是中央大陆南北军队互通的唯二咽喉通道。魔神拉普拉斯洞悉此点，降服了赤龙之王并将大量赤龙投放布设在该山脉中，打造阻绝交通的天然军事天险。
- 原文依据："这两个地方是从第二次人魔大战那时就已经存在的溪谷，据说即使是在当时，也是宽度足以让军队通过的唯一通路。而拉普拉斯正是因为预料到这一点，才会把赤龙放到这座山脉中。这是瑞杰路德告诉我的事情，所以肯定没错。"、"「不过，拉普拉斯曾经让赤龙的王服从于自己之下。所以如果是『七大列强』中排行前几名的那些人，起码可以通过赤龙山脉吧。」"

- 事件名：基列奴讨伐脱队赤龙
- 内容：基列奴青年时期尚未获得剑圣头衔时，曾与四名实力匹敌的上级剑士组成五人猎团迎战一头坠地的脱队赤龙，最终战死两人将其诛杀。
- 原文依据："「可是，基列奴说过她以前有打倒过脱队的赤龙啊！……听说她好像是在成为剑圣前有跟赤龙战斗过！……基列奴说成员是五个实力跟她差不多的上级剑士。」……「说是两个。」"

- 事件名：抵达赤龙下颚
- 内容：鲁迪乌斯一行三人离开西隆王国，历经四个月的漫长跋涉，终于抵达成群赤龙盘旋的阿斯拉王国入口「赤龙下颚」。
- 原文依据："从西隆王国出发后经过四个月。我们终于到达通往阿斯拉王国的入口，「赤龙下颚」。"

## 七、社会规则 / 习俗 / 文化
- 内容：**赤龙禁区的生存共识**：“闯入赤龙地盘必死无疑”是中央大陆全体居民的普遍常识。因平地不适宜赤龙起降，平原生活与赤龙形成事实上的地理隔离。
- 原文依据："关于赤龙到底是用什么方法来找出入侵地盘的生物，目前尚未查明。只有「闯入赤龙地盘就死定了」这点成为这个世界的常识。"、"中央大陆上的山脉虽然都很高，但基本上大部分的地形都是平缓的原野和森林。因此，居住在平地的人们很少会遭到赤龙袭击。"

- 内容：**战士加冕的成人礼文化**：在斯佩路德等尚武传统中，被族中资深战士认可为“战士”即宣告脱离儿童期，意味着此后必须承担成人的生死责任与尊严。
- 原文依据："「从今天开始，你可以自称为战士。……你已经独当一面了。」……「但是，你不可以自鸣得意。我的意思是不会再把你当成小孩看待，懂了吗？」"

- 内容：**脱队龙悬赏机制**：脱队赤龙引发的损害为全国性灾难，公会常规设定为S级团队讨伐任务，禁止低阶冒险者擅自送死，鼓励多组高级冒险者配合作战。
- 原文依据："委托虽然是S级，不过为了安全起见，会派出将近十组的队伍并使用陷阱……由于赤龙是高额素材，好像也有那种才刚升上C级，根本没资格承接委托的菜鸟去鲁莽挑战，不过多半都会被赤龙烧成烤肉吃个精光。"

## 九、角色认知 vs 客观事实
- 角色以为：艾莉丝以为凭借瑞杰路德或鲁迪乌斯的强大实力，可以不必绕远路、直接徒步翻越赤龙山脉。
- 原文是否暗示另有真相：是。瑞杰路德断言徒步通过是不可能的死路，数百只赤龙昼夜无休的围攻就连剑神、北神等列强强者都会耗尽体力折返，唯有拉普拉斯等级的极少数顶级强者才有可能通过。
- 原文依据："「何必这样绕路，既然有瑞杰路德在，应该有办法通过赤龙山脉这种小地方吧！」……「别讲这种傻话。」瑞杰路德边苦笑边回答。……结果就算是他，要徒步通过赤龙山脉似乎也是不可能的任务。……「真要说谁能做到，只有在『七大列强』中名列前茅的那些人。恐怕就算是北神或剑神，也会在半途折返吧。」"

- 角色以为：鲁迪乌斯一直将艾莉丝视作需要受自己保护照顾、稚气未脱的年幼小孩。
- 原文是否暗示另有真相：是。瑞杰路德直接指出艾莉丝实力已达独当一面的战士水准，心智也在走向成熟，唯独鲁迪乌斯仍固执地以成年人看待孩童的俯视视角对待她。
- 原文依据："「你为什么要对艾莉丝说那种话？」瑞杰路德微微睁开眼，看往我这边。「因为你一直把她当小孩子看待。」"

- 角色以为：鲁迪乌斯在到达赤龙下颚前，以为旅程能一直平安顺遂，身边亲近的人都会幸运存活。
