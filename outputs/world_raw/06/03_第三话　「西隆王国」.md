# 第三话　「西隆王国」 世界设定提取

## 一、地理与场所
- 名称：西隆王国
  - 内容：位于中央大陆南部、邻近北方激烈纷争地带的小国，拥有约两百年历史。建国初期即与王龙王国结盟，国力悬殊，实际立场类似王龙王国的附属国，并作为阻隔北方战乱的防波堤。境内田地与牲畜放牧相间，有类似三叶草的休耕牧草地。王国周边存在大量迷宫，吸引了众多高等级冒险者聚集。
  - 原文依据："西隆王国虽然是个小国，却是拥有约两百年历史的古国。……中央大陆南部是丰腴的土地，然而直到王龙王国在三百年前左右支配最南端一带之前，向来是激烈纷争不断的区域。就算是现在，只要往北移动也依旧是一大片纷争地带。西隆王国的位置正好邻近于这样的纷争地带。位处这种地点，为什么西隆王国还能够维持国家主权两百年？那是因为在建国后的初期阶段，西隆就和王龙王国缔结了同盟关系。不过虽说是同盟，双方的国力差距却很明显。因此西隆王国和途中经过的那两个国家相同，立场都类似王龙王国的附属国。……还是因为西隆王国能阻隔纷争地带，发挥作为防波堤的功用呢？……而西隆王国周边存在着为数不少的迷宫。"
- 名称：拉塔基亚
  - 内容：西隆王国的王都。外围建有坚固的奇幻风格外城墙；城内街道错综复杂，不仅小巷曲折幽深，连大街也是弯来拐去，极易让人迷路（与米里希昂严整的棋盘状街道截然不同）。因聚集大量意图靠迷宫发财的高水准冒险者，城内旅社物价整体偏高。
  - 原文依据："最后抵达西隆王国的王都，拉塔基亚。……西隆王国的首都拉塔基亚也不例外，外围有着一圈看起来就很有奇幻风格的坚固城墙。……这个城镇连大街都弯来拐去，和呈现棋盘状的米里希昂真是大不相同。连没有迷路属性的我目前也陷入即将迷路的状态。……或许是因为这城市里有许多高层级的冒险者，连低层级的旅社也要价偏高。"
- 名称：中央大陆与魔大陆城墙设定对比
  - 内容：魔大陆由于魔物强悍且频繁入侵，城镇对城墙的建设更为彻底，小聚落常态性猎杀周边魔物，大型城镇利用周边各种族特殊能力制造出极高防卫力的城墙；中央大陆主要都市虽建有城墙，但外在魔物威胁相对较低，城墙防卫的紧迫感不如魔大陆。
  - 原文依据："话说起来，关于城墙的存在状况，其实魔大陆和这边并没有什么差别。甚至反而该说，在魔物比较强大的魔大陆上设置得更为彻底。尽管没有其他城镇拥有利卡里斯镇那种规模的巨大天然城墙，不过都会各自应用住在附近的各种族特殊能力，制造出坚固的墙壁来保护城镇。此外就算是小型的聚落，似乎也会经常性地驱除村子周边的魔物。和魔大陆相比，中央大陆的城墙会让人觉得那顶多只是为了耍帅的玩意儿。"

## 二、组织与势力
- 名称：西隆王国正规军（王宫士兵）
  - 内容：西隆王国的王宫守备与正规军力量，着统一制服。基层士兵亦具备相当剑术水平（能拔剑弹开突发岩炮弹，疑似修习水神流）。配备警笛，能通过不同的吹奏节律在曲折巷道间相互定位并联络增援，具备极快封锁街区的调度机制。
  - 原文依据："在梦里见到的那个光景中有出现两个士兵，他们身上的服装我曾在这城市内目睹多次，是这国家的正规军制服。……面对突然飞来的岩炮弹，士兵反射性地拔出剑，把岩炮弹打偏。……是水神流吗？……是笛子，掉进洞里的士兵吹起了警笛。过了一会儿之后，远处和很近的巷子里都开始接二连三地响起笛声。哔哔哔哔────！吹笛的方式和造成的声响都各自有着细微的不同之处。恐怕是靠声音来传达彼此位置。……「这附近的道路已经全都遭到封锁！很快就会有其他士兵赶来这里！」"

## 三、力量体系 / 魔法 / 技能
- 名称：土风复合爆破魔术
  - 内容：先利用土魔术在实体土墙上引发内部应力并制造裂痕，紧接着在墙壁中心用风魔术激发出冲击波，瞬间将厚重土墙崩解粉碎。
  - 原文依据："利用土魔术来操控墙壁制造出裂痕，同时使用风魔术，在墙壁中心产生冲击波，于是土墙就发出轰隆声响然后粉碎。"
- 名称：土枪反冲跳跃法
  - 内容：在脚底瞬间制造前端削平的土枪快速突刺升起，利用强劲机械推进力把施术者弹射至半空中以飞越重围。缺点是落地时缺乏缓冲将承受巨大冲击，可能导致双腿骨折。
  - 原文依据："让自己脚边出现前端被削平的土枪。然后靠着土枪的推进力，化身为人肉炮弹，飞向半空。……顺便说一下，我的双脚在落地时「啪！」地一声狠狠折断。以后再也不干这种事。"
- 名称：落下型陷阱（土魔术）
  - 内容：瞬间使目标脚下的泥土下陷形成陷阱坑洞，令其失足坠落丧失机动性。
  - 原文依据："看到士兵试图跑走，我在他的脚边设置了落下型陷阱。"
- 名称：无咏唱魔术的社会反应
  - 内容：无咏唱魔术在中央大陆极其罕见，西隆王国士兵亲眼目睹后极度震惊，并失声喊出"居然使出了无咏唱魔术！难道这家伙就是那个……？"，显示西隆军方可能知晓或在追查具备无咏唱能力的特定人物。
  - 原文依据："「居然使出了无咏唱魔术！」「难道这家伙就是那个……？」「快去叫人来支援！」"

## 四、种族 / 生物
- 名称：小人族
  - 内容：世界上的智慧种族之一，身形极为娇小短小，外观轮廓容易与人类幼童混淆。
  - 原文依据："不，这世界上还有小人族这种身材特别矮小的种族。严禁掉以轻心，在哪个适当地点甩掉对方吧。"

## 五、物品 / 道具 / 武器
- 名称：西隆士兵警笛
  - 内容：西隆王国士兵随身佩戴的报警哨笛。吹响时声调尖锐如鸟鸣，可通过不同的吹奏技巧和声调传递不同指令与方位，实现多方位部队的快速联动与围剿封锁。
  - 原文依据："突然有个很像是鸟叫声的尖锐声响传遍周遭。声音来自陷阱底部。是笛子，掉进洞里的士兵吹起了警笛。过了一会儿之后，远处和很近的巷子里都开始接二连三地响起笛声。哔哔哔哔────！吹笛的方式和造成的声响都各自有着细微的不同之处。恐怕是靠声音来传达彼此位置。"
- 名称：洛琪希图案自制印鉴
  - 内容：鲁迪乌斯以洛琪希所佩戴项链的特殊纹样为底版手工雕刻制作的印章，用于火漆封信，作为私下联络洛琪希的信物暗记。
  - 原文依据："我用蜡封住信封，盖下按照洛琪希那条项链的图案来制作成的印鉴（自制）。"

## 六、历史 / 传说 / 事件
- 事件名：四百年前人族国家大灭绝
  - 内容：距今约四百年前的战争中，除了阿斯拉王国与米里斯神圣国两个古老强国幸存外，中央大陆其余所有人族国家全部灭亡，现存多数小国历史均在数百年以内。
  - 原文依据："在历史以千年为单位来变动的这个世界里，两百年这种数字或许会给人一种不太古老的感觉。不过这是因为在四百年前的战争中，除了阿斯拉王国和米里斯神圣国以外的人族国家已经全数灭亡。"
- 事件名：王龙王国平定南部历史
  - 内容：中央大陆南部原为各方势力混战不断的纷争之地，约三百年前王龙王国平定并支配最南端一带，才形成了南部相对安定的政治格局。
  - 原文依据："中央大陆南部是丰腴的土地，然而直到王龙王国在三百年前左右支配最南端一带之前，向来是激烈纷争不断的区域。"
- 事件名：死神骑士夏伊娜传说
  - 内容：《北神英雄谭》中记载的女骑士，北神三剑士之一兼北神的伴侣，号称无论身处多么恶劣凶险的绝境战场也必定生还。当地居民常将孩子命名为夏伊娜以保佑平安免遭横祸。
  - 原文依据："死神骑士夏伊娜是在北神英雄谭里登场的女骑士。她是北神三剑士的其中一人，也是北神的伴侣之一。据说无论前往多严酷的战场也必定能生还……有听闻这一带的居民为了避免儿童因为意外事故而丧生，经常把孩子取名为夏伊娜。"
- 事件名：水神初代列达尔传说
  - 内容：水神流初代宗主，反击天才，曾施展魔术将大海冻结形成立足点，进而斩杀海龙王。水神流历代宗主承袭其名，男性称列达尔，女性称列妲。
  - 原文依据："至于列达尔则是水神。据说他是反击的天才，也是让大海结冻制造出立足点，打倒海龙王的英雄。水神流的宗主代代都借用这位伟大人物的名字，男性就自称为列达尔，女性则自称为列妲。这也是相当常见的人名。"

## 七、社会规则 / 习俗 / 文化
- 内容：迷宫探索与冒险者经济：西隆王国等周边迷宫众多的地区，吸引了大量以此为业的高阶（包括S级）冒险者。率先通关迷宫可获巨资，这种财富聚集现象带动了整座王都甚至低阶旅社的消费水平。
  - 原文依据："或许是因为这国家附近有比较多迷宫，路上可以看到不少身手俐落的冒险者。有很多冒险者是以探索迷宫作为主业。……只要能率先破解其中任何一个，就会有庞大的资金落入手中。路边这些来来往往的冒险者里，应该有好些人是意图一口气发大财的S级冒险者吧。"
- 内容：辟邪祈福的命名习俗：当地居民崇信英雄传说，习惯借用死神骑士夏伊娜的名字避免意外，或借用水神列达尔/列妲的名字给孩子取名。
  - 原文依据："有听闻这一带的居民为了避免儿童因为意外事故而丧生，经常把孩子取名为夏伊娜。……男性就自称为列达尔，女性则自称为列妲。这也是相当常见的人名。"
- 内容：寄信服务与密函暗记：冒险者公会兼营邮件递送服务。在信函交流中，寄信人使用特定火漆印记作为个人凭信，并在正文中运用藏头句（如"请你帮助我"）传递隐蔽意图。
  - 原文依据："而且，我还利用文章的第一个字来纵向排出：「请你帮助我」这样的藏头文。……我用蜡封住信封，盖下按照洛琪希那条项链的图案来制作成的印鉴（自制）。……之后我前往冒险者公会把信寄出"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯认为洛琪希目前仍任职于西隆王宫，寄信到王宫即可联络到洛琪希获得救助爱夏与莉莉雅的强力支援。
  - 原文是否暗示另有真相：是 / [存疑]（洛琪希早已离职远赴魔大陆；士兵见到无咏唱魔术脱口而出"难道这家伙就是那个……？"，暗示西隆王宫可能存在其他知晓无咏唱之人，信件走向成谜）。
  - 原文依据："那个可爱而且有点少根筋的师傅，是否还在这个国家担任宫廷魔术师呢？……总之，我会写信给王宫里的洛琪希……直到真正交到洛琪希手上为止，都无从得知信件的下落。可以说薛丁格的洛琪希。"
- 角色以为：鲁迪乌斯推断当街抓捕爱夏的两名士兵只是一般奉公守法、听令行事的底层士兵，甚至心怀愧疚。
  - 原文是否暗示另有真相：不明。
  - 原文依据："那两个士兵并没有露出低俗的表情。如果真要分类，那看起来反而像是一脸歉疚。说不定他们只是听令行事，并非出自本意。……我想他们大概不是坏人。"
- 角色以为：鲁迪乌斯认为利用土枪反冲力飞上空中能帅气脱身。
  - 原文是否暗示另有真相：否（虽成功脱离包围，但落地毫无缓冲，双脚当场严重折断）。
  - 原文依据："顺便说一下，我的双脚在落地时「啪！」地一声狠狠折断。以后再也不干这种事。"
