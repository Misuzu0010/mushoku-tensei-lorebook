# 第九话　「转折点二」 世界设定提取

## 一、地理与场所
- 名称：赤龙下颚
- 内容：是一条只有单一道路往前延伸的溪谷。虽不像圣剑街道那样笔直，但没有岔路。位于国境与国境之间，不属于任何国家的领域；只要通过这里便会进入阿斯拉王国。
- 原文依据："赤龙下颚，这里是只有一条道路往前延伸的溪谷。虽然不像圣剑街道那样笔直，不过还是一条没有岔路的单一通路。是位于国境与国境之间，不属于任何国家的领域。只要通过这里就会进入阿斯拉王国。"

## 二、组织与势力
- 名称：七大列强
- 内容：世界的顶级强者排位体系。龙神奥尔斯帝德在其中位居第二位。
- 原文依据："龙神，「七大列强」排行第二位。"

## 三、力量体系 / 魔法 / 技能
- 名称：预见眼在面对超强对手时的现象
- 规则：魔眼在面对实力压倒性强大且行动变幻莫测的极速对手时，看到的未来影像会出现严重抖动与多层重叠，甚至无法辨别轮廓；一秒后的预见可能同时浮现头部、喉咙、心脏、肺部等所有要害被分别摧毁的复数影像。
- 原文依据："〔男子的身影出现许多层抖动重叠的影像。〕由于抖动得太严重，甚至连轮廓都看不清。"、"一秒后的我，所有要害都会被摧毁。头部、喉咙、心脏、肺部……我可以看到这些部位各自被破坏的影像，甚至还可以看见那家伙每次都在场的影像。"

- 名称：水神流奥义「流」
- 规则：水神流的高阶招式。仅用手掌轻触对手攻击的武器侧面，即可将对手攻击所蕴含的全部运动能量直接反弹回对手身上，使其旋转飞出受创。
- 原文依据："「……奥义『流』。」面对艾莉丝，奥尔斯帝德没费太多工夫。只是用掌心轻轻挡下她的剑。……是水神流的剑技，奥尔斯帝德的动作就像是把那剑技更钻研提升后的感觉。所有的运动能量都被反弹回艾莉丝身上。"

- 名称：魔术师的战斗弱点与咏唱封锁
- 规则：对付魔术师的最有效攻击是击毁对方的肺部，一旦肺部被毁，魔术师将因无法呼吸发声而无法进行魔术咏唱，从而封锁治愈魔术的使用，并迅速因失去呼吸机能而濒死；但拥有无咏唱能力的魔术师在肺部损毁后仍能施放无咏唱魔术。
- 原文依据："「对付魔术师，最好的攻击就是毁掉对方的肺……」……遇上魔术师，只要击溃对方的肺部就行。这样能让敌人无法咏唱。事实上，我的治愈魔术在此时已经被封死。当然，肺部遭到摧毁会让连生命活动都无法继续维持。"、"「我应该已经打烂了你的肺部，是无咏唱魔术吗？这是不是从人神那里获得的力量？」"

- 名称：乱魔
- 规则：将手掌对准施术者，直接干涉并搅乱对手从身体放出或在身前聚集的魔力，使魔术无法凝聚成形而直接消散，实现魔术无效化。但单手的乱魔无法完全封锁施术者利用多重咏唱（例如另一只手同时施法）发动的魔术。
- 原文依据："「已经够了，『乱魔』！」……在奥尔斯帝德把右手朝向我的那瞬间，自己右手前方即将聚集而成的魔力被扰乱了。不管我再怎么把魔力送往手掌前方，还是无法成形，直接消散。……对方是干涉了我从右手放出的魔力，利用搅乱魔力的方式来让魔术无效化。"、"「唔……让『乱魔』无效化了？不，不是……应该是多重咏唱的一种吧？居然能以无咏唱方式来做到这种事，真是个灵巧的家伙……是这种感觉吗？」"

- 名称：前龙门
- 规则：奥尔斯帝德打响手指召唤出的约五十公分正方形、装饰着华丽龙图案的银色小窗门。打开后能将对手即将成形施放的魔术魔力完全吸入中和。然而若面对的魔力量过于庞大，小尺寸的门无法完全承受时，窗框会承受不住而裂开，未被完全吸收的魔力仍会发生余波爆炸；施展后门框会逐渐消失。
- 原文依据："男子打响左手的手指。于是，有个五十公分的正方形小窗从他的脚边升了上来。是一个有装饰着华丽龙图案的美丽银色小窗。"、"「打开吧，『前龙门』。」奥尔斯帝德喃喃说出这句话，于是那扇窗户打开了。这瞬间，我左手前方即将形成魔术的魔力全被吸收。窗框也发出清脆声响并裂开。同时，奥尔斯帝德的身边发生爆炸。然而爆炸的规模远低于我原本的预想……"、"「真是惊人的魔力量，这个尺寸的『前龙门』无法完全承受吗？简直可以和拉普拉斯相提并论……」"

- 名称：斗气
- 规则：一种用于身体强化与防御的体系机制。奥尔斯帝德击穿鲁迪乌斯时，对其无法使用斗气护体感到失望。
- 原文依据："「真是让人失望啊，人神那家伙。居然让这种连使用斗气都无法办到的家伙成为棋子，到底有什么打算……」"

## 四、种族 / 生物
- 名称：纯黑发特征
- 特征：在这个世界里很少有纯粹的纯黑发，大多数看似黑发的人，仔细观察其实多为深褐色或偏向灰色。
- 原文依据："这个世界很少有纯粹的黑发。就算乍看之下是黑发，但仔细观察后会发现其实是深褐色或有点偏向灰色。"

- 名称：龙神奥尔斯帝德的生理特征与体质影响
- 特征：男性，银色头发，金色的双眼，眼白多得夸张，眼神凶恶。靠近他人时，其存在散发出一种让包括战士（如瑞杰路德、艾莉丝）在内的常人产生无法抑制的极度恐惧与敌意的特异体质；但鲁迪乌斯却不会对他感到恐惧，奥尔斯帝德对此感到非常异常。
- 原文依据："那家伙有银色的头发，金色的双眼，身上并没有特别装备防具，而是穿着不知道用哪种皮革制成的粗犷白色大衣，性别是男性。说到我对他的印象，充其量只有「真是个眼神凶恶的家伙」。这个人的眼白部分真是多得夸张。"、"原本就偏白的皮肤已经完全不带血色，还不断冒出冷汗，握着短枪的手也持续颤抖。……是恐惧。"、"「换句话说，你不会感到恐惧吗？」男子皱起眉头。「嗯……真奇怪。我没有见过你的记忆。」"

## 五、物品 / 道具 / 武器
- 名称：纯白无面纹面具
- 说明：跟随奥尔斯帝德的黑发少女所戴的面具。没有任何花纹与装饰，在这个世界中属于极其罕见、没有其他人会佩戴的特殊装扮。
- 原文依据："她的脸上戴着面具。是一个上面没有任何花纹，也没有任何装饰的纯白面具，要说没有特徵还真的找不出特徵，却是个让人看过一眼就不会忘记的面具。……在这个世界里，没有人会戴着这样的面具。"

## 六、历史 / 传说 / 事件
- 事件名：龙神与人神的绝对敌对
- 内容：龙神奥尔斯帝德与人神处于不可调和的死敌立场，奥尔斯帝德立誓必定杀死人神；一旦发现与人神有接触或被其判定为人神使徒者，奥尔斯帝德会立刻予以斩杀。
- 原文依据："「是吗，你是人神的使徒吗？」"、"「死了以后去告诉人神，就说『龙神奥尔斯帝德一定会杀了你』。」"

- 事件名：奥尔斯帝德对历史预期的偏差
- 内容：奥尔斯帝德知晓保罗·格雷拉特、艾莉丝、瑞杰路德等人，但在其认知中，保罗“应该没有儿子，只有两个女儿”，且完全没有关于鲁迪乌斯的记忆。
- 原文依据："「我父亲是保罗・格雷拉特。」「……嗯？保罗应该没有儿子，只有两个女儿。」"、"「嗯……真奇怪。我没有见过你的记忆。」"

- 事件名：魔神拉普拉斯的魔力量基准
- 内容：拉普拉斯在历史上拥有极其惊人的魔力量基准，奥尔斯帝德在目睹鲁迪乌斯最大出力的魔力时，称其魔力量“简直可以和拉普拉斯相提并论”。
- 原文依据："「真是惊人的魔力量，这个尺寸的『前龙门』无法完全承受吗？简直可以和拉普拉斯相提并论……」"

## 九、角色认知 vs 客观事实
- 角色认知：
  1. 奥尔斯帝德认为保罗·格雷拉特“应该没有儿子，只有两个女儿”；
  2. 奥尔斯帝德认为鲁迪乌斯是“人神的使徒”，其无咏唱魔术及庞大魔力量是从人神那里获得的力量。
- 原文是否暗示另有真相：是
- 原文依据：
  1. 鲁迪乌斯确确实实是保罗的长子（"我父亲是保罗・格雷拉特。""「……嗯？保罗应该没有儿子，只有两个女儿。」"），表明奥尔斯帝德掌握的原有历史情报与现实发生出入；
  2. 鲁迪乌斯的无咏唱魔术与魔力量是幼年通过自我练习锻炼得来，且鲁迪乌斯仅仅是梦中见过自称HITOGAMI（人神）的存在，并非受其雇佣或差遣的仆从使徒（"「有听过，我梦里出现过叫HITOGAMI……」""「是吗，你是人神的使徒吗？」""我才刚觉得自己被冤枉了"）。
