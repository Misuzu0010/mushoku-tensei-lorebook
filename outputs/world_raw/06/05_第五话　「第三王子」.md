# 第五话　「第三王子」 世界设定提取

## 一、地理与场所
- 名称：西隆王国的牢房（地下结界房间）
- 内容：西隆王国内部用于关押囚犯的地下石室套房。建材为坚固紧密的石头，采光略显不足，无床铺，设有老旧的垂直排放型厕所。天花板高度约四公尺，天花板上方设有一个约A4纸张大小、由沉重石板密封并刻有魔法阵的投食孔洞。室内布置有王级结界魔术，使内部人员无法使用魔术亦无法离开。
- 原文依据："建材是坚固的石头，紧密坚硬地组合而成。虽然缺点是采光略为不足又没有床铺，厕所还是有点老旧的垂直排放型，要是住久了肯定会生病……"、"还往上跳跃想看看能不能碰到差不多有四公尺高的天花板。"、"只有发现天花板上可以打开一个约A4大小的洞口而已。看样子帕库斯是打算从那里把食物丢进来。"、"然而看起来很沉重的石板却像是被焊死的人孔盖那般牢牢固定，似乎很难掀开。而且盖子上好像也画有魔法阵。"

## 二、组织与势力
- 名称：米里斯教团 / 神殿骑士团
- 内容：信奉米里斯教的宗教势力及其武装组织。在米里斯教团的影响下，魔族人偶被列为违禁品；若持有魔族人像被神殿骑士团知晓，即便西隆王国的王子，也会被送上异端审问法庭当成魔神崇拜者处决。
- 原文依据："在试图推广瑞杰路德模型的过程中，我得知在米里斯教团的影响下，魔族人偶是违禁品。"、"要是持有这种人像的事情被米里斯教团的神殿骑士团知道，就算是西隆的王子，也会被送上异端审问法庭，然后当成魔神崇拜者处死吧。"、"会被处死啊……毕竟神殿骑士团好像都是些宗教狂热分子。"

- 名称：西隆王国禁卫队
- 内容：西隆王国王室成员身边的亲卫部队。王室内部存在将亲卫部队私自作为筹码转让或交易的荒唐现象（如第三王子札诺巴为换取洛琪希手办而将自己最后的部下交易给第七王子帕库斯）。
- 原文依据："「殿下的部下里没有熟悉结界的人吗？」「本王子没有部下！」「是这样吗，可是连那个帕库斯都有禁卫队……」「因为本王子把最后一个部下拿去和洛琪希人偶交易！哎呀，这真是一笔好买卖！」"

## 三、力量体系 / 魔法 / 技能
- 名称：王级结界魔术（牢房结界）
- 规则：第七王子帕库斯用于困住鲁迪乌斯（原预谋用于捕捉洛琪希）的高阶结界魔术。只要身处结界内部，魔术就会被完全无效化，内部人员无法逃往外部，外界物理重击也无法破坏分毫。其作用机理是强行吸收魔力，即便施术者能释放魔力，魔力也会被吸收而无法形成具体物理或魔法现象（宛如强风中打火机无法点火）。其维持通常依托于藏在房间某处的魔力结晶。
- 原文依据："请看看这坚固的结界。只要待在里面，竟然能让魔术无效，也无法前往外部！就连身为A级冒险者的我全力挥拳攻击也纹丝不动。"、"关于魔术方面，我做了各式各样的尝试，但每一个都没有发动。既然魔力会被吸收，那么就尽可能放出最大的魔力来破坏这魔法阵吧！我试过这种像是少年漫画剧情的行动，却完全没出现能有效果的动静。能释出魔力，可是不知道为什么无法化为具体形式。我无法让魔力变化成现象，感觉好像可以但实际上却不行。"、"帕库斯好像有说过这是王级的结界魔术吧？"、"「徒弟，这房间里的某处应该藏着用来维持这结界的魔力结晶，你要找出那东西并破坏它！」"

- 名称：土魔术手办造型与硬化技术
- 规则：鲁迪乌斯独创的利用土魔术雕刻/塑形岩石制作手办模型的高难度魔术工艺。成品的石质硬度与重量远超矿坑族的石制工艺品；通过反复试错与集中消耗大量魔力，可制成即使极度细长（如魔杖、长枪柄）也绝不断裂扭曲的强韧部件（制作1公分长细柄需消耗一整天的时间与巨量魔力）；还包含多手位替换、可穿脱长袍等精密可动结构。
- 原文依据："「可以看出是雕刻岩石制成，然而材质却比矿坑族石制工艺品的材料更硬更重。能够把这种硬度的石头雕刻到如此精巧的技术，并不存在于现今的世上……举例来说，你看这个魔杖的部分。就算是灵巧的矿坑族，要把坚硬石材削磨到这么细也是极为困难的事情。」"、"魔杖这种细长的零件很容易折断。为了弥补这缺点，我反覆在失败中求取经验。这份辛劳没有白费，最后获得优良的硬度和韧性。瑞杰路德人偶的枪柄也是同样材质。为了制作这部分，需要相当多的魔力、集中力以及时间。讲的具体一点，就是一公分需要花上一整天。"、"「不愧是『水王级魔术师』洛琪希的弟子！这人偶是用魔术制作出的物品吧！」"

## 四、种族 / 生物
- 名称：矿坑族
- 特征：以擅长石制雕刻与工艺品著称的种族。手艺灵巧，但无法将极硬石材削磨至超精细度而不折断，工艺风格被札诺巴评价为缺乏性感与情感表现力的“粗野”。
- 原文依据："然而材质却比矿坑族石制工艺品的材料更硬更重。能够把这种硬度的石头雕刻到如此精巧的技术，并不存在于现今的世上……举例来说，你看这个魔杖的部分。就算是灵巧的矿坑族，要把坚硬石材削磨到这么细也是极为困难的事情。"、"「的确，一些关键部分远不及矿坑族的纤细技术。甚至可以说是外行人。然而，这个人偶却具备了粗野的矿坑族终究无法到达的领域！」"

## 五、物品 / 道具 / 武器
- 名称：瑞杰路德模型人偶
- 说明：鲁迪乌斯以土魔术手工精雕的魔族战士手办。形象为手持长枪的斯佩路德族战士，额头上镶嵌红宝石状特征，枪柄具备坚硬不易折断的石质韧性。因具有鲜明魔族外貌特征，在人族领地被视为魔族人像/邪神像。
- 原文依据："那是举着枪的战士人偶──瑞杰路德的模型。「你在哪里得到这个魔族人偶？」"、"瑞杰路德的模型在额头上有宝石，因此一看就知道是魔族。"、"瑞杰路德人偶的枪柄也是同样材质。"

- 名称：洛琪希模型人偶
- 说明：鲁迪乌斯在布耶纳村时期雕刻的岩石手办，原型为水王级魔术师洛琪希。五年前被第七王子帕库斯以五枚阿斯拉金币购入，后被第三王子札诺巴换走。具备拆卸长袍机构、三手臂切换姿态机构，内部还原贴身内裤与身材曲线，腋下原雕刻有黑痣（被札诺巴误磨平）。在行家眼中估值达百枚阿斯拉金币以上。
- 原文依据："结果从袋子里被拿出来的物品，是洛琪希的人偶模型。"、"「这个魔族的人像是大约五年前在市场找到的东西……发现的人是我弟弟，据说因为这东西和当时是宫廷魔术师的洛琪希很相像，所以他亲自在市场从行商人的手上买下。」"、"「贩卖的价钱却是五枚阿斯拉金币。如果是本王子，愿意出价一百枚金币。」"、"「小心拆下固定住长袍的部分后……其实这人偶有三只手。穿着长袍的型态和穿着贴身衣物的型态，制作者是利用这种机关让两种型态合而为一。」"

- 名称：洛琪希的内裤（圣物）
- 说明：被鲁迪乌斯供奉为“圣物”的洛琪希贴身内裤，形状像本垒板的白色布料。曾被莉莉雅洗净后用于包裹送给鲁迪乌斯的十岁生日礼物（木雕项链），随身携带于小箱子中，后被札诺巴认出其材质款式与洛琪希手办内部完全一致。
- 原文依据："形状像本垒板的白色布制物体，毫无疑问……这正是……圣物。「莉莉雅好像打算在你十岁生日时把这东西当成礼物。」"、"圣物被清洗乾净了。洛琪希的特级初榨橄榄油已被洗去，丧失神性。"、"我比较了一下内裤和模型，才发现人偶身上的内裤和原本是圣物的那件内裤相同。"

- 名称：木雕项链坠子
- 说明：莉莉雅随身小箱子内部的手工木雕项链，雕刻手法笨拙，外部由洛琪希的内裤包裹作为掩护/包装。
- 原文依据："接着从箱子内取出一个被柔软布料包住的东西，谨慎地把布解开。里面是木雕的项链坠子。这木头好像在哪里看过。当然坠子是手工雕刻，可以看出制作者的技术似乎颇为笨拙。"

## 六、历史 / 传说 / 事件
- 事件名：洛琪希辞去西隆宫廷魔术师事件
- 内容：约五年前，拥有“水王级魔术师”称号的洛琪希在西隆王国担任宫廷魔术师，后因不堪忍受第七王子帕库斯偷内裤、偷看洗澡等性骚扰行为而愤然离开西隆王国。
- 原文依据："「洛琪希・米格路迪亚已经不在这国家了。她无法继续忍受我那弟弟的性骚扰，因此离开此地。」……「好像是偷内裤和偷看她洗澡吧。」"、"「不愧是『水王级魔术师』洛琪希的弟子！」"

- 事件名：莉莉雅遭西隆王国逮捕事件
- 内容：大转移事件后，莉莉雅在洛琪希离开王宫的次日突然现身于第三王子札诺巴房间内，随后遭到卫兵逮捕并交由第七王子帕库斯看管监禁，行李被扣押。
- 原文依据："「在这种情况下，莉莉雅突然出现在本王子房内，那是洛琪希离开后隔天的事情。」「莉莉雅被士兵逮捕，发生很多事后决定由帕库斯负责管理，不过在她持有的行李中有这种东西。」"

## 七、社会规则 / 习俗 / 文化
- 内容：**米里斯教信仰下的魔族艺术禁忌**：米里斯教严格排斥魔族，其势力范围内将魔族相关物品（人偶、雕像）视作崇拜魔神的异端邪物。任何人若藏匿魔族人偶，面临被神殿骑士团移送宗教裁判处决的极高风险，民间商人多以极低价格脱手以规避法律责任。
- 原文依据："在试图推广瑞杰路德模型的过程中，我得知在米里斯教团的影响下，魔族人偶是违禁品。"、"要是持有这种人像的事情被米里斯教团的神殿骑士团知道，就算是西隆的王子，也会被送上异端审问法庭，然后当成魔神崇拜者处死吧。所以只要用低价贱卖，就多的是借口可卸责。"

- 内容：**手办狂热者的拜师礼仪**：札诺巴对艺术与雕刻极致追求达到病态执迷程度，一旦发现能制作出超越凡俗艺术品的“神之手”制作者，可以彻底抛弃王族自尊与身份，五体投地匍匐拜师。
- 原文依据："札诺巴忽然五体投地，整个人用力趴向地面……「请您一定要允许本王子称呼您为师傅！」札诺巴这样说完，移动手脚匍匐前进，试图亲吻我的鞋子。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯在札诺巴手持瑞杰路德人偶质问时，以为札诺巴是受米里斯教影响前来以魔族人偶罪名问罪审讯自己。
- 原文是否暗示另有真相：是。札诺巴并非问罪，而是因痴迷该高超工艺，急切追寻制作者的身份。
- 原文依据："魔族的人偶。我没想太多就带来了，果然魔族人偶在这一带也被视为邪神像吗？……这家伙果然也是要拿这件事来问罪吧……「原来您就是这个人像的制作者吗！……请您一定要允许本王子称呼您为师傅！」"

- 角色以为：鲁迪乌斯认为札诺巴是个没有部下、行事鲁莽没有脑袋的无能王子，煽动他去解决帕库斯会引发灾难性后果。
- 原文是否暗示另有真相：是。鲁迪乌斯自述完全看走了眼，札诺巴的介入实际上让这次危机迅速彻底走向终结。
- 原文依据："我以为自己煽动了没有部下的废物王子，主动去招惹麻烦。也以为事态会往非常糟糕的方向演变……然而，我后来才知道原来这些是错误的判断。对于札诺巴・西隆这个人物，我完完全全看走了眼。事后仔细回想，或许在札诺巴得知我是人偶制作者的那一刻起，这次事件就已全面结束。"
