# 第二话　「米」 世界设定提取

## 一、地理与场所
- 名称：维邦（市）
  - 内容：王龙王国的首都。城市内汇集贩售中央大陆与米里斯大陆两地的特产，铁匠铺与剑术道场林立。干道在经过维邦后分歧为两条：一条往西，一条往北通向西隆王国。
  - 原文依据："我们首先沿着主要干道前进，途中经过王龙王国的首都，维邦。就像是要绕过王龙山脉，道路会在通过这个首都之后分歧成两条。一条是直直往北的路线，另一条是往西走的路线。按照计画，我们选择了通往西隆的往北路线。……维邦市是个贩卖着中央大陆与米里斯大陆双方特产品的城市。……此外，这个城市里有很多打铁铺与剑术道场。"
- 名称：王龙山
  - 内容：位于王龙王国西北方的山峰，曾有王者“王龙王卡夏库特”盘踞，地盘内蕴藏着极庞大的矿物资源。
  - 原文依据："据说是因为打倒西北方王龙山的王者──王龙王卡夏库特，获得其地盘内的庞大矿物资源，才得以一口气登上强国之位。"
- 名称：沙纳基亚王国
  - 内容：王龙王国的附属国之一，位于王龙王国以北、通往西隆王国的途经国家。地理环境河流众多，气候适合水稻生长，沿途分布着广袤水田。受宗主国王龙王国的指示大面积种植水稻，产出的稻米（沙纳基亚米）大量输出至王龙王国市场。
  - 原文依据："到达西隆王国之前必须先通过两个国家。分别是沙纳基亚王国和齐卡王国，两国的立场都算是王龙王国的附属国。沙纳基亚王国很盛行种植稻米。或许是拥有适合的地理条件吧，顺着道路移动时，可以看到一整片的水田。这附近有很多河川……这里的米和我们在王龙王国吃到的东西相同，看样子是把此地栽种的作物输出到王龙王国的市场。因此，我决定称呼这种米为沙纳基亚米。……还有沙纳基亚王国的水田好像也是基于王龙王国的指示。身为附属国还真是辛苦啊。"
- 名称：齐卡王国
  - 内容：王龙王国的附属国之一，位于沙纳基亚王国以北、通向西隆王国的途经国家。受王龙王国强制要求盛行栽种开近白色花朵的油料植物（类似油菜）。该国主食亦为大米，且米质优于南方。
  - 原文依据："在齐卡王国，盛行栽种类似油菜的植物。从道路上也可以看到开着近白色花朵的整片花田。虽说是盛行，不过听说栽种这种植物似乎是王龙王国强制齐卡王国必须进行的事业……顺道一提，这国家的主食也是米。实际品嚐进行比较后，我发现越往北方，稻米的品质似乎就越高。"
- 名称：中央大陆北方诸小国
  - 内容：位于中央大陆北方的一群小国，目前长期处于战乱争战不休的状态。
  - 原文依据："然而很遗憾的是，目前中央大陆北方的诸小国依然争战不休。在这段状态下恐怕种不出好吃的稻米吧，真的非常遗憾。"
- 名称：维邦至西隆王国的旅途耗时
  - 内容：从王龙王国首都维邦出发，沿干道向北穿越沙纳基亚王国与齐卡王国抵达西隆王国，全程耗时约四个月。
  - 原文依据："这样的旅程持续了四个月。我们终于抵达西隆王国。"

## 二、组织与势力
- 名称：王龙王国
  - 内容：位列世界第三大国，是中央大陆南部的霸权大国，坐拥四个附属国。过去只是南部普通国家，借由夺取王龙山矿物资源迅速强盛。对附属国推行经济与农产产业强制命令（如指示沙纳基亚种稻、强制齐卡种油料作物）。国内文化包容开放，不拘泥于传统，类似大熔炉。
  - 原文依据："王龙王国是这世界第三大的国家，也是中央大陆南部的霸者，拥有四个附属国。过去这国家只是存在于中央大陆南部的众多国家之一，据说是因为打倒西北方王龙山的王者──王龙王卡夏库特，获得其地盘内的庞大矿物资源，才得以一口气登上强国之位。……尽管拥有各式各样的逸事，这国家却没有那么重视传统，反而给人一种类似美国的大熔炉感。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔力对材质处理的局限
  - 内容：魔术使用者（鲁迪乌斯）能够运用土魔术等修补石制或铁制物品，但无法依靠魔力来加工修整木材构件。
  - 原文依据："如果是石制或铁制的物品，我自己也多少能够修理，却没有办法靠魔力来处理木材。只能多给修理工一些钱，要求对方尽快修好。"
- 名称：土魔术塑形日用器皿
  - 内容：土魔术可细腻精准地随手制造日常用具与厨具餐具，如军用饭盒、炉灶、大碗、筷子、汤匙等。
  - 原文依据："还有用土魔术仔细制作的军用饭盒、炉灶……我把饭装进用土魔术制作的大碗里。……再举起用土魔术制造的筷子……顺便还做了汤匙给她"
- 名称：解毒魔术的日常食品应用
  - 内容：在生食未经现代卫生检测的禽蛋前，可先施加解毒魔术进行杀菌消毒/防毒处理，防止生食引起的胃肠问题或中毒。
  - 原文依据："接下来先非常仔细地把施加过解毒魔术的蛋打散……这里的蛋大概和能在日本吃到的生食用新鲜鸡蛋不同吧，之后不使用解毒魔术可能不太妙……"
- 名称：剑术流派分布（中央大陆南部）
  - 内容：王龙王国及维邦市的剑术道场以北神流与水神流居多，多为上级剑士开设针对儿童的基础道场。
  - 原文依据："此外，这个城市里有很多打铁铺与剑术道场。流派各有不同，但看起来北神流和水神流似乎比较多。我依去偷看一下道场的情况，很多地方的教导对象都是小孩。连道场主人都只有上级剑士水准的案例似乎也很多"

## 四、种族 / 生物
- 名称：王龙王卡夏库特
  - 内容：曾盘踞在王龙王国西北方王龙山的强大王者生物/龙王，被讨伐后其蕴藏的庞大矿物矿脉成为王龙王国崛起的基石。
  - 原文依据："据说是因为打倒西北方王龙山的王者──王龙王卡夏库特，获得其地盘内的庞大矿物资源，才得以一口气登上强国之位。"
- 名称：类似油菜的开花植物
  - 内容：齐卡王国大面积种植的经济农作物，开近白色花朵，主要用于压榨提炼食用油。
  - 原文依据："在齐卡王国，盛行栽种类似油菜的植物。从道路上也可以看到开着近白色花朵的整片花田。"
- 名称：斯佩路德族在中央大陆的社会反应
  - 内容：中央大陆社会虽普遍强烈排斥魔族，但对斯佩路德族的恐惧反而不如魔大陆剧烈（距离危机源遥远）。人们对斯佩路德族的辨识极度依赖绿色头发特征；当见到光头时多不以为意，但若提到恶魔之名或确认额头红宝石，仍会产生畏惧反应。
  - 原文依据："中央大陆上明明强烈排斥魔族，然而不知道为什么，对斯佩路德族的畏惧反而没有魔大陆上那么严重。……不是绿色头发的斯佩路德族就不算是斯佩路德族……如果你希望的话，也可以让你看看他额头上的宝石喔？……不……不，不必了。真抱歉，我没想到他是真货。原来还真的存在啊……所谓的斯佩路德族……"

## 五、物品 / 道具 / 武器
- 名称：四十八魔剑
  - 内容：散落于世界各地的传奇怪异魔剑群，其最初的发祥地为王龙王国。
  - 原文依据："这里还是散落于世界各地的四十八魔剑的发祥之地，也是北神英雄谭其中一节提到的地点。"
- 名称：大米（沙纳基亚米）
  - 内容：中央大陆南部产出的大米，外观微偏黄色，口感较干燥，杂味偏重，多用于炖饭和咸粥；越往北方的国家（如齐卡王国），出产的稻米品质越好。
  - 原文依据："那就是米。看起来有点偏黄，不过的确是米。……这里的米和我们在王龙王国吃到的东西相同，看样子是把此地栽种的作物输出到王龙王国的市场。因此，我决定称呼这种米为沙纳基亚米。……实际品嚐进行比较后，我发现越往北方，稻米的品质似乎就越高。"
- 名称：七星烧
  - 内容：近期在阿斯拉王国发明并风靡周边国家的炸肉料理（日式炸肉风格）。做法为将羊肉、猪肉或马肉裹上面粉或米粉调成的面衣，经高温油炸而成，外脆里嫩流出肉汁，通常佐以岩盐、干燥香草或地方秘传酱汁调味。制作受限于食用油产量，主要在产油丰富的国家流行。
  - 原文依据："从先前的王龙王国到齐卡王国的周遭一带，都在流行一种叫作「七星烧」的料理。拿肉去沾上面粉或米粉制成的面衣，再用高温油炸──简单来说就是日式炸肉。好像是最近在阿斯拉王国那边被发明出来而且大为流行的料理，风潮也影响到这区域。除了能取得大量食用油的国家，其他地方想实际制作似乎颇有难度，然而近邻诸国的食用油生产量很高，能吃到的机会也跟着变多。……虽说的确是肉，不过通常是羊、猪或是马肉。……有利用岩盐、乾燥香草、以及当地代代相传的酱汁等调味料来让味道产生变化……外表乾乾脆脆，咬下去却会冒出肉汁。"
- 名称：沙漏
  - 内容：民间与酒馆中使用的常见物理计时道具，可通过翻转次数来精确定量烹饪时间。
  - 原文依据："我翻转向酒馆老板借来的沙漏，加强火力。"

## 六、历史 / 传说 / 事件
- 事件名：王龙王国的兴起
  - 内容：王龙王国原本只是中央大陆南部的平庸小国之一，通过击溃并讨伐西北方王龙山的统治者“王龙王卡夏库特”，占有其巢穴领地内丰厚的海量矿产资源，借此跻身世界三大强国之列。
  - 原文依据："过去这国家只是存在于中央大陆南部的众多国家之一，据说是因为打倒西北方王龙山的王者──王龙王卡夏库特，获得其地盘内的庞大矿物资源，才得以一口气登上强国之位。"
- 事件名：《北神英雄谭》轶事
  - 内容：记载北神英雄传说的典籍，其中有一章节故事发生于王龙王国。
  - 原文依据："也是北神英雄谭其中一节提到的地点。"

## 七、社会规则 / 习俗 / 文化
- 内容：王龙王国的饮食习俗虽有大米，但习惯将其烹饪为西班牙炖饭（paella）或咸粥等适宜使用调羹食用的餐点，并无单吃纯白米饭的饮食风气。
  - 原文依据："这国家的餐厅会提供的餐点都是西班牙炖饭和咸粥那类便于使用汤匙食用的东西。和我追求的目标有点不同。我想吃的东西是白米饭。"
- 内容：冒险者公会的社会阶层挑衅风气：低等级（如C级）年轻冒险者容易对年纪轻轻升入A级的后辈产生敌意与嫉妒，常挑衅声称对方是靠同行强者带飞；而A级冒险者在公会内具有相当显著的注目度与声望。
  - 原文依据："看到艾莉丝年纪轻轻就升上A级，也有一些家伙算是存心想要找碴。那种人以C级程度的年轻人居多。他们会嚷着些：「你明明没有实力，是靠男人帮忙把层级拉上来的吧？」之类的言论来刁难，然后被艾莉丝一拳摆平。"
- 内容：米里斯宗教圈对魔族文化的排斥：在米里斯宗教圈势力辐射范围内，社会严厉排斥魔族，导致斯佩路德族形象的人偶在此区域完全无法推广销售。
  - 原文依据："毕竟只要还待在米里斯宗教圈的势力范围内，恐怕就无法把瑞杰路德的人偶模型推销出去。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯认为人神信中提及的“西隆王宫里的旧识”是指洛琪希，以为洛琪希目前仍身在西隆王国担任宫廷魔术师。
  - 原文是否暗示另有真相：是 / [存疑]（读者已知洛琪希在第5卷已离开西隆王宫出海寻找鲁迪乌斯一家，此时并不在西隆王宫；但鲁迪乌斯主观坚信洛琪希在西隆）。
  - 原文依据："「西隆王国就是那个吧？鲁迪乌斯你师傅所在的国家。」……没错，她应该在西隆。人神也说过要我寄信给旧识。我一开始还觉得旧识是指谁啊，后来才想到会和我书信往来的对象只有一个人。所以他的意思大概是要我找洛琪希帮忙吧。"
- 角色以为：鲁迪乌斯推想在首都维邦因马车故障被耽搁七天，可能属于人神暗中操纵命运以确保自己在特定时刻与受害的爱夏相遇。
  - 原文是否暗示另有真相：不明 [存疑]
  - 原文依据："那么，或许这次的马车故障事件也是命运操控之类所造成的结果。我猜想要是太急，恐怕也无法遭遇那个场面。"
