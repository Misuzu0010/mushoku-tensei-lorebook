# 第七话　「『妹妹兼侍女』诞生之日」 世界设定提取

## 一、地理与场所
- 名称：西隆王国边境分歧点城镇
- 内容：西隆王国境内的小城镇，设有旅社。此地是交通要冲，通往阿斯拉王国和米里斯神圣国的道路在此分道扬镳，鲁迪乌斯与莉莉雅、爱夏在此正式道别。
- 原文依据："这里是西隆王国某个小城镇里的旅社。通往阿斯拉王国和米里斯神圣国的道路在此地分歧为二。因此，我会在这里和莉莉雅她们道别。"

## 二、组织与势力
- 名称：阿斯拉王宫（后宫）
- 内容：莉莉雅曾经供职侍奉的王权核心场所。该处王侯贵族道德极其糜烂，充斥着大量拥有各种反常嗜好的贵胄（对女性分泌物等特殊癖好）。
- 原文依据："「要是连收藏内裤这种小事都觉得是变态，在阿斯拉王宫工作会变成什么样子呢……」「你说阿斯拉王宫吗？话说起来，你以前好像曾在后宫工作吧？」「是的。和那里相比，老爷跟鲁迪乌斯少爷根本不能算是变态。」……「总之，在阿斯拉的王侯贵族里，有许多人拥有反常的嗜好。和那些人相比，对憧憬对象的内裤有兴趣是很普通的事情。」"

- 名称：保罗搜寻队伍（冒险者公会联络网）
- 内容：保罗为了搜寻菲托亚领地失踪人口在各地冒险者公会铺设的人手与部下网络。遭难亲属若盘缠短缺可持线索前往公会联系寻求支援。
- 原文依据："「还有我会先给你一些盘缠，万一在半路上有可能不够用，请去冒险者工会寻找父亲大人的部下。」「了解了。」"

## 三、力量体系 / 魔法 / 技能
- 名称：大范围森林冰冻魔术
- 规则：鲁迪乌斯展现的高阶水/冰系魔术破坏力表现。当其全力施展时，能够将正在降暴雨的整片森林彻底冻结成冰。
- 原文依据："「对啊！鲁……饲主他很厉害喔！只要拿出真本事，就算是下着大雨的森林也会整个结冻！」「是利用魔术吗！真了不起！」"

## 五、物品 / 道具 / 武器
- 名称：木雕项链坠子（配皮绳）
- 说明：莉莉雅正式交付给鲁迪乌斯的十岁生日礼物。鲁迪乌斯为其穿上皮绳并贴身佩戴在脖子上，发誓绝不再放手。
- 原文依据："其中之一穿了皮绳挂在我的脖子上，另一个则是放进箱子里慎重保管。我绝对再也不会放手。「谢谢你送我这个坠子（和内裤）。」"

- 名称：鲁迪乌斯的旧护额
- 说明：鲁迪乌斯在魔大陆利卡里斯镇购买并长期佩戴的装备，吸附了长期旅行的汗水。在本章作为信物和理解的凭据转赠给妹妹爱夏。
- 原文依据："「这个护额是我持续使用的装备。」「为什么突然拿出这个？」「就把这东西送给你吧。」我把从怀里取出的护额递给爱夏。这是以前在利卡里斯镇购买的东西。虽然有在清洗，不过经常使用，大概吸了不少我的汗水。"

## 六、历史 / 传说 / 事件
- 事件名：鲁迪乌斯与爱夏相认与离别约定
- 内容：在边境分歧点城镇启程前，爱夏借故单独拉鲁迪乌斯至草丛，试探哥哥的人格与价值观。鲁迪乌斯向其解释收藏内裤等同于信徒珍藏崇拜对象的圣物，并赠送旧护额。爱夏在临上马车之际突然喊破鲁迪乌斯身份（「谢谢你，哥哥！我们约好了喔，以后要再见面！」），约定未来若与哥哥失散或无处可去便前去服侍他。
- 原文依据："丢下最后这句话后，爱夏立刻站了起来，冲向有三名护卫在等待的马车。……「再见，哥哥！我们约好了喔，以后要再见面！」马车走了。目送他们离开后，我也回到自己的马车。"

## 七、社会规则 / 习俗 / 文化
- 内容：**从属侍女的驯化与服侍文化**：侍女阶层（如莉莉雅）对其后代贯彻从属伦理，自幼灌输服侍指定主人（同父异母长兄）的职责，将身体发育程度（讨男性欢心、繁衍子嗣）作为衡量合格侍女的工具性标准；但新一代幼童对此展现出对自身意志的维护与抗拒。
- 原文依据："「鲁迪乌斯少爷，我从平日起就一直叮嘱爱夏，要求她将来必须服侍您。」……「我已经把自己知道的所有事情都教给女儿了。现在她虽然还很年幼，不过大概四年以后，就会成长为男性喜欢的好身材吧。」"、"「妈妈从平日就一直吩咐，说我将来必须服侍同父异母的哥哥。……我才不愿意！」"、"「你知道男人会喜欢的意思是什么吗？」「就是指会让人想生小孩的身材吧！」"

- 内容：**阿斯拉王侯贵族的癖好常态**：阿斯拉王国贵族社会充斥各种反常乃至怪异的性心理偏好，使得一般人眼中出格的收藏癖在宫廷侍从眼中反倒被视作稀松平常。
- 原文依据："「要是连收藏内裤这种小事都觉得是变态，在阿斯拉王宫工作会变成什么样子呢……总之，在阿斯拉的王侯贵族里，有许多人拥有反常的嗜好。和那些人相比，对憧憬对象的内裤有兴趣是很普通的事情。」"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯自以为成功隐瞒了真实身份，以“饲主”的假身份说服并哄骗了年仅六岁的爱夏。
- 原文是否暗示另有真相：是。爱夏早就通过直呼名字、同行同伴失言等破绽看穿了鲁迪乌斯的真实身份，装傻是为了亲自试探哥哥的为人是否正直可靠。
- 原文依据："爱夏睁着亮晶晶的双眼看我……「那，对于我说你是变态的事情，你没有生气吧？」「嗯，当然没…………咦？」……「谢谢你，哥哥！」……艾莉丝以没好气的态度开口：「什么嘛，果然还是露出马脚了啊。」……所以早就已经露馅了。那么……爱夏为什么要装作不知道？……她恐怕是想查清自己的哥哥到底是不是可以信赖的人物吧。"

- 角色以为：鲁迪乌斯在爱夏提出想随他一同旅行时，主观以为是莉莉雅在背后唆使女儿施展哀求战术。
- 原文是否暗示另有真相：是。完全是爱夏本人的试探计谋，莉莉雅并不知情也绝不可能同意。
- 原文依据："「是不是你妈妈要求你这样做？」……「不，妈妈不可能会答应。」"
