# 第四话　「神不存在」 世界设定提取

## 一、地理与场所
- 名称：西隆王国王宫（内部结构）
  - 内容：西隆王国的权力核心建筑，规模与阿斯拉王国边境领主府邸相仿。正门实行严格等级限制，仅限贵族出入；骑士随员及一般访客须绕经后门进入。后门内设有士兵警卫室（配长桌供士兵轮值休闲）。王宫深处最冷清的走廊尽头设有特制机关房间，地板为可翻落的下陷式陷阱机关；机关下方为约三坪大的地下密室，地面刻有发出微弱光芒的封魔结界魔法阵，用于秘密囚禁高威胁目标。
  - 原文依据："聊着聊着，我们到达王宫。看起来虽然相当大，却比不上利卡里斯镇的奇希里斯城和米里希昂的白之宫。而是和艾莉丝她家差不多的规模。……绕过王宫的外围，从像是后门的地方进入。「非常抱歉，正门是贵族专用。」……后门里有一个类似士兵警卫室的地方。……她并没有走上楼梯，而是来到走廊的底端，在位于最深处的房间前面停下脚步。……「丢下去。」然而随着男子的发言，我脚边的地板消失了。……此处是一个小房间，大概只有三坪左右吧。地面上画着魔法阵，正发出微弱的光芒。……脚边的地板在男子发令的同时崩塌，我也摔进类似落下型陷阱的地方。"
- 名称：西隆王都大街与临时奴隶市场
  - 内容：西隆王都的大街道路曲折繁复，部分路段狭窄至无法供马车交会，带有防范外敌入侵攻城的城防规划特色。大街旁的高台上设有公开拍卖奴隶的市场（因原本设于城内深处的常规奴隶市场日前因冒险者私斗受损而临时迁移至大街）。市场上奴隶（涵盖人族与兽族等）上身赤裸涂油展示，并由奴隶商人当街报出身家特长公开竞价（如起拍价金币三枚）；台下放置铁笼收押待售奴隶。
  - 原文依据："两人以略快的脚步通过马车来来往往的大街角落。这条大街弯来拐去，有时候还会出现狭窄到马车无法会车的路段。大概是为了因应敌国进攻的对策吧。……原来是面对大街的地方有个奴隶市场。在一个类似舞台的高台上，并排着好几个奴隶。其中三个是人族，一个是长着兔耳的兽族。两名男性，两名女性。无论男女都上半身赤裸，即使从远处也可以看出皮肤显得油油亮亮，或许是为了好看而被涂上了油。……听说之前在原本的奴隶市场那一带发生了冒险者之间的冲突，导致市场无法使用，因此暂时移到这个地方。"
- 名称：瓦夏瓦国
  - 内容：中央大陆的国家之一，奴隶商人口中提及出产强悍骑士战斗奴隶的国家。
  - 原文依据："「这家伙原本是瓦夏瓦国的骑士！是战斗用的奴隶！虽然态度有点狂妄，不过很有实力！从金币三枚开始喊价！」"

## 二、组织与势力
- 名称：西隆王国第七皇子禁卫队
  - 内容：隶属于西隆王国第七王子帕库斯·西隆的近身精锐护卫部队，地位明显高于王宫普通卫兵和正规军士兵（卫兵遇禁卫队骑士会肃立敬礼）。女性骑士金洁·约克为其成员之一，在西隆王国骑士序列中位列第十二名左右，其家属疑似被帕库斯扣押作为逼其服从的人质。
  - 原文依据："「在下是隶属于西隆第七皇子禁卫队的金洁・约克。」……金洁向门口卫兵轻轻点头致意后，门口卫兵立刻站直。她说过自己是禁卫队，想来比一般士兵伟大。……「金洁小姐的地位很高呢。」「我想自己在骑士中大概排行第十二名左右吧……」……「不行！去找！家人怎样都无所谓吗！」「……呜！我立刻派出搜索队。」"
- 名称：西隆王宫卫兵对魔实战体系（洛琪希训练体系）
  - 内容：洛琪希在西隆担任宫廷魔术师兼王子家庭教师期间，曾参与对王宫士兵的实战演训。王宫正规士兵多修习水神流中级剑术，经洛琪希在混战中施展魔术的高强度反射训练后，掌握了在突遭魔术奇袭时能够瞬间拔剑将其架开格偏的实战防御技巧。
  - 原文依据："「洛琪希老师在王宫里是负责做些什么事呢？」「她平常是负责教导王子，但有空时也会参加士兵们的演习。」……根据信件，训练的内容是要洛琪希在乱战状态下施展魔术，让士兵们想办法顺势挡开。……「正是如此。我等都是水神流的中级剑士，多亏有洛琪希大人的训练，现在才能在遭受魔术攻击时立刻举起剑来挡开。」"
- 名称：西隆王室派系（第七王子帕库斯派）
  - 内容：第七王子帕库斯·西隆虽缺乏政治远见但拥有王室专横特权，性格暴虐好色，执着于捕获洛琪希作为性奴隶生子；他利用职权秘密拘禁转移到王宫的莉莉雅和爱夏作为人质，并畏惧阿斯拉王国上级贵族（伯雷亚斯家族）的制裁，因而暗中行动。
  - 原文依据："「嘎哈哈哈哈！没用！没用的！那个魔法阵是我为了抓住洛琪希而让人制作的王级结界！凭你根本没有办法对付！」……「帕库斯！帕库斯・西隆！」……「本王子会把她当成性奴隶饲养一辈子，还会让她生下五个继承人！」……「要是我抓了莉莉雅和你的事情曝光，那个叫伯雷亚斯的贵族就会和我为敌吧！」"

## 三、力量体系 / 魔法 / 技能
- 名称：王级结界（封魔魔法阵）
  - 内容：帕库斯专为捕获水王级魔术师洛琪希而命人布置的高位阶魔法阵设施。刻画于密室地面，散发微弱光芒。阵内形成全封闭屏障，处于阵内的施术者即便向外输出庞大魔力，魔术也完全无法成形发动（土枪、土柱等均无效），且结界壁障坚韧，物理敲击完全无法损毁。
  - 原文依据："地面上画着魔法阵，正发出微弱的光芒。我反射性地想要使用魔术。……然而，魔术却没有发动。我再次灌注更强的魔力，想让脚边出现土柱，却依旧没有发动。真奇怪，明明确实有输出魔力……「这是……结界吗？」我试着把手伸向魔法阵边缘，结果碰到像是墙壁的东西。接着使劲敲打了一下，一点效果都没有。「嘎哈哈哈哈！没用！没用的！那个魔法阵是我为了抓住洛琪希而让人制作的王级结界！凭你根本没有办法对付！」"
- 名称：水神流反魔术剑术
  - 内容：水神流中级剑士通过特定训练培养的条件反射，能在敌方魔术（如突发岩炮弹）射来的一瞬间拔剑劈击，改变魔术弹道予以化解。
  - 原文依据："「我等都是水神流的中级剑士，多亏有洛琪希大人的训练，现在才能在遭受魔术攻击时立刻举起剑来挡开。」"
- 名称：治愈魔术治疗严重骨折
  - 内容：初级以上的治愈魔术能够在骨折发生后立刻使断骨愈合如初，迅速恢复肢体运动能力。
  - 原文依据："那时我立刻用治愈魔术治好骨折，不过真的很痛。"

## 四、种族 / 生物
- 名称：兔耳兽族
  - 内容：兽族分支亚种之一，头部生有长长的兔子耳朵，常被捕奴队自大森林等地掠夺贩卖。
  - 原文依据："其中三个是人族，一个是长着兔耳的兽族。……那个兽族是从大森林里被抓来的吗？"
- 名称：矿坑族
  - 内容：世界上的智慧种族之一，身形粗短敦实（被鲁迪乌斯用于形容矮壮体型）。
  - 原文依据："像是把小人族加矿坑族除以二的感觉。"

## 五、物品 / 道具 / 武器
- 名称：王级封魔结界魔法阵
  - 内容：刻画在地表的魔法阵设施，具有完全封锁阵内魔力构筑与施展的功能。
  - 原文依据："地面上画着魔法阵，正发出微弱的光芒。……「那个魔法阵是我为了抓住洛琪希而让人制作的王级结界！凭你根本没有办法对付！」"
- 名称：瑞杰路德人偶模型
  - 内容：鲁迪乌斯以土魔术手工精制的斯佩路德族玩偶手办，在米里斯宗教圈内不受欢迎，鲁迪乌斯随身置于道具袋中保存。
  - 原文依据："这时，我在道具袋的角落发现不受欢迎NO・1的瑞杰路德人偶模型。"
- 名称：日常洁具（木桶与肥皂）
  - 内容：民间旅社和家庭通用的清洁工具，包含洗衣专用木桶与清洁用肥皂块。
  - 原文依据："手边有洗衣用的木桶和肥皂"

## 六、历史 / 传说 / 事件
- 事件名：莉莉雅与爱夏的西隆王宫被拘事件
  - 内容：两年前菲托亚领地转移事件发生时，莉莉雅与爱夏直接被传送到西隆王宫内。因身份不明被拘留，随后第七王子帕库斯得知其与洛琪希的关系，遂将其软禁在王宫中作为诱捕洛琪希的诱饵，长达两年之久且严禁其与外界通信求援。
  - 原文依据："原来她们被转移到这国家的王宫。自然被当成可疑分子逮捕，不过莉莉雅说明各种情况后，结果好像就演变成前述被软禁在王宫里的下场。……拘留的名目大概随便用什么都行，例如宣称莉莉雅是别国间谍之类。然后，双方交谈之后，发现莉莉雅似乎和洛琪希认识的王子心生一计。那就是利用莉莉雅当诱饵，联络上洛琪希，想把她引来此地。"
- 事件名：洛琪希离去西隆王都
  - 内容：洛琪希因故离开西隆王都已达两年之久，第七王子帕库斯动用势力搜索两年仍未能寻获其下落。
  - 原文依据："「本王子已经找了两年但是找不到！不过迟早会找到！因为那女人很显眼！」"

## 七、社会规则 / 习俗 / 文化
- 内容：合法公开的奴隶贸易制度：中央大陆奴隶交易受法律允许与保护，存在专门的奴隶商人与竞拍体制。奴隶按技能与属性分为战斗奴隶、劳力奴隶等，通常在特定深巷市场交易，特殊情况下可在繁华大街公开竞标售卖。
  - 原文依据："原来是面对大街的地方有个奴隶市场。在一个类似舞台的高台上，并排着好几个奴隶。……虽然在这个世界里，奴隶本身似乎并不是坏事，然而这还是我第一次看到在面对大街的地方正大光明地开市。「是的，那种竞标通常是在更里面的场所举行。」"
- 内容：西隆王宫的出入门禁阶级森严：严格区分贵族与非贵族进出通道，正门严禁平民通行，即便是骑士引荐的客人也必须走后门。
  - 原文依据："金洁却往旁边转。她绕过王宫的外围，从像是后门的地方进入。「非常抱歉，正门是贵族专用。」"
- 内容：阿斯拉王国上级贵族的国际威慑：阿斯拉王国的大贵族（如伯雷亚斯家族）在国际上具有极强威慑力，诸如西隆王国的王族在侵犯与其有牵连的人员时，因畏惧外交纠纷或招致军事打击，必须竭力封锁消息进行秘密监禁。
  - 原文依据："「要是我抓了莉莉雅和你的事情曝光，那个叫伯雷亚斯的贵族就会和我为敌吧！」"
- 内容：女仆英才教育传承：莉莉雅对爱夏施加了高度专业化的贵族女仆英才教育，包括察言观色、伪装演技、利用孩童天真外貌引导他人同情协助等实用世故技巧。
  - 原文依据："「妈妈告诉我，像我这样的小孩只要从下面往上看着大人，然后说：『我想寄信给爸爸』，之后就算不付钱，对方也还是会帮忙。」……爱夏似乎从莉莉雅那里学到了各式各样的知识。包括一般常识、礼仪规矩、在生活中能派上用场的智慧，还有女仆的奥义……诸如此类。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯以为洛琪希仍在西隆王宫任教，只要面见洛琪希就能顺利自证身份并调解矛盾。
  - 原文是否暗示另有真相：是。客观事实是洛琪希两年前就已经离开西隆王都，根本不在王宫内。
  - 原文依据："「但是在那之前，请先叫洛琪希过来。我原本是她的学生，我要请洛琪希证明我的身分。」「洛琪希不在。」「你说……什么……」"
- 角色以为：帕库斯认为只要扣留鲁迪乌斯作为诱饵，洛琪希就会自投罗网，且全面封锁消息就不会引起阿斯拉贵族的干预。
  - 原文是否暗示另有真相：是。帕库斯逻辑矛盾混乱，既封锁所有消息不让外界知晓，又找不到洛琪希达两年之久，外界与洛琪希根本无从知晓鲁迪乌斯被捕。
  - 原文依据："「洛琪希那么优秀，想必会在哪个地方打听到情报！」「那个……是不是起码要做一些类似放出情报的动作会比较好呢？」「我在来到此地之前，完全没有查到任何关于莉莉雅的情报……洛琪希要用什么方法才能得知我被捕的消息？」"
- 角色以为：爱夏深信自己的哥哥鲁迪乌斯是一个毫无优点的变态（不仅偷看大人房事洗澡，还把家庭教师的内裤当成宝物藏在盒子里），因而极度不信任关于鲁迪乌斯的正面传说。
  - 原文是否暗示另有真相：是 / 否（鲁迪乌斯确实私藏洛琪希内裤并视若神明供奉，但其魔术天才与营救家人的决心亦是真实客观事实）。
  - 原文依据："「家里有个妈妈很重视的小箱子……里面放了什么？……是内裤，女生用的内裤……换句话说，我哥哥在四五岁时，就已经把显然比自己年长的女性的内裤当成宝物。……妈妈虽然帮忙隐瞒，不过我绝对没有弄错，哥哥他毫无疑问是个变态！」"
- 角色以为：西隆士兵向帕库斯通报抓捕爱夏的犯人是“一个自称为影月骑士，满身肌肉的高大男子，边狂笑边在屋顶上跳来跳去的变态”。
  - 原文是否暗示另有真相：是。实际犯人是十二岁少年鲁迪乌斯，士兵提供完全不符的虚假特征报告，暗示王宫基层士兵同情爱夏或对帕库斯阳奉阴违。
  - 原文依据："「根据报告，犯人是个自称为影月骑士，满身肌肉的高大男子。而且还是个边狂笑边在屋顶上跳来跳去的变态。」……喂喂！士兵……士兵先生，要确实报告啊！我哪里满身肌肉啊！不，不过实际上，说不定这是对方的善意。"
