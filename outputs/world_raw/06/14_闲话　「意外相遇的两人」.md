# 闲话　「意外相遇的两人」 世界设定提取

## 一、地理与场所
- 名称：克拉斯玛镇
- 内容：位于魔大陆西北角，繁荣程度仅次于利卡里斯镇。此地是支配该区域的魔王与海人族贸易的据点，汇集了海人族带来的各类海产以及魔大陆特产的强烈刺激性香草，能烹饪出极美味的结合料理，是魔大陆数一数二的美食之都（竞争对手是温恩港）。
- 原文依据："洛琪希・米格路迪亚到达克拉斯玛镇。克拉斯玛镇位于魔大陆的西北角。尽管比不上利卡里斯镇，但克拉斯玛镇也是个繁荣的城镇。乍看之下，这里似乎是那种没有任何特徵，感觉随处可见的无趣城镇。不过实际上支配附近一带的魔王和海人族颇有交情，双方互有贸易往来。而克拉斯玛镇正是这些贸易的据点，也是海人族物资与魔族物资都会汇聚而来的场所。海人族带来的各式海产，以及魔大陆特有的刺激性强烈的香草。在克拉斯玛镇可以品嚐到结合上述两种特产的超美味料理。这里可以说是魔大陆上数一数二的美食之都。顺便说一下，竞争对手是温恩港。"

- 名称：温恩港（补充）
- 内容：魔大陆港口城市，是克拉斯玛镇在魔大陆美食之都上的竞争对手；此前奇希莉卡曾在此偶然遇见鲁迪乌斯。
- 原文依据："顺便说一下，竞争对手是温恩港。"以及"「本宫曾在温恩港偶然遇上他，是个相当有趣的家伙！」"

- 名称：迷宫都市拉庞
- 内容：位于贝卡利特大陆的繁华迷宫都市。奇希莉卡通过魔眼确认失踪的塞妮丝正处于该都市（推测可能身处迷宫内部深处）。
- 原文依据："奇希莉卡板起脸发出唔唔声，把力量灌注到眼睛上。接着，她看到了。看到塞妮丝的所在地。『在贝卡利特大陆，迷宫都市拉庞……的样子。』"以及"「噢，对了！说不定对方是待在迷宫内部，毕竟那里是迷宫都市嘛。不过本宫倒是没去过。」"

- 名称：贝卡利特大陆
- 内容：迷宫都市拉庞所在的大陆。该大陆的迷宫内部充满高浓度的魔力，会阻碍魔界大帝魔眼的远距离探测。
- 原文依据："「您无法看到迷宫内部吗？」「嗯，因为贝卡利特大陆的迷宫里充满高浓度的魔力。」"

- 名称：奇希莉卡城
- 内容：在过去的拉普拉斯战役中存在的城堡，魔王巴迪冈迪曾在此城与魔神拉普拉斯交手并落败。
- 原文依据："在拉普拉斯战役中属于稳健派，在奇希莉卡城中和魔神拉普拉斯交手并败北。"

## 二、组织与势力
- 名称：支配克拉斯玛镇的魔王势力（掠夺魔王巴格拉哈格拉）
- 内容：统治魔大陆西北一带的魔王势力。巴格拉哈格拉与海族之王拥有私人私交，达成了物资贸易往来，并享有海族通航规矩下的默许个人通行特权。
- 原文依据："魔王巴格拉哈格拉是统治附近一带的魔王。是个长着猪脸，身材肥胖的魔王。据说在食物和酒类方面拥有魔大陆上最优秀的知识。原本属于稳健派，然而在拉普拉斯战役中却以急先锋的身分参加。由于从人族领地里把所有食物和酒类都搜括一空，因此获得「掠夺魔王」的称号。"以及"魔王巴格拉哈格拉和海族之王有个人交情……据说仅限个人朋友可以偷偷通过是一种受到默许的行为。"

- 名称：海族 / 海人族
- 内容：支配全世界所有海洋的强大种族势力。自拉普拉斯战役战后处理发生冲突后，对陆地各种族在海上的通行进行严格管制。拥有由海中魔兽拖曳的专属快船；海王与部分陆地魔王维持着私人私交。
- 原文依据："这世界的常识之一，是全世界的海洋都受到海族支配，居住于陆地的人们的海上通行受到限制。虽然起因是进行拉普拉斯战役的战后处理时发生了很多混乱争执，不过先姑且略过。魔王巴格拉哈格拉和海族之王有个人交情。虽说就算有交情也不能打破由海族全体制定的规矩，然而那是另一回事。据说仅限个人朋友可以偷偷通过是一种受到默许的行为。"

- 名称：不死身魔王巴迪冈迪势力 / 比耶寇亚地区
- 内容：巴迪冈迪是统治比耶寇亚地区的魔王，也是不死魔王阿托菲的弟弟、魔界大帝奇希莉卡的未婚夫。
- 原文依据："「不死身魔王巴迪冈迪」，是拉普拉斯战役中大显身手的「不死魔王阿托菲」的弟弟。在拉普拉斯战役中属于稳健派，在奇希莉卡城中和魔神拉普拉斯交手并败北。虽然现在行踪不明，但应该是个伟人。"以及"魔王巴迪冈迪这名号，是统治比耶寇亚地区的魔王。"

- 名称：魔族稳健派（历史政治派系）
- 内容：魔族在战乱时期的内部派系阵营。巴迪冈迪与巴格拉哈格拉在拉普拉斯战役前均属于稳健派。
- 原文依据："原本属于稳健派，然而在拉普拉斯战役中却以急先锋的身分参加。"以及"在拉普拉斯战役中属于稳健派，在奇希莉卡城中和魔神拉普拉斯交手并败北。"

## 三、力量体系 / 魔法 / 技能
- 名称：高阶魔眼「万里眼」
- 规则：魔界大帝奇希莉卡拥有的高级魔眼之一。能跨越无垠地理阻隔看到世界上远方的一切人和物；但若自身未恢复全盛实力，或者目标身处充斥极高浓度魔力的环境（如贝卡利特大陆的迷宫深处）中时，视线会被阻碍而看不清楚。
- 原文依据："之前曾经听说，如果是使用奇希莉卡拥有的高阶魔眼之一「万里眼」，这世上没有她看不到的事物。"以及"「不，嗯……有点看不清楚。」「看不清楚？就算使用陛下的眼睛也无法看清吗？」「毕竟本宫还没恢复原本状况啊……」「您无法看到迷宫内部吗？」「嗯，因为贝卡利特大陆的迷宫里充满高浓度的魔力。」"

- 名称：魔界大帝赏赐魔眼之能
- 规则：魔界大帝奇希莉卡具备向他人赋予赏赐魔眼的能力。正由于具备这种独一无二的能力，她才没有被止步冠以“魔王”称号而是被称为“魔界大帝（魔帝）”，并凭此获得了足以掀起人魔大战的巨大战力与号召力。
- 原文依据："魔界大帝赏赐的魔眼相当有名。正因为她拥有这种能力，魔界大帝才没有被称为魔王而是被称为魔帝，还获得足以引起人魔大战的战力。"

- 名称：解毒与治愈魔术解酒术
- 规则：解毒魔术可用于清除身体内部的酒精毒素以解除醉酒状态，随后配合对头部的治愈魔术可彻底消除宿醉头痛。
- 原文依据："猛烈疼痛的脑袋和自己充满酒臭味的口气让她皱起眉头。洛琪希立刻使用解酒用的解毒魔术来清除身体里的毒素，然后对头部施展治疗术。"

## 四、种族 / 生物
- 名称：海人族 / 海族
- 特征：支配全世界海洋的种族。酿造独特的甜酒；掌握利用海中魔兽拖曳船只的独门航海技术。
- 原文依据："海人族带来的各式海产……海族特有的甜酒倒是很不错……这是从很久以前就存在的海族船只。和人族船只相比，由海中魔兽负责拖曳的船只看起来虽然有点寒酸，实际上却比人族船只速度更快，也更安全。"

- 名称：矿坑族（生理特性补充）
- 特征：体格宽厚强健，毛发胡须浓密，天生极度嗜酒且酒量极为庞大，习惯用双手抱抱的整桶大酒牛饮；体质强悍到绝不会因为饮酒过量而丧命。
- 原文依据："矿坑族的塔尔韩德很喜欢喝酒……态度堂堂的塔尔韩德和高头大马的魔族男性各自抱住酒桶，咕嘟咕嘟喝了起来。虽说他的体型宽广，但真不知道那些酒到底是被喝进哪里。塔尔韩德把需要用双手才能抱住的酒桶喝乾之后……有一瞬间洛琪希还以为他死了，然而矿坑族不可能因为酒喝太多而死。"

- 名称：奇希莉卡・奇希里斯（魔界大帝生理与诅咒特征）
- 特征：魔界大帝。长着丰盈的紫色卷发以及类似山羊的双角，皮肤苍白，外表呈现为幼小少女形态，自述已存活三百年以上；体内受某种类似“诅咒”的制约，无法离开魔大陆，终日只能在魔大陆境内流浪徘徊。
- 原文依据："对方身穿及膝的长靴，皮制的热裤，还有皮制小可爱。肤色苍白，锁骨、腰部、肚脐、大腿全都裸露在外。头上是发量丰盈的紫色卷发，以及类似山羊的角。怎么看都比洛琪希年幼。「呼哈哈哈！愚蠢的矿坑族！别看本宫这种样子，其实已经活了三百年！短短二十年根本不会有任何影响！」"以及"「哎呀？那位大人不上船吗？」「嗯，奇希莉卡无法离开魔大陆！」「是吗？是诅咒吗？」「类似。」魔界大帝奇希莉卡无法离开魔大陆。因此，她只能日复一日地在魔大陆上徘徊。"

- 名称：不死身魔王巴迪冈迪（外貌与种族特质）
- 特征：身材高大魁梧的魔族，拥有黑曜石般的黑色皮肤，具备六只手臂（分上、中、下三层），紫色及腰长发。是不死魔王阿托菲的弟弟，拥有不死之身。
- 原文依据："直接推开门进来的人是一个身材魁梧的男性。对方拥有宛如黑曜石，让人一看就知道是魔族的肤色，还长着六只手臂。上层双臂环胸，中层伸出食指不客气地指向洛琪希，下层扠在腰上。长度及腰的头发则是紫色……「不死身魔王巴迪冈迪」，是拉普拉斯战役中大显身手的「不死魔王阿托菲」的弟弟。"

- 名称：掠夺魔王巴格拉哈格拉（生理外貌）
- 特征：长着猪脸、体型肥胖的魔王，拥有魔大陆关于美食与酒类最顶尖的丰富知识。
- 原文依据："是个长着猪脸，身材肥胖的魔王。据说在食物和酒类方面拥有魔大陆上最优秀的知识。"

- 名称：海中魔兽
- 特征：生活于海洋中的魔兽，被海族驯服并套上缆绳用于在海面牵引拖曳航海船只。
- 原文依据："和人族船只相比，由海中魔兽负责拖曳的船只看起来虽然有点寒酸，实际上却比人族船只速度更快，也更安全。"

## 五、物品 / 道具 / 武器
- 名称：海人族的甜酒
- 说明：海族特酿酒类。带有海潮芳香，入口时口腔充满浓郁甜味，吞咽后喉间留有一丝咸味，配下酒菜极其诱人开胃。在古早时期的魔大陆并未出现，是近代魔王与海族贸易带来的产物。
- 原文依据："对于认定酒这种东西基本上喝起来都会辣的洛琪希来说，甜酒带来了冲击。这酒闻起来有一股海潮的芳香，含进嘴里，会有一种难以言喻的甜味充满整个口腔。吞下之后虽然会留下一点咸味，不过这时搭配下酒菜反而更促进食欲。"以及"「不过呢，几百年以来酒也变得相当好喝了。以前的魔大陆上没有这种甜酒。」「似乎是海族的酒，听说是这边的魔王大人和他们进行交易。」"

- 名称：海族船只
- 说明：自古流传的海族专属航海船只，通过驯服的海中魔兽牵引航行。虽然视觉上比人族船只稍显简陋寒酸，但航行速度更快、遭遇海上危险的安全性更高。
- 原文依据："这是从很久以前就存在的海族船只。和人族船只相比，由海中魔兽负责拖曳的船只看起来虽然有点寒酸，实际上却比人族船只速度更快，也更安全。"

- 名称：魔大陆通货与物价
- 说明：魔大陆物价水准极其低廉，普通人纵情吃喝仅需一枚阿斯拉铜币即可买单；大额消费与赔偿使用绿矿钱（六枚即可抵消酒馆严重损毁与全场酒水消费）；小额零钱使用屑铁钱。
- 原文依据："洛琪希心想，这种时候会让人很庆幸魔大陆的物价便宜。毕竟不管吃喝多少，也只要一枚阿斯拉铜币就能结清。"以及"洛琪希从钱袋里拿出六枚绿矿钱，塞进老板手中。……这家店的酒都被我们喝光了……"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役战后海洋规矩确立
- 内容：拉普拉斯战役结束后，在进行战后处理协商时发生诸多冲突和纠纷，海族最终全面掌控世界海洋，确立了严格限制陆地种族海上通行的国际条约与规矩。
- 原文依据："这世界的常识之一，是全世界的海洋都受到海族支配，居住于陆地的人们的海上通行受到限制。虽然起因是进行拉普拉斯战役的战后处理时发生了很多混乱争执，不过先姑且略过。"

- 事件名：“掠夺魔王”巴格拉哈格拉参战
- 内容：原属稳健派的魔王巴格拉哈格拉在拉普拉斯战役中出任急先锋，进攻人族领地时搜刮洗劫了所有人族的美食与酒类，因此被冠上“掠夺魔王”的名号。
- 原文依据："原本属于稳健派，然而在拉普拉斯战役中却以急先锋的身分参加。由于从人族领地里把所有食物和酒类都搜括一空，因此获得「掠夺魔王」的称号。"

- 事件名：巴迪冈迪大战拉普拉斯

## 七、社会规则 / 习俗 / 文化
- 内容：海族海上通行禁令与默许特权潜规则：海族法律严禁陆地各种族擅自渡海；但海王与部分魔王私交甚笃，对于魔王的个人朋友偷偷搭船出海采取睁一只眼闭一只眼的默许态度。魔王巴迪冈迪借此带领艾莉娜丽洁直航中央大陆。
- 原文依据："虽说就算有交情也不能打破由海族全体制定的规矩，然而那是另一回事。据说仅限个人朋友可以偷偷通过是一种受到默许的行为。魔王巴迪冈迪和魔王巴格拉哈格拉是旧识。换句话说只要利用这层关系，即使不经由天大陆，要前往中央大陆也不是难事。"

- 内容：魔大陆酒馆纠纷与奴隶市场制裁：在魔大陆酒馆酗酒闹事造成财物损坏者，若无力当场足额赔偿损失，会被店家抓送至奴隶市场折价变卖。
- 原文依据："「总之你没钱吧？」「不，那个……抱歉，口袋空空……」「那么，只能把你卖去奴隶市场。」「什么！居然要把本宫卖了……！」"

- 内容：魔大陆结伴行动安全法则：由于魔大陆夜晚充满成群凶猛魔物，高阶魔术师即使战斗力高强，睡眠期间也防不胜防，因而必须至少两人组队同行以保安全。
