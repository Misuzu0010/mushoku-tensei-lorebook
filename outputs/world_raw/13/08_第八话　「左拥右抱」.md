# 第八话　「左拥右抱」 世界设定提取

## 一、地理与场所
- 名称：魔法都市夏利亚•中央广场
- 内容：夏利亚的中心广场。秋季收获期会在此举办收获祭，广场中央搭起高台并点燃营火，用收获作物熬煮大锅杂烩配酒分发给大家，人们围着营火感恩大地恩惠。发情期的兽族战士也会在此出没集结。
- 原文依据："由于即将举办收获祭，广场中央搭起一座高台。虽说是祭典，却只是在广场上点起营火，用收获的各种作物来煮成杂烩，然后和酒一起分享给大家而已。参加祭典的人们会围着营火，一边吃饭一边感谢大地的恩惠。除此之外并没有安排什么特别的节目，也不会唱歌跳舞。"、"魔法都市夏利亚只有在这个时期会出现如此喧嚣的气氛。另外，广场里到处可以看到兽族。都是一些拿着形似柴刀的大剑，外表壮硕骁勇的兽族。"

- 名称：魔法都市夏利亚•工房区
- 内容：夏利亚集中了众多魔道具工坊的街区。这里售卖许多由不熟练的魔道具制作师学徒制造的试作品（效果类似玩具但偶尔能淘到未来天才制作师的珍品），与商业区昂贵耐用的魔道具形成区分。
- 原文依据："首先从工房区开始，这里有许多魔道具。当然，商业区也有贩卖魔道具。不过几乎都是能够耐得住实用需求，虽然方便却很高价的商品。至于工房区，可以找到由技术还不熟练的魔道具制作师学徒所制作，等于还是试作品的东西。那些学徒的作品通常没什么大不了的效果，跟玩具没有两样。不过有时候也能挖掘出一些珍品，出自那种将来会被视为天才的制作师之手……以上是洛琪希提供的情报。"

- 名称：魔法都市夏利亚•商业区
- 内容：夏利亚的商业街区。设有高档服饰店以及售卖经久耐用、价格昂贵实用魔道具的店铺。高级服饰店不仅陈列日常便服，还备有正式洋装、高级长袍与全套童装。
- 原文依据："当然，商业区也有贩卖魔道具。不过几乎都是能够耐得住实用需求，虽然方便却很高价的商品。"、"我们移动到商业区，目的地是希露菲常去的服饰店。"、"虽说是童装，不过从平常穿的便服到长袍、正式洋装都有，种类很丰富。"

- 名称：魔法都市夏利亚•旅馆区
- 内容：聚集了许多冒险者的街区。傍晚时分，结束迷宫探索的冒险者会带着战利品归来，缺钱者也会在此出脱变现物品，因此偶有珍品流出；区域内还分布着服务不同阶层冒险者的旅馆与酒馆。
- 原文依据："最后，我们来到聚集了许多冒险者的旅馆区。因为逛了好几个地方，时间已经来到傍晚。到了这个时段，结束迷宫探索的冒险者们会带着战利品回来。另外，缺钱的冒险者也会趁着这段时间卖掉手上东西来变现。因此有时候可以找到一些珍品。"

- 名称：服务S级冒险者的高级旅馆
- 内容：位于夏利亚旅馆区的高级旅馆，艾莉娜丽洁向希露菲与洛琪希推荐的约会与和好场所。设施完备，料理美味，附设一楼酒馆，提供大床与极佳的隔音效果。
- 原文依据："目标是一间服务S级冒险者的旅馆，也是艾莉娜丽洁建议我可以作为约会最后一站的地方。这间高级旅馆的食物好吃，气氛良好，床铺很大，还有隔音也很好。"、"因此，我们决定先前往一楼的酒馆用餐。毕竟这里是一间料理也很美味的旅馆。"

- 名称：北方大地
- 内容：夏利亚所处的广域地理区域。气候与物产受限，平时食物价格较高且收获量少，居民日常通常粗茶淡饭；唯有秋季收获期食品新鲜美味且便宜；在北方大地极难吃到费工的甜点。
- 原文依据："北方大地的食物价格很高，收获量也不多。因此平常都粗茶淡饭，但是目前正当食料丰富的季节，这里又是高级旅馆。"、"或许因为这阵子是收获期，街上相当热闹。马车来来去去，贩卖蔬菜水果的摊商脸上也堆满笑容。这个时期的食品不但便宜，而且新鲜又美味。"、"「真是太棒了，北方居然也能吃到这种东西！」"

- 名称：米里斯神圣国
- 内容：鲁迪乌斯曾造访过的国度，其饮食文化中拥有制作精巧、工序费繁的甜点。
- 原文依据："虽然有甜点，和以前在米里斯神圣国吃过的费工甜点还是不太一样。"

## 二、组织与势力
- 名称：魔法大学
- 内容：夏利亚的核心魔法学府。在兽族发情期时，来自各地的兽族战士与追求者以魔法大学为目标集结，企图在此向就读的莉妮亚和普露塞娜挑战求婚。
- 原文依据："这个时期似乎正好碰上莉妮亚和普露塞娜的发情期，认为自己才是最佳人选的勇者们以魔法大学为目标，从各地集结至此。"、"商人很忙，兽族战士们正匆匆赶往魔法大学"

- 名称：宫廷魔术师
- 内容：国家或王室雇佣的高阶魔术师阶层。洛琪希曾担任过此职，享有丰厚薪资与社会地位，出入高级服饰店等高档消费场所。
- 原文依据："「我绝对没有指责希露菲太浪费的意思。以前担任宫廷魔术师的时候，我自己也会利用这样的店。」"

- 名称：冒险者公会 / 冒险者群体
- 内容：公会对冒险者进行分级认证（提及S级与A级），评级代表社会与实力门槛；冒险者平日深入迷宫探索获取战利品，傍晚在旅馆区变现，日常服装多偏好廉价耐磨款式。
- 原文依据："目标是一间服务S级冒险者的旅馆"、"莉妮亚和普露塞娜开出的条件是剑术必须圣级以上，魔术必须上级以上，冒险者不满A级者就不合格"、"不过那充其量只是因为我平常都购买冒险者基准的廉价服装。"

## 三、力量体系 / 魔法 / 技能
- 名称：等级评定体系（剑术与魔术）
- 规则：剑术存在“圣级”以上等级划分；魔术存在“上级”以上等级划分。这些等级是衡量战力强弱的公认通用标准。
- 原文依据："莉妮亚和普露塞娜开出的条件是剑术必须圣级以上，魔术必须上级以上，冒险者不满A级者就不合格"

- 名称：魔道具技术与制造体系
- 规则：魔道具通常只要注入魔力即可引发内部预设的效果（如注入魔力使内容物结冻）。魔道具的制造有专门的制作师与学徒，分为试作品、玩具级与实用高档品；制作水平差异巨大，顶级天才制造的作品具有极高实用与收藏价值。
- 原文依据："至于工房区，可以找到由技术还不熟练的魔道具制作师学徒所制作，等于还是试作品的东西。那些学徒的作品通常没什么大不了的效果，跟玩具没有两样。不过有时候也能挖掘出一些珍品，出自那种将来会被视为天才的制作师之手"、"「这个只要注入魔力就会让里面食物结冻的锅子或许可以送给爱夏。」"

- 名称：魔力附加品
- 规则：通过魔法工艺赋予特殊性能的装备与物品。价格极其昂贵，非一般平民必需品；高级官员或王室侍从的工作服常属于此类防具或装备。
- 原文依据："不过魔力附加品都很高价，而且老实说根本不是必需品。"、"而且就算出了什么事，希露菲的工作服几乎都是魔力附加品。"

## 四、种族 / 生物
- 名称：兽族
- 特征：外表壮硕骁勇，生有动物的耳朵与尾巴，皮毛外观是其择偶重要指标；多携带形似柴刀的大剑；生理上具有周期性的“发情期”（本章对应秋天收获期）；适龄期有求偶传统习俗，求偶者会前往决斗迎战以争取结婚资格；审美看重皮毛柔顺亮丽、耳尾傲立、性格兼备狂野与绅士。
- 原文依据："另外，广场里到处可以看到兽族。都是一些拿着形似柴刀的大剑，外表壮硕骁勇的兽族。因为兽族也算是在举办祭典。这个时期似乎正好碰上莉妮亚和普露塞娜的发情期，认为自己才是最佳人选的勇者们以魔法大学为目标，从各地集结至此。莉妮亚和普露塞娜好像也觉得差不多该找个夫婿了，听说今年会正面迎战这些人。然而两人并没有按照传统规则行事，而是宣称会从打赢她们的对手中挑选。莉妮亚和普露塞娜开出的条件是剑术必须圣级以上，魔术必须上级以上，冒险者不满A级者就不合格；还要毛皮柔顺漂亮，个性狂野却又绅士，耳朵和尾巴都傲然竖起的男性。"

- 名称：米格路德族（魔族）
- 特征：魔族的一支（洛琪希所属种族）。身材娇小，成年后外观仍长久保持少女形态；洛琪希对甜点表现出极其强烈的喜爱与感动，鲁迪乌斯推测该族可能普遍喜好甜食[存疑]。
- 原文依据："看到甜点，最开心的人是洛琪希。她睁着兴奋到发亮的双眼，把甜点连连送进嘴里。是我家师傅自己喜欢甜食吗？还是米格路德族都喜欢甜食？"

- 名称：黑色公牛
- 特征：北方大地出产或供给高级餐馆的肉牛生物，油脂肥美，在高级旅馆配以大量辛香料煎烤为牛排供应。
- 原文依据："洒满了辛香料，油脂肥美的黑色公牛牛排。"

- 名称：犰狳（犰狳次郎）
- 特征：小型带甲生物，鲁迪乌斯家中饲养的宠物，前额平坦可供涂写。
- 原文依据："最后大概只能在犰狳次郎的额头写上「保时捷」几个字充数。"

## 五、物品 / 道具 / 武器
- 名称：结冻锅（魔道具）
- 说明：工坊区学徒制作的魔道具之一，只要注入魔力即可让放入锅内的食物结冻。
- 原文依据："「这个只要注入魔力就会让里面食物结冻的锅子或许可以送给爱夏。」"

- 名称：魔术师长袍与帽子
- 说明：魔术师的专属装束。高档款式的帽子价格昂贵；洛琪希日常使用的黑色帽子伴随其从布耶纳村历经多次战斗，缝线多有脱落破损。
- 原文依据："她注意到一件长袍，那是被特别展示出来的魔术师用长袍和帽子。……那顶帽子已经很旧了，是不是从她待在布耶纳村那时一直使用至今？虽说还不到破破烂烂的地步，缝线脱落的开口却显示出这帽子经历过许多场战斗。不过因为是黑色帽子，那些受损部分并不是那么显眼。洛琪希重新戴好帽子，然后慢慢踮起脚尖，拿下店内陈列的帽子。她把帽子翻来覆去地看了一阵，注意到价钱标签后表情有点扭曲，立刻把帽子放回原位。"

- 名称：魔法剑士风格服装
- 说明：适合冒险者行动的轻便服饰，手肘部分附带护具，常搭配斗篷穿戴，适合身材苗条的初阶冒险者。
- 原文依据："是魔法剑士风格的服装，手肘部分装有护具。或许少了点优雅，不过希露菲穿起来很像刚踏入这一行的新人冒险者"

- 名称：形似柴刀的大剑
- 说明：兽族战士普遍携带的沉重大剑，外形类似大砍柴刀。
- 原文依据："都是一些拿着形似柴刀的大剑，外表壮硕骁勇的兽族。"

- 名称：七星的卷轴
- 说明：七星提供给鲁迪乌斯的魔法卷轴，鲁迪乌斯能借此持续获取版税收入补贴家计。
- 原文依据："目前维持家计的资金共有希露菲的收入、洛琪希的收入、靠七星给的卷轴所获得的版税，还有探索迷宫的报酬等四项来源。"

- 名称：收获祭杂烩
- 说明：收获祭时在广场大锅中以各种秋季新收获农作物混合炖煮的免费浓汤/乱炖，民众自备锅具即可盛取，但因食材混杂味道参差。
- 原文依据："用收获的各种作物来煮成杂烩，然后和酒一起分享给大家而已。……顺便说一下，只要拿着锅子过来，似乎就可以领到免费的杂烩。听说去年我不在的时候，爱夏就有去领过。她说因为什么都丢进去煮，其实不太好吃。"

- 名称：辛辣炖煮河鱼汤
- 说明：北方高级旅馆提供的精巧料理，味道带辛辣感，疑采用油腌芥子等香料调味。
- 原文依据："口味有点辛辣的炖煮河鱼汤"、"「这个汤很好喝，不知道用了什么调味。」「是不是放了用油腌过的芥子……？」"

- 名称：类苹果蜜饯甜点
- 说明：北方高级旅馆供应的罕见甜点。以极酸的类苹果本土水果切成适口小块，浸润在浓稠糖浆（类似蜂蜜）中，风味近似蜜饯或水果鸡尾酒。
- 原文依据："主要材料是跟苹果很像的水果。我吃过这东西，比前世的苹果酸很多。这种水果被切成一口大小，然后泡进类似蜂蜜的浓稠糖浆里。吃起来的味道类似蜜饯，也有点像水果鸡尾酒，还满好吃的。"

- 名称：类似威士忌的美酒
- 说明：高级旅馆酒馆供应的高品质烈酒，带有芳醇酒香。
- 原文依据："散发出芳醇酒香，类似威士忌的美酒。"

## 六、历史 / 传说 / 事件
- 事件名：夏利亚收获祭
- 内容：秋季作物丰收时在夏利亚举办的传统庆典。广场点起营火烹制大锅杂烩分发民众并佐以美酒，共同感恩大地恩惠，无特殊歌舞娱乐。
- 原文依据："由于即将举办收获祭，广场中央搭起一座高台。虽说是祭典，却只是在广场上点起营火，用收获的各种作物来煮成杂烩，然后和酒一起分享给大家而已。参加祭典的人们会围着营火，一边吃饭一边感谢大地的恩惠。除此之外并没有安排什么特别的节目，也不会唱歌跳舞。"

- 事件名：兽族选婿骚动
- 内容：秋季恰逢莉妮亚与普露塞娜的发情期，各地兽族勇者涌入夏利亚意图求娶；两人打破传统规则，自行开出圣级剑术、上级魔术、A级冒险者且外貌性格极高的要求，并宣称必须打赢她们才考虑入选。
- 原文依据："这个时期似乎正好碰上莉妮亚和普露塞娜的发情期，认为自己才是最佳人选的勇者们以魔法大学为目标，从各地集结至此。莉妮亚和普露塞娜好像也觉得差不多该找个夫婿了，听说今年会正面迎战这些人。然而两人并没有按照传统规则行事，而是宣称会从打赢她们的对手中挑选。莉妮亚和普露塞娜开出的条件是剑术必须圣级以上，魔术必须上级以上，冒险者不满A级者就不合格；还要毛皮柔顺漂亮，个性狂野却又绅士，耳朵和尾巴都傲然竖起的男性。"

- 事件名：转移迷宫探索与保罗遗产
- 内容：鲁迪乌斯一行此前在转移迷宫救人与探索所获得的丰厚报酬及保罗留下的财产，数额极其庞大，足以供其全家游手好闲生活三十年。
- 原文依据："尤其是最后那项「探索迷宫的报酬」也可以说是保罗的遗产，金额大到足以让我们过上三十年游手好闲的日子。"

## 七、社会规则 / 习俗 / 文化
- 内容：十岁生日庆祝习俗。在当地文化中，十岁生日被视为人生的一大重要成长节点，长辈或亲属通常会精心选购服装（大衣、靴子、洋装等）作为正式生日贺礼并举行庆生会。
- 原文依据："「想挑选送给十岁孩子的生日礼物。」「原来如此，那么请往这边走！」……十岁生日算是人生的大事，想必有很多人会购买衣服吧。"、"我们决定私底下偷偷准备庆生会，给她们一个惊喜。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯自认为左拥右抱带着希露菲和洛琪希走在大街上，会成为全城男性投来极度羡慕嫉妒恨目光的焦点。
- 原文是否暗示另有真相：是。路人各忙各的，商人和学生匆匆而过，几乎没有多少人投来特别注视。
- 原文依据："这些羡慕的眼神真是让人心里舒畅！我抱着这种想法观察周遭，却发现商人很忙，兽族战士们正匆匆赶往魔法大学；学生看了这边一眼，不过随即转开视线。冒险者也一样，在酒馆里还可以另当别论，但是他们并没有闲到会在大街上喝起倒彩。看样子注意到我们的人比想像中还少得多。"

- 角色以为：洛琪希认为该服饰店过于奢华高级而感到不安畏缩；希露菲因常陪伴爱丽儿出入，将其视作普通标准的服装店；鲁迪乌斯因习惯了冒险者的廉价地摊货，也主观觉得偏贵。
- 原文是否暗示另有真相：是。各人的消费基准由自身长期生活的环境决定（宫廷侍从 vs 冒险者 vs 贫寒魔术师），在目前格雷拉特家充裕的经济状况下该店价格完全属于合理负担范围。
- 原文依据："看到这间店的规模，洛琪希有点畏缩。……「咦？有高级到那样吗？」希露菲不解地歪了歪头。……「不，以格雷拉特家的经济状况来看，应该没有问题。只是我平常很少出入这种水准的店，所以才会有那种感觉。」"、"老实说，以我的的基准来看，衣服开价到这种价位确实有点偏高。不过那充其量只是因为我平常都购买冒险者基准的廉价服装。"

- 角色以为：莉妮亚和普露塞娜认为可以按照她们开出的严苛条件（剑术圣级、魔术上级、冒险者A级以上、外貌皮毛优秀、性格兼具狂野与绅士）挑到夫婿。
- 原文是否暗示另有真相：是。鲁迪乌斯明确指出这套条件“未免太过不切实际”，普通兽族勇者极难同时兼备如此高阶的复合条件。
- 原文依据："莉妮亚和普露塞娜开出的条件是剑术必须圣级以上，魔术必须上级以上，冒险者不满A级者就不合格；还要毛皮柔顺漂亮，个性狂野却又绅士，耳朵和尾巴都傲然竖起的男性。老实说我觉得未免太过不切实际。"

- 角色以为：鲁迪乌斯猜测米格路德族是否全族都喜欢甜食。
- 原文是否暗示另有真相：不明 [存疑]。原文仅展现洛琪希个人对甜点极度感动与喜爱，未证实是其个人口味还是种族生理特征。
- 原文依据："看到甜点，最开心的人是洛琪希。她睁着兴奋到发亮的双眼，把甜点连连送进嘴里。是我家师傅自己喜欢甜食吗？还是米格路德族都喜欢甜食？「真是太棒了，北方居然也能吃到这种东西！」"
