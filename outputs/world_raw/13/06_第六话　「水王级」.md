# 第六话　「水王级」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚魔法大学体育仓库
  - 内容：魔法大学角落的一处仓库设施，被某个学生称为体育仓库，前方通道常有学生与行人经过。
  - 原文依据：「在被某个学生称之为体育仓库的仓库前方。」「虽然这里是体育仓库前方，不过还是有不少行人。」
- 名称：夏利亚郊外（支流、农田与荒野）
  - 内容：夏利亚周边的郊外区域。右侧有一条小河，为夏利亚旁主河流的支流，河水清澈有鱼；左侧为空无一物的平原与森林。属于北方大地，但特定季节处处绿意。沿途先前分布有薯田和麦田，深入后变为完全没有人烟的广阔野地。
  - 原文依据：「我们目前来到郊外。右边是一条清澈的小河，左边可以看到空无一物的平原和森林。即使是北方大地，这个季节也是处处绿意。先前还有看到薯田和麦田，现在只剩下什么都没有的广阔野地。我不确定究竟移动了多久，不过看样子已经来到没有人烟的地方。河里的鱼在阳光照耀下反射出熠熠光芒。这条小河是夏利亚旁边那条河川的支流。」
- 名称：阿斯拉王宫（提及）
  - 内容：阿斯拉王国的王宫。希露菲转移事件后曾降落至其上空并在此担任护卫术师；宫廷中蓄养有被称为最高级的好马（如骑士团长的坐骑）。
  - 原文依据：「我只是在阿斯拉王宫里见过几匹被称为最高级的好马，例如骑士团长的坐骑之类……」「她不幸被转移到阿斯拉王宫的上空，驱使魔术之后总算成功降落。」

## 二、组织与势力
- 名称：魔法大学学生会
  - 内容：魔法大学内的学生自治与治安组织，干部包括路克与「沉默的菲兹」，负责受理报案与调解校内纠纷（如调查鲁迪乌斯施暴传言）。
  - 原文依据：「『学生会来了！』这时，被称为校内第一美男子的男性来到现场。戴着太阳眼镜的白发少女也跟在他后面一起前来……这两人是学生会的干部，路克和菲兹。」「『有人报案说鲁迪乌斯正在对女学生施暴……』」
- 名称：阿斯拉王国骑士团（提及）
  - 内容：阿斯拉王国的正规骑士武装编制，骑士团长配备有最高级别的良马坐骑。
  - 原文依据：「我只是在阿斯拉王宫里见过几匹被称为最高级的好马，例如骑士团长的坐骑之类……」

## 三、力量体系 / 魔法 / 技能
- 名称：水王级攻击魔术「雷光」（Lightning）
  - 规则：
    1. 体系归属：属于水系统攻击魔术的王级分类（该世界不存在独立的电击魔术分类，雷电属于水系魔术）。
    2. 施法咒文：咒语分为两阶段。前半段借用并咏唱水圣级「豪雷积雨云」的咒文构筑雷云大雨环境：「雄伟的水之精灵，登上天空的雷帝之王子啊！实现我的愿望，带来凶暴的恩惠，让矮小的存在见识您的力量！以神之铁锤敲击铁砧，显现您的可畏，让洪水淹没整片大地！啊，雨啊！冲垮一切，驱逐所有事物吧！」；后半段紧接着咏唱压缩收束咒文：「雄伟的光之精灵，支配天空的雷帝啊！您是否看见屹立之者！那是傲慢的雷帝之敌！吾欲手持神圣之剑，化为一击打倒仇敌之人！将以光辉闪耀之力，展现雷帝之威仪！」，最终呼喊魔术名「『雷光』！」。
    3. 运作神髓：神髓在于「把魔力压缩集中」的步骤。在空中展开大量魔力制造雷云，在魔力尚未安定时以蛮劲强行抑制并推进至下一阶段集中压缩，将翻搅的黑色云层压缩至仅如豆子般大小，正下方破开孔洞射出通往地面的光柱闪电。施法完毕后天空乌云与大雨瞬间散尽，恢复晴朗蓝天。
    4. 威力与消耗：威力居于已知魔术首位，能将粗大巨树彻底湮灭化为黑点焦炭，推测威力超越蓄力到最高值的岩炮弹。魔力消耗极大，水王级魔术师洛琪希借助魔杖全力施展一次即达魔力极限脱力倒地，且自称五次也会失败一次；希露菲因无法成功压缩魔力而施放失败并耗尽魔力。
    5. 无咏唱转化：只要经历过一次完整咏唱并理解控制原理，即可通过无咏唱方式再次施展。
  - 原文依据：「我会传授水王级魔术『雷光』。」「话说回来，Lightning吗……如果光听名字，感觉是常见的电击魔法。然而仔细想想，这个世界并没有电击魔术这种东西。不仅如此，这还是王级魔术。」「『雄伟的水之精灵，登上天空的雷帝之王子啊！实现我的愿望，带来凶暴的恩惠，让矮小的存在见识您的力量！以神之铁锤敲击铁砧，显现您的可畏，让洪水淹没整片大地！啊，雨啊！冲垮一切，驱逐所有事物吧！』……『雄伟的光之精灵，支配天空的雷帝啊！您是否看见屹立之者！那是傲慢的雷帝之敌！吾欲手持神圣之剑，化为一击打倒仇敌之人！将以光辉闪耀之力，展现雷帝之威仪！』……『雷光』！」「从被压缩的乌云里，射出一道通往地面的光柱。那是闪电。」「因为以我的魔力，就算借助魔杖也只能使用一次就达到极限……比起我的事，你有看清楚『雷光』吗？」「要是在这里让魔术完成，恐怕就无法进行那种压缩。要在魔力尚未安定的情况下，推进到下一阶段才行。每咏唱出一个字，都可以感觉到魔力变得更加狂暴。我强行抑制魔力，拚命地压缩集中。这是一种需要蛮劲的招式，必须以力量来驾驭的魔术。」「『雷光』。这个魔术的原理很简单。在空中展开大量魔力，然后进行压缩，击向指定的场所。制造出雷云，让闪电劈落。就只是这样。如此想来，『豪雷积雨云』和『雷光』可以说是成套的魔术。在至今的魔术中，『雷光』拥有居于首位的威力。毕竟是把我知道的最耗魔力魔术『豪雷积雨云』的能量集中到一点上，这也是理所当然的结果。说不定威力甚至能超越蓄力到最高值的岩炮弹。」「虽然名字叫作『雷光』，不过这个魔术的神髓在于『把魔力压缩集中』的步骤。说不定其他王级魔术也可以基于相同原理来操控。不管怎么样，自己只要咏唱过一次咒语，以后就能够以无咏唱方式来再次使用。」
- 名称：水圣级攻击魔术「豪雷积雨云」
  - 规则：在空中大范围制造雷云、引发狂风暴雨与落雷的水圣级魔术，是水王级「雷光」的前半段基础构筑。
  - 原文依据：「整片天空突然乌云密布，迅速转为漆黑。同时，现场下起倾盆大雨。从侧面吹来的狂风吹袭肆虐，瞬间让我的长袍整个溼透。空中到处都是闪电，感觉随时会化为落雷。但是，这只是──水圣级的攻击魔术『豪雷积雨云』。」「她失败了一次，然后成功使出水圣级魔术『豪雷积雨云』。」
- 名称：原创魔术「电击」（鲁迪乌斯命名）
  - 规则：鲁迪乌斯以「雷光」原理进行改良的微型派生魔术。以无咏唱方式制造微型「豪雷积雨云」，经压缩后朝着指定地点释放微型「雷光」形成电流放电。电压较低，不致死，主要作用为短时间内麻痹神经使对手无法动弹。击向物体难以回避；但若在施术者近身释放会波及自身引发触电麻痹；鲁迪乌斯推测该招式对身体缠绕斗气的对手可能同样有效。
  - 原文依据：「只要以无咏唱方式制造出小型的『豪雷积雨云』，压缩后朝着指定地点放出『雷光』，就会有电流击出。而且或许是因为电压较低，明明是在放电，威力却没那么高。我并不明白其中的运作原理，不过这样正合我意。然而就算威力较低，一旦在自身附近使用，还是会惨遭波及而触电。只是并不致死，顶多是一段时间以内会麻痹到无法起身的程度。因为这类攻击魔术会波及到自身，实在太危险而无法派上用场。不过，还是多练习一下吧。如果想让对手无力抵抗，这是不错的技能。毕竟电流会击向物体所以难以回避，而且用电流来麻痹神经的攻击说不定对那种身上缠有斗气的对手也有效。目前没有实验对象，等到巴迪冈迪回来，再拜托他让我试试吧。这招或许能成为关键场面的王牌。顺便说一下，这个魔术虽然是小型的『雷光』，不过为了区别，我另外命名为『电击』。」
- 名称：魔力总量锻炼法则与特异体质
  - 规则：自幼年（两三岁）起频繁使用魔术可锻炼增加魔力总量，但鲁迪乌斯的超庞大魔力量主要归因于其特殊的特异体质。希露菲的魔力总量在客观上高于洛琪希，而洛琪希的魔力总量也绝对不算少。
  - 原文依据：「只是这次比较后可以发现，看来希露菲的魔力比洛琪希多。明明洛琪希的魔力总量也绝对不算少。」「自己确实从两三岁时开始使用魔术，努力增加魔力总量至今。然而能增加到这种程度，想必是因为我拥有特异体质。虽然有努力，但也算是开了外挂。」
- 名称：斗气（提及）
  - 规则：近战战士身上缠绕的防御与强化能量，推测可能被具有神经麻痹特性的电流穿透影响。
  - 原文依据：「用电流来麻痹神经的攻击说不定对那种身上缠有斗气的对手也有效。」
- 名称：土堡（土魔术防御）
  - 规则：运用土魔术在地面构筑圆顶状的土质堡垒，可提供物理防护遮蔽，抵御暴雨与雷电。
  - 原文依据：「『松风要是感冒就不好了，请用土堡把它围起来。』『明白。』我按照洛琪希的指示，用土堡围住松风。松风没有抵抗，乖乖躲进土制的圆顶堡垒中。」

## 四、种族 / 生物
- 名称：马匹（松风、卡拉瓦乔）
  - 特征：常规陆行骑乘动物。鲁迪乌斯家的宠物马「松风」性格听话温驯、力气大，可同时承载三人长途行进，具备一定灵性（能对主人的日常对话及安抚做出嘶鸣回应）；保罗过去的坐骑马「卡拉瓦乔」曾遭雷击重创后顽强生还；阿斯拉王宫中备有骑士团长等高层专用的最高级好马。
  - 原文依据：「『松风是很棒的马呢。既听话又温驯，而且力气很大。』……我家最常被丢着不管的宠物──马匹松风虽然驮着三个人，依然毫不在意地踩着强而有力的步伐前进。『我记得是金洁小姐帮忙选的吧？那个人选马的眼光很好。』」「『噢，抱歉，当然松风也很优秀。因为你可是格雷拉特家的马。』洛琪希赶紧安抚松风。这里的马能够听懂人话吗？还是洛琪希会说马的语言？不，不管是什么样的宠物，只要每天对话，至少都会做出回应。」「『老师，你还记得卡拉瓦乔吗？』『嗯，是保罗先生的马吧。真让人怀念……』……对了，那时候的马差点被闪电打死。幸好被击中后勉强还剩下一口气」
- 名称：次郎
  - 特征：格雷拉特家饲养的坐骑/宠物，体型足以供洛琪希单独骑乘，爱夏日常会与之交谈。
  - 原文依据：「爱夏也是几乎每天都会找次郎与比特说说话。」「『要不然，其实我也可以自己骑次郎喔。』」
- 名称：比特
  - 特征：格雷拉特家饲养的宠物之一，爱夏日常会与其交流沟通。
  - 原文依据：「爱夏也是几乎每天都会找次郎与比特说说话。」

## 五、物品 / 道具 / 武器
- 名称：魔杖「傲慢水龙王」
  - 说明：鲁迪乌斯从十岁起持有的专属长魔杖，具备优异的魔力传导与辅助调控性能，可承受并辅助施展水王级魔术。
  - 原文依据：「傲慢水龙王，从十岁起就和我同甘共苦的搭档。我想，没有魔杖大概也能成功……不过，我还是举起魔杖。」
- 名称：洛琪希的魔杖
  - 说明：杖身顶端镶嵌有魔石。施展水王级大型魔术时需将杖尖刺向地面，左手握持杖柄，右手覆盖于魔石上方进行咒文咏唱与魔力疏导。
  - 原文依据：「她把魔杖刺向地面。然后用左手握着杖柄，右手覆盖在魔石的上方。然后，像是一个字一个字确认般地慢慢咏唱起咒语。」「因为以我的魔力，就算借助魔杖也只能使用一次就达到极限」
- 名称：雨具
  - 说明：水系大型魔术修练必备装备。由于水圣级及水王级魔术施展过程中会引发大范围倾盆大雨，施术者与旁观者需提前穿戴以防淋湿感冒。
  - 原文依据：「希露菲和洛琪希一边讨论一边穿上雨具。圣级那时被淋成了落汤鸡，所以知道会下雨的我们带来了事先准备好的雨具。」

## 六、历史 / 传说 / 事件
- 事件名：希露菲转移至阿斯拉王宫及护卫经历
  - 内容：菲托亚领地转移事件中，希露菲被传送至阿斯拉王宫上空，凭借魔术安全着陆生还，但因极度恐惧或魔力过度损耗致使发色转白；随后凭无咏唱魔术及爱丽儿赏识留在王宫；在爱丽儿王位争夺战落败遭数十名刺客夜袭时，希露菲以护卫术师身份全歼敌人。
  - 原文依据：「她不幸被转移到阿斯拉王宫的上空，驱使魔术之后总算成功降落。不过或许是因为过于害怕，也可能是因为魔力损耗过度，她的头发整个变白。一方面是因为获得爱丽儿的青睐，一方面是能够使用无咏唱魔术的能力受到器重，希露菲并没有被赶出王宫。当爱丽儿在政争中落败遭到几十名刺客袭击时，希露菲成功以护卫术师的身分击溃敌人。」
- 事件名：鲁迪乌斯五岁时的水圣级毕业考试
  - 内容：十二年前鲁迪乌斯五岁时，洛琪希带其前往郊外考核水圣级魔术「豪雷积雨云」，当时落雷险些击毙保罗的坐骑马匹卡拉瓦乔。
  - 原文依据：「自己五岁时，洛琪希曾要我学会水圣级魔术作为毕业考，当时也是像这样来到郊外，把马拴在树上……在那之后过了十二年……对了，那时候的马差点被闪电打死。幸好被击中后勉强还剩下一口气」

## 七、社会规则 / 习俗 / 文化
- 内容：
  1. 魔法大学师生认知与学生舆论：洛琪希外表娇小如少女，其已就任大学教师的事实尚未广为人知，常被误认为是普通女学生；鲁迪乌斯被全校公认为最恐怖的恶徒及龙头老大（学校传言称「龙头老大是个怪咖」），导致其在校内纠缠他人时路人畏惧不敢介入。
  2. 菲兹女性身份公开的社会反响：学生会干部「沉默的菲兹」曾长期在校内女扮男装，其女性身份公布后引来众多学生关注与赞赏。
  3. 多妻共处与家庭包容文化：鲁迪乌斯迎娶希露菲与洛琪希二人，正妻希露菲对后来加入的洛琪希抱持理解与感激，洛琪希亦对希露菲保持尊重与顾虑，家庭内部形成和睦相处机制。
- 原文依据：「『没办法，洛琪希老师是教师的事实似乎尚未被大家所熟知。』」「这种反应的理由是因为那个青年很恐怖，他是这一带最有名的恶徒。周围的人们都觉得就算过去帮忙，少女的命运依旧不会改变。不仅如此，说不定连自己也会有什么悲惨的下场。」「『菲兹学姐最近一口气变可爱了呢。』『没想到她是女性，真是出人意料。』」「正因为希露菲愿意包容，才能有现在的幸福状况。好运的人其实是我。」「──学校的传言•其之六『龙头老大是个怪咖』──」

## 九、角色认知 vs 客观事实
- 角色以为：路人及报案者误以为校内恶徒鲁迪乌斯在对无辜女学生施暴；希露菲误以为鲁迪乌斯在强人所难索求房事。
  - 原文是否暗示另有真相：是（洛琪希是教师而非女学生，鲁迪乌斯并非施暴，而是在再三请求洛琪希传授水王级魔术）。
  - 原文依据：「『有人报案说鲁迪乌斯正在对女学生施暴……』路克重重地叹了一口气。他的眼中映出叫作鲁迪乌斯的青年，以及名为洛琪希的少女。少女既不是女学生，鲁迪乌斯也没有施暴。」「『那个啊……鲁迪，就算已经结婚，你也不该强人所难。因为女孩子还是有不愿意的时候喔？』……『噢，我是在拜托洛琪希传授水王级魔术。』原来是这么一回事。」
- 角色以为：洛琪希自认为心胸狭隘害怕被弟子超越，自认才能远逊于鲁迪乌斯和希露菲，担心两人很快学会后自己毫无胜算。
  - 原文是否暗示另有真相：是（洛琪希过于自谦。虽然鲁迪乌斯凭借特异体质与无咏唱经验一次成功，但希露菲在压缩魔力环节失败并耗尽魔力，证明水王级魔术门槛极高，即使是洛琪希本人施展也有两成失败率）。
  - 原文依据：「『我并不是你嘴里形容的那种了不起人物，只是一个害怕弟子会超越自己的心胸狭隘之人。况且基本上，为了学会那个，我当初可是花上了好几个月。可是鲁迪和希露菲都比我有才能，感觉你们需要的时间会比我短得多……』」「『就算是我，五次也会失败一次喔。』洛琪希这样安慰希露菲。虽然我简简单单就成功，不过希露菲的失败保住了洛琪希的面子……应该有保住吧。」
- 角色以为：希露菲认为自己只是运气好才得以与鲁迪乌斯重逢结婚，面对洛琪希自己毫无胜算，洛琪希可能会视自己为碍事之人。
  - 原文是否暗示另有真相：否（客观上洛琪希非常珍视能与希露菲融洽相处，甚至自我怀疑是否在做临死前的美梦；鲁迪乌斯也深知全靠希露菲包容才有现在的家庭）。
  - 原文依据：「『或许希露菲会觉得我是个碍事的存在，但是能像这样三个人一起骑马，我觉得非常开心。』听到『碍事的存在』时，希露菲的身体震了一下。『不，别说什么碍事……完全没那回事。我这边也一样，很高兴能和洛琪希好好相处。因为如果要争夺鲁迪，我想自己大概没有胜算。其实我只是运气好而已。』……正因为希露菲愿意包容，才能有现在的幸福状况。好运的人其实是我。」
- 角色以为：希露菲和鲁迪乌斯认为希露菲在转移到阿斯拉王宫上空后头发变白，或许是因为过于害怕，也可能是因为魔力损耗过度 [存疑]。
  - 原文是否暗示另有真相：不明（原文为角色的推测性表达，未给出绝对定论）。
  - 原文依据：「不过或许是因为过于害怕，也可能是因为魔力损耗过度，她的头发整个变白。」
- 角色以为：鲁迪乌斯由Lightning名称联想电击魔法，但随即明确该世界不存在独立的电击魔术分类，雷电现象归于水系魔术。
  - 原文是否暗示另有真相：否（客观上符合该世界的魔术体系划分）。
  - 原文依据：「话说回来，Lightning吗……如果光听名字，感觉是常见的电击魔法。然而仔细想想，这个世界并没有电击魔术这种东西。不仅如此，这还是王级魔术。」
