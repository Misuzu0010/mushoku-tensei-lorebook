# 第十二话　「第四阶段」 世界设定提取

## 一、地理与场所
- 名称：转移遗迹
- 内容：古代遗留下来的空间传送设施。从魔法大学所在的夏利亚徒步前往需耗费五天时间，来回需十天，结合转移之后的后续路程移动，通常预估往返总共需要耗费一个月左右。
- 原文依据："使用转移遗迹或许会比较快，不过光是前往那个转移遗迹就要花上五天时间。来回就要十天。而且转移之后大概还要移动，预估总共要花上一个月应该比较妥当吧。"

- 名称：甲龙王佩尔基乌斯的居所 [存疑]
- 内容：具体地理位置未明。并不在夏利亚附近，但七星掌握特殊的会面途径，声称“想见的话，一天就能见到”。此外该处接受访客同行，佩尔基乌斯规定了“十二个人以内都没问题”的人数限制。
- 原文依据："想见的话，一天就能见到。" "不在附近，平常也没有见面。但是有见面的方法。" "对方说过十二个人以内都没问题。就算在场所有人都一起跑去想来也没关系。"

## 二、组织与势力
- 名称：拉诺亚魔法大学学生会
- 内容：魔法大学的学生自治与管理组织，爱丽儿在其中担任领导角色并负责招募人手。学生会在吸收成员时不仅考量学科成绩，也会看重学生在群体中的人际凝聚力（如诺伦因“能带动向心力”而受邀加入）。诺伦早在鲁迪外出旅行期间（距今一年以上）便已开始在学生会帮忙。
- 原文依据："是爱丽儿学姐来邀请我加入。她说虽然我的成绩绝对算不上优秀，却能带动向心力，所以问我要不要考虑一下。" "在学生会帮忙这件事本身已经有一年以上了吧？我记得是在鲁迪你外出旅行的期间开始。"

## 三、力量体系 / 魔法 / 技能
- 名称：异世界召唤术 / 召唤魔术（七星的研究）
- 规则：
  1. 阶段进展：研究至今已历时近三年。第一阶段耗时长，第二阶段（成功召唤瓶盖等小物件）与第三阶段较顺利突破；第四阶段的目标为“指定召唤物的详细条件”。目前该阶段的魔法阵尚无法做到极其精细的特定指定（七星原定目标为高丽菜，实验结果召唤出了西瓜）。
  2. 装置与魔力：需通过上百张绘制双面魔法阵的A2纸张层叠制作成魔道具石板状装置。单张魔法阵的魔力消耗等同于上级魔术，叠层装置魔力抽取量极巨（虽经改良但仍可轻易超过上级魔术十倍至二十倍），常人无法承受，几乎仅有鲁迪乌斯能够稳定供给。
  3. 发动现象：魔力充分灌注后，魔法阵发出朦胧光芒并依次变换颜色（黄、红、蓝、白），随后射向四方的光线聚拢于中央一点，伴随轻微碰撞声将异世界物体召唤成型。
  4. 传承与造诣：龙神奥尔斯帝德亦掌握召唤术；而甲龙王佩尔基乌斯则是极其精通召唤术各方面细节的古老权威。
- 原文依据：
  "现在，我的眼前有一个巨大的魔法阵。乍看之下，那很像是一块石板。不过实际上，是用很多两面都画满魔法阵的A2纸张层层堆叠起来的魔法阵。使用的纸张应该超过一百张吧。纸张边缘被木框盖住，木框本身也画上了魔法阵。已经成了一种魔道具。"
  "希露菲以前说过，这个魔法阵光是一个就会耗掉等同于上级魔术的魔力。现在至少有一百张。在克里夫的协助下，魔力消耗量有稍微压低，所以大概不会高达一百倍，不过应该可以随便就超过十倍、二十倍吧。"
  "复杂魔法阵发出的光芒……开始改变颜色。黄、红、蓝、白……来自魔法阵的各色光芒让我觉得似曾相识……射向四方的光芒开始聚集到一个点上。叩咚……现场响起轻微的碰撞声。魔法阵突然不再接收魔力，光芒也消失了。……魔法阵的中心出现一个绿色的物体。……是西瓜。"
  "况且基本上，还无法设定得那么详细。甚至我这次的目标本来是想召唤出高丽菜。"
  "从我开始协助七星的研究，至今已经快满三年了。……我记得第四阶段是要指定召唤物的详细条件吧？"
  "老实说，关于你想知道的召唤魔术，去找那种人直接学习会比较好。" "奥尔斯帝德虽然也使用召唤术，不过我要找的是另外一个人。"

- 名称：解毒魔术 / 治愈魔术的生理缓解应用
- 规则：除了针对创伤与剧毒，解毒魔术与治愈魔术也可用于缓解因感冒及醉酒引发的身体恶心与不适反应。
- 原文依据："她的脸色有点难看，是不是因为酒醉而不舒服？谁教她感冒了还要喝酒。'要不要帮你解毒？' '……麻烦了。' 对她使用解毒和治愈魔术之后，七星似乎好过了一点，带着稍微清醒的表情呼了一口气。"

- 名称：奥尔斯帝德的万般术法 [角色认知/传闻]
- 规则：根据人神所述，奥尔斯帝德能够使用世界上所有的招式与术法（包含召唤术）。
- 原文依据："奥尔斯帝德虽然也使用召唤术，不过我要找的是另外一个人。" "按照人神所说，奥尔斯帝德似乎能使用世界上的所有招式和术法。不过，会使用和很熟悉应该是两回事。"

## 四、种族 / 生物
- 名称：异世界瓜菜生态与地球改良作物的差异
- 特征：异世界本身存在多种外形奇特的瓜类与蔬菜，市场也有瓜类作物销售，亦有类似高丽菜的本土植物。但该世界缺乏地球上经过人工品种改良的特殊农产品（例如无籽西瓜、夕张哈密瓜），当地并无类似的培育栽培方法。异世界人（如克里夫）初次见到绿黑相间条纹的西瓜时会感到外观诡异骇人，甚至怀疑其是否会咬人。
- 原文依据："克里夫很有兴趣地靠近西瓜，伸出手指戳了几下。'绿黑条纹啊，真是吓人的外观……可以拿起来吗？这玩意儿该不会咬我吧？'……不过，他居然觉得西瓜长得吓人。果然看在这个世界的人们眼里，绿黑相间的条纹会让人觉得诡异吗？……只是这个世界也有很多奇形怪状的水果和蔬菜。如果仔细寻找，说不定可以找到西瓜，毕竟市场也有卖瓜类作物。" "因为那是经过品种改良的作物，在这边应该是不存在于世上的东西。" "这玩意儿居然是无籽西瓜。再怎么说，这个世界里应该并没有使用类似的栽培方法。"

- 名称：长寿种族 / 远古遗存者
- 特征：如甲龙王佩尔基乌斯等存在，自四百年前的古老战役存活至今，寿命悠长，通晓诸多常人不知的古老知识、疑难病症与应对方法。
- 原文依据："其实我也不确定，只是那个人活了很久，很有可能知道什么办法。" "这个名字正是四百年前在拉普拉斯战役中，引导人族赢得胜利的「杀死魔神的三英雄」之一。"

## 五、物品 / 道具 / 武器
- 名称：层叠式召唤魔法阵魔道具
- 说明：七星主导开发制作、克里夫与札诺巴协助制作、鲁迪注入魔力的大型召唤装置。由一百张以上双面绘制魔法阵的A2纸张堆叠组成，外部由画有魔法阵的木框固定密封，外表类似石板。能够承受并流通高额魔力以唤来异世界物品。
- 原文依据："现在，我的眼前有一个巨大的魔法阵。乍看之下，那很像是一块石板。不过实际上，是用很多两面都画满魔法阵的A2纸张层层堆叠起来的魔法阵。使用的纸张应该超过一百张吧。纸张边缘被木框盖住，木框本身也画上了魔法阵。已经成了一种魔道具。"

- 名称：札里夫义手
- 说明：札诺巴日常佩戴使用的特制义手道具，能有效辅助并带动其精密操作与技术工艺水平的提升。
- 原文依据："札诺巴也靠着使用「札里夫义手」带动技术力更为提升。"

- 名称：通信用魔道具 / 魔力附加品 [存疑/角色推测]
- 说明：鲁迪乌斯推测该世界中可能存在的远距离联络工具。据其已知情况，世界中虽尚未亲见即时通话类魔道具，但存在可传送文字（需耗时）或通过事先约定的信号暗号进行通讯传达的魔力道具方式。
- 原文依据："是不是利用魔力附加品来联络呢？我没有实际看过电话类的魔道具，不过这世界能够瞬间转移。既然如此，应该不至于真的没有类似电话的东西吧。而且虽然传送文章似乎需要一段时间，不过如果只是单纯的暗号，好像只要事先讲定就可以传达意思。类似信号弹那样的感觉。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：发生于四百年前的历史重大战争。人族在该战役中面对魔神，在关键英雄的引领下最终杀死了魔神，赢得了战争的胜利。
- 原文依据："这个名字正是四百年前在拉普拉斯战役中，引导人族赢得胜利的「杀死魔神的三英雄」之一。"

- 事件名：「杀死魔神的三英雄」传说与甲龙王佩尔基乌斯
- 内容：四百年前拉普拉斯战役中杀死魔神、引导人族取得全面胜利的三位传奇英雄。甲龙王佩尔基乌斯正是其中之一。该名号具有极高的历史与政治分量，七星要求知情者严守秘密不得向外宣扬。
- 原文依据："他叫甲龙王佩尔基乌斯。这个名字正是四百年前在拉普拉斯战役中，引导人族赢得胜利的「杀死魔神的三英雄」之一。" "我希望你们不要外传，可以吗？"

- 事件名：菲托亚领转移事件的前兆异象
- 内容：在多年前转移灾害爆发前夕，现场曾出现过黄、红、蓝、白各色光芒流转变换，并最终汇聚向一点的发光模式。本次七星的异世界召唤实验中魔力激化时亦重现了该种颜色变化的光芒模式。
- 原文依据："复杂魔法阵发出的光芒……开始改变颜色。黄、红、蓝、白……来自魔法阵的各色光芒让我觉得似曾相识，以前看过这种发光模式。对了，是转移事件发生前没多久，那时候也出现过这种光芒。"

## 七、社会规则 / 习俗 / 文化
- 内容：拉诺亚魔法大学课程难度体系。魔法大学的课程学业从三年级开始难度会显著增加。
- 原文依据："还有课业也是，从三年级开始应该会变难。"

- 内容：魔法大学学生会的吸纳标准与人际向心力价值。学生会选拔不唯学科成绩论，具备能够聚集并带动同学凝聚力的学生亦能获得特邀加入资格。
- 原文依据："是爱丽儿学姐来邀请我加入。她说虽然我的成绩绝对算不上优秀，却能带动向心力，所以问我要不要考虑一下。"

- 内容：学术成果的宴会庆祝与重要人物保密礼仪。七星在完成重要阶段实验后会举办宴饮聚会庆祝，同时在涉及传说英雄佩尔基乌斯等高位存在时，保持严谨的私下密谈与不可外传原则。
- 原文依据："当天晚上，我们举办了宴会。……七星猛灌黄汤……" "我希望你们不要外传，可以吗？……他叫甲龙王佩尔基乌斯。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯在魔力注入魔法阵、看到黄红蓝白各色光芒流转汇聚时，因该发光模式酷似当年转移事件爆发前的景象，担忧实验失控引发大规模空间转移灾害波及城镇与家人。
- 原文是否暗示另有真相：否。该魔法阵经过长年理论研究与实验验证，并不具备空间转移灾害机能，光芒聚集仅是完成了从异世界成功召唤西瓜的过程。
- 原文依据："黄、红、蓝、白……来自魔法阵的各色光芒让我觉得似曾相识，以前看过这种发光模式。对了，是转移事件发生前没多久，那时候也出现过这种光芒。怎么办，要停止实验吗？……然而，我没有感觉到会发生什么事情的动静。况且基本上，我们制作的魔法阵根本没有那种机能。就是为了避免发生那种事情，我们不断累积研究成果至今。"

- 角色以为：当七星说“想见的话，一天就能见到”时，鲁迪乌斯先是以为佩尔基乌斯就在夏利亚附近且七星偶尔会去见面；在七星澄清不在附近后，鲁迪又自行猜测是否通过类似电话或信号弹机制的魔力附加品远程暗号联络。
- 原文是否暗示另有真相：是。七星明确澄清佩尔基乌斯“不在附近，平常也没有见面。但是有见面的方法”，具体手段并非鲁迪猜测的邻近居住；鲁迪关于类似电话通信道具的推测纯属缺乏事实依据的主观揣想（鲁迪自述“没有实际看过电话类的魔道具”）。
- 原文依据："想见的话，一天就能见到。" "哦？原来在附近啊，其实你偶尔会去见对方？" "不在附近，平常也没有见面。但是有见面的方法。" "是不是利用魔力附加品来联络呢？我没有实际看过电话类的魔道具……"

- 角色以为：鲁迪乌斯与诺伦听闻七星介绍后，心生希望，认为佩尔基乌斯很有可能拥有治愈塞妮丝失忆症的手段或病例经验。
- 原文是否暗示另有真相：不明/存疑。七星本人亦明确说明无法打包票，仅因佩尔基乌斯活得极为悠久，推论其“很有可能知道什么办法”。
- 原文依据："其实我也不确定，只是那个人活了很久，很有可能知道什么办法。"

- 角色以为：鲁迪乌斯根据人神的说法，认为奥尔斯帝德能使用世界上所有的招式与术法，但推测其“能使用”并不代表像专门开发者那样熟稔召唤魔术细节。
- 原文是否暗示另有真相：不明。这是人神向鲁迪单方面灌输的说法；七星证实了奥尔斯帝德确实会使用召唤术，但七星选择请教的召唤权威是佩尔基乌斯而非奥尔斯帝德。
- 原文依据："奥尔斯帝德虽然也使用召唤术，不过我要找的是另外一个人。" "按照人神所说，奥尔斯帝德似乎能使用世界上的所有招式和术法。不过，会使用和很熟悉应该是两回事。"
