# 第四话　「是我培育的」 世界设定提取

## 一、地理与场所
- **卢迪乌斯家的庭院与试验田**
  - 内容：卢迪乌斯家的庭院过去荒废且地面裸露，现经打理后种有三棵冬天叶子不枯萎、春秋冬分别开花的树木（委托冒险者公会从森林移植，由札诺巴协助搬运以减免搬运费用）。庭院角落用砖墙围起了一片小规模田地，卢迪乌斯在此采用旱作方式尝试种植从贝卡利特大陆带回的水稻种子，由爱夏与塞妮丝日常负责拔草照料。
  - 原文依据："这个院子以前整个荒废，地面也裸露在外。结果一阵子没注意，外貌已经改变不少。首先，院子里种了三棵叶子在冬天也不会干枯的树木。这些树木好像会在春、夏、秋三季分别开花，不知道是用了什么方法从哪个地方弄来的东西。好奇提问之后，才知道好像是委托冒险者公会从森林里移植过来的。我本来以为这些树难以搬运所以要价应该很高，结果因为有札诺巴帮忙，最后只花了护卫的费用。另外，院子角落有个用砖墙围起来的区域。这里种着我带回来的稻种。因为我不知道该如何开拓水田，因此采用旱作。目前没有发生什么问题，已经长出了茎。"

- **地下室密室（御神体祭坛）**
  - 内容：卢迪乌斯家中位于地下室的秘密场所，是卢迪乌斯在夜深人静时悄悄拜访祈祷的心灵圣所，里面供奉着洛琪希很久以前的内裤。该处被爱夏暗中发现，并以此作为要挟卢迪乌斯同意饲养魔木的筹码。
  - 原文依据："「那个在地下的密室！」……人都有不可被外人触碰的禁忌。对我来说，地下室的祭坛就是那种禁忌。那里是我会在夜深人静之后，悄悄拜访并献上祈祷的神圣场所。虽说吾神已经陪伴于自己身边，不过这个和那个是两码子事。……尤其是洛琪希姐姐，要是知道自己那么久以前的内裤被人像那样供奉起来，哥哥觉得她会怎么想～？"

- **五大陆（世界地理框架提及）**
  - 内容：世界由五大陆构成，已知包含魔大陆、米里斯大陆、中央大陆、贝卡利特大陆与天大陆。除天大陆外，卢迪乌斯均已游历，并确认在这四块大陆的森林和平原中均广泛分布着魔木。
  - 原文依据："我曾经旅行过很多地方。魔大陆、米里斯大陆、中央大陆、贝卡利特大陆。虽然没去过天大陆，不过这世界的五大陆几乎都踏遍了。在我去过的所有大陆上，都存在着名为魔木的魔物。森林里几乎一定会有，连在平地也经常出没。"

- **阿斯拉王国（特产种植分布）**
  - 内容：阿斯拉王国的部分地区栽种名为芭缇尔丝的植物，用作媚药材料与香水原料。爱夏持有的种子即源自阿斯拉王国。
  - 原文依据："「咦，不对喔，我记得这是在阿斯拉王国拿到的芭缇尔丝种子。」"、"芭缇尔丝花……我听说过这名称，是媚药的材料。另外好像还可以作为香水的原料，所以阿斯拉王国的部分地区栽种着这种植物。"

- **米格路德村（魔大陆村落农田）**
  - 内容：魔大陆的米格路德族村庄内，农田里种植/饲养着类似食人花（食○花）的魔木，用于防范和驱逐啄食庄稼的害鸟。
  - 原文依据："「虽然在这边都没看到，不过米格路德族就有为了驱除田里的害鸟而饲养魔木。」……我记得米格路德村里种了类似食○花的玩意儿。"

- **拉诺亚魔法大学（设施与传闻）**
  - 内容：大学内部设有供坐骑驻留的马厩（魔兽次郎白天在此睡午觉）；洛琪希在校内任课；学校内流传着关于卢迪乌斯的都市传说（"龙头老大的家中栖息着魔物"）。
  - 原文依据："次郎被洛琪希骑去学校了，这时间想必在大学的马厩里睡午觉。"、"──学校的传言•其之四「龙头老大的家中栖息着魔物」──"

## 二、组织与势力
- **冒险者公会**
  - 内容：冒险者公会接受并执行各类委托任务，包括组织护卫队伍协助雇主前往森林采伐、移植珍稀树木等业务。
  - 原文依据："好奇提问之后，才知道好像是委托冒险者公会从森林里移植过来的。我本来以为这些树难以搬运所以要价应该很高，结果因为有札诺巴帮忙，最后只花了护卫的费用。"

## 三、力量体系 / 魔法 / 技能
- **土魔术（土壤生成）**
  - 规则：魔法使可以通过普通土魔术制造土壤。卢迪乌斯用土魔术生成的土壤相比夏利亚当地的普通土壤富含更多营养，对植物发芽和盆栽生长具有明显增益。
  - 原文依据："土壤是使用哥哥之前做给我的那些，果然比起这附近的土壤，好像还是哥哥制造的土壤比较有营养。既然如此，土壤的部分大概也没问题。毕竟我当初也没特别想什么，就只是很普通地用土魔术制造出土壤。"

- **预知眼**
  - 规则：卢迪乌斯持有的魔眼能力，察觉危险异响时可瞬间激活以观察短暂未来，结合魔力注入肉体以进行警戒与迎击。
  - 原文依据："在听到后方声音的那瞬间，我首先发动预知眼，再把魔力灌注到双手上。"

- **隐身魔道具 / 魔力附加品 [存疑]**
  - 规则：推测存在的道具类别。卢迪乌斯在索敌时推测可能存在能够让人隐身且有时效限制的魔道具，并在排查异常花盆时推测是否存在被施加魔力的魔法道具。
  - 原文依据："难道是看不到的敌人？还是能够隐身的魔道具？如果是那样，效果迟早会消失。"、"花盆是以前和爱夏一起在杂货店购买的普通物品。想来不会是魔力附加品或魔道具之类。"

- **驯兽技术与魔物人工培育**
  - 规则：世界中存在受雇训练大型魔兽（如犰狳次郎）的专业“驯兽师”；同时，植物型魔物（如魔木）只要经过细心照料培育，同样会亲近人类并听从口令做出反应，可作为看家、驱鸟的使魔或宠物进行驯养。
  - 原文依据："话虽如此，次郎是专业驯兽师训练出来的魔兽。"、"「魔木只要确实照料就会亲近人类，而且这种尺寸大概不会有什么危险。」"、"它和其他孩子有和睦相处，也会乖乖听我的话！……看起来确实可以沟通，而且好像很听爱夏的话。"

## 四、种族 / 生物
- **魔木（统称及分支种类）**
  - 特征：栖息于世界各地的代表性魔物，如同奇幻故事中的史莱姆般普遍存在。分布于魔大陆、米里斯大陆、中央大陆、贝卡利特大陆的森林和平地。虽属树之魔物，但外型各异，擅长拟态成周围植物环境并埋伏袭击旅人。已知分支包括：
    - **石魔木**：外形似马铃薯。
    - **仙人掌魔木**：外形似仙人掌。
    - **长老魔木**：据传闻具备操纵水流的魔力 [存疑]。
  - 原文依据："名为魔木的魔物可说是随处可见，它们是栖息于这世界的代表性魔物。举个例子来比喻，魔木在这个世界里就等于奇幻作品里的史莱姆。……在我去过的所有大陆上，都存在着名为魔木的魔物。森林里几乎一定会有，连在平地也经常出没。虽然魔木是树的魔物，但外型不一定长得像树。例如像是马铃薯的石魔木和看似仙人掌的仙人掌魔木，有各式各样的种类。根据听来的情报，好像还有能操纵水的长老魔木。"

- **宝宝魔木「比特」**
  - 特征：爱夏使用阿斯拉王国的芭缇尔丝种子意外培植出的小型魔木。株高仅约15公分（连根约20公分），生有四片叶子和两根藤蔓，尚无花果。见光会转动茎叶进行日光浴并使花盆发出叩咚晃动声。具有类似动物的感知与互动反应，经爱夏训练能辨识并听令缠绕爱夏的小指、中指或大拇指，被爱夏命名为「比特」。
  - 原文依据："长着四片叶子和两根藤蔓，没有花朵也没有果实，看起来还是幼苗。所以我决定把这家伙暂时称为「宝宝魔木」……这玩意儿顶多只有十五公分高。要是连根部也计算进去，大概二十公分左右吧。"、"种在最小花盆里的植物突然开始扭动。而且还转动茎部把叶子朝向窗外，像是要让全身上下都受到阳光照耀。只要那盆植物做出任何动作，花盆就会跟着晃动，发出叩咚叩咚的声响。"、"「小指是哪个？」虽然有点犹豫，不过藤蔓还是正确缠住爱夏的小指。「中指呢？」藤蔓放开小指，缠住中指。……顺便说一下，这个「宝宝魔木」被命名为「比特」。"

- **芭缇尔丝（植物）**
  - 特征：阿斯拉王国特定区域种植的经济植物。长有叶片和藤蔓，成株可开出紫色花朵；花朵可用作媚药材料及香水原料。成株株高大约为幼苗期的两倍（约30公分）。
  - 原文依据："「咦，不对喔，我记得这是在阿斯拉王国拿到的芭缇尔丝种子。」「嗯，这孩子不是长着叶子和藤蔓吗？再长大一点，应该会开出紫色花朵。」芭缇尔丝花……我听说过这名称，是媚药的材料。另外好像还可以作为香水的原料，所以阿斯拉王国的部分地区栽种着这种植物。"、"「芭缇尔丝成长后大概只会变成现在的两倍大，我想不会有问题。」"

- **魔兽与魔物的同源关系**
  - 特征：根据世间传闻考证，供人类骑乘或训练的“魔兽”（如魔大陆骑行蜥蜴、贝卡利特犰狳次郎）与具有攻击性的“魔物”，追溯其本源实为同一种来源 [存疑]。
  - 原文依据："在魔大陆上乘坐过的蜥蜴和贝卡利特大陆带回来的犰狳次郎是魔兽，然而据说追溯之后，会发现魔兽和魔物其实出自同源。如果能够亲近人，这个「宝宝魔木」或许也算是魔兽吧？"

- **次郎（犰狳魔兽）**
  - 特征：产自贝卡利特大陆的大型犰狳型魔兽，经专业驯兽师驯养，温顺可供骑乘，体型庞大，平时作为洛琪希往返魔法大学的坐骑。
  - 原文依据："次郎被洛琪希骑去学校了，这时间想必在大学的马厩里睡午觉。"、"论起危险度，感觉体型巨大的次郎反而危险得多。话虽如此，次郎是专业驯兽师训练出来的魔兽。"

- **松风（马匹）**
  - 特征：卢迪乌斯在贝卡利特大陆购买的坐骑马匹，寄养于夏利亚城内的公用马厩中。
  - 原文依据："至于去贝卡利特大陆时购买的马──松风被寄放在城里的马厩，我偶尔会去看看它的情况，但是松风不太可能自己来到这里。"

- **冬季常青开花树木（树种未知）**
  - 特征：森林中的野生树种，其树叶即便在严冬季节也不会干枯，且能在春季、夏季、秋季三个季节分别开出花朵。
  - 原文依据："院子里种了三棵叶子在冬天也不会干枯的树木。这些树木好像会在春、夏、秋三季分别开花，不知道是用了什么方法从哪个地方弄来的东西。好奇提问之后，才知道好像是委托冒险者公会从森林里移植过来的。"

- **水稻（稻米旱作）**
  - 特征：卢迪乌斯从贝卡利特大陆带回的稻谷种子，在缺乏水田设施的情况下可进行旱作发芽并长出茎秆，是否结穗尚待观察。
  - 原文依据："这里种着我带回来的稻种。因为我不知道该如何开拓水田，因此采用旱作。目前没有发生什么问题，已经长出了茎。看起来虽然顺利，但是还无法确定是否能结出稻穗。"

- **米格路德族（与魔木的关系）**
  - 特征：魔大陆的魔族之一。传统农耕中会在田间饲养类似食人花（食○花）的魔木，利用其生物本能捕捉驱赶害鸟。
  - 原文依据："「虽然在这边都没看到，不过米格路德族就有为了驱除田里的害鸟而饲养魔木。」……我记得米格路德村里种了类似食○花的玩意儿。"

## 五、物品 / 道具 / 武器
- **魔术师人型布偶娃娃**
  - 说明：放置在爱夏房间床边约20公分高的玩偶，形象为亮褐色头发、身穿长袍手持魔杖的魔术师。周边市集未曾售卖，行商人与人偶狂热者札诺巴手中亦无存货，属于罕见之物（卢迪乌斯怀疑是行商人处购得，断言不是爱夏自制 [存疑]）。
  - 原文依据："随处可见很有女孩子味的小东西，例如床边的娃娃。那是二十公分左右的人型娃娃，亮褐色的头发，身穿长袍拿着魔杖，看来是个魔术师。这一带应该没有卖这类布偶娃娃，是不是跟行商人买的？我记得连札诺巴手上也没有这种东西。也就是说，这是相当珍贵的物品。该不会是爱夏自己做的吧……不，不可能。"

- **女仆服**
  - 说明：爱夏日常穿着的仆从工作制服，衣柜中备有三套，每件均有多次密集的缝补痕迹，显露出长年穿用与老手仆从的气质。
  - 原文依据："我打开房间角落的衣柜，里面塞着三套女仆服。每一件都有明显的缝补痕迹，似乎经常穿用。和使用者的年龄相反，全是散发出老手气势的制服。"

- **洛琪希的旧内裤（圣物/御神体）**
  - 说明：洛琪希很久以前穿过的内裤，被卢迪乌斯供奉在地下室祭坛中当作虔诚祈祷的神圣信物与心灵支柱。
  - 原文依据："人都有不可被外人触碰的禁忌。对我来说，地下室的祭坛就是那种禁忌。那里是我会在夜深人静之后，悄悄拜访并献上祈祷的神圣场所。"、"尤其是洛琪希姐姐，要是知道自己那么久以前的内裤被人像那样供奉起来，哥哥觉得她会怎么想～？"

- **保罗的遗剑**
  - 说明：保罗战死后遗留的佩剑，现由诺伦保管，诺伦注视此剑时会流露辛酸与思念。
  - 原文依据："也不会像诺伦那样看着保罗的剑露出辛酸表情。"

## 六、历史 / 传说 / 事件
- **保罗战死与塞妮丝心智受损**
  - 内容：保罗在迷宫救援战中阵亡，塞妮丝陷入类似失神状态。卢迪乌斯家中各人表现各异：莉莉雅面露忧郁、诺伦凝望遗剑辛酸悲痛，而爱夏表面维持日常家务与园艺劳作，看似并无悼念表现。
  - 原文依据："虽然保罗丧命，塞妮丝成了那种状况，爱夏还是没有任何变化，每天都很有精神。爱夏不会像莉莉雅那样看着窗外露出忧郁表情。也不会像诺伦那样看着保罗的剑露出辛酸表情。"

## 七、社会规则 / 习俗 / 文化
- **侍从阶级礼节与家族称谓规范**
  - 内容：莉莉雅严格教育爱夏遵守侍从与正室夫人之间的身份界限。即便爱夏自幼由塞妮丝照顾并同住一屋，也绝对严禁直呼塞妮丝为“妈妈”，必须尊称为「塞妮丝夫人」或「夫人」。
  - 原文依据："「塞妮丝夫人」这个称呼总让我觉得有点不太对。「我说，爱夏。对于母亲，你直接叫她妈妈也可以喔。」「不了，妈妈说过不可以那样，还说要尊称为塞妮丝夫人或夫人才行。」原来是莉莉雅的吩咐，她的教育真是彻底。不过爱夏本身也没有把塞妮丝当成母亲看待，大概很难真的开口叫妈妈。"

- **居民饲育魔物的安全守则（卢迪乌斯家规）**
  - 内容：鉴于魔物潜在的危险性，卢迪乌斯准许爱夏在家中饲养魔木时立下的四条安全准则：
    1. 一旦危害人类就要立即处分；
    2. 必须确实教育，让它不会袭击人类；
    3. 对于家人，必须仔细说明它是什么样的植物；
    4. 为了以防万一，不能把它放在婴儿附近。
  - 原文依据："当然，我提出几个饲养它的条件。一、一旦危害人类就要立即处分。二、必须确实教育，让它不会袭击人类。三、对于家人，必须仔细说明它是什么样的植物。四、为了以防万一，不能把它放在婴儿附近。"

- **米格路德族的农耕生态习俗**
  - 内容：魔大陆米格路德族在村庄耕种期间，自古有在家园与农田周边饲养魔木以驱赶吃粮害鸟的传统习俗。

## 九、角色认知 vs 客观事实
- **认知点一：魔木是否能够驯服及对人类的危险性**
  - 角色以为：卢迪乌斯认为魔木是危险、没有耳朵、绝不可沟通驯服的凶暴魔物，长大必然危害人类或半夜将人勒死，主张必须当场焚毁或杀除。
  - 原文是否暗示另有真相：是。
  - 客观事实：魔木具备感知能力，能准确听懂爱夏口令并按指示缠绕指定手指；洛琪希亦证实只要悉心照料魔木就会亲近人类，魔大陆米格路德族长久以来就有在田间饲养魔木驱除害鸟的成熟传统。
  - 原文依据："「别面不改色地说谎，没有耳朵的魔木怎么听你的话？」"、"「魔木只要确实照料就会亲近人类，而且这种尺寸大概不会有什么危险。」……「嗯。虽然在这边都没看到，不过米格路德族就有为了驱除田里的害鸟而饲养魔木。」"

- **认知点二：盆栽魔木的突变与诞生原因**
  - 角色以为：爱夏认为自己仅是按常规种植阿斯拉王国获得的芭缇尔丝种子；卢迪乌斯则推测是种子里偶然混入魔木种子、魔木拟态环境、或者因浇灌爱夏剩洗澡水引发变异。
  - 原文是否暗示另有真相：不明 [存疑]。原文仅客观叙述该植物移栽至花盆后突然活动，究竟是普通种子受卢迪乌斯的魔力土壤刺激、品种杂交抑或纯属种子混入，本章未给出确定结论。
  - 原文依据："「咦，不对喔，我记得这是在阿斯拉王国拿到的芭缇尔丝种子。」"、"以普通方式培育普通种子，结果长成了魔物。这种事情真的有可能发生吗？如果理由是爱夏拿到的种子里偶然混入了魔木的种子，感觉还比较可以接受。魔木会拟态成周围的环境。或许是在这种过程中，选择了芭缇尔丝花作为让自己不会显得特异的外型……这种推测姑且还算说得通。"

- **认知点三：爱夏对保罗之死的情感态度**
  - 角色以为：卢迪乌斯主观以为爱夏完全没有悼念父亲的心思，甚至推测父亲对爱夏可能不重要、或者爱夏已遗忘幼年在布耶纳村的往事、母亲莉莉雅尚存的喜悦盖过了丧父之痛。
  - 原文是否暗示另有真相：不明 [存疑]。卢迪乌斯的想法属于其个人内心独白与揣测，并未证实爱夏日常充满活力的举止是真实不在意还是刻意伪装以支撑家庭氛围。
  - 原文依据："看起来就像是没有悼念保罗的意思，让我忍不住担心……或许对爱夏来说，父亲并不是那么重要的存在。……说不定爱夏对保罗跟塞妮丝的事情也已经记忆模糊。"

- **认知点四：魔术师人形布偶娃娃的制造者**
  - 角色以为：卢迪乌斯根据布偶精致的做工推断这是从行商人处购买的极罕见珍品，并断定绝不可能是爱夏自制。
  - 原文是否暗示另有真相：不明 [存疑]。该布偶外貌（亮褐色头发、长袍、魔杖）高度符合卢迪乌斯自身特征，爱夏对手工和兄长崇拜极深，卢迪乌斯的断言可能低估了爱夏的制作能力。
  - 原文依据："那是二十公分左右的人型娃娃，亮褐色的头发，身穿长袍拿着魔杖，看来是个魔术师。这一带应该没有卖这类布偶娃娃，是不是跟行商人买的？我记得连札诺巴手上也没有这种东西。也就是说，这是相当珍贵的物品。该不会是爱夏自己做的吧……不，不可能。"
