# 第十一话　「毕业典礼」 世界设定提取

## 一、地理与场所
- 名称：魔法大学大讲堂
- 内容：拉诺亚魔法大学举行室内毕业典礼的专用大型礼堂（入学典礼在室外举行）。平时一般学生及鲁迪乌斯从未来过，内部设置有大型讲台，毕业生在此登台逐一受领作为毕业证明的纹章与证书。
- 原文依据："入学典礼是在室外举行，毕业典礼则是在室内。自己至今从未来过的大讲堂里设置了大型讲台，毕业生一个个轮流领取作为毕业证明的纹章。"

- 名称：魔法大学教职员室大楼
- 内容：拉诺亚魔法大学教职员专用的整栋办公大楼。由于全校教师规模多达两三百人，因此教职员室独占一整栋建筑。
- 原文依据："学生旁边站着一整排教师，光是教师应该就有两三百人吧。话说回来，没想到学校里有这么多教师，难怪教职员室必须用到一整栋建筑。"

- 名称：魔法大学别馆与宿舍连接道（树林旁道）
- 内容：位于魔法大学别馆通往宿舍途中、紧邻树林的偏僻道路。冬季积雪严重且视野不佳，曾是鲁迪乌斯与札诺巴绑架莉妮亚与普露塞娜、首次起冲突的地点，也是两人毕业决斗的场地。
- 原文依据："如此这般，我们从别馆移动到通往宿舍的路上。旁边就是树林，而且还积着雪，视野很差。……这里是以前我和札诺巴绑架莉妮亚和普露塞娜的现场，也是和她们第一次起冲突的地点。"

- 名称：北方大地（气候环境）
- 内容：北方大地的冬季天空常呈现特有的灰色阴霾，天气严寒且频繁降雪。
- 原文依据："我也抬起头来，眼前是北方大地特有的灰色天空。今晚肯定又会下雪。"

- 名称：大森林 [提及]
- 内容：德路迪亚族（包括泰德路迪亚族与亚德路迪亚族）聚居生活的故乡，境内分布着不同部族的村落。
- 原文依据："在大森林输掉的话，会被迫走上无聊人生的说。例如会叫我们和村子里最强的战士结婚的说。……从今以后，普露塞娜将回到大森林，为了成为族长而继续锻炼精进。"

## 二、组织与势力
- 名称：拉诺亚魔法大学（学制、规模与人员制度）
- 内容：
  1. 学生规模与毕业率：全校学生总数超过一万人；七年级新生入学时约有近两千人，但最终能顺利毕业者每届仅约五百人。入学门槛不高，但因魔术难度及各种原因导致退学率极高。
  2. 升级评鉴规则：一般学生离校旅行半年会影响评鉴成绩导致留级；但若兼具顶尖优异成绩与王公贵族护卫立场（如希露菲），可依凭人脉关系顺利升级。
  3. 教职员构成：教师团队规模达两三百人，占用整栋建筑办公。洛琪希担任水魔术教师，因实力非凡受到一般学生敬畏。
  4. 典礼出席规则：在校生无义务参加毕业与入学典礼，一般学生在典礼当日放假；在校生若想观摩必须特地申请许可，典礼被视作被选中的人物才能参加的荣誉。
  5. 优待制度：特别生享有较多优待。
- 原文依据：
  - "因为她是一般学生，离校旅行半年的行为影响到评鉴成绩。"
  - "希露菲的应出席日数也不够，但是她本来就拥有学年顶尖水准的优秀成绩，再加上身为爱丽儿公主之护卫的立场，最后顺利升级。可以彻底感受到社会讲求人脉关系的现实。"
  - "毕业生的人数顶多只有五百人。据说这间学校的学生总数超过一万人，毕业生却只有五百人。我想现在的七年级在刚开学时应该也有将近两千人吧。但是随着时间过去，会一点一点地有人退学离开，最后只剩下这个数字。想入学不是难事，要毕业却没那么容易。"
  - "学生旁边站着一整排教师，光是教师应该就有两三百人吧。"
  - "顺便说一下，一般学生今天放假。在校生没有参加毕业典礼和入学典礼的义务。不但没有义务，甚至要申请许可才能观摩。听说所谓的典礼是被选中的人物才有资格参加的一种荣誉。"

- 名称：魔法大学学生会
- 内容：全员出席毕业典礼，主要成员包括爱丽儿、路克及两名随从、希露菲等。诺伦列席于学生会末座，预定自下学期起正式加入学生会。
- 原文依据："学生会成员全数出席。自己认识的脸孔大约有四人，爱丽儿、路克，还有爱丽儿的两名随从。另外希露菲也在场。……可以看到诺伦待在学生会成员的末座。自己什么都没听说，难道她加入了学生会？今年没看到她表现出那种态度，所以是下学期开始才列入成员吗？"

- 名称：德路迪亚族（泰德路迪亚族 / 亚德路迪亚族）
- 内容：兽族王者种族，分支为泰德路迪亚族（猫系）与亚德路迪亚族（犬系）等部族，各有村落。族内通过实力对决角逐族长之位。[存疑：部族间是否只有一个统领全族的族长，抑或各部族分别有族长，鲁迪乌斯尚存疑问]。
- 原文依据："而且又是兽族王者德路迪亚族的公主，身分方面也无可挑剔。……获胜的那一方会成为德路迪亚族的族长喵。……可是，本来就有泰德路迪亚族和亚德路迪亚族两个部族，根本没必要决斗吧？……自己待过的地方是泰德路迪亚族的村落，不过好像也有听说过亚德路迪亚族的村落。难道是所谓的「族长」只有一个吗？还是「德路迪亚族的族长」拥有统领所有支族的立场？"

- 名称：魔术公会 [提及]
- 内容：管理并认证魔术师等级的公会组织，拉诺亚魔法大学合格毕业生会随毕业证书一同获得魔术公会颁发的D级证明。
- 原文依据："在此颁发毕业证书以及魔术公会D级证明！"

## 三、力量体系 / 魔法 / 技能
- 名称：魔术学习难关与魔力总量限制
- 规则：初级魔术容易掌握，但上级魔术与混合魔术掌握难度极高；且若个人的魔力总量上限过低，会根本无法学会高阶魔术，这是大量学生无法毕业而退学的核心原因。
- 原文依据："想入学不是难事，要毕业却没那么容易。特别是上级魔术和混合魔术都难以掌握，还有人是因为魔力总量太低所以无法学会。还有，虽然具备才能却觉得只要能学会初级魔术就够了的人或许也不在少数。"

- 名称：肉搏战与魔术咏唱机制（无咏唱魔术优势）
- 规则：一旦进入高强度的贴身肉搏战，战士处于类似无氧运动状态，呼吸急促、难以开口朗读，因而没有时间和条件进行咒语咏唱以发动魔术；唯有掌握「无咏唱魔术」的术士（如鲁迪乌斯与希露菲），才能在肉搏攻击动作的间隙穿插施放魔术。
- 原文依据："「打从一开始普露塞娜选择近身战的那一刻起，进行魔术战的可能性就消失了。因为一旦开始互殴，就没有时间咏唱咒语。如果是我和希露菲，还可以在肉搏攻击之间穿插无咏唱魔术，然而这两人是战士。她们等于是处于无氧运动状态，应该连开口说话都有困难。例如马拉松选手能顺便朗读诗歌吗？不能，那是──」"

- 名称：异世界召唤魔法阵阶段体系
- 规则：七星进行的异界召唤实验分为不同阶段演进：
  - 第一阶段：成功召唤出无生命的简单异界物品（如宝特瓶）。
  - 第二阶段：召唤物品的构件完整度提升（宝特瓶上附带瓶盖）。
  - 第三阶段：召唤目标进阶至活体生物范畴，包含「植物」或「小动物」（如蔬菜、小型生物）。
- 原文依据："她的研究确实有进展，几个月前已经完成了第二阶段，让第一阶段召唤来的宝特瓶上出现了瓶盖。现在是第三阶段，预计要召唤「植物」或「小动物」之类的「生物」。她正在朝着这个目标努力。我想只要再过一阵子，前世的蔬菜就会出现在这个世界里。"

- 名称：解毒魔术的疗效局限
- 规则：解毒魔术可用于缓解并治疗发烧与干咳等感冒病症，但若受术者生活作息与环境长期恶劣（如长年闭门幽居地下暗室、食用水分不足的保存食品、缺乏日光照射），免疫力低下会导致数日内病症反复发作。
- 原文依据："动不动干咳，而且还会发烧。虽然我几乎每次都会帮她用解毒魔术治疗，然而不消几日，七星就会又出问题。"

- 名称：治愈魔术与外伤消除
- 规则：治愈魔术能迅速愈合撕裂伤、咬伤及钝器击伤等外伤，但在兽族的战斗荣誉观念中，受术者往往会拒绝接受治愈魔术以保留伤疤作为骄傲与回忆。
- 原文依据："「你来这里坐下，我要使用治愈魔术。」我一边说一边伸手想治疗普露塞娜肩膀上的伤，她却用力打掉我的手。「谢谢你的好意，但是没必要的说。这些伤是荣誉的说，我要全部留下。」"

- 名称：魔眼（预知眼）
- 规则：鲁迪乌斯所持有的特殊眼部瞳术，能够预判对手的动作与轨迹，在旁观高强度决斗时可主动发动。
- 原文依据："我发动魔眼，七星戴上魔力附加品的护身用戒指。"

- 名称：圣级水魔术 [提及]
- 规则：水系统魔术的高阶分级，洛琪希在魔法大学学生时期便已能熟练施展。
- 原文依据："尽管我并不清楚当时的洛琪希到底有多优秀，但是她至少已经能使用圣级水魔术……结果却还是落选。"

## 四、种族 / 生物
- 名称：兽族（德路迪亚族分支）生理与战斗特征
- 特征：
  1. 威吓习性：临战前会发出带有猛兽低吼特征的尖锐或低沉威吓声（如「吓──！」「咕呜呜呜！」）以压制牵制对手。
  2. 泰德路迪亚族（猫系）：体质天生擅长游泳；战斗中速度占优；手部能伸出锋利坚韧的利爪，在挥拳时以猫拳撕抓重创对手；口部生有尖锐利牙咬击；拥有猫科动物特有的敏锐瞬间反射神经，善于微幅侧身闪避打击。
  3. 亚德路迪亚族（犬/狼系）：肉体力量较猫族更为强悍；擅长正面强攻冲撞与压制；拥有极强杀伤力的利牙咬击，能撕咬并锁死对手肢体。
- 原文依据：
  - "两人发出不像是年轻女孩的威吓声，互相牵制。"
  - "力量是普露塞娜稍占上风，速度是莉妮亚略胜一筹！"
  - "是爪子！莉妮亚伸出自己的爪子，在挥拳的同时抓伤对手！这是非常锋利洗练的猫拳！"
  - "明明是擅长游泳的泰德路迪亚族却溺水，真是丢脸的说！"
  - "莉妮亚利用猫科动物特有的瞬间反射神经配合稍微把头和身体往旁边移动的闪避动作，并没有被直接击中！"
  - "普露塞娜使出利牙！咬住莉妮亚想踢向她脖子的脚！没错！普露塞娜是狗！是野兽！是狼！她还有这个武器！"
  - "莉妮亚也咬了回去！亮出她的利牙反击！"

## 六、历史 / 传说 / 事件
- 事件名：莉妮亚与普露塞娜的毕业决斗
- 内容：在拉诺亚魔法大学通往宿舍的积雪树林旁，莉妮亚与普露塞娜为决定谁返回大森林继承德路迪亚族族长、谁享有外出自由生活，由鲁迪乌斯与七星作为见证人进行了一场全力的肉搏死斗。最终普露塞娜获胜成为族长候补，莉妮亚落败获得自由；二人随后先后离校。
- 原文依据："接下来，我和莉妮亚要决定到底谁比较强的说。……获胜的那一方会成为德路迪亚族的族长喵。……所以比较强的去当族长，另一个就自由活下去的说。……然后，只有一个人站了起来。「赢了的说……」是普露塞娜。"

- 事件名：洛琪希落选毕业生代表往事
- 内容：洛琪希在魔法大学就读期间成绩顶尖，且已能施展圣级水魔术，但因其平民身份，未能当选看重高贵出身的毕业生代表。
- 原文依据："然而洛琪希在学时也相当优秀，却没有被选为毕业生代表。对，连那个洛琪希都没有被选上。尽管我并不清楚当时的洛琪希到底有多优秀，但是她至少已经能使用圣级水魔术……结果却还是落选。"

## 七、社会规则 / 习俗 / 文化
- 内容：毕业生代表选拔的身分偏向规则
  - 魔法大学挑选毕业生代表时极度注重学生的家世门第。若平民学生与贵族学生成绩相当，必定选择贵族担任代表以避免引发纷争并迎合贵族阶层的虚荣；即便平民实力卓绝（如学生时代的洛琪希），亦难突破出身门槛当选代表。
  - 原文依据："而且又是兽族王者德路迪亚族的公主，身分方面也无可挑剔。该说是果然如此吗？成为毕业生代表的人选似乎一定要具备高贵的身分。如果平民和贵族的成绩相同，会选择贵族作为代表。这样能避免引发问题，而且贵族心里才会舒坦。……魔法大学号称来者不拒，愿意接受任何学生，不过既然是人类经营的设施，恐怕依旧无法摆脱人世的各种束缚纠葛吧。"

- 内容：兽族的决斗习俗、败者命运与伤疤荣耀
  - 在大森林的传统习俗中，决斗竞争失败者往往会被迫接受包办命运，如被强制要求与村中最强战士成婚。
  - 兽族视决斗负伤留下的伤口与伤疤为战士的荣誉与骄傲勋章，常会特意拒绝使用治愈魔术将其消除，以此纪念战斗经历与对手。
  - 原文依据：
    - "在大森林输掉的话，会被迫走上无聊人生的说。例如会叫我们和村子里最强的战士结婚的说。"
    - "普露塞娜：「谢谢你的好意，但是没必要的说。这些伤是荣誉的说，我要全部留下。……因为以后不知道能不能再见到莉妮亚，所以要留下来的说。」"
    - "莉妮亚：「因为是输掉的伤，老实说我想消掉喵。不过算了，这次就认分接受喵。反正只要经过一段时间，这种东西就会成为一种骄傲。」"

- 内容：亚德路迪亚族的恩情谚语/族规传说
  - 部族中流传着「亚德路迪亚族对恩情是百年不忘」的传言与信条（但在本章莉妮亚的指责中被斥为胡说八道）。
