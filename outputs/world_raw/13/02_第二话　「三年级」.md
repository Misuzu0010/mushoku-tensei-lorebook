# 第二话　「三年级」 世界设定提取

## 一、地理与场所
- 名称：涅里斯公国
  - 内容：被称为「魔法三大国之一」的国家。参孙老师与其妹妹莲学姐的故乡，莲为该国的王族。
  - 原文依据："我妹妹进入涅里斯公国的魔术骑士团，似乎适应得不错。只是如果丢着不管，不知道她又会惹出什么麻烦。""听说那个学姐是魔法三大国之一的涅里斯公国的王族，拥有卓越的魔术才能。"
- 名称：魔法大学城内治安环境（小巷与教会）
  - 内容：魔法大学所在城镇整体治安还算不错，但只要走入偏僻小巷，依然会有绑架犯出没，年幼孩童不宜独自行走。城内建有米里斯教会。
  - 原文依据："我经常在城里的教会见到你的妹妹。""虽说这附近的治安还算不错，不过只要走进小巷，还是有绑架犯出没。"
- 名称：鲁迪乌斯宅邸地下室
  - 内容：鲁迪乌斯宅邸地下室入口设有暗门，走下楼梯后内部建有秘密祭坛，上面供奉着象征两位妻子的神圣物品（贴身布料），鲁迪乌斯每日在此祈祷。
  - 原文依据："目的地是地下室。我蹑手蹑脚地走下楼梯，在地下室入口前多次确认后方，然后打开暗门。老实一句话，里面是祭坛。上面供奉的是……圣物。布和布，用来敬拜各自所属神明的神圣物品。今天，我也静静地在此祈祷。"

## 二、组织与势力
- 名称：涅里斯公国魔术骑士团
  - 内容：魔法三大国之一涅里斯公国的魔术骑士团队，参孙老师的妹妹莲（涅里斯公国王族）从魔法大学毕业后加入该骑士团。
  - 原文依据："我妹妹进入涅里斯公国的魔术骑士团，似乎适应得不错。只是如果丢着不管，不知道她又会惹出什么麻烦。"
- 名称：拉诺亚魔法大学特别生班级管理制度（班导配置机制）
  - 内容：特别生班级由于学生性格特立独行，班导通常安排与班上特别生有亲属关联或具备驾驭、掣肘能力的人物担任。参孙老师因妹妹莲在班上而担任班导，妹妹毕业后便预定离职回乡；洛琪希与鲁迪乌斯及札诺巴皆有深厚关联，因而被安排担任副班导，并预定于次年正式接手担任该班班导。
  - 原文依据："洛琪希老师因为种族的特性，外表看起来很年轻，不过实际上已经超过五十岁。听说她和这班上的同学有关系，因此安排她负责这个班级。目前暂时是副班导，从明年起会正式接手这个班级，也请大家做好心理准备。""我事后才知道，负责这个特别生班级的教师，原本就经常安排和特别生有关联的人物来担任。大概是因为有很多特别生都特立独行。所以最好是让有可能驾驭特别生，或是有可能掣肘特别生的人物来担任班导。例如目前的班导参孙老师，他的家人是在克里夫入学的那年毕业的某个学姐。听说那个学姐是魔法三大国之一的涅里斯公国的王族，拥有卓越的魔术才能。总而言之，洛琪希和我与札诺巴都有关连，可以算是最合适的人选。"
- 名称：米里斯教（教徒立场）
  - 内容：信奉米里斯教的神职与信徒严格推崇一夫一妻制，视一夫多妻为缺乏节操的行为，反对将女性当作收藏品；教徒面对公开的多妻宣告会发出嘘声。神职或修行者可代神明宽恕知罪反省者的罪过。
  - 原文依据："『你们两人都是我的挚爱！』这样宣告之后，一部分学生发出嘘声。肯定是米里斯教徒。没关系，我和你们信仰不同宗教，也不会干涉你们的主张。""增加太多伴侣不是什么好事，女性可不是收藏品。""很好。看你有在反省，我就原谅你的罪吧。因为米里斯大人非常宽宏大量。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔眼（预知眼）
  - 规则：鲁迪乌斯右眼植入的魔眼具备预知能力，在实战中能精确预判并避开敏捷兽族的爪击反击。
  - 原文依据："她伸出爪子想攻击，我靠着魔眼避开。"
- 名称：生活魔术应用（注水与即时加热）
  - 规则：将无咏唱水魔术与火魔术结合应用于日常生活，能在一瞬间用热水灌满整个浴池。
  - 原文依据："既然只剩下用热水灌满浴池的步骤，一瞬间就能完成。"
- 名称：魔术无效特性 [传闻提及]
  - 规则：九头龙具备使魔术无效化的生理与防御特性。
  - 原文依据："他说老大和魔术无效的九头龙交战，还说什么如果本王子有跟去，或许师傅就不会失去什么伟大云云的左手。"

## 四、种族 / 生物
- 名称：兽族（猫族、犬族）
  - 特征：
    1. 拥有动物特征的耳朵、尾巴与爪子，身体敏捷。
    2. 尾巴是兽族极度敏感且痛苦的弱点部位，被人强行拉扯会产生剧烈痛苦，人族难以理解这种感受。
    3. 毕业最高年级有决斗挑选男性对象并带回兽族故乡的婚配习俗。
    4. 具有通过生育后代（怀二胎等）争夺并确立妻子中第一地位的观念。
  - 原文依据："我们今年要毕业了，所以要挑个对象喵。""没错的说，今年要决斗，然后找个男人回故乡的说。""要赶快想办法怀上第二胎喵。""才能确立身为第一的地位的说。""人族无法理解这种痛苦喵，居然拉了少女的尾巴，实在不可原谅喵。"
- 名称：魔族（米格路德族）
  - 特征：具备长寿且外貌极难老化的种族特性，实际年龄即便已超过五十岁，外表看起来依然如少女般年轻。
  - 原文依据："洛琪希老师因为种族的特性，外表看起来很年轻，不过实际上已经超过五十岁。"
- 名称：犰狳（次郎）
  - 特征：被爱夏驯养照顾的生物，经训练后性格忠诚服从，表现如同看门狗般。
  - 原文依据："偶尔也会应付一下跑来缠她的犰狳次郎。顺便说一下，次郎好像由爱夏负责照顾。她把次郎训练得很好，最近慢慢变成如同看门狗般忠实的仆人。"

## 五、物品 / 道具 / 武器
- 名称：马奶
  - 说明：当地的传统滋补品，加热后供刚生产的产妇饮用，富含营养并能促进母乳充足分泌。
  - 原文依据："在这一带，为了让生了小孩的母亲能够奶水充足，都会让她们喝马奶。""今天的早餐是约可豆和薯类煮成的汤搭配小麦面包，还有营养丰富的马奶！"
- 名称：约可豆
  - 说明：当地常见食材豆类，常与薯类煮成绿色汤品作为日常主食之一。
  - 原文依据："我看了下，有绿色的汤和白色的面包……""今天的早餐是约可豆和薯类煮成的汤搭配小麦面包……"
- 名称：米（种子）
  - 说明：水稻/大米的种子，鲁迪乌斯带回后交由具种植才能的爱夏保管，计划待气候转暖后尝试育种试种。
  - 原文依据："我已经把要当成种子的米交给爱夏，拜托她如果种得活就麻烦了。爱夏说等天气再暖一点会试试看，实在可靠。我从现在起就满心期待，相信如天才般优秀的爱夏一定会让自己吃到米。"
- 名称：吸收的魔石
  - 说明：具备吸收魔力特性的魔法矿石/道具，鲁迪乌斯在平时研究其机制。
  - 原文依据："趁着空档研究吸收的魔石，还要提笔写作。"
- 名称：义手
  - 说明：鲁迪乌斯断臂后装配的人造义肢手，因外表引人注目而引发学校师生的各种猜测与传言。
  - 原文依据："只要大家看到老大的左手成了义手，一样会出现各种谣言的说。"
- 名称：圣物（布料）
  - 说明：鲁迪乌斯在地下室祭坛供奉的神圣物品，为两位妻子洛琪希与希露菲的贴身衣物（布料），每日被其虔诚参拜祈祷。
  - 原文依据："老实一句话，里面是祭坛。上面供奉的是……圣物。布和布，用来敬拜各自所属神明的神圣物品。今天，我也静静地在此祈祷。"

## 六、历史 / 传说 / 事件
- 事件名：迷宫归来与断臂传闻蔓延事件
  - 内容：鲁迪乌斯自转移迷宫断臂归来后，在魔法大学内部引发大量猜想与传言扩散。札诺巴透露了其与魔术无效九头龙激战断臂的经过；莉妮亚等人及其他学生则衍生出「前往魔大陆与七大列强交战取胜并断臂」、「和斯佩路德族大打出手」、「单枪匹马压制百万魔物」、「使用古代魔术遭力量反噬断臂」、「龙头老大的眼睛会发光」等夸张传闻。
  - 原文依据："说老大碰上强大到让你失去左手的强敌。""他说老大和魔术无效的九头龙交战，还说什么如果本王子有跟去，或许师傅就不会失去什么伟大云云的左手。""我仔细追问，才知道流传着一堆无凭无据的传言。例如：『和斯佩路德族大打出手』、『单枪匹马压制了百万魔物』、『成功使出古代魔术，却因为力量反弹而失去一只手』等等。""──学校的传言•其之二『龙头老大的眼睛会发光』──"

## 七、社会规则 / 习俗 / 文化
- 当地产妇产后滋补习俗：
  - 内容：当地为刚生产的母亲提供加热马奶，以帮助分泌充沛母乳。
  - 原文依据："在这一带，为了让生了小孩的母亲能够奶水充足，都会让她们喝马奶。"
- 兽族毕业决斗择偶与归乡习俗：
  - 内容：兽族学生在学校就读到最高年级毕业前夕，会通过决斗挑选配偶男性，随后一同返回故乡生活。
  - 原文依据："我们今年要毕业了，所以要挑个对象喵。""没错的说，今年要决斗，然后找个男人回故乡的说。"
- 兽族家庭阶级与妻妾观念：
  - 内容：兽族观念认为尽早生育下一代（生下第二胎）是确立其在妻子中第一地位的关键手段，若缺乏存在感且伴侣增多，会被逐渐边缘化并遭到冷落。
  - 原文依据："要赶快想办法怀上第二胎喵。""才能确立身为第一的地位的说。""菲兹没什么存在感，是那种等到再有第三、第四人之后，就会慢慢被赶往角落遭到冷落的类型的说。"
- 米里斯教戒律与宽恕规则：
  - 内容：米里斯教严格要求一夫一妻，视重婚纳妾为罪行，认为女性不是收藏品；但若违戒者能够坦诚反省，神职人员会以「米里斯大人非常宽宏大量」为由给予宗教宽恕。
  - 原文依据："增加太多伴侣不是什么好事，女性可不是收藏品。""很好。看你有在反省，我就原谅你的罪吧。因为米里斯大人非常宽宏大量。"
- 社交礼节规则：
  - 内容：在此地区（尤其贵族与学生社交圈），长期外出归来若未能第一时间登门问候打招呼，会引起对方相当介意；相比之下冒险者群体的社交则随性冷淡得多。
  - 原文依据："光是少打了一次招呼，似乎就会让这附近的人相当介意。爱丽儿也是一样。相较之下，冒险者们冷淡随性得多。"
- 格雷拉特家庭内部规矩：
  - 内容：家庭内部自然形成了「洗澡时尽量两人一组」的默契；洗澡时被要求用毛巾遮挡身体正面以作为端庄礼貌的修养。
  - 原文依据："不知不觉之间，这个家已经形成『洗澡时尽量两人一组』的默契。""爱夏，洗澡时要用毛巾遮住前面。……这是一种修养。"

## 九、角色认知 vs 客观事实
- 角色认知 1：
  - 角色以为：鲁迪乌斯看到女儿露西极少哭闹且表现乖巧，一度怀疑她是前世坏男人转世的「转生者」，甚至用日文与英文进行语言试探。
  - 原文是否暗示另有真相：否（露西只是性格乖巧的普通婴儿，对试探言语仅发出咿呀婴儿回应）。
  - 原文依据："露西虽然很健康，但是个性乖巧。由于她实在太少哭闹，我曾经怀疑露西是不是生了什么病……『露西小姐会让人回想起鲁迪乌斯少爷小时候呢。』『转生者』这个名词闪过我的脑海。……虽然也不能说是经过验证后的结果，不过我想露西并不是转生者。因为她听了我的话，只会笑着呜呜啊啊回应。"
- 角色认知 2：
  - 角色以为：莉妮亚以为鲁迪乌斯是前往魔大陆与世界顶尖战力「七大列强」交战，牺牲左手战胜强敌并逼对方狼狈逃走，并试图大加宣扬。
  - 原文是否暗示另有真相：是（这是莉妮亚自己编造吹捧的英雄传奇；客观事实是鲁迪在迷宫中迎战魔术无效的九头龙并断臂）。
  - 原文依据："不愧是老大，居然可以前往魔大陆和七大列强交战，而且牺牲左手获得胜利喵！""而且，听说对方还连滚带爬地狼狈逃走，不愧是老大的说。""以上是我刚刚想到的老大传奇喵，只要把这件事大大宣扬出……""他说老大和魔术无效的九头龙交战……"
- 角色认知 3：
  - 角色以为：魔法大学学生之间流传鲁迪乌斯是「和斯佩路德族大打出手」、「单骑讨伐百万魔物」、「施展古代魔术力量反噬」而失去左手，以及「眼睛会发光」。
  - 原文是否暗示另有真相：是（均为校园内毫无根据的荒唐谣言）。
  - 原文依据："我仔细追问，才知道流传着一堆无凭无据的传言。例如：『和斯佩路德族大打出手』、『单枪匹马压制了百万魔物』、『成功使出古代魔术，却因为力量反弹而失去一只手』等等。""──学校的传言•其之二『龙头老大的眼睛会发光』──"
- 角色认知 4：
  - 角色以为：克里夫认为诺伦之所以最终原谅鲁迪乌斯迎娶第二个妻子，是出于弱者心理，担心若坚决反对会被鲁迪赶出家门流离失所。
  - 原文是否暗示另有真相：不明 / 角色个人推测（克里夫从米里斯教徒及弱者立场进行主观推想，鲁迪乌斯本人明确表示绝不会做出赶走妹妹的行为）。
