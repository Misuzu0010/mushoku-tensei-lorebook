# 第一话　「洛琪希成为教师」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚魔法大学（魔法大学内部设施）
- 内容：北方大地的最高魔法学府。校内设有副校长室/会客室、专供研究者与特待生使用的个人研究室（如札诺巴研究室、克里夫研究室等）。学制设有学年与学期制度（鲁迪乌斯升入三年级，洛琪希预定下学期起任教）。冬季走廊寒冷，校内流传着各种关于学生的荒诞传闻。
- 原文依据："「鲁迪，我想去魔法大学工作，可以吗？」"、"我的身分也有改变，从今天起就是三年级了。"、"一行人移动到会客室后，我和洛琪希并排坐在吉纳斯的正对面。"、"目的地是札诺巴的研究室。"、"嘎叽嘎叽的声音在寒冷的走廊中回响着。"、"不管怎么样，洛琪希似乎已经确定从下学期起就会开始在这间学校任教。"

- 名称：基亚拉公国 [存疑]
- 内容：曾经存在的一个公国，拥有特色的传统手工艺（如木雕马工艺），但在当前时间点已经灭亡不存在。
- 原文依据："「呜呜……这只木雕马是基亚拉公国的传统工艺……但是基亚拉公国已经不存在，恐怕再也无法……」"

- 名称：米里斯神圣国
- 内容：距离拉诺亚王国非常遥远的大陆国家。国内聚集有能够施展令缺损肢体重生的高等治愈魔术的治疗术师，但即便在该国这类人员数量也极为稀少。
- 原文依据："虽说前往米里斯神圣国就找得到那样的人，不过数量还是寥寥无几。若以冒险者的生活水准来看，根本是遥不可及的事情。"、"米里斯的治疗术师或许会因此蒙受损失，不过两地相隔遥远，只要请魔法大学或魔术公会居间协调，我觉得有机会能行得通。"

- 名称：贝卡利特大陆
- 内容：鲁迪乌斯等人此前远征的大陆，当地存在玻璃人偶等特色工艺品。
- 原文依据："后来，我和札诺巴又聊了一会儿，内容主要是关于我在贝卡利特大陆上看到的人偶。提到玻璃人偶时，札诺巴兴奋得两眼都亮了起来。"

- 名称：洛琪希的故乡（魔大陆米格路迪亚族村落）
- 内容：距离拉诺亚极为遥远，若借助数个转移魔法阵进行长途跨洲跋涉，大约需要耗费两个月左右时间才能到达。
- 原文依据："「呜……不，没有必要那样做。毕竟我的故乡很远，还是等以后再说吧。」"、"总觉得只要通过几个转移魔法阵，大概两个月左右就能到达，不过……"

## 二、组织与势力
- 名称：拉诺亚魔法大学管理层
- 内容：由吉纳斯副校长掌管日常繁杂行政公文审批、外宾会客与教师考核录用。副校长拥有直接审核并录用教师的权力。
- 原文依据："一如往常，吉纳斯身边到处是堆积如山的文件。"、"「是这样的，师傅。我后来经历了很多事，也因此明白教导他人的乐趣，所以想请教是否有机会让我在这里职掌教鞭。」"、"「嗯，吉纳斯师傅……副校长也认可了我的能力。」"

- 名称：魔术公会
- 内容：与魔法大学并立的跨区域魔术组织，能够在魔道具产业推广以及跨地域/跨行业利益冲突（如魔道具义手与米里斯治疗术师的利益纠纷）中充当协调斡旋的中介机构。
- 原文依据："米里斯的治疗术师或许会因此蒙受损失，不过两地相隔遥远，只要请魔法大学或魔术公会居间协调，我觉得有机会能行得通。不，肯定行得通。"

- 名称：米里斯治疗术师群体
- 内容：米里斯神圣国内掌握高等治愈魔术的群体。因垄断肢体断裂重生的昂贵医疗手段而享有极高收益，对低成本机械/魔道具义肢的普及可能存在行业利益竞争。
- 原文依据："但是，治疗肢体缺损很花钱。一旦完全失去身体的一部分，除非财力相当雄厚，否则难以接受治疗。更何况这世上没有几个人类有能力施展那种可以让缺损部位再长出来的高等治愈魔术。虽说前往米里斯神圣国就找得到那样的人，不过数量还是寥寥无几。"、"米里斯的治疗术师或许会因此蒙受损失，不过两地相隔遥远，只要请魔法大学或魔术公会居间协调，我觉得有机会能行得通。"

## 三、力量体系 / 魔法 / 技能
- 名称：双系魔术师称号规则 [存疑]
- 规则：根据鲁迪乌斯的认知，魔术界即使有人能同时掌握两个系统的同阶高阶魔术（如兼具水圣级与火圣级），也不会被称为“Double”或“Twin”，因此外部往往只知其单一属性称号。
- 原文依据："嗯？吉纳斯是水圣级魔术师吗？我一直以为他是火圣级，是不是我误会了？不，就算能够使用两种类别的魔术，也不会被称为Double或Twin。所以应该只是自己不知道而已，其实吉纳斯同时也身为水圣级魔术师。"

- 名称：治愈魔术分级效果与医疗成本体系
- 规则：
  1. 初级治愈魔术：普及度较高，能轻松治愈前世需要专门医疗机构处理的严重外伤。
  2. 高等治愈魔术：具备将断肢接回或促进缺损部位重新生长的神迹级效果，但全大陆掌握者寥寥无几（主要集中在米里斯神圣国），施法费用极其高昂，普通冒险者与平民完全无力承担。
- 原文依据："在这个世界里，就算四肢遭到切断，也能够靠高等治愈魔术来接上断肢或促进重生。除此之外，甚至连那种在前世必须前往适切设施进行治疗的伤势，在这里也只要会使用初级治愈魔术就足以轻松治好。但是，治疗肢体缺损很花钱。一旦完全失去身体的一部分，除非财力相当雄厚，否则难以接受治疗。更何况这世上没有几个人类有能力施展那种可以让缺损部位再长出来的高等治愈魔术。虽说前往米里斯神圣国就找得到那样的人，不过数量还是寥寥无几。若以冒险者的生活水准来看，根本是遥不可及的事情。"

- 名称：手部魔道具运行机制（札里夫义手）
- 规则：
  1. 语音契约/指令启闭：佩戴后需吟诵特定言灵咒语启动（如“土啊，成为吾之臂膀吧”），内侧会与残肢断面紧密贴合并抽取使用者魔力运转；取下时需吟诵解除咒语（“臂膀啊，回归为土壤吧”）。
  2. 感知与神经同步：启动后佩戴者能获得触觉和温度感知（虽有些许迟钝如同隔着厚手套），并能随心所欲活动五指。
  3. 魔力强化与负荷上限：注入魔力可成倍放大力量，但若注入过大魔力会超出承载极限导致构件损坏。
  4. 施法媒介：魔道具能作为魔力导体，佩戴者可通过义手指尖直接释放魔术（如生成水弹）。
  5. 续航消耗：持续运转需消耗佩戴者魔力，以札诺巴的魔力量仅能维持2至3小时。
  6. 诅咒抑制：该魔道具具备抑制佩戴者天生“神子/怪力”诅咒的特殊作用。
- 原文依据：
  "「这是能够按照使用者意志动作的手部魔道具。」"、
  "「因为只要使用这个魔道具，甚至还能够抑制本王子的怪力。」"、
  "「只要戴上并下令：『土啊，成为吾之臂膀吧』，这东西就会化为使用者的手。至于想拆下时，也只需咏唱『臂膀啊，回归为土壤吧』即可。」"、
  "刚讲完这句话，我随即感觉到魔力从手上被吸走。被吸走的魔力并不算多。毕竟连札诺巴也能使用，这是当然。下一瞬间，魔道具的内侧紧贴到左手的断面上。有东西贴着的感觉慢慢消失，同时「指尖」的感觉也逐渐浮现。"、
  "我试着从指尖放出小型魔术，成功制造出约莫小指前端大小的水弹。看样子在魔术方面也能顺利使用。"、
  "「如果想增强力道，只需注入魔力即可。灌注的魔力越多，力量就越大。」……「不过呢，若是师傅使出全力来灌注魔力，手套应该会坏掉。这东西虽然做得比人手坚固，还是要请您特别注意。」"、
  "听说若以札诺巴的魔力为基准，大概只能支撑两到三个小时。"

- 名称：九头龙战斗与克制机制（回顾）
- 规则：九头龙天生具备“魔术无效”体质，物理肉体极其强悍，头颅被斩下后能快速再生。攻略克制方法是由近战剑士负责斩首，随即立刻用火焰/热量彻底烧毁断面伤口以遏制再生。
- 原文依据："「嗯，是魔术无效的九头龙。」「九头龙吗……唔，确实是强敌。」……「是啊，而且那家伙的脑袋被砍掉之后会再生，实在很难对付。」「先由我的父亲……剑士砍下头部，我再烧毁伤口。」"

- 名称：转移魔法阵机制
- 规则：古代遗留的长途空间传送设施，可通过多个转移魔法阵连环中转实现跨大陆旅行，将数年的常规旅程缩减至两个月左右。
- 原文依据："总觉得只要通过几个转移魔法阵，大概两个月左右就能到达，不过……"

## 四、种族 / 生物
- 名称：米格路迪亚族（魔族）
- 特征：水蓝色长发、体型娇小玲珑、容貌幼小且长寿。成年女性外观身形依然如少女幼女般纤细，缺乏明显的起伏曲线。故乡位于遥远的魔大陆。
- 原文依据："会让人觉得是否过于幼小的肢体；欠缺起伏，绝对无法算得上有女人味的腰部线条。"、"水蓝色长发间隐约可见的洁白后颈！"、"我猜他们大概是无法相信外表年幼的洛琪希要登上讲坛吧。"、"「毕竟我的故乡很远，还是等以后再说吧。」"

- 名称：兽族
- 特征：保留动物特征（耳朵、尾巴），嗅觉与感官极其敏锐，能通过辨识气味察觉他人实力差距与亲密从属关系。在遭遇上位威压或不可违逆的气势时会本能地吓得缩起尾巴并低头屈服。
- 原文依据："莉妮亚和普露塞娜的反应尤其有趣。她们光是闻了一下洛琪希的味道就吓得发抖。我向缩起尾巴的两人介绍洛琪希是自己敬爱的师傅后，两人一起低下头行礼。这大概是因为兽族很敏感才能理解吧……理解什么叫作真正不可违逆之人的气势。"

- 名称：九头龙
- 特征：强大的迷宫魔物，拥有九个头颅，具备魔术无效体质与断头快速再生特性。
- 原文依据："「嗯，是魔术无效的九头龙。」「九头龙吗……唔，确实是强敌。」……「是啊，而且那家伙的脑袋被砍掉之后会再生，实在很难对付。」"

## 五、物品 / 道具 / 武器
- 名称：札里夫义手（试作品第一号）
- 说明：札诺巴与克里夫逆向解析自动人偶构造所制成的手部魔道具试作样品，后赠予失去左手的鲁迪乌斯。外观粗陋类似厚护手模型，由土魔术材质及魔力回路构成。能根据使用者意志如真实手臂般自如开合手指，具备触觉与温感，可传导释放魔术，注入魔力可成倍放大握力，并能抑制札诺巴的怪力。目前缺陷包括外观粗糙、手指粗大缺乏美感、触感不够敏锐（类似隔着厚手套）、开合伴随机械摩擦嘎叽声无法静音、札诺巴魔力仅可维持2~3小时。
- 原文依据：
  "拿出来的东西是一个手部模型。不，不对。若要说是手部模型，这东西有点太粗陋了。外观要说是类似护手也还说得通，我想大概是手套的模型吧。"、
  "「这是能够按照使用者意志动作的手部魔道具。」「本王子按照师傅您的指示，针对那个人偶进行研发，还找了克里夫来协助，努力走到了这一步。」"、
  "「从札诺巴和克里夫各取几个字，叫作『札里夫义手』如何？」……「那么这个手套就是『札里夫义手』的试作品第一号。」"、
  "嘎叽嘎叽的声音在寒冷的走廊中回响着。是我的义手发出来的声音。我边走边进行调整，确定到底该注入多少魔力。每次开合手掌，义手就会发出嘎叽声。毕竟是试作的产品，再怎么样也不能设计成静音。"

- 名称：自动人偶（Automaton）
- 说明：拥有自主行动机制与精细机构的古代魔导人偶，札诺巴与鲁迪乌斯的核心研发目标，义手仅为其研发手部构造过程中的副产品。
- 原文依据："「本王子按照师傅您的指示，针对那个人偶进行研发，还找了克里夫来协助，努力走到了这一步。」"、"「本王子也明白这东西还有很多必须改进的地方，可是自动人偶的研究也必须继续进行。您觉得该怎么办？」"、"「不管再怎么说，我们的目的都是要制作出自动人偶，不能忘记这一点。」"

- 名称：基亚拉公国木雕马
- 说明：已灭亡的基亚拉公国的传统工艺品，拳头大小的马形木雕，存世稀少且无法再现。札诺巴的珍藏品之一，因鲁迪乌斯测试义手注入魔力过载而被捏断马腿。
- 原文依据："我拿起旁边的木制雕像，那是一只拳头大小的马。"、"木雕马的脚断了。……「呜呜……这只木雕马是基亚拉公国的传统工艺……但是基亚拉公国已经不存在，恐怕再也无法……」"

- 名称：玻璃人偶
- 说明：存在于贝卡利特大陆上的人偶工艺品，造型特殊，令札诺巴极为神往。
- 原文依据："后来，我和札诺巴又聊了一会儿，内容主要是关于我在贝卡利特大陆上看到的人偶。提到玻璃人偶时，札诺巴兴奋得两眼都亮了起来。"

- 名称：瑞杰路德人偶
- 说明：茱丽在鲁迪乌斯离开期间独立制作并完成的斯佩路德族战士瑞杰路德的黏土模型人偶。
- 原文依据："「茱丽在几天前完成了那位大人的人偶，她应该很想让师傅您看看。」唔，瑞杰路德人偶完成了吗？"

## 七、社会规则 / 习俗 / 文化
- 内容：
  1. 王族身份尊卑与阶级礼节：王室成员与平民之间有严格的阶级礼法差距。一国王储/王子（如札诺巴）公然对平民身份的教师行五体投地跪拜大礼，被视为严重违背常理、引人非议且令平民惶恐不安的行为。
  2. 婚后冠夫姓与第二夫人身份名分：女性结婚后姓名需变更为丈夫家族的姓氏（洛琪希原名洛琪希·米格路迪亚，婚后正式全名为“洛琪希·M·格雷拉特”）。即使在多妻制中作为第二夫人，也是具备合法繁衍后代地位的正式妻子；在社交圈介绍时，女性极度看重丈夫公开承认并介绍其为“妻子”而非含糊的“老师”或旧称。
  3. 肢体残疾者的阶层分化待遇：由于肢体再生的高等治愈魔术极度昂贵且罕见，平民与底层冒险者一旦断肢，普遍只能依靠简易木棒作为假肢度日，只有大富豪或顶级权贵才能承担断肢重生的医疗费用。
  4. 家族重大喜事合并庆祝的家庭习惯：经历重大变故与动荡后，家庭倾向于选择稳定时期，将结婚、成人礼（妹妹十岁生日）、新生儿诞生等重大事件合并举办大型家族庆祝宴会。

  "「请您抬起头来，一国的王子居然对区区在下这么客气，实在让人惶恐。要是被其他人看到该怎么办呢！」洛琪希惊慌失措。"、

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯根据洛琪希称吉纳斯为师傅，推测原本被自己认为是火圣级魔术师的吉纳斯“同时也身为水圣级魔术师”。
- 原文是否暗示另有真相：不明 [存疑]。原文仅为鲁迪单方面推论与心理活动，并未交代吉纳斯具体掌握的魔术等级与属性实力。
- 原文依据："嗯？吉纳斯是水圣级魔术师吗？我一直以为他是火圣级，是不是我误会了？不，就算能够使用两种类别的魔术，也不会被称为Double或Twin。所以应该只是自己不知道而已，其实吉纳斯同时也身为水圣级魔术师。"

- 角色以为：鲁迪乌斯以为兽族少女莉妮亚和普露塞娜闻到洛琪希气味吓得发抖缩尾巴下跪，是因为兽族本能理解了洛琪希身上“不可违逆之人的气势”。
- 原文是否暗示另有真相：是。前文明确交代鲁迪乌斯昨晚刚与洛琪希同房，洛琪希身上带有鲁迪乌斯极其浓重且具有支配性的气味。莉妮亚和普露塞娜对“老大”鲁迪乌斯极度畏惧，闻到的是鲁迪的气味而非洛琪希本身的气势，鲁迪产生了自得的误解。
- 原文依据："莉妮亚和普露塞娜的反应尤其有趣。她们光是闻了一下洛琪希的味道就吓得发抖。我向缩起尾巴的两人介绍洛琪希是自己敬爱的师傅后，两人一起低下头行礼。这大概是因为兽族很敏感才能理解吧……理解什么叫作真正不可违逆之人的气势。"

- 角色以为：鲁迪乌斯以为向他人大力推介洛琪希为“伟大的老师”、用尽辞藻夸奖是对她最崇高的尊重与爱意。
- 原文是否暗示另有真相：是。洛琪希本人不仅感到尴尬、认为鲁迪在过度吹捧甚至是在嘲讽揶揄自己，而且洛琪希更渴望并期待的是鲁迪向社交圈公开宣布自己作为“妻子”的身份名分。
- 原文依据："「我很高兴你愿意把我介绍给其他人认识，不过你对我的评价似乎有点过于夸大。」……「唉……每次鲁迪称呼我为『老师』时，我总有一种遭到嘲讽的感觉。」……「这件事也就算了，鲁迪你明明把我介绍给很多人，却只会说我是『老师』，不愿意称呼我为『妻子』。」"

- 角色以为：札诺巴和鲁迪乌斯认为，洛琪希是“师傅的师傅”，因此身为一国王子的札诺巴向平民洛琪希行五体投地跪拜大礼是天经地义、理所当然的。
- 原文是否暗示另有真相：是。在贵族社会的客观礼法制度中，一国王储身份的贵族向平民行叩拜大礼属于严重的逾矩与失礼，会给被叩拜的平民带来巨大的社交非议与惶恐，洛琪希吓得极度惊慌。
- 原文依据："「请您抬起头来，一国的王子居然对区区在下这么客气，实在让人惶恐。要是被其他人看到该怎么办呢！」洛琪希惊慌失措。……「是！因为洛琪希小姐是师傅的师傅。」看吧，连札诺巴也这么说。「我不是要问当不当然，我是想知道理由！」「理所当然的事情没有理由，老师只要直接泰然以对就好了。」"

- 角色以为：学校学生流传龙头老大（鲁迪乌斯）的断臂手能发射出去。
- 原文是否暗示另有真相：是。札里夫义手仅为试作型魔道具假肢，开合时伴随机械咔叽声，并不具备火箭飞拳发射功能，属于学生们添油加醋产生的荒谬校园谣言。
- 原文依据："──学校的传言•其之一「龙头老大的手能发射出去」──"、"讲到可以拆下来的手，头一个会联想到的东西就是那个，火○飞拳。不过这只手并不会飞出去……虽然要射出去应该是办得到啦。"
