# 第三话　「Training with 诺伦」 世界设定提取

## 一、地理与场所
- 名称：第三室外修练场
- 内容：拉诺亚魔法大学校园内的设施，即操场的角落区域。学生常在此处进行自主训练、散步，或驻足围观他人的训练活动。
- 原文依据："来到傍晚时刻，地点是魔法大学校园一角。我站在第三室外修练场──也就是操场的角落。"

- 名称：剑圣之地
- 内容：位于西方的地域，聚集了众多具备剑圣阶级的高手。如果招募时备足丰厚的报酬，可能有剑圣等级的剑士愿意前往外地担任剑术指导。
- 原文依据："不然就是西方有个被称为剑圣之地的区域，只要招募时多准备点报酬，说不定会有剑圣等级的人愿意过来教诺伦。"

## 二、组织与势力
- 名称：诺伦•格雷拉特公设粉丝同好会
- 内容：于甲龙历四二五年在拉诺亚魔法大学内成立的组织。起初由数十名在日常实习与授课中被诺伦拼命却频频失败的可爱模样治愈的男学生自发聚集形成；后由鲁迪乌斯以兄长身份介入并订立规则以规范行为、防止犯罪，并出任第一任会长（名字未公开）。成员共计三十人，被后世记载为对后来的魔法大学产生巨大影响的组织。
- 原文依据："甲龙历四二五年。拉诺亚魔法大学里成立了一个组织。诺伦•格雷拉特公设粉丝同好会。总人数多达三十人的这个集团，被认为是对后来的魔法大学带来巨大影响的组织。第一任会长的名字并未公开。"

- 名称：米里斯教
- 内容：拥有特定宗教礼仪的信仰派别。其信徒在进行祈祷时，通常采取双膝跪地、双手合握祈愿的仪式姿势。
- 原文依据："转头一看，诺伦也跪了下来，以米里斯教的方式握着手祈祷。"

## 三、力量体系 / 魔法 / 技能
- 名称：剑术阶级划分（初级、剑圣）
- 规则：剑术具有明确的阶级段位体系，包括基础达标的“名正言顺的初级”，以及高阶层级的“剑圣等级”。
- 原文依据："等到诺伦的水准差不多达到名正言顺的初级时，或许找基列奴来教她会比较好。……只要招募时多准备点报酬，说不定会有剑圣等级的人愿意过来教诺伦。"

- 名称：实战剑术理念
- 规则：剑术本质为具威胁性、带来疼痛与肉体伤害的残酷战斗技术；在这个世界练习剑术不拘泥于死板规矩，实际肉搏对打中最依仗实战“经验”；战场胜负往往直接关乎生死，弱者战败便可能丧命。
- 原文依据："如果是前世的剑道，大概必须学习更多东西，但是这个世界没有那些规矩。而且进一步来说，干架这种事情就是「经验」最能发挥效果。" 以及 "两方相战，强的一方会赢，弱的一方会输。一旦输了会丢掉性命，因此不能说输了也没关系。"

- 名称：治愈魔术
- 规则：能够迅速治愈肉体轻伤、擦伤及磕碰导致的皮下瘀青，并有效缓解疼痛，常用于日常受伤救治与剧烈训练后的身体恢复。
- 原文依据："她慢跑时经常跌倒，有时候膝盖上会有伤口或瘀青。遇上这种情况时，我会施展治愈魔术。也就是对妹妹的膝盖使出「痛痛飞走了」的魔法。" 以及 "我迅速治好诺伦的伤，吩咐她快点去更衣室。"

- 名称：魔法大学实战与基础魔术教学
- 规则：魔法大学设置了属性魔术实践（如火魔术实习）与“魔术战斗训练”课程，训练过程中配备专门教官对学生的失误进行当场指导与严厉训斥。
- 原文依据："我跟她同学年，还一起实习，有次看到她因为火魔术失败好几次──在魔术战斗训练时被教官责骂，眼中噙着泪水的样子，就不由自主地──"

## 四、种族 / 生物
- 名称：长耳族
- 特征：身材与体态维持能力极强，即使经历怀胎生育，臀部与身体线条依然能保持紧致优美、不易走形变样。
- 原文依据："尽管已经生过小孩，希露菲的屁股却没有变大。艾莉娜丽洁的身材也保持得很好，长耳族真是厉害的种族。"

## 五、物品 / 道具 / 武器
- 名称：魔术石剑
- 说明：鲁迪乌斯使用土魔术自行塑造制造的训练用重剑。虽然外形粗粝且刀刃并未开锋，但具备相当的重量，适合搭配怪力强大的魔导义手进行挥动和力量训练。
- 原文依据："换好衣服之后，我拿起放在房间角落的石剑。外型不太好看的这把石剑是自己用魔术制造而成的东西。刀刃部分并未开锋，不过颇有重量，适合力量强大的义手使用。"

- 名称：义手（魔导义手）
- 说明：鲁迪乌斯左臂佩戴的义手假肢，具备远超常人肉体的强大力量。
- 原文依据："刀刃部分并未开锋，不过颇有重量，适合力量强大的义手使用。"

- 名称：照相魔道具 [存疑]
- 说明：推测可能存在能够拍下并保存具体场景画面的魔道具，但在该世界中极为罕见且并未普及。
- 原文依据："认真去找或许可以找到能拍下场景的魔道具，然而那种东西并不普及。因此只能像这样供奉死者的遗物，用来代替佛龛。"

- 名称：保罗的剑（死者遗物）
- 说明：保罗•格雷拉特生前爱用的佩剑。保罗战死后，该剑被挂在诺伦房间的墙壁上供奉，作为代替佛龛祭奠死者的凭依。
- 原文依据："发现保罗的剑被挂在墙上。……因此只能像这样供奉死者的遗物，用来代替佛龛。我站到保罗爱剑的前方，双手合十。"

- 名称：魔法大学指定体操服
- 说明：拉诺亚魔法大学校方指定的专用运动服，样式为长袖上衣搭配长裤，设计朴素保守且缺乏女性曲线美感，在大学校内贩卖部有售。
- 原文依据："身穿体操服的诺伦拿着木剑走了出来。这套长袖上衣搭配长裤的体操服穿起来一点女人味都没有，是魔法大学指定的体操服。正好大学的贩卖部里有卖，所以我就买来给她。"

- 名称：魔法大学制服与防寒斗篷
- 说明：拉诺亚魔法大学统一规制的校服，搭配裙装；在寒冷或多风天气，可在制服外加套类似雨衣式斗篷的防寒外衣。
- 原文依据："她在平常的制服上套着一件很像雨衣式斗篷的防寒衣。" 以及 "学校订出制服时我还认为何必做那种徒劳的事情，现在却觉得那身衣服很棒。"

## 六、历史 / 传说 / 事件
- 事件名：甲龙历四二五年诺伦粉丝同好会成立
- 内容：甲龙历四二五年，拉诺亚魔法大学内正式建立起拥有三十名成员的“诺伦•格雷拉特公设粉丝同好会”，对后续的魔法大学发展产生了深远影响，首任会长未公开其姓名。
- 原文依据："甲龙历四二五年。拉诺亚魔法大学里成立了一个组织。诺伦•格雷拉特公设粉丝同好会。总人数多达三十人的这个集团，被认为是对后来的魔法大学带来巨大影响的组织。第一任会长的名字并未公开。"

- 事件名：学校传言•其之三「龙头老大的一声令下」
- 内容：拉诺亚魔法大学校内流传的都市传说之一，称被称为“龙头老大”（鲁迪乌斯）的人物只要发号施令，随时随地至少能迅速召集三十名手下听候调遣。
- 原文依据："──学校的传言•其之三「龙头老大一声令下，至少可以立刻召集到三十个人」──"

## 七、社会规则 / 习俗 / 文化
- 内容：死者遗物祭奠习俗。由于该世界缺乏普及的照片记录技术，人们祭奠已故亲友时，通常通过在住处悬挂、供奉死者生前遗物（如惯用武器）的方式来代替佛龛进行日常祈祷与缅怀。
- 原文依据："如果是生前，会在佛龛附近放上遗照，不过这世界没有照片。认真去找或许可以找到能拍下场景的魔道具，然而那种东西并不普及。因此只能像这样供奉死者的遗物，用来代替佛龛。"

- 内容：米里斯教祈祷仪式礼仪。米里斯教信众在向神明祷告时，习惯性双膝跪地、双手十指交握于胸前祈祷。
- 原文依据："转头一看，诺伦也跪了下来，以米里斯教的方式握着手祈祷。"

- 内容：成年年龄与责任认知。在该世界，十八岁左右已被社会公认为正式的成年人，必须具备对残酷现实、生死斗争的成熟理解与自担后果的能力。
- 原文依据："年龄大概是十八岁左右吧……这些人虽然还很年轻，但在这个世界已经是成人了，自然能够理解战斗的严酷。"

- 内容：奴隶贩卖与人身安全风险。社会治安中潜伏着绑架防卫脆弱者并倒卖为奴隶的犯罪风险，且奴隶买卖在社会体制中存在交易市场。
- 原文依据："万一碰上绑架犯，她可能会逃不掉。要是小诺伦成了奴隶，我会买下她。" 以及 "要是诺伦成了奴隶，我也会找到买下她的家伙，让对方狠狠受到教训。"

- 内容：生食海鲜习惯缺失 [存疑]。根据鲁迪乌斯的观察推断，该世界居民普遍缺乏生吃海鲜（生鱼片等刺身）的饮食习惯与餐饮文化。
- 原文依据："话说回来，自从来到这世界以后，我就再也没吃过生鱼片了。这里大概没有生吃海鲜的文化吧。"

## 九、角色认知 vs 客观事实
- 角色以为：粉丝同好会男学生们以为鲁迪乌斯逼迫从未握过剑的诺伦进行严酷训练，是在操场借训练之名发泄心中怨气，蓄意折磨、虐待与霸凌妹妹。
- 原文是否暗示另有真相：是
- 原文依据："你为什么霸凌小诺伦？……小诺伦确实有点迟钝，也经常失败。或许她的失败让你感到不快，可是，她总是非常拚命。所以你没有必要把她折磨成那样吧？而且基本上，小诺伦根本没有拿过剑。结果你却逼她拿着剑承受那么严格的训练，再怎么说都太过分了吧？" 与 "是诺伦本人主动提出想要学习剑术，如果只有半吊子的决心会很危险，而且诺伦必须比别人加倍努力。"

- 角色以为：鲁迪乌斯起初以为这些保护诺伦的学生是一个有组织掌控者、明文纪律以及接触规则（类似前世偶像粉丝团与握手会规约）的正规粉丝组织。
- 原文是否暗示另有真相：是
- 原文依据："感觉两边在各说各话，他们对粉丝同好会、规约这些名词也没什么反应。……追问详情之后，我得知奇妙的事实。看样子这个社团并不是由哪个人率先号召组织而成，而是各人目睹诺伦可爱行为后自然聚集，最后成了集团。听说在集团内，他们连彼此叫什么都不清楚。"

- 角色以为：魔法大学学生传言以为“龙头老大”（鲁迪乌斯）是具有恶霸势力的帮派头目，一声令下随时能召集三十名暴力打手。
- 原文是否暗示另有真相：是
- 原文依据："总人数多达三十人的这个集团，被认为是对后来的魔法大学带来巨大影响的组织。第一任会长的名字并未公开。──学校的传言•其之三「龙头老大一声令下，至少可以立刻召集到三十个人」──"（所谓召集的三十人实际上是鲁迪乌斯为了保护妹妹而整编立规的“诺伦粉丝同好会”学生成员）。

- 角色以为：鲁迪乌斯以为这个世界大概完全没有生吃海鲜（生鱼片）的文化。
- 原文是否暗示另有真相：不明（仅为鲁迪乌斯根据自身在中央大陆等地的生活经验做出的主观猜测，故标注[存疑]）。
- 原文依据："话说回来，自从来到这世界以后，我就再也没吃过生鱼片了。这里大概没有生吃海鲜的文化吧。"
