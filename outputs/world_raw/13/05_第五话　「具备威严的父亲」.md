# 第五话　「具备威严的父亲」 世界设定提取

## 一、地理与场所
- 名称：夏利亚（魔法都市夏利亚）
  - 内容：提摩西的故乡，提摩西与苏珊娜结婚后定居于此。当地夏季积雪融化，连续多日干燥炎热。
  - 原文依据："季节来到夏天。积雪已经融化，连续几天都很干燥炎热。"，"两人回到提摩西的故乡夏利亚定居。"
- 名称：巴榭兰特公国边境城镇
  - 内容：位于北方大地的巴榭兰特公国边境，鲁迪乌斯十二岁与艾莉丝分别后抵达的城镇，在此解散了队伍「Dead End」，也是其初次与苏珊娜的队伍结识并共同接取委托的地点。
  - 原文依据："只身到达巴榭兰特公国边境城镇的我解散了队伍「Dead End」，也因此受到难以言喻的寂寥感侵袭。"
- 名称：阿斯拉王国
  - 内容：原苏珊娜队伍成员帕特里斯在队伍解散后返回该国，打算成为士兵。国内的地方贵族伯雷亚斯家有着严苛的家族养育习俗。
  - 原文依据："帕特里斯也回阿斯拉王国去了，说是要成为士兵。"，"连阿斯拉王国的地方贵族伯雷亚斯家也是，旁支的男孩必须交给当家养育。"
- 名称：消灭的大陆 [存疑]
  - 内容：魔石多头龙曾栖息的大陆，随着该大陆的消灭，魔石多头龙一并绝灭。
  - 原文依据："由于魔石多头龙随着大陆消灭而一并绝灭，现在这种魔石被视为梦幻魔石。"

## 二、组织与势力
- 名称：苏珊娜的原冒险者队伍
  - 内容：过去活跃于北方大地的五人冒险者队伍，由两名战士（包含苏珊娜）、一名弓术师（莎拉）、一名治愈术师、一名魔术师（队长提摩西）组成。队伍阶级为B级低阶，全员皆为老手。在鲁迪乌斯离开北方边境城镇后不久，因缺少一人难以维系而解散。
  - 原文依据："他们是由两名战士，一名弓术师，一名治愈术师，和一名魔术师所组成的五人队伍。队伍层级虽然是B级低阶，不过五个人都是老手。"，"是啊，你离开后没多久就解散了。毕竟凭我们的实力，少了一个成员之后实在很辛苦。帕特里斯也回阿斯拉王国去了，说是要成为士兵。"
- 名称：阿斯拉王国伯雷亚斯家
  - 内容：阿斯拉王国的地方贵族，家族规定旁支所生的男孩必须交由主家当家抚养。
  - 原文依据："连阿斯拉王国的地方贵族伯雷亚斯家也是，旁支的男孩必须交给当家养育。"

## 三、力量体系 / 魔法 / 技能
- 名称：弓术 / 弓箭运用
  - 规则：在冒险者中极其罕见，极少有人使用。因为要将弓箭练到纯熟所需耗费的时间比魔术还要长；但掌握诀窍并拥有精准射中要害的能力后，在任何地方都能具备立足生存的充足实力。
  - 原文依据："这世界的冒险者很少使用弓箭，她是相当罕见的存在。莎拉拥有精准射中要害的能力，也具备作为冒险者的充足实力。"，"要把弓箭这种东西练到纯熟必须耗费比魔术更多的时间，所以很少人使用，不过那孩子已经懂得诀窍，在哪里都能生存下去。"
- 名称：乱魔
  - 规则：能够分解魔术的技术。吸魔石释放的振动波效果与乱魔类似，但分解等级似乎比乱魔更高（吸魔石能破坏无法被乱魔轻易解决的地面魔法阵等）。
  - 原文依据："这种振动波的效果大概和『乱魔』类似，但是分解的等级似乎更高。"，"总觉得只要使用这个魔石，应该可以破坏无法用乱魔对付的东西。"
- 名称：水王级魔术
  - 规则：水系高阶魔术阶层，洛琪希具备其传授能力。
  - 原文依据："差不多该请洛琪希教导我水王级魔术了。"
- 名称：魔法阵与结界魔术的消除规则
  - 规则：画在地面上的结界魔术连同魔法阵可被吸魔石发动的效果彻底破坏；画在纸上的卷轴式魔法阵在未发动时不受影响，但在发动状态下会被消去；采用镂刻方式制作的魔道具内部魔法阵无法被吸魔石消除。
  - 原文依据："结果，画在地面上的结界魔术连同魔法阵都一并遭到魔石破坏。画在纸上的卷轴式魔法阵没有消失，但是换成发动中的卷轴后，似乎就能毫无问题地顺利消去。不过，这个魔石无法消除魔道具内部的魔法阵。或许是因为魔道具的魔法阵并非图画，而是采用镂刻方式。"
- 名称：魔力锻炼修行
  - 规则：反复进行魔术塑形与人偶制作等作业（如量产瑞杰路德人偶）可作为锻炼魔力的修行方式。
  - 原文依据："一方面可以作为锻炼魔力的修行，另一方面哪天开始贩卖时，库存多一点也没有坏处。"

## 四、种族 / 生物
- 名称：魔石多头龙
  - 特征：龙系生物，体内会产生能够吸收周围魔力的石头（吸魔石）。随着其栖息大陆的消灭而一并绝灭。
  - 原文依据："是魔石多头龙体内产生的石头，据说可以吸收周围的魔力。由于魔石多头龙随着大陆消灭而一并绝灭，现在这种魔石被视为梦幻魔石。"
- 名称：龙系生物
  - 特征：龙系生物常在体内制造魔石（如海中大蛇型龙系生物、魔石多头龙等），其魔石大多具备魔力相关效能（如增强魔力、抑制魔力消耗、双倍魔力效果或吸收分解魔力等）。此外野生龙系生物拥有远胜人类的动态视力与极迅速的反射神经，能在目击魔术后迅速做出防御反应。
  - 原文依据："龙系生物好像经常在体内制造出魔石，这也是其中之一。还有我的魔杖上使用的魔石，也是海中的大蛇型龙系生物制造出来的东西。龙之魔石具备各式各样的效能，基本上大多都和魔力有关。例如能增强魔力、抑制魔力消耗，或是让相同的魔力发挥出双倍的效果等等。"，"看样子那个九头龙是在看到魔术后才发动魔石，靠着优秀的反射神经让攻击自己的魔术化为无效。一般会觉得怎么可能做到那种事，不过野生动物拥有比人类优秀许多的动态视力，反应也非常迅速。"
- 名称：矿坑族
  - 特征：茱丽所属种族。族内似乎流传有类似童话的故事，但疑似没有向幼童念读故事书的文化习惯，或者缺乏书籍 [存疑]。
  - 原文依据："听说茱丽小时候从来没有人像这样读故事给她听。是矿坑族没有这种文化吗？他们好像有类似童话的故事，该不会是没有书籍吧？还是双亲忙碌到没有空理会女儿？其实随便怎样都好。"
- 名称：斯佩路德族
  - 特征：族人瑞杰路德曾完全为主公而战却遭背叛，最终复仇成功，其故事与其使用的长枪紧密相关。目前鲁迪乌斯等人正通过贩售关于瑞杰路德的书籍与高质量人偶推进斯佩路德族的形象改善计划。
  - 原文依据："叙述瑞杰路德其实完全是为了主公而战，结果却遭到背叛，最后成功复仇，和他的枪有着深厚关联的那个故事。"，"总之，斯佩路德族的形象改善计画也进行得很顺利。"

## 五、物品 / 道具 / 武器
- 名称：吸魔石
  - 说明：来自魔石多头龙（九头龙）体表的淡绿色鳞片状魔石，微透明。具备正反两面，外表难以区分；将手贴在背面注入魔力时会发出尖锐叽叽声并激活，吸收正面方向的魔力制造物。实验证实它并非真正将魔力吸收补充给施术者，反而在维持时会消耗等同于施术分量的自身魔力；其原理推测为将魔力转化为能瞬间分解魔力制造物的高阶振动波 [存疑/推测]。可破坏地面结界魔法阵及发动中的卷轴魔法阵，但无法破坏成型后魔力已稳定的人偶 [存疑] 或魔道具内部镂刻的魔法阵。鲁迪乌斯计划将其嵌入札里夫义手掌心。
  - 原文依据："所谓的那个魔石，就是对付九头龙时，它那身会吸收魔力，让我陷入苦战的鳞片。乍看之下，这个魔石只是淡绿色的鳞片。要不是略显透明，外观看起来根本不像石头。前往图书馆调查后，我查到了一些情报。首先，这种魔石的名字好像叫作『吸魔石』。是魔石多头龙体内产生的石头，据说可以吸收周围的魔力。由于魔石多头龙随着大陆消灭而一并绝灭，现在这种魔石被视为梦幻魔石。"，"这个魔石有所谓的『正面』和『背面』。从外表难以辨别，然而确实存在。把手贴在背面上注入魔力，魔石就会吸收正面那边的魔力。而且吸收时会发出尖锐的叽叽声。"，"进一步实验之后，我发现这个魔石似乎『并不会吸收魔力』。因为我对自己放出魔术，然后高举石头大喊：『就是现在！』并发动魔石，结果耗掉的魔力并没有补回。甚至反而可以感觉到又用掉一些魔力，分量等同于发动魔术时必须消耗的魔力。"
- 名称：龙之魔石
  - 说明：龙系生物体内生成的魔石统称。鲁迪乌斯魔杖（傲慢水龙王）上嵌有的魔石即来自海中大蛇型龙系生物，具备增幅魔力、降低消耗等与魔力紧密关联的效能。
  - 原文依据："还有我的魔杖上使用的魔石，也是海中的大蛇型龙系生物制造出来的东西。龙之魔石具备各式各样的效能，基本上大多都和魔力有关。例如能增强魔力、抑制魔力消耗，或是让相同的魔力发挥出双倍的效果等等。"
- 名称：自动人偶核心
  - 说明：自动人偶接近胸部中央安装的控制驱动核心。外观呈现红色、类似水晶的大魔石形状，实质上是由多块表面刻满魔法阵的小魔石组合而成。图形极其复杂古怪，原制作者的研究仅进行到半途，目前出土的自动人偶为失败作。
  - 原文依据："他谨慎地切开躯体上的接合处，分解内部构造。于是，据说在接近胸部中央的位置发现了一颗巨大的魔石。那颗魔石是红色的，有着类似水晶的漂亮形状。不过，实际上那并不是『一颗』魔石。而是由好几个表面刻满魔法阵的小魔石组合而成。毫无疑问，这就是自动人偶的核心。"，"因为图形过于奇怪复杂，而且那本古文书的内容也到处都是但书、警告，还有被斜线划掉的文字。总而言之，可以看出那个自动人偶的制作者在核心方面的研究其实才进行到半途。现有的作品是失败作，也无法确定制作者的目标。"
- 名称：札里夫义脚
  - 说明：札诺巴在自动人偶研究过程中发明的魔导义肢，构造与札里夫义手相同。由札诺巴绘制设计图、鲁迪乌斯制作外型原型、克里夫雕刻魔法阵，制作一个需耗时约一个月，尚无法量产。
  - 原文依据："在过程中，他发明了『札里夫义脚』。这个义脚在构造方面似乎和义手相同，我在制作原型时也有出一份力。由札诺巴绘制设计图，我做出外型，克里夫刻上魔法阵。这些作业相当费工，制作一个就要花上将近一个月。我计画将来总有一天要把义手和义脚成套出售，然而量产想必是很久以后才能办到的事。"
- 名称：札里夫义手
  - 说明：鲁迪乌斯所装备的魔导义手，正计划将吸魔石组装至其手掌处进行战斗运用。
  - 原文依据："总之，我想把魔石组装到『札里夫义手』的手掌上，并暂时以此形式来运用。"
- 名称：瑞杰路德人偶
  - 说明：鲁迪乌斯制作范本、由茱丽复制量产的魔术粘土人偶。造型摆出毫无破绽的帅气姿势，品质极高，甚至被诺伦收藏在宿舍柜子上。
  - 原文依据："是我给她出的作业，瑞杰路德人偶的复制品。……毕竟人偶摆出来的姿势没有任何破绽，即使看在外行人眼里也会觉得非常帅气。拿给诺伦看过之后，由于她低声表示想要，所以我把人偶赠送给她。现在好像被诺伦放在宿舍的柜子上当摆饰。"
- 名称：诺伦撰写的瑞杰路德传记书稿
  - 说明：诺伦完成的一部篇幅不长、文笔粗劣的书籍。记录了瑞杰路德为主公而战遭背叛后成功复仇、与其长枪深具渊源的故事。鲁迪乌斯计划修改后作为面向年轻群体的书籍出版。
  - 原文依据："其实诺伦那边的书也完成了。即使开始练剑，她依旧没有抛下写作。这本书的内容不长，文笔拙劣粗糙，提到的事件也只有一个──叙述瑞杰路德其实完全是为了主公而战，结果却遭到背叛，最后成功复仇，和他的枪有着深厚关联的那个故事。……只要稍作修改，应该就可以作为以年轻人为对象的书籍来贩售。"

## 六、历史 / 传说 / 事件
- 事件名：魔石多头龙绝灭与大陆消灭
  - 内容：古代某个大陆遭遇消灭，原本栖息在该大陆的魔石多头龙随之完全绝灭，吸魔石自此成为世间罕见的梦幻魔石。
  - 原文依据："由于魔石多头龙随着大陆消灭而一并绝灭，现在这种魔石被视为梦幻魔石。"
- 事件名：队伍「Dead End」解散
  - 内容：四年前鲁迪乌斯十二岁时，与艾莉丝分别后来到巴榭兰特公国边境城镇，在此正式解散了三人队伍「Dead End」，陷入强烈的失意与寂寥。
  - 原文依据："当时的自己才十二岁。和艾莉丝分手后，为了掩盖失意而前往北方大地。只身到达巴榭兰特公国边境城镇的我解散了队伍「Dead End」，也因此受到难以言喻的寂寥感侵袭。"
- 事件名：苏珊娜原冒险者队伍解散
  - 内容：在北方大地边境城镇，鲁迪乌斯离去后不久，由于队伍失去一名成员实力难以支撑而正式解散；帕特里斯回阿斯拉王国从军，提摩西与苏珊娜结婚并返回夏利亚定居。
  - 原文依据："『是啊，你离开后没多久就解散了。毕竟凭我们的实力，少了一个成员之后实在很辛苦。帕特里斯也回阿斯拉王国去了，说是要成为士兵。』"
- 事件名：瑞杰路德的背叛与复仇传说
  - 内容：瑞杰路德原本忠心耿耿为主公战斗，却惨遭背叛，最终完成复仇，这起过往与其使用的长枪有着极深的渊源。
  - 原文依据："叙述瑞杰路德其实完全是为了主公而战，结果却遭到背叛，最后成功复仇，和他的枪有着深厚关联的那个故事。"

## 七、社会规则 / 习俗 / 文化
- 贵族与王族的长子继承及性别执念：
  - 内容：王族与贵族阶层极其在意长子与子嗣性别，要求生下男孩以继承家业。阿斯拉王国的地方贵族伯雷亚斯家更有严格传统，旁支所生的男孩必须交给主家当家抚养。
  - 原文依据："『才能继承家业啊。』……札诺巴和爱丽儿也提过同样的事情，看样子王族和贵族之类果然很在意小孩的性别。连阿斯拉王国的地方贵族伯雷亚斯家也是，旁支的男孩必须交给当家养育。"
- 婴儿五岁前不见外人的习俗 [存疑]：
  - 内容：据札诺巴所述，世上某些国家存在一种习俗，规定小孩子在满五岁之前不能与家人以外的外人见面。
  - 原文依据："『不过，本王子忘了是哪一国有种习俗，说小孩子五岁前不能见家人以外的外人。』"
- 母乳商品化与奶妈雇佣文化：
  - 内容：产妇在婴儿早产夭折或死产后仍有母乳分泌，社会上允许母乳作为商品出售，由此产生奶妈雇佣需求。
  - 原文依据："虽然孩子死了，母亲还是会有母乳，而母乳这种东西可以作为商品。于是苏珊娜想找找看有没有哪个人家正好在招募奶妈，却偶然发现我的名字。"
- 冒险者生存法则与文化：
  - 内容：冒险者随时面临丧命风险；在北方大地冒险者间有特定的常识规矩，单打独斗难以获得声名，通常需要组队协作。

## 九、角色认知 vs 客观事实
- 角色以为：根据书籍记载与传闻，吸魔石能够吸收周围的魔力补充给自身。
  - 原文是否暗示另有真相：是。
  - 客观事实：鲁迪乌斯经实验发现，吸魔石并不会补充使用者的魔力，反而需要消耗自身等同于施术魔力量的魔力来激活；其原理疑似为将魔力转换成能瞬间分解魔力制造物的高阶振动波并从正面输出 [存疑/推测]。
  - 原文依据："是魔石多头龙体内产生的石头，据说可以吸收周围的魔力。"、"进一步实验之后，我发现这个魔石似乎『并不会吸收魔力』。因为我对自己放出魔术，然后高举石头大喊：『就是现在！』并发动魔石，结果耗掉的魔力并没有补回。甚至反而可以感觉到又用掉一些魔力，分量等同于发动魔术时必须消耗的魔力。"、"从反面输入的魔力是不是会被转换成『能瞬间分解魔力制造物的振动波』，然后从正面输出呢？"
- 角色以为：鲁迪乌斯起初担心神志恍惚的塞妮丝犹如失智老人，可能会情绪突变做出伤害婴儿露西的举动。
  - 原文是否暗示另有真相：是。
  - 客观事实：塞妮丝面对露西时流露出慈爱祖母的关爱温情，从未表现过失控抓狂的暴力行为，甚至似乎能凭借当母亲的经验敏锐察觉露西饥饿要喂奶。
  - 原文依据："当初，我对塞妮丝接近露西的行为抱着更强烈的戒心。因为我认为现在的她类似所谓的痴呆老人，搞不好会在某种感情变化下出手伤害露西。然而一切都是自己想太多了。塞妮丝只是静静地看着露西，没有表现出任何负面情绪，反而散发出一种温柔祖母正在关爱孙女的气氛。……况且基本上，塞妮丝根本从来不曾做出任何抓狂失控的行为。"、"话说回来，塞妮丝她刚刚……是不是发现露西肚子饿了？……如果有养育过两个孩子的经验，是不是就能看出来呢？"
- 角色以为：鲁迪乌斯推测希露菲的体质似乎不太容易受孕。
  - 原文是否暗示另有真相：不明 [存疑]（仅为鲁迪乌斯个人揣测与心理担忧，缺乏医学证据确认）。
  - 原文依据："而且希露菲的体质似乎不太容易怀孕。"
- 角色以为：鲁迪乌斯推测矿坑族可能没有给小孩子读故事书的文化习惯，或者该族没有书籍。
  - 原文是否暗示另有真相：不明 [存疑]（仅为鲁迪乌斯因茱丽童年经历而产生的猜测，鲁迪乌斯本人也补充了可能是其父母过于忙碌等其他可能性）。
  - 原文依据："听说茱丽小时候从来没有人像这样读故事给她听。是矿坑族没有这种文化吗？他们好像有类似童话的故事，该不会是没有书籍吧？还是双亲忙碌到没有空理会女儿？其实随便怎样都好。"
