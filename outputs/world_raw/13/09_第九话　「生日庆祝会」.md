# 第九话　「生日庆祝会」 世界设定提取

## 一、地理与场所
- 名称：夏利亚城外小河及魔法都市夏利亚区域规划
  - 内容：城外有一条远离喧嚣、水质清澈且鱼影丰富的宁静小河，该河流一路流经魔法都市夏利亚，城中居民日常生活会利用此河流汲水和洗衣，上游常有冒险者活动。魔法都市夏利亚城内明确划分为商业区、旅馆区、工房区以及学校。
  - 原文依据："我们现在来到城外。眼前是远离喧嚣的宁静小河，清澈的河水中可以看到许多鱼影。"
  - 原文依据："话虽如此，又不能去商业区那边，万一不巧遇上去拿礼物的希露菲就糟了。当然去旅馆区或工房区、学校也行，不过我还是提议了一个方案。"
  - 原文依据："而且，这条河有流经魔法都市夏利亚。人们的日常生活会利用到这条河，例如汲水和洗衣。所以有时候，靴子或许会因为某种理由而掉进河里，最后找不回来。另外也有可能是冒险者在更上游的地方掉了靴子，然后沿河漂流到这里。"

- 名称：阿斯拉王国布耶纳村
  - 内容：鲁迪乌斯的故乡。阿斯拉王国有着在喜庆日子制作传统蛋糕的习俗，鲁迪乌斯在布耶纳村五岁生日和十岁生日时均吃过此种糕点。
  - 原文依据："我以前在阿斯拉王国吃过同样的东西，记得是在布耶纳村过五岁生日时有吃到，十岁生日那次好像也有出现。"

- 名称：魔大陆
  - 内容：环境严酷的大陆，在当地旅行时往往条件艰苦，经常需要强迫自己忍耐并食用极其难吃的食物以求生存。
  - 原文依据："我在魔大陆上旅行时，也有一段时期必须强迫自己接受难吃的食物，不过应该没有吃过有毒的魔物。"

## 二、组织与势力
- 名称：米里斯教
  - 内容：主张一夫一妻制教义的宗教。信徒（如诺伦）对一夫多妻行为心存芥蒂与抵触，即使对当事人个人没有恶感，也因宗教信仰原因对丈夫纳第二位妻子（洛琪希）抱有成见。
  - 原文依据："身为米里斯教徒，她对洛琪希果然还是有点意见。不过呢，也不是真的那么讨厌洛琪希本人。"

- 名称：冒险者
  - 内容：在各大陆荒野或城市周边流域活动的职业群体。冒险者独行在外旅行时必须自力更生获取食物，在真正饥寒交迫的生存绝境下，甚至连有毒的魔物（如毒蝎子）也不得不吃下以保全性命。
  - 原文依据："因为一个人旅行的时候，必须尽可能自力取得食物。"
  - 原文依据："另外也有可能是冒险者在更上游的地方掉了靴子，然后沿河漂流到这里。"
  - 原文依据："爱夏小姐，你或许是身在福中不知福。要知道真正饿肚子的时候，有时候甚至连毒蝎子都得吃下去。"
  - 原文依据："以前基列奴好像也提过类似的事情，冒险者都那样吗？"

## 三、力量体系 / 魔法 / 技能
- 名称：水魔术（结冻 / 瞬间冷冻）
  - 规则：水魔术可将整条河流的水流完全结冻用于捕鱼；亦可用于对肉类、生鲜鱼获进行瞬间冷冻，以便于长期保鲜贮存。
  - 原文依据："如果想抓鱼，直接让河水结冻就好了。"
  - 原文依据："钓到的鱼都用魔术瞬间冷冻后带回家里。"

- 名称：土魔术（造物造椅）
  - 规则：土魔术可在野外瞬间重塑土石构造，凭空制作出平整坚固的椅子供人休憩坐禅。
  - 原文依据："洛琪希是个老手。她坐在我用土魔术制作的椅子上，用一只手拿着钓竿，眯起眼睛盯着水面。"

- 名称：魔眼（预知眼）
  - 规则：能够预先看穿未来一秒所发生的景象，鲁迪乌斯可借此捕捉水下浮标下一秒的细微抽动以精准起竿。
  - 原文依据："所以从现在开始，我要使用魔眼。"
  - 原文依据："自己要靠着看穿一秒后的未来，展现出压倒性的实力差距。我发动魔眼，专心观察浮标。"

- 名称：雷电与爆炸魔术捕鱼
  - 规则：具备高强魔术实力者无需依靠钓竿，直接使用电击和爆炸魔术即可进行大范围电鱼与炸鱼捕获。
  - 原文依据："我能够使用电击和爆炸，根本没有必要坚持用钓的。"

- 名称：魔导义手强化力量与挥剑技巧
  - 规则：长期每日剑术挥击训练能形成俐落纯熟的动作控制；装配在手臂上的魔导义手能提供极高力道，足以无视外部阻力强行拉起上钩的沉重物体。
  - 原文依据："透过每天的挥剑练习，我已经锻炼出俐落纯熟的上下动作。借由义手强化的手臂也可以无视一切抵抗，我强行把钓钩拉出水面。"

- 名称：斯佩路德族长枪刺鱼术
  - 规则：战士在水边捕鱼时无需钓具，将长枪往水中刺击，枪尖便能一次性精准刺中三条鱼。
  - 原文依据："不，他是拿枪往水里一刺，枪尖就会刺中三条鱼──"

## 四、种族 / 生物
- 名称：巨大蜘蛛
  - 特征：体型庞大的蜘蛛生物，其吐出的蛛丝弹性和韧性极佳，常被用来作为手工钓具的高强度钓线。
  - 原文依据："只有弹性很好的木材和巨大蜘蛛的蛛丝组合而成的简易钓竿。"

- 名称：射纹蛙
  - 特征：水生蛙类，其发声器官鸣囊具有良好浮力与弹性，适合加工后作为钓鱼用的浮标。
  - 原文依据："再搭配用射纹蛙的鸣囊制作的浮标以及铁制的钓钩，鱼饵则是蚯蚓。"

- 名称：毒蝎子（魔物）
  - 特征：带有剧毒的蝎型魔物，常出没于严酷地带，在极端饥荒绝境中冒险者有时会被迫以其充饥。
  - 原文依据："要知道真正饿肚子的时候，有时候甚至连毒蝎子都得吃下去。"
  - 原文依据："我在魔大陆上旅行时，也有一段时期必须强迫自己接受难吃的食物，不过应该没有吃过有毒的魔物。"

- 名称：夏利亚城外河鱼
  - 特征：栖息于夏利亚城外小河中，水质清澈可见大量鱼影，部分大型个体体型可比拟锦鲤，喜食蚯蚓。
  - 原文依据："清澈的河水中可以看到许多鱼影。"
  - 原文依据："很大只，可能跟锦鲤差不多。"

- 名称：野外夜行魔物习性
  - 特征：荒野及城外区域在入夜天黑之后会有魔物频繁出没，具备较强的危险性。
  - 原文依据："因为天黑之后可能会有魔物出没。"

- 名称：[存疑] 靴鱼
  - 特征：鲁迪乌斯在钓到沉入水底的旧长靴后，为在钓鱼比赛中掩盖尴尬而临时胡诌的所谓“河中生物”，本质为废弃人类靴子，并非真正生物。
  - 原文依据："虽然看起来像靴子，不过却是如假包换的河中生物。我把那东西称为……呃，靴鱼。"
  - 原文依据："不就是靴子吗！不行！太奸诈了！爱夏把手伸进篓子里，抓起靴子丢回河中。"

## 五、物品 / 道具 / 武器
- 名称：简易钓具
  - 说明：在没有卷线器与假饵（路亚）等机械化设备的条件下，使用高弹性木材、巨大蜘蛛蛛丝、射纹蛙鸣囊浮标与铁制钓钩组装而成的钓鱼用具，以蚯蚓为饵。
  - 原文依据："没有卷线器和假饵那类方便的东西。只有弹性很好的木材和巨大蜘蛛的蛛丝组合而成的简易钓竿。再搭配用射纹蛙的鸣囊制作的浮标以及铁制的钓钩，鱼饵则是蚯蚓。"

- 名称：阿斯拉王国传统蛋糕
  - 说明：阿斯拉王国的传统喜庆糕点。为质地松软的海绵蛋糕，不添加鲜奶油，糕体内部混入大量果干；蛋糕胚本身微带苦味，依靠果干的天然甜味来平衡整体风味。通常只在家族有大喜庆事的日子烘焙制作。
  - 原文依据："首先是蛋糕被送到了桌上。这个蛋糕类似烤得很松软的海绵蛋糕，不过没有使用鲜奶油。里面混入大量的果干，蛋糕本身有点苦，是靠着水果的甜味来平衡口味。我以前在阿斯拉王国吃过同样的东西，记得是在布耶纳村过五岁生日时有吃到，十岁生日那次好像也有出现。"
  - 原文依据："我找莉莉雅请教了一下关于蛋糕的事情，听说这是阿斯拉王国的传统糕点。通常有喜事的日子就会准备，但是保罗不喜欢，所以她以前几乎没做过。"

- 名称：植物辞典
  - 说明：收录各类植物知识的专业书籍。在鲁迪乌斯五岁生日时，由母亲塞妮丝满怀自豪地作为生日礼物赠予他。
  - 原文依据："像我五岁生日时，她非常兴奋地送了我一本植物辞典，脸上的表情就像是在说：『如何？还是我最了解鲁迪的兴趣吧』。"

- 名称：刺绣手帕
  - 说明：绣有美丽花朵的手帕，外观质地一模一样，由莉莉雅与塞妮丝共同作为礼物分别赠予诺伦与爱夏，代表对爱夏作为保罗亲生女儿的认可与同等关照。
  - 原文依据："那是两条绣着美丽花朵的手帕，看起来一模一样。"
  - 原文依据："『这是我和夫人送给你们两人的礼物。』……『嗯，当然可以，因为你也是保罗老爷的女儿。』"

- 名称：魔导义手
  - 说明：装配于鲁迪乌斯断臂处的高出力机械/魔导假肢，蕴含极强力量，足以强行对抗外力将水底重物拉拽出水面。
  - 原文依据："借由义手强化的手臂也可以无视一切抵抗，我强行把钓钩拉出水面。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移事件七周年与格雷拉特家团聚
  - 内容：菲托亚领地转移大灾害发生至今已过去整整七年时间，格雷拉特一家历经长期艰苦离散与搜寻终于在夏利亚重聚。但父亲保罗已在迷宫战死，母亲塞妮丝依然处于记忆丧失与失语神游状态。
  - 原文依据："转移事件之后已经过了七年。虽然花了这么长的时间，不过全家人总算团聚了。父亲已经离我们而去，母亲的记忆不知道能不能恢复。"
  - 原文依据："回想转移事件导致一家离散的那段辛苦时期。因为过去的痛苦经验将会成为支撑现在的基础。"

- 事件名：保罗生前的信件之约与全家团聚宴遗愿
  - 内容：保罗生前在寄给鲁迪乌斯的信中曾许下愿望：等到全家离散的所有人彻底团聚之后，一定要举办一场盛大的家庭庆祝派对。本次惊喜宴会即为践行其遗志而举办。
  - 原文依据："等全家人都团聚之后要举办一场派对……这是保罗以前在信上提过的愿望。保罗本人已经辞世的现实虽然让人寂寞又悲伤，然而今天也算是为了保罗，我想要好好庆祝。"

- 事件名：鲁迪乌斯童年生日
  - 内容：五岁生日时塞妮丝赠送植物辞典，全家享用了阿斯拉传统蛋糕；十岁生日时同样按照阿斯拉传统准备了海绵蛋糕庆祝。
  - 原文依据："像我五岁生日时，她非常兴奋地送了我一本植物辞典……"
  - 原文依据："我以前在阿斯拉王国吃过同样的东西，记得是在布耶纳村过五岁生日时有吃到，十岁生日那次好像也有出现。"

- 事件名：[存疑] 魔法大学怪谈传闻其之九
  - 内容：魔法大学校内学生间口耳相传的神秘谣言第九条，内容为“龙头老大是光头”。
  - 原文依据："──学校的传言•其之九「龙头老大是光头」──"

## 七、社会规则 / 习俗 / 文化
- 内容：关键年龄生日庆典与补办礼仪
  - 原文依据："『十岁生日快乐！』『生日快乐。』不要说诺伦，恐怕连爱夏都没听懂希露菲她们在说什么。『那个……我们已经十一岁了……』……『嗯，可是我们在你们十岁时没能帮忙庆祝。所以鲁迪他说只不过是慢了一年而已，现在补送礼物应该也没问题。』"
  - 原文依据："等诺伦和爱夏十五岁的时候，我也要帮她们盛大庆祝一番。"
  - 原文依据："听说这是阿斯拉王国的传统糕点。通常有喜事的日子就会准备……"
  - 说明：社会文化极其看重孩童特定年岁节点：五岁为幼年成长关，十岁为少年成长重要大关（因灾难错过的十岁生日甚至需要在事后专门隆重补送大件礼物补办），十五岁则为正式成人礼节点。每逢大喜吉日，阿斯拉王国习惯烘焙无鲜奶油的果干海绵蛋糕进行宴席庆祝。

- 内容：一夫多妻家庭中正妻接纳侧室的赠礼认可仪式
  - 原文依据："『是结婚贺礼啊。洛琪希，恭喜你和鲁迪结婚了！』……『洛琪希，我们也要像塞妮丝小姐和莉莉雅小姐那样，两个人好好相处喔。』"
  - 原文依据："后来我才知道，洛琪希就是在这个时候才初次实际感受到……她真的获得了希露菲的认可。"
  - 说明：在一夫多妻体制下，第一位妻子（正妻）向后入门的侧室主动赠送新婚贺礼（如帽子），并以塞妮丝与莉莉雅和睦相处为典范，是正式确立家庭秩序与给予侧室正当家庭身份认可的重要仪式。

- 内容：贵族侍妾与庶出子女的尊卑规矩
  - 原文依据："『那个，妈妈……我也可以收下吗？』『嗯，当然可以，因为你也是保罗老爷的女儿。』我不知道莉莉雅的心境发生了何种变化。明明她以往都嘱咐爱夏必须彻底以女仆自居。『但是你记住，今后务必也要继续尊重诺伦大小姐和鲁迪乌斯少爷。』"
  - 说明：在阿斯拉地方贵族/保罗家族中，侍妾及其所出之女（爱夏）虽血缘上同为保罗骨肉，但家规传统上要求其必须自居女仆身份，终身侍奉长男（鲁迪乌斯）与正室嫡女（诺伦大小姐），言行举止必须遵守尊卑主仆礼数。

- 内容：米里斯教徒对一夫一妻教条的伦理认同
  - 原文依据："身为米里斯教徒，她对洛琪希果然还是有点意见。不过呢，也不是真的那么讨厌洛琪希本人。"
  - 说明：受米里斯教纯洁一夫一妻教规熏陶的信奉者，在道德情感上本能地排斥多妻行为，即便不对第二任妻子产生人身仇恨，也会因宗教教义而产生难以消除的心理芥蒂。

- 内容：城镇周边公共河流的生活化利用规矩
  - 原文依据："而且，这条河有流经魔法都市夏利亚。人们的日常生活会利用到这条河，例如汲水和洗衣。所以有时候，靴子或许会因为某种理由而掉进河里，最后找不回来。另外也有可能是冒险者在更上游的地方掉了靴子，然后沿河漂流到这里。"
  - 说明：穿城而过的自然水系是城镇居民共享的公共资源，居民沿河汲水、浣洗衣物，并与钓客、上游过境冒险者共享同一条流域。
