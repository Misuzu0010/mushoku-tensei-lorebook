# 第六话　「白色面具 后篇」 世界设定提取

## 一、地理与场所
- 名称：阿斯拉王国无名草原
- 内容：五年前七星静香发生空间穿越后最初降落的地点，为一片空旷无人烟的平原，随后在此处被龙神奥尔斯帝德发现并保护。
- 原文依据："七星似乎是一回过神，就发现自己身在阿斯拉王国。她当时处在空无一物的草原，据说是之后才得知那里就是阿斯拉王国。由于那里空无一物，杳无人烟，正当她伤脑筋不知该如何是好时，好像是奥尔斯帝德出现并保护了她。"

- 名称：人魔大战时期的古代遗迹与转移魔法阵
- 内容：人魔大战时期建造的古代遗迹中，残留着刻印式的古代“转移魔法阵”。奥尔斯帝德利用这些散落在世界各地的转移魔法阵，带着七星在一年之内完成了环游世界一圈的巡回。
- 原文依据："『简单说呢，就是传送装置。在这个世界被称为「转移魔法阵」，你知道吗？』……『好像还残留在人魔大战时所建造的遗迹里。』……虽然说是环游世界，不过也只是徒步从这个转移魔法阵绕去下一个转移魔法阵的旅行。"

## 二、组织与势力
- 名称：龙神奥尔斯帝德势力 / 阵营特性
- 内容：奥尔斯帝德身上带有一种“被所有生物厌恶的诅咒”，导致其所到之处极易引发争端与敌意；但“龙神”名号具有极高社会信用与威慑力，凭其亲笔信可直接约见知名魔术师、各国骑士团长乃至国王。与人神存在“私人恩怨”，且视人神的使徒为必须尽早铲除的隐患。奥尔斯帝德保护了毫无自保能力的七星，并协助其寻找返回原世界的线索。
- 原文依据："可能是由于奥尔斯帝德具有被所有生物厌恶的诅咒，所以她才得火速学会吧。"、"尽管奥尔斯帝德受到厌恶，但龙神的大名具有利用价值，光凭他的一封亲笔信似乎就能与知名的魔术师、骑士团长还有国王等人会面。"、"『我也不明白详细状况。不过他曾说是私人恩怨。还有，如果放任人神的使徒自由行动事情会变得很棘手，因此得趁早处理掉，他是这么说的。』"

- 名称：未公开姓名的召唤术权威
- 内容：隐匿于世间的顶级召唤术学者，要求七星隐瞒其姓名以免招致贪求金钱与权力之人的纠缠。该学者断言世界上不存在将人类从异世界召唤过来的方法，甚至原本就无法召唤人类。
- 原文依据："『那个人说：「要是其他人得知你认识我，想必会有贪求金钱与权力之人试图接近你。如果不想引起麻烦，还是别张扬我的名字吧」。』……而那个人似乎是这个世界的召唤术权威。然而，即使是如此人物，据说也没有方法将人类从异世界召唤过来。真要说的话，即使不是从异世界，也应该无法召唤人类才对。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔术分类（动态魔术 vs 静态魔术）
- 规则：以攻击魔术、治疗魔术为主的魔术属于“动态魔术”，主要依赖口头咏唱（或无咏唱）施展；以召唤魔术、结界魔术为主的魔术属于“静态魔术”，主要依赖魔法阵进行构筑与行使。
- 原文依据："基本上，这个世界的召唤魔术是运用魔法阵来行使。据说，如果攻击或是治疗方面的动态魔术是以咏唱为主，那么召唤或是结界这类静态魔术就是以魔法阵为主。"

- 名称：魔法阵的原理与制作机制
- 规则：
  1. **现代涂料魔法阵**：将魔力结晶研磨成粉，与特定配方材料混合调制成专用涂料。涂料一旦接触便会渗入对象物体难以消除。向涂料注入魔力可增幅能量并产生魔法效果；施放一次后涂料即挥发蒸发。王级以上的大规模魔术需极昂贵的特殊涂料，成本堪比国家预算。
  2. **刻印式魔法阵**：利用石材等耐用材质直接雕刻阵型并直接灌入魔力，可持久反复使用，常用于古代遗迹转移魔法阵或现代魔道具制作。
  3. **魔法阵形状失传与法则研发**：现代魔法阵的形状多因口传而大量失传，现存多从遗迹壁画或古王宝库卷轴誊抄；七星静香通过解析魔法阵的底层法则并反复实验，独立开发出了数套全新原创魔术。
- 原文依据："所谓的魔法阵，好像是将魔力结晶捣成粉状，再混合几种既定材料制成涂料后画出来。只要沾上涂料就会溶进对象物体内，不会轻易消除。一旦将魔力灌入涂料就能增幅力量，配合魔法阵的形状发挥效果。基本上，使用过一次之后涂料就会蒸发。……基本上，要使用王级以上的大规模魔术时好像还需要特殊的涂料，实际准备起来会需要相当于国家预算的庞大金额。……用石头之类的道具刻出魔法阵，直接将魔力灌进去。听说七星因为自己无法运用魔力，所以并没仔细调查，不过在制作魔道具时似乎会运用到这类技术。……因为魔法阵的「形状」是以口述流传，目前大部分似乎都已失传。如今已经没有人能制作出新的魔法阵。……然而，七星却彻底颠覆这样的状况。她调查魔法阵的法则性，描绘大量的魔法阵，反覆进行实验，最后终于成功地开发了几套独创魔术。"

- 名称：世界魔力分布法则与穿越者生理特异性
- 规则：
  1. 这个世界上的一切物质（包括路边死尸）都蕴含魔力；
  2. 纯肉身穿越而来的地球人（如七星静香）魔力总量为零，无法运用任何魔术；
  3. 转生者（如鲁迪乌斯）获得了异世界血肉之躯，体内能容纳世界巅峰级的庞大魔力；
  4. 穿越者肉体具备“不老”特质（七星穿越五年容貌完全不变，停留于十六七岁），但不具备不死性；转生者则同常人一样正常生长发育。
- 原文依据："『顺带一提，据说在这个世界的一切物体都具有魔力，即使是路边的尸体也不例外。毕竟我是从没有魔法的世界来的，想说这也是理所当然……我的魔力总量……据说是零。』"、"『我呢，自从来到这世界已经过了五年左右，但完全不会变老。』……『我倒是会像一般人那样成长。』"、"『这副身体大概也只是不老，并非不死。』"

- 名称：世界排除力 / 历史修正力假说 [存疑]
- 规则：七星提出科幻假说，认为来自原世界的异邦人属于异界杂质/异物，若大幅改变该世界的历史走向，可能会引动世界自身的修正力量将干预者排除在外。
- 原文依据："『我们在这个世界是异物。要是对历史造成巨大变动，说不定会被这个世界排除在外耶。』『被世界排除？那是什么意思？』『你没看过科幻小说吗？简单来说，就是试图让历史回归原本自然面貌的力量。』"

- 名称：转移事件的成因假说 [存疑]
- 规则：五年前菲托亚领地大转移事件的发生时间与七星静香穿越降临的时间完全一致。七星推论大转移灾害可能是由于她被强行召唤进入这个世界所引发的巨大空间/次元反作用力，但幕后召唤者与真实机制未知（奥尔斯帝德亦称这是第一次发生）。
- 原文依据："『我不清楚那起事件是怎么引起的。不过事件是发生在五年前，刚好与我来到这个世界的时间点一致。……恐怕那起事件是因为我来到这个世界的反作用力所引起的。换句话说，表示我可能就是那起事件的原因。』"、"『嗯，他也只说：「这种事情还是第一次发生」。』"

## 四、种族 / 生物
- 名称：异世界穿越者（以七星静香为代表）
- 特征：纯肉体自地球穿越而来，魔力总量为绝对零，身体完全不老化，但肉体强度与常人无异，易伤易死，缺乏抗病与防御手段。
- 原文依据："『毕竟我没有魔力，也毫无战斗的手段。这副身体大概也只是不老，并非不死。』"

## 五、物品 / 道具 / 武器
- 名称：七星的防身戒指（魔道具 / 魔力附加品）
- 说明：七星随身携带并佩戴在手上的三枚戒指，属于自卫型魔力装备：
  1. 第一枚戒指：发光后可抑制/阻断对方的魔术发动（使菲兹的无咏唱魔术哑火失效）；
  2. 第二枚戒指：发光后在自身周围展开无形护盾，阻挡物理冲击（菲兹的拳头撞上半空中的无形障碍）；
  3. 第三枚戒指：储备未用。
- 原文依据："她从口袋取出戒指戴在手上，而且还戴了三枚。……随后戒指发光，菲兹学长的魔术没有发动。……然而随着第二枚戒指发光，他的拳头在半空狠狠地撞上某种东西。那枚戒指是魔道具……不对，是魔力附加品吗？"

- 名称：古代转移魔法阵
- 说明：刻印在古代遗迹石构建筑上的空间传送设施，满足供能即可实现瞬间空间转移。
- 原文依据："『简单说呢，就是传送装置。在这个世界被称为「转移魔法阵」……好像还残留在人魔大战时所建造的遗迹里。』"

## 六、历史 / 传说 / 事件
- 事件名：人魔大战时期的空间传送网络
- 内容：人魔大战时期曾广泛构筑并运用转移魔法阵，后世因战争损毁与禁忌封禁，现仅在无人深入的古遗迹深处残存。
- 原文依据："『好像还残留在人魔大战时所建造的遗迹里。』"、"他说转移魔术在这个世界似乎算是禁忌，尽量别在人前说出口会比较好。"

- 事件名：菲托亚领地大转移事件与七星降临
- 内容：五年前发生在阿斯拉王国的灾难。七星在灾害同刻出现在阿斯拉王国荒野草原，怀疑灾难系跨界召唤的反作用力波及。鲁迪乌斯一家及菲兹的家人均在此灾难中离散或受害。
- 原文依据："『我不清楚那起事件是怎么引起的。不过事件是发生在五年前，刚好与我来到这个世界的时间点一致。……恐怕那起事件是因为我来到这个世界的反作用力所引起的。』"、"『我……我们因为那场灾害究竟吃了多少苦！我爸爸……还有我妈妈都……！都是因为你！』"

- 事件名：鲁迪乌斯与七星静香的合作协定（Give and Take）
- 内容：双方因立场不同达成交易契约：鲁迪乌斯留在异世界并提供自身庞大的魔力协助七星的魔法阵召唤实验；七星则向鲁迪乌斯共享召唤魔术的研究知识、转移事件调查成果以及广泛的人脉情报。
- 原文依据："『你得来协助我的实验。然后，至于你想知道的事情，就由我来告诉你。如果是我不懂的就查完再告诉你。毕竟我人脉很广，对调查也还挺有自信。』……『简而言之，就是Give and Take的关系对吧？』『没错，幸好你理解力很高。』"

## 七、社会规则 / 习俗 / 文化
- 内容：转移魔术禁忌：转移魔术在当前世界上属于不可公开讨论与行使的绝对禁忌。
- 原文依据："『他说转移魔术在这个世界似乎算是禁忌，尽量别在人前说出口会比较好。』"

- 内容：异界知识的资本化运用：七星在阿斯拉王国将地球先进的料理、缝纫知识变现，结合龙神名誉背书与人脉特权，打造了无需劳作即可源源不断产生财富的商业通路。
- 原文依据："而她在这段期间建立了一个架构，就是将原本世界的料理或是缝纫技术等知识传授给别人借此赚钱，接着再动用金钱掌握特权，最后只要运用特权，等钱自己进入口袋就行了。而且她还把七大列强的龙神当作后盾，借此广为宣传获取他人的信用，再透过自身的话术确立通路。"

## 九、角色认知 vs 客观事实
- 角色以为：菲兹听到七星说转移灾害原因在于自己，愤怒认定七星是引发灾难的凶手而挥拳袭击。
- 原文是否暗示另有真相：是。
- 原文依据："『我……我们因为那场灾害究竟吃了多少苦！我爸爸……还有我妈妈都……！都是因为你！』……『抱歉，是我说明不够充分。她好像也不是自愿过来这里。换句话说，她也是被害者。』"

- 角色以为：七星静香推测鲁迪乌斯在地球原世界是寿终正寝而死。
- 原文是否暗示另有真相：是（鲁迪乌斯是在同一场车祸中为救七星等人被卡车撞死，鲁迪乌斯刻意隐瞒含糊带过）。
- 原文依据："『原来如此，是寿终正寝吗？』七星擅自这么解读。再次强调，我并没有告诉她我就是当时冲过去的那个人。"

- 角色以为：七星以为来自地球的人都理应“魔力总量为零”且“不会老化”。
- 原文是否暗示另有真相：是（七星为肉身穿越，而鲁迪乌斯为灵魂转生，拥有异世界肉体与顶尖魔力，且身体会正常成长）。
- 原文依据："『而且我们没有魔力吧？』……『我有魔力喔，而且也能使用魔术。』……『我呢，自从来到这世界已经过了五年左右，但完全不会变老。』……『我倒是会像一般人那样成长。』"
