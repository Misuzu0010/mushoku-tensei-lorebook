# 第七话　「在魔法大学的一天」 世界设定提取

## 一、地理与场所
- 名称：米里希昂大圣堂
- 内容：米里斯神圣国的设施，存放保管神级解毒魔术咏唱咒文的场所。
- 原文依据："听说这套魔术历代仅只有一人能使用，咏唱咒文目前似乎被存放在米里希昂大圣堂妥善保管。"

- 名称：七星的研究室（魔法大学内）
- 内容：非常宽敞，入口处有置物区，内部设有被抗魔砖覆盖的实验室，隔壁教室则是七星的寝室（一处存放食物，禁止鲁迪出入）。
- 原文依据："她的研究室很宽敞。然而一踏进去就会看到东西摆得乱七八糟，给人一种矮墙浅屋的感觉。从类似置物区的地方稍微移动后，就会看到用抗魔砖覆盖的实验室。如果再由此前去隔壁的教室，就是七星的寝室。"

- 名称：魔法大学食堂（餐厅）
- 内容：一楼为普通用餐处；二楼有学生情侣用餐；三楼根据潜规则未给奴隶身份的人设置椅子。
- 原文依据："因为在三楼的话，茱丽没有位子坐。三楼好像没有为奴隶身分的人设置椅子。当然，这是潜规则。"

## 二、组织与势力
- 名称：拉诺亚魔法大学教学体系
- 内容：分设年级与教室（如五年级教室），开设治愈魔术（如上级治愈）、攻击魔术、混合魔术、中级/上级解毒魔术等不同方向的课程与实技训练，配有土圣级等专职教师指导。
- 原文依据："这里是五年级的教室，我要在这学习治愈魔术的上级。""据说普露塞娜主修治愈方面的魔术，莉妮亚则是以攻击方面的魔术课程为主。""教会我这招的老师叮咛我：『会对农作物造成损害，所以尽量避免在城镇中使用』。……不管怎么说，这样一来我也是土圣级魔术师了。"

## 三、力量体系 / 魔法 / 技能
- 名称：斗气（肉体强化）
- 规则：驱使体内的魔力，将构成身体的肉片用魔力一片一片覆盖上去并加以固定，从而让体能获得爆炸性提升的技术。通常只要锻炼身体自然就会掌握，但存在极少数无论如何锻炼也完全无法使用斗气的无才能者（如鲁迪乌斯）。拉普拉斯身上没有缠绕斗气，但依然极为强大。
- 原文依据："据巴迪冈迪的说法，所谓的斗气听说就是驱使体内的魔力，借此让体能获得爆炸性提升的一种技术。简而言之就是肉体强化。""将构成身体的肉片用魔力一片一片覆盖上去，并加以固定！""一般而言，据说只要锻炼身体，自然就会了解如何将斗气缠绕在身上。我自认累积了不少训练，然而至今依然无法将斗气缠绕在身上。总之，就是没有才能。好像偶尔会有这种人。就是无论怎么锻炼也无法使用斗气的家伙。""毕竟那个拉普拉斯也没有缠绕什么斗气，却依然很强！"

- 名称：魔力负荷与人族肉体限制
- 规则：强大的魔力若没有相称的肉体强度与技术，胡乱使用会摧毁自身；人族的身体再怎么锻炼，若强行模仿拉普拉斯运用魔力的方式，肉体不消片刻就会支离破碎。
- 原文依据："要是学那家伙使用魔力的方法，你的肉体不消片刻就会支离破碎。真要说的话，你身为人族却拥有如此魔力，这件事本身就很异常！""强大的魔力会摧毁自身。我也隐隐约约察觉到这件事。所谓灌注魔力的流程，就像是把手臂伸展到极限的动作一样。如果硬是将手臂伸展到整个弯过去，那当然会骨折。看来拉普拉斯这个人不仅具有庞大的魔力，还拥有与其相符的肉体强度与技术。然而我没有肉体强度或是技术。人族的身体再怎么锻炼，也无法练就拉普拉斯那种境界。"

- 名称：解毒魔术体系
- 规则：初级解毒能应对绝大多数常见症状。中级以上针对特定疾病、高阶魔物毒素或蔓延病情需对症下药咏唱，魔力消耗与咏唱时间远超攻击魔术。中级需背诵五十句以上咏唱（包含制造毒素的魔术）；上级需背诵上百句；圣级以上减少背诵但魔力消耗大幅增加；王级以上被各国研究并藏匿，可制造解毒无效之毒与治疗法；神级解毒魔术能医治魔石病等罕见疾病，历代仅一人能使用。
- 原文依据："所谓的解毒魔术，基本上初级就能对应绝大多数的症状。不过对于特定的疾病，还有高阶魔物使用的毒素，或者病情正在蔓延的状态下，就需要对症下药进行咏唱，并消耗庞大的魔力。在中级以上的解毒魔术课程，会学习与这些症状对应的术。这类魔术的咏唱时间很长。一旦到了中级就会变成攻击魔术的好几倍。……在中级必须记住五十句以上的咏唱。而且其中还存在着制作出毒素的魔术。……上级的话会到上百句。……到了圣级以上虽然会慢慢减少背诵的必要性，但取而代之的是会增加消耗的魔力。此外，到了王级以上甚至会被各国研究，并藏匿其存在。会制作治愈魔术无法发挥功效的毒威胁他国，再做出用来治疗的术式。……顺带一提，据说神级的解毒魔术能够治好某种稀有病状。我记得是叫魔石病吧？好像是体内的魔力会慢慢化为魔石的一种疾病。听说这套魔术历代仅只有一人能使用，咏唱咒文目前似乎被存放在米里希昂大圣堂妥善保管。"

- 名称：混合魔术瓶颈
- 规则：攻击魔术师在进阶时遇到瓶颈，绝大部分都发生在混合魔术领域（涉及如水与火结合的蒸发、凝固、融解等相变机理）。
- 原文依据："据说攻击魔术师会遇到瓶颈，大部分的状况都是在混合魔术这个领域。"

- 名称：土圣级魔术「沙暴」
- 规则：土属性圣级攻击魔术，上级魔术「沙尘暴」的高阶版。释放出惊人的强风与大量砂砾覆盖周边大范围区域，遮蔽视线并造成呼吸困难，效果结束后残留扑天盖地且易崩塌的砂砾。由于会对农作物造成严重损害，通常被告诫避免在城镇内使用。
- 原文依据："那就是『沙暴』。是上级魔术『沙尘暴』的高阶版。……单从字面上看来感觉没什么了不起，然而实际用过之后，才发现会有惊人的强风和砂砾覆盖周遭一带。不仅视线会被遮蔽，甚至还会呼吸困难。即使效果时间结束，也会有容易崩塌的砂子残留得扑天盖地。如果说水圣级的『豪雷积乌云』是雨和暴风的魔术，那么『沙暴』就是砂与暴风的魔术。……教会我这招的老师叮咛我：『会对农作物造成损害，所以尽量避免在城镇中使用』。"

- 名称：召唤魔术的规则与反噬风险
- 规则：在独创或特定魔法阵中注入魔力进行召唤，消耗魔力极大。若仅有庞大魔力而试图召唤超出自身掌控力以上的强力魔兽，会被召唤物反噬咬死；发动上级召唤卷轴一张即消耗相当于上级魔术的魔力，一般具备无咏唱才能的优秀魔术师发动二十张左右即耗尽魔力。
- 原文依据："『鲁迪乌斯同学，这个……光发动一张就需要消耗相当于上级魔术的魔力。』尽管菲兹学长会使用无咏唱魔术，然而魔力总量似乎并没有那么多。不，就一般水准来看的话好像还算满多的……毕竟，他光是发动二十张左右的卷轴就会耗尽魔力。""故事内容在讲述名为希格的魔女接连地召唤出魔物。尽管她最后消耗庞大的魔力，成功从大量的供品中召唤出比自己更强的魔兽，但却被活活咬死吞下肚。弟子们为此悲恸不已，并在心中发誓不再召唤自己力不能支的魔兽。"

## 四、种族 / 生物
- 名称：不死魔族（以巴迪冈迪为例）
- 特征：拥有六只手臂，黑色肌肤（醉酒时转为红黑色），肉体生命力极强，即便身体几乎被完全消灭也能耗费时间再生复活。
- 原文依据："将那六只手臂环抱胸前或是扠在腰间""他仅仅一击就几乎把吾的身体消灭，害吾花了不少时间复活！当时还以为死定了呢！""从他的黑色肌肤变色为红黑色这点来看，八成是醉了吧。他的肌肉也太谜了。"

- 名称：矿坑族（以茱丽为例）
- 特征：生来喜好美酒，即使幼年饮酒也毫无不良反应。
- 原文依据："不愧是矿坑族！光看一眼就能了解这酒的美味！""我是听说过矿坑族喜好美酒，茱丽果然也是这样吗？"

- 名称：长耳族（以菲兹为例）
- 特征：体质上几乎不会囤积脂肪，身形非常纤瘦。
- 原文依据："长耳族几乎不会囤积脂肪，我认为他应该很瘦啦……"

## 五、物品 / 道具 / 武器
- 名称：抗魔砖
- 说明：用于覆盖并构筑魔法实验室的特殊建材，具备抗魔特性。
- 原文依据："从类似置物区的地方稍微移动后，就会看到用抗魔砖覆盖的实验室。"

- 名称：魔力结晶
- 说明：魔法实验与道具研究消耗的核心资源，市面流通量有限，一旦大规模垄断可能招致各方怨恨。
- 原文依据："尽管她坐拥大笔财富，但魔力结晶却不是随时都会进货，因为魔力结晶在市场上的数量有限，一旦全部垄断恐怕会招来各处的怨恨，可说是一种进退两难的实验。"

- 名称：《希格的召唤魔术》
- 说明：一本带有寓言童话性质的魔术文献，记载魔女希格因召唤过于强大的魔兽反遭吞噬的历史故事，告诫后人不可召唤力不能支的魔兽；书中未载具体召唤阵绘制方法。
- 原文依据："这本书上写着《希格的召唤魔术》。……故事内容在讲述名为希格的魔女接连地召唤出魔物。尽管她最后消耗庞大的魔力，成功从大量的供品中召唤出比自己更强的魔兽，但却被活活咬死吞下肚。……在这本书里没有写到有关召唤的具体方法以及魔法阵的种类。"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯与巴迪冈迪之战
- 内容：可疑的魔王/魔神拉普拉斯曾与巴迪冈迪交战，仅凭一击就几乎将巴迪冈迪肉体彻底消灭，巴迪冈迪耗费了相当长时间才得以复活。
- 原文依据："『巴迪冈迪大人，您曾见过拉普拉斯吗？』『嗯，他仅仅一击就几乎把吾的身体消灭，害吾花了不少时间复活！当时还以为死定了呢！呼哈哈哈哈！』"

- 事件名：魔女希格的反噬传说
- 内容：魔女希格接连召唤魔物，最终以大量供品消耗庞大魔力召唤出超出自身能力的强悍魔兽，遭其活活咬死吞食。
- 原文依据："故事内容在讲述名为希格的魔女接连地召唤出魔物。尽管她最后消耗庞大的魔力，成功从大量的供品中召唤出比自己更强的魔兽，但却被活活咬死吞下肚。弟子们为此悲恸不已，并在心中发誓不再召唤自己力不能支的魔兽。"

## 七、社会规则 / 习俗 / 文化
- 内容：生日祝贺习俗——该世界并不存在祝贺五岁、十岁以及十五岁以外生日的风俗。
- 原文依据："由于在这个世界并没有祝贺五岁、十岁以及十五岁以外的风俗，我现在也完全想不起来自己的生日究竟是哪天。"

- 内容：奴隶阶级潜规则——在拉诺亚魔法大学食堂三楼，有着不给奴隶身份者提供座位的社会潜规则。
- 原文依据："因为在三楼的话，茱丽没有位子坐。三楼好像没有为奴隶身分的人设置椅子。当然，这是潜规则。"

- 内容：圣级魔术传授规矩——导师在传授圣级魔术时，往往会按规矩事先叮咛其灾害范围，要求尽量避免在城镇中使用以防破坏农作物与建筑。
- 原文依据："教会我这招的老师叮咛我：『会对农作物造成损害，所以尽量避免在城镇中使用』。传授圣级时是不是都规定要像这样事先叮咛啊。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯以为只要不断锻炼身体，自己总有一天会掌握把斗气缠绕在身上的方法。
- 原文是否暗示另有真相：是。巴迪冈迪指出鲁迪乌斯根本没有使用斗气的才能，属于极少数无论如何锻炼也缠绕不了斗气的人。
- 原文依据："『你就是那个啦！没有才能！』巴迪冈迪直截了当地解说我办不到的理由。一般而言，据说只要锻炼身体，自然就会了解如何将斗气缠绕在身上。我自认累积了不少训练，然而至今依然无法将斗气缠绕在身上。总之，就是没有才能。好像偶尔会有这种人。就是无论怎么锻炼也无法使用斗气的家伙。"

- 角色以为：鲁迪乌斯以为自己在女生宿舍路段仍是人人唾弃的“内裤小偷”，走过去会被群起攻击。
- 原文是否暗示另有真相：是。菲兹指出莉妮亚和普露塞娜早已到处帮鲁迪澄清辩护，加上其展现的绅士作风与克制强大，鲁迪在女生宿舍其实相当受欢迎。
- 原文依据："『少扯谎了。前阵子才被传八卦耶，我可是清清楚楚听到喽。怎么可能会受欢迎，绝对不可能啦。』『呵呵，虽然大家一开始都很怕你，但是莉妮亚和普露塞娜有到处帮你说话。她们说老大是个宽容的绅士，所以不会对弱者出手喵，这样。……所以啦，这下大家好像总算察觉到鲁迪乌斯同学的魅力。』"

- 角色以为：鲁迪乌斯以为菲兹学长是大约十三岁、未来会变成让女人哭泣的美少年。
- 原文是否暗示另有真相：是。鲁迪自身感官已察觉到违和，甚至怀疑“最近菲兹学长看起来根本就是女人”，在制作人偶时也因菲兹身材疑虑犯愁。
- 原文依据："我想菲兹学长现在应该大约十三岁吧，感觉不消数年就会成长为让女人哭泣的美男子。哎呀，该怎么说呢。老实说，我觉得最近菲兹学长看起来根本就是女人。是我的眼睛有问题吗？该不会我正在朝那边的道路觉醒吧？"
