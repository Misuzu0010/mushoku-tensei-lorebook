# 闲话　「希露菲叶特0」 世界设定提取

## 一、地理与场所
- 名称：魔法大学修练场
- 内容：魔法大学进行实习课程以及对新生进行实力测试的场地。
- 原文依据："在修练场进行实习课程时，看到吉纳斯副校长带了一个人走进来"

- 名称：魔法大学图书馆
- 内容：位于主校舍外面，馆藏书籍极其丰富，但关于转移事件相关的文献极其稀少，且部分书籍存在被人为撕扯破坏的情况。
- 原文依据："图书馆位于主校舍外面，距离下一堂课开始应该也没剩多少时间。"、"这间图书馆非常宽广，尽管有很多书籍，但是关于转移事件所需的资料却少之又少。……况且其他书籍甚至还有一部分被人撕走。"

- 名称：女子宿舍周边道路
- 内容：魔法大学女子宿舍外的道路。根据住宿生校规，日落之后严禁男生在此道路通行，以防范内衣盗窃及兽族发情期引发的纠纷。
- 原文依据："明明太阳已经西下，居然还会有男学生在这一带行走。根据住宿生的规矩，男生不能在这个时间走在这条路上。毕竟除了内衣小偷的问题以外，还有发情期的问题，虽然现在并非处于那种季节就是。"

- 名称：魔大陆
- 内容：极其残酷严苛的大陆，生存环境恶劣，全境仅存在D级以上的魔物。前往该大陆修行的剑士极少能生还，因菲托亚领地转移事件被传送到该地的人往往被视为无生还希望。
- 原文依据："魔大陆的事情我也曾有耳闻。据说那里只存在D级以上的魔物，是个非常严苛的土地。虽然也有剑士为了武者修行而前去魔大陆，但几乎都没有回来。因转移事件而被传送到那里的人被视为没有希望生存。然而，鲁迪却成功从那里回来。"

## 二、组织与势力
- 名称：第一王子派 / 第二公主派
- 内容：阿斯拉王国内部争夺王位的两大政治派系。伯雷亚斯・格雷拉特家族效忠于第一王子派，视第二公主爱丽儿为政敌；爱丽儿一派则在北方魔法大学积蓄力量并拉拢强力在野人才。
- 原文依据："伯雷亚斯家是第一王子派。换句话说，伯雷亚斯是敌人。因此，担任伯雷亚斯家家庭教师的鲁迪，是敌人的机率也很高。"、"如今我也成了第二公主派的最强战力。"

- 名称：爱丽儿第二公主派核心武装——「沉默的菲兹」
- 内容：菲兹被塑造成爱丽儿殿下“实力的象征”。依靠实力高强、身世神秘的护卫形象来彰显爱丽儿的存在感并以此吸引多名追随者。若其出身为乡下小姑娘的真实身份暴露，可能会导致追随者叛离。其实力被评定为相当于圣级剑士，虽敌不过其他王子麾下的王级高手，但已是第二公主派内的最强战力。
- 原文依据："菲兹是爱丽儿殿下「实力的象徵」。有个不知来自何处，且实力高强的人物跟随在爱丽儿殿下身边，可以让爱丽儿殿下更彰显自己的存在感。……虽然还没达到什么七大列强，什么王啊，什么帝的那种水准，但是有人说我现在的实力已相当于圣级剑士。虽然无法胜过其他王子们麾下的王级高手，但是如今我也成了第二公主派的最强战力。正因为有「菲兹」这号人物跟随爱丽儿殿下，才会有好几个人基于这样的理由成为爱丽儿殿下的部属。然而，一旦知道菲兹也不过是乡下出身的小姑娘，这些人就很有可能叛离。"

- 名称：魔法大学女子宿舍自警团
- 内容：居住在女子宿舍一楼的女学生自发组织的警卫团体，实质领导人为兽族的辛馨亚蒂，成员对违反宿舍规定的行为极度敏锐且执法严苛。
- 原文依据："就算只是抄捷径，我想一楼那些自称自警团的女孩也会立刻将他团团围住。"、"抓住鲁迪手臂的女学生，辛馨亚蒂非常固执。……既然身为实质领导人的她打了退堂鼓，其他女孩也只好跟着离去。"

## 三、力量体系 / 魔法 / 技能
- 名称：乱魔
- 规则：一种能将对手施展的魔术直接打消或封锁的高级神秘魔术。在施法者准备魔术时可强行打断其魔法，连魔法大学的学员和教师都鲜有人知晓其存在。
- 原文依据："我的魔术被莫名其妙的魔术封住，在无计可施的状况下被从未见过的超强岩炮弹削过脸颊。……「那是叫作乱魔的魔术，你没听说过吗？」不知道，甚至连听都没听过。那恐怕是某个种族的独创魔术之类的吧。就算问魔法大学的任何人，应该也不会有人知道这种魔术的存在。"

- 名称：土魔术稳固身形
- 规则：鲁迪乌斯在遭遇众人围困时，会下意识地利用土魔术将自己的双脚与地面固定，以保持下盘绝对稳定。
- 原文依据："鲁迪正用土魔术固定自己的双脚。我不清楚他为何要这么做。"

- 名称：混合魔术教学体系差异
- 规则：魔法大学正规课程中所讲授的混合魔术理论与方法，与洛琪希教导鲁迪乌斯的原理完全不同，且相对繁杂晦涩，连爱丽儿与路克等人理解起来都极其苦战。
- 原文依据："混合魔术的课程与我知道的完全不同。鲁迪似乎是从洛琪希小姐那学习的，我原本以为这所学校也是采取同样的教法，但却有点麻烦。虽说如此，因为我曾接受过鲁迪的指导，还是可以顺利地理解课程内容，只是爱丽儿殿下和路克倒是为此陷入苦战。"

## 四、种族 / 生物
- 名称：长耳族
- 特征：外貌五官端正高贵，但在身体发育上胸部天生平坦贫瘠，是不可改变的种族遗传特性。
- 原文依据："这也没办法啊。这部分是遗传到长耳族的血统。是种族特性，根本不可能变大嘛。"、"那名女子是长耳族。是个和爸爸感觉很像的人。端正的五官给人一种高贵的印象。"

- 名称：兽族
- 特征：具有发情期；在性格行为上普遍对遵守规章制度表现得极其忠实且不知变通。
- 原文依据："她并不是坏人。只不过所谓的兽族就是会对遵守规定显得特别忠实，很不知变通。"、"毕竟除了内衣小偷的问题以外，还有发情期的问题，虽然现在并非处于那种季节就是。"

## 五、物品 / 道具 / 武器
- 名称：《转移迷宫探索记》
- 说明：亚尼马斯所著的关于转移迷宫探索的书籍。以生动易懂的故事体裁写成，是了解转移魔法与迷宫机制最基础浅显的入门书籍。
- 原文依据："「啊，对了！关于转移，你可以看一下亚尼马斯写的《转移迷宫探索记》。虽然内容是故事形式，但写得很浅显易懂。」首先要做的，就是推荐当初让我理解何谓转移的书籍给鲁迪。如果是那本书，应该连小孩子都能知道转移究竟是什么。"

- 名称：阿斯拉王室御用贴身衣物
- 说明：使用极其名贵布料缝制，并因具备阿斯拉王室成员穿过的附加价值而在黑市能卖出高昂价格，曾引发校内盗窃与转卖风波。
- 原文依据："爱丽儿殿下的贴身衣物是以极为高价的布料制作而成。而且还是阿斯拉王族的贴身衣物，因此会有附加价值。简而言之，就是在市场上能以昂贵的价格售出。事实上在刚入学那时，也的确曾经有人偷走拿出来清洗的内衣转卖出去。五件里面有四件被偷，其中三件被卖出。剩下来的那件，似乎是那名犯人男学生以个人目的使用。"

## 六、历史 / 传说 / 事件
- 事件名：「泥沼的鲁迪乌斯」传闻扩散
- 内容：鲁迪乌斯在中央大陆北部数年内跃升为A级冒险者并在魔法三大国名声大噪。外界流传的情报称其3岁拜洛琪希为师、5岁成为水圣级、7岁担任艾莉丝家庭教师并将其培养为出色淑女。该履历因过于传奇而一度被爱丽儿和路克视为虚构夸大。
- 原文依据："那份情报是有关被称为「泥沼的鲁迪乌斯」这号人物。鲁迪乌斯。没错，我们获得了鲁迪的情报。他年纪轻轻就成为A级冒险者，是个仅花短短数年的时间就在魔法三大国声名远播的魔术师。"、"三岁时拜水王级魔术师洛琪希・米格路迪亚（当时为水圣级）为师，年仅五岁就成为水圣级魔术师。七岁时来到菲托亚领地的要塞都市罗亚，担任市长女儿艾莉丝・伯雷亚斯・格雷拉特的家庭教师，借由良好的教育，使得原本无法驯服的野丫头，摇身一变成为出色的淑女。后来，因为菲托亚领地转移事件而下落不明。……爱丽儿殿下和路克依旧对此半信半疑"

- 事件名：魔法大学内衣失窃事件
- 内容：爱丽儿刚入学时晾晒的5件贴身衣物被同校男学生盗走4件，其中3件流出变卖，1件被该男生自用。该事件导致爱丽儿的贴身衣物转由菲兹全权代洗，并促成了女生宿舍自警团的高度戒备。
- 原文依据："事实上在刚入学那时，也的确曾经有人偷走拿出来清洗的内衣转卖出去。五件里面有四件被偷，其中三件被卖出。剩下来的那件，似乎是那名犯人男学生以个人目的使用。"、"从那之后，清洗爱丽儿殿下的贴身衣物就成了我的工作。"

- 事件名：鲁迪乌斯入学测验与宿舍门禁误会事件
- 内容：鲁迪乌斯受邀入学并在修练场以「乱魔」和留手的强力岩炮弹完胜希露菲（菲兹）；入学当天傍晚因不知宿舍校规途经女子宿舍外，适逢希露菲晾衣手滑掉落内裤被其接住，遭辛馨亚蒂率领的自警团围攻定罪，后由菲兹拔杖亮出魔力强硬阻拦解围。
- 原文依据："在修练场进行实习课程时……我的魔术被莫名其妙的魔术封住，在无计可施的状况下被从未见过的超强岩炮弹削过脸颊。"、"突然有女学生放声大叫。然后住在一楼的那群自称自警团的女孩立刻飞奔出来，鲁迪转眼间就被团团包围。……「我说过他没有犯错吧？总之，你给我放手……！」"

## 七、社会规则 / 习俗 / 文化
- 内容：魔法大学特别生待遇规定：特别生享有居住单人房且免除宿舍值日任务的优待，但由于不参加普通住宿生的规则集会，容易产生对宿舍禁令与生活规则不知情的管理脱节。
- 原文依据："鲁迪是特别生，特别生是住单人房。据说，虽然特别生可以不需要负责宿舍内指派的各种值日工作，但也无法参加说明宿舍规则的等等集会。"

- 内容：魔法大学宿舍防盗与通报义务：女子宿舍周边禁止男性晚间通行，全校学生中一旦有人最先目击违规男性，负有主动通报其他人的守则义务。
- 原文依据："根据住宿生的规矩，男生不能在这个时间走在这条路上。……第一个发现男性的人，有通报其他人的义务。"

- 内容：阿斯拉贵族阶层的生活风气：阿斯拉王室成员的贴身物品在流通市场具备病态的高额转卖价值；阿斯拉王国境内贵族阶层存在较多变态行为者，使得王族及侍从对此类骚扰司空见惯。
- 原文依据："阿斯拉王族的贴身衣物，因此会有附加价值。简而言之，就是在市场上能以昂贵的价格售出。……这对于在阿斯拉王国土生土长的爱丽儿殿下，还有虽然期间短暂，也服侍过爱丽儿殿下一阵子的我来说，并不是值得大惊小怪的事。因为在阿斯拉王国，有更多更变态的人。"

## 九、角色认知 vs 客观事实
- 角色以为：外部流传的情报称鲁迪乌斯在罗亚担任家庭教师时，“借由良好的教育，使得原本无法驯服的野丫头，摇身一变成为出色的淑女”。希露菲、爱丽儿和路克均认为这部分经历过于离谱、定是虚构。
- 原文是否暗示另有真相：是。艾莉丝本质依然凶暴粗鲁，并未真正成为世俗意义上的温婉淑女，王宫内外也皆知其为野丫头，情报确实对管教成果进行了美化虚构。
- 原文依据："借由良好的教育，使得原本无法驯服的野丫头，摇身一变成为出色的淑女。……这份经历不对劲，是虚构的。……「不过实际听到这些传说，还是会让人觉得过于夸大。」"

- 角色以为：希露菲看到鲁迪身后紧跟着一名举止亲昵的美丽长耳族女子（艾莉娜丽洁），惊疑以为她是鲁迪的妻子。
- 原文是否暗示另有真相：是。该名女子为艾莉娜丽洁，是同行伙伴，并非鲁迪的妻子。
- 原文依据："因为鲁迪的身后站着一名漂亮到不行的女性。（……咦……难道是……鲁迪的太太？）那名女子是长耳族。是个和爸爸感觉很像的人。"

- 角色以为：鲁迪乌斯在入学对决击败菲兹后，误以为菲兹是身为主考官学长刻意放水承让给新生挽回面子，深感歉疚并欲登门致歉。
- 原文是否暗示另有真相：是。菲兹当时魔术被乱魔彻底封死，完全束手无策，落败是纯粹的实力被碾压，根本没有故意让步。
- 原文依据："「谢谢你，前辈！是你刻意把胜利让给身为新生的我吧！」" vs "我感到困惑。我不懂他的意思，因为我对他完全束手无策。鲁迪分明也知道这点。可是他却说我卖他面子？"、"「之前真是非常抱歉，都是我欠缺考虑的行动才会导致那种让学长丢了面子的状况……」……我倒是打从一开始就不认为自己能胜过鲁迪。当然啦，我也没想到自己会像那样完全束手无策"

- 角色以为：希露菲看到鲁迪被自警团抓住手臂时不予反抗、双脚固定，以为他是像寻常男孩一样害怕被女生讨厌或被阵势吓得发抖。
- 原文是否暗示另有真相：是。鲁迪实战经验极其丰富，脚底用土魔术固定以稳住身形，不反抗是因为初来乍到自知违背宿舍校规且手握女内裤理亏，希望避免冲突扩大，并非软弱发抖。
- 原文依据："鲁迪正用土魔术固定自己的双脚。我不清楚他为何要这么做。……鲁迪或许是觉得自己被我讨厌，所以才会感到有点害怕。……就像普通的男孩子一样。"
