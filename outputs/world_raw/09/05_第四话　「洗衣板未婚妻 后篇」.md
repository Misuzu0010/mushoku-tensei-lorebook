# 第四话　「洗衣板未婚妻 后篇」 世界设定提取

## 一、地理与场所
- 名称：魔法都市夏利亚
- 内容：拉诺亚魔法大学所在的城市。城内由魔术公会、冒险者公会以及三国联合骑士团驻扎防守。
- 原文依据："另外，拉诺亚魔法大学所在的魔法都市夏利亚，则是由魔术公会、冒险者公会，再加上派驻此地的三国联合骑士团集齐稀少的兵力，包围魔法大学。"

- 名称：魔法大学上级魔术用演习场
- 内容：拉诺亚魔法大学内部场地，平日为荒芜一物的宽广校园正中央场地，用于上级魔术演习或大型决斗。
- 原文依据："现在，我正站在魔法大学的上级魔术用演习场……其实也就是荒芜一物的宽广校园正中央，与巴迪冈迪对峙。"

- 名称：魔法三大国与大学的地理关系
- 内容：拉诺亚王国、涅里斯公国以及巴榭兰特公国离拉诺亚魔法大学均有相当一段距离，发生紧急事态时国内增援骑士团无法即刻赶到。
- 原文依据："拉诺亚王国、涅里斯公国以及巴榭兰特公国这三国在收到魔王巴迪冈迪来袭的消息后，随即出动了国内的骑士团。同时也号召冒险者一同前往，然而，这三国离大学还是有段距离。"

## 二、组织与势力
- 名称：三国联合骑士团 / 守护城镇的三国骑士团
- 内容：由拉诺亚王国、涅里斯公国、巴榭兰特公国派驻在夏利亚的联合骑士力量，设有骑士团长。在魔王来袭事件后，巴迪冈迪以临时的武术顾问身份加入该联合骑士团。
- 原文依据："参加这次会谈的除了盖奥尔格之外，还有守护这个城镇的三国骑士团团长，另外再加上魔术公会的总帅。"、"而且还以临时的武术顾问身分加入了联合骑士团。"

- 名称：魔术公会
- 内容：在夏利亚设有驻留战力与总帅。事件平息后，魔术公会接收了巴迪冈迪自愿提供的一只手臂，用于研究其不死性。
- 原文依据："另外加上魔术公会的总帅……巴迪冈迪为了补偿自己带来的麻烦，愿意提供一只手臂给魔术公会作为研究不死性之用"

- 名称：拉诺亚魔法大学管理层
- 内容：校长为风王级魔术师盖奥尔格（平时戴假发）；副校长为吉纳斯。魔王事件后校方与三国代表、魔术公会共同商讨善后事宜，并接纳巴迪冈迪作为活广告入学。
- 原文依据："据说戴着发饰的大叔是这所学校的校长，名字叫什么来着？我想起来了，是风王级魔术师盖奥尔格。"、"于是，巴迪冈迪就以活广告的身分进入魔法大学就读。"

## 三、力量体系 / 魔法 / 技能
- 名称：魔王阵营现状与实力
- 规则：魔王基本不离开魔大陆。激进派与武斗派魔王大多在拉普拉斯战役中灭绝，现存的基本是对战争不感兴趣的稳健派或保守派，但即使是稳健派也具备统治魔大陆的强大实力。
- 原文依据："毕竟所谓的魔王，基本上不会离开魔大陆。激进派与武斗派的魔王几乎都在拉普拉斯战役中灭绝了。因此，目前在魔大陆只剩下对战争没有兴趣的稳健派或是保守派的魔王。然而，虽然挂名稳健派或是保守派，他们也是一方之主，具有足以统治魔大陆的实力。"

- 名称：不死身与肉体再生（巴迪冈迪）
- 规则：巴迪冈迪具备“不死身”特性，肉体即便被打碎至四分五裂甚至仅余下半身也不会真正死亡，可在短时间内再生复活（散落的残肢会自动爬行合体），但若肉量损失严重，短时间内体型会缩小，完全恢复原本体型需要时间；此外身体表面具备强韧的“斗气”。
- 原文依据："被岩炮弹直接命中的巴迪冈迪伴随着砰的一声巨大声响，整个上半身直接粉身碎骨，六只手臂也被肢解得四分五裂……变成原本一半尺寸的巴迪冈迪站在我的眼前。……此时那六只手臂沙沙地从旁边爬过来，直接合体在他的身上。随后巴迪冈迪的身高霍然成长，只是并没恢复原本的大小。……『看来要恢复原样得稍微花点时间才行！』"、"如果那招能贯通吾的斗气直接伤到吾，就算你赢了。"

- 名称：魔眼抗性 / 魔眼无效化
- 规则：巴迪冈迪对魔眼具备抗性，鲁迪乌斯的预知眼对其完全无效，视野中看不到其未来行动残影或身形。
- 原文依据："预知眼什么都看不见。巴迪冈迪站着的位置……没有任何物体存在。……『不过很遗憾，魔眼对吾无效。』"

- 名称：魔力总量顶峰（拉普拉斯与鲁迪乌斯）
- 规则：魔神拉普拉斯的魔力总量在历史中堪称最高等级。奇希莉卡评价鲁迪乌斯的魔力甚至比拉普拉斯还强（巴迪冈迪亦提及奇希莉卡说话轻率，存在看错的可能 [存疑]）。此外，世界顶峰级的魔力总量无法单纯依靠后天的常规魔力训练达成。
- 原文依据："魔神拉普拉斯的魔力总量综观历史来看也堪称最高等级。换句话说，你具有全世界最高水准的魔力总量。"、"『一般来说是没有办法。』"

- 名称：魔术的物理法则特征（无后座力）
- 规则：施展发射型魔术时不存在后座力/反作用力，但其产生的物理打击效果依然客观存在。
- 原文依据："岩炮弹咻的一声射出。没有感受到后座力。不知为何，魔术并不存在反作用力的概念，然而效果依然理所当然存在。"

- 名称：极致提炼的中级魔术（岩炮弹特化型）
- 规则：普通的中级土魔术（岩炮弹）在长时间集中注入庞大魔力的情况下，可在“硬度”（高密度纺锤形与钻槽结构）、“旋转”（极高速自旋）、“发射速度”（极限推力）三个维度进行极致提炼，其杀伤力足以贯穿魔王的斗气并将肉体轰碎。但因蓄力提炼时间过长，在一般实战中难以运用。
- 原文依据："要使用的魔术是岩炮弹……提炼本身的魔力，做得越牢固、越坚硬越好。……尽可能地形成尖锐的纺锤形，并刻出钻头般的钻槽。再来是旋转。得尽可能形成高速旋转……最后是速度。提炼魔力，尽可能地用最高速射出。其实我从未把这么庞大的魔力灌注在岩炮弹上，毕竟得花时间注入魔力，因此几乎无法运用在实战上。"、"原来就算是普通的中级魔术，只要锻炼到极致也会发出那样的威力啊……"

## 四、种族 / 生物
- 名称：不死魔族（巴迪冈迪）
- 特征：外貌为漆黑肌肤、身材魁梧、拥有六只手臂。寿命长达数千岁，对时间流逝的感知单位以数年、数十年计，因此对短时间变化反应迟缓；肉体被摧毁亦能自我再生。
- 原文依据："提到漆黑的肌肤以及六只手臂，那就是指不死身的魔王巴迪冈迪。"、"要是活到数以千计的年龄，对时间的感觉也会有落差吗？……事实上，我也是两年前跟他道别的……"

- 名称：人族
- 特征：肉体在魔王等长寿或强韧种族眼中极其脆弱，受一点小伤就有致命危险。
- 原文依据："『毕竟人族受了一点小伤马上就会死嘛！吾听说很多人有跟你同样的想法！』"

- 名称：矿坑族
- 特征：拉诺亚魔法大学内有该族学生（如札诺巴的同学），擅长雕刻工艺。
- 原文依据："真要说的话，毕竟这部分并非我的专门领域，所以还请了跟札诺巴同学年的矿坑族协助。"

## 五、物品 / 道具 / 武器
- 名称：魔力附加品鞋子（菲兹穿戴）
- 说明：附有魔力的鞋类装备，能大幅提升移动奔跑速度（速度约为鲁迪乌斯的三倍）。
- 原文依据："『因为……我的鞋子是魔力附加品……』听到这句话，我把视线移到学长平常穿的鞋子。原来这是魔力附加品啊。"

- 名称：菲兹的斗篷与太阳眼镜 [存疑]
- 说明：菲兹在暖和天气也始终不脱下的斗篷与常年佩戴的太阳眼镜，菲兹对是否为魔力附加品含糊其辞地回答“秘密”。
- 原文依据："说不定他平常穿戴在身上的斗篷也是魔力附加品。毕竟他就算天气暖和了起来也始终不脱下那件斗篷。……『难道说……那副太阳眼镜也是？』『呼……呼……这也是……没错，不对……这是……秘密……』"

- 名称：傲慢水龙王
- 说明：鲁迪乌斯的法杖，杖头镶嵌有巨大惊人的魔石。
- 原文依据："我从菲兹学长手中接过「傲慢水龙王」……『菲兹学长，来看看这前端的魔石，你觉得这家伙如何？』『大……大得吓人……』"

## 六、历史 / 传说 / 事件
- 事件名：拉普拉斯战役
- 内容：过去的古老大战。激进派与武斗派魔王几乎在此战役中全军覆没；不死身魔王巴迪冈迪在该战役前即已存在，且曾与魔神拉普拉斯交手，连拉普拉斯也未能彻底将其消灭。
- 原文依据："激进派与武斗派的魔王几乎都在拉普拉斯战役中灭绝了。"、"他是从拉普拉斯战役开打前就存在的古老魔王之一。……据说他曾与那个拉普拉斯交手过。换句话说，如果这事属实，就表示连拉普拉斯也无法彻底消灭他。"

- 事件名：鲁迪乌斯对决巴迪冈迪
- 内容：巴迪冈迪因嫉妒奇希莉卡夸奖鲁迪乌斯而前来挑战，提出让鲁迪乌斯出一招、正面接下的决斗规则。鲁迪乌斯以极致提炼的岩炮弹将其上半身击碎。巴迪冈迪复活后承认鲁迪乌斯获胜并允其自称勇者，随后以三拳将鲁迪乌斯打昏。最终三大国将其迎为国宾，巴迪冈迪以活广告身份入学。
- 原文依据："如果那招能贯通吾的斗气直接伤到吾，就算你赢了。……被岩炮弹直接命中的巴迪冈迪伴随着砰的一声巨大声响，整个上半身直接粉身碎骨……是你赢了，鲁迪乌斯！……于是，巴迪冈迪就以活广告的身分进入魔法大学就读。"

## 七、社会规则 / 习俗 / 文化
- 内容：魔王的信条是不打破约定；巴迪冈迪允许坦率接受其要求并开怀大笑的人直呼其名“巴迪”。
- 原文依据："『魔王绝对不会打破约定。』"、"『直呼巴迪无妨。只要对方坦率地接受吾要求开怀大笑，吾就允许他用这个名字称呼本人。』"

- 内容：战胜魔王之人会被赋予自称“勇者”的资格与许可。
- 原文依据："『是你赢了，鲁迪乌斯！现在允许你自称为勇者！』"

- 内容：魔王的睿智传闻：巴迪冈迪在魔法大学内视察向学生搭话，传闻若不上报通报校方，就有可能被赐予“魔王的睿智” [存疑]。
- 原文依据："偶尔会进行视察向学生搭话，好像还因此被通报过。不过若不通报的话，据说就会被赐予魔王的睿智……"

## 九、角色认知 vs 客观事实
- 角色以为：吉纳斯副校长兴奋地认为鲁迪乌斯是在激烈交战中“先发制人使出一招并得到魔王肯定”。
- 原文是否暗示另有真相：是。
- 原文依据："看样子，他并不清楚我们在决斗之前交谈的内容。其实巴迪冈迪是故意接下我的魔术，无论对他管不管用战斗都会就此划下句点。"

- 角色以为：鲁迪乌斯看到巴迪冈迪身体炸碎、倒地不动，以为自己失手杀了魔王。
- 原文是否暗示另有真相：是（巴迪冈迪是不死身，迅速自行再生复活）。
- 原文依据："我……我杀了他吗……？……『呼哈哈哈哈！吾大复活！』变成原本一半尺寸的巴迪冈迪站在我的眼前。"

- 角色以为：巴迪冈迪转述奇希莉卡称鲁迪乌斯的魔力甚至比拉普拉斯还强、是世界最高水准，但巴迪冈迪也怀疑奇希莉卡讲话随便可能是看错了。
- 原文是否暗示另有真相：不明（本章未给出绝对定论，标注存疑）。
- 原文依据："『魔神拉普拉斯的魔力总量综观历史来看也堪称最高等级。换句话说，你具有全世界最高水准的魔力总量。』……『吾并不清楚事情真相，因为奇希莉卡讲话也挺随便的。说不定只是她看错。』"
