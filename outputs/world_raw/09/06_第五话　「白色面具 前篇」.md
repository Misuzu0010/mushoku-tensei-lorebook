# 第五话　「白色面具 前篇」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚魔法大学研究栋（塞伦特的研究室）
- 内容：位于研究栋三楼最深处，由特别生塞伦特打通了三间房间改装而成。室内堆满大量书籍、捆扎纸张、各式魔道具，以及堆积如山的大量魔石与魔力结晶，为其日常生活与闭门研究的场所。
- 原文依据："他说是在研究栋三楼的最里面。据说塞伦特打通了位于该处的三间房间并改装成研究室，几乎闭门不出在那生活。"、"研究室里面散乱着大量书籍和成捆纸张，到处都搁着不知有何用途的魔道具，还有堆得像山一样高的大量魔力结晶与魔石。"

- 名称：赤龙下颚
- 内容：过去鲁迪乌斯与龙神奥尔斯帝德交手、险些丧命的峡谷地形。
- 原文依据："『不过正因在「赤龙下颚」相遇竖了旗标，我们才能在这所学校再会。算是这样的因果路线吧。』"

## 二、组织与势力
- 名称：魔术公会的等级体系与制度
- 内容：魔术公会内部设有严格的分级体系。B级公会成员若前往其他国家建立魔术学校，公会会派专人协助指导技术并提供资金赞助（吉纳斯副校长为B级）；A级相当于分部长层级（塞伦特因多项发明革新被授予A级）；S级属于公会干部层级（盖奥尔格校长为S级）。
- 原文依据："根据我的调查，魔术公会的A级是分部长等级，S级则属于干部等级。我记得盖奥尔格校长是S级，而吉纳斯副校长则是B级。"、"印象中，我曾听说只要成为B级，在其他国家建立魔术学校时就会有专人帮忙教导技术，甚至还可以获得资金赞助。"、"因此这些功绩被魔术公会认可，塞伦特被赐予A级公会成员的称号。"

## 三、力量体系 / 魔法 / 技能
- 名称：斗气与身体强化
- 规则：剑士自然而然缠绕在身上的能量。缠绕斗气能显著提高防御力、速度与臂力。巴迪冈迪的漆黑肉体具有强韧斗气，据其所述唯有达到剑神流“王级”水准（如基列奴、瑞杰路德级别）的剑技才能造成伤害。鲁迪乌斯虽能通过锻炼增加肌肉量，但无法自然缠绕斗气，肉体素质与反应速度依然仅为常人水准。
- 原文依据："虽然这是我从巴迪冈迪那听来的，但要伤到他用斗气缠绕过的那副漆黑身躯，好像必须要有剑神流王级水准的剑技才能办到。王级。换句话说就是要有基列奴或是瑞杰路德那种等级的战士才能勉强与他一战。"、"所谓斗气，似乎是所有剑士都会自然而然缠绕在身上的能力，然而即使再怎么锻炼，我的肉体也无法具有像艾莉丝或是瑞杰路德他们那种速度与臂力。尽管能增加肌肉量，但也仅只如此。结果，我也只有攻击力高人一等。"

- 名称：召唤魔术与转移的机制关联与现状
- 规则：召唤魔术与转移魔术在本质上一个是“呼唤过来”，一个是“传送出去”，但两者的原理和共通点极多。在拉诺亚魔法大学并无专门教授召唤魔术的教师；公会中虽有召唤魔术师但大多仅初级或中级（只能召唤无害使魔或无自我意识的小精灵）；高深召唤术极罕见（推测可能与结界、神击同样被某国独占垄断 [存疑]）。全校仅塞伦特・赛文斯塔一人在专门深入研究召唤魔术。
- 原文依据："调查的内容当然是关于转移与召唤方面。然而我越是调查，就发现转移与召唤之间的共通点越多。尽管一个是呼唤过来，一个是传送出去，两件事有着本质上的不同，但所有内容实在都过于相似。看样子有必要认真学习召唤的知识。……在这所大学并没有专门教授召唤魔术的老师。尽管去魔术公会似乎就可找到能使用召唤魔术的人物，但充其量也不过是初级或是中级，顶多召唤出无伤大雅的使魔或是几乎不具自我意识的精灵。"、"『这所学校还有一个人在专门研究召唤魔术！』……『就是特别生的塞伦特・赛文斯塔。』"

- 名称：附加系魔术
- 规则：存在能操控至上级水准的魔术师，但附加系魔术与召唤系魔术原理相去甚远。
- 原文依据："如果是附加系的话，似乎有人能操控到上级，然而附加系与召唤系魔术相去甚远"

- 名称：穿越 vs 转生（空间跳跃 vs 灵魂转世）
- 规则：“转生”保留前世记忆、灵魂以婴儿形态诞生并拥有异世界新肉体与血统外貌；“穿越”则是肉体本身未发生改变的空间跳跃/空间转移，连带年龄、原本相貌直接跨界来到异世界（七星静香即为穿越者，其容貌与十五年前车祸现场完全一致）。
- 原文依据："『也就是所谓的穿越。我穿越到这无趣的世界来了。』……我是所谓的转生者。肉体会与原本的不同，只会带着前世的记忆诞生于这个世界。然而穿越却不同。穿越……换句话说就是转移，一种空间跳跃。她保持着年龄和肉体不变，直接来到这个世界。"

- 名称：解毒魔术课程
- 规则：魔法大学开设有中级解毒魔术等系统课程。
- 原文依据："上完中级的解毒魔术课，我一踏出走廊就看见了辛馨亚蒂。"

## 四、种族 / 生物
- 名称：兽族的文化观念与等级制度
- 特征：极其看重上下级序列与组织从属关系，崇尚强权与武力压制，有强烈的“争当顶点/老大”的本能。
- 原文依据："『老大根本不懂喵。组织的上下关系得要确实区分才行喵。』『没错的说，这很重要的说。』看来对兽族来说，上下关系至关重要"、"『老大既然能打赢菲兹，那就能站上这所学校的顶点的说。』"

- 名称：地球人 / 异界来客
- 特征：来自原本世界的现代人类。目前确认存在的地球人有七星静香（穿越者，肉体穿越）、鲁迪乌斯（转生者，前世死后转生）。另有七星正在寻找的另外两名地球人：篠原秋人、黑木诚司。
- 原文依据："我接下她递出的纸，上面写着「篠原秋人　黑木诚司」……『我的名字叫七星静香，是日本人。最近以塞伦特・赛文斯塔的假名自称。』……『我自从来到这个世界之后也是第一次遇到「地球人」』"

## 五、物品 / 道具 / 武器
- 名称：白色面具
- 说明：七星静香常年佩戴的纯白色无表情面具，能完全隐藏其真实容貌。在与龙神奥尔斯帝德同行时亦佩戴该面具。
- 原文依据："她戴着面无表情的……白色面具。"、"那个白色面具的少女，当时和奥尔斯帝德在一起。"

- 名称：黑板与粉笔
- 说明：塞伦特（七星静香）引入魔法大学的现代教学用具，将石灰固定成棒状（粉笔），在漆黑板子上书写文字，使得教学更加顺畅直观。
- 原文依据："还有，也是塞伦特设计出名为黑板的工具。将石灰固定成棒状，在涂成漆黑一片的板子上书写文字。仅仅这样就让课程更为流畅进行，因此受到好评。"

- 名称：魔法大学统一制服（塞伦特改良）
- 说明：由塞伦特调动阿斯拉王国的设计师及工房人脉制作，通过统一着装彻底改善了魔法大学外界眼中“各类混杂种族的鄙俗学校”之负面印象。
- 原文依据："而且设计制服的人也是塞伦特。塞伦特动用了阿斯拉王国的设计师及工房的人脉，让他们在那制作制服。原本世人认为魔法大学是间聚集了杂七杂八种族的鄙俗学校，但塞伦特借由统一制服洗刷既有成见，顺利地提升学校的形象。"

- 名称：科里浓汤
- 说明：塞伦特发明的独创料理，实为复刻地球的咖哩。将马铃薯、胡萝卜、洋葱等熬煮，加入十多种辛香料制作的调味混合物，搭配面包蘸食浓稠褐色汤汁。
- 原文依据："另外，还发明出名为科里浓汤的独创料理。那是一种将马铃薯、红萝卜及洋葱等食材放进锅里熬煮，再把混合了十几种辛香料制成的调味料加进锅里，最后用面包去沾熬煮出来的浓稠褐色汤汁来吃的料理。简而言之，就是咖哩。"

## 六、历史 / 传说 / 事件
- 事件名：塞伦特对魔法大学的现代化改革
- 内容：塞伦特确立来自阿斯拉王国的食材供应链改善食堂伙食、发明科里浓汤、设计统一制服、设计黑板教学工具，因这一系列丰功伟业被魔术公会授予A级公会成员称号。
- 原文依据："听过的不只是名字，也听说过这个人物对这所学校所做的各项丰功伟业。首先，是改善餐厅的餐点。确立来自阿斯拉王国的食材运输路线……另外，还发明出名为科里浓汤的独创料理。……而且设计制服的人也是塞伦特。……还有，也是塞伦特设计出名为黑板的工具。……因此这些功绩被魔术公会认可，塞伦特被赐予A级公会成员的称号。"

- 事件名：地球车祸与跨界穿越事件
- 内容：约十五年前在地球，鲁迪乌斯的前世为救两名险遭卡车碾压的争吵高中男女而丧命并转生；其中的女高中生七星静香则以肉身穿越形式直接来到异世界，后来与龙神奥尔斯帝德同行，并在赤龙下颚救下了被龙神贯穿心脏濒死的鲁迪乌斯。
- 原文依据："是我生前的记忆，最后的那瞬间。差点被卡车辗过的高中生，一对争吵的男女，而其中一人，那个女人……眼前站着一个与她长相如出一辙的少女。……明明从那之后已经过了十五年，她的脸却和当时一模一样。……『也就是所谓的穿越。我穿越到这无趣的世界来了。』"、"『为什么你会那么害怕啦。我之前不是救了你吗？……对喔，那个时候你已经死了所以没有印象嘛。』"

## 七、社会规则 / 习俗 / 文化
- 内容：魔法大学食材供应链：魔法大学位于北方大地，原本无法享用丰富多样的食材，经由塞伦特开辟的阿斯拉王国运输线改善了饮食环境。
- 原文依据："首先，是改善餐厅的餐点。确立来自阿斯拉王国的食材运输路线，让学校能使用原本在北方大地无法享用的食材。"

- 内容：校园实力崇拜与威慑：鲁迪乌斯击败菲兹、收服兽族问题学生并一击击溃魔王后，在全校学生中建立了近乎恐惧的威信，学生走廊相遇时主动退避让路。
- 原文依据："最近有人在畏惧我。对象是在魔法大学就读的几乎所有学生。……毕竟我打倒了学园第一高手菲兹，还让问题学生对我言听计从。后来还打倒了让学校陷入恐慌的魔王，而且只用一招。这样当然会让人感到畏惧。"

## 九、角色认知 vs 客观事实
- 角色以为：校内一般学生以为鲁迪乌斯既然拥有王级破坏力并秒杀魔王，其身体能力必然同样恐怖，凌驾魔王。
- 原文是否暗示另有真相：是。
- 原文依据："一般学生怎么可能会理解这种事。说不定他们以为既然我的攻击力有王级水准，那么身体能力应该也是以此为基准。俨然是凌驾魔王的存在。……我并没有缠绕巴迪冈迪所说的斗气。……结果，我也只有攻击力高人一等。"

- 角色以为：塞伦特向菲兹说明鲁迪乌斯与自己“来自同乡”，菲兹断然否定说“怎么可能”。
- 原文是否暗示另有真相：是（鲁迪乌斯前世确实与七星来自同一个地球日本，菲兹基于异世界认知判定不可能）。
- 原文依据："『不用惊慌，他只是和我来自同乡。』『同乡？怎么可能！』菲兹学长对此做出否定。"

- 角色以为：七星静香以为鲁迪乌斯同样来自现代地球，理所当然会极度渴望并协助一起“回到原本的世界”。
- 原文是否暗示另有真相：是（鲁迪乌斯极度抗拒回到原本世界，果断拒绝）。
- 原文依据："『为了回到原本的世界，就让我们彼此协助吧。』……『我……根本不想要回到原来的世界。』"

- 角色以为：七星静香以为鲁迪乌斯有着白人外貌又会日语，猜测他是混血儿或住在日本的外国人。
- 原文是否暗示另有真相：是（鲁迪乌斯前世是纯粹的日本家里蹲尼特族，转生后才拥有异世界肉体与混血外表）。
- 原文依据："『话说回来，你是哪里出身的？美国？还是来自欧洲？应该是白人吧……可是你却懂日语……莫非你是混血儿吗？像是住在日本的外国人之类的？』"
