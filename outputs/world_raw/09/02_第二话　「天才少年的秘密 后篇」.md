# 第二话　「天才少年的秘密 后篇」 世界设定提取

## 一、地理与场所
- 无

## 二、组织与势力
- 名称：米里斯教团（神职体系）
- 内容：米里斯神父接受过专门聆听信徒忏悔并开导信徒的专业训练；克里夫具备米里斯神父的身份与受训经历。
- 原文依据："鲁迪乌斯，我姑且也以米里斯神父的身分受过聆听信徒忏悔的训练。尽管其他人说我在这方面并没有什么才能，但至少可以和你一起想办法。要是有什么事就找我商量吧。"

- 名称：冒险者公会（阶级）
- 内容：艾莉娜丽洁拥有S级冒险者等级，在冒险队伍中担任前卫战士。
- 原文依据："艾莉娜丽洁・杜拉冈罗德。是S级冒险者，前卫，担任战士，目前是魔法大学的一年级学生。"

## 三、力量体系 / 魔法 / 技能
- 名称：吸取精力的诅咒
- 规则：艾莉娜丽洁身体所附带的诅咒。受诅咒侵蚀者每晚都必须通过性交吸取男性的精力以维持状态，因此无法维持单一固定的伴侣关系，常年重复一夜情关系。该体质鲜少受孕，但受孕生产后具备抚养子女长大的能力。
- 原文依据："她的身体被某种诅咒侵蚀。因此每晚都得吸取男人的精力不可。所以，她不会与特定的男人交往，只会一而再再而三地重复仅仅一夜的关系。据说她还生过小孩，但关于孩子的下落却不愿透露给我。……然而实际上她鲜少怀孕，就算怀孕生产，也似乎会好好地抚养小孩长大使其能够自立，但详情如何我并不清楚。""你很清楚我身上的诅咒吧？我没有办法跟单一特定对象交往。""『我一定会设法解开你身上的诅咒！所以跟我结婚吧！』"

- 名称：混合魔术运用理论
- 规则：若将混合魔术引发的各类物理与环境现象规律彻底记熟，即使自身不连续释放两种属性魔术，亦可借助并利用自然界现成的环境现象重现出混合魔术的效果。
- 原文依据："只要把混合魔术会引发的各种状况都背起来就很简单。即使不使用两种魔术，也可利用自然界内的现象顺利重现。"

- 名称：前卫战士水魔术应用
- 规则：前卫战士可将初级水魔术融入近身肉搏战术体系之中。
- 原文依据："最近据说还打算把初级的水魔术套用在自己的战术上。"

## 四、种族 / 生物
- 名称：兽族（生理感知特质）
- 特征：兽族拥有极其灵敏的嗅觉感知，能够嗅出他人身体在动情时是否散发出“发情的气味”。
- 原文依据："因为老大之前碰我们时没闻到什么发情的气味，所以我只是觉得会不会是这样的说……"

- 名称：长耳族（生理特征）
- 特征：外貌身形修长，寿命极长且年龄不详（艾莉娜丽洁身形比十六岁的人类少年克里夫更加高大）。
- 原文依据："艾莉娜丽洁・杜拉冈罗德。……年龄不详。""艾莉娜丽洁比克里夫还高，应该说男方太娇小了。"

## 六、历史 / 传说 / 事件
- 事件名：黑狼之牙队伍历史
- 内容：艾莉娜丽洁曾与鲁迪乌斯的父母保罗、简妮丝同属于一支冒险者队伍（黑狼之牙），因而鲁迪乌斯深知其为人与诅咒内情。
- 原文依据："是的，我的确认识艾莉娜丽洁。因为她是我父母以前所属的队伍成员。"

## 七、社会规则 / 习俗 / 文化
- 内容：米里斯教徒礼法中对“媒人”极为敬重，严守对介绍人的敬意承诺；米里希昂流派的行礼规矩为双脚并拢立正并将单拳抵在腹前。
- 原文依据："克里夫从我的身后迅速地站了出来，将拳头顶在肚子前，双脚并拢立定。这应该是米里希昂流的礼仪规矩吧。""这是当然。我是虔诚的米里斯教徒！自然会对媒人致上足够的敬意。""毕竟我不是米里斯教徒，还请你不要到时候才说什么：『媒人怎么可以这么做』之类的怪罪我喔。""我不会这么做的。"

## 九、角色认知 vs 客观事实
- 角色以为：克里夫起初认定艾莉娜丽洁圣洁不可侵犯，那些指责她与众多男学生随意发生肉体关系的传言全都是出于嫉妒捏造的流言蜚语。
- 原文是否暗示另有真相：是。艾莉娜丽洁确实受身体诅咒所迫，必须每晚吸取男性精力，在校内频繁与多名男学生发生一夜情。
- 原文依据："不过呢，克里夫却认为窗边的女孩与性行为无缘。『但是却有不好的传言指称她会轻率地和其他男学生性交。我想大概是有人嫉妒她才会放出这样的闲言闲语吧。』……她的身体被某种诅咒侵蚀。因此每晚都得吸取男人的精力不可。所以，她不会与特定的男人交往，只会一而再再而三地重复仅仅一夜的关系。"

- 角色以为：鲁迪乌斯在图书馆与菲兹谈论感情话题时，看到菲兹满脸通红、局促羞涩，以为菲兹暗恋的人是高不可攀的阿斯拉王国爱丽儿公主。
- 原文是否暗示另有真相：是。原文暗示菲兹心有所属且痛苦于无法表明心意，其实菲兹真正暗恋的对象是鲁迪乌斯本人。
- 原文依据："『一见钟情……而且还找我商量……难……难道是爱丽儿大人？如果是的话那可不行。……』……『呃，因为我也有喜欢的人，所以可以了解那个人的心情。……只能看着对方却无法表明自己的心意，我认为这样很痛苦。』菲兹学长满脸通红，甚至还红到耳朵。……会是谁啊……就常理推断应该是爱丽儿公主吧，毕竟他刚才也起了不小的反应。"

- 角色以为：鲁迪乌斯与艾莉娜丽洁私下交谈后，都以为将诅咒真相与轻浮恶名告知克里夫后，恪守清规的米里斯教徒克里夫必定会知难而退，恋情绝无可能。
- 原文是否暗示另有真相：是。克里夫在得知诅咒真相后，非但没有退缩，反而男子气概爆发当场向艾莉娜丽洁求婚并承诺必定解开其诅咒，打动了艾莉娜丽洁，两人迅速确定恋人关系。
- 原文依据："『呃，这跟说好的不同吧？』『鲁迪乌斯，被他用那么有男子气概的方式求婚，就算是我也会怦然心动的。』……『我一定会设法解开你身上的诅咒！所以跟我结婚吧！』……然后就到旅社品嚐了克里夫娇嫩的……"

- 角色以为：普露塞娜和莉妮亚曾怀疑鲁迪乌斯之所以虽然对她们毛手毛脚却从未动真格推倒她们，是因为鲁迪乌斯身体有ED不举的隐疾。
- 原文是否暗示另有真相：是。普露塞娜根据鲁迪接触时缺乏“发情气味”推断属实，鲁迪乌斯在班级中当场坦白并承认自己确实罹患ED。
- 原文依据："『因为老大之前碰我们时没闻到什么发情的气味，所以我只是觉得会不会是这样的说……』普露塞娜说完这句话后，众人注视着我的视线顿时转变为怜悯的眼神。……『算了，也没关系啦。反正被知道我也不会感到困扰。』"
