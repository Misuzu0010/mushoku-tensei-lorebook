# 第九话　「死斗」 世界设定提取

## 一、地理与场所
- 名称：迷宫最深处的巨大房间
  - 内容：转移迷宫最深层的守关房间，内部空间极其宽广，有九头龙严阵以待，其后方有一块封着塞妮丝的魔力结晶。
  - 原文依据："九头龙在巨大的房间里严阵以待。它身后有一块魔力结晶，被封在里面的人果然是塞妮丝没错。"

## 二、组织与势力
无

## 三、力量体系 / 魔法 / 技能
- 名称：火魔术（近距离焚烧效果）
  - 规则：远距离发射的火球在靠近九头龙时会被缩小并消解吸收；必须近距离贴身使出高温火魔术，将断颈伤口彻底烧成焦炭才能阻止其肉体再生。若火力不够未烤透，或烧焦部位被咬掉，仍会重新再生。
  - 原文依据："火球越靠近九头龙就越小，在命中的同时消失无踪。只在耳边留下像是玻璃被刮的刺耳声响。"、"只有靠近攻击，否则无法打倒敌人。唯一办法就是贴近九头龙使出火魔术，把伤口整个烧成焦炭。"、"温度高得惊人，连我都可以感受到让人呼吸困难的高温……然而我必须使出这种水准的火力，否则无法烧毁断面。一旦没有烤透，九头龙甚至有可能会再生。"
- 名称：治愈魔术（Healing）
  - 规则：初级治愈魔术，咏唱咒文为“神圣之力是香醇之粮──『Healing』！”，可快速治愈战斗造成的出血与外伤。
  - 原文依据："「神圣之力是香醇之粮──『Healing』！」塔尔韩德受伤之后，洛琪希立刻边咏唱边跑过去，治好他的伤口。"
- 名称：冰击
  - 规则：水/冰系魔术，咏唱咒文为“愿伟大的冰之加护降临汝所求之处，承受冰河之浊流吧，『冰击』！”，艾莉娜丽洁在零距离释放，制造冰块砸击目标尚未长出鳞片的柔嫩肌肉。
  - 原文依据："「愿伟大的冰之加护降临汝所求之处，承受冰河之浊流吧，『冰击』！」艾莉娜丽洁居然使出魔术，从零距离的位置攻击再生中的断颈。冰块砸向还没长出鳞片的柔软肌肉然后碎裂四散，断颈喷出如石榴般的鲜血，不断痛苦扭动。"
- 名称：火炎放射
  - 规则：火系攻击魔术，咏唱咒文为“微小的火星将会把巨大的恩惠燃烧殆尽！『火炎放射』！”，可用于近距离猛烈喷射火焰，灼烧目标或将断颈彻底化为焦炭。
  - 原文依据："「微小的火星将会把巨大的恩惠燃烧殆尽！『火炎放射』！」不知何时追上艾莉娜丽洁的洛琪希使出火炎放射。即使威力被鳞片减弱，九头龙的断颈还是被烧得冒烟。"、"「微小的火星将会把巨大的恩惠燃烧殆尽！『火炎放射』」那个声音虽小，却明确地在我耳边响起。最后一颗头化为焦炭落到地上。"
- 名称：水魔术（防御水墙）
  - 规则：制造出一大片厚重的水墙用于阻挡火焰与高热。抵挡龙的火焰气息时会产生大量蒸气导致室内温度急剧升高。普通数名魔术师联手也难以阻挡龙息，需要异乎寻常的庞大魔力方能奏效。
  - 原文依据："我制造出一片水，一大片厚厚的水墙。──几乎同时，九头龙吐出气息。九头龙的三颗头一起往这边喷出极为猛烈的火焰气息，冲击水墙。周围冒出大量蒸气，让室内的温度急速上升。"、"如果是一般魔术师独自面对，根本无从抵抗。即使集合五名……不，将近十名魔术师共同制造出一面水墙，或许可以……不，就算那样做，大概也无法抵挡。不过，我的魔力并不一般。"
- 名称：岩炮弹
  - 规则：土系攻击魔术，零距离直接击中九头龙未受鳞片保护的眼窝内部可将整个脑袋炸爆。
  - 原文依据："下一瞬间，我放出岩炮弹。九头龙的脑袋爆开，同时眼皮也完全闭上。"
- 名称：上级治愈魔术（Shine Healing）
  - 规则：咏唱咒文为“奇迹的天使啊，请对生命之鼓动赐予上天之气息。太阳悬于天顶，神之圣使厌恶赤红。请降临光之海，展开纯白的羽翼。如此一来即可驱逐赤红。『ShineHealing』。”；无法使断肢再生，但能使断裂残端伤口止血并生长出新生肉芽，同时治愈周身擦挫伤。
  - 原文依据："「奇迹的天使啊，请对生命之鼓动赐予上天之气息。太阳悬于天顶，神之圣使厌恶赤红。请降临光之海，展开纯白的羽翼。如此一来即可驱逐赤红。『ShineHealing』。」我咏唱上级治愈魔术。自己很清楚上级治愈无法治好失去的部位。然而，我还是使用了上级治愈魔术。被扯断的缺口长出粉红色的新肉，出血也停止了。顺便还可以感觉到脸上的伤口和被保罗踹开时受到的撞击伤也逐渐痊愈。"
- 名称：斗气
  - 规则：高级战士缠绕身体的特殊能量。保罗凭借强大的肉体与身缠斗气，在使出全力踢飞成年人时能抵消反作用力，保持自身位置纹丝不动。
  - 原文依据："保罗是这个世界的剑士，能力优秀，肌肉发达，还能够身缠斗气。换句话说，他即使把我踢了出去，自己的位置也可以保持不动。"

## 四、种族 / 生物
- 名称：九头龙
  - 特征：
    1. 拥有九颗巨大的头颅，行动敏捷如野蛇；常态下不会同时动用四颗以上头颅，但在狂暴或战况剧变时可五颗头同时围攻单一目标；
    2. 具备魔术无效化/削减特性，远距离飞来的魔术靠近其身体会迅速缩小并在命中时消散；
    3. 拥有超强肉体再生能力，断颈若未彻底碳化会迅速重生；若断面被烧焦，能通过其他头颅咬断并吃掉焦炭部分，从而重启再生；
    4. 头颅被斩断后，粗大如磨泥器般覆盖锐利鳞片的八根断颈仍可作为鞭子大范围横扫周遭；
    5. 能喷吐威力骇人的火焰气息，极高温火焰可瞬间熔化钢铁、蒸发小型沼泽；气息属于最后王牌，受体内机构或蓄力限制无法连续施放，多颗头同时喷吐后会产生使用硬直；
    6. 头部额头长有角状突起，眼皮覆盖厚重坚硬鳞片且肌肉极为强韧，闭合时力如断头台，能瞬间切碎皮肉骨骼；眼睛本身无鳞片保护，为肉体弱点；
    7. 最终的主头被彻底摧毁并焚烧后，其生命会真正消逝，不会无休止复活。
  - 原文依据："九头龙不会同时动用四颗头以上，是因为处理能力不够吗？还是单纯因为动到太多颗会彼此妨碍？"、"火球越靠近九头龙就越小，在命中的同时消失无踪。只在耳边留下像是玻璃被刮的刺耳声响。"、"九头龙的一颗头。特别大的那颗头，咬断烧焦断颈之一的前端。……被咬的断颈开始迅速再生。……被烧焦的断面无法再生。然而只要吃掉烧焦的部分，就能够重新再生。"、"龙的火焰气息以惊人的温度出名，甚至可以轻易熔化钢铁，瞬间蒸发小型的沼泽。"、"气息有使用限制。虽然不清楚理由，但或许是用到了体内的什么机构，还是因为必须累积魔力，总之无法连续使用。所以，气息是龙的最后王牌。"、"九头龙把没有头部的颈子当成鞭子般甩动。它晃动身体，一口气使用八条覆盖着像磨泥器般锐利的鳞片，必须以两手才能抱住的粗大颈子扫向周遭。"、"九头龙试图闭上眼睛。包覆着鳞片的眼皮逐渐往下的样子宛如断头台。"、"左手消失了。皮肤和肌肉被眼皮上的鳞片切断，骨头被构成眼皮的强韧肌肉搅碎。然后在最后那一瞬间，被九头龙猛然抬头的动作整个扯断。"、"它没有再生，最后的脑袋不是不死身。"

## 五、物品 / 道具 / 武器
- 名称：魔力结晶
  - 说明：迷宫最深处用于封印塞妮丝的晶体构造物。
  - 原文依据："九头龙在巨大的房间里严阵以待。它身后有一块魔力结晶，被封在里面的人果然是塞妮丝没错。"
- 名称：斗士短剑
  - 说明：艾莉娜丽洁佩戴并使用的近战短剑，锋利坚固，可在零距离配合魔术进行刺击。
  - 原文依据："接着举起斗士短剑，狠狠刺进那根正在再生的断颈里。"

## 六、历史 / 传说 / 事件
- 事件名：迷宫最深处的死斗与保罗战死
  - 内容：鲁迪乌斯一行人在转移迷宫最深处与守护魔力结晶的九头龙展开死斗。在斩断并烧毁数颗头颅后，九头龙甩动无头颈部并以最后一颗头袭向鲁迪乌斯。保罗为救鲁迪乌斯全力将其踢开，自己停留在原地被九头龙咬断下半身阵亡；鲁迪乌斯近距离以岩炮弹轰破九头龙眼窝，配合洛琪希的火炎放射击杀九头龙，鲁迪乌斯的左手则被九头龙的眼皮咬断扯落。
  - 原文依据："因为九头龙的最后一颗头朝着我这边冲来，所以保罗把我踢飞。……他即使把我踢了出去，自己的位置也可以保持不动。所以……也就是说……他停在我原本所在的位置……保罗倒在地上。……没有下半身。……保罗他……死了。"、"左手消失了。皮肤和肌肉被眼皮上的鳞片切断，骨头被构成眼皮的强韧肌肉搅碎。然后在最后那一瞬间，被九头龙猛然抬头的动作整个扯断。"

## 七、社会规则 / 习俗 / 文化
- 迷宫攻坚战中无战斗力成员的职责：
  - 内容：在面对特级危险的迷宫决战时，缺乏正面战斗能力的成员（如盗贼基斯）在后方待命；若突击主力全灭，其职责是必须立刻逃生，将全灭的结果传达出去。
  - 原文依据："基斯待在更后方待命。他没有能参与战斗的能力，在这种时候派不上用场。然而，他还是在场。因为假如我们全灭，他的任务就是逃离此地并把结果传达出去。"

## 九、角色认知 vs 客观事实
- 角色以为：九头龙在受到连续断颈压制后踉跄后退，鲁迪乌斯推测它可能是害怕或是设下陷阱。
  - 原文是否暗示另有真相：是（九头龙后退是为了用主体大头吃掉自己被烧焦的断颈前端，借此摆脱碳化抑制重新再生）。
  - 原文依据："它彷佛是对我们感到害怕，摇摇晃晃地开始后退。……等一下，那不是陷阱吗？……九头龙的一颗头。特别大的那颗头，咬断烧焦断颈之一的前端。……被咬的断颈开始迅速再生。"
- 角色以为：战斗结束后，鲁迪乌斯以为这场苦战的代价仅仅是自己失去了一条左手，心中尚觉侥幸，以为保罗平安存活。
  - 原文是否暗示另有真相：是（保罗为救鲁迪乌斯全力将其踹离危险位置，自己承受攻击被腰斩殉职）。
  - 原文依据："如果当作打倒它的代价是只有牺牲了左手，说不定还算是便宜。要不是保罗在千钧一发之际救了我，自己很有可能已经丧命。「……谢谢您救了我一命，父亲。」我回头寻找保罗的身影。结果却没有回应……保罗倒在地上。……没有下半身。"
