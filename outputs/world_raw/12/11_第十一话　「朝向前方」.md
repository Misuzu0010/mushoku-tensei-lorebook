# 第十一话　「朝向前方」 世界设定提取

## 一、地理与场所
- 名称：迷宫都市城镇（拉庞）
  - 内容：转移迷宫所在的城镇，拥有其他大陆都无法看到的大量魔力附加品，街道上可供逛街游览；城内设有酒馆与旅社，为前来进行迷宫攻略的冒险者提供休整居所。
  - 原文依据："「呃……因为这城镇里有其他大陆都无法看到的大量魔力附加品，我想就算只是去逛逛那些，或许也很有趣喔。」"、"我想尽快让前辈振作起来，然后跟这个城镇说再见。"
- 名称：贝卡利特大陆 / 中央大陆 / 魔大陆 / 转移迷宫
  - 内容：转移事件后六年间，保罗等人跨越的大陆与探索目标；行动轨迹自中央大陆前往魔大陆，再从魔大陆移动到贝卡利特大陆，最终持续探索转移迷宫。
  - 原文依据："从中央大陆前往魔大陆，再从魔大陆移动到贝卡利特大陆，最后是持续探索转移迷宫。"
- 名称：北方大地
  - 内容：鲁迪乌斯的家人们（妻子希露菲、妹妹诺伦和爱夏等）在此等待他归来。
  - 原文依据："因为必须把这些消息告诉在北方大地等待的家人，所以我感到不安。"
- 名称：布耶纳村 / 阿斯拉王国
  - 内容：阿斯拉王国的乡下村庄。洛琪希当年在阿斯拉王都求职屡次碰壁后，曾前往布耶纳村担任幼年鲁迪乌斯的家庭教师并借住于格雷拉特家。
  - 原文依据："「在布耶纳村的生活真的很幸福。当时的我想在阿斯拉王国工作，结果却屡次碰壁。原本只是把乡下的家庭教师工作当成一种过渡，但是鲁迪你的才能出类拔萃，保罗先生和塞妮丝小姐也以温暖态度对待我。」"

## 三、力量体系 / 魔法 / 技能
- 名称：神级治愈魔术的极限与大脑创伤治疗
  - 规则：一般世间认知认为，如果脑袋被砍断或头部被压烂，就算用上神级治愈魔术也无法治好；因此一旦中了魔物毒导致大脑受损变成废人，世间无药可医；即便身体机能恢复到能行走说话，丧失的记忆也不会复原 [存疑：属于世间常识认知与艾莉娜丽洁以往见闻，神级治愈魔术的绝对上限缺乏严密实证检验]。
  - 原文依据："他们偶尔会听说有人中了魔物毒而变成废人，但是完全没听说过治好的案例。因为一般认为，如果脑袋被砍断或头部被压烂，就算用上神级治愈魔术也无法治好。因此一旦脑袋出了毛病，当然也没有能治疗的办法。「就算恢复到可以走路可以说话，记忆也不会回来。」"
- 名称：魔术师的体魄特征与肉体锻炼
  - 规则：一般魔术师普遍专注于魔术研习而不进行肌肉锻炼，手臂并不强壮；鲁迪乌斯因常年锻炼剑术与体魄，拥有强壮健硕的手臂与胸膛，呈现出“不太像是魔术师”的体格特征。
  - 原文依据："「鲁迪的手臂很强壮呢，不太像是魔术师。」「…………因为我有锻炼。」"

## 四、种族 / 生物
- 名称：长耳族
  - 特征：外貌拥有奢华的金发；寿命极长，艾莉娜丽洁比同为老牌冒险者的塔尔韩德（矿坑族）与基斯（魔族）更为年长，且其孙女（希露菲叶特）已到了成家生育的年龄。
  - 原文依据："拥有一头奢华金发的长耳族女性……艾莉娜丽洁喃喃说道。"、"她比塔尔韩德和基斯更年长，也声称曾经见过类似的案例，想来是知道些什么情报。"、"「鲁迪乌斯的结婚对象是我的孙女。」"
- 名称：矿坑族
  - 特征：男性蓄有浓密胡须；极度嗜酒且酒量极强，狂饮大量最喜爱的酒类也不会轻易出现喝醉的征兆。
  - 原文依据："长着浓密胡须的矿坑族男性……塔尔韩德以若无其事的态度接话。然而，他的声调却显得有气无力。明明已经狂灌一大堆自己最喜欢的酒，却完全没有出现喝醉的徵兆。"
- 名称：魔族（猴貌系）
  - 特征：基斯所属的魔族分支，相貌特征神似猴子。
  - 原文依据："相貌神似猴子的魔族男性……基斯看着手里的杯子，附和她的发言。"
- 名称：米格路迪亚族
  - 特征：魔族的一支，特征为水蓝色头发，体型矮小娇小，外貌看似年幼少女但寿命长达数百年（洛琪希的双亲在数年前依然健在，被认为“大概能再活个一百年”；洛琪希自称虽然身材娇小，但比鲁迪乌斯活了更久）。
  - 原文依据："拥有一头水蓝色头发的魔族少女，至今都保持沉默的洛琪希•米格路迪亚喃喃这样说道。"、"「是啊。最后一次见面已经是几年前了，不过他们看起来很好，大概能再活个一百年。」"、"「我是鲁迪的师傅。尽管我是个矮小又不成熟的师傅，不过毕竟比你活了更久，还是很牢靠的。」"

## 五、物品 / 道具 / 武器
- 名称：魔力附加品
  - 说明：迷宫都市拉庞特产的大量蕴含魔力的特殊器物道具，在其他大陆极为罕见，在城镇中有大量流通展示。
  - 原文依据："「呃……因为这城镇里有其他大陆都无法看到的大量魔力附加品，我想就算只是去逛逛那些，或许也很有趣喔。」"

## 六、历史 / 传说 / 事件
- 事件名：转移事件六周年与搜寻结局
  - 内容：转移事件至今历时整整六年。原黑狼之牙成员与鲁迪乌斯等人历经跋涉，自中央大陆跨越魔大陆、再至贝卡利特大陆攻略转移迷宫。最终以保罗阵亡殉职、塞妮丝虽获救但神志失常变为失去记忆的废人告终，给长年艰苦搜寻的众人带来巨大的精神打击与空虚感。
  - 原文依据："毕竟已经六年了。转移事件后已经过了六年。这段时间绝对算不上短暂，从中央大陆前往魔大陆，再从魔大陆移动到贝卡利特大陆，最后是持续探索转移迷宫。"、"各分东西的队伍成员慢慢重新聚在一起。……原本以为这种情景已经不可能再现，众人却以保罗为中心再次聚集起来。每个人想必都认为，等救出塞妮丝之后，只要再去找到肯定待在某处的基列奴，就可以大伙一起好好喝上一杯。但是，保罗死了。只是这样，就让他们感受到一种难以言喻的空虚，彷佛一切都徒劳而终。"
- 事件名：洛琪希初出茅庐时期的护卫战死事件
  - 内容：洛琪希刚成为冒险者时，曾有一位如大哥般的前辈与其组队并悉心教导其冒险者各项基础规范，后来该前辈为保护洛琪希而战死，洛琪希当时亦陷入极度低潮。
  - 原文依据："「我刚成为冒险者时，有个人立刻和我组队，还教导我关于冒险者的各种基础。虽然我不会说他等同于父母，但是对我来说就像是大哥。」……「这个人因为保护我而死。」……「我当时也很烦恼。」"
- 事件名：洛琪希移居布耶纳村家庭教师往事
  - 内容：洛琪希当年在阿斯拉王都求职屡遭挫折，将前往偏远乡下布耶纳村担任家庭教师视为过渡，却被保罗和塞妮丝以温暖态度接纳，体会到了家庭温情，并视格雷拉特家为自己的第二个家族。
  - 原文依据："「在布耶纳村的生活真的很幸福。当时的我想在阿斯拉王国工作，结果却屡次碰壁。原本只是把乡下的家庭教师工作当成一种过渡，但是鲁迪你的才能出类拔萃，保罗先生和塞妮丝小姐也以温暖态度对待我。或许实际教导我什么叫作家人温情的人是他们两位。对我来说，他们就是第二个家族。」"

## 七、社会规则 / 习俗 / 文化
- 冒险者与佣兵的创伤排解习俗：
  - 内容：在冒险者与佣兵群体中，死亡如影随形。面对战争或从九死一生的凶险委托脱险后，男性为了排解恐惧与精神创伤，普遍有饮酒、前往妓院买春与女人同房的习俗；世俗认为通过肉体欢愉与直观体认活着的喜悦，能稍微排解心理痛苦并重新振作。
  - 原文依据："「因为所谓的男人都很现实。去喝个酒，跟女人上床，让心情变舒畅了，直接体认到活着的喜悦后，就可以稍微打起精神。」"、"男人在陷入低潮时会去找女人。洛琪希觉得自己以前也曾在哪里听过这件事。尤其是那些佣兵，据说在战争前后都会为了转移恐惧心而去买春。冒险者也一样，完成像是去鬼门关前走一遭的委托后，有不少人会前往妓院。"
- 成年与成家年龄观念：
  - 内容：在该世界的世俗观念中，十六岁已经不再是年幼小童，在精神和肉体上已被视作应当能跨越父母离世难关、成家立业生儿育女的“出色大人”。
  - 原文依据："「嗯，结婚了，孩子也快出生了。」「是……是吗……也对，鲁迪也到这年纪了……」"、"话虽如此，他也已经十六岁了，不是年幼小孩。即使经历过艰辛遭遇，内心精神应该也已经是出色的大人。更何况死亡会平等降临到每个人身上，对于冒险者来说更是家常便饭。父母总有一天会离去，无论是谁都必须跨过这个难关。"
- 艾莉娜丽洁的男女相处底线：
  - 内容：艾莉娜丽洁虽然性生活放荡且常与不特定多数男性往来，但严守底线绝不对孙女（希露菲叶特）的伴侣出手；且在与克里夫建立感情后，因不想背叛克里夫而不再轻易与其他男性发生肉体关系。
  - 原文依据："「就算是我，也有无法出手的对象。」"、"「鲁迪乌斯的结婚对象是我的孙女。」"、"艾莉娜丽洁的内心情绪也很复杂。她不想打扰希露菲的婚姻。……然而一旦有不想背叛克里夫的心情介入，艾莉娜丽洁就再也无法那样做。"

## 九、角色认知 vs 客观事实
- 角色以为：塔尔韩德推测塞妮丝虽然变成了废人，但既然保住了性命，说不定还有机会治好。
  - 原文是否暗示另有真相：否（塔尔韩德自己心里也不相信这一推测；世间医学与魔术常识表明，中魔物毒致脑部受损从无治愈案例，即使神级治愈魔术也对头部毁灭性伤势无能为力，失忆亦无法挽回）。
  - 原文依据："「但是她还活着，说不定有机会治好。」塔尔韩德讲出连自己心里也不相信的推测。他们偶尔会听说有人中了魔物毒而变成废人，但是完全没听说过治好的案例。……「就算恢复到可以走路可以说话，记忆也不会回来。」"
- 角色以为：洛琪希以为鲁迪乌斯至今仍是单身，因此在迷宫脱险后主动向他展开积极追求攻势。
  - 原文是否暗示另有真相：是（鲁迪乌斯在北方早已与艾莉娜丽洁的孙女希露菲叶特结婚，且妻子已有身孕即将临盆）。
  - 原文依据："「鲁迪乌斯的结婚对象是我的孙女。」「……咦！」「咦……鲁迪他结婚了吗？」「嗯，结婚了，孩子也快出生了。」……她以为鲁迪还是单身，因此展开攻势。"
- 角色以为：洛琪希为了劝诱鲁迪乌斯通过肉体接触走出悲伤，自称“经验丰富，比起一般的小丫头，我想自己可以做得更好”。
  - 原文是否暗示另有真相：是（洛琪希在撒谎掩饰羞涩与笨拙，鲁迪乌斯与其同房时立刻发觉所谓的经验丰富完全是弥天大谎，她是初次经历且强忍疼痛接纳）。
  - 原文依据："「别……别看我这个样子，其实经验丰富，比起一般的小丫头，我想自己可以做得更好。所以你可以放松心情……」"、"自己对洛琪希的行为非常粗暴。虽然我立刻发觉所谓的经验丰富是弥天大谎，仍旧没把这件事放在心上。然而她却忍着疼痛接纳一切，没有表示任何拒绝。"
- 角色以为：同行伙伴们（塔尔韩德、基斯等）认为鲁迪乌斯闭门不出、日渐憔悴是因为失去父亲与母亲成废人的悲伤，或者是十六岁的年轻人尚未成熟，迟早能自行跨越丧亲难关振作起来；洛琪希也以为他与自己当年失去如大哥般的同伴境遇相同。
  - 原文是否暗示另有真相：是（鲁迪乌斯崩溃的根本原因并非单纯丧亲，而是转生者的隐秘心结与极度自我厌恶：他活了前世三十四年加现世十六年共五十年，却惊觉自己在面对父母离世时与前世一样逃避责任、原地踏步、毫无改变，因而陷入了绝望的自我怀疑与道德崩溃）。
  - 原文依据："「因为鲁迪和保罗先生的感情很好。」"、"「别紧张，鲁迪乌斯是保罗和塞妮丝的儿子。就算现在陷入低潮，迟早也会靠自己振作起来吧。」"、"讲来讲去，结果还是不明白啊。洛琪希不可能理解经过转生，夹在前世的自己和现在的状况之间，感到左右为难的我到底是什么心情。我不只是为了保罗的死而伤心。也不只是为了塞妮丝成了废人而悔恨。……我一直不肯去面对自己和前世家人之间的纷争与不和。就是因为一直逃避，所以结果……我在这个世界，在第二次的人生也还是重蹈覆辙。……前世总共三十四年，这一世至今十六年。明明加起来已经活了五十年，结果却还是……然而，我却被迫面对其实自身将近完全没有改变的现实。"
- 角色以为：洛琪希以为鲁迪乌斯清晨向她讲述的是一个凭空想像出来的虚构男子寓言故事。
  - 原文是否暗示另有真相：是（该故事是鲁迪乌斯前世三十四年蛰居啃老、逃避父母葬礼、被殴打赶出家门后转生到这个新世界的真实前世经历）。
  - 原文依据："「这些话只是想像出来的故事。」我先以这句话作为前提，然后开始叙述某个男子的故事，一个虚构的故事。这个男子在年轻时曾经碰过痛苦的遭遇，因此决定隐遁。之后将近二十年，他都过着只会啃老的废物生活。然而某一天，他的双亲突然死去……男子在此失去一切，却运气很好地来到新天地……我想她不至于会相信这些故事就直接等于我的人生。毕竟她很聪明，说不定会认为这故事另有什么深层含意。"
