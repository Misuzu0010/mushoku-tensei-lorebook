# 第三话　「进入迷宫」 世界设定提取

## 一、地理与场所
- 名称：转移迷宫（实际探索地理环境与细节）
- 内容：
  - 入口与外观：位于山壁上的洞窟，外表看似普通，周围有蜘蛛型魔物与密集的蛛网，距离拉庞约一天路程（轻装半天可达）。洞口透出阴森、能让人直觉辨认是迷宫的气场。内部光线微暗，必须依靠照明用具。
  - 第一层内部：为类似蚂蚁巢的弯曲洞穴通路，墙壁与天花板满布白色蛛丝，地上爬满朱凶蜘蛛捕食的小蜘蛛与未长大的幼蛛。蜘蛛群中突然出现的空隙处（圆形或四边形空白）即是隐藏的转移魔法阵（有些不发光）。通路每走约1小时会出现一个魔法阵，重复5次到达终点房间。终点房间布满蜘蛛巢，深处并排两个更大型、深蓝色的魔法阵，其中一个是通往第二层的正确魔法阵（基斯此前留有刻着圆圈记号的石头标记）。
  - 第二层内部：地面小蜘蛛消失，蛛巢大减并显露土壤。出现高1公尺、长2公尺、重达一吨的钢铁爬虫，并与朱凶蜘蛛联合作战。突破第二层约耗时10小时到达第三层。
  - 第三层入口带：小蜘蛛完全绝迹，墙上仅偶尔有蛛丝，没有生物动静，从昏暗洞窟深处散发出毛骨悚然的气息。
- 原文依据："转移迷宫。乍看之下，那只是一个洞窟。外观没什么特别。虽然周围有很多蜘蛛型魔物，墙上还密密麻麻地爬满蜘蛛网……洞口透出一股阴森的氛围……能让人直觉理解「那里就是迷宫」的氛围。……距离拉庞只要一天路程，甚至半天就能赶到……第一层，我们在蚂蚁窝般的洞穴中前进。墙壁和天花板上布满了大量的白色蜘蛛丝，深处可以看到蓝白色的转移魔法阵发出光芒。……在这样的蜘蛛群中，会突然出现空白处，一些圆形或四边形的空间。那种地方就是转移陷阱。……大概要花上一个小时，才能到达一个魔法阵。这段过程重复了五次，换算成时间大约是五个小时吧。第一层的终点是一个布满蜘蛛巢的房间，深处并排着两个魔法阵。看起来比至今为止的魔法阵更大一些，蓝色也更深一点。……目前在其中一个魔法阵的前方，放着一颗刻有圆圈记号的石头。据说这是基斯以前留下的标记，显示出正确的魔法阵。……从第二层开始，地上的小蜘蛛消失，蜘蛛巢也大幅减少，地面的土壤终于显露在外。……就这样，我们到达第三层。计算时间，大概是进入迷宫后过了十小时吧。"

## 二、组织与势力
- 名称：保罗迷宫小队探索阵型与行进规范
- 内容：
  - 斥候走在队伍最前方约十步探路（基斯穿十字铁靴留下印记，负责识别不发光的隐形转移魔法阵）；
  - 前卫由坦（艾莉娜丽洁）走在最前，副攻击手（保罗）紧随；
  - 后卫由主攻击手兼补师（鲁迪乌斯）负责施法歼灭，副坦兼机动人员（塔尔韩德）在后卫身旁近身警戒护卫。
  - 休息规程：前卫必须立刻解下铠甲擦除魔物体液进行保养，预备人员轮流站岗把风，后卫与斥候就地图路线进行研讨修正。
- 原文依据："先行探路的基斯离我们大约十步。他穿着特殊的靴子……会在踩过的地方留下十字痕迹。……艾莉娜丽洁的位置是坦……走在最前面的人应该是我吧……保罗才刚坐下，立刻脱掉铠甲和配剑带，动手擦拭表面的魔物体液。他是要利用短暂的休息期间，迅速保养好装备。根据那熟练的手法，可以看出保罗确实是这一行的专家。……基斯一边闲聊，同时从行李中拿出书和地图。地图总共有两张，其中一张描绘得很仔细，另外一张只制作到一半。"

## 三、力量体系 / 魔法 / 技能
- 名称：洞窟/迷宫内魔术使用三大禁忌
- 规则：
  1. 绝对严禁用火：在密闭洞穴或深层房间中用火会迅速耗尽氧气并产生毒气（一氧化碳中毒），且无法用解毒魔术治愈。
  2. 禁止攻击天花板：直接冲击天花板会破坏洞体结构导致坍塌被活埋。
  3. 慎用水与土魔术：大量用水会使地基松动，土魔术若不慎挪用洞内原生土壤会掏空支撑柱引发坍方；推荐优先采用冰系魔术。
- 原文依据："「你听好了，不可以使用火魔术。」「为什么？」「一旦用火，房间里会充满毒气。尤其是阶层变深后更是要特别注意。」「……无法用解毒治好吗？」「不行。」……「还有，也禁止攻击天花板。理由你应该懂吧？」「因为有可能会导致洞窟坍塌。」「没错。所以最好也不要用太多水，尽量用冰攻击。」「知道了。」如果使用大量的水，会造成地盘松动。……土魔术有可能会在不知不觉之间动用到洞窟里的土。万一掏空了洞窟内的支柱，说不定会引起坍方。所以还是用冰吧"

- 名称：冰枪暴风雪（上级水魔术）
- 规则：降下大量尖锐冰枪的范围攻击魔术。可用于从远方依次歼灭密集敌人而不破坏洞穴土石构造。洛琪希亦擅长此术。
- 原文依据："我决定使用上级水魔术「冰枪暴风雪」，这是能降下大量冰枪的魔术。为了避免波及到保罗他们，我从最深处的敌人开始依序歼灭。……「喔喔，不愧是洛琪希的弟子，连使用的魔术都相同……」"

- 名称：多重魔术并行发动（双重咏唱/施法）
- 规则：鲁迪乌斯能够同时并发两种不同属性的魔术（一手维持「冰枪暴风雪」压制后卫蜘蛛，一手释放「岩炮弹」射杀近战毛虫）。
- 原文依据："我可以同时使出两种魔术，一边用「冰枪暴风雪」招呼后卫的朱凶蜘蛛，一边用岩炮弹把保罗和艾莉娜丽洁负责吸引住的钢铁爬虫一只只解决。"

- 名称：转移迷宫规则与传送特性
- 规则：
  - 转移陷阱仅在“同阶层内”转移，不会跨阶层把人直接送到最底层Boss面前。
  - 转移迷宫通路被传送阵割裂，无法使用常规迷宫探索的「右手法则」探遍全图。
  - 迷宫中偶见完全不发光的转移魔法阵隐蔽于地面，极难防范。
- 原文依据："「我记得偶尔也会出现没发光的魔法阵，必须特别留意，对吧？」……按照书上所写，转移陷阱似乎设定好只会转移到同一层。就算是随机转移，也不会发生踩下去就直接被传送到最下层头目面前的状况。……因为在这个迷宫里，没办法靠右手法则来把整个迷宫走遍。"

## 四、种族 / 生物
- 名称：朱凶蜘蛛与钢铁爬虫（联合作战生态）
- 特征：
  - 钢铁爬虫：体高约1公尺、长约2公尺，重达约1吨。外壳极其坚固，能弹开普通岩炮弹并抵挡精钢剑斩击；虽为毛虫身形但敏捷度与蜈蚣相似。非致命伤时会在地上疯狂翻滚挣扎。
  - 朱凶蜘蛛：会喷射极具粘性的蜘蛛丝进行远程牵制。
  - 战术协同：钢铁爬虫在前充当肉盾吸收伤害，朱凶蜘蛛在后吐丝缠绕封锁冒险者行动；一旦冒险者被蛛丝困住，即遭钢铁爬虫撞击蹂躏。
- 原文依据："这种高一公尺，长两公尺的钢铁爬虫给人一种粗短壮硕的印象。……这种魔物的坚固顽强正如外表，动作却是敏捷到不符外表。这速度与其说是毛虫，反而更容易让人联想到蜈蚣。再加上钢铁爬虫和朱凶蜘蛛似乎是同伙，会由钢铁爬虫挡在前方，朱凶蜘蛛躲在后面用有黏性的蜘蛛丝攻击。一旦被蜘蛛丝缠住，就会惨遭体重恐怕重达一吨的钢铁爬虫蹂躏。钢铁爬虫很坚硬，就算是保罗也无法一击将其打倒。……听说钢铁爬虫的硬度似乎能弹开普通的岩炮弹"

- 名称：灯之精灵（召唤精灵）
- 特征：通过卷轴召唤而出的悬浮光球，发出日光灯般明亮柔和的光芒，魔力消耗微乎其微，魔力充沛者可维持极长时间。
- 原文依据："于是一颗光球往上飞，在我们的头上盘旋。……精灵的光线比火把还亮，即使魔力不高也可以维持很久。只要这东西普及开来，说不定火把会从市场上消失。"

## 五、物品 / 道具 / 武器
- 名称：精灵卷轴（七星制）
- 说明：七星制作的光源召唤卷轴，撕开注入微量魔力即可召唤灯之精灵，使探险者双手解放无需手持火把，发光亮度与时效远胜传统火把。
- 原文依据："进入洞窟以后，我立刻使用从七星那里拿到的精灵卷轴。于是一颗光球往上飞，在我们的头上盘旋。……基斯和保罗也可以使用这个卷轴。……发动时必须消耗的魔力似乎微不足道。发现这下可以不必拿着火把的两人都很高兴"

- 名称：十字铁底靴
- 说明：鞋底焊接/粘贴十字架形状铁板的特殊靴子，非魔法道具，属于冒险者经验发明的防滑工具，在走过之处会留下清晰的十字脚印，便于后方队员精准踩着脚印避开未知转移陷阱。
- 原文依据："先行探路的基斯离我们大约十步。他穿着特殊的靴子，底部黏着十字架形状的铁板，会在踩过的地方留下十字痕迹。当然，那不是魔力附加品。大概是冒险者的智慧结晶吧，是一种可以防滑，还可以留下清楚足迹的方便道具。"

- 名称：贝卡利特大陆特殊蜘蛛丝溶解液
- 说明：贝卡利特大陆流传的特制药剂，加水稀释使用，能在不伤人体的前提下迅速溶解具有黏性的蜘蛛丝，艾莉娜丽洁反映会使皮肤粗糙；去污清洁力极强，亦可用于彻底擦除金属铠甲上附着的魔物体液污垢。
- 原文依据："基斯带着能溶解蜘蛛丝的液体，他们拿来以水稀释后使用。据说这是在贝卡利特大陆流传的特殊药品，对人体无害。……保罗还是沾了药水，用力擦了几下。……真的擦掉了，谢啦。"

- 名称：保罗的随身双剑
- 说明：右手为常年随身携带的锋利爱剑；左手为特制短剑（介于长剑与短刀之间，双面开锋，剑身微曲，带护手，剑身正中有孔隙，用途推测为防切斩肉块粘连）。
- 原文依据："保罗拿着两把剑……其中之一是保罗在家也几乎随身不离的剑……至于左手那把剑是我没见过的造型，大概类似所谓的短剑。长度不像短刀那么短，也没有长剑那么长。双面开锋，剑身稍微弯曲，还附有可罩住手部的护手。至于剑刃正中央的洞，可能是为了防止砍断的东西黏在剑上。"

## 六、历史 / 传说 / 事件
- 事件名：艾莉娜丽洁长耳族身世与血缘关系揭晓
- 内容：艾莉娜丽洁当面向保罗说明其与罗尔兹是母子关系，希露菲为其孙女，因此鲁迪乌斯是其孙女婿，保罗和塞妮丝在辈分上相当于其孩子。保罗此前对此一无所知并大受打击。
- 原文依据："「希露菲是我的孙女。鲁迪乌斯既然和我的孙女结婚，等于是成了我的孙子。这样一来，身为他双亲的保罗和塞妮丝……你们两人也相当于我的孩子。」……「听说罗尔兹先生是艾莉娜丽洁小姐的儿子。」「你说罗尔兹？那家伙从来没提过这种事情啊。」"

## 七、社会规则 / 习俗 / 文化
- 内容：迷宫近郊支援规则：若迷宫距城镇仅半天至一天路程，支援留守人员通常返回城镇待命，无需在迷宫外荒野扎营。
- 原文依据："莉莉雅和维拉、雪拉会骑马返回城镇。大型冒险者集团在挑战迷宫时，有时候会安排支援人员在迷宫入口搭营，不过幸好这里距离拉庞只要一天路程，甚至半天就能赶到，因此没有必要特地在洞窟外面等候。"
- 内容：迷宫战后装备维保习惯：专业近战战士在脱离战斗后必须立即卸甲保养、擦净带有腐蚀性或粘连性的魔物体液。
- 原文依据："保罗才刚坐下，立刻脱掉铠甲和配剑带，动手擦拭表面的魔物体液。他是要利用短暂的休息期间，迅速保养好装备。根据那熟练的手法，可以看出保罗确实是这一行的专家。"

## 九、角色认知 vs 客观事实

- 原文是否暗示另有真相：不明（本章末尾仅为主角主观笃定感觉，究竟是真实线索还是心理作用未在本章证实）。
- 原文依据："我觉得自己好像闻到怀念的洛琪希香味。不，这不是我的错觉。确实是洛琪希的香味，洛琪希的气息。我不可能会弄错，可以感觉到胸中一阵骚动。她在这里。我确定洛琪希就在这里。"
