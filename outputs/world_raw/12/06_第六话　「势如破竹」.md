# 第六话　「势如破竹」 世界设定提取

## 一、地理与场所
- 名称：转移迷宫（第三层至第六层环境与特性）
  - 内容：
    1. 第三层：分布有朱凶蜘蛛、钢铁爬虫与指挥官型魔物疯狂髑髅；迷宫手记作者当年耗费五天突破，主角队伍约两天探索完毕并绘制地图。
    2. 第四层：踏入传送阵后环境突变，四周呈现类似转移魔法阵遗迹风格的石质墙面；魔物以装甲战士与疯狂髑髅为主；从本层步行撤退回地面约耗时十五小时。
    3. 第五层：魔物新增能够攀附在天花板与墙壁的暴食恶魔，会打破常规地面战线；冒险者在向上警戒时极易踩中地面转移陷阱。
    4. 第六层：主角队伍全员状态良好、直达第六层并展开连续攻略。
  - 原文依据："首先按照预定，一口气前进到第三层。第三层的敌人共有三种。除了朱凶蜘蛛和钢铁爬虫，还多了疯狂髑髅。"、"那本书的作者当初花了五天才突破第三层。但是我们进展的速度比他们快，而且已经来过第三层好几次了，地图也逐步完成。"、"一踏入通往第四层的魔法阵，周围的环境就整个变了样。眼前出现熟悉的石墙，和转移魔法阵的遗迹看起来很像。搞不好这里果然是同系统的遗迹变化而成的迷宫。"、"回程是步行，大约花了十五小时，果然还是很花时间。"、"从第五层开始，除了疯狂髑髅和装甲战士，还会出现暴食恶魔。"、"然而，必须时时看着上方会造成问题。因为注意力被上方吸走，就代表容易疏忽掉地面上的陷阱。如此一来，有可能会不小心踩到转移陷阱，被送往奇怪的地方。"、"最后，我们到达第六层。"
- 名称：迷宫都市拉庞
  - 内容：贝卡利特大陆的迷宫城市，物资丰富；市场上能稳定购得绘制魔法阵所需的染料与羊皮纸、针对重装魔物的特化减速药剂，以及各种稀有的魔力附加品武器。
  - 原文依据："拉庞不愧是迷宫都市，魔法阵用的染料和羊皮纸都能取得，也顺利制作完成。"、"基斯跑去购买对铠甲型魔物有效的药品。据说丢中对方后，就会缠住关节部分让敌人行动变慢。"、"至于保罗左手的短剑，听说是在拉庞买到的魔力附加品……"
- 名称：布耶纳村
  - 内容：鲁迪乌斯幼年成长的阿斯拉王国乡村，鲁迪乌斯曾在该地阅读过英雄传记《佩尔基乌斯的传说》。
  - 原文依据："不过我还记得在布耶纳村读过的《佩尔基乌斯的传说》一书中有个战士的武器也具备同样能力。"

## 二、组织与势力
- 名称：米里斯教团
  - 内容：教团内有抄写/绘制魔法卷轴的专门工作，雪拉过去曾在此类岗位打工，因而熟练掌握批量制作魔法卷轴的技能。
  - 原文依据："听说她在米里斯教团打工时有负责过绘制卷轴，所以很擅长这方面。而且还保证今天之内可以完成五十张，实在可靠。"

## 三、力量体系 / 魔法 / 技能
- 名称：水神流剑术
  - 规则：以顺势化解敌人攻势与趁隙还击为主体的防御反击型剑术流派；该流派的防御与反击技巧对魔法攻击同样有效，高明者可针对敌方攻击魔术释放剑气予以化解并反制。
  - 原文依据："「听说装甲战士会使用水神流的剑术，贸然使用魔术的话会遭到反击。」水神流……我很少碰到这个流派的人，那是一种以顺势化解与趁隙还击为主体的剑术。而且不知道为什么，这些技术对魔术居然也有效。尽管我不清楚到底是如何办到，但是据说针对攻击魔术，有可以发出剑气作为反击的剑技。"
- 名称：剑神流剑术
  - 规则：以极致速度与惊人杀伤力著称的攻击型剑术流派；精通者即使使用副手武器亦能轻松劈断坚固的魔物铠甲。
  - 原文依据："他用右手的剑化解装甲战士的斩击，再举起左手的短剑迅速砍掉对方的一只手臂。明明铠甲看起来很硬，对他却似乎不成问题。剑神流的剑士真的都是些怪物……"
- 名称：保罗的剑术等级
  - 规则：保罗在三大剑术流派上均已取得“上级”认证，综合实战能力被鲁迪乌斯评估为具备相当于圣级剑士的水准。
  - 原文依据："三大剑术都习得上级的经历果然不是浪得虚名。若以才能来看，保罗应该具备可以到达圣级的水准吧。不，说不定保罗实际上已经拥有相当于圣级的实力。毕竟光凭分级，很难测出一个人真正的强弱。"
- 名称：缩短咏唱与广域精准操控
  - 规则：洛琪希擅长通过缩减咒文咏唱释放大范围魔术（如「水蒸」、「冰结领域」、「冰霜刃」），并能在混战中精准控制作用目标与范围，完全不误伤前卫队友。
  - 原文依据："明明她不断以缩短的咏唱来使出广范围的魔术，却从未误击到队友。「水蒸」的水滴有时也会喷到保罗他们身上，然而之后的「冰结领域」却只会冻住敌方，可以说是精准得惊人。"、"「以英武的冰之剑制裁目标吧！『冰霜刃』！」"
- 名称：泥沼（迷宫使用限制）
  - 规则：土系统初级妨碍魔术，可将地面液化使敌人深陷；但在迷宫地下深层若深度过大可能破坏地基造成地质坍塌，通常需将深度控制在及膝左右。
  - 原文依据："「『泥沼』！」我趁着装甲战士即将往前跨步时，在地面制造出泥沼。两只魔物都迅速下沉，直到大腿以下都陷入泥中才停止。"、"话虽如此，如果制造出太深的泥沼，有可能会贯穿地盘。虽说应该不会那么容易就导致崩塌，不过会造成地形变化的魔术还是该适可而止，我想深度及膝就差不多了。"
- 名称：不死系魔物的克制机制
  - 规则：铠甲型不死系魔物具备高物理抗性与对常规魔术的反制力，但极度弱神圣属性打击（神击）与厚重土石物理冲击（岩石攻击/大型岩炮弹）。
  - 原文依据："基本上，这类铠甲型魔物似乎算是不死系。对不死系魔物有效的魔术是神击和岩石攻击。只要赏对方一颗分量足够的大型岩炮弹，通常一击就可以把它们打成碎片。"
- 名称：上级治愈魔术
  - 规则：高阶医疗神圣魔术，只要伤者尚未当场断气死亡，即可修复严重创伤脱离致命险境。
  - 原文依据："只要不是当场死亡，我就可以使用上级治愈魔术进行治疗，希望他至少要避免要害被打中。"

## 四、种族 / 生物
- 名称：疯狂髑髅
  - 特征：A级指挥官型不死系/魔像型魔物。外表为无头泥巨人，高达2.5公尺且身形极其厚实；胸口镶嵌有人类头骨作为唯一致命弱点，遭遇危险时会将头骨缩入泥浆躯体内；身体遭物理打击毫无损伤；攻击方式为挥动泥拳与发射类似岩炮弹的土系魔术；弱点是怕水（水流过度冲刷会导致泥浆流失）与怕火（高温烘干泥浆使其丧失行动能力）；具备高度智慧，会役使低智商魔物，以钢铁爬虫为前锋、朱凶蜘蛛为中卫、自己殿后形成战术阵型。
  - 原文依据："疯狂髑髅是A级的魔物。外表是没有头的泥巨人，高度差不多有二点五公尺，宽度也很惊人，显得厚实顽强。胸口埋着一颗头骨，那里就是弱点。"、"行动缓慢，但是泥巴部分无论遭到多少攻击也不受影响。陷入危险状态时，会把胸口的头骨藏进体内。攻击手段是用泥制的身体殴打敌人，还会使出类似岩炮弹的魔术。"、"而是因为这家伙居然能够率领智力较低的魔物──把朱凶蜘蛛和钢铁爬虫当成奴仆使唤。虽然外表近似魔像，疯狂髑髅却具备了高度的智能，会组成以钢铁爬虫为前卫，朱凶蜘蛛为中卫，自己是后卫的的队形袭击敌人，是指挥官型的魔物。"、"疯狂髑髅很怕水，因为身体由泥巴组成，含水量太高会造成泥巴流失。或者用火也行，只要让泥巴乾掉，那家伙就无法行动。"
- 名称：装甲战士
  - 特征：A级铠甲型不死魔物。生有四条手臂并持有四把长剑；身披沉重铠甲，行动缓慢，但力量极大；掌握精湛的水神流剑术，能借由反击剑技化解并反制远程攻击魔法；极度畏惧神击与钝重巨型岩炮弹轰击，且沉重体型极易陷入泥沼中。
  - 原文依据："只见两具长了四只手的铠甲魔物正在逐步靠近。是装甲战士。基本上，这类铠甲型魔物似乎算是不死系。对不死系魔物有效的魔术是神击和岩石攻击。"、"「听说装甲战士会使用水神流的剑术，贸然使用魔术的话会遭到反击。」"、"铠甲型魔物力量大，剑术也很高明，但是行动迟缓。此外，因为铠甲沉重，很容易陷入泥巴里。"
- 名称：暴食恶魔
  - 特征：A级恶魔类魔物。长手长脚、拥有极度巨大的口部与尖锐利齿，四肢带有坚硬爪子，能在迷宫天花板和垂直墙面上自如攀爬移动，能够越过地面防线直接突袭后排；速度敏捷、攻击凶残，但自身防御力脆弱且不耐打击，受击易从天花板坠落；生理上极度厌恶塔尔弗洛树根燃烧散发的特殊气味熏香，吸入后会丧失凶性并紧贴地面抱头逃窜，危险度锐减至C级。
  - 原文依据："从第五层开始，除了疯狂髑髅和装甲战士，还会出现暴食恶魔。暴食恶魔是一种拥有巨大嘴巴和尖锐牙齿的恶魔，而且长手长脚，还有能攀在天花板上的锐利爪子。"、"暴食恶魔是强敌，毕竟它们能够沿着天花板和墙壁移动。换句话说，我们组成的队形无法发挥效果。"、"速度快，攻击力好像也很高，但是防御力低，而且算不上耐打。第一次遭遇时让我们有点吓到，不过这家伙只要遭到攻击就会从天花板上掉下来……"、"那些家伙非常讨厌某种味道。只要把被当成食物贩卖的塔尔弗洛树的树根点起来作为薰香，暴食恶魔就会离开天花板来到地上。而且还会贴着地面趴下，摆出尽可能逃离烟雾的姿势。因此，会变得非常容易对付。在这种状况下的暴食恶魔别说B级，降等为C级都没问题。"
- 名称：钢铁爬虫
  - 特征：外壳极其坚硬的魔物，常被疯狂髑髅驱动作为冲锋破阵的肉盾前卫。
  - 原文依据："第二层会碰到的敌方战术是钢铁爬虫往前冲锋，朱凶蜘蛛吐出蜘蛛丝来缠住敌人……"、"而且不只装甲战士，其实钢铁爬虫之类的坚硬对手也会让她有点陷入苦战……"
- 名称：朱凶蜘蛛
  - 特征：能喷射高粘度蜘蛛丝束缚猎物的魔物，常在疯狂髑髅指挥下担任中卫牵制目标。
  - 原文依据："朱凶蜘蛛吐出蜘蛛丝来缠住敌人，到了这里会再加上疯狂髑髅的指挥和魔术攻击。"

## 五、物品 / 道具 / 武器
- 名称：灯之精灵的卷轴
  - 说明：使用魔法染料与羊皮纸制作的照明魔法卷轴，撕开或激发后提供稳定光源。
  - 原文依据："灯之精灵的卷轴也有点不够用了，我决定事先补满。拉庞不愧是迷宫都市，魔法阵用的染料和羊皮纸都能取得，也顺利制作完成。"
- 名称：关节拘束药剂
  - 说明：迷宫都市拉庞出售的针对重铠魔物的特化炼金药剂，投掷破裂后会粘附并阻塞关节缝隙，使其机动力急剧受限。
  - 原文依据："基斯跑去购买对铠甲型魔物有效的药品。据说丢中对方后，就会缠住关节部分让敌人行动变慢。"
- 名称：保罗的破甲短剑（魔力附加品/魔剑）
  - 说明：保罗在拉庞购得的稀有魔力附加武器，附加有「破甲」特性——斩击对象的材质越坚硬，剑刃发挥的锋利度就越高；能轻易将钢铁一分为二，却连普通的柔软肉干都无法切断。曾因判定困难被商铺当成连肉干都切不开的次品抛售。
  - 原文依据："至于保罗左手的短剑，听说是在拉庞买到的魔力附加品，具备对手越坚硬剑刃就越锋利的「破甲」能力。这能力相当稀有，却因为过于稀有，市场无法判别出这种能力，结果被当成连肉乾都切不断的废铁低价抛售。"、"那是一把连肉乾都切不断，却能够把钢铁切成两半的魔剑。"
- 名称：艾莉娜丽洁的真空波刺剑（魔力附加品）
  - 说明：艾莉娜丽洁的配剑，刺击时能从剑尖激发真空波远攻，但对高韧性硬甲魔物的杀伤力较为匮乏。
  - 原文依据："她目前使用的刺剑是魔力附加品，能力是可以从剑尖放出真空波，然而要拿来对付装甲战士却有点不便。"
- 名称：艾莉娜丽洁的冲击波斗士短剑（魔力附加品）
  - 说明：在拉庞以数枚高纯度魔力结晶购买的高级魔力武器，刺击时伴随猛烈冲击波，主要用于击退强敌拉开防御安全距离。
  - 原文依据："最后，艾莉娜丽洁买了一把斗士短剑，据说附加了突刺时会产生冲击波的能力。伤害力虽然不高，但是紧急时可以把对手打飞，拉开彼此距离。由于这能力很实用，价格也相当昂贵。艾莉娜丽洁从怀里取出几个圆形的魔力结晶，顺利买下了那把剑。"
- 名称：魔力结晶
  - 说明：蕴含浓郁魔力的圆形结晶，在高端冒险者贸易中充当硬通货，单枚具备极高购买力。
  - 原文依据："艾莉娜丽洁从怀里取出几个圆形的魔力结晶，顺利买下了那把剑。她到底有多少个那种魔力结晶啊？"
- 名称：塔尔弗洛树的树根
  - 说明：原本作为普通食材出售的植物根部，点燃所产生的气味是暴食恶魔的天生厌恶源，点燃熏烤可直接压制其滞空优势。
  - 原文依据："只要把被当成食物贩卖的塔尔弗洛树的树根点起来作为薰香，暴食恶魔就会离开天花板来到地上。而且还会贴着地面趴下，摆出尽可能逃离烟雾的姿势。"
- 名称：《转移迷宫探索记》
  - 说明：前人攻略转移迷宫留下的详尽实战手记，记录了各层生态与克制敌方特殊弱点的绝妙秘策。
  - 原文依据："针对暴食恶魔，《转移迷宫探索记》里记载了划时代的对应法。"
- 名称：《佩尔基乌斯的传说》
  - 说明：阿斯拉王国流传的古典英雄传记书籍，记载了古代战士及其所持破甲魔剑的典故。
  - 原文依据："不过我还记得在布耶纳村读过的《佩尔基乌斯的传说》一书中有个战士的武器也具备同样能力。那是一把连肉乾都切不断，却能够把钢铁切成两半的魔剑。"

## 六、历史 / 传说 / 事件
- 事件名：《佩尔基乌斯的传说》记载的魔剑典故
  - 内容：英雄传说中记载过一种特殊的古代魔剑，无法切断肉干却能斩裂钢铁，保罗根据此传说在拉庞低价淘到了具备相同破甲效果的短剑。

## 九、角色认知 vs 客观事实
- 角色以为：保罗声称自己是依靠敏锐独特的“冒险者慧眼”从市场废铁堆中淘出了附带「破甲」属性的极品魔剑。
  - 原文是否暗示另有真相：是（鲁迪乌斯推测保罗很可能是读过《佩尔基乌斯的传说》，从店主抱怨“连肉干都切不开”这一典故特征中识破了魔剑的真正价值）。
  - 原文依据："保罗声称他是凭自己的慧眼看出这把剑的能力，不过我还记得在布耶纳村读过的《佩尔基乌斯的传说》一书中有个战士的武器也具备同样能力。那是一把连肉乾都切不断，却能够把钢铁切成两半的魔剑。我想保罗肯定是从「连肉乾都切不断」这点来察觉出其中奥妙。"
- 角色以为：保罗在被鲁迪乌斯夸奖剑技变强时表情冷峻严肃，表示自己完全没变强甚至更弱。
  - 原文是否暗示另有真相：是（保罗只是在儿子面前强行装深沉，艾莉娜丽洁立刻观察到并揭穿他背过身去暗自窃喜、嘴角笑裂失控的真实状态）。
  - 原文依据："「嗯？不，没那种事，甚至比以前还弱。」可是，保罗却连笑都不笑一下……「保罗这家伙笑得整张脸都垮了，好恶心。」「你管我啊，何必把这种事情讲出来。」「你是因为被鲁迪乌斯称赞所以心中暗喜吧。我懂我懂，嘻嘻嘻。」"
- 角色以为：洛琪希在消耗战后自嘲自身魔力总量太少、容易枯竭。
  - 原文是否暗示另有真相：是（鲁迪乌斯观察到洛琪希一直是以缩短咏唱连续施放广域控场与杀伤魔术，本身消耗就极大，而且能够持续高烈度战斗数天，其真实魔力储量实际上相当充沛，不在希露菲之下）。
