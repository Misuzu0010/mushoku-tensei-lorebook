# 第五话　「不屈的魔术师」 世界设定提取

## 一、地理与场所
- 名称：转移迷宫（层级与构造特性）
  - 内容：
    1. 第二层：魔物威胁较高，若缺少强力魔术师的战力，队伍基本上难以通过。
    2. 第三层：敌人数量众多；布满各种转移陷阱，战斗时必须分神闪避；若在其中以魔术强行破墙开路，有引发大面积崩塌的严重风险。
    3. 第四层：据笔记记载其风格与前几层截然不同，类似人工建造的遗迹。
    4. 迷宫融合现象：历史悠久的迷宫有时会与其他迷宫或遗迹（如转移遗迹）融合，形成风格突变、可能拥有两个魔力结晶的复合迷宫。转移迷宫符合该外在特征，但据笔记记载其魔力结晶只有一个。
  - 原文依据："虽然我提议务必由我来负责搬运洛琪希的玉体，不过一旦少了我的战力，基本上我们根本无法通过第二层。"、"「我想应该没有必要，但是第三层的敌人数量很多，还是由我来挡在后卫前面吧。」"、"「鲁迪那种破墙前进的方法最好不要常用，有导致崩塌的危险。」"、"尤其是转移迷宫这种满是陷阱的场所，连战斗中也得分神去闪躲那些不能踩到的地方。"、"「话说起来，书上写第四层是完全不同的感觉，好像会变成类似遗迹那样。」「也就是说，这里可能会有两个最深处。」"、"历史悠久的迷宫有时会和其他迷宫融合，形成拥有两个魔力结晶的状态。听说那种迷宫的风格会在途中突然转变。转移迷宫符合这种特徵。话虽如此，好像也不是每个符合这种特徵的迷宫都有两个魔力结晶，这顶多只是一种可能性。按照书上所写，转移迷宫的魔力结晶只有一个。不过也有可能这里本来不是转移迷宫，而是随处可见的普通迷宫和其他遗迹融合，最后就成为转移迷宫。至于所谓的其他遗迹……举例来说，就是转移遗迹之类。"

## 二、组织与势力
- 名称：保罗迷宫攻略队伍（前S级冒险者队伍「黑狼之牙」成员重组）
  - 内容：队伍分为探索组与待机组，前身成员虽曾解散但仍保持顶级S级队伍的严密协作水准：
    1. 运作机制：探索组回到城镇时专注休息，由待机组（维拉、雪拉、莉莉雅等）负责在城镇内采购补给与准备医疗用品。
    2. 职能分工：保罗担任全队队长（负责最终决断与点名）；基斯担任探索组组长兼斥候（负责指挥及统领待机组采购）；莉莉雅担任待机组组长（统整物资）；塔尔韩德担任中卫兼阵型配置者；保罗（主坦）与艾莉娜丽洁（副坦/辅助）搭档前卫；鲁迪乌斯（辅助）与洛琪希（殿后魔术师）搭档后卫。
  - 原文依据："探索组回到城镇时就专心休息，这段期间内由待机组负责行动，基本上是这样的规划。"、"基斯明明是探索组，却连待机组也负责指挥。"、"就算曾经闹翻解散，这些人还是S级的冒险者队伍。"、"队形由他负责决定。因为他站在队伍最后面，也是最常看到看到整个现场的人。"、"斥候：基斯。前卫：保罗、艾莉娜丽洁。中卫：塔尔韩德。后卫：鲁迪乌斯、洛琪希。"、"如果探索组的组长是基斯，那么待机组的组长就是莉莉雅。然后，整个队伍的队长是保罗。讲到这个队长要做什么，就是做出最终决断和点名。"

## 三、力量体系 / 魔法 / 技能
- 名称：绝对零度
  - 规则：传说中的帝级水魔术，具备极高的即效性、强大的威力与极广的杀伤范围。
  - 原文依据："「我是指你救我时使用的那个魔术。看那即效性、威力和范围，真的非常了不起。那就是传说中的帝级魔术『绝对零度』吧？」"
- 名称：冰霜新星
  - 规则：水魔术，在迷宫攻略中能有效克制并消灭大批魔物；若施术者注入巨额魔力，其杀伤力和范围甚至会被误判为帝级魔术。
  - 原文依据："不是，那只是冰霜新星而已。在第二层移动时，我从塔尔韩德那边听说冰霜新星是洛琪希用过的有效魔术，所以效法了一下。"、"「不，那只是冰霜新星，不过威力比你的魔术强大。」"
- 名称：岩炮弹
  - 规则：土魔术，鲁迪乌斯经过魔力强化与压缩后能打出等同于帝级魔术威力的打击效果。
  - 原文依据："虽说我的岩炮弹似乎有等同于帝级的威力，但实际上我无法使用那种层级的魔术。"
- 名称：「预知」魔眼
  - 规则：特异能力魔眼，能够预知数秒后的未来，但限制在于无法预测视线范围以外发生的事情。
  - 原文依据："「鲁迪乌斯负责辅助洛琪希。洛琪希是遇到意外状况就会失误的类型，但是鲁迪乌斯拥有『预知』魔眼，而且年纪轻轻却很冷静，或许能事先防止失误发生。」"、"预知眼无法预测视线范围以外的事情，也就是说，我必须一直看着洛琪希。"
- 名称：转移魔法阵
  - 规则：迷宫中的危险魔法陷阱，一旦踏入便会被强行传送至其他未知区域。
  - 原文依据："然而洛琪希之前确实误踩了转移魔法阵，这里还是别自己惹事吧。"

## 四、种族 / 生物
- 名称：人族
  - 特征：肉体会随着岁月自然成长、体格高大化，与长寿种族有显著生长差异。
  - 原文依据："「话说回来，那个……鲁迪你长大了呢。」「因为我是人族，不过老师您还是没变。」"
- 名称：米格路迪亚族（魔族）
  - 特征：长寿种族，外表年龄和体型数十年如一日，成年后依然保持矮小体格，外观长久没有变化。
  - 原文依据："久别重逢的洛琪希没有什么变化。不管是外表的年龄还是散发出来的气质，全都一如既往。"、"「是啊……我依然是这种矮个子。」"

## 五、物品 / 道具 / 武器
- 名称：转移迷宫攻略笔记
  - 说明：某位曾探索至转移迷宫最深处附近的冒险者留下的笔记手记，记录了迷宫各层结构特征、魔力结晶数量等关键攻略情报。
  - 原文依据："「是鲁迪带来的书。有个家伙攻略到转移迷宫最深处附近，这本书是他的笔记。你也先看过一遍吧。」"

## 六、历史 / 传说 / 事件
- 事件名：洛琪希与塔尔韩德的长期搭档旅行
  - 内容：洛琪希与塔尔韩德过去曾两人结伴旅行了很长一段时间，彼此之间建立了深厚的信赖关系。
  - 原文依据："听说洛琪希和塔尔韩德曾经两人结伴旅行很长一段时间，从这些对话里也能听出彼此的信赖关系，让我有点嫉妒。"
- 事件名：洛琪希转移迷宫受困与获救
  - 内容：洛琪希因踩中转移魔法阵受困于转移迷宫第三层一个月，靠顽强意志独自求生；最终鲁迪乌斯凭借神秘预感强行破墙开路，以强化冰霜新星将其成功救出。
  - 原文依据："不过，大概该归咎于一个月的迷宫受困生活吧，她显得相当衰弱。"、"要不是这家伙突然对我说什么感觉到神的存在，而且还打破墙壁往前冲，否则我们恐怕无法找到你。"、"被困在转移迷宫里一个月，独自持续奋战，而且逃离几天后就要若无其事地再度挑战，洛琪希的心理素质实在让人敬佩。"

## 七、社会规则 / 习俗 / 文化
- 迷宫冒险者的“无法进入迷宫的诅咒”（心理创伤）：
  - 内容：冒险者在迷宫中死里逃生后，若未在短时间内尽快重返迷宫，心理上会产生强烈的创伤恐惧，出现想要进入迷宫时身体动弹不得的现象，俗称“诅咒”。因此遭遇生死危机后尽快重返迷宫是冒险者的常识。
  - 原文依据："「但是在迷宫中死里逃生后，要是没有赶快再去，就会罹患再也无法进入迷宫的诅咒。」「诅咒？有那种东西？」「嗯。虽然不清楚原因，不过听说那种人想要进入迷宫时，就会因为心中充满恐惧而无法动弹。」"
- 迷宫深入与撤退规范：
  - 内容：探索迷宫时通常以找到下一层的通路或传送阵为阶段性目标，以此决定继续深入或撤退；撤退后再次进入迷宫时，直接快速前往上次的撤退点继续探索。若探索间隔时间过长，迷宫内的陷阱可能会增多。
  - 原文依据："基本上，在迷宫里找到前往下一层的通路后，会决定要继续深入还是要暂时撤退。如果决定撤退，再度进入迷宫时就会一直线前往上次的最后地点，从那里继续探索。"、"听说要是间隔太久，陷阱有可能会变多，因此迅速行动很重要。"
- 冒险者对体味与污垢的包容文化：
  - 内容：长期处于险恶迷宫与野外环境，冒险者普遍对浑身脏污或异味具有很高的容忍度。
  - 原文依据："「哈哈，这种程度就嫌臭的话，哪有办法当冒险者！」"

## 九、角色认知 vs 客观事实
- 角色以为：洛琪希认为鲁迪乌斯在第三层解救她时使用的超强力冰冻魔术是传说中的帝级水魔术「绝对零度」。
  - 原文是否暗示另有真相：是（鲁迪乌斯实际使用的是经过海量魔力增幅强化的初中级魔术「冰霜新星」）。
  - 原文依据："「那就是传说中的帝级魔术『绝对零度』吧？」不是，那只是冰霜新星而已。在第二层移动时，我从塔尔韩德那边听说冰霜新星是洛琪希用过的有效魔术，所以效法了一下。"
- 角色以为：冒险者们认为从迷宫脱险后不敢再进入迷宫是一种神秘的“诅咒”。
  - 原文是否暗示另有真相：是/不明（鲁迪乌斯根据前世知识推测这实质上是心理层面的恐慌症/创伤后应激反应，并非真正的超自然诅咒）。
  - 原文依据："「虽然不清楚原因，不过听说那种人想要进入迷宫时，就会因为心中充满恐惧而无法动弹。」噢，我生前在漫画里有看过这种剧情，那好像是一种恐慌症，也就是PD。"
- 角色以为：鲁迪乌斯认为自己能在迷宫第三层突然感知到洛琪希陷入危机并准确判定其方位，是源于两人之间命运般的紧密纽带或神之导引。
  - 原文是否暗示另有真相：[存疑]（鲁迪乌斯主观认定是与洛琪希的紧密联系，但自身也曾怀疑是否有“人神做了什么”的可能，本章未证实真实机制）。
  - 原文依据："我不知道为什么会产生那种预感，只是莫名有种确信。我想，一定是自己和洛琪希之间的紧密关系拉着我们相聚。没错，肯定是那样。说不定还有一点点可能性是人神做了什么，但我不相信。"
