# 第十三话　「归来」 世界设定提取

## 一、地理与场所
- 名称：北方大地
  - 内容：冬季漫长且多雪，秋季过后便进入漫长的冬季并开始飘雪。
  - 原文依据："北方大地已经在飘雪了。从这边出发踏上旅程后，过了大约四个月。秋天和兽族的发情期都早已结束，正准备进入漫长的冬季。"
- 名称：瘤胃森林
  - 内容：位于北方大地前往魔法都市夏利亚途中的森林，初冬积雪及踝，深冬（一个月后）积雪深度可及腰，会严重阻碍通行。
  - 原文依据："瘤胃森林里也堆着可以淹没脚踝的积雪。要是再晚一个月回来，积雪恐怕会深度及腰。那样一来，移动到夏利亚的这段路程肯定也会变得很困难。"
- 名称：魔法都市夏利亚
  - 内容：鲁迪乌斯等人生活的北方城市，城内有中心街道和旅社。
  - 原文依据："我们抵达魔法都市夏利亚。我一直线往自家前进，可以感觉到自己步伐越踏越快。"、"「哦，这里就是城镇中心吗？总之，我们去找间旅社吧。也不能这么一大群人都跑去打扰前辈家──」"
- 名称：贝卡利特大陆
  - 内容：鲁迪乌斯一行此前前往营救塞妮丝的大陆，环境有沙漠。
  - 原文依据："只有悲伤，我在贝卡利特大陆上只留下了悲伤。"、"犰狳好像也觉得很冷，果然还是该把它留在沙漠里才对吗？"

## 二、组织与势力
- 名称：米里斯教团 / 米里斯教
  - 内容：信奉单一的神，教规严格要求一夫一妻制且教徒终生只能爱一名妻子；教徒脖子上挂有教团象征物，城镇中设有教会，每七天会举行类似弥撒的宗教活动。
  - 原文依据："克里夫的脖子上挂有米里斯教团的象徵物，而且好像每七天就会去镇上教会参加类似弥撒的活动。"、"「你知道吗？所谓的米里斯教徒必须遵守只能娶一名妻子的教规。」「虽然要求教徒必须终生爱着那名妻子的教规有点死板，不过一旦站在被爱那方的立场，会觉得这实在是一个美好的教义。」"

## 三、力量体系 / 魔法 / 技能
- 名称：斗气
  - 规则：战职者的能力体系，能让斗气缠绕在身体周围；无法让斗气缠身者在剑术上很难继续进步。
  - 原文依据："因为我在这个世界里，对于战斗方面并不是那么有才能。没办法让所谓的斗气缠身，也一直不懂到底该如何做。既然无法让斗气缠身，剑术似乎也不可能进步。"
- 名称：土魔术
  - 规则：可用于凭空塑造土质构造物，鲁迪乌斯以此制造出供人乘坐的背架。
  - 原文依据："塞妮丝似乎很辛苦，所以我用土魔术制造出临时背架，让她坐在背上。"
- 名称：解毒魔术
  - 规则：治愈/解毒体系的魔术，用于消除异常状态或毒素。
  - 原文依据："「喂！前辈，你怎么了，脸色这么难看。是不是用一下解毒魔术会比较好？」"
- 名称：王级魔术
  - 规则：高级别的魔术阶级，但在魔术完全无效的对手（如九头龙）面前无法起效。
  - 原文依据："而且这次的对手又是魔术无效的九头龙，就算我有努力学会王级魔术，恐怕也没有意义。"

## 四、种族 / 生物
- 名称：兽族
  - 特征：有特定的发情期，发情期随秋季结束而结束。
  - 原文依据："秋天和兽族的发情期都早已结束，正准备进入漫长的冬季。"
- 名称：犰狳（次郎）
  - 特征：栖息于沙漠的生物，极其畏寒，受冻时会颤抖，需要依靠火/温度相关的魔术升温维持体温。鲁迪乌斯为其取名为“次郎”。
  - 原文依据："犰狳虽然冷到发抖，不过只要时时用魔术帮它升温就不要紧。"、"犰狳好像也觉得很冷，果然还是该把它留在沙漠里才对吗？不，事到如今已经太迟了。至少要先取个名字，让它随时可以离去吧。嗯，次郎，就叫次郎吧。加油啊，次郎。"
- 名称：九头龙
  - 特征：迷宫中的魔物，具备魔术无效的特性。
  - 原文依据："而且这次的对手又是魔术无效的九头龙，就算我有努力学会王级魔术，恐怕也没有意义。"

## 五、物品 / 道具 / 武器
- 名称：米里斯教团的象征物
  - 说明：米里斯教徒挂在脖子上的宗教饰品/圣物。
  - 原文依据："克里夫的脖子上挂有米里斯教团的象徵物，而且好像每七天就会去镇上教会参加类似弥撒的活动。"

## 六、历史 / 传说 / 事件
- 事件名：保罗迎娶莉莉雅
  - 内容：保罗在已有塞妮丝一位妻子的情况下使莉莉雅怀孕，随后迎娶莉莉雅为二妻。塞妮丝不仅没有因此变得不幸，反而与莉莉雅相处融洽。
  - 原文依据："「你试着回想一下吧。保罗娶了莉莉雅之后，塞妮丝有变得不幸吗？」……塞妮丝确实没有变得不幸，而是跟往常一样。反而和莉莉雅变得比过去更要好，看起来似乎比以前还要幸福。"
- 事件名：人神的预言与指引
  - 内容：人神曾预言鲁迪乌斯前往贝卡利特大陆后会产生“后悔”，并在此前指引鲁迪乌斯在魔法大学结识莉妮亚与普露塞娜。
  - 原文依据："是关于人神的预言。那家伙说过我会「后悔」。"、"快点回想人神的发言。他说过要我和莉妮亚与普露塞娜怎样又怎样，这是不是在暗示她们手上有什么？是不是在叫我必须获得她们的帮助，然后去解决什么问题呢？"

## 七、社会规则 / 习俗 / 文化
- 婚姻与宗教观念（一夫一妻与一夫多妻）：
  - 内容：米里斯教信徒遵循严格的一夫一妻制教规；但在非米里斯教文化圈中，一夫多妻被社会普遍接受，只要平等关爱妻子便不被视为不忠。
  - 原文依据："「你知道吗？所谓的米里斯教徒必须遵守只能娶一名妻子的教规。」"、"「如果你抛弃希露菲当然是另当别论，不过只要你有好好爱着她，就不算是不忠。」"、"是因为基本上，大概只有米里斯有那种一夫一妻的文化。"
- 妻子改姓与名号：
  - 内容：原本没有姓氏的平民女性（如希露菲叶特），结婚后会冠上丈夫的家族姓氏（如希露菲叶特·格雷拉特）；续娶新妻子同样会冠夫姓。
  - 原文依据："「我的妻子名叫希露菲叶特•格雷拉特。不过她原本没有姓氏，单纯叫作希露菲叶特。」「嗯，我听说过。」「那么洛琪希，你有没有意愿把名字改成洛琪希•格雷拉特呢？」"
- 娶第二位妻子的家庭伦理：
  - 内容：在决定迎娶第二位妻子前，必须事先征得原配正妻的同意，若未获同意则不能贸然成婚。
  - 原文依据："「……我非常感谢你对我说这句话，但是，可以不必取得夫人的同意吗？」「我必须徵得她的同意。」「那么，请你在徵得同意之后，再问我一次。」"

## 九、角色认知 vs 客观事实
- 角色以为：艾莉娜丽洁根据洛琪希在集市喝酒时所说“那一天没有来”，推测洛琪希可能怀上了鲁迪乌斯的孩子；鲁迪乌斯也信以为真并以此为理由下定决心负责求婚。
  - 原文是否暗示另有真相：[存疑]（艾莉娜丽洁随后补充“目前还没有确定就是了……”，是否真正怀孕在此时尚未确诊证实）。
  - 原文依据："「在集市喝酒时，洛琪希说过那一天没有来。」……「算了，目前还没有确定就是了……」"
- 角色以为：鲁迪乌斯在归途由于人神曾预言他会“后悔”，加上家里留守着怀孕的希露菲，极度恐慌地怀疑家里出了大变故（如希露菲早产遇险、妹妹们生病或遭袭）。
  - 原文是否暗示另有真相：是（鲁迪乌斯纯属自寻烦恼过度焦虑，家里一切平安安好）。
  - 原文依据："「希露菲，你没事吗？没发生什么事情吗？」「咦？嗯，大家都对我很好，爱夏也很努力。」「其他还有谁……诺伦呢？莉妮亚和札诺巴他们也没事吗？」「咦？没发生任何事喔。」「没有任何人生病或受伤吧？」「啊，嗯……没发生什么特别的事情……」……让我总算确定，真的什么事都没有发生。……结果所谓的后悔，是指保罗的死，还有关于前世双亲的事情。是我自寻烦恼。"
