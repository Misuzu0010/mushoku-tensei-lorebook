# 第十六话　「在墓碑前」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚王国
  - 内容：魔法都市夏利亚所属的王国，国内拥有名声显赫的高水平医生。
  - 原文依据："透过爱丽儿的介绍，找上了拉诺亚王国数一数二的名医。"
- 名称：米里斯神圣国
  - 内容：塞妮丝娘家（拉托雷亚家族）所在的宗教国度。
  - 原文依据："也无法预测塞妮丝在米里斯神圣国的娘家会表示什么意见。"
- 名称：北方大地
  - 内容：冬季寒风暴雪肆虐，雪势大时难以出行，深冬集市上极难买到鲜花，墓园道路常被积雪封闭。
  - 原文依据："要说问题，大概只有风雪太强所以来不及去叫医生这种程度的事情。"、"在这个北方大地，冬季里很难取得鲜花。"、"通往这里的道路被积雪封住，不过墓地本身有管理人稍微除过雪……"
- 名称：阿斯拉王国布耶纳村原址
  - 内容：保罗生前担任驻乡骑士的故土，大转移前全家的故乡。
  - 原文依据："老实说，把保罗的墓地盖在阿斯拉王国布耶纳村原址附近或许比较好。毕竟这片土地和保罗没有任何关系与缘分。"
- 名称：夏利亚郊外贵族用墓地
  - 内容：位于夏利亚郊外小山丘上，管理水平远好于大众公墓，有常驻墓地管理员维护与清理积雪；保罗安葬于此。
  - 原文依据："隔天，我独自一人前往位于郊外小山丘上的贵族用墓地。保罗的墓也在那里。……这里的管理比大众用墓地好多了，所以只好让保罗忍耐一下。"
- 名称：鲁迪乌斯的家
  - 内容：二楼包含曾死过原住户的大房间（现由塞妮丝与莉莉雅居住），以及二楼最小的狭窄房间（洛琪希选择入住）。
  - 原文依据："塞妮丝最后住进这个家里的另外一间大房间。我对莉莉雅说这是之前住户死去的房间所以不建议她们使用，但是塞妮丝却喜欢到不肯离开。"、"讲到我另一个妻子，洛琪希她住进二楼的一个小房间。而且是二楼最小的房间之一。……洛琪希似乎比较喜欢狭窄空间。"

## 二、组织与势力
- 名称：魔法大学
  - 内容：夏利亚的魔法学府，洛琪希正式入职担任教师。
  - 原文依据："还有，洛琪希成了魔法大学的教师。带她去介绍给大家时也顺便做了归来报告……"
- 名称：塞妮丝娘家（米里斯神圣国）
  - 内容：位于米里斯神圣国具有重要势力的贵族世家，对塞妮丝的下落与安危具备过问权。
  - 原文依据："也无法预测塞妮丝在米里斯神圣国的娘家会表示什么意见。"

## 三、力量体系 / 魔法 / 技能
- 名称：世界的医疗局限与治愈魔术失衡
  - 规则：因高度依赖治愈魔术，导致常规医疗技术严重偏向外伤与某些特定分野；医学界对大脑机能受损与失忆症既无认知也无疗法，顶尖名医对此束手无策，仅能开出失忆症复健训练表。
  - 原文依据："找上了拉诺亚王国数一数二的名医。然而对方似乎不曾见过这种症状，所以乾脆放弃表示不清楚治疗方法。看样子这个世界的医疗技术在记忆方面果然是束手无策。大概是因为有治愈魔术，这世界的医疗技术似乎只偏向某些分野。话虽如此，我还是成功请医生拟定了一份失忆症病人用的复健训练表。"
- 名称：治愈魔术在急产/难产中的效用
  - 规则：生产现场配备掌握治愈魔术的术师，能在突发危险或大出血等紧急事态时提供极高的生还保障。
  - 原文依据："因为发生紧急事态时如果有人能使用治愈魔术，应对能力会完全不同。"

## 四、种族 / 生物
- 名称：绿发禁忌（斯佩路德族历史影响）
  - 特征：在世界普遍认知中，绿发被视为不可触碰的禁忌与歧视标志；产妇（希露菲）产下婴儿后极度害怕孩子长有绿发，直到确认孩子发色非绿才如释重负。
  - 原文依据："「太好了……她的头发不是绿色。」……光是发色为绿，就会成为一种禁忌。女儿拥有和我一样的发色，自己必须为了这份幸运而感谢神明。"
- 名称：米格路德族
  - 特征：外貌身型长得与人类相仿但生态有所不同；魔族与人族的混血后代在人族社会中容易受到带有歧视性质的批评与非议。
  - 原文依据："「这是我第一次看到人类出生的瞬间，真是惊人。」"、"我不清楚米格路德族的生态，不过既然有近似人类的外型，想必没有太大的差别。"、"不要让孩子因为被批评是和魔族的混血儿，结果产生什么奇怪的扭曲心态。"

## 五、物品 / 道具 / 武器
- 名称：拉诺亚式圆形墓碑
  - 说明：拉诺亚王国风格的圆形墓碑，保罗之墓以此式样建立。
  - 原文依据："我在雪中来到拉诺亚式的圆形墓碑前方。"
- 名称：烈酒
  - 说明：口感如烈火窜喉的浓烈酒精饮品，被用于祭祀扫墓，由生者饮用并浇淋于墓碑上祭奠逝者。
  - 原文依据："嚐过那种彷佛有一团火窜过喉咙的烈酒后，我把酒倒到墓碑上。"
- 名称：帮助记忆恢复的魔道具 [存疑]
  - 说明：鲁迪乌斯设想是否存在能治疗失忆症的特殊魔法道具，当前存疑、尚未确认存在。
  - 原文依据："如果有机会，或许该试着寻找能帮助记忆恢复的魔道具。当然，我不知道是否真的有那种东西。"

## 六、历史 / 传说 / 事件
- 事件名：露西·格雷拉特诞生
  - 内容：希露菲顺产诞下一名女婴，发色遗传鲁迪乌斯的茶褐色；鲁迪乌斯取双方名字首字将其命名为“露西·格雷拉特”。
  - 原文依据："是个女孩，和我有着相同发色的可爱女孩。……我从自己和希露菲的名字里取了第一个字，把女儿命名为露西。露西•格雷拉特。"
- 事件名：诺伦降生时的臀位凶险（过往事件）
  - 内容：多年前诺伦出生时为头部向上、臀部朝下的臀位胎位，险些导致母女双亡，保罗当场手足无措，由莉莉雅协助接生脱险。
  - 原文依据："诺伦是头上屁股下的臀位，当时母子都很危险。保罗完全帮不上忙，只顾着张皇失措。"
- 事件名：保罗安葬于夏利亚郊外
  - 内容：鲁迪乌斯在夏利亚郊外贵族公墓为保罗立碑下葬，全队同行者曾携带酒与短剑在墓前聚首祭拜。
  - 原文依据："隔天，我独自一人前往位于郊外小山丘上的贵族用墓地。保罗的墓也在那里。……我已经把这个地方告诉基斯他们。而且也已经所有人一起来祭拜过一次。"

## 七、社会规则 / 习俗 / 文化
- 公墓分级制度：
  - 内容：墓地分为大众用公墓与贵族用墓地，贵族墓地配有专职管理人员维护并负责除雪，环境与管理水平远胜平民公墓。
  - 原文依据："这里的管理比大众用墓地好多了，所以只好让保罗忍耐一下。"、"墓地本身有管理人稍微除过雪……"
- 祭扫与悼念习俗：
  - 内容：亲友祭扫时通常携带逝者生前喜爱之物（如酒或武器），有在墓前饮酒开宴并将酒液倾倒于墓碑祭奠的习俗；常态下亦有献花风俗（但北方冬季花卉断货）。
  - 原文依据："大家都各自带了保罗应该会喜欢的东西。例如酒或短剑之类，基斯和塔尔韩德在墓前开起盛大酒宴……"、"原本想买个花作为祭品，但是城镇里没卖。在这个北方大地，冬季里很难取得鲜花。"、"我每喝一口，就倒一些酒在墓碑上。"
- 子女命名习俗：
  - 内容：夫妻各取自身名字的首字组合，为新生子女起名（如鲁迪/Rudi + 希露菲/Sylphi 组合命名为露西/Lucy）。
  - 原文依据："我从自己和希露菲的名字里取了第一个字，把女儿命名为露西。露西•格雷拉特。"
- 生产助产礼制：
  - 内容：产房接生由具备助产经验的女性（主妇、侍女）主导，男子通常不参与实质接生流程，婴儿出生后男性家属会被请出房间以便侍女善后。
  - 原文依据："后来，我被莉莉雅赶出房间。说是有很多事情要做，叫我先出去等着。"
- 魔族血统与社会歧视：
  - 内容：人族社会对人魔混血儿童存在强烈的偏见与排斥心理。
  - 原文依据："不要让孩子因为被批评是和魔族的混血儿，结果产生什么奇怪的扭曲心态。"

## 九、角色认知 vs 客观事实
- 角色以为（关于塞妮丝失忆的医学治疗）：鲁迪乌斯寄希望于爱丽儿引荐的拉诺亚王国顶级名医，以为其能有办法诊治塞妮丝的精神掏空和失忆。
  - 原文是否暗示另有真相：否（客观事实是名医对大脑记忆病变未曾见过、束手无策，异世界当前常规医疗在此领域完全空白）。
  - 原文依据："找上了拉诺亚王国数一数二的名医。然而对方似乎不曾见过这种症状，所以乾脆放弃表示不清楚治疗方法。看样子这个世界的医疗技术在记忆方面果然是束手无策。"
- 角色以为（关于新生儿发色担忧）：希露菲因过去幼年惨痛的绿发歧视经历，在生产前极度担忧刚出生的孩子也长着绿色头发；生下后确认是茶褐色才如释重负。
  - 原文是否暗示另有真相：否（客观事实是孩子确实遗传了鲁迪乌斯的发色，并非绿发）。
  - 原文依据："莉莉雅把孩子抱了起来，交给希露菲。希露菲搂着小婴儿，呼出一口气。「太好了……她的头发不是绿色。」……女儿拥有和我一样的发色，自己必须为了这份幸运而感谢神明。"
