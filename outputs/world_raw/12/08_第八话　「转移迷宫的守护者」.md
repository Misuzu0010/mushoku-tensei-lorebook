# 第八话　「转移迷宫的守护者」 世界设定提取

## 一、地理与场所
- 名称：转移迷宫最深处（灰色宫殿 / 守护者大厅）
  - 内容：位于转移迷宫第六层尽头红色转移魔法阵另一端的最深层空间。其规模极为宏大，如棒球场般宽广的长方形大厅，呈现出庄严肃穆的宫殿样式。大厅角落竖立着数根粗壮柱子，天花板极高，地面铺满雕刻着繁复浮雕的磁砖，通体呈灰色调。此处深处盘踞着守护者「魔石多头龙」，并安置着封印塞妮丝的巨大绿色魔力结晶。
  - 原文依据："通过魔法阵后，我们来到一个极为宽广的空间。那是一间和棒球场差不多大，看起来宛如宫殿的长方形大厅。角落里竖立着好几根粗柱子，天花板高到需要把头整个往上仰才能看清。地上铺着类似磁砖的东西，每一个都刻有图案复杂的浮雕。如果要用一句话来形容，就是显得很庄严肃穆吧。"、"这间灰色宫殿的深处有一只魔物。"

- 名称：转移迷宫第六层（通关状态）
  - 内容：通往迷宫最深处的过渡阶层。队伍借助克制暴食恶魔的塔尔弗洛树树根，以零物资损耗的状态通过该层并在安全房间中充分休息。该层尽头设有通往最深处的红色转移魔法阵。
  - 原文依据："第六层轻松过关。多亏塔尔弗洛树的树根，暴食恶魔跟小喽啰没两样。我们并不需要特别动用到什么物资，说是完全没有损耗也没问题。而且在先前那个房间里也已经充分休息过了。"、"然而很不可思议的是，我也可以确定这个魔法阵前往的地方就是迷宫的最深处。"

## 二、组织与势力
本章无新增组织与势力（仅涉及保罗搜救队内部既有成员）。

## 三、力量体系 / 魔法 / 技能
- 名称：魔术卷轴战术与施法限制
  - 规则：
    1. 缩短咏唱的局限：如洛琪希即便能缩短咒语极速连发魔术，上级魔术仍需较长咏唱时间，面对突发险情必须依靠预先储备的魔术卷轴作为底牌与隐藏杀招。
    2. 无咏唱施法者的盲区：无咏唱施法者虽然不需要攻击卷轴，但治愈魔术通常另当别论；且一旦施法者的喉咙或肺部严重受伤，无咏唱施法亦可能受阻，因此需要中级治愈魔术卷轴作为应急保命手段。
  - 原文依据："为了对应紧急状况，洛琪希随身藏着几个卷轴，都是上级魔术的卷轴。她缩短了咏唱咒语，能以相当快的替换率来接连使出好几个魔术。然而，上级魔术还是需要比较长的咏唱。如此一来，总是会碰上无论如何都来不及的情况。所以这些卷轴就是那种时候的隐藏杀招。"、"我能够以无咏唱方式使出魔术，不需要上级魔术的卷轴。但是，治愈魔术另当别论。为了以防万一，还是收下这些卷轴吧。所谓的万一，就是指喉咙和肺部受伤的时候。"

- 名称：初级治愈魔术的治愈上限与效果
  - 规则：初级治愈魔术拥有极强的组织修复能力。即便人体肩膀被锋利鳞片削去一大块肉（在前世世界需缝合数十针的重创），在初级治愈魔术的作用下依然能够完全治愈且不留下任何伤疤痕迹。
  - 原文依据："她的肩膀被削掉一大块。……不过，这种伤还属于用初级治愈魔术就能完全治好不留痕迹的范围。如果是生前的世界，大概得缝上几十针吧。这个世界真是方便。"

- 名称：战术性水魔术与障眼法
  - 规则：魔术除了杀伤与防御外兼具战术位移与遮蔽功能。例如洛琪希咏唱中级水魔术「水流」，在同伴身前凭空召出水流将保罗冲走，使其瞬间脱离敌方近身攻击范围；鲁迪将魔力集于双手制造大范围浓雾，可作为阻断魔物视线以安全撤退的障眼法。
  - 原文依据："『潺潺的浊流啊！水流！』在洛琪希咏唱咒语的同时，保罗面前冒出一团水。那团水把保罗冲走，让他逃出九头龙的攻击范围。"、"把魔力尽可能集中到手上，在九头龙和保罗之间制造出浓雾。一整片白茫茫的烟雾是一种障眼法。"

- 名称：双剑高速斩击与预知眼的动态捕捉极限
  - 规则：顶尖剑士（保罗）采用双手持剑战法，身手极度敏捷，其出剑速度与步法甚至超越了魔眼「预知眼」的完全捕捉能力，能利用身体旋转产生的离心力与双剑连续挥斩一举斩断巨大龙颈。
  - 原文依据："保罗挥动右手的剑一砍到底，真是惊人的剑速。接下来，保罗的身影晃了一下，这是因为他的速度快到即使用了预知眼也无法完全捕捉。九头龙的另一个脑袋喷出血花。这次是左手的剑一砍到底。不过因为长度不够，没有直接砍断。保罗旋转身体，利用离心力再度挥出右手的剑。原本还挂在脖子上的那颗头也掉了下来。"

- 名称：刺剑冲击波技能
  - 规则：艾莉娜丽洁持盾刺剑时，可由剑尖激发出肉眼无法辨识的无形冲击波进行攻击（但在魔石之鳞面前被弹开无效）。
  - 原文依据："艾莉娜丽洁总算赶到。她举着盾牌，把手中的剑往前刺。下一瞬间，剑尖发出肉眼无法辨识的冲击波。叽──！又是那种声音。"

## 四、种族 / 生物
- 名称：九头龙（一般种）
  - 特征：龙种魔物之一。生有多颗头部，天性独居不形成族群，单体战力位居最高水准。主要栖息于魔大陆某处，此前已被学术确认的种类根据鳞片颜色区分为三种：白色、灰色、金色。在此之前普遍认为不存在绿色鳞片的九头龙。
  - 原文依据："所谓的九头龙是龙种的魔物之一。这种龙拥有复数的头部，不会形成族群，但是若以单一个体而言，却具备了最强水准的力量。我记得它们栖息于魔大陆某处，光是目前已经确认的种类就有三种，是基于鳞片的颜色来区分为白色、灰色、金色。绿色鳞片的九头龙并不存在。"

- 名称：魔石多头龙（恶魔之龙 / 转移迷宫守护者）
  - 特征：
    1. 外观与体格：体型约为赤龙的两倍，身躯矮壮，生有九颗如蟒蛇般扭动的头部，全身覆满闪耀翠绿色光芒的鳞片。
    2. 魔石之鳞：全身覆盖着能够吸收魔力的魔石鳞片。鳞片表面类似鲨鱼皮，布满突起的盾鳞，锋利坚硬如磨泥器，仅凭身体接触擦撞即可突破坚固防御、削掉受击者整块皮肉；且一切中远程飞行魔术（如冰击、威力足以击飞魔王的岩炮弹、土落弹等）与冲击波在即将命中或触及时都会发出刮玻璃般的尖锐刺耳声（叽──！），随即被吸收、弹开或使岩石崩碎为沙，魔术完全无效化。
    3. 再生能力：生命力极为惊人，被切断的头颅切口处肉芽会迅速隆起并延伸，短时间内即可完全复原出全新头部。
    4. 弱点推论[存疑]：被斩断头部的肉质切口处没有魔石鳞片保护，魔术不会被弹开；根据鲁迪推测，在断颈处施以火灼烧切口可抑制其细胞再生；此外文献记载零距离直接接触肉体施放魔术理论上可造成伤害。
    5. 历史与生存状态：文献中被称为「恶魔之龙」，曾在第二次人魔大战期间被目击，传言随着大陆消灭而一并绝迹，原本被当世视为空想传说，实则作为转移迷宫最深处的守护者存活至今。
  - 原文依据："一只巨大的魔物，尺寸大约是赤龙的两倍。即使站在远处，也能看到翠绿色的鳞片熠熠生辉。体型矮壮，而且长着好几颗头。"、"魔石多头龙的全身覆盖着能吸收魔力的魔石之鳞，可说是恶魔之龙。书上还有写到这种魔物曾在第二次人魔大战时被目击过，之后就随着大陆消灭而一并绝灭。我原本认为那只是空想……没想到居然实际存在。"、"看样子那个九头龙的外皮好像跟鲨鱼的皮肤一样，布满许多突起的盾鳞。"、"被保罗砍掉脑袋的两个切口之一开始隆起伸长，冒出肉来形成头部。另一边也随后出现同样变化，逐渐复原。这家伙再生了。"、"虽然没带火把，但是伤口没有鳞片，不必担心魔术会被弹开。"

## 五、物品 / 道具 / 武器
- 名称：红色转移魔法阵
  - 说明：位于迷宫第六层深处、通往迷宫最深处的双方向转移魔法阵。与通常散发蓝白光辉的魔法阵不同，其绽放出代表极度危险的深红色光芒（被鲁迪联想为「Red zone」）。在实战中证实具备双向传送功能，可供队伍紧急脱险撤退。
  - 原文依据："至今看过的转移魔法阵都是散发出蓝白色的光芒，眼前的魔法阵却是红色。红色是代表危险的颜色，也有「Red zone」这种说法。"、"眼前的红色魔法阵看起来是双方向魔法阵，实际上却有可能是单方向。"、"所有人都平安从魔法阵中现身。"

- 名称：巨大魔力结晶（结晶化柱）
  - 说明：位于转移迷宫最深处、魔石多头龙身后守护的绿色水晶柱状魔力结晶。高度约两公尺，体积超乎寻常。塞妮丝整个人被封印囚禁于该结晶之中。据洛琪希所述，强力的魔力附加品在迷宫中有时会被如此结晶化封存，打倒对应的迷宫守护者后结晶化即可解除并取出其中物品。
  - 原文依据："在九头龙后方，它守护的房间最深处。有一块魔力结晶，大到夸张的绿色魔力结晶。高度约有两公尺，形状类似水晶柱。我从来没看过那么巨大的魔力结晶。……是她，那个人被关在魔力结晶之中。「塞妮丝！」"、"关于塞妮丝小姐结晶化这件事，我想应该有办法解决。……是的，我听说过强力的魔力附加品有时候会像那样被封在魔力结晶里，但是打倒守护者后，结晶化就会解除，也能取出内部的物品。"

- 名称：便携魔力结晶
  - 说明：艾莉娜丽洁随身持有的圆形弹珠大小的晶石道具。在迷宫探索魔力耗尽时可直接用于补充恢复魔力，是在受困无法撤退等绝境下保障施法能力的珍贵资源。
  - 原文依据："艾莉娜丽洁把什么东西丢了过来。我接下来一看，原来是类似弹珠的圆形石头……艾莉娜丽洁持有的魔力结晶。『魔力耗尽的时候就拿来用吧。』"

- 名称：魔术卷轴（上级魔术卷轴 / 中级治愈魔术卷轴 / 精灵卷轴）
  - 说明：封存有特定阶级与效果魔术的纸质道具，撕开即可触发无需咏唱的法术效果。洛琪希藏有应对危机的高阶攻击卷轴；鲁迪携有中级治愈魔术卷轴作为声带或肺部负伤无法发声时的应急后手。在法律与行规上明确「禁止擅自复制」。
  - 原文依据："为了对应紧急状况，洛琪希随身藏着几个卷轴，都是上级魔术的卷轴。"、"我从洛琪希那边取得中级治愈魔术的卷轴，摺好并收进长袍的口袋里。"、"不，我记得这类物品禁止擅自复制。不过只是个人使用的话，我想应该不会被抓到。"

- 名称：烟雾弹
  - 说明：基斯持有的探险道具，摔碎后迅速释放大量浓重烟雾，能瞬时遮蔽巨型魔物的视野，为受困同伴创造脱离战圈的机会。
  - 原文依据："基斯正在往前跑，他从塔尔韩德旁边经过，移动到保罗后方，然后把手里握着的某个东西丢向九头龙。响起有什么破裂的声音。于是，以九头龙为中心，开始有一股烟雾冉冉上升。原来是烟雾弹。"

## 六、历史 / 传说 / 事件
- 事件名：第二次人魔大战与魔石多头龙记载
  - 内容：历史文献曾记录魔石多头龙在第二次人魔大战期间被目击，战后随着大陆的崩毁消灭而一并绝迹，长久以来被视为传说生物，直至本章在转移迷宫中被再度确认其实际存在。
  - 原文依据："书上还有写到这种魔物曾在第二次人魔大战时被目击过，之后就随着大陆消灭而一并绝灭。我原本认为那只是空想……没想到居然实际存在。"

- 事件名：大转移事件中的「石头内部转移」异变
  - 内容：大转移灾害中极少数受害者在被随机传送时，会发生直接被传送到石头或地底岩体内部的极为罕见的物理嵌入异变。塞妮丝被困入魔力结晶即可能与此类转移变故相关。
  - 原文依据："转移时被传送到石头里面之类。转移到石头里似乎是极为罕见的状况，不过反过来说，罕见就代表还是有发生过。"

- 事件名：赫拉克勒斯斩杀九头龙神话（鲁迪生前知识引入）
  - 内容：鲁迪前世记忆中的希腊神话，讲述英雄赫拉克勒斯斩下九头龙首级后以火把烧灼切口从而破除其再生的战例。该传说成为全队制定魔石多头龙攻略战术的核心理论支撑。
  - 原文依据："我听说过只要用火烧，九头龙的头部就不会再生。我说明了希腊神话英雄赫拉克勒斯的故事。赫拉克勒斯曾经和九头龙交手。根据故事，只要在切断头部后拿火把烧灼切口就可以阻止再生。"

- 事件名：保罗搜救队的全域搜寻历程
  - 内容：大转移事件后，前黑狼之牙成员（艾莉娜丽洁、塔尔韩德、基斯）与洛琪希协助保罗展开长年搜救，足迹纵贯魔大陆，并远赴北方大地接引鲁迪，历经六年最终将全家人下落齐聚确认于转移迷宫。
  - 原文依据："转移事件发生后已经过了很长一段时间，这段时间内麻烦你们纵贯魔大陆，还前往北方大地找到鲁迪，真的是尽心尽力到超乎我的想像。可是，这一切都到此为止。等塞妮丝得救……就算无法得救，我的家人也在此全数寻获。这次已经是最后了，请把力量借给我。"

## 七、社会规则 / 习俗 / 文化
- 内容：迷宫撤退与守护者房间封闭机制
  - 规则：正常探索迷宫时若魔力耗尽，常规做法是肃清后方通路魔物后主动撤退休整；但在攻略迷宫守护者房间时，普遍流传有封闭结界机制（如同封闭斗技场，不击倒守护者便无法逃离房间）。
  - 原文依据："在探索迷宫的过程中，有可能会耗尽魔力。一般来说，这种状况下会选择撤退，因此必须事先把后方空间里的敌人全部歼灭。然后逃离迷宫，等魔力恢复后再重新挑战。但是，听说和守护者战斗时，有时候却无法逃跑。会被困在类似斗技场的场所里，打倒敌人前都无法出去……就是这样的情形。"

- 内容：魔法卷轴的复制禁令
  - 规则：在此世界中，封印魔术的卷轴属于受到法律或行规管辖的特殊魔法物品，社会公约明确「禁止擅自复制」。
  - 原文依据："我很想带一个回去，让七星或克里夫复制一下。不，我记得这类物品禁止擅自复制。不过只是个人使用的话，我想应该不会被抓到。"

- 内容：前卫坦克战斗职责共识
  - 规则：在冒险者小队的职能分工中，担任前卫坦克的队员（如艾莉娜丽洁）负责抵御正面伤害与掩护队友，队伍内部普遍认为「承受伤害本就是坦克的本职工作」。
  - 原文依据："毕竟艾莉娜丽洁是坦，可以说受伤就是她的工作。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪推测红色的转移魔法阵可能外表看似双向、实际上是单方向传送陷阱（"眼前的红色魔法阵看起来是双方向魔法阵，实际上却有可能是单方向。"）。
  - 原文是否暗示另有真相：否（客观事实证明该魔法阵为双方向，全队遇险后成功通过它全员安全撤回第六层）。
  - 原文依据："所有人都平安从魔法阵中现身。洛琪希、塔尔韩德、基斯，还有大口喘气的保罗。最后一个人是受了伤的艾莉娜丽洁。"

- 角色以为：基斯、鲁迪及世人普遍认为九头龙只有白、灰、金三种，绿色鳞片的九头龙在常理中并不存在；洛琪希甚至认为书上记载魔石多头龙在第二次人魔大战后随大陆毁灭而绝迹一事仅为空想（"绿色鳞片的九头龙并不存在。"、"我原本认为那只是空想……没想到居然实际存在。"）。
  - 原文是否暗示另有真相：是（传说中的魔石多头龙并未灭绝，客观事实是其实际存活在转移迷宫最深处充当迷宫守护者）。
  - 原文依据："魔石多头龙的全身覆盖着能吸收魔力的魔石之鳞，可说是恶魔之龙。书上还有写到这种魔物曾在第二次人魔大战时被目击过，之后就随着大陆消灭而一并绝灭。我原本认为那只是空想……没想到居然实际存在。"
