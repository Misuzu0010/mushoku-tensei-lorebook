# 第一话　「推荐函」 世界设定提取

## 一、地理与场所
- 名称：迷宫都市拉庞
- 内容：位于贝卡利特大陆中央附近的城市，塞妮丝被转移后所在的目的地。
- 原文依据："听说塞妮丝似乎是待在位于贝卡利特大陆中央附近的迷宫都市拉庞。"

- 名称：贝卡利特大陆
- 内容：世界五大陆之一，地理位置极其遥远。从中央大陆北方大地徒步前往需要耗费数月甚至一年以上时间。
- 原文依据："听说塞妮丝似乎是待在位于贝卡利特大陆中央附近的迷宫都市拉庞。我很想立刻动身前往贝卡利特大陆。但是，贝卡利特大陆很遥远。如果要从这里徒步前往，不知道要花上几个月。说不定必须耗费一年以上的时间。"

- 名称：北方大地（气候特征补充）
- 内容：冬季气候极其恶劣严寒，持续降下大雪，积雪深度可超五公尺。国内主干道由国家负责组织一定程度的除雪以保障通行，但跨境及境外道路险峻难行、容易迷失遇难；本地魔物（如拉斯塔熊）在冬季不冬眠照常活动。
- 原文依据："中央大陆北部「北方大地」的冬季非常严苛。会持续降下大雪，积雪深度超过五公尺。在国内还有现成道路可走，国家也会负责除雪到一定程度所以能够移动，不过一旦到了国外难度就会提高。"、"像拉斯塔熊明明也是熊，但是却不会冬眠。"

- 名称：拉诺亚王国
- 内容：位于北方大地的国家，世界著名的最高魔法学府「拉诺亚魔法大学」坐落于此。
- 原文依据："最近，鲁迪乌斯大人的名号『泥沼的鲁迪乌斯』在拉诺亚王国也是如雷贯耳。"、"我感受着这冲击里带有的宝贵情谊，然后踏上前往拉诺亚王国的旅程。"

- 名称：米里希昂 / 米里斯神圣国
- 内容：米里斯神圣国的首都为米里希昂。居民绝大部分为米里斯教徒，全境严格奉行一夫一妻制，拥有一妻以上的男性在当地生活会处处受限难受。
- 原文依据："「可是他们也有可能会住在米里希昂啊。」「那里不是有两个老婆的男人能住得舒服的地方。」米里斯教徒的教规中有一条是一夫一妻。在居民大部分是米里斯教徒的米里斯神圣国，一夫一妻是常识。"

## 二、组织与势力
- 名称：拉诺亚魔法大学
- 内容：水王级魔术师洛琪希的母校，经营管理主体为魔术公会。
  - 特别生制度：针对具特殊才能、高名望未加入公会者或高魔力王公贵族所设。享有免修课程、免缴学费、自由使用校内藏书与研究设备的特权，学籍保留可达七年。
  - 毕业考核与评级：特别生若在七年内完成一项研究成果并转让给学校或魔术公会，可被推荐获得魔术公会C级成员资格；即使无成果毕业，也能直接获得魔术公会D级成员资格。
  - 招生考量：借由招揽奇才挂名入读，利用其未来扬名来为魔法大学提升声誉与知名度。
- 原文依据："这封信被封得很密实，正面写着「拉诺亚魔法大学」几个字。"、"拉诺亚魔法大学已经准备好招收您为特别生。所谓的特别生，是指拥有特殊立场，不但免修课程且免除学费，还可以使用本校藏书与设备，自由进行研究或其他活动的学生。只要在七年以内（到毕业为止）完成一项研究，并且将该研究转让给本校或魔术公会，也能够推荐您成为魔术公会的C级成员。当然，就算没有得出任何研究成果，依旧可以和其他毕业生同样登录为D级成员。"、"魔法大学比较特别，只要毕业就可以成为D级成员。这是因为经营魔法大学本身的主体正是魔术公会。"、"「魔法大学啊，会率先主动联络像你这种会使用奇妙魔术的魔术师，或是以冒险者身分打响名声却没有加入魔术师公会的家伙，还有那些身为他国王侯贵族但拥有惊人魔力的人士。然后会希望这些人可以不必实际听讲上课，只要挂个名取得学籍就好。」「这又是为什么？」「因为那种家伙要是将来出了名，不就能顺便帮魔法大学宣传吗？」"

- 名称：魔术公会
- 内容：对魔术领域进行全面统筹支援的跨国组织，职能涵盖贩售魔法卷轴、资助魔道具研发制作、学术研究等。
  - 入会门槛：只要掌握初级魔法即可登记入会，从F级起步。
  - 阶级特权与晋升：随着等级提升权限与援助增加（F级不享任何支援）。普通魔术学校毕业生为E级，拉诺亚魔法大学毕业生可直升D级，优秀首席或交出学术成果的特别生可获C级。
  - 晋升规则漏洞：缺乏像冒险者公会那样明确的标准，主要依赖委托达成度与公会贡献度（人脉与马屁亦能影响），B级及以下等级实质上可以通过金钱购买获得。
- 原文依据："魔术公会是对魔术相关事物提供全面支援的组织。最低条件是只要会使用初级魔法就可以加入。从F级开始，层级提升后权限会随之增加，也能获得各式各样的援助。如果是就读于大部分的魔术学校，在毕业时能成为E级成员。不过魔法大学比较特别，只要毕业就可以成为D级成员。这是因为经营魔法大学本身的主体正是魔术公会。而且特别生只要交出研究成果就能成为C级。"、"顺便说一下，F级似乎不会获得任何支援。魔术公会的层级好像要靠着达成公会的委托，或是根据对魔术公会的贡献度才有办法提升。……魔术公会的层级可以用钱买到，不过只到B级为止。"

- 名称：盗贼公会
- 内容：负责销赃盗窃物资以及管理奴隶买卖的非法地下集团。
- 原文依据："顺便说一下，对于「盗贼」公会我就比较了解，那是负责销赃和管理奴隶买卖的集团。"

- 名称：Cave A Mondo
- 内容：以魔术师为核心战力的A级冒险者队伍，成员共4人（包括1名魔法战士和3名中级以上魔术师），队长康拉德为火魔术上级魔术师，曾在拉诺亚魔法大学就读五年后退学。
- 原文依据："我以视线观察四周，发现A级队伍「Cave A Mondo」的成员。他们是以魔术师为中心的队伍。人数是偏少的四人，包括一名魔法战士以及三名魔术师。所有人都是中级以上的魔术师，队长则是火魔术的上级魔术师。"、"「康拉德先生你是不是出身于拉诺亚魔法大学？」「嗯，不过我才念了五年就退学了。」"

## 三、力量体系 / 魔法 / 技能
- 名称：无咏唱魔术
- 规则：施法时完全不念咒文即可任意发动与塑形魔术，在外界属于极其罕见且备受瞩目的高强技术。
- 原文依据："听说您是能够自在操控无咏唱魔术的高强冒险者。"

- 名称：水王级魔术师
- 规则：魔术领域的阶级评定之一，王级属于仅次于帝级与神级的高位水准（如洛琪希为水王级）。
- 原文依据："更得知鲁迪乌斯大人是那位水王级魔术师洛琪希的弟子。"

- 名称：魔术的生活与生存应用
- 规则：魔术可用于多种环境适应与日常维持：
  - 运用火魔术即时融化积雪开辟雪道；
  - 运用魔术调高室内环境温度，并生成热水清洗身体；
  - 建筑中存在利用魔术原理运转的「魔术式暖炉」进行整栋供暖。
- 原文依据："我必须边跑边用火魔术融化积雪好开出一条自己专用的道路。"、"用魔术提高室内温度后，我制造出热水，擦乾满是汗水的身体。"、"或是利用魔术式暖炉来让整栋建筑物变暖。"

- 名称：战士仇恨管理技巧
- 规则：高阶武斗战士的核心实战技能，能精准把控魔物/敌方的攻击倾向与仇恨目标，掩护队友或引导战场局势。
- 原文依据："攻击力有点低，但是管理仇恨值的技巧极为高明。以战士来说是一流吧。"

## 四、种族 / 生物
- 名称：兽族
- 特征：亚人种族之一。在情欲躁动或求偶时，身体会散发出特殊的「发情气味」。
- 原文依据："远远也能看出对方满脸通红，身上散发出兽族所谓的「发情气味」。"

- 名称：长耳族（生理补充）
- 特征：身材普遍苗条、平胸，体内脂肪含量极少，因而极度耐受不了寒冷天气。
- 原文依据："扣掉长耳族特徵的贫胸……"、"不过身上脂肪似乎很少的艾莉娜丽洁看起来真的很冷……"

## 五、物品 / 道具 / 武器
- 名称：拉诺亚魔法大学特别生推荐函
- 说明：由副校长吉纳斯・哈尔法斯署名并盖印密实的正式公函，邀请具备罕见无咏唱技术的魔术师作为免学费免考勤的特别生入学。
- 原文依据："这封信被封得很密实，正面写着「拉诺亚魔法大学」几个字。……『拉诺亚魔法大学』副校长　吉纳斯・哈尔法斯敬启。"

- 名称：魔术式暖炉
- 说明：应用于高级旅社或大型建筑的魔导供暖设施，可对整栋楼房实现集中供暖。
- 原文依据："如果是高级旅社，就会在每间房里都设置壁炉，或是利用魔术式暖炉来让整栋建筑物变暖。"

- 名称：魔术卷轴 / 魔道具
- 说明：由魔术公会提供研制、支援及对外贩售的魔法物资器具。
- 原文依据："「他们会贩卖卷轴还有对魔道具制作提供支援等等。」"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移事件的后续调查线索
- 内容：人神在白色虚空中向鲁迪乌斯给出神谕性建议，指示其前往拉诺亚魔法大学就读并调查菲托亚领地转移事件的真相，称该调查是解开其身体心病（ED）并找回男人自信与能力的关键。
- 原文依据："「鲁迪乌斯，去拉诺亚魔法大学就读吧。你要在那里调查菲托亚领地的转移事件，如此一来，你身为男人的能力与自信应该能取回。」"

## 七、社会规则 / 习俗 / 文化
- 米里斯教社会婚恋规则：
  - 奉行严格的一夫一妻制教规，在米里斯教徒占主体的米里斯神圣国被视作绝对不可违背的伦理常识，重婚者在当地会受到强烈的道德与社会排斥。
  - 原文依据："米里斯教徒的教规中有一条是一夫一妻。在居民大部分是米里斯教徒的米里斯神圣国，一夫一妻是常识。「那里不是有两个老婆的男人能住得舒服的地方。」"

- 贵族阶层与冒险者交往习惯：
  - 格雷拉特是阿斯拉王国境内的大领主贵族家系。在冒险者群体间，成员通常只用单名或称号称呼，不注重或难以知晓彼此隐藏的贵族姓氏背景。
  - 原文依据："「格雷拉特好像是阿斯拉的地区领主吧？真是惊人，你为什么会在这里自己一个人当冒险者啊？」"、"「泥沼的鲁迪乌斯」这名号虽然小有名气，不过似乎没有连姓氏也一起传开。"

- 旅馆客栈的分级待遇：
  - 面向C级及普通冒险者的平价旅社仅提供厚重被褥与大厅壁炉，无室内供暖；高级旅舍则每间客房独立配备壁炉，或铺设全楼魔术式暖炉。
  - 原文依据："北方大地的冬季夜晚很寒冷。虽然旅社里装了壁炉所以比室外暖和很多，但这个世界没有空调设备也没有电暖器。如果是高级旅社，就会在每间房里都设置壁炉，或是利用魔术式暖炉来让整栋建筑物变暖。然而很遗憾，这里是服务C级冒险者的便宜旅社，顶多只有提供厚重的被子。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯原先以为等严冬过后的春天动身徒步赶往贝卡利特大陆与保罗、塞妮丝、洛琪希团聚是当下的最优选择。
- 原文是否暗示另有真相：是
- 原文依据："「是吗？不过，这次还是听我的建议会比较好喔。因为要是前往贝卡利特大陆，你一定会后悔。」「后悔？为什么？」「这不能说。」"人神明确警告若前往贝卡利特大陆必将后悔，并指引其前往魔法大学。

- 角色以为：鲁迪乌斯最初怀疑拉诺亚魔法大学寄来的免除学费及免修课程推荐信是某种新型诈骗或拐卖陷阱。
- 原文是否暗示另有真相：是
- 原文依据："换句话说，这是新式的诈欺手法之类吧。……「魔法大学啊，会率先主动联络像你这种会使用奇妙魔术的魔术师，或是以冒险者身分打响名声却没有加入魔术师公会的家伙……挂个名取得学籍就好。」「因为那种家伙要是将来出了名，不就能顺便帮魔法大学宣传吗？」"康拉德证实此为大学招揽奇才的宣传常规制度，并非诈骗。

- 角色以为：艾莉娜丽洁转述塞妮丝在拉庞「很悠哉地在探索迷宫」，鲁迪乌斯推断是艾莉娜丽洁为了安抚他而美化添加的措辞。
- 原文是否暗示另有真相：不明 / [存疑]
- 原文依据："根据艾莉娜丽洁的情报，塞妮丝似乎很悠哉地在探索迷宫。我想所谓的「悠哉」应该是艾莉娜丽洁为了让我安心才自己加上去的形容吧。"
