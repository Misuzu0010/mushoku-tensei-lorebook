# 第二话　「入学考试」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚王国
- 内容：中央大陆北部最大的国家。其国力本身与中央大陆南部的西隆王国相当，但作为盟主与巴榭兰特公国、涅里斯公国缔结同盟，并与魔术公会关系极为密切。三国综合实力位列世界第四。
- 原文依据："拉诺亚王国是中央大陆北部最大的国家。国力和中央大陆南部的西隆王国相当。然而拉诺亚王国和巴榭兰特公国、涅里斯公国缔结了同盟，与魔术公会也有密切关系。只要综合三国的力量，即使位于贫瘠的北部，这个同盟仍旧被视为持有世界上排名第四的实力。……盟主拉诺亚王国"

- 名称：魔法三大国
- 内容：拉诺亚王国、巴榭兰特公国、涅里斯公国三国的统称。作为魔术公会总部所在地，三国倾注海量资金与心力招募世界人才推动魔术研究，拥有世界第四的综合国力。
- 原文依据："基于这种背景，拉诺亚、巴榭兰特、涅里斯这三国被合称为「魔法三大国」。……最大的理由是因为这三国都在魔术相关研究上投注大量心力。它们从世界各国招集优秀的人才，慷慨提供资金，致力于推进魔术研究。"

- 名称：魔法都市夏利亚
- 内容：位于盟主拉诺亚王国边陲近国境线处的大都会，魔法三大国的中枢与核心繁荣都市，汇聚了三大国所有的魔术核心设施。
  - 城市规划格局（参考米里希昂）：
    - 中央：最新式抗魔砖建造的「魔术公会总部」；
    - 东部：以「拉诺亚魔法大学」为核心的「学生区」；
    - 西部：以「涅里斯魔道具工房」为核心的「工房区」；
    - 北部：以「商业公会」为核心的「商业区」；
    - 南部：接待外来旅客和冒险者的「旅馆区」（设有带暖气设备的A级旅馆）。
- 原文依据："为此准备的地方，就是存在于盟主拉诺亚王国的角落，位置非常接近国境线的大都市，魔法都市夏利亚。例如「拉诺亚魔法大学」、「魔术公会总部」、「涅里斯魔道具工房」这类和魔术有关连的所有设施与事物都被凝聚并纳入此地。这里可以说是魔法三大国的中枢，也是最兴盛繁华的都市。如果从上空俯瞰魔法都市夏利亚，可以看到城镇中央是以最新式抗魔砖建造的魔术公会，东边是以魔法大学为中心的学生区，西边是以魔道具工房为中心的工房区，北边是以商业公会为中心的商业区，南边则是迎接外来旅客和冒险者的旅馆区。懂的人一看便知，这是参考了米里希昂的格局。"

- 名称：拉诺亚魔法大学校园及各建筑分区
- 内容：占地极其辽阔的巨型学府，建筑多为抗魔砖砌造，中央建有要塞城堡般的建筑。
  - 主干道与围墙：校门直道两旁种有落叶树，外侧立有约3公尺高的抗魔砖墙。
  - 中央广场：道分三叉，中央竖立「初代校长兼第56代魔术公会总帅芙拉・克罗蒂亚」的长袍雕像。
  - 正面校舍群：包含6栋以上如要塞般的教学楼，以及设在修练楼内的魔术实验训练室（内部铺设大型魔法阵、抗魔砖墙）与户外魔术运动场。
  - 左侧建筑群：红色屋顶的多窗阳台建筑群，为学生宿舍。
  - 右侧建筑群：蓝色屋顶建筑，为教职员办公楼（设有来访接待柜台与各等级会客室）。
  - 其他校区设施：设有供专项研究的研究楼（独立研究室）、藏书丰富的大型图书馆、大型学生餐厅等。
- 原文依据："在极为广大的校园里，矗立着好几排连绵不绝的砖造楼房，中央甚至有一栋类似城堡的建筑物。……行道树的外侧耸立着高度大约有三公尺的砖墙。……「这些全都是用抗魔砖建造的。」……中央有一座身穿长袍的女性雕像。雕像上贴着「初代校长，第五十六代魔术公会总帅芙拉・克罗蒂亚」的名牌……正面道路前方有一整片宛如要塞的巨大校舍群。光是视线所及的范围，就有六栋以上的建筑物。……左手边有好几栋红色屋顶的建筑物。……看阳台上晒着衣服的样子，可能是学生宿舍吧。……右手边是蓝色屋顶的房子……教职员楼……修练楼的训练室，也就是用来进行魔术实验和考试的场所。"

## 二、组织与势力
- 名称：涅里斯公国
- 内容：魔法三大国之一，与拉诺亚、巴榭兰特结盟。在夏利亚西侧设有享誉大陆的「涅里斯魔道具工房」。
- 原文依据："然而拉诺亚王国和巴榭兰特公国、涅里斯公国缔结了同盟……「涅里斯魔道具工房」"

- 名称：魔术公会总部
- 内容：跨国魔术组织的最高中枢，设在夏利亚市中心，采用最新型抗魔砖建造；对独家秘方的抗魔砖生产与销售实行完全垄断。
- 原文依据："城镇中央是以最新式抗魔砖建造的魔术公会……听说抗魔砖的制造和贩卖都由魔术公会独占……"

- 名称：拉诺亚魔法大学（制度与教学架构）
- 内容：
  - 院系设置：开设魔术科系、普通文化课程、贵族科系、商人算术系、军事科系（学生极少）。虽无帝王学与精神医学课程，但治愈与解毒魔术师资力量雄厚，魔术教师团队水准大幅凌驾于阿斯拉王立学校之上。
  - 学员结构与包容性：广招各界人士，涵盖十岁幼童至百岁老人，各民族、各亚人种族及受诅咒者兼收并蓄。
  - 学费标准：常规入学金加全部学费一次付清约阿斯拉金币3枚；考核优异者可减免，家庭贫困者可申请毕业后延期缴付。
  - 特别生权力与义务（以鲁迪乌斯为例）：免除全部学费与日常听课义务（亦可随班选修）；每月仅需参加一次例行班会；自由调配时间借用研究室、训练室、泡图书馆、外出当冒险者或赴公会发表成果；严禁在拉诺亚王国境内犯罪、破坏校园或侮辱魔术公会。
  - 校内自治与精英：设有学生会组织，四年级的天才特别生菲兹为学生会干部成员。
- 原文依据："拉诺亚魔法大学和一般的魔术学校不同，也有开设普通学校的课程……此外，还有以贵族为对象的科系，以及适合商人的算术系等等。……虽然没有能教导帝王学的人才，不过在魔术方面的教师阵容，我们有自信甚至能远远凌驾于阿斯拉的王立学校之上。……基本上也开设了教导军事的科系，但是几乎没有学生。……如果是治愈、解毒魔术方面，本校拥有引以自豪的许多优秀教师……"、"在这间学校里，从十岁前后的小朋友到超过百岁的人物都可以看到。基本上似乎年轻人占多数，不过年龄各异，种族也不同。"、"如果一口气付清入学金与到毕业为止的学费，大约是阿斯拉金币三枚。……只要按照规定接受考试并获得优秀成绩，似乎可以减免部分学费和入学金。还有如果实在没钱，好像也可以毕业后再补缴。"、"基本上特别生的学费可以免除，而且根据情况，也可以不必去上课。……只要出席每个月一次的班会，基本上在学校里面做什么都是个人自由。"、"其实那个班级里也有一名能使用无咏唱魔术的学生。……今年还进入学生会……菲兹同学"

## 三、力量体系 / 魔法 / 技能
- 名称：乱魔
- 规则：极其罕见的反魔术对抗技能。在对手聚集魔力发动魔术的刹那施展，能扰乱敌方魔力构筑使其魔术当场崩溃流产。在针对魔术师的实战中效果拔群（此前仅龙神奥尔斯帝德使用过，魔法大学师生均未曾听闻见识）。
- 原文依据："「『乱魔』！」我对菲兹使出乱魔。「咦？怪了？为什么？」发现应该要使出的魔术却没有出现，菲兹以惊讶表情看着自己魔杖的前端。"、"「那是叫作乱魔的魔术，你没听说过吗？」菲兹摇了摇头。他似乎没听说过乱魔，这魔术是不是比较冷门？不过我个人认为在碰上其他魔术师的对人战斗时，这招是极为有效的魔术……话说起来，自己虽然当了两年的冒险者，却没有看过奥尔斯帝德以外的人使用这一招。"

- 名称：实战复合魔法阵（圣级治愈 + 上级结界）
- 规则：魔法大学修练楼训练室内设有的半径五公尺复合阵式：
  - 上级结界边缘：单向性屏障，仅对魔术伤害产生绝缘与抵御效果（常规魔术无法击穿），但不阻挡物理通过，人手和物理实体武器可自由穿透。
  - 阵内圣级治愈术：阵内人员受到常规外伤攻击时会即时受到圣光沐浴瞬刻愈合；但对瞬间致命击杀（当场死亡）完全无效。
- 原文依据："地板上有四个半径五公尺左右的魔法阵排成一横列。……「那个魔法阵是？」「圣级治愈术的魔法阵，即使受到攻击也会瞬间回复。」「而且外缘部分还设置了上级的结界，一般的魔术攻击无法撼动。」"、"我试着敲打外缘部分，结果手却直接穿了出去。「鲁迪乌斯先生，这个魔法阵只会针对魔术产生抵抗效果。」「也就是物理攻击可以通过吗？」"、"治愈魔术并非万能。虽然这是可以瞬间治好简单伤口的圣级治愈魔术，但是如果被刚刚的岩炮弹直接击中，也有可能立刻死亡。圣级治愈魔术无法治好当场死亡。"

- 名称：岩炮弹（精密高穿透运用）
- 规则：土系攻击魔术。能够自由微调形体尺寸（如缩小至指尖大小）、转速与初速；经高密度压缩与超高速旋转发射后，具备极高动能物理贯穿力，能正面突破上级魔术结界并贯穿粉碎抗魔砖墙。
- 原文依据："讲来讲去，结果还是岩炮弹最好用。可以瞄准精确目标又具备强大威力，想调节强度或是连续发射也很容易。"、"大小设定为小指的指尖般大。旋转速度和发射速度都偏高……岩炮弹发出咻咻声往前飞，通过菲兹脸颊旁边后，发出「锵」的轻快声响并突破结界，直接刺进用抗魔砖建造的墙壁，打得瓦砾四散，这才总算停下。"

- 名称：预知眼（魔眼）
- 规则：能在瞳孔中直接捕捉并显示对手未来数秒行动轨迹与施法预兆的瞳术。
- 原文依据："号令一下，我的魔眼就显示出菲兹举起魔杖的影像。"

- 名称：诅咒
- 规则：世界中存在难以用常规解毒消弭的异化身体诅咒现象。如艾莉娜丽洁身负的诅咒：若未定期与男性行房排出积聚魔力，身体便会剧烈发抖、脸色铁青并衰竭致死。
- 原文依据："身体因为不明原因而不断发抖，脸色铁青，而且看我的眼神很恐怖。……后来问了详情，这好像是某种「诅咒」，没有定期和男人炒饭就会死掉的「诅咒」。"

## 四、种族 / 生物
- 名称：长耳族（菲兹的外貌特征）
- 特征：特征为长耳，白发、体型矮小瘦弱、缺少肌肉，手掌触感细腻柔软，声音清亮偏高。
- 原文依据："对方有一头白色短发，脸上戴着墨镜。耳朵很长，是长耳族吗？个头不高，不，或许只是因为年纪还小吧。大概十三岁左右的感觉。看起来就是秀才类型，彻底欠缺肌肉。"、"他的手掌很柔软，是不是没有拿过剑呢？"

## 五、物品 / 道具 / 武器
- 名称：抗魔砖
- 说明：具备高阶魔力抗性的特殊建材，可硬抗大范围攻击魔术。生产制作工艺属最高机密，制造与贩售由魔术公会全权独占。在阿斯拉王国仅限王都使用，属于极昂贵物资；但在魔法三大国及公会设施被极为普遍地大量采用。
- 原文依据："「这些全都是用抗魔砖建造的。」……所谓的抗魔砖正如其名，是一种对魔力有抗性的砖块，似乎连大规模的攻击魔术也能够承受。……听说抗魔砖的制造和贩卖都由魔术公会独占，在阿斯拉王国是只有王都才会使用到的昂贵物品。之前在米里斯神圣国和王龙王国都没看到，但是来到魔法三大国后却经常看到，甚至连各处的冒险者公会的墙壁都有使用。"

- 名称：魔力结晶
- 说明：主要产自迷宫深处的球形高纯度结晶体，玩具弹力球大小。在世界全境均具备极高硬通货结算功能，无需折价即可直接视作支票兑现，单枚市价在阿斯拉金币10枚以上。
- 原文依据："此外，我知道她的背包里放着好几个魔力结晶。之前曾经请她让我看过一次，是呈现漂亮球形的魔力结晶，大小跟弹力球玩具差不多。如果卖掉，好像可以卖得阿斯拉金币十枚以上的价钱。我本来还很好奇她是从哪里得到这种东西，不过艾莉娜丽洁原本是以探索迷宫为主的冒险者。所以我擅自推测她大概是把以前找到的魔力结晶当成支票般随身携带吧。因为魔力结晶即使没有事先变卖，也可以在任何地方换成现金。"

- 名称：傲慢水龙王
- 说明：鲁迪乌斯从十岁起持有并使用至今的高阶法杖权杖。
- 原文依据："我也举起自己的权杖，从十岁起就一直使用至今的「傲慢水龙王」，最近甚至还想帮这家伙取名为夏琳。"

- 名称：阿斯拉金币（购买力补足）
- 说明：全大陆购买力最高的法定硬币。在北方大地仅需一枚金币即可维持很长一段时间的悠闲生活；三枚金币即可完全结清魔法大学全期学费。
- 原文依据："阿斯拉金币是这世界最高价的金币。以这一带来说，大概只要一枚就可以游手好闲好一阵子。"、"如果一口气付清入学金与到毕业为止的学费，大约是阿斯拉金币三枚。"

## 六、历史 / 传说 / 事件
- 事件名：芙拉・克罗蒂亚创立魔法大学
- 内容：第56代魔术公会总帅芙拉・克罗蒂亚创办了拉诺亚魔法大学并担任初代校长，其长袍雕像立于校园正中央广场。
- 原文依据："雕像上贴着「初代校长，第五十六代魔术公会总帅芙拉・克罗蒂亚」的名牌，这就是初代校长的雕像吧。"

## 七、社会规则 / 习俗 / 文化
- 成年年岁与冒险者群体心态：
  - 世界主流社会普遍以15岁界定为成年，绝大多数冒险者在15岁前后注册从业。未成年即在行内崭露头角并攀升至B级或A级的高阶冒险者，通常自尊心与争胜心极强。
  - 原文依据："虽然会因为种族和国家而有所不同，但这世界基本上是满十五岁算成年，大部分冒险者也差不多是在这年纪出道。不过，还是有不少人在成年前就踏入这一行。话虽如此，成年前就当上冒险者的人很少会爬到高层级。至于那些为数稀少的「能成功爬上高层级的年轻人」，多半是自尊心的化身。"

- 学府风纪规则与地域文化对比：
  - 拉诺亚魔法大学校规对男女交往与性观念持高度包容态度，只要非强迫威胁，校方认可成年与青年自愿的亲密关系（因学生跨种族、跨年龄且存在诅咒特质者众多）；相比之下，米里斯神圣国首都米里希昂的学校对此则实行全盘禁止。
  - 原文依据："「艾莉娜丽洁小姐，看来只要不是强制，校方似乎允许一定程度的自由行为。」「真是美好的学校。你知道吗？米里希昂的学校是全面禁止喔。」……在这间学校里，从十岁前后的小朋友到超过百岁的人物都可以看到。基本上似乎年轻人占多数，不过年龄各异，种族也不同。既然如此，当然会有各式各样的常识。像艾莉娜丽洁这种身受诅咒的人也不在少数。"
