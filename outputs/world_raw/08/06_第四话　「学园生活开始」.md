# 第四话　「学园生活开始」 世界设定提取

## 一、地理与场所
- 名称：拉诺亚魔法大学宿舍餐厅及其餐点
- 内容：宿舍餐厅按照学年与身份排定大致就餐顺序与楼层，提供适合多种族习惯的丰富菜色，其中包括模仿日式油炸肉食的“七星烧”，以及类似咖哩风味的“科里浓汤”。
- 原文依据："听说宿舍的餐厅有按照学年和身分来分别排出吃饭的顺序，不过时段没抓得那么精准似乎也不要紧，毕竟早上很忙嘛。……这间餐厅有很多相当合我口味的食物。例如那个模仿日式炸肉的七星烧，还有很像咖哩但其实是别种东西的科里浓汤等等。虽然距离我喜欢的食物还差一步，不过可以吃到类似的东西，我个人已经满足。我想，这里一定是准备了让不同种族都能够吃到适当食物的菜色吧。"

## 二、组织与势力
- 名称：米里斯教团对特定魔术体系的垄断与异端审问
- 内容：米里斯教团独占垄断了神击魔术与结界魔术的全部教授及传播权利。两年前魔法大学吞下特定苛刻条件后，教团才获准大学开设初级课程；中级以上魔术（如“物理障壁”）严禁大学传授。即使教师自身掌握亦不得擅自外传，一旦违规泄密将遭到米里斯教团跨国追捕，甚至被押解接受残酷的异端审问。
- 原文依据："才知道不管是神击魔术还是结界魔术，相关权利都掌握在米里斯教团手中，因此魔法大学的课程似乎只到初级。「物理障壁」属于中级，被告知在此无法学到。老师本身会用，要教人也没有问题，但是那样做好像是违规行为。要是犯下违规行为而且消息曝光，就会遭到米里斯教团追捕，甚至有可能必须接受异端审问。顺便说一下，据说以前这两种魔术连初级都被禁止传授，是学校在大约两年前吞下了某个条件后才总算获得许可。"

- 名称：特别生与校内不良学生势力（莉妮亚与普露塞娜不良团伙）
- 内容：莉妮亚与普露塞娜是大学内不良学生的领袖头目。二年级特别生札诺巴入学初期四处挑起暴力打斗，被莉妮亚与普露塞娜以二打一击败后沦为跟班小弟。菲兹一年级时，两人曾找爱丽儿找碴，菲兹在决斗中以一打二击败两人。此外特别生群体怪人频出：克里夫性格好斗易起冲突、塞伦特入学初期频繁惹事、艾莉娜丽洁被传闻为袭击男学生的长耳族冒险者。
- 原文依据："「或许你没听说，不过他是从刚入学就到处引发冲突的暴力问题学生。」……「结果，他被莉妮亚和普露塞娜这两个……类似不良学生首领的人给打败后，札诺巴就安分下来了。」……「因为……我们一年级的时候，两人主动对爱丽儿大人找碴，那时是我在决斗中打倒了她们。」……「像那个叫克里夫的人也很容易和别人起冲突，塞伦特在刚入学的时期似乎也经常引发问题。还有，听说今年的一年级新生里有个冒险者出身的奇怪长耳族会袭击男学生。」"

## 三、力量体系 / 魔法 / 技能
- 名称：神击魔术
- 规则：专门克制鬼魂类与无实体气体型魔物的魔术体系。原理类似于直接用魔力撞击目标，但纯魔力直接砸中无法造成实质伤害，需依靠特定的魔力作用机制。施法者必须具备洞悉看透敌人本质底细的能力，根据魔物种类针对性切换魔术。其权利完全受米里斯教团封锁，大学仅授初级基础理论与咏唱咒文。（注：一流剑士连幽灵也能直接斩杀，无需看透魔物虚实）。
- 原文依据："所谓的神击魔术，是指对鬼魂类以及没有实体的气体型魔物特别有效的魔术。以理论来说，是不是类似乱魔呢？感觉像是直接拿魔力去砸在敌人身上。不过呢，直接拿魔力攻击并无法造成任何伤害，因此其中有什么特殊作用，只是我没弄懂这部分。……据说必须根据敌人来改变使用魔术的种类。如果想成为优秀的神击魔术师，看透敌人底细的能力似乎也很重要……顺道一提，一流的剑士似乎连幽灵也可以照砍不误，根本连看透都省了。"

- 名称：结界魔术
- 规则：构建防御或关押屏障的魔术体系。主要依托魔法阵构筑，初级可用咏唱发动。初级结界为「魔力障壁」，能在身前展开抵挡并减轻火焰、寒气等魔术属性效果的防护面（抗魔砖与宿舍暖气均为其延伸应用）；中级结界「物理障壁」能抵御物理攻击，但在校内被禁止传授。结界分为对物理型与对魔法型，圣级以上能够设置兼具两者的双重复合结界。用途包括保护自身与监禁目标。大学课程重点偏向如何解构破除结界。
- 原文依据："至于所谓的结界魔术就如同字面，是制作结界的魔术。基本上会使用魔法阵，不过如果是初级，也可以用咏唱发动。在初级的课程中，会学习如何在自己身前立起一道针对魔术方面的屏障，也就是「魔力障壁」。「魔力障壁」具备能隔绝、减轻火焰和寒气的效能。抗魔砖以及宿舍暖气的原理大概都是这魔术的进化型吧。……「物理障壁」属于中级，被告知在此无法学到。……在授课时好像反而会把焦点放在如何破除结界这部分上。结界分为对物理型与对魔法型，到了圣级以上，听说就能够设置同时兼具双方特性的结界。此外，结界的用途也是各式各样，例如有用来保护自身的结界，也有用来关住某个对象的结界。"

- 名称：转移魔术与“神隐现象”
- 规则：转移魔术在世界上被严格列为“禁术”，相关文献在公开图书馆中被严加封锁或语焉不详。历史上除菲托亚领地大灾害外，曾发生过多起小规模“神隐现象”——某人突兀消失后，出现在其他异地或原地重现。转移后的传送落点可能存在某种内在倾向性规则。
- 原文依据："虽说我姑且有在到处翻找文献，然而或许是因为转移魔术本身被指定为禁术，书上并没有详细的记载。""「我查到过去似乎发生过好几次和菲托亚领地类似的事件。」我把查到的线索告诉菲兹学长。……「虽然规模没有菲托亚领地那么大，不过似乎发生过有人突然消失又突然回来的事件。」也就是所谓的「神隐现象」。一个人突然消失，后来出现在其他地方，或是又在原来地方再度出现。虽然算不上是频繁……但是这世界好像偶尔会发生这种事。""要是可以厘清被转移后的落点有什么倾向，应该会更容易找到人……"

- 名称：乱魔
- 规则：破坏对手术式、扰乱魔力的特殊魔术技巧，是克制无咏唱魔术的强力奇袭手段。
- 原文依据："因为我能够使用「乱魔」，所以对付使用无咏唱魔术的对手会特别有利，毕竟那是破坏对手特技的奇袭攻击。如果在对方明知我会使用乱魔的情况下交手，自己不见得可以取胜。……「那个魔术是叫作乱魔吗？真厉害，下次也教我吧。」「好啊，没问题。」"

## 四、种族 / 生物
- 名称：鬼魂类 / 气体型魔物
- 特征：没有实体物理形态的魔物，常规物理武器与未经转换的纯魔力撞击对其无法生效，但受到神击魔术克制，亦能被顶级一流剑士以剑术直接斩灭。
- 原文依据："所谓的神击魔术，是指对鬼魂类以及没有实体的气体型魔物特别有效的魔术。……一流的剑士似乎连幽灵也可以照砍不误，根本连看透都省了。我以冒险者身分行动的期间，曾经看过好几次幽灵类的魔物……"

## 五、物品 / 道具 / 武器
- 名称：七星烧
- 说明：魔法大学宿舍餐厅根据异界菜色灵感制作的食品，模仿日式炸肉排风味。
- 原文依据："例如那个模仿日式炸肉的七星烧，还有很像咖哩但其实是别种东西的科里浓汤等等。"

- 名称：科里浓汤

- 原文依据："还有很像咖哩但其实是别种东西的科里浓汤等等。"

- 名称：菲兹的日常行头配饰
- 说明：常年佩戴的大墨镜（绝不摘下）、学校制服、时尚剪裁披风、结实皮靴与合手白手套。
- 原文依据："白发搭配墨镜，身穿学校指定的制服搭配颇有时尚感的披风，还有似乎很耐用的靴子以及刚好合手的白手套。我见过菲兹学长好几次，感觉他总是这副打扮。……菲兹学长从来不曾拿下墨镜。连一次都不曾拿下过，不管什么时候都没有例外。"

## 六、历史 / 传说 / 事件
- 事件名：菲兹与莉妮亚、普露塞娜的校内决斗
- 内容：爱丽儿与菲兹入学一年级时，不良头目莉妮亚与普露塞娜主动找爱丽儿挑衅，菲兹在公开决斗中以一敌二打败两人，保持了在校一对一从未落败的不败战绩。
- 原文依据："「因为……我们一年级的时候，两人主动对爱丽儿大人找碴，那时是我在决斗中打倒了她们。」「一打二？」「嗯。所以啊……你有可能会被迁怒……」……「在这间学校里，没有人能在一对一的情况下打败我。就算我看起来是这副样子，至今也从来没有输过。」"

- 事件名：北神二世雷白克传说
- 内容：北神二世的名字为雷白克。
- 原文依据："「菲兹学长你的姓氏该不会是雷白克吧？」「咦？雷白克……这好像是北神二世的名字？我怎么可能叫雷白克，当然不是。而且基本上我根本没有姓氏，又不是贵族。」"

## 七、社会规则 / 习俗 / 文化
- 内容：大学宿舍允许携带奴隶与王公仆役入宿的特例制度：经校方许可，学生可将个人奴隶带入宿舍居住。王族或大贵族亦可通过权势通融将随从仆役（如女仆）带进宿舍，但若仆从引发事故纠纷，主人须承担连带全责。菲兹长住女生宿舍即依仗爱丽儿的阿斯拉王族特权及个人信赖。
- 原文依据："基本上只要取得许可，可以把奴隶带进宿舍里。就算想带进宿舍的人员不是奴隶，只要申请者是拥有权势的王族或贵族，多少有通融的余地，就像男生宿舍这边也有贵族带了女仆。只是万一那些女仆和仆人引起什么问题，当然主人必须负起责任。虽然菲兹学长的身分是学生而非仆人，不过能通融大概是靠着爱丽儿公主的领袖魅力和身为阿斯拉王族的权力，再加上菲兹学长个人也受到信赖吧。"

- 内容：平民无姓氏阶级文化：在社会阶级规则中，平民阶层普遍没有家族姓氏，仅贵族等特权阶级拥有姓氏。
- 原文依据："「而且基本上我根本没有姓氏，又不是贵族。」"

- 内容：转移魔术被列为全大陆禁术：转移魔术被世界各大势力公认为危险禁忌秘术，公开书籍文献对其实行严格管控封锁。
- 原文依据："虽说我姑且有在到处翻找文献，然而或许是因为转移魔术本身被指定为禁术，书上并没有详细的记载。"

## 九、角色认知 vs 客观事实
- 角色以为：鲁迪乌斯以为札诺巴是性格老实纯朴的人，在班里一直被不良首领莉妮亚与普露塞娜欺凌霸凌。
- 原文是否暗示另有真相：是。菲兹指出札诺巴入学起就是四处找人打架斗殴的暴力问题儿童，莉妮亚与普露塞娜是作为不良学生老大联手二打一将其制伏，札诺巴纯属因决斗战败才听命加入对方阵营。
- 原文依据："「或许你没听说，不过他是从刚入学就到处引发冲突的暴力问题学生。」听到札诺巴是整天打架的问题学生，我露出苦笑。不知道该说是果然还是该怎么说，看样子札诺巴并不是被霸凌的对象。……「结果，他被莉妮亚和普露塞娜这两个……类似不良学生首领的人给打败后，札诺巴就安分下来了。」"

- 角色以为：全校传闻菲兹是极度冷漠、一言不发的“沉默的魔术师”。
- 原文是否暗示另有真相：是。菲兹面对鲁迪乌斯时不仅主动打招呼、热情协助转移调查，还腼腆开朗，并解释自己只是在不熟的外人面前性格怕生，并非真正的冷酷寡言。
- 原文依据："「话说回来，学长跟我讲话时都很正常呢。」「……嗯？什么意思？」「我之前有听说过你非常沉默寡言。」「那个……因为……我这人比较怕生。」话是这样说，但我怎么记得是他主动找我搭话？"

- 角色以为：鲁迪乌斯将菲兹当作真正的男性少年（“一个充满谜团的男人”），并对面对其笑容和柔软双手时产生的心跳加速感到困惑与自我怀疑。
- 原文是否暗示另有真相：是。前章闲话读者视角已明示菲兹实为女性希露菲叶特，因护卫职责女扮男装并佩戴墨镜隐藏身份，鲁迪乌斯受其男装与假身份误导将其认定为男性。
- 原文依据："一个充满谜团的男人──菲兹学长。……这表情和又小又软的手掌，让我心跳加速。自己居然对男人……不，怎么可能。只是一时昏了头吧。"

- 角色以为：菲兹声称自己根本没有姓氏，不是贵族。
- 原文是否暗示另有真相：是。菲兹身为平民确实没有贵族家族姓氏，但他其实隐藏了自己的本名“希露菲叶特”，以此维持身份秘密。
- 原文依据："「而且基本上我根本没有姓氏，又不是贵族。」"
