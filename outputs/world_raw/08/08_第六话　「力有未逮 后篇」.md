# 第六话　「力有未逮 后篇」 世界设定提取

## 一、地理与场所
- 名称：北方大陆 / 中央大陆北部
  - 内容：在北方大陆，奴隶买卖在几乎所有国家都是完全合法的，部分地区甚至予以奖励。奴隶事业是中央大陆北部的重要商业支柱之一，甚至达到维系国家存续的程度；且北方奴隶以身体健壮、优秀闻名。
  - 原文依据："在中央大陆南部和米里斯大陆上，奴隶买卖只能勉强经营，在这个北方大陆却完全不同。到了这一带，奴隶买卖几乎在所有国家都是完全合法，有些地方还予以奖励。因为奴隶事业是中央大陆北部的重要商业行为之一，甚至到了没有奴隶事业会让国家无法维持下去的地步。"、"此外，由于北方奴隶通常身体健壮又优秀，因此还有特地从其他国家来此购买的人。"
- 名称：阿斯拉王国
  - 内容：与贫困无缘的丰饶国度。即便处于社会最底层也不会挨饿；北方奴隶商人与阿斯拉王国建有渠道，会将容貌出众或能力杰出的奴隶销往阿斯拉王国（被视为奴隶中的赢家）。
  - 原文依据："不过呢，奴隶商人中也有些和阿斯拉王国建立起关系。一部分容貌出众，或是拥有杰出能力的奴隶可能会被卖到阿斯拉王国。阿斯拉王国是和贫困无缘的土地，就算在阿斯拉王国里处于最底层，也不会为饥饿所苦。能前往阿斯拉王国的奴隶是赢家组"
- 名称：魔法都市夏利亚奴隶市场（商业区）
  - 内容：魔法都市内共有五处奴隶市场，水准参差不齐。其中一处信誉极差（在户外兜售濒死奴隶）；正规奴隶市场设在土石结构的室内建筑中，内部常年燃烧火堆供暖，以防止待售的赤裸奴隶受冻患病。
  - 原文依据："在规模的城镇中会有好几处奴隶市场，魔法都市里有五个。这五个奴隶市场的水准有好有坏，其中有一处被形容成「绝对不要去会比较好」。听说那里是可信度较低的奴隶市场，会若无其事地把快要病死的奴隶强制推销给客人。"、"在北方大地，奴隶市场多位于建筑物内部。……一进入室内，身体立刻被一股热气包围。原来是建筑物内部到处都有火堆。然后，大概可以看到八个展示台，上面都排列着没穿衣服的奴隶。所以简而言之，就是因为太冷所以没有在户外买卖。奴隶会冷到感冒。"
- 名称：瑞姆商会奴隶贩售处
  - 内容：由三栋相连的土石大型房舍构成，设有警卫把守。包含八处展示卖场、咨商处以及后方的奴隶仓库。仓库内排列着半坪大小的带轮铁笼，通常一笼关押一至二人。
  - 原文依据："类似的房舍有三栋彼此相连，入口大门上方写着「瑞姆商会　奴隶贩售处」。"、"这八处卖场全都属于瑞姆商会旗下的奴隶商人，上面陈列并贩卖着由各地蒐集或买来的奴隶。"、"从市场后方前往隔壁的建筑物──奴隶仓库。虽然说是仓库，实际上却只是排列着装有轮子的铁笼，里面关着奴隶。铁笼的空间大约只有半坪，一个铁笼里基本上会关着一到两人。"
- 名称：青龙山脉山脚（米里斯大陆）
  - 内容：矿坑族的故乡与聚居地，位于米里斯大陆大森林南侧青龙山脉脚下。
  - 原文依据："矿坑族基本上是米里斯大陆的居民，住在大森林南侧，青龙山脉的山脚下。真的是除非遭到绑架，否则不会来到这附近。"
- 名称：王龙山脉
  - 内容：部分离开米里斯大陆的矿坑族会前往王龙山脉依靠山地矿业谋生工作。
  - 原文依据："矿坑族中，有一部分的人认为只要有山就可以活下去。如果只是离开米里斯大陆，在王龙山脉工作倒是还没问题；但是偶尔会有些没怎么搞清楚状况的家伙跑来北部，结果没办法进入山里所以走投无路。"
- 名称：魔法三大国
  - 内容：中央大陆北部的三个国家同盟/区域概念，包括拉诺亚王国在内，属于即使没有奴隶产业也能自立的国家。
  - 原文依据："包括拉诺亚王国在内的「魔法三大国」是没有奴隶也能立足的国家，不过只要再往东方移动，有好几个会定期把村里小孩卖给奴隶商人的贫困村庄。"

## 二、组织与势力
- 名称：瑞姆商会（多梅尼商店）
  - 内容：北方规模庞大的奴隶贸易商会，旗下拥有多家分支商号（如多梅尼商店，分店长为婓布里特），承办不同档次与种族的奴隶买卖。
  - 原文依据："入口大门上方写着「瑞姆商会　奴隶贩售处」。"、"「幸会，我是瑞姆商会旗下，多梅尼商店的分店长，婓布里特。」"
- 名称：盗贼公会
  - 内容：地下黑道组织，坊间传闻其在暗中设有奴隶养殖场。
  - 原文依据："还有谣言说盗贼公会私底下建立了类似奴隶养殖场的地方。"
- 名称：北方战士团 / 佣兵团
  - 内容：北方大陆的武装组织，会从奴隶商人手中低价采购贫困村庄卖出的儿童与奴隶，充当消耗性战争奴隶。
  - 原文依据："像那样的奴隶有时候会被北方大地的战士团、佣兵团甚至国家买下，当成战争用的奴隶后用完就丢。"
- 名称：魔法大学宿舍管理部门
  - 内容：魔法大学对学生宿舍有严格管理规章，若要携带奴隶入住必须申请许可证（王族身份更易获批）。
  - 原文依据："这也是因为不管怎么样，一旦购买奴隶并带回学校宿舍就必须申请许可证，而王族会比较容易取得许可证。"

## 三、力量体系 / 魔法 / 技能
- 名称：无咏唱魔术的学习年龄界限
  - 规则：越年幼越容易掌握无咏唱魔术；一旦超过十岁，几乎不再可能学会无咏唱魔术。
  - 原文依据："「因为小时候比较容易学会无咏唱魔术。」「咦？是那样吗？」「嗯，我想差不多到了十岁就几乎没有可能学会了。」"
- 名称：魔力总量成长机制（反驳固有定论）
  - 规则：世间教科书虽记载“魔力总量天生注定”，但这属于误解；实情是十岁以后魔力总量几乎停滞不再增长。若从幼年（约五岁左右）开始持续消耗与运用魔术，魔力总量可实现爆炸性成长。
  - 原文依据："「啊，还有如果从五岁左右开始使用魔术，可以让魔力总量爆炸性增加。」"、"「可是我听说在这个世界，魔力总量是天生注定。」「那是错误的理论。教本上的确有写那种事，不过我认为那是因为超过十岁以后魔力就几乎不会再成长，所以造成这种误解。」"
- 名称：治愈与解毒魔术的规则
  - 规则：治愈魔术能治疗创伤但无法恢复体力；解毒魔术能祛除毒素与常规疾病。奴隶商人在交付货物时一般会附带施加解毒魔术。
  - 原文依据："还对她施展解毒魔术。不过治愈魔术没办法恢复体力，所以等一下要带她去吃饭。"、"基本上在您购买时会由我方负责对她施加解毒魔术，但还是不太推荐。"
- 名称：神子怪力体质（防御与蛮力）
  - 规则：神子（如札诺巴）拥有压倒性的绝对蛮力与体魄防御，仅凭身体抖动便能震飞全身甲胄的警卫，常人根本无法制约。
  - 原文依据："只见男子受到札诺巴用铁爪功伺候，还被抬了起来。……就在旁边的警卫立刻冲上来打算制服札诺巴，札诺巴却纹丝不动。反而只是稍微抖动身体，就把警卫都弹飞出去。哎呀，真是强大的力量。一个有点像阿宅的高个子瘦皮猴把健壮的警卫抓起来用力甩动。这就是神子的力量吗！"

## 四、种族 / 生物
- 名称：矿坑族（矮人一族）
  - 特征：原居米里斯大陆青龙山脉山脚，双手大多灵巧且具备艺术理解力，擅长锻造铁器与制作装饰品；视山地为生存根本；幼年期只通晓兽神语，在北方大陆极度罕见。
  - 原文依据："「讲到双手灵巧的种族，果然是矿坑族吧？」「是啊，能使用土魔术的矿坑族是最好的选择……」"、"「因为矿坑族那些家伙有很多人都双手灵巧又能理解艺术。」"、"矿坑族基本上是米里斯大陆的居民，住在大森林南侧，青龙山脉的山脚下。"、"双亲都是矿坑族，父亲是铁匠，母亲会制作装饰品。所以关于双手的灵巧度，只要有遗传到双亲，应该是可以期待。只是，语言方面只懂兽神语。"、"矿坑族中，有一部分的人认为只要有山就可以活下去。"
- 名称：贝卡利特大陆人种
  - 特征：天生拥有非日晒形成的深褐色皮肤。
  - 原文依据："是个拥有褐色皮肤的男子，那颜色不光是因为日晒。我猜他可能出身于贝卡利特大陆，或是双亲其中之一是贝卡利特大陆的人。"
- 名称：长耳族（精灵族）
  - 特征：体型高挑纤细，容貌出众，长耳具备随情绪下垂等生动反应。
  - 原文依据："所谓的长耳族拥有正中喜好的外型，全都是些体型高挑纤细的帅哥美女。"、"菲兹学长泄气地把耳朵往下垂。"

## 五、物品 / 道具 / 武器
- 名称：铁项圈与脚镣
  - 说明：奴隶贸易中用于束缚、看押和标识奴隶的铁制刑具装备。
  - 原文依据："这是一个被套上铁项圈和脚镣的小孩。"
- 名称：阿斯拉大铜币
  - 说明：阿斯拉王国法定货币之一，一枚阿斯拉大铜币足以购买一名健康状况恶劣的幼年矿坑族奴隶。
  - 原文依据："阿斯拉大铜币一枚，这就是少女的价钱。"

## 六、历史 / 传说 / 事件
- 事件名：鲁迪乌斯讨伐脱队龙
  - 内容：鲁迪乌斯在去年的冒险者时期讨伐了脱队龙，凭借A级冒险者“泥沼”的名号在北方大陆商界广为流传。
  - 原文依据："「哦哦！您就是泥沼吗！我曾经听过传闻，说您在去年打倒了脱队龙。」「那只是因为运气好，而且当时对手也已经很衰弱。」A级冒险者「泥沼的鲁迪乌斯」这名字来到这一带，似乎总算还有点名气。"
- 事件名：札诺巴误杀弟弟（拔头王子事件）
  - 内容：札诺巴早年因无法控制神子天生怪力，失手杀死弟弟朱利亚斯，从而被称为“拔头王子”。
  - 原文依据："「那么，就叫作朱利亚斯。」札诺巴平静地提议……「是的，朱利亚斯是本王子以前因为力道拿捏错误而不小心杀掉的可怜弟弟。」之前听说过札诺巴勒死自己弟弟，还被称为拔头王子"

## 七、社会规则 / 习俗 / 文化
- 内容：北方大陆奴隶贩售文化与运作
  - 规则：北方大陆奴隶买卖完全合法化且规模巨大。奴隶来源包括战乱孤儿、因负债被卖儿童、自卖救家者、贫困村庄定期进贡变卖等；待售奴隶通常全身赤裸供买家检验体格骨骼，交易时通常会提供解毒魔术服务。
  - 原文依据："在中央大陆南部和米里斯大陆上，奴隶买卖只能勉强经营，在这个北方大陆却完全不同。到了这一带，奴隶买卖几乎在所有国家都是完全合法……人会变成奴隶的理由有很多。例如在战争中成了孤儿的人，因为作物歉收负债累累而被父母卖掉的小孩，或是为了拯救家人而卖掉自己的人……"、"大概可以看到八个展示台，上面都排列着没穿衣服的奴隶。"
- 内容：矿坑族命名习俗
  - 规则：矿坑族传统在七岁前没有专属的个人名字，仅以“某某与某某之子”代称；满七岁后方根据个人喜好、憧憬或擅长的事物正式取名。
  - 原文依据："「矿坑族在七岁之前都不会有正式的名字。」「正式的名字？」「嗯。矿坑族在七岁前没有自己的名字，等到年满七岁的时候，会依据自己喜欢、憧憬，或是擅长的事物来取名。」"、"「……圣铁的巴萨尔和美丽雪棱的莉莉特拉之子。」"
- 内容：宿舍奴隶许可证制度
  - 规则：魔法大学学生购买奴隶并安置在校舍必须向校方提出申请并获得许可证。
  - 原文依据："这也是因为不管怎么样，一旦购买奴隶并带回学校宿舍就必须申请许可证，而王族会比较容易取得许可证。"

## 九、角色认知 vs 客观事实
- 角色以为：世间大众与教本皆记载“魔力总量天生注定无法改变”。
- 原文是否暗示另有真相：是。菲兹指出此为认知偏差，实际上是因为十岁后魔力成长停止所导致的错觉；十岁前（五岁起）坚持使用魔术可使魔力总量暴增。
- 原文依据："「可是我听说在这个世界，魔力总量是天生注定。」「那是错误的理论。教本上的确有写那种事，不过我认为那是因为超过十岁以后魔力就几乎不会再成长，所以造成这种误解。」"
- 角色以为：鲁迪乌斯推测菲兹的师傅是阿斯拉王国的宫廷魔术师等高贵人物。
- 原文是否暗示另有真相：是。菲兹的师傅实际就是鲁迪乌斯本人（来自菲托亚领地，菲兹调查转移事件寻找的人正是鲁迪乌斯），但鲁迪乌斯对此毫无察觉。
- 原文依据："菲兹学长是公主的护卫，说不定他的师傅是宫廷魔术师之类。……「他并不是身分高贵的人士……其实……是菲托亚领地的人。」……「他还活着，已经找到人了啊。」……「咦？既然这样，为什么我没办法见到对方？」「嘻嘻……这是秘密。」"
- 角色以为：菲兹是害羞、年轻的美少年（男性学长）。
- 原文是否暗示另有真相：是。菲兹实为希露菲（女性），其遮挡斗篷、扭捏和大腿内夹等肢体动作实为少女在面对裸体奴隶及鲁迪乌斯时的羞赧反应。
- 原文依据："真是一种很像处男的反应，我也经历过那样的时期。……为什么每次看到这个笑容，自己就会心跳加速呢？我可以爱上二次元的伪娘，但是我应该绝对不是男同志啊……"
