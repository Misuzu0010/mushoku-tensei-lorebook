# 第七话　「兽族大小姐绑架监禁事件 前篇」 世界设定提取

## 一、地理与场所
- 名称：大森林
  - 内容：拥有充沛木材资源的广大森林领地。栖息着兽族各部族以及长耳族、矿坑族、小人族等，德路迪亚族为大森林各族的共同领袖。整个大森林的综合战力被评估为足以与人族大国米里斯神圣国进行全面战争。
  - 原文依据："居住在拥有充沛木材资源的大森林里的兽族也没有成为例外。"、"此外，不只对兽族，德路迪亚族的发言对长耳族、矿坑族、以及小人族等种族也有很大的影响力。是住在大森林的所有种族的领袖。综观整个大森林，被视为拥有能够和米里斯国全面战争的战力。"
- 名称：魔法大学别馆与林间广场
  - 内容：魔法大学主校舍之外独立的别馆，供部分高年级课程教学使用；从别馆通往宿舍的道路旁有一处毗邻森林、视野相对狭窄的空旷广场。
  - 原文依据："她们在和主校舍有一段距离的别馆上课。我们找出从那里前往宿舍的路线，选了一个没什么人的地方布阵。这里是一个邻近森林，不太容易看清周遭的广场。"

## 二、组织与势力
- 名称：德路迪亚族（泰德路迪亚族 / 亚德路迪亚族）
  - 内容：兽族中的领导氏族，大森林的守护者。5500年前第一次人魔大战后，由兽神基迦确立了其至高领袖地位。分为泰德路迪亚（猫系，族长为裘斯塔夫、战士长为裘耶斯）与亚德路迪亚（狗系，族长为布鲁德古、战士长为提鲁提利亚）。其发言权在大森林内的长耳族、矿坑族、小人族中皆具极大权威，直系后裔身份等同于王族公主。
  - 原文依据："出身于大森林的守护者・德路迪亚族之一的泰德路迪亚族。是族长裘斯塔夫的孙女，也是战士长兼下任族长裘耶斯的女儿。"、"出身于大森林的守护者・德路迪亚族之一的亚德路迪亚族。是族长布鲁德古的孙女，也是战士长兼下任族长提鲁提利亚的女儿。"、"「德路迪亚族」这个种族在兽族之中是特别的存在。……而这个「兽神基迦」，正是出身于德路迪亚族。所以在基迦死后，德路迪亚族依旧是大森林里众多兽族的领袖。"、"若以人族来打比方，她们就是拥有王位继承权的人物……没错，等于是公主。"
- 名称：兽族
  - 内容：世界主要种族之一，不仅盘踞在大森林，还广泛分布于中央大陆、贝卡利特大陆等地区，全族拥有匹敌米里斯神圣国的强悍武力与庞大人口规模。
  - 原文依据："然而时至今日，兽族不只居住在大森林里，也前往中央大陆和贝卡利特大陆等其他地区。总数虽然比不上人族，但也绝对不是可以等闲视之的数量。……综观整个大森林，被视为拥有能够和米里斯国全面战争的战力。因此所谓的兽族，就是具备此等武力的强大种族。"
- 名称：魔法大学前不良集团
  - 内容：由莉妮亚与普露塞娜凭借打架实力与德路迪亚族千金特权聚集的一年级混混集团。后因袭击阿斯拉第二公主爱丽儿，被护卫“沉默的菲兹”单枪匹马击溃，近二十名不良成员全被退学。
  - 原文依据："她们以一年级的身分成为不良集团的老大。……最后引发带着大批不良学生直接出手的袭击事件。于是，整群人都被菲兹学长一个人痛殴一顿。……将近二十名的袭击者遭到菲兹学长只身击退的事实并不会改变。……教师们也开会讨论，最后决定把将近二十名的袭击者全部退学。然而莉妮亚和普露塞娜并没有被退学，大概是校方判断把德路迪亚族的千金小姐退学是个不妥的下策。"
- 名称：学生会
  - 内容：拉诺亚魔法大学的学生管理机构，爱丽儿公主在一年级时便破格加入。
  - 原文依据："让不满爆发的导火线，是爱丽儿才一年级就进入学生会的事迹。"
- 名称：米里斯神殿骑士团
  - 内容：米里斯神圣国的武装宗教骑士集团，以具备狂热信仰著称。
  - 原文依据："从师傅的态度中可以感觉到的不只是憧憬，还有某种带有狂热信仰倾向的情感。没错，就跟米里斯神殿骑士团给人的感觉是一样的。"

## 三、力量体系 / 魔法 / 技能
- 名称：声音魔术（战吼）
  - 规则：德路迪亚族代代秘传的特有魔术。通过深吸气发出口部咆哮，能直接剥夺敌人的身体控制权、使其陷入全身麻痹无力的状态。该魔术难以用魔眼读取且魔力机制未知；若用沙尘等异物干扰其口腔吸气发声，能有效破除其释放。
  - 原文依据："靠着德路迪亚族代代相传的声音魔术……"、"本王子的自由被那招夺走，就这样只能被她们当猎物玩弄虐待。"、"另外一个则趁这个时候使出声音魔术让敌人无法使出力量。"、"声音魔术很难用魔眼判别，虽然事先阻止是比较好的做法，但是我不知道魔力在使用声音魔术时是如何运作。因此，我不确定「乱魔」是否会有用，只好在普露塞娜眼前制造出大量沙尘。大口吸气的普露塞娜因为吸入沙尘而用力咳嗽。"
- 名称：兽族协同战法与身体机能
  - 规则：兽族嗅觉极为敏锐（难以瞒过并实施暗中偷袭）；四肢着地冲刺速度极快；两人配合时通常由一人以高敏捷在侧翼进行骚扰佯攻，另一人担任后卫发动声音魔术封锁敌方，且二人可随时换位。
  - 原文依据："因为找不到可以瞒过德路迪亚族鼻子的方法。"、"其中之一会以高速移动并同时利用魔术等方式来扰乱敌人，另一个则趁这个时候使出声音魔术让敌人无法使出力量。虽然很单纯，但是这两人具备同等的身体能力，所以就算后卫遭到攻击，也能够立刻交换彼此负责的任务。"、"普露塞娜则像狗一样手脚着地，打算和札诺巴拉开距离。……用手脚移动的普露塞娜速度很快"
- 名称：幼童无咏唱魔术训练法则（鲁迪乌斯流）
  - 规则：每天开局仅让幼童施展一次完整的咏唱魔术，之后严禁传授咒文，强制其持续凭借无咏唱感觉生成土弹。利用幼童阶段可塑性极高的魔力特性，仅需一个月即可引导其成功使出无咏唱土魔术。
  - 原文依据："他只有在一天开始时会让茱丽使出一次利用咏唱发动的魔术，接下来就不会再传授任何咏唱，而是要茱丽一直以无咏唱方式制造土弹。……只用了短短一个月，茱丽就成功制造出土弹。而且是以无咏唱方式，实在让人吃惊。"
- 名称：奴隶禁锢印记与烙印
  - 规则：世俗防止奴隶逃匿的常规手段，一般会在买入的奴隶肉体上烫上烙印或刻画特殊的束缚魔术印记。
  - 原文依据："为了让买来的奴隶无法逃走，原本在奴隶身上烙印或是施加特殊魔术印记是一般的做法，然而师傅似乎不喜欢那种东西，购买茱丽时也没有进行这类处理。"
- 名称：实战应对（泥沼与预知眼）
  - 规则：预知眼能捕捉对手数步内的动作轨迹。泥沼配合硬化魔术能瞬间限制常规对手的机动性，但面对身经百战的上级剑士（如保罗、艾莉丝）时，对方能通过精准的平衡感或敏锐预判在陷入前闪避或煞车。
  - 原文依据："〔莉妮亚往旁边移动约三步之后，会突然改变方向对这边攻击。〕虽然她速度相当快，不过我已经发动预知眼。"、"我在普露塞娜的眼前制造出泥沼。……与此同时，我继续使出土魔术，让泥巴硬化。"、"如果是实战经验丰富的上级剑士，有能力避开泥沼这种程度的攻击。"

## 四、种族 / 生物
- 名称：德路迪亚族（泰德路迪亚族 / 亚德路迪亚族）
  - 特征：具备鲜明野兽生理习性与面貌特征。猫系（泰德路迪亚）愤怒时瞳孔收缩、尾巴竖立呼气；狗系（亚德路迪亚）喜好四足着地疾奔、龇牙、嗅觉超常；二者均为兽族贵胄。
  - 原文依据："莉妮亚张大嘴巴，瞳孔迅速收缩。她发出愤怒的呼气声，尾巴直直竖起。"、"普露塞娜动动鼻子吸气……舔了舔嘴角"、"普露塞娜则像狗一样手脚着地"
- 名称：小人族
  - 特征：居住在大森林的亚种种族之一，接受德路迪亚族的统领。
  - 原文依据："德路迪亚族的发言对长耳族、矿坑族、以及小人族等种族也有很大的影响力。"

## 五、物品 / 道具 / 武器
- 名称：1／8比例洛琪希模型
  - 说明：鲁迪乌斯以洛琪希为原型制作的原型手办，具有细致的可拆换零件与坚硬的魔杖，被札诺巴当作不可替代的神圣至宝；在与兽族二女决斗中被用作赌注输掉后惨遭摔踩粉碎。
  - 原文依据："「1／8洛琪希模型」已经很悲惨地遭到解体。头部断掉，用来换装的零件整个粉碎，手臂在手肘那里折断，脚也歪往奇怪的方向。这是凄惨的残骸，只有魔杖因为很坚固总算还保持完整。"
- 名称：瑞杰路德人偶
  - 说明：鲁迪乌斯制作的斯佩路德族战士人偶，兼具威严与力量感，妥善保存在带锁的专用宝箱中。
  - 原文依据："这是一个同时带有威胁感和强大感的战士人偶，不管什么时候欣赏都非常完美。"

## 六、历史 / 传说 / 事件
- 事件名：第一次人魔大战后的大森林防卫战（五千五百年前）
  - 内容：约5500年前第一次人魔大战人族胜利后，傲慢的人族向周边各种族宣战进犯大森林。德路迪亚族领袖「兽神基迦」挺身而出团结全兽族奋战，成功击退人族保全大森林，获尊为“兽神”。德路迪亚族由此奠定君临大森林全族的领袖历史地位。
  - 原文依据："他们的起源可以追溯到五五○○年前，第一次人魔大战之后的时期。人族和魔族的全面战争──人魔大战，这场战争的胜利者是人族。人族把魔族当成奴隶般对待，变得越来越傲慢。由于获得了压倒性的丰裕生活，人族接二连三地对其他种族宣战。居住在拥有充沛木材资源的大森林里的兽族也没有成为例外。面对逼近的大军，当时的兽族首领「兽神基迦」挺身而出。为了对抗卑劣的人族，兽神基迦团结整个兽族，自己也站在最前线奋战。据说他发挥力量，有时则是运用智慧，并且在其他兽族的协助下，最后成功守住大森林。「兽神」成为君临所有兽族顶点的男人，也是英雄之名。而这个「兽神基迦」，正是出身于德路迪亚族。"
- 事件名：爱丽儿公主遇袭事件与不良集团解散
  - 内容：爱丽儿公主入学后进入学生会，莉妮亚与普露塞娜因嫉妒纠集近二十名不良学生袭击爱丽儿，被菲兹学长单人全部击溃。校方将参与袭击的不良学生全员开除退学，但因政治考量保留了二女学籍。
  - 原文依据："最后引发带着大批不良学生直接出手的袭击事件。于是，整群人都被菲兹学长一个人痛殴一顿。……将近二十名的袭击者遭到菲兹学长只身击退的事实并不会改变。莉妮亚和普露塞娜她们两个也被菲兹学长一个人毫不留情地彻底击垮。由于事件浮上枱面，教师们也开会讨论，最后决定把将近二十名的袭击者全部退学。然而莉妮亚和普露塞娜并没有被退学，大概是校方判断把德路迪亚族的千金小姐退学是个不妥的下策。"
- 事件名：札诺巴决斗败北与洛琪希人偶被毁事件
  - 内容：札诺巴在一年级时接受莉妮亚与普露塞娜决斗，拿洛琪希人偶做赌注，因对方奇异的声音魔术败北，洛琪希人偶被二女砸碎践踏。
  - 原文依据："事情起因于自己一年级时，莉妮亚和普露塞娜前来下了战帖。那时，决定要用彼此的重要物品作为赌注，所以自己拿出了「洛琪希人偶」。……然而，那两个家伙突然使出奇妙的招式。本王子的自由被那招夺走，就这样只能被她们当猎物玩弄虐待。在无计可施的情况下，本王子吞下败仗，只能哭着交出人偶。……把人偶砸到地上，用脚又踢又踩，弄得支离破碎后还把碎片踢散。"

## 七、社会规则 / 习俗 / 文化
- 内容：决斗胜者支配准则
  - 规则：在校内混混及兽族法则中，“打输的一方必须绝对服从胜利者的支配命令”；双方下定赌注后的处置具有强制效力。
  - 原文依据："因此对她们来说，「打输的人必须服从胜利者的命令」是一种规则。莉妮亚、普露塞娜还有札诺巴三个人订出了规则，然后三个人都去遵守。"
- 内容：决斗下战书习俗（西隆 vs 德路迪亚）
  - 规则：西隆王国传统是在决斗战书中随信附带一把小刀与一朵花；德路迪亚族的开战挑战习俗则是将腐烂的果实砸向对手头顶。
  - 原文依据："在我的祖国，自古以来的规矩是要随信附上小刀和一朵花。不过在德路迪亚族中，把烂掉的果实丢到对手头上的行为好像具备相同的意义。"
- 内容：大森林领袖家族的治外法权特权
  - 规则：德路迪亚族直系血统在北方大陆魔法大学同样拥有极大外交威慑力，即便犯下严重校规违纪聚众斗殴，学校高层也因担心引发大国矛盾而放弃退学处分。
  - 原文依据："然而莉妮亚和普露塞娜并没有被退学，大概是校方判断把德路迪亚族的千金小姐退学是个不妥的下策。"

## 九、角色认知 vs 客观事实
- 角色以为（实力差距认知）：
  - 鲁迪乌斯根据二人年龄与以往被艾莉丝暴打的经验，推测莉妮亚与普露塞娜具备接近艾莉丝的强横肉搏实力，严阵以待。
