# 序章　「泥沼的冒险者」 世界设定提取

## 一、地理与场所
- 名称：巴榭兰特公国
- 内容：位于中央大陆西北部，是魔法三大国之一，在北方大地是数一数二的大国。
- 原文依据："这里是位于中央大陆西北部的巴榭兰特公国。巴榭兰特公国是魔法三大国之一，在北方大地也是数一数二的大国。"

- 名称：丕平
- 内容：巴榭兰特公国的第三都市。
- 原文依据："这国家的第三都市名为丕平。"

- 名称：北方大地
- 内容：中央大陆北部的通称。食物较贵；气候严寒，树叶落尽并有薄雪，漫长的冬季即将到来。
- 原文依据："为了寻找被转移的家人，他移动到中央大陆北部──通称「北方大地」的地区……"、"不过因为北方大地的食物较贵，其中也有些人会克制食量。"、"路上有一层薄薄积雪，树上的叶子都掉了，树枝则妆点着雪白。漫长的冬天即将到来。"

- 名称：要塞都市罗亚市 / 菲托亚领地
- 内容：阿斯拉王国菲托亚领地的城市，市长为菲利普。在转移事件后当地遭遇惨状，搜索团实质解散后难民营将经营重心从搜索改为开拓。
- 原文依据："他的儿子，要塞都市罗亚市的市长菲利普・B・格雷拉特以及其妻子也死亡。"、"菲托亚领地搜索团实质上已经解散，难民营也把经营重心从搜索改为开拓。"

## 二、组织与势力
- 名称：菲托亚领地搜索团
- 内容：转移事件后成立的民间/官方搜索组织。因大流士・席尔巴・贾尼乌斯上级大臣中止资金援助，实质上已经解散。
- 原文依据："因此，大流士・席尔巴・贾尼乌斯上级大臣中止对搜索菲托亚领民的相关资金援助。尽管还有人以个人身分继续搜索活动，然而菲托亚领地搜索团实质上已经解散，难民营也把经营重心从搜索改为开拓。"

- 名称：米里斯教团
- 内容：宗教组织，拥有正统祈祷仪轨与神明。对于信奉或安奉非米里斯教团神佛的行为会感到不快。
- 原文依据："静静地对着安奉在小箱子里的神佛献上祈祷。那东西并非来自米里斯教团。看在米里斯教团的眼里，大概会感到不快吧。"

- 名称：Thunderbolt
- 内容：活跃范围遍及巴榭兰特公国全境的冒险者集团，旗下拥有多支冒险者队伍。
- 原文依据："他率领的冒险者队伍「Stepped Leader」隶属于活跃范围遍及巴榭兰特公国全土的集团「Thunderbolt」旗下……"

- 名称：Stepped Leader
- 内容：S级武斗派冒险者队伍，隶属于集团「Thunderbolt」，队长为佐尔达特・黑克勒。主要从事迷宫探索，偶尔承接讨伐委托。队伍原为7人，因一名魔术师意外死亡，现由6名成员组成（两名剑士、一名战士、两名治愈魔术师、一名攻击魔术师）。
- 原文依据："他率领的冒险者队伍「Stepped Leader」隶属于活跃范围遍及巴榭兰特公国全土的集团「Thunderbolt」旗下，是主要从事迷宫探索，偶尔也会承接讨伐委托的武斗派队伍。「Stepped Leader」由六名成员组成。两名剑士，一名战士，两名治愈魔术师，一名攻击魔术师。原本是七人队伍，但是在一名魔术师因为意外事故死亡之后，现在缺少攻击火力。"

- 名称：Rod Knights
- 内容：A级冒险者队伍，参与讨伐脱队赤龙。
- 原文依据："A级队伍「Rod Knights」。"

- 名称：铁块兵团
- 内容：A级冒险者队伍，参与讨伐脱队赤龙。
- 原文依据："A级队伍「铁块兵团」。"

- 名称：Cave A Mondo
- 内容：A级冒险者队伍（4人），原计划参与赤龙讨伐，后因认为讨伐人数过少无法打赢而主动退出。
- 原文依据："A级队伍「Cave A Mondo」"、"「Cave A Mondo」的四人退出，现在剩下二十一人。"

- 名称：醉汉的胡言乱语
- 内容：A级冒险者队伍，参与讨伐脱队赤龙。
- 原文依据："A级队伍「醉汉的胡言乱语」。"

- 名称：Big Voice乐团
- 内容：C级冒险者队伍，由三名兼任吟游诗人的冒险者组成，在酒馆舞台演奏说书并创作冒险谭。
- 原文依据："队伍名是「Big Voice乐团」……记得应该是C级的队伍。"

## 三、力量体系 / 魔法 / 技能
- 名称：泥沼魔术
- 规则：土与水复合系魔术。能瞬间在目标地面生成具备高度黏性的泥坑泥浆，有效限制目标行动；施术者灌注更多魔力可使泥沼黏性倍增，能强行困住赤龙等级的巨兽。
- 原文依据："他前方瞬间出现具备高度黏性的泥坑。正如「泥沼」这个别称，他很擅长能制造出泥沼的魔术。多达十几只的拉斯塔熊群被突然在眼前出现的泥巴绊住脚，动作也因此变慢。"、"原来是在赤龙逃走的方向有一个泥坑，它已经陷入具备高度黏性的泥浆里。泥沼送出更多魔力。赤龙不断乱动试图逃出泥坑，周围的泥巴却产生更强烈的黏性。"

- 名称：浓雾 / 水蒸气烟幕
- 规则：利用火魔术快速融化周围积雪产生大量水蒸气形成墙壁，作为临时掩体烟幕迷惑敌人视线。
- 原文依据："泥沼用熟练的动作施展火魔术，融化周围的积雪，制造出水蒸气形成的墙壁。这是利用大自然来临时制造出的烟幕，老练的魔术师会像这样来欺骗敌人的眼睛。"

- 名称：水墙魔术
- 规则：迅速制造大面积水幕屏障，能抵挡高温冲击与赤龙的烈火吐息。
- 原文依据："泥沼迅速回过身子，制造出巨大的水墙。接着撞开冉冉上升的水蒸气，继续行动。"

- 名称：岩石炮弹 / 岩块攻击
- 规则：制造高密度岩石并以极高速度射出，具备穿透赤龙坚硬龙鳞的强大物理杀伤力；亦可凝聚巨大岩块进行重击。
- 原文依据："制造出岩石炮弹。高速射出的炮弹打穿赤龙的鳞片。"、"然后把巨大的岩块击向还在挣扎的赤龙。"

- 名称：剑术流派（剑神流 / 水神流）
- 规则：剑术存在明确体系与阶级，如佐尔达特习得「剑神流上级」与「水神流中级」。
- 原文依据："是习得剑神流上级与水神流中级的剑士，也是这一带有名的冒险者之一。"

## 四、种族 / 生物
- 名称：赤龙（脱队龙）
- 特征：中央大陆最强生物，虽长于空中飞行但四肢强韧、地面行动极快且敏捷。拥有狡诈与高智慧，会优先锁定并排除最具威胁的目标。其必杀技为口中喷出的「火焰气息」，能将生物化为灰烬。鳞片坚硬无比。被击杀后若尸体残骸未被彻底烧毁，有转变为僵尸龙的风险。素材包括龙鳞、龙骨和龙肉，价值极高。
- 原文依据："和龙群分散，落到地上的中央大陆最强生物。"、"虽然赤龙是在空中飞行的生物，却拥有强韧的四肢，实际动作比外观印象更加轻快。即使坠地，龙依旧是非常强大的生物。"、"脱队龙很狡猾，也拥有智慧，至少知道首先该排除最具威胁性的敌人。"、"这是赤龙的必杀技，火焰气息。要是被直接击中，任何生物都会被烧成灰烬。"、"等大家尽量拿完之后，剩下的部分我会全部烧毁。因为万一变成僵尸龙可就麻烦了。"、"今天的收获是赤龙的素材，鳞片、骨头、龙肉。"

- 名称：拉斯塔熊
- 特征：北方大地的群居熊型魔物，行动速度极快，成群奔跑会在雪原上掀起大片白烟；在生态链中是赤龙的捕食猎物。
- 原文依据："「两点钟方向有一大群拉斯塔熊，在雪地上激起好大一片白烟！」「有几只？」「八……不，有十只！它们已经注意到我们！直直朝着这边前进！速度很快！」"、"它的猎物是拉斯塔熊群。"

- 名称：长耳族
- 特征：人亚族之一，外貌特征为细长的双眼、长长的耳朵、闪亮金发、身形苗条、胸部平坦。
- 原文依据："门口站着一个发型活像是法国长棍面包的长耳族。……她拥有细长的双眼，长长的双耳，闪亮的金发。那苗条的身材与平坦的胸部，再加上一对长耳，完全是标准的长耳族。"

- 名称：僵尸龙 [存疑]
- 特征：死去的龙尸若未及时且完全焚毁，可能异变转化而成的亡灵不死魔物。
- 原文依据："等大家尽量拿完之后，剩下的部分我会全部烧毁。因为万一变成僵尸龙可就麻烦了。"

## 五、物品 / 道具 / 武器
- 名称：木雕项链坠子
- 说明：莉莉雅赠予鲁迪乌斯的护身坠饰。艾莉娜丽洁剑鞘上也佩戴有同款式样但工艺更精湛（专业级）的坠子。
- 原文依据："是莉莉雅给我的项链坠子。「哎呀，真是个不精致但很可爱的东西呢。是什么人送你的？」「是我家的女仆。」……艾莉娜丽洁以不是特别在意的态度，把自己腰间剑鞘上挂着的东西拿给我看。是同样造型的坠子。不过，制作得比我的精巧。如果说我这个是业余级的作品，她那个就是专业级的作品。"

- 名称：祈祷神龛木盒
- 说明：鲁迪乌斯早晚用来祈祷的神盒（内部供奉物为洛琪希的圣物），非米里斯教团物品。
- 原文依据："静静地对着安奉在小箱子里的神佛献上祈祷。那东西并非来自米里斯教团。看在米里斯教团的眼里，大概会感到不快吧。"

## 六、历史 / 传说 / 事件
- 事件名：菲托亚领地转移事件（魔力灾害）
- 内容：甲龙历四一七年发生的特大灾难（本章为甲龙历四二二年，灾害已过去五年）。灾害导致菲托亚领主绍罗斯死亡，罗亚市长菲利普与其妻死亡，随后艾莉丝也被报告死亡。阿斯拉王国大臣大流士中止搜索资金，官方宣布事件落幕并解散搜索团，难民营转为开拓。
- 原文依据："通称为「菲托亚领地转移事件」的这场灾害之后过了五年。领主绍罗斯・B・格雷拉特死亡。他的儿子，要塞都市罗亚市的市长菲利普・B・格雷拉特以及其妻子也死亡。而且这些报告过后不久，菲利普的女儿艾莉丝・B・格雷拉特也被报告已经死亡。因此，大流士・席尔巴・贾尼乌斯上级大臣中止对搜索菲托亚领民的相关资金援助。尽管还有人以个人身分继续搜索活动，然而菲托亚领地搜索团实质上已经解散，难民营也把经营重心从搜索改为开拓。如此这般，对阿斯拉王国而言，转移事件已经落幕。"

## 七、社会规则 / 习俗 / 文化
- 讨伐龙的作战编制常规：
  - 单一冒险者队伍挑战龙等同自杀，常规必须由多支队伍联合作战；为保证万全，标准编制通常需要7支队伍以上（近40人规模）。
  - 原文依据："讨伐龙的任务通常由多个队伍一起进行，单一队伍去挑战是自杀行为。"、"进行讨伐龙的委托时，一般认为若想万全，最好要有七支队伍以上，也就是将近四十人的参加成员。"

- 冒险者饮食习俗：
  - 冒险者平均食量通常是一般人的两至三倍。但在物价高昂的北方大地，部分冒险者会刻意节制饮食。
  - 原文依据："据说冒险者的平均食量是一般人的两倍或三倍。不过因为北方大地的食物较贵，其中也有些人会克制食量。"

- 吟游诗人行业文化：
  - 属于在酒馆舞台演奏说书赚取打赏的行业，大型城镇中会与剧院签订独家契约。
  - 许多冒险者兼任吟游诗人，将亲身经历或采访其他冒险者的见闻改编为冒险谭诗歌以此谋生。
  - 该世界不存在著作权概念，互相改编、合并彼此诗歌是行业常态；吟游诗人队伍通常也具备基本的战斗防身能力。
  - 原文依据："吟游诗人，这是在酒馆舞台等地方演奏唱歌或弹曲说书以赚取打赏的职业。在比较大的城镇，据说也会和剧场等地缔结专属合约。……冒险者里也有相当多人的职业是「吟游诗人」。他们会把自己和其他冒险者一起旅行的过程写成诗歌，或是找经历过有趣冒险的人探听详情并改写成冒险谭……在没有着作权的这个世界里，把别人的诗歌改编成自己版本的行为是家常便饭……"
